# Decoy

**Pequeños procesos sustitutos que hacen creer a Discord que un juego se está ejecutando.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca de Decoy con juegos recientes e ilustraciones" />

</div>

Decoy mantiene en ejecución un proceso sustituto inofensivo con ventana bajo el nombre de ejecutable de un juego, de modo que la detección de juegos de Discord reporta que estás jugando a ese juego. Nunca necesitas instalar ni iniciar el juego real, por lo que nada pesado ocupa espacio en tu disco.

Conoce **todos los juegos que Discord puede detectar** (alrededor de 25,000 entradas) porque lee la propia lista pública de detección de Discord y la mantiene actualizada automáticamente.

> [!WARNING]
> Simular la ejecución de un juego puede ir en contra de los Términos de Servicio de Discord y utilizas Decoy **bajo tu propio riesgo**.
> Este proyecto no está afiliado, respaldado ni vinculado a Discord Inc. Consulta el [Descargo de responsabilidad](#descargo-de-responsabilidad).

## Características

- **Todo lo que Discord puede detectar.** La lista de juegos se descarga desde el endpoint público de detección de Discord, se guarda en caché localmente y se actualiza a diario. Los juegos nuevos y los ejecutables agregados recientemente aparecen automáticamente.
- **Búsqueda que sigue el ritmo.** Búsqueda instantánea por nombre de juego o ejecutable entre miles de juegos, vista de cuadrícula o lista compacta, favoritos y una fila de «Recientes».
- **Un solo clic.** Elige un juego, selecciona el ejecutable (si hay varios), define cuánto tiempo mantenerlo y presiona iniciar. Un anillo de cuenta regresiva y una notificación te avisan cuando se acaba el tiempo.
- **No deja rastro.** Un señuelo solo existe mientras se ejecuta: el pequeño exe se crea al iniciar y se elimina al detener. Todo se detiene al salir, y los restos tras un cierre inesperado se limpian en el siguiente inicio.
- **Discreto.** Permanece en la bandeja del sistema, sin ventanas ni botones en la barra de tareas para los señuelos en sí.
- **Traducciones abiertas.** La interfaz se basa en archivos JSON simples, por lo que agregar un idioma es cuestión de un solo archivo. Se incluyen inglés y ruso.
- **Privado.** Sin cuenta, sin token de Discord, sin telemetría. Consulta [Privacidad](#privacidad).

## Cómo funciona

1. Discord determina que estás jugando a un juego al observar los procesos en ejecución en tu PC y comparar sus nombres de ejecutable con una lista pública (`/api/v9/applications/detectable`).
2. Decoy descarga esa lista y, para el juego que elijas, copia un diminuto programa sustituto (de unos 120 KB, escrito en Rust e incrustado en Decoy) en una carpeta temporal utilizando el nombre del ejecutable de la lista, por ejemplo `.../cod26-cod.exe`.
3. El sustituto no hace nada salvo tener una ventana de nivel superior, ubicada muy lejos fuera de la pantalla para que nunca la veas. Discord solo reconoce un proceso si tiene una ventana, razón por la cual un proceso completamente sin ventanas es ignorado.
4. En aproximadamente 15 segundos, Discord muestra el juego como tu actividad actual.
5. Cuando el temporizador finaliza o presionas detener, Decoy finaliza el proceso y elimina el archivo. Un objeto de trabajo de Windows garantiza que los señuelos terminen junto con Decoy, incluso si este se cierra de forma inesperada.

## Instalación

Elige uno en la página de [Releases](../../../../releases):

| Descarga | Para |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por usuario, no requiere permisos de administrador, agrega una entrada en el menú Inicio y un desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Descomprime en cualquier lugar y ejecuta `decoy.exe`. Todos los datos se guardan en la carpeta `data` junto a él, no se escribe nada en tu perfil de usuario. Elimina la carpeta para borrarlo. |

Verifica una descarga con `SHA256SUMS.txt` (`Get-FileHash <file>` en PowerShell).

Windows SmartScreen puede advertir sobre un editor no reconocido debido a que las compilaciones no están firmadas digitalmente; selecciona *Más información → Ejecutar de todas formas* si confías en la compilación.

Requisitos: Windows 10 u 11 (64 bits) con el runtime de WebView2 (ya incluido en Windows 11 y en actualizaciones recientes de Windows 10).

## Uso

1. Abre la **Biblioteca** y busca un juego, o presiona `Ctrl` + `K` desde cualquier lugar.
2. Haz clic en un juego. En el panel de la derecha, elige el proceso y cuántos minutos mantenerlo (las actividades de Discord suelen requerir 15).
3. Presiona **Iniciar señuelo**. Discord mostrará el juego después de unos segundos.
4. Obsérvalo en **En ejecución**, detén uno o todos en cualquier momento, o simplemente deja Decoy en la bandeja del sistema.

Los juegos cuya entrada en Discord aún no tiene ejecutables están ocultos de forma predeterminada (no pueden ser detectados). Activa *Mostrar juegos sin exe* para verlos; la lista se actualiza a diario, por lo que estarán disponibles tan pronto como Discord agregue un proceso.

### Línea de comandos

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Inicia un señuelo de inmediato, por ejemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar desde el código fuente

Requisitos previos: [Node.js](https://nodejs.org) 20+, la cadena de herramientas estable de [Rust](https://rustup.rs) (destino MSVC) con las herramientas de compilación de Visual Studio C++, y el runtime de WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Comprobaciones útiles:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notas: el exe del señuelo es compilado por `src-tauri/build.rs` con `rustc` directamente desde `src-tauri/stub/stub.rs` y luego se incrusta en la aplicación. Cuando el frontend se ejecuta en un navegador convencional (`npm run dev`), se utiliza un pequeño backend simulado (`src/mock.ts`), lo cual resulta práctico para trabajar en la interfaz de usuario.

## Traducciones

Las cadenas de la interfaz residen en [`src/locales`](../../src/locales), un archivo JSON por idioma (`en.json`, `ru.json`, ...). Agregar un idioma significa agregar un archivo; sin cambios de código. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) para conocer el formato del archivo, un prompt listo para usar en traducción automática y el script de validación. Las traducciones de este README van en `docs/i18n/README.<code>.md`.

## Estructura del proyecto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacidad

- Decoy solo utiliza la red para descargar la lista pública de detección de Discord (en el primer inicio, y luego como máximo una vez al día o cuando presionas actualizar) y, para su visualización, los iconos e ilustraciones de los juegos desde la CDN pública de Discord.
- No lee, no almacena ni envía tu token de Discord ni ningún dato de tu cuenta, y no se comunica con el cliente de Discord.
- La configuración (favoritos, idioma, duraciones) se almacena localmente en el almacenamiento WebView de la aplicación; la caché de la lista de juegos y los archivos temporales de los señuelos residen en `%LOCALAPPDATA%\app.decoy.desktop`.
- Sin analíticas, sin informes de fallos y sin cuentas.

## Limitaciones conocidas

- Discord puede modificar el funcionamiento de la detección en cualquier momento. Si un señuelo deja de ser reconocido, abre un reporte de problema (issue).
- Algunas actividades requieren algo más que un proceso en ejecución (por ejemplo, estar dentro de una experiencia particular en una plataforma de juegos). Decoy solo imita el proceso.
- Las entradas sin ejecutables en la lista de Discord no se pueden detectar.
- En ocasiones, el software de seguridad marca pequeños ejecutables no firmados que permanecen inactivos en la memoria. El señuelo es de código abierto y está compilado a partir de `src-tauri/stub/stub.rs`; puedes compilarlo tú mismo.
