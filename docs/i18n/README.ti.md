# Decoy

**Discord ጸወታ ይጻወት ከም ዘሎ ንክሓስብ ዝገብሩ ደቀቕቲ ተተካእቲ መስርሓት (processes)።**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="ናይ Decoy ቤተ-መጽሓፍ ምስ ናይ ቀረባ ጸወታታትን ስእልታትን" />

</div>

Decoy ጉድኣት ዘይብሉን ኣብ መስኮት ዝርአን ተተካኢ መስርሕ ብስም executable ናይ ሓደ ጸወታ ከም ዝሰርሕ ይገብር፤ በዚ ኸኣ Discord ነቲ ጸወታ ትጻወቶ ከም ዘለኻ ይሕብር። ነቲ ሓቀኛ ጸወታ ምትካል ወይ ምጅማር ኣየድልየካን እዩ፣ ስለዚ ኣብ ዲስክኻ ዝኾነ ዓቢ ቦታ ዝሕዝ ነገር ኣይህሉን።

Discord **ከለልዮም ዝኽእል ኩሎም ጸወታታት** (ኣስታት 25,000 ዝኾኑ) ይፈልጥ እዩ፣ ምኽንያቱ ናይ Discord ባዕሉ ህዝባዊ ዝርዝር መላለዪ ስለ ዘንብብን ባዕሉ ብባዕሉ እዋናዊ ስለ ዝገብሮን።

> [!WARNING]
> ጸወታ ይካየድ ከም ዘሎ ምምሳል ምስ ናይ Discord ውዕል ኣገልግሎት (Terms of Service) ክጋጮ ይኽእል እዩ፣ ከምኡ’ውን Decoy እትጥቀመሉ **ኣብ ናትካ ሓላፍነት** ጥራይ እዩ።
> እዚ ፕሮጀክት ምስ Discord Inc. ዝኾነ ምትእስሳር፣ ደገፍ ወይ ርክብ የብሉን። [ሓላፍነት ምእላይ](#ሓላፍነት-ምእላይ) ርአ።

## ባህርያት

- **Discord ከለልዮ ዝኽእል ኩሉ ነገር።** ዝርዝር ጸወታታት ካብ ናይ Discord ህዝባዊ endpoint ይወርድ፣ ኣብ ውሽጢ ኮምፒውተርካ ብካሽ ይዕቀብ ከምኡ’ውን መዓልታዊ ይሕደስ። ሓደስቲ ጸወታታትን ሓደስቲ ዝተወሰኹ executables ብባዕሎም ይረኣዩ።
- **ቅልጡፍ ፍለጋ።** ብስም ጸወታ ወይ executable ኣብ ኣሽሓት ጸወታታት ቅልጡፍ ፍለጋ፣ ብሰሌዳ ወይ ብዝተጠርነፈ ዝርዝር ምርኣይ፣ ዝተመረጹን ናይ "ቀረባ" መስርዕን።
- **ብሓንቲ ጠውቂ።** ጸወታ ምረጽ፣ executable ምረጽ (ብዙሓት እንተ ሃልዮም)፣ ክንደይ ግዜ ክጸንሕ ከም ዘለዎ ወስን እሞ ጀምር ጠውቕ። ናይ ግዜ ቆጻሪ ቀለበትን ምልክታን እቲ ግዜ ምስ ተወድአ ይሕብሩኻ።
- **ዝኾነ ኣሰር ኣይገድፍን።** ሓደ decoy ዝህልዎ ኣብ ዝሰርሓሉ እዋን ጥራይ እዩ: እታ ንእሽቶ exe ክጅምር ከሎ ትፍጠር፣ ደው ክብል ከሎ ድማ ትስረዝ። መተግበሪኡ ክዕጾ ከሎ ኩሉ ደው ይብል፣ ኣብ ድንገታዊ ምዕጻው (crash) ዝተረፉ ነገራት ድማ ኣብ ዝቕጽል ምኽፋት ይጸርጉ።
- **ህዱእ።** ኣብ system tray ይነብር፣ ንdecoys ዝኾኑ መስኮታት ወይ ናይ taskbar መልጎማት የለውን።
- **ክፉት ትርጉማት።** እቲ መተሓላለፊ ብቀለልቲ JSON ፋይላት ዝምራሕ እዩ፣ ስለዚ ቋንቋ ምውሳኽ ሓንቲ ፋይል ምውሳኽ ጥራይ እዩ። እንግሊዝኛን ሩስኛን ተኻቲቶም ኣለዉ።
- **ውልቃውነት ዝተሓለወ።** ኣካውንት ኣየድልን፣ ናይ Discord token የለን፣ ናይ ቴሌሜትሪ መረዳእታ ምእካብ የለን። [ውልቃውነት](#ውልቃውነት) ርአ።

## ከመይ ይሰርሕ

1. Discord ኣብ ኮምፒውተርካ ዝሰርሑ መስርሓት (processes) ብምርኣይን ናይ executable ስሞም ምስ ህዝባዊ ዝርዝር (`/api/v9/applications/detectable`) ብምውድዳርን ጸወታ ትጻወት ከም ዘለኻ ይውስን።
2. Decoy ነቲ ዝርዝር የውርዶ፣ ነቲ ዝመረጽካዮ ጸወታ ድማ ካብቲ ዝርዝር ዝተረኽበ ናይ executable ስም ብምጥቃም ንእሽቶ ተተካኢ ፕሮግራም (ኣስታት 120 KB፣ ብRust ዝተጻሕፈን ኣብ ውሽጢ Decoy ዝተኻተተን) ናብ ግዝያዊ ፎልደር ይቐድሖ፣ ንኣብነት `.../cod26-cod.exe`።
3. እቲ ተተካኢ ፕሮግራም ንስኻ ከይትርእዮ ካብ ስክሪን ኣዝዩ ርሒቑ ካብ ዝቕመጥ ሓደ ላዕለዋይ መስኮት (top-level window) ወጻኢ ዋላ ሓደ ኣይገብርን። Discord መስኮት ዘለዎ መስርሕ ጥራይ እዩ ዘለሊ፣ መስኮት ዘይብሉ መስርሕ ሸለል ዝበሃለሉ ምኽንያት ድማ እዚ እዩ።
4. ኣብ ውሽጢ ኣስታት 15 ካልኢት Discord ነቲ ጸወታ ከም ናይ ሕጂ ንጥፈትካ ገይሩ የርእዮ።
5. እቲ ግዜ ቆጻሪ ምስ ተወድአ ወይ ደው መበሊ ምስ ጠወቕካ፣ Decoy ነቲ መስርሕ የቋርጾ ነቲ ፋይል ድማ ይስርዞ። ናይ Windows job object እቲ ኣፕ እንተ ተበላሸወ እኳ (crash እንተ ገበረ) decoys ምስ Decoy ሓቢሮም ከም ዝጠፍኡ የረጋግጽ።

| ምውራድ | ንምንታይ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **መተከሊ (Installer)።** ንሓደ ተጠቃሚ ጥራይ፣ ናይ ኣመሓዳሪ (administrator) ፍቓድ ኣየድልዮን፣ ናይ Start menu መእተዊን መውጽእን (uninstaller) ይውስኽ። |
| `Decoy_x.y.z_x64-portable.zip` | **ተንቀሳቓሲ (Portable)።** ኣብ ዝደለኻዮ ቦታ ፈቲሕካ `decoy.exe` ኣስርሕ። ኩሉ ዳታ ኣብ ጎኑ ኣብ ዘሎ ናይ `data` ፎልደር ይጸንሕ፣ ኣብ ናይ ተጠቃሚ ፕሮፋይልካ ዝጸሓፍ ነገር የለን። ንምእላይ ነቲ ፎልደር ሰርዞ። |

ነቲ ዝወረደ ፋይል ብ`SHA256SUMS.txt` ኣረጋግጽ (ኣብ PowerShell `Get-FileHash <file>`)።

እቶም builds ብዲጂታል ፊርማ (code signed) ስለ ዘይተገብሩ Windows SmartScreen ዘይተፈልጠ ኣሕታሚ ኢሉ መጠንቀቕታ ከርኢ ይኽእል እዩ፤ ነቲ build እንተ ኣሚንካዮ *More info → Run anyway* ዝብል ምረጽ።

ዘድልዩ ነገራት: Windows 10 ወይ 11 (64-bit) ምስ WebView2 runtime (ኣብ Windows 11 ከምኡ’ውን ኣብ ናይ ቀረባ እዋን ናይ Windows 10 ሓደስቲ ሕታማት ድሮ ዝተኻተተ)።

## ኣጠቓቕማ

1. **ቤተ-መጽሓፍ** ክፈት እሞ ጸወታ ድለ፣ ወይ ካብ ዝኾነ ቦታ `Ctrl` + `K` ጠውቕ።
2. ኣብ ሓደ ጸወታ ጠውቕ። ኣብ የማናይ ሸነኽ ዘሎ ፓነል ነቲ መስርሕን ክንደይ ደቓይቕ ክጸንሕ ከም ዘለዎን ምረጽ (ናይ Discord ንጥፈታት መብዛሕትኡ ግዜ 15 ደቒቕ ይሓቱ)።
3. **Decoy ጀምር** ጠውቕ። Discord ድሕሪ ሒደት ካልኢታት ነቲ ጸወታ ከርእዮ እዩ።
4. ኣብ ትሕቲ **ዝሰርሑ ዘለዉ** ተዓዘቦ፣ ሓዲኡ ወይ ንኹሎም ኣብ ዝኾነ እዋን ደው ኣብሎም፣ ወይ ድማ ንDecoy ኣብ tray ሕደጎ።

ናይ Discord መዝገቦም ገና executables ዘይብሎም ጸወታታት ብቀዳምነት ሕቡኣት እዮም (ክልለዩ ኣይክእሉን እዮም)። ንዓታቶም ንምርኣይ *exe ዘይብሎም ጸወታታት ኣርኢ* ዝብል ኣበርክቶ፤ እቲ ዝርዝር መዓልታዊ ስለ ዝሕደስ Discord መስርሕ ምስ ወሰኸሎም ቀልጢፎም ድሉዋት ይኾኑ።

### መስመር ትእዛዝ (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ንdecoy ብቀጥታ የብግሶ፣ ንኣብነት `decoy.exe --launch "robloxplayerbeta.exe" 15`።

## ካብ ምንጪ ምህናጽ (Build from source)

ቅድመ-ኩነታት: [Node.js](https://nodejs.org) 20+፣ ስሩዕ ናይ [Rust](https://rustup.rs) መሳርሒታት (MSVC target) ምስ Visual Studio C++ build tools፣ ከምኡ’ውን WebView2 runtime።

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # ኣብ ምምዕባል ሁነታ ብhot reload ኣስርሕ
npm run tauri build    # መተከሊኡ ኣብ src-tauri/target/release/bundle/nsis ኣዳሉ
```

ጠቐምቲ ፍተሻታት:

```bash
npm run check-locales  # ነፍሲ ወከፍ ናይ ትርጉም ፋይል ምስ ru.json ኣረጋግጽ
npx tsc --noEmit       # ዓይነታት ናይ frontend ኣረጋግጽ
cargo check --manifest-path src-tauri/Cargo.toml
```

መተሓሳሰቢታት: ናይ decoy exe ብ`src-tauri/build.rs` ኣቢሉ ብቐጥታ ብ`rustc` ካብ `src-tauri/stub/stub.rs` ተጠርኒፉ (compiled) ኣብቲ ኣፕ ይካተት። እቲ frontend ኣብ ንቡር መርበብ ሓበሬታ (browser) ክሰርሕ ከሎ (`npm run dev`) ንእሽቶ mock backend (`src/mock.ts`) ጥቕሚ ኣብ ልዕሊ ይውዕል፣ እዚ ድማ ኣብ UI ንምስራሕ ምቹእ እዩ።

## ትርጉማት

ናይ UI ጽሑፋት ኣብ [`src/locales`](../../src/locales) ይርከቡ፣ ንነፍሲ ወከፍ ቋንቋ ሓደ JSON ፋይል (`en.json`, `ru.json`, ...)። ቋንቋ ምውሳኽ ማለት ሓደ ፋይል ምውሳኽ እዩ፤ ምንም ናይ ኮድ ለውጢ የለን። ንቅርጺ ፋይል፣ ንማሽን ትርጉም ድሉው ዝኾነ prompt ከምኡ’ውን መረጋገጺ ስክሪፕት [docs/TRANSLATING.md](../TRANSLATING.md) ርአ። ናይዚ README ትርጉማት ናብ `docs/i18n/README.<code>.md` ይኸዱ።

```
src/                    React + TypeScript frontend
  components/           Library፣ ዝርዝር ፓነል፣ settings፣ ...
  locales/              ፋይላት ትርጉም (ንሓደ ቋንቋ ሓደ JSON)
  i18n-core.ts          ጽዕነትን ፍለጋን ቋንቋ

src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            መዝገብ ጸወታታት፣ ናይ decoy መስርሓት፣ tray
  stub/stub.rs          እቲ ዝካተት ተተካኢ ፕሮግራም
```

## ውልቃውነት

- Decoy መርበብ ሓበሬታ (network) ዝጥቀመሉ ናይ Discord ህዝባዊ ዝርዝር ንምውራድ ጥራይ እዩ (ኣብ ፈለማ ምጅማር፣ ድሕሪኡ ኣብ መዓልቲ ሓንሳብ ወይ ሓድሽ ክትጠውቕ ከለኻ) ከምኡ’ውን ንምርኣይ ዝኸውን ኣርማታት ጸወታን ስእልታትን ካብ ናይ Discord ህዝባዊ CDN ንምውራድ ጥራይ እዩ።
- ናትካ Discord token ወይ ዝኾነ ናይ ኣካውንት ዳታ ኣየንብብን፣ ኣይዕቅብን ወይ ኣይሰድን እዩ፣ ከምኡ’ውን ምስ ናይ Discord client ኣይዘራረብን።
- ቅጥዕታት (ዝተመረጹ፣ ቋንቋ፣ ናይ ጸንሒት ግዜታት) ኣብ ውሽጢ መተግበሪ ኣብ ዘሎ WebView ማዕከን ይዕቀቡ፤ ናይ ጸወታ ዝርዝር ካሽን ግዝያውያን ናይ decoy ፋይላትን ኣብ `%LOCALAPPDATA%\app.decoy.desktop` ይነብሩ።
- ናይ ኣሰራርሓ መጽናዕቲ (analytics) የለን፣ ናይ ብልሽት ጸብጻብ የለን፣ ኣካውንት የለን።

## ፍሉጣት ደረታት

- Discord ኣሰራርሓ ምልላይ ኣብ ዝኾነ እዋን ክቕይሮ ይኽእል እዩ። ሓደ decoy ምልላዩ እንተ ኣቋሪጹ፣ በጃኹም issue ክፈቱ።
- ገለ ንጥፈታት ካብ ዝሰርሕ መስርሕ ንላዕሊ የድልዮም (ንኣብነት ኣብ ውሽጢ ሓደ ናይ ጸወታ መድረኽ ፍሉይ ተመክሮ ምህላው)። Decoy ነቲ መስርሕ ጥራይ እዩ ዝመስሎ።
- ኣብ ዝርዝር Discord executables ዘይብሎም መዛግብቲ ክልለዩ ኣይክእሉን እዮም።
- ናይ ድሕንነት ሶፍትዌራት ሓሓሊፎም ኣብ ዝኽሪ (memory) ስራሕ ፈቲሖም ዝቕመጡ ዘይተፈርሙ ደቀቕቲ executables ከጠራጥሩ ይኽእሉ እዮም። እቲ decoy ክፉት ምንጪ (open source) እዩ ካብ `src-tauri/stub/stub.rs` ዝተሃንጸ ድማ እዩ፤ ባዕልኻ ክትጥርንፎ (compile ክትገብሮ) ትኽእል ኢኻ።

Decoy ንውልቃዊ፣ ንትምህርታዊ ከምኡ’ውን ንፈተነ ዕላማታት ጥራይ “ከም ዘለዎ” (as is) ዝቐረበ እዩ። ዝሰርሕ ጸወታ ምምሳል ነቲ ናይ Discord ወይ ናይቲ ጸወታ ኣሕታሚ ውዕል ኣገልግሎት (Terms of Service) ክጥሕስ ይኽእል እዩ፣ ከምኡ’ውን ኣብ ኣካውንትካ ስጉምቲ ከስዕብ ይኽእል እዩ። ብኸመይ ከም እትጥቀመሉ ባዕልኻ ጥራይ ኢኻ ተሓታቲ። "Discord" ከምኡ’ውን ኩሎም ናይ ጸወታ ስማትን ኣርማታትን ናይ ዝምልከቶም ወነንቲ ንግዳዊ ምልክታት እዮም፣ ኣብዚ ድማ ነቲ ዘመልክትዎ ሶፍትዌር ንምልላይ ጥራይ ዝጠቐሙ እዮም።
