# Decoy

**Drobné zástupné procesy, vďaka ktorým si Discord myslí, že beží hra.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Knižnica Decoy s nedávnymi hrami a obrázkami" />

</div>

Decoy udržiava v chode neškodný zástupný proces s oknom pod názvom spustiteľného súboru hry, takže detekcia hier v Discorde hlási, že danú hru hráte. Skutočnú hru nemusíte nikdy inštalovať ani spúšťať, takže na vašom disku nezaberá žiadne miesto.

Vie o **každej hre, ktorú Discord dokáže detegovať** (približne 25 000 položiek), pretože číta vlastný verejný detekčný zoznam Discordu a sám ho udržiava aktuálny.

> [!WARNING]
> Predstieranie bežiacej hry môže byť v rozpore so Zmluvnými podmienkami Discordu a Decoy používate **na vlastné riziko**.
> Tento projekt nie je spojený so spoločnosťou Discord Inc., nie je ňou podporovaný ani schválený. Pozrite si časť [Vyhlásenie o vylúčení zodpovednosti](#vyhlásenie-o-vylúčení-zodpovednosti).

## Funkcie

- **Všetko, čo Discord dokáže detegovať.** Zoznam hier sa sťahuje z verejného koncového bodu Discordu pre detekciu, ukladá sa do lokálnej vyrovnávacej pamäte a denne sa obnovuje. Nové hry a novo pridané spustiteľné súbory sa objavujú automaticky.
- **Vyhľadávanie, ktoré drží krok.** Okamžité vyhľadávanie podľa názvu hry alebo spustiteľného súboru medzi tisíckami hier, zobrazenie v mriežke alebo kompaktnom zozname, obľúbené položky a riadok „Nedávne“.
- **Jedno kliknutie.** Vyberte hru, zvoľte spustiteľný súbor (ak je ich viacero), zvoľte, ako dlho má bežať, a stlačte spustiť. Odpočítavací kruh a upozornenie vás informujú, keď čas vyprší.
- **Nezanecháva po sebe nič.** Návnada existuje iba počas svojho behu: drobný exe súbor sa vytvorí pri spustení a vymaže pri zastavení. Všetko sa ukončí pri zatvorení aplikácie a prípadné zvyšky po páde sa upracú pri ďalšom spustení.
- **Nenápadný.** Beží v systémovej lište (system tray), žiadne okná ani tlačidlá na paneli úloh pre samotné procesy návnady.
- **Otvorené preklady.** Rozhranie je riadené čistými JSON súbormi, takže pridanie jazyka znamená pridanie jediného súboru. Angličtina a ruština sú súčasťou.
- **Súkromný.** Žiadny účet, žiadny token Discordu, žiadna telemetria. Pozrite si časť [Súkromie](#súkromie).

## Ako to funguje

1. Discord zisťuje, že hráte hru, kontrolou procesov bežiacich na vašom PC a porovnávaním názvov ich spustiteľných súborov s verejným zoznamom (`/api/v9/applications/detectable`).
2. Decoy tento zoznam stiahne a pre vybranú hru skopíruje drobný zástupný program (približne 120 KB, napísaný v Rust a integrovaný v Decoy) do dočasného priečinka pod názvom spustiteľného súboru zo zoznamu, napríklad `.../cod26-cod.exe`.
3. Tento zástupný program nerobí nič okrem udržiavania jedného okna najvyššej úrovne umiestneného ďaleko mimo obrazovky, takže ho nikdy neuvidíte. Discord rozpoznáva iba procesy, ktoré vlastnia okno – proces úplne bez okien ignoruje.
4. Počas približne 15 sekúnd Discord zobrazí hru ako vašu aktuálnu aktivitu.
5. Keď časovač vyprší alebo stlačíte zastaviť, Decoy proces ukončí a súbor vymaže. Objekt úlohy systému Windows (job object) zabezpečuje, že sa návnady ukončia spoločne s Decoy, aj keby aplikácia neočakávane spadla.

## Inštalácia

Vyberte si na stránke [Releases](../../../../releases):

| Na stiahnutie | Určenie |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Inštalátor.** Pre jedného používateľa, bez potreby správcovských práv, pridá položku do ponuky Štart a odinštalátor. |
| `Decoy_x.y.z_x64-portable.zip` | **Prenosná verzia (Portable).** Rozbaľte kdekoľvek a spustite `decoy.exe`. Všetky údaje zostávajú v priečinku `data` vedľa neho, do vášho používateľského profilu sa nič nezapisuje. Ak ju chcete odstrániť, stačí priečinok vymazať. |

Stiahnutý súbor overte pomocou `SHA256SUMS.txt` (`Get-FileHash <file>` v PowerShell).

Windows SmartScreen môže varovať pred nerozpoznaným vydavateľom, pretože zostavy nie sú digitálne podpísané. Ak zostave dôverujete, zvoľte *Ďalšie informácie → Spustiť aj tak*.

Požiadavky: Windows 10 alebo 11 (64-bitový) s modulom runtime WebView2 (už súčasťou Windows 11 a nedávnych aktualizácií systému Windows 10).

## Použitie

1. Otvorte **Knižnicu** a vyhľadajte hru, alebo odkiaľkoľvek stlačte `Ctrl` + `K`.
2. Kliknite na hru. V paneli vpravo vyberte proces a počet minút, ako dlho ho udržiavať (aktivity v Discorde zvyčajne vyžadujú 15).
3. Stlačte **Spustiť návnadu**. Discord hru zobrazí po niekoľkých sekundách.
4. Sledujte proces v sekcii **Bežiace**, kedykoľvek môžete jeden alebo všetky zastaviť, alebo nechajte Decoy bežať v systémovej lište.

Hry, ktorých záznam v Discorde zatiaľ nemá žiadne spustiteľné súbory, sú predvolene skryté (nemožno ich detegovať). Ak ich chcete zobraziť, zapnite voľbu *Zobraziť hry bez exe*; zoznam sa denne obnovuje, takže budú k dispozícii, hneď ako Discord príslušný proces pridá.

### Príkazový riadok

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Spustí návnadu okamžite, napríklad `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Zostavenie zo zdrojového kódu

Požiadavky: [Node.js](https://nodejs.org) 20+, stabilný toolchain [Rust](https://rustup.rs) (cieľ MSVC) s nástrojmi na zostavenie Visual Studio C++ a runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Užitočné kontroly:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Poznámky: Spustiteľný súbor pre decoy je kompilovaný pomocou `src-tauri/build.rs` bežným `rustc` zo súboru `src-tauri/stub/stub.rs` a potom vložený do aplikácie. Keď frontend beží v bežnom prehliadači (`npm run dev`), používa sa malý simulovaný backend (`src/mock.ts`), čo je praktické na prácu na používateľskom rozhraní.

## Preklady

Texty používateľského rozhrania sa nachádzajú v [`src/locales`](../../src/locales), jeden JSON súbor pre každý jazyk (`en.json`, `ru.json`, ...). Pridanie jazyka znamená pridanie súboru; nie sú potrebné žiadne zmeny v kóde. Formát súboru, pripravené zadanie pre strojový preklad a overovací skript nájdete v [docs/TRANSLATING.md](../TRANSLATING.md). Preklady tohto súboru README patria do `docs/i18n/README.<code>.md`.

## Štruktúra projektu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Súkromie

- Decoy využíva sieť iba na stiahnutie verejného zoznamu detekcie Discordu (pri prvom spustení a potom maximálne raz za deň alebo po kliknutí na obnovenie) a na zobrazenie ikon a obrázkov hier z verejnej CDN siete Discordu.
- Nečíta, neukladá ani neodosiela váš Discord token ani žiadne údaje účtu a nekomunikuje s klientom Discordu.
- Nastavenia (obľúbené položky, jazyk, trvania) sa ukladajú lokálne v úložisku WebView aplikácie; vyrovnávacia pamäť zoznamu hier a dočasné súbory návnad sa nachádzajú v `%LOCALAPPDATA%\app.decoy.desktop`.
- Žiadna analytika, žiadne hlásenia o chybách, žiadne používateľské účty.

## Známe obmedzenia

- Discord môže spôsob detekcie kedykoľvek zmeniť. Ak prestane byť decoy rozpoznávaný, otvorte prosím hlásenie o probléme (issue).
- Niektoré aktivity vyžadujú viac než len bežiaci proces (napríklad prítomnosť v konkrétnom režime či hre v rámci hernej platformy). Decoy napodobňuje iba proces.
- Záznamy bez spustiteľných súborov v zozname Discordu nie je možné detegovať.
- Bezpečnostný softvér môže občas označiť malé nepodpísané spustiteľné súbory, ktoré nečinne bežia v pamäti. Decoy je open source a je zostavený zo súboru `src-tauri/stub/stub.rs`; môžete si ho skompilovať sami.

## Vyhlásenie o vylúčení zodpovednosti

Decoy je poskytovaný „tak, ako je“, na osobné, vzdelávacie a testovacie účely. Predstieranie spustenej hry môže porušovať Zmluvné podmienky služby Discord alebo vydavateľa hry a môže viesť k opatreniam voči vášmu účtu. Za spôsob použitia nesiete výhradnú zodpovednosť vy sami. „Discord“ a všetky názvy a logá hier sú ochrannými známkami príslušných vlastníkov a sú tu použité iba na identifikáciu softvéru, na ktorý odkazujú.
