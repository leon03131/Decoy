# Decoy

**କ୍ଷୁଦ୍ର ଷ୍ଟାଣ୍ଡ-ଇନ୍ ପ୍ରୋସେସ୍ ଯାହା Discord କୁ ଜଣାଏ ଯେ ଏକ ଖେଳ ଚାଲୁଅଛି।**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)

Decoy ଏକ ଖେଳର ଏକ୍ସିକ୍ୟୁଟେବଲ୍ (exe) ନାମରେ ଏକ କ୍ଷତିହୀନ, ୱିଣ୍ଡୋଯୁକ୍ତ ପ୍ଲେସହୋଲ୍ଡର୍ ପ୍ରୋସେସ୍ ଚାଲୁ ରଖେ, ଯାହାଫଳରେ Discord ର ଗେମ୍ ଡିଟେକ୍ସନ୍ ଆପଣଙ୍କୁ ସେହି ଖେଳ ଖେଳୁଥିବା ଭାବରେ ଦେଖାଏ। ଆପଣଙ୍କୁ ପ୍ରକୃତ ଖେଳକୁ ଇନଷ୍ଟଲ୍ କିମ୍ବା ଆରମ୍ଭ କରିବା ଆବଶ୍ୟକ ପଡ଼େ ନାହିଁ, ତେଣୁ ଆପଣଙ୍କ ଡିସ୍କରେ କୌଣସି ବଡ଼ ଫାଇଲ୍ ସ୍ଥାନ ନିଏ ନାହିଁ।

ଏହା **Discord ଚିହ୍ନଟ କରିପାରୁଥିବା ପ୍ରତ୍ୟେକ ଖେଳ** (ପ୍ରାୟ ୨୫,୦୦୦ ଏଣ୍ଟ୍ରି) ବିଷୟରେ ଜାଣିଛି, କାରଣ ଏହା Discord ର ନିଜସ୍ୱ ସାର୍ବଜନୀନ ଡିଟେକ୍ସନ୍ ତାଲିକା ପଢ଼େ ଏବଂ ନିଜେ ଏହାକୁ ଅଦ୍ୟତନ (ଅପ୍-ଟୁ-ଡେଟ୍) ରଖେ।

## ବୈଶିଷ୍ଟ୍ୟଗୁଡ଼ିକ

- **Discord ଚିହ୍ନଟ କରିପାରୁଥିବା ସବୁକିଛି।** ଗେମ୍ ତାଲିକାଟି Discord ର ସାର୍ବଜନୀନ ଡିଟେକ୍ସନ୍ ଏଣ୍ଡପଏଣ୍ଟରୁ ଡାଉନଲୋଡ୍ ହୁଏ, ଲୋକାଲ୍ ଭାବରେ କ୍ୟାଶ୍ ହୁଏ ଏବଂ ପ୍ରତିଦିନ ରିଫ୍ରେଶ୍ ହୁଏ। ନୂତନ ଖେଳ ଏବଂ ନୂତନ ଭାବେ ଯୋଡ଼ାଯାଇଥିବା ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଗୁଡ଼ିକ ନିଜେ ତାଲିକାରେ ଦେଖାଯାଏ।
- **ତ୍ୱରିତ ସନ୍ଧାନ।** ହଜାର ହଜାର ଖେଳ ମଧ୍ୟରେ ଖେଳର ନାମ କିମ୍ବା ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଦ୍ୱାରା ତତକ୍ଷଣାତ୍ ସନ୍ଧାନ, ଗ୍ରୀଡ୍ କିମ୍ବା କମ୍ପାକ୍ଟ ତାଲିକା ଭ୍ୟୁ, ପସନ୍ଦ ଏବଂ "ନିକଟ ଅତୀତର" (Recent) ଧାଡ଼ି।
- **ଗୋଟିଏ କ୍ଲିକ୍‌ରେ ସବୁ।** ଏକ ଖେଳ ବାଛନ୍ତୁ, ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଚୟନ କରନ୍ତୁ (ଯଦି ଏକାଧିକ ଥାଏ), କେତେ ସମୟ ରଖିବାକୁ ଚାହାନ୍ତି ତାହା ସ୍ଥିର କରନ୍ତୁ ଏବଂ ଷ୍ଟାର୍ଟ ଦବାନ୍ତୁ। ଏକ କାଉଣ୍ଟଡାଉନ୍ ରିଙ୍ଗ୍ ଏବଂ ବିଜ୍ଞପ୍ତି ଆପଣଙ୍କୁ ସମୟ ସରିବା ବିଷୟରେ ଜଣାଇଦେବ।
- **କୌଣସି ଅବଶିଷ୍ଟାଂଶ ଛାଡ଼େ ନାହିଁ।** ଏକ decoy କେବଳ ଚାଲୁଥିବା ସମୟରେ ହିଁ ବିଦ୍ୟମାନ ଥାଏ: କ୍ଷୁଦ୍ର exe ଟି ଆରମ୍ଭ ସମୟରେ ସୃଷ୍ଟି ହୁଏ ଏବଂ ବନ୍ଦ କରିବା ସମୟରେ ବିଲୋପ (ଡିଲିଟ୍) ହୋଇଯାଏ। ଆପଣ ବାହାରିବା ମାତ୍ରେ ସବୁକିଛି ବନ୍ଦ ହୋଇଯାଏ ଏବଂ କ୍ରାସ୍‌ରୁ ରହିଯାଇଥିବା ଅବଶିଷ୍ଟ ଫାଇଲ୍ ପରବର୍ତ୍ତୀ ଲଞ୍ଚ ସମୟରେ ସଫା କରିଦିଆଯାଏ।
- **ଶାନ୍ତ ଓ ନୀରବ।** ସିଷ୍ଟମ୍ ଟ୍ରେରେ ଅବସ୍ଥାନ କରେ, decoy ଗୁଡ଼ିକ ପାଇଁ କୌଣସି ୱିଣ୍ଡୋ କିମ୍ବା ଟାସ୍କବାର୍ ବଟନ୍ ନଥାଏ।
- **ମୁକ୍ତ ଅନୁବାଦ।** ଇଣ୍ଟରଫେସ୍‌ଟି ସାଧାରଣ JSON ଫାଇଲ୍ ଦ୍ୱାରା ପରିଚାଳିତ, ତେଣୁ ଏକ ଭାଷା ଯୋଡ଼ିବା କେବଳ ଗୋଟିଏ ଫାଇଲ୍ ଯୋଡ଼ିବା ସହିତ ସମାନ। English ଏବଂ Russian ଅନ୍ତର୍ଭୁକ୍ତ ଅଛି।
- **ବ୍ୟକ୍ତିଗତ ଓ ଗୋପନୀୟ।** କୌଣସି ଆକାଉଣ୍ଟ୍ ନାହିଁ, କୌଣସି Discord ଟୋକେନ୍ ନାହିଁ, କୌଣସି ଟେଲିମେଟ୍ରି ନାହିଁ। [ଗୋପନୀୟତା](#ଗୋପନୀୟତା) ଦେଖନ୍ତୁ।

## ଏହା କିପରି କାମ କରେ

1. Discord ଆପଣଙ୍କ PC ରେ ଚାଲୁଥିବା ପ୍ରୋସେସ୍‌ଗୁଡ଼ିକୁ ଦେଖି ଏବଂ ସେଗୁଡ଼ିକର ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ନାମକୁ ଏକ ସାର୍ବଜନୀନ ତାଲିକା (`/api/v9/applications/detectable`) ସହିତ ତୁଳନା କରି ସ୍ଥିର କରେ ଯେ ଆପଣ ଏକ ଖେଳ ଖେଳୁଛନ୍ତି।
2. Decoy ସେହି ତାଲିକା ଡାଉନଲୋଡ୍ କରେ ଏବଂ ଆପଣ ବାଛିଥିବା ଖେଳ ପାଇଁ, ତାଲିକାରୁ ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ନାମ ବ୍ୟବହାର କରି ଏକ କ୍ଷୁଦ୍ର ଷ୍ଟାଣ୍ଡ-ଇନ୍ ପ୍ରୋଗ୍ରାମ୍ (ପ୍ରାୟ ୧୨୦ KB, Rust ରେ ଲିଖିତ ଏବଂ Decoy ମଧ୍ୟରେ ଏମବେଡ୍ ହୋଇଥିବା) ଏକ ଅସ୍ଥାୟୀ ଫୋଲ୍ଡରକୁ କପି କରେ, ଉଦାହରଣ ସ୍ୱରୂପ `.../cod26-cod.exe`।
3. ଏହି ଷ୍ଟାଣ୍ଡ-ଇନ୍ ପ୍ରୋଗ୍ରାମ୍ କେବଳ ଗୋଟିଏ ଟପ୍-ଲେଭଲ୍ ୱିଣ୍ଡୋ ନିଜ ଅଧୀନରେ ରଖିବା ବ୍ୟତୀତ ଆଉ କିଛି କରେନାହିଁ, ଯାହା ସ୍କ୍ରିନ୍‌ର ବହୁତ ବାହାରେ ରଖାଯାଇଥାଏ ଯାହାଫଳରେ ଆପଣ ଏହାକୁ କେବେ ଦେଖିପାରିବେ ନାହିଁ। Discord କେବଳ ସେହି ପ୍ରୋସେସ୍‌କୁ ଚିହ୍ନଟ କରେ ଯାହାର ଏକ ୱିଣ୍ଡୋ ଥାଏ, ସେଥିପାଇଁ ସମ୍ପୂର୍ଣ୍ଣ ୱିଣ୍ଡୋହୀନ ପ୍ରୋସେସ୍‌କୁ ଅଣଦେଖା କରାଯାଏ।
4. ପ୍ରାୟ ୧୫ ସେକେଣ୍ଡ ମଧ୍ୟରେ Discord ଗେମ୍‌ଟିକୁ ଆପଣଙ୍କର ବର୍ତ୍ତମାନର କାର୍ଯ୍ୟକଳାପ (activity) ଭାବରେ ପ୍ରଦର୍ଶନ କରେ।
5. ଯେତେବେଳେ ଟାଇମର୍ ଶେଷ ହୁଏ କିମ୍ବା ଆପଣ ଷ୍ଟପ୍ ଦବାନ୍ତି, Decoy ପ୍ରୋସେସ୍‌ଟିକୁ ବନ୍ଦ କରିଦିଏ ଏବଂ ଫାଇଲ୍ ବିଲୋପ କରେ। ଏକ Windows job object ନିଶ୍ଚିତ କରେ ଯେ ଯଦି Decoy କ୍ରାସ୍ ବି ହୁଏ, ତେବେ ମଧ୍ୟ decoy ପ୍ରୋସେସ୍‌ଗୁଡ଼ିକ Decoy ସହିତ ବନ୍ଦ ହୋଇଯିବ।

## ବ୍ୟବହାର ବିଧି

1. **ଲାଇବ୍ରେରୀ** ଖୋଲନ୍ତୁ ଏବଂ ଏକ ଖେଳ ଖୋଜନ୍ତୁ, କିମ୍ବା ଯେକୌଣସି ସ୍ଥାନରୁ `Ctrl` + `K` ଦବାନ୍ତୁ।
2. ଏକ ଖେଳ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ। ଡାହାଣ ପାର୍ଶ୍ୱ ପ୍ୟାନେଲରେ ପ୍ରୋସେସ୍ ଏବଂ ଏହାକୁ କେତେ ମିନିଟ୍ ରଖିବେ ତାହା ଚୟନ କରନ୍ତୁ (Discord କାର୍ଯ୍ୟକଳାପ ସାଧାରଣତଃ ୧୫ ମିନିଟ୍ ଆବଶ୍ୟକ କରେ)।
3. **Start decoy** ଦବାନ୍ତୁ। କିଛି ସେକେଣ୍ଡ ପରେ Discord ଖେଳଟିକୁ ଦେଖାଇବ।
4. **ଚାଲୁଅଛି** ଅଧୀନରେ ଏହାକୁ ଦେଖନ୍ତୁ, ଯେକୌଣସି ସମୟରେ ଗୋଟିଏ କିମ୍ବା ସମସ୍ତ ବନ୍ଦ କରନ୍ତୁ, କିମ୍ବା Decoy କୁ କେବଳ ଟ୍ରେରେ ରଖିଦିଅନ୍ତୁ।

ଯେଉଁ ଖେଳଗୁଡ଼ିକର Discord ଏଣ୍ଟ୍ରିରେ ଏପର୍ଯ୍ୟନ୍ତ କୌଣସି ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ନାହିଁ, ସେଗୁଡ଼ିକ ପୂର୍ବନିର୍ଦ୍ଧାରିତ ଭାବେ ଲୁକ୍କାୟିତ ଥାଏ (ସେଗୁଡ଼ିକ ଚିହ୍ନଟ ହୋଇପାରିବ ନାହିଁ)। ସେଗୁଡ଼ିକୁ ଦେଖିବା ପାଇଁ *exe ନଥିବା ଖେଳ ଦେଖାନ୍ତୁ* ଚାଲୁ କରନ୍ତୁ; ତାଲିକାଟି ପ୍ରତିଦିନ ରିଫ୍ରେଶ୍ ହୁଏ, ତେଣୁ Discord ଏକ ପ୍ରୋସେସ୍ ଯୋଡ଼ିବା ମାତ୍ରେ ସେଗୁଡ଼ିକ ଉପଲବ୍ଧ ହୋଇଯାଏ।

## ଉତ୍ସରୁ ବିଲ୍ଡ କରନ୍ତୁ

ପୂର୍ବାବଶ୍ୟକତା: [Node.js](https://nodejs.org) 20+, Visual Studio C++ ବିଲ୍ଡ ଉପକରଣ ସହିତ ଷ୍ଟେବଲ୍ [Rust](https://rustup.rs) ଟୁଲଚେନ୍ (MSVC ଟାର୍ଗେଟ୍), ଏବଂ WebView2 ରନଟାଇମ୍।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ଉପଯୋଗୀ ଯାଞ୍ଚଗୁଡ଼ିକ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ଟିପ୍ପଣୀ: decoy exe ଟି `src-tauri/build.rs` ଦ୍ୱାରା `src-tauri/stub/stub.rs` ରୁ ସାଧାରଣ `rustc` ସହିତ କମ୍ପାଇଲ୍ କରାଯାଇଥାଏ ଏବଂ ତା'ପରେ ଆପ୍ ମଧ୍ୟରେ ଏମବେଡ୍ କରାଯାଏ। ଯେତେବେଳେ ଫ୍ରଣ୍ଟଏଣ୍ଡ ଏକ ସାଧାରଣ ବ୍ରାଉଜରରେ ଚାଲେ (`npm run dev`), ଏକ ଛୋଟ ମକ୍ ବ୍ୟାକଏଣ୍ଡ (`src/mock.ts`) ବ୍ୟବହୃତ ହୁଏ, ଯାହା UI ଉପରେ କାମ କରିବା ପାଇଁ ସୁବିଧାଜନକ।

## ଅନୁବାଦ

UI ଷ୍ଟ୍ରିଙ୍ଗଗୁଡ଼ିକ [`src/locales`](../../src/locales) ରେ ରହିଥାଏ, ପ୍ରତି ଭାଷା ପାଇଁ ଗୋଟିଏ JSON ଫାଇଲ୍ (`en.json`, `ru.json`, ...)। ଏକ ଭାଷା ଯୋଡ଼ିବା ଅର୍ଥ କେବଳ ଗୋଟିଏ ଫାଇଲ୍ ଯୋଡ଼ିବା; କୌଣସି କୋଡ୍ ପରିବର୍ତ୍ତନ ନାହିଁ। ଫାଇଲ୍ ଫର୍ମାଟ୍, ମେସିନ୍ ଅନୁବାଦ ପାଇଁ ଏକ ପ୍ରସ୍ତୁତ ପ୍ରମ୍ପ୍ଟ ଏବଂ ବୈଧକରଣ ସ୍କ୍ରିପ୍ଟ ପାଇଁ [docs/TRANSLATING.md](../TRANSLATING.md) ଦେଖନ୍ତୁ। ଏହି README ର ଅନୁବାଦଗୁଡ଼ିକ `docs/i18n/README.<code>.md` କୁ ଯାଏ।

## ଗୋପନୀୟତା

- Decoy କେବଳ Discord ର ସାର୍ବଜନୀନ ଡିଟେକ୍ସନ୍ ତାଲିକା ଡାଉନଲୋଡ୍ କରିବା ପାଇଁ (ପ୍ରଥମ ଆରମ୍ଭରେ, ତା'ପରେ ଦିନକୁ ସର୍ବାଧିକ ଥରେ କିମ୍ବା ଆପଣ ଯେତେବେଳେ ରିଫ୍ରେଶ୍ ଦବାନ୍ତି) ଏବଂ ପ୍ରଦର୍ଶନ ପାଇଁ Discord ର ସାର୍ବଜନୀନ CDN ରୁ ଗେମ୍ ଆଇକନ୍ ଓ ଆର୍ଟୱାର୍କ ଆଣିବା ପାଇଁ ନେଟୱାର୍କ ବ୍ୟବହାର କରେ।
- ଏହା ଆପଣଙ୍କ Discord ଟୋକେନ୍ କିମ୍ବା କୌଣସି ଆକାଉଣ୍ଟ୍ ଡାଟା ପଢ଼େ ନାହିଁ, ସଂରକ୍ଷଣ କରେ ନାହିଁ କିମ୍ବା ପଠାଏ ନାହିଁ, ଏବଂ ଏହା Discord କ୍ଲାଏଣ୍ଟ ସହିତ କଥାବାର୍ତ୍ତା କରେ ନାହିଁ।
- ସେଟିଂସ (ପସନ୍ଦ, ଭାଷା, ଅବଧି) ସ୍ଥାନୀୟ ଭାବରେ ଆପ୍ ର WebView ଷ୍ଟୋରେଜରେ ସଂରକ୍ଷିତ ହୁଏ; ଗେମ୍ ତାଲିକା କ୍ୟାଶ୍ ଏବଂ ଅସ୍ଥାୟୀ decoy ଫାଇଲ୍ `%LOCALAPPDATA%\app.decoy.desktop` ରେ ରହେ।
- କୌଣସି ଆନାଲିଟିକ୍ସ ନାହିଁ, କୌଣସି କ୍ରାସ୍ ରିପୋର୍ଟିଂ ନାହିଁ, କୌଣସି ଆକାଉଣ୍ଟ୍ ନାହିଁ।

## ଜଣାଶୁଣା ସୀମାବଦ୍ଧତା

- Discord ଯେକୌଣସି ସମୟରେ ଡିଟେକ୍ସନ୍ କାର୍ଯ୍ୟ କିପରି କରେ ତାହା ପରିବର୍ତ୍ତନ କରିପାରେ। ଯଦି ଏକ decoy ଚିହ୍ନଟ ହେବା ବନ୍ଦ ହୁଏ, ଦୟାକରି ଏକ issue ଖୋଲନ୍ତୁ।
- କେତେକ କାର୍ଯ୍ୟକଳାପ ପାଇଁ କେବଳ ଏକ ଚାଲୁଥିବା ପ୍ରୋସେସ୍ ଅପେକ୍ଷା ଅଧିକ କିଛି ଆବଶ୍ୟକ ହୁଏ (ଉଦାହରଣ ସ୍ୱରୂପ ଏକ ଗେମ୍ ପ୍ଲାଟଫର୍ମର ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ଅନୁଭୂତି ମଧ୍ୟରେ ରହିବା)। Decoy କେବଳ ପ୍ରୋସେସ୍‌ର ନକଲ କରେ।
- Discord ର ତାଲିକାରେ ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ନଥିବା ଏଣ୍ଟ୍ରିଗୁଡ଼ିକ ଚିହ୍ନଟ ହୋଇପାରିବ ନାହିଁ।
- ସୁରକ୍ଷା ସଫ୍ଟୱେର୍ ବେଳେବେଳେ ମେମୋରୀରେ ନିଷ୍କ୍ରିୟ ବସିଥିବା ଛୋଟ ଅନସାଇନ୍ଡ ଏକ୍ସିକ୍ୟୁଟେବଲ୍‌ଗୁଡ଼ିକୁ ସନ୍ଦେହଜନକ ଭାବେ ଚିହ୍ନିତ କରେ। Decoy ଓପନ୍ ସୋର୍ସ ଏବଂ `src-tauri/stub/stub.rs` ରୁ ନିର୍ମିତ; ଆପଣ ଏହାକୁ ନିଜେ କମ୍ପାଇଲ୍ କରିପାରିବେ।

## ଦାୟିତ୍ୱହୀନତା ବୟାନ

Decoy ବ୍ୟକ୍ତିଗତ, ଶିକ୍ଷାଗତ ଏବଂ ପରୀକ୍ଷଣ ଉଦ୍ଦେଶ୍ୟରେ "ଯେପରି ଅଛି ସେହିପରି" (as is) ପ୍ରଦାନ କରାଯାଇଛି। ଚାଲୁଥିବା ଖେଳର ନକଲ କରିବା Discord କିମ୍ବା ଖେଳ ପ୍ରକାଶକଙ୍କ ସେବା ସର୍ତ୍ତାବଳୀ (Terms of Service) ଉଲ୍ଲଂଘନ କରିପାରେ, ଏବଂ ଆପଣଙ୍କ ଆକାଉଣ୍ଟ୍ ବିରୁଦ୍ଧରେ କାର୍ଯ୍ୟାନୁଷ୍ଠାନ ଗ୍ରହଣ କରାଯାଇପାରେ। ଆପଣ ଏହାକୁ କିପରି ବ୍ୟବହାର କରିବେ ସେଥିପାଇଁ କେବଳ ଆପଣ ହିଁ ଦାୟୀ। "Discord" ଏବଂ ସମସ୍ତ ଗେମ୍ ନାମ ଓ ଲୋଗୋ ସେମାନଙ୍କର ସମ୍ପୃକ୍ତ ମାଲିକମାନଙ୍କର ଟ୍ରେଡମାର୍କ ଏବଂ ଏଠାରେ କେବଳ ସେମାନେ ସୂଚାଉଥିବା ସଫ୍ଟୱେର୍ ଚିହ୍ନଟ କରିବା ପାଇଁ ବ୍ୟବହୃତ ହୋଇଛି।
