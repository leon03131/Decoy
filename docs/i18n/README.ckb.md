# Decoy

**پڕۆسەی جێگرەوەی بچووک کە وا لە Discord دەکەن وا تێبگات یارییەک کراوەتەوە.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="کتێبخانەی Decoy لەگەڵ یارییە نوێیەکان و وێنەکانیان" />

</div>

بەرنامەی Decoy پڕۆسەیەکی جێگرەوەی زیانبەخشنەبوو بە پەنجەرەیەکەوە لەژێر ناوی فایلی جێبەجێکاری (exe) یارییەکدا بە کراوەیی دەهێڵێتەوە، تاوەکو سیستەمی ناسینەوەی یاری لە Discord وا نیشان بدات کە تۆ ئەو یارییە دەکەیت. هەرگیز پێویست ناکات یارییە ڕاستەقینەکە دابمەزرێنیت یان بیکەیتەوە، بۆیە هیچ قەبارەیەکی گەورە لەسەر پەپکەکەت (disk) داگیر ناکات.

بەرنامەکە ئاگاداری **هەموو ئەو یارییانەیە کە Discord دەتوانێت بیانناسێتەوە** (نزیکەی ٢٥,٠٠٠ یاری)، چونکە خۆی ڕاستەوخۆ لیستی گشتیی ناسینەوەی Discord دەخوێنێتەوە و ڕۆژانە بەخۆی نوێی دەکاتەوە.

> [!WARNING]
> ساختەکردنی یارییەکی کراوە لەوانەیە پێچەوانەی مەرجەکانی بەکارهێنانی Discord بێت و بەکارهێنانی Decoy **لەسەر بەرپرسیارێتیی خۆتە**.
> ئەم پڕۆژەیە بە هیچ شێوەیەک پەیوەندی بە Discord Incـەوە نییە و لەلایەن ئەوانەوە پشتگیری نەکراوە. سەیری [بەرپرسیارێتی](#بەرپرسیارێتی) بکە.

## تایبەتمەندییەکان

- **هەموو ئەو شتانەی کە Discord دەتوانێت بیانناسێتەوە.** لیستی یارییەکان لە خاڵی کۆتایی ناسینەوەی گشتیی Discord دادەبەزێنرێت، بە شێوەی ناوخۆیی پاشەکەوت دەکرێت و ڕۆژانە نوێ دەکرێتەوە. یارییە نوێیەکان و ئەو فایلە جێبەجێکارانەی تازە زیاد دەکرێن خۆیان دەردەکەون.
- **گەڕانێکی خێرا و هاوکات.** گەڕانی دەستبەجێ بە ناوی یاری یان فایلی exe لەنێوان هەزاران یاری، پیشاندانی تۆڕی یان لیستی کۆکراوە، دڵخوازەکان و ڕیزبەندی «دواینەکان».
- **بە یەک کرتە.** یارییەک هەڵبژێرە، فایلی جێبەجێکار هەڵبژێرە (ئەگەر چەندین دانە بوون)، ماوەی هێشتنەوەی دیاری بکە و دەستپێکردن داگرە. ئەڵقەیەکی ژماردنی پێچەوانە و ئاگادارکردنەوەیەک کاتی تەواوبوونت پێ دەڵێن.
- **هیچ پاشماوەیەک لە دوای خۆی بەجێناهێڵێت.** پڕۆسەی Decoy تەنیا لە کاتی کارکردنیدا بوونی هەیە: فایلی بچووکی exe لە کاتی دەستپێکردندا دروست دەکرێت و لە کاتی وەستاندندا دەسڕدرێتەوە. هەموو شتێک دەوەستێت کاتێک لە بەرنامەکە دەردەچیت، و هەر پاشماوەیەک لە ئەگەری لەکارکەوتندا (crash) لە دەستپێکردنەوەی داهاتوودا پاک دەکرێتەوە.
- **بێدەنگ.** لە بەشی سیستەمدا دەمێنێتەوە (tray)، هیچ پەنجەرە یان دوگمەیەکی شریتی ئەرکەکان (taskbar) بۆ پڕۆسەکانی Decoy دەرناکەوێت.
- **وەرگێڕانی کراوە.** ڕووکاری بەرنامەکە بە فایلە سادەکانی JSON بەڕێوەدەچێت، بۆیە زیادکردنی زمانێکی نوێ تەنیا یەک فایلە. ئینگلیزی و ڕووسی لەخۆگیراون.
- **پاراستنی نهێنی.** بێ هەژمار، بێ تۆکنی Discord، بێ کۆکردنەوەی دراوەی بەکارهێنان (telemetry). سەیری [پاراستنی نهێنی](#پاراستنی-نهێنی) بکە.

## چۆن کاردەکات

1. بەرنامەی Discord بە سەیرکردنی ئەو پڕۆسانەی لەسەر کۆمپیوتەرەکەت کاردەکەن و بەراوردکردنی ناوی فایلە جێبەجێکارەکانیان لەگەڵ لیستێکی گشتیدا بڕیار دەدات کە تۆ یاری دەکەیت (`/api/v9/applications/detectable`).
2. بەرنامەی Decoy ئەو لیستە دادەبەزێنێت، و بۆ ئەو یارییەی هەڵیدەبژێریت، بەرنامەیەکی جێگرەوەی زۆر بچووک (نزیکەی ١٢٠ کیلۆبایت، بە زمانی Rust نووسراوە و لەناو Decoy جێگیر کراوە) لە بوخچەیەکی کاتیدا بە بەکارهێنانی ناوی فایلی exe لە لیستەکە کۆپی دەکات، بۆ نموونە `.../cod26-cod.exe`.
3. بەرنامە جێگرەوەکە هیچ ناکات جگە لە خاوەندارێتیکردنی یەک پەنجەرەی ئاستی سەرەوە، کە زۆر دوور لە دەرەوەی ڕوونما دانراوە تا هەرگیز نەیبینیت. بەرنامەی Discord تەنیا ئەو پڕۆسانە دەناسێتەوە کە خاوەنی پەنجەرەن، هەربۆیە پڕۆسەی تەواو بێ پەنجەرە پشتگوێ دەخرێت.
4. لە ماوەی نزیکەی ١٥ چرکەدا، Discord یارییەکە وەک چالاکیی ئێستات نیشان دەدات.
5. کاتێک کاتەکە تەواو دەبێت یان دوگمەی وەستاندن دادەگریت، Decoy پڕۆسەکە کۆتایی پێدەهێنێت و فایلەکە دەسڕێتەوە. سیستەمی job object لە Windows دڵنیایی دەدات کە هەموو پڕۆسەکانی Decoy لەگەڵ داخستنی خودی Decoy دادەخرێن، تەنانەت ئەگەر بەرنامەکە لەپڕ لەکار بکەوێت.

## دامەزراندن

یەکێکیان لە پەڕەی [وەشانەکان](../../../../releases) هەڵبژێرە:

| داگرتن | بۆ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **دامەزرێنەر (Installer).** بۆ هەر بەکارهێنەرێک، پێویستی بە دەسەڵاتی بەڕێوەبەر (Admin) نییە، بەشێک لە پێڕستی دەستپێک (Start menu) و بەرنامەیەکی سڕینەوە زیاد دەکات. |
| `Decoy_x.y.z_x64-portable.zip` | **گوازراوە (Portable).** لە هەر شوێنێک دەریبهێنە و `decoy.exe` بخەرە کار. هەموو دراوەکان لە بوخچەی `data` لە تەنیشتیدا دەمێننەوە، هیچی لە پرۆفایلی بەکارهێنەرەکەتدا تۆمار ناکرێت. بۆ سڕینەوە تەنیا بوخچەکە بسڕەوە. |

فایلی دابەزێنراو بە `SHA256SUMS.txt` پشتڕاست بکەرەوە (لە ڕێگەی فەرمانی `Get-FileHash <file>` لە PowerShell).

سیستەمی Windows SmartScreen لەوانەیە ئاگاداری بدات لەبەر نەناسراوبوونی بڵاوکەرەوە چونکە وەشانەکان واژووی دیجیتاڵییان نییە؛ ئەگەر متمانەت پێیەتی *More info → Run anyway* هەڵبژێرە.

پێداویستییەکان: سیستەمی Windows 10 یان 11 (وەشانی 64-bit) لەگەڵ ژینگەی کارپێکردنی WebView2 (پێشتر لە وەشانی نوێی Windows 11 و نوێکردنەوەکانی ئەم دواییەی Windows 10 بوونی هەیە).

## بەکارهێنان

1. **کتێبخانە** بکەرەوە و بگەڕێ بەدوای یارییەکدا، یان لە هەر شوێنێک بیت `Ctrl` + `K` دابگرە.
2. کرتە لەسەر یارییەک بکە. لە بەشی لای ڕاستدا، پڕۆسەکە و چەندێتیی خولەکی هێشتنەوە دیاری بکە (چالاکییەکانی Discord بەزۆری پێویستیان بە ١٥ خولەکە).
3. دوگمەی **دەستپێکردنی Decoy** داگرە. پاش چەند چرکەیەک، Discord یارییەکە نیشان دەدات.
4. لە بەشی **چالاکەکان** چاودێریی بکە، یەکێکیان یان هەموویان لە هەر کاتێکدا بێت بوەستێنە، یان تەنیا Decoy لە بەشی سیستەمدا بەجێبهێڵە.

ئەو یارییانەی کە هێشتا تۆمارەکەیان لە Discord فایلی جێبەجێکاری نییە بە شێوەی بنەڕەتی شاردراونەتەوە (چونکە ناتوانرێت بناسرێنەوە). بژاردەی
*پشاندانی یارییەکانی بێ exe* چالاک بکە بۆ بینینیان؛ لیستەکە ڕۆژانە نوێ دەکرێتەوە، بۆیە هەر کاتێک Discord پڕۆسەی بۆ زیاد بکات دەستبەجێ بەردەست دەبن.

### هێڵی فەرمان

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

دەستبەجێ پڕۆسەیەکی Decoy دەست پێ دەکات، بۆ نموونە `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## دروستکردن لە سەرچاوەوە

پێداویستییە سەرەتاییەکان: [Node.js](https://nodejs.org) وەشانی 20+، زنجیرە ئامرازی جێگیری [Rust](https://rustup.rs) (ئامانجی MSVC) لەگەڵ ئامرازەکانی دروستکردنی Visual Studio C++‎، و ژینگەی WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

پشکنینە بەسوودەکان:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

تێبینییەکان: فایلی exeـی Decoy لەلایەن `src-tauri/build.rs` بە بەکارهێنانی `rustc` لە `src-tauri/stub/stub.rs` کۆمپایل دەکرێت و دواتر لەناو بەرنامەکەدا جێگیر دەکرێت. کاتێک ڕووکاری پێشەوە لە وێبگەڕێکی ئاساییدا کاردەکات (`npm run dev`)، پاشبنەمایەکی وەهمیی بچووک (`src/mock.ts`) بەکاردەهێنرێت، کە بۆ کارکردن لەسەر ڕووکارەکە زۆر گونجاوە.

## وەرگێڕانەکان

دەقەکانی ڕووکاری بەرنامە لە [`src/locales`](../../src/locales) دانراون، یەک فایلی JSON بۆ هەر زمانێک (`en.json`، `ru.json`، ...).
زیادکردنی زمان تەنیا زیادکردنی فایلێکە؛ بێ دەستکاریکردنی کۆد. سەیری [docs/TRANSLATING.md](../TRANSLATING.md) بکە بۆ شێوازی فایل، داواکاریی ئامادەکراو بۆ وەرگێڕانی ئامێری و سکریپتی پشکنین. وەرگێڕانی ئەم READMEـیە لە `docs/i18n/README.<code>.md` دادەنرێت.

## پێکهاتەی پڕۆژە

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## پاراستنی نهێنی

- بەرنامەی Decoy تەنیا بۆ داگرتنی لیستی گشتیی ناسینەوەی Discord هێڵی ئینتەرنێت بەکاردەهێنێت (لە یەکەم دەستپێکردندا، پاشان ئەوپەڕی ڕۆژی جارێک یان کاتێک دوگمەی نوێکردنەوە دادەگریت) و، بۆ پیشاندان، وێنۆچکەی یارییەکان لە تۆڕی گەیاندنی ناوەڕۆکی (CDN) گشتیی Discord.
- هەرگیز تۆکنی Discord یان هیچ دراوەیەکی هەژمارەکەت ناخوێنێتەوە، پاشەکەوتی ناکات و نانێرێت، و هیچ پەیوەندییەک لەگەڵ بەرنامەی فەرمیی Discord ناکات.
- ڕێکخستنەکان (دڵخوازەکان، زمان، ماوەکان) بە شێوەی ناوخۆیی لە کۆگای WebViewـی بەرنامەکە هەڵدەگیرێن؛ دراوەی پاشەکەوتکراوی لیستی یارییەکان و فایلە کاتییەکانی Decoy لە ڕێڕەوی `%LOCALAPPDATA%\app.decoy.desktop` دادەنرێن.
- بێ شیکاری (analytics)، بێ ڕاپۆرتی لەکارکەوتن، و بێ هەژمار.

## سنووردارکردنە ناسراوەکان

- بەرنامەی Discord دەتوانێت لە هەر کاتێکدا شێوازی کارکردنی ناسینەوە بگۆڕێت. ئەگەر چیتر پڕۆسەی Decoy نەناسراوە، تکایە کێشەیەک (issue) تۆمار بکە.
- هەندێک لە چالاکییەکان پێویستیان بە شتی زیاترە جگە لە تەنیا پڕۆسەیەکی کراوە (بۆ نموونە بوون لەناو ئەزموونێکی دیاریکراوی پلاتفۆرمی یارییەکەدا). بەرنامەی Decoy تەنیا پڕۆسەکە لاسایی دەکاتەوە.
- ئەو تۆمارانەی فایلی جێبەجێکاریان لە لیستی Discord نییە ناتوانرێت بناسرێنەوە.
- هەندێک جار نەرمەکاڵای پاراستن و دژەڤایرۆس گومان لە فایلە بچووکە جێبەجێکارە واژوونەکراوەکان دەکەن کە لە بیرگەدا (RAM) بێدەنگ دەمێننەوە. بەرنامەی Decoy سەرچاوە کراوەیە و لە `src-tauri/stub/stub.rs` دروست دەکرێت؛ دەتوانیت خۆت کۆمپایلی بکەیت.

## بەرپرسیارێتی

بەرنامەی Decoy وەک ئەوەی هەیە "as is" بۆ مەبەستی کەسی، فێرکاری و تاقیکردنەوە پێشکەش دەکرێت. لاساییکردنەوەی یارییەکی کراوە لەوانەیە پێچەوانەی مەرجەکانی بەکارهێنانی Discord یان بڵاوکەرەوەی یارییەکە بێت، و ڕەنگە ببێتە هۆی گرتنەبەری ڕێوشوێن بەرامبەر بە هەژمارەکەت. تۆ بە تەنیا بەرپرسیاری لە چۆنیەتیی بەکارهێنانی. ناوی "Discord" و هەموو ناو و لۆگۆی یارییەکان نیشانەی بازرگانیی خاوەنە ڕاستەقینەکانیانن و لێرەدا تەنیا بۆ ناساندنی ئەو نەرمەکاڵایانە بەکارهاتوون.
