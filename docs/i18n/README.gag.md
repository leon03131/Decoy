# Decoy

**Discord bir oyunun işlediğini sansın deyni küçük stand-in proțesslär.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bıldırkı oyunnarlan hem resimnerlän Decoy bibliotekası" />

</div>

Decoy, bir oyunun exe adı altında pencereli, zararsız bir stand-in proțessini işlär durumda tutêr, ölä ki Discord-un oyun tanıma sistemi sizi o oyunu oynêêr gibi gösterer. Asıl oyunu hiç kurmaa yaki başlatmaa lääzım diil, bu üzerä diskinizdä büük fayllar er tutmêêr.

O **Discord-un tanıyabildiği her oyunu** (yaklaşık 25.000 zapis) biler, çünkü Discord-un kendi açık tanıma dizimini okuyêr hem onu kendiliğindän eni tutêr.

> [!WARNING]
> İşleyän oyunu taklit etmää Discord-un Kullanış Şartlarına karşı gelebilir hem Decoy-u **kendi riskinizä** kullanırsınız.
> Bu proyekt Discord Inc. şirketinä baalı diil, onun tarafından onaylanmadı yaki desteklenmedi. Bakınız [Cuvapçılıktan vazgeçmäk](#cuvapçılıktan-vazgeçmäk).

## Özelliklär

- **Discord-un tanıyabildiği hepsi şey.** Oyun dizimi Discord-un açık tanıma uç noktasından indiriler, lokal olarak keşlener hem her gün enilenir. Eni oyunnar hem eni eklenmiş exe faylları kendiliğindän görünür.
- **Hızınıza uyan aaramak.** Binlärlän oyun arasında oyun adına yaki exe-yä görä tez aaramak, plitka yaki kompakt dizim görünüşü, biyenilännär hem “Bıldırkı” sırası.
- **Bir basmak.** Oyunu seçin, exe faylını seçin (birdän çoksa), ne kadar vakit tutulacağını seçin hem başlatmaa basın. Geri sayım halkası hem bildiri vakit bitincä haber verer.
- **Arkasında hiç bir iz bırakmêêr.** Bir decoy sade işlediği vakit yaşêêr: minik exe başlatılarkan yaratılar hem durdurularkan siliner. Çıkarkan hepsi şey durdurular, avariyadan kalan artıklar da bir dahaki başlatmada süpürüler.
- **Sessiz.** Sistem tray-ında yaşêêr; decoy-ların kendisi için hiç bir pencere yaki görev paneli düümesi yok.
- **Açık çevirilär.** İnterfeys sade JSON fayllarınnan yönetiler, bu üzerä eni dil eklemää sade bir fayldan ibarettir. İngiliz hem Rus dilleri içindädir.
- **Konfidențiallık.** Esap yok, Discord tokeni yok, telemetriya yok. Bakınız [Konfidențiallık](#konfidențiallık).

## Nasıl işleyer

1. Discord, kompyuterinizdä işleyän proțesslerä bakıp onların exe adlarını açık bir dizimlän (`/api/v9/applications/detectable`) karşılaştırarak sizin bir oyun oynadığınıza karar verer.
2. Decoy bu dizimi indirer hem seçtiğiniz oyun için dizimdeki exe adını kullanarak (örnein `.../cod26-cod.exe`) küçük bir stand-in programını (yaklaşık 120 KB, Rust dilindä yazılmış hem Decoy içinä gömülmüş) geçici bir klasörä kopiyalêêr.
3. Stand-in, ekrandan pek uzaa erleştirilmiş bir üst düzey pencereye saabi olmaktan başka hiç bir şey yapmêêr, siz onu hiç görmeersiniz. Discord sade bir penceresi olan proțessleri tanıyêr, bu sebeptän da pencereli olmayan proțesslär hesaba alınmêêr.
4. Yaklaşık 15 saniyedä Discord oyunu sizin şindiki zanaatınız gibi gösterer.
5. Taymer bitincä yaki durdura basınca Decoy proțessi bitirer hem faylı siler. Bir Windows iş obyekti (job object), Decoy çöksä bilä decoy-ların Decoy-lan barabar ölmesini garanti eder.

## Kurmak

[Releases](../../../../releases) sayfasından birini seçin:

| İndirmää | Neyä görä |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Kurucu.** Kullanıcı başına kurulur, administrator hakları istemeer, Başlat menüsü zapisi hem sökücü program ekler. |
| `Decoy_x.y.z_x64-portable.zip` | **Portativ.** İstediğiniz erä çıkarın hem `decoy.exe` faylını çalıştırın. Hepsi data onun yanındaki `data` klasöründä kalır, kullanıcı profilinizä hiç bir şey yazılmêêr. Çıkarmaa deyni klasörü silmää yeter. |

İndirilmiş faylı `SHA256SUMS.txt` faylınnan yoklayın (PowerShell-dä `Get-FileHash <file>`).

Windows SmartScreen tanınmayan tipograf bildirisi gösterebilir, çünkü yığımnar kod imzalı diil; yığıma inanırsanız *More info → Run anyway* (*Taa çok bilgi → Gene da çalıştır*) seçin.

Lääzımnıqlar: Windows 10 yaki 11 (64-bit) WebView2 runtime-lan barabar (Windows 11-dä hem son Windows 10 enilemelerindä bar).

## Kullanış

1. **Biblioteka** açın hem oyunu aarayın, yaki istediginiz erdän `Ctrl` + `K` basın.
2. Bir oyuna basın. Saa panelda proțessi hem kaç minuta tutulacağını seçin (Discord görevleri adettä 15 istär).
3. **Decoy başlatmaa** basın. Birkaç saniyedän sora Discord oyunu gösterecek.
4. Onu **İşleyän** altında izleyin, istediginiz vakit birini yaki hepsini durdurun, yaki Decoy-u sade tray-da bırakın.

Discord zapislärindä taa exe faylı olmayan oyunnar adettä saklıdır (onlar tanınamaz). Onları görmää deyni *Exe-siz oyunnarı göstermää* açın; dizim her gün enilenir, bu üzerä Discord bir proțess ekledii gibi hazır olacêklar.

### Komanda satırı

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Bir decoy-u tez başlatêr, örnein `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kaynak koddan toplamaa

Ön koşullar: [Node.js](https://nodejs.org) 20+, stabil [Rust](https://rustup.rs) alet takımı (MSVC target) Visual Studio C++ toplama aletlerinnän barabar, hem WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Faydalı yoklamalar:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notlar: decoy exe faylı `src-tauri/build.rs` tarafından düz `rustc` ilän `src-tauri/stub/stub.rs` üstündän toplanêr hem sora uygulama içinä gömüler. Frontend sade bir brauzerdä işleyerkän (`npm run dev`), UI üstündä çalışmaa kolaylaştıran küçük bir mock backend (`src/mock.ts`) kullanılêr.

## Çevirilär

İnterfeys metinneri [`src/locales`](../../src/locales) klasöründä, herbir dil için bir JSON faylı olarak bulunêr (`en.json`, `ru.json`, ...). Dil eklemää bir fayl eklemää demektir; kod diişmesi lääzım diil. Fayl formatı, maşina çevirisi için hazır prompt hem kontrol skripti için [docs/TRANSLATING.md](../TRANSLATING.md) faylına bakın. Bu README-nin çevirileri `docs/i18n/README.<code>.md` içine gider.

## Proyekt düzeni

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Konfidențiallık

- Decoy șebekeyi sade Discord-un açık tanıma dizimini indirmää deyni (ilk başta, sora gündä en çok bir kerä yaki enilemää basarkan) hem, göstermäk için, Discord-un açık CDN-indän oyun nışannarını hem resimnerini almaa deyni kullanêr.
- Discord tokeninizi yaki hiç bir akkaunt bilgisini okumêêr, saklamêêr hem yollamêêr, hem da Discord klientinnän konuşmêêr.
- Kurulumnar (biyenilännär, dil, vakitlär) uygulamanın WebView deposunda lokal olarak saklanêr; oyun dizimi keşi hem geçici decoy faylları `%LOCALAPPDATA%\app.decoy.desktop` klasöründä bulunur.
- Analitika yok, kaza raporları yok, akkaunt yok.

## Belli kısıtlamalar

- Discord tanıma metodunu istedii vakit diiştirebilir. Decoy tanınmamaa başlarsa, yalvarêrız bir problem (issue) açın.
- Kimi zanaatlar işleyän bir proțess-tän taa çok şey istär (örnein bir oyun platformunun belli bir olayının içindä bulunmaa). Decoy sade proțessi taklit eder.
- Discord dizimindä exe faylı olmayan oyunnar tanınamaz.
- Güvenlik programnarı yufka oturên imzasız küçük exe fayllarını şüpheli olarak nışannayabilir. Decoy açık kaynaklıdır hem `src-tauri/stub/stub.rs` faylından toplanêr; kendiniz da toplayabilirsiniz.

## Proyektä katılmaa

Yannışlıklar için bildirilär, fikirler hem çevirilär hoş geldilär. Yalvarêrız ilkin [CONTRIBUTING.md](../../CONTRIBUTING.md) okuyun.

## Cuvapçılıktan vazgeçmäk

Decoy kisisel, üürenmäk hem test etmäk niyetlerinnän "nasıl bar ölä" veriler. İşleyän oyunu taklit etmää Discord-un yaki oyun tipografının Kullanış Şartlarını bozabilir hem akkauntunuza karşı iş görmää getirebilir. Onu nasıl kullanırsınız sade siz cuvapçısınız. "Discord" hem hepsi oyun adları hem logoları saapilerinin ticarat markalarıdır hem burada sade anlatılan programmayı bildirmää deyni kullanılmıştır.
