# Decoy

**Discord-қа ойын іске қосылып тұрғандай көрсететін шағын жалған процестер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Соңғы ойындары мен мұқабалары бар Decoy кітапханасы" />

</div>

Decoy ойынның орындалатын файлының атымен зиянсыз, терезесі бар жалған процесті іске қосып ұстап тұрады, сондықтан Discord ойын анықтау жүйесі сізді сол ойынды ойнап жатыр деп есептейді. Сізге нақты ойынды орнату немесе іске қосу қажет емес, сондықтан дискіңізде үлкен көлемді ештеңе сақталмайды.

Ол **Discord анықтай алатын барлық ойындарды** біледі (шамамен 25 000 жазба), өйткені ол Discord-тың өзінің ашық анықтау тізімін оқиды және оны өздігінен жаңартып отырады.

> [!WARNING]
> Ойынның жұмыс істеп тұрғанын жалған көрсету Discord-тың Қызмет көрсету шарттарына қайшы келуі мүмкін және сіз Decoy-ды **өз тәуекеліңізбен** пайдаланасыз.
> Бұл жоба Discord Inc. компаниясымен байланысты емес, мақұлданбаған немесе қатысы жоқ. [Жауапкершіліктен бас тарту](#жауапкершіліктен-бас-тарту) бөлімін қараңыз.

## Мүмкіндіктері

- **Discord анықтай алатын барлық нәрсе.** Ойындар тізімі Discord-тың ашық анықтау түйінінен жүктеледі, жергілікті кэштеледі және күн сайын жаңартылады. Жаңа ойындар мен жаңадан қосылған орындалатын файлдар автоматты түрде пайда болады.
- **Жылдам іздеу.** Мыңдаған ойындар арасында ойын аты немесе орындалатын файл бойынша лезде іздеу, тор немесе жинақы тізім көрінісі, таңдаулылар және «Соңғы» қатары.
- **Бір рет басу.** Ойынды таңдаңыз, орындалатын файлды таңдаңыз (егер бірнешеу болса), оны қанша уақыт ұстау керектігін көрсетіңіз және іске қосуды басыңыз. Кері санақ сақинасы мен хабарландыру уақыттың аяқталғанын хабарлайды.
- **Артында із қалдырмайды.** Жалған процесс (decoy) тек жұмыс істеп тұрған кезде ғана болады: шағын exe іске қосылғанда жасалады және тоқтатылғанда жойылады. Шыққан кезде бәрі тоқтатылады, ал қателіктерден қалған қалдықтар келесі іске қосылғанда тазартылады.
- **Байқалмайды.** Жүйелік науада (трейде) орналасады, жалған процестердің өзі үшін ешқандай терезе немесе тапсырмалар тақтасындағы батырмалар болмайды.
- **Ашық аудармалар.** Интерфейс қарапайым JSON файлдарымен басқарылады, сондықтан тілді қосу бар болғаны бір файл. Ағылшын және орыс тілдері қосылған.
- **Құпиялылық.** Есептік жазба, Discord токені, телеметрия жоқ. [Құпиялылық](#құпиялылық) бөлімін қараңыз.

## Қалай жұмыс істейді

1. Discord сіздің ДК-де жұмыс істеп тұрған процестерді қарап және олардың орындалатын файл атауларын ашық тізіммен (`/api/v9/applications/detectable`) салыстыру арқылы ойын ойнап жатқаныңызды анықтайды.
2. Decoy осы тізімді жүктеп алады және сіз таңдаған ойын үшін тізімдегі орындалатын файл атын пайдаланып (мысалы, `.../cod26-cod.exe`), уақытша қалтаға шағын орынбасар бағдарламаны (шамамен 120 КБ, Rust тілінде жазылған және Decoy ішіне ендірілген) көшіреді.
3. Орынбасар бағдарлама сіз ешқашан көрмейтіндей етіп экраннан тыс алыс орналасқан жалғыз жоғарғы деңгейлі терезеге ие болудан басқа ештеңе істемейді. Discord тек терезесі бар процесті ғана таниды, сондықтан толықтай терезесіз процесс ескерілмейді.
4. Шамамен 15 секунд ішінде Discord ойынды сіздің ағымдағы әрекетіңіз ретінде көрсетеді.
5. Таймер аяқталғанда немесе тоқтатуды басқанда, Decoy процесті аяқтайды және файлды жояды. Windows-тың job нысаны Decoy тіпті апатты түрде жабылса да, жалған процестердің Decoy-мен бірге тоқтатылуын қамтамасыз етеді.

## Орнату

[Releases](../../../../releases) бетінен біреуін таңдаңыз:

| Жүктеп алу | Мақсаты |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Орнатқыш.** Әр пайдаланушы үшін, әкімші құқықтары қажет емес, «Бастау» (Start) мәзіріне жазба мен жойғышты қосады. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативті нұсқа.** Кез келген жерге шығарып алып, `decoy.exe` іске қосыңыз. Барлық деректер қасындағы `data` қалтасында қалады, пайдаланушы профиліне ештеңе жазылмайды. Жою үшін қалтаны өшіріңіз. |

Жүктелген файлды `SHA256SUMS.txt` арқылы тексеріңіз (PowerShell ішінде `Get-FileHash <файл>`).

Windows SmartScreen құрастырылымдардың сандық қолтаңбасы болмағандықтан белгісіз баспагер туралы ескертуі мүмкін; егер құрастырылымға сенсеңіз, *Толығырақ (More info) → Бәрібір іске қосу (Run anyway)* таңдаңыз.

Талаптар: WebView2 runtime бар Windows 10 немесе 11 (64-биттік) (Windows 11 және соңғы Windows 10 жаңартуларында бар).

## Қолдану

1. **Кітапхананы** ашып, ойынды іздеңіз немесе кез келген жерден `Ctrl` + `K` пернелерін басыңыз.
2. Ойынды басыңыз. Оң жақтағы панельде процесті және оны қанша минут ұстап тұру керектігін таңдаңыз (Discord белсенділіктері әдетте 15 минут сұрайды).
3. **Жалған процесті бастау** түймесін басыңыз. Discord бірнеше секундтан кейін ойынды көрсетеді.
4. Оны **Іске қосылған** бөлімінен бақылаңыз, кез келген уақытта біреуін немесе барлығын тоқтатыңыз, немесе жай ғана Decoy-ды науада (трейде) қалдырыңыз.

Discord жазбасында әлі орындалатын файлдары жоқ ойындар әдепкі бойынша жасырылған (олар анықталмайды). Оларды көру үшін *exe жоқ ойындарды көрсету* опциясын қосыңыз; тізім күн сайын жаңартылып отырады, сондықтан Discord процесс қосқан бойда олар қолжетімді болады.

### Пәрмен жолы

```
decoy.exe --launch "<Discord тізіміндегі орындалатын файл жолы>" [минут]
```

Жалған процесті бірден іске қосады, мысалы `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Бастапқы кодтан құрастыру

Алғышарттар: [Node.js](https://nodejs.org) 20+, Visual Studio C++ құрастыру құралдары бар тұрақты [Rust](https://rustup.rs) құралдар жинағы (MSVC target) және WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload мүмкіндігі бар әзірлеу режимінде іске қосу
npm run tauri build    # src-tauri/target/release/bundle/nsis ішінде орнатқышты жасау
```

Пайдалы тексерулер:

```bash
npm run check-locales  # әрбір аударма файлын ru.json файлымен салыстырып тексеру
npx tsc --noEmit       # фронтенд типтерін тексеру
cargo check --manifest-path src-tauri/Cargo.toml
```

Ескертпелер: decoy exe файлы `src-tauri/build.rs` арқылы `src-tauri/stub/stub.rs` кодынан кәдімгі `rustc` көмегімен құрастырылады және қолданба ішіне ендіріледі. Фронтенд қарапайым браузерде іске қосылған кезде (`npm run dev`) шағын жалған бэкенд (`src/mock.ts`) қолданылады, бұл интерфейспен жұмыс істеуге ыңғайлы.

## Аудармалар

Пайдаланушы интерфейсінің жолдары [`src/locales`](../../src/locales) ішінде сақталады, әр тілге бір JSON файлдан (`en.json`, `ru.json`, ...).
Тіл қосу — жаңа файл қосу дегенді білдіреді; кодты өзгерту қажет емес. Файл пішімі, машиналық аудармаға арналған дайын сұрау (prompt) және тексеру сценарийі үшін [docs/TRANSLATING.md](../TRANSLATING.md) файлын қараңыз. Осы README файлының аудармалары `docs/i18n/README.<code>.md` ішіне орналастырылады.

## Жоба құрылымы

```
src/                    React + TypeScript фронтенді
  components/           Кітапхана, мәліметтер тақтасы, баптаулар, ...
  locales/              аударма файлдары (әр тілге бір JSON)
  i18n-core.ts          тілді жүктеу және іздеу
  store.ts              қолданба күйі (zustand)
src-tauri/              Rust бэкенді (Tauri 2)
  src/lib.rs            ойындар дерекқоры, жалған процестер, трей
  stub/stub.rs          ендірілетін орынбасар бағдарлама
scripts/                көмекші сценарийлер (локальдарды тексеру)
docs/                   аудару нұсқаулығы, скриншоттар
```

## Құпиялылық

- Decoy желіні тек Discord-тың ашық анықтау тізімін жүктеп алу үшін (алғашқы іске қосылғанда, одан кейін күніне ең көбі бір рет немесе жаңартуды басқанда) және ойын белгішелері мен мұқабаларын көрсету үшін Discord-тың ашық CDN-інен жүктеуге ғана пайдаланады.
- Ол сіздің Discord токеніңізді немесе қандай да бір тіркелгі деректеріңізді оқымайды, сақтамайды және жібермейді, сондай-ақ Discord клиентімен байланыс жасамайды.
- Баптаулар (таңдаулылар, тіл, ұзақтықтар) қолданбаның WebView жадында жергілікті түрде сақталады; ойындар тізімінің кэші және уақытша decoy файлдары `%LOCALAPPDATA%\app.decoy.desktop` ішінде орналасады.
- Аналитика, апаттық есептер, есептік жазбалар жоқ.

## Белгілі шектеулер

- Discord ойынды анықтау механизмін кез келген уақытта өзгерте алады. Егер жалған процесс танылмай қалса, мәселе (issue) ашыңыз.
- Кейбір белсенділіктер жай жұмыс істеп тұрған процестен де көп нәрсені талап етеді (мысалы, ойын платформасының белгілі бір ойынында болу). Decoy тек процесті еліктейді.
- Discord тізімінде орындалатын файлдары жоқ жазбалар анықталмайды.
- Қауіпсіздік бағдарламалары жадта бос тұрған қолтаңбасы жоқ шағын орындалатын файлдарға кейде күдікпен қарауы мүмкін. Жалған процесс ашық бастапқы кодты және `src-tauri/stub/stub.rs` арқылы жинақталған; оны өзіңіз құрастыра аласыз.

## Жауапкершіліктен бас тарту

Decoy «сол күйінде» жеке, білім беру және тестілеу мақсаттары үшін беріледі. Жұмыс істеп тұрған ойынды жалған еліктету Discord-тың немесе ойын шығарушысының Қызмет көрсету шарттарын бұзуы мүмкін және есептік жазбаңызға қарсы шаралар қолдануға әкелуі мүмкін. Оны қалай пайдаланатыныңызға тек өзіңіз жауаптысыз. «Discord» және барлық ойын атаулары мен логотиптері тиісті иелерінің сауда белгілері болып табылады және мұнда олар сілтеме жасайтын бағдарламалық құралды анықтау үшін ғана қолданылады.
