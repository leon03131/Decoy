# Decoy

**लहान स्टँड-इन प्रोसेस जे Discord ला एखादा गेम चालू असल्याचा भास करून देतात.**

![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="नुकतेच खेळलेले गेम्स आणि आर्टवर्कसह Decoy लायब्ररी" />

Decoy एखाद्या गेमच्या executable नावाखाली एक निरुपद्रवी, विंडो असलेली प्लेसहोल्डर प्रोसेस चालू ठेवतो, ज्यामुळे Discord चे गेम डिटेक्शन तुम्ही तो गेम खेळत असल्याचे दाखवते. तुम्हाला कधीही खरा गेम इन्स्टॉल किंवा सुरू करण्याची आवश्यकता नसते, त्यामुळे तुमच्या डिस्कवर कोणतीही मोठी फाइल राहत नाही.

Discord ज्या **प्रत्येक गेमला डिटेक्ट करू शकते ते सर्व गेम्स** (सुमारे २५,००० नोंदी) याला माहिती आहेत, कारण हे Discord ची स्वतःची सार्वजनिक डिटेक्शन यादी वाचते आणि ती स्वतःहून अद्ययावत (अपडेट) ठेवते.

> [!WARNING]
> गेम चालू असल्याचा खोटा भास निर्माण करणे हे Discord च्या सेवा शर्तींचे (Terms of Service) उल्लंघन ठरू शकते आणि तुम्ही Decoy चा वापर **तुमच्या स्वतःच्या जोखमीवर** करत आहात.
> हा प्रकल्प Discord Inc. शी संलग्न, मान्यताप्राप्त किंवा जोडलेला नाही. [अस्वीकरण](#अस्वीकरण) पहा.

## वैशिष्ट्ये

- **Discord डिटेक्ट करू शकते ते सर्वकाही.** गेमची यादी Discord च्या सार्वजनिक डिटेक्शन एंडपॉइंटवरून डाउनलोड केली जाते, स्थानिक पातळीवर कॅश केली जाते आणि दररोज रीफ्रेश केली जाते. नवीन गेम्स आणि नव्याने जोडलेल्या executables स्वतःहून दिसू लागतात.
- **जलद आणि अचूक शोध.** हजारो गेम्समधून गेमचे नाव किंवा executable द्वारे तत्काळ शोध, ग्रिड किंवा कॉम्पॅक्ट सूची दृश्य, आवडते (favorites) आणि "Recent" ओळ.
- **एक क्लिक.** एखादा गेम निवडा, executable निवडा (एकापेक्षा जास्त असल्यास), तो किती वेळ चालू ठेवायचा ते ठरवा आणि स्टार्ट दाबा. एक काउंटडाउन रिंग आणि नोटिफिकेशन वेळ संपल्यावर तुम्हाला सूचित करतात.
- **मागे काहीही शिल्लक ठेवत नाही.** एक decoy तो चालू असेपर्यंतच अस्तित्वात असतो: लहान exe सुरू होताना तयार केली जाते आणि थांबवल्यावर हटवली जाते. तुम्ही बाहेर पडल्यावर सर्वकाही थांबवले जाते, आणि क्रॅशचे उर्वरित अवशेष पुढील लाँचच्या वेळी साफ केले जातात.
- **शांत.** सिस्टम ट्रेमध्ये राहते, स्वतः decoys साठी कोणतीही विंडोज किंवा टास्कबार बटणे नसतात.
- **खुले भाषांतर.** इंटरफेस साध्या JSON फाइल्सद्वारे चालवला जातो, त्यामुळे नवीन भाषा जोडणे म्हणजे फक्त एकच फाइल जोडणे आहे. इंग्रजी आणि रशियन भाषांचा समावेश आहे.
- **खाजगी.** कोणतेही खाते नाही, कोणताही Discord टोकन नाही, कोणतीही टेलिमेट्री नाही. [गोपनीयता](#गोपनीयता) पहा.

## हे कसे कार्य करते

1. Discord तुमच्या PC वर चालू असलेल्या प्रोसेस तपासून आणि त्यांच्या executable नावांची तुलना एका सार्वजनिक यादीशी (`/api/v9/applications/detectable`) करून तुम्ही एखादा गेम खेळत आहात हे ठरवते.
2. Decoy ती यादी डाउनलोड करते आणि तुम्ही निवडलेल्या गेमसाठी, यादीतील executable नावाचा वापर करून एका लहान स्टँड-इन प्रोग्रामला (सुमारे १२० KB, Rust मध्ये लिहिलेला आणि Decoy मध्ये अंतर्भूत केलेला) एका तात्पुरत्या (temporary) फोल्डरमध्ये कॉपी करते, उदाहरणार्थ `.../cod26-cod.exe`.
3. हा स्टँड-इन प्रोग्राम एका टॉप-लेव्हल विंडोच्या मालकीशिवाय इतर काहीही करत नाही, जी स्क्रीनवरून खूप लांब पार्क केली जाते जेणेकरून तुम्हाला ती कधीही दिसणार नाही. Discord केवळ अशाच प्रोसेसला ओळखते ज्याच्याकडे एखादी विंडो असते, म्हणूनच पूर्णपणे विंडो नसलेल्या प्रोसेसकडे दुर्लक्ष केले जाते.
4. साधारण १५ सेकंदांच्या आत Discord तुमच्या चालू ॲक्टिव्हिटीच्या रूपात तो गेम दाखवू लागते.
5. जेव्हा टायमर संपतो किंवा तुम्ही स्टॉप दाबता, तेव्हा Decoy प्रोसेस समाप्त करते आणि फाइल हटवून टाकते. एक Windows जॉब ऑब्जेक्ट हे सुनिश्चित करतो की Decoy क्रॅश झाला तरीही decoys Decoy सोबतच बंद होतील.

आवश्यकता: WebView2 रनटाइमसह Windows 10 किंवा 11 (64-bit) (Windows 11 आणि अलीकडील Windows 10 अद्यतनांमध्ये आधीपासूनच समाविष्ट आहे).

## वापर

1. **Library** उघडा आणि गेम शोधा, किंवा कुठूनही `Ctrl` + `K` दाबा.
2. गेमवर क्लिक करा. उजव्या बाजूच्या पॅनेलमध्ये प्रोसेस निवडा आणि ती किती मिनिटे चालू ठेवायची ते निवडा (Discord ॲक्टिव्हिटीजसाठी सहसा १५ मिनिटे आवश्यक असतात).
3. **Start decoy** दाबा. Discord काही सेकंदांनंतर गेम दाखवू लागेल.
4. हे **Running** अंतर्गत पहा, कोणत्याही वेळी एक किंवा सर्व थांबवा, किंवा फक्त Decoy ला सिस्टम ट्रेमध्ये राहू द्या.

ज्या गेम्सच्या Discord नोंदीमध्ये अद्याप कोणतीही executables नाहीत ते डीफॉल्टनुसार लपवलेले असतात (ते डिटेक्ट केले जाऊ शकत नाहीत). ते पाहण्यासाठी *Show games without exe* चालू करा; ही यादी दररोज रीफ्रेश केली जाते, त्यामुळे Discord ने प्रोसेस जोडताच ते उपलब्ध होतात.

### कमांड लाइन

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

त्वरित decoy सुरू करतो, उदाहरणार्थ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## सोर्सवरून बिल्ड करा

पूर्वावश्यकता: [Node.js](https://nodejs.org) 20+, Visual Studio C++ बिल्ड टूल्ससह स्थिर [Rust](https://rustup.rs) टूलचेन (MSVC टार्गेट), आणि WebView2 रनटाइम.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload सह डेव्हलपमेंट मोडमध्ये चालवा
npm run tauri build    # src-tauri/target/release/bundle/nsis मध्ये इन्स्टॉलर तयार करा
```

उपयुक्त तपासण्या:

```bash
npm run check-locales  # ru.json विरुद्ध प्रत्येक भाषांतर फाइल तपासा
npx tsc --noEmit       # फ्रंटएंड टाइप-चेक करा
cargo check --manifest-path src-tauri/Cargo.toml
```

टिपा: decoy exe हे `src-tauri/build.rs` द्वारे साध्या `rustc` सह `src-tauri/stub/stub.rs` वरून कंपाइल केले जाते आणि नंतर ॲपमध्ये अंतर्भूत केले जाते. जेव्हा फ्रंटएंड सामान्य ब्राउझरमध्ये चालतो (`npm run dev`), तेव्हा एक लहान मॉक बॅकएंड (`src/mock.ts`) वापरला जातो, जो UI वर काम करण्यासाठी सोयीचा ठरतो.

## भाषांतरे

UI स्ट्रिंग्स [`src/locales`](../../src/locales) मध्ये असतात, प्रति भाषा एक JSON फाइल (`en.json`, `ru.json`, ...).
नवीन भाषा जोडणे म्हणजे एक फाइल जोडणे; कोडमध्ये कोणताही बदल करण्याची गरज नाही. फाइल फॉरमॅट, मशीन भाषांतरासाठी तयार प्रॉम्प्ट आणि व्हॅलिडेशन स्क्रिप्टसाठी [docs/TRANSLATING.md](../TRANSLATING.md) पहा. या README ची भाषांतरे `docs/i18n/README.<code>.md` मध्ये जातात.

## प्रकल्प संरचना

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## गोपनीयता

- Decoy केवळ Discord ची सार्वजनिक डिटेक्शन यादी (पहिल्यांदा सुरू करताना, नंतर दिवसातून जास्तीत जास्त एकदा किंवा तुम्ही रीफ्रेश दाबता तेव्हा) आणि स्क्रीनवर दाखवण्यासाठी Discord च्या सार्वजनिक CDN वरून गेम आयकॉन आणि आर्टवर्क डाउनलोड करण्यासाठी नेटवर्कचा वापर करते.
- हे तुमचे Discord टोकन किंवा कोणताही खाते डेटा वाचत नाही, साठवत नाही किंवा पाठवत नाही, आणि ते Discord क्लायंटशी संवाद साधत नाही.
- सेटिंग्ज (आवडते, भाषा, कालावधी) ॲपच्या स्थानिक WebView स्टोरेजमध्ये साठवल्या जातात; गेम सूची कॅश आणि तात्पुरत्या decoy फाइल्स `%LOCALAPPDATA%\app.decoy.desktop` मध्ये राहतात.
- कोणतेही विश्लेषण (analytics) नाही, क्रॅश रिपोर्टिंग नाही, खाती नाहीत.

## ज्ञात मर्यादा

- Discord कधीही डिटेक्शन कसे काम करते यात बदल करू शकते. जर एखादा decoy ओळखला जाणे बंद झाले, तर कृपया एक issue उघडा.
- काही ॲक्टिव्हिटीजसाठी केवळ चालू असलेल्या प्रोसेसपेक्षा अधिक गोष्टींची आवश्यकता असते (उदाहरणार्थ गेम प्लॅटफॉर्मच्या विशिष्ट अनुभवामध्ये असणे). Decoy फक्त प्रोसेसची नक्कल करते.
- Discord च्या यादीत executables नसलेल्या नोंदी डिटेक्ट केल्या जाऊ शकत नाहीत.
- सुरक्षा सॉफ्टवेअर अधूनमधून मेमरीमध्ये निष्क्रिय बसलेल्या लहान स्वाक्षरी नसलेल्या (unsigned) executables ला संशयास्पद म्हणून फ्लॅग करते. Decoy ओपन सोर्स आहे आणि `src-tauri/stub/stub.rs` वरून तयार केलेला आहे; तुम्ही स्वतः ते कंपाइल करू शकता.
