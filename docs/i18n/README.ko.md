# Decoy

**Discord가 게임을 플레이 중인 것으로 인식하게 만드는 초경량 대역 프로세스.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="최근 게임 및 아트워크가 표시된 Decoy 라이브러리" />

</div>

Decoy는 게임의 실행 파일 이름으로 안전한 창(windowed) 기반의 자리표시(placeholder) 프로세스를 백그라운드에서 실행하여, Discord의 게임 감지 기능이 사용자가 해당 게임을 플레이 중인 것으로 표시하도록 합니다. 실제 게임을 설치하거나 실행할 필요가 전혀 없으므로 디스크 용량을 낭비하지 않습니다.

Discord의 자체 공개 감지 목록을 읽어와 자동으로 최신 상태를 유지하므로, **Discord가 감지할 수 있는 모든 게임**(약 25,000개)을 인식합니다.

> [!WARNING]
> 실행 중인 게임을 위장하는 것은 Discord 서비스 이용약관에 위배될 수 있으며, Decoy의 사용에 따른 **모든 책임은 사용자 본인에게 있습니다**.
> 본 프로젝트는 Discord Inc.와 제휴, 보증 또는 연결되어 있지 않습니다. [면책 조항](#면책-조항)을 참조하세요.

## 주요 기능

- **Discord가 감지할 수 있는 모든 게임 지원.** 게임 목록은 Discord의 공개 감지 엔드포인트에서 다운로드되어 로컬에 캐시되고 매일 새로고침됩니다. 새로운 게임 및 새로 추가된 실행 파일이 자동으로 표시됩니다.
- **빠르고 쾌적한 검색.** 수천 개의 게임을 게임 이름이나 실행 파일명으로 즉시 검색할 수 있으며, 그리드 또는 컴팩트 목록 보기, 즐겨찾기, '최근 항목' 표시줄을 지원합니다.
- **원클릭 실행.** 게임을 선택하고, (여러 개인 경우) 실행 파일을 고른 뒤, 유지할 시간을 설정하고 시작을 누르기만 하면 됩니다. 카운트다운 링과 알림을 통해 종료 시간을 알려줍니다.
- **흔적을 남기지 않음.** 대역(Decoy) 프로세스는 실행 중에만 존재합니다. 시작 시 초경량 exe 파일이 생성되고 중지 시 삭제됩니다. 프로그램을 종료하면 모든 프로세스가 중지되며, 비정상 종료로 인한 잔여 파일은 다음 실행 시 자동으로 정리됩니다.
- **조용하고 깔끔함.** 시스템 트레이에 상주하며, 대역 프로세스 자체의 창이나 작업 표시줄 버튼이 전혀 표시되지 않습니다.
- **손쉬운 번역.** 인터페이스는 순수 JSON 파일로 구동되므로, 단 하나의 파일만 추가하면 새로운 언어를 지원할 수 있습니다. 현재 영어와 러시아어가 포함되어 있습니다.
- **철저한 개인정보 보호.** 계정 불필요, Discord 토큰 불필요, 원격 측정(Telemetry) 없음. [개인정보 보호](#개인정보-보호)를 참조하세요.

## 작동 방식

1. Discord는 PC에서 실행 중인 프로세스를 검사하고 그 실행 파일 이름을 공개 목록(`/api/v9/applications/detectable`)과 대조하여 게임 플레이 여부를 판별합니다.
2. Decoy는 해당 목록을 다운로드한 뒤, 선택한 게임에 대해 초경량 대역 프로그램(약 120 KB, Rust로 작성되어 Decoy에 내장됨)을 목록의 실행 파일 이름(예: `.../cod26-cod.exe`)으로 임시 폴더에 복사합니다.
3. 이 대역 프로그램은 화면 밖 멀리 배치되어 눈에 보이지 않는 최상위 창(top-level window)을 하나 소유하는 것 외에는 아무런 동작도 하지 않습니다. Discord는 창을 소유한 프로세스만 인식하므로, 창이 전혀 없는 프로세스는 무시되기 때문입니다.
4. 약 15초 이내에 Discord에 해당 게임이 현재 활동으로 표시됩니다.
5. 타이머가 종료되거나 중지를 누르면 Decoy가 프로세스를 종료하고 파일을 삭제합니다. Windows 잡 오브젝트(Job Object)를 사용하여 Decoy가 비정상 종료되더라도 대역 프로세스가 함께 종료되도록 보장합니다.

## 설치

[Releases](../../../../releases) 페이지에서 원하는 버전을 다운로드하세요:

| 다운로드 | 용도 |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **설치 프로그램.** 사용자별 설치, 관리자 권한 불필요, 시작 메뉴 항목 및 제거 프로그램 추가. |
| `Decoy_x.y.z_x64-portable.zip` | **포터블.** 원하는 위치에 압축을 풀고 `decoy.exe`를 실행. 모든 데이터는 프로그램 옆의 `data` 폴더에 유지되며 사용자 프로필에는 아무것도 기록되지 않음. 삭제하려면 해당 폴더를 삭제. |

`SHA256SUMS.txt`로 다운로드 파일을 검증할 수 있습니다(PowerShell에서 `Get-FileHash <file>` 실행).

빌드에 코드 서명이 되어 있지 않아 Windows SmartScreen에서 알 수 없는 게시자 경고가 표시될 수 있습니다. 빌드를 신뢰하는 경우 *추가 정보 → 실행*을 선택하세요.

요구 사양: Windows 10 또는 11(64비트) 및 WebView2 런타임(Windows 11 및 최신 Windows 10 업데이트에 이미 포함되어 있음).

## 사용법

1. **라이브러리**를 열고 게임을 검색하거나, 어디서든 `Ctrl` + `K`를 누릅니다.
2. 게임을 클릭합니다. 오른쪽 패널에서 프로세스와 유지할 시간(분)을 선택합니다(Discord 퀘스트/활동은 대개 15분을 요구합니다).
3. **대역 시작**을 누릅니다. 몇 초 후 Discord에 게임이 표시됩니다.
4. **실행 중** 탭에서 상태를 확인하고 언제든지 하나 또는 전체를 중지할 수 있으며, Decoy를 트레이에 그대로 두어도 됩니다.

Discord 항목에 아직 실행 파일이 없는 게임은 기본적으로 숨겨져 있습니다(감지할 수 없기 때문입니다). 이 게임들을 보려면 *exe 없는 게임 표시*를 켜세요. 목록은 매일 새로고침되므로 Discord가 프로세스를 추가하는 즉시 사용할 수 있게 됩니다.

### 명령줄

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

대역 프로세스를 즉시 시작합니다(예: `decoy.exe --launch "robloxplayerbeta.exe" 15`).

## 소스코드에서 빌드

사전 요구 사항: [Node.js](https://nodejs.org) 20 이상, Visual Studio C++ 빌드 도구가 포함된 안정화 버전 [Rust](https://rustup.rs) 툴체인(MSVC 타깃), WebView2 런타임.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # 핫 리로드를 지원하는 개발 모드로 실행
npm run tauri build    # src-tauri/target/release/bundle/nsis 경로에 설치 프로그램 생성
```

유용한 검사 명령어:

```bash
npm run check-locales  # ru.json을 기준으로 모든 번역 파일 유효성 검사
npx tsc --noEmit       # 프론트엔드 타입 검사
cargo check --manifest-path src-tauri/Cargo.toml
```

참고: 대역 exe는 `src-tauri/build.rs`에서 `src-tauri/stub/stub.rs`를 순수 `rustc`로 컴파일한 후 앱에 임베드합니다. 일반 브라우저에서 프론트엔드를 실행할 때(`npm run dev`)는 작은 모의(mock) 백엔드(`src/mock.ts`)가 사용되므로 UI 작업 시 유용합니다.

## 번역

UI 문자열은 [`src/locales`](../../src/locales)에 언어별 JSON 파일(`en.json`, `ru.json` 등)로 저장됩니다.
새 언어를 추가하는 것은 파일 하나를 추가하는 것만으로 충분하며 코드 수정이 필요 없습니다. 파일 형식, 바로 사용할 수 있는 기계 번역용 프롬프트 및 유효성 검사 스크립트에 대해서는 [docs/TRANSLATING.md](../TRANSLATING.md)를 참조하세요. 이 README의 번역본은 `docs/i18n/README.<code>.md`에 저장됩니다.

## 프로젝트 구조

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## 개인정보 보호

- Decoy는 Discord의 공개 감지 목록을 다운로드할 때(최초 실행 시, 이후 최대 하루에 한 번 또는 새로고침을 누를 때)와 게임 아이콘 및 아트워크를 Discord의 공개 CDN에서 가져와 표시할 때에만 네트워크를 사용합니다.
- 사용자의 Discord 토큰이나 어떠한 계정 데이터도 읽거나 저장하거나 전송하지 않으며, Discord 클라이언트와 직접 통신하지 않습니다.
- 설정(즐겨찾기, 언어, 지속 시간)은 앱의 로컬 WebView 스토리지에 저장되며, 게임 목록 캐시와 임시 대역 파일은 `%LOCALAPPDATA%\app.decoy.desktop`에 저장됩니다.
- 분석 도구 없음, 충돌 보고 없음, 계정 없음.

## 알려진 제한사항

- Discord는 언제든지 감지 방식을 변경할 수 있습니다. 대역 프로세스가 더 이상 인식되지 않으면 이슈를 등록해 주세요.
- 일부 활동은 단순한 실행 프로세스 이상을 요구합니다(예: 특정 게임 플랫폼 내의 특정 세션/경험에 접속 중이어야 함). Decoy는 프로세스만을 흉내 냅니다.
- Discord 목록에 실행 파일이 없는 항목은 감지될 수 없습니다.
- 보안 소프트웨어가 메모리에서 유휴 상태로 대기하는 서명되지 않은 소형 실행 파일을 종종 위협으로 탐지할 수 있습니다. 대역 프로그램은 오픈 소스이며 `src-tauri/stub/stub.rs`에서 빌드됩니다. 사용자가 직접 컴파일할 수도 있습니다.

## 면책 조항

Decoy는 개인적, 교육적 및 테스트 목적으로 "있는 그대로(as is)" 제공됩니다. 실행 중인 게임을 흉내 내는 것은 Discord 또는 해당 게임 배급사의 서비스 이용약관을 위반할 수 있으며, 계정 제재로 이어질 수 있습니다. 본 프로그램을 사용하는 방식에 대한 모든 책임은 전적으로 사용자 본인에게 있습니다. "Discord" 및 모든 게임 이름과 로고는 해당 소유자의 상표이며, 여기서는 해당 소프트웨어를 식별하기 위한 목적으로만 사용되었습니다.
