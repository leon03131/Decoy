# Decoy

**Pìcołi progresi de covertina che fa crédare a Discord che ghe sia un zogo in esecusion.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Librarìa de Decoy co zoghi resenti e artwork" />

</div>

Decoy el mantien in esecusion un proceso inòcuo co fenèstra soto el nome de l'eseguìbiłe de un zogo, cusì el sistema de riłevamento de Discord el te mostra drio zogar a cheł zogo. No serve mai instałar o verzar el zogo vero e pròpio, par cuesto no resta gnente de grando sol disco.

El conose **ogni zogo che Discord el pol riłevar** (sirca 25.000 voxi) parché el leze ła lista pùblega de riłevamento de Discord e el ła mantien azornà da soło.

> [!WARNING]
> Falsifegar un zogo in esecusion pol ndar contro i Tèrmini de Servisio de Discord e te dopari Decoy **a to ris-cio e perìcoło**.
> Sto projeto no 'l ze afiłià, aprovà o cołegà a Discord Inc. Varda [Desonara de responsabiłità](#desonara-de-responsabiłità).

## Caratarìsteghe

- **Tuto cueło che Discord pol riłevar.** Ła lista dei zoghi ła vien descargà da l'endpoint pùblego de riłevamento de Discord, salvà inte ła cache łocałe e azornà ogni dì. Zoghi novi e eseguìbiłi pena zontài i conparise da sołi.
- **Serca rapida che tien el paso.** Reserca istantànea par nome del zogo o de l'eseguìbiłe tra miłiari de zoghi, vista a cubełeti o a lista conpata, preferìi e na riga dei “Resenti”.
- **Un clic soło.** Sełiessi un zogo, sełiessi l'eseguìbiłe (se ghe n'è pì de un), sernisi cuanto tenpo tegnirlo e schicia avia. Un aneo co conto a ła roversa e na notìfega i te dise co 'l tenpo el ze scadùo.
- **No 'l sbandona gnente.** Un decoy el esiste soło fin che 'l zira: el pìcoło exe el vien creà a l'invio e scansełà co 'l se ferma. Tuto vien fermà co te vien fora, e cualsesia scarto de un crash el vien netizà a l'avio drioman.
- **Silensioxo.** El vive inte ła tray de sistema, sensa fenèstre o botoni inte ła bara de łe aplicasion par i decoy stessi.
- **Tradusion verte.** L'intarfasa ła ze dirizesta da senplisi file JSON, donca zontar na łéngua el ze cuestion de un file sìngoło. L'ingleze e el ruso i ze incluxi.
- **Risarvà.** Nisun account, nisun token de Discord, nisuna tełemetrìa. Varda [Privacy](#privacy).

## Come che 'l funsiona

1. Discord el deside che te sì drio zogar a un zogo vardando i progresi in esecusion sol to PC e confrontando i so nomi de eseguìbiłe co na lista pùblega (`/api/v9/applications/detectable`).
2. Decoy el descàrega cheła lista e, par el zogo che te ga seliesto, el còpia un pìcoło programa de covertina (sirca 120 KB, scrito in Rust e incorporà in Decoy) inte na cartèła tenporànea doparando el nome de l'eseguìbiłe de ła lista, par exenpio `.../cod26-cod.exe`.
3. El programa de covertina no 'l fa gnente altro che verzar na fenèstra de primo liveło, parchejà tanto distante dal schermo cusì no te ła vedi mai. Discord el conose un proceso soło se 'l ga na fenèstra, ed èco parché un proceso conpletamente sensa fenèstre el vien ignorà.
4. Entro sì e nò 15 segondi Discord el mostra el zogo cofà ła to atività corente.
5. Co scasca el timer o co te schici ferma, Decoy el sera el proceso e el scanseła el file. Un ojeto job de Windows el garantise che i decoy i more insieme a Decoy, anca se 'l va in crash.

## Instałasion

Càtane un da ła pàjina de łe [Releases](../../../../releases):

| Download | Par |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instałatore.** Par utente sìngoło, no serve diriti de aministrador, zonta na voxe al menu Start e un programa par dizinstałar. |
| `Decoy_x.y.z_x64-portable.zip` | **Portàbiłe.** Despaca indove che te vol e fa partir `decoy.exe`. Tuti i dati i resta inte ła cartèła `data` rente a eło, gnente vien scrito inte 'l to profiło utente. Scanseła ła cartèła par cavarlo. |

Verìfega un download co `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen el podarìa vertir de un editor no reconosùo parché łe build no łe ga firma dizitałe; sełiessi *Pì informasion → Esegui isteso* se te te fidi de ła build.

Rechixiti: Windows 10 o 11 (64-bit) col runtime WebView2 (za incluxo in Windows 11 e inte i azornamenti resenti de Windows 10).

## Come dopararlo

1. Verzi **Librarìa** e serca un zogo, opùr schicia `Ctrl` + `K` da cualsesia parte.
2. Fai clic so un zogo. Inte 'l paneło a drita sełiessi el proceso e cuanti menuti tegnirlo (łe atività de Discord de sołito łe domanda 15 menuti).
3. Schicia **Fai partir el decoy**. Discord el mostrerà el zogo dopo pochi segondi.
4. Tienlo soto ocio soto **In esecusion**, fèrmane un o tuti in cualsesia momento, opùr łasa senplisemente Decoy inte ła tray.

I zoghi che inte ła voxe de Discord no i ga 'ncora nisun eseguìbiłe i vien scondùi par inpostasion predefinìa (no i pol èsar riłevài). Ativa *Mostra zoghi sensa exe* par védarli; ła lista ła vien azornà ogni dì, cusì i deventa disponìbiłi pena che Discord zonta un proceso.

### Riga de comando

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

El fa partir un decoy suito, par exenpio `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Conpiłar dal codexe sorzente

Prerechixiti: [Node.js](https://nodejs.org) 20+, el toolchain stàbiłe de [Rust](https://rustup.rs) (target MSVC) co i Visual Studio C++ build tools, e el runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Controłi ùtiłi:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Note: l'eseguìbiłe del decoy el vien conpiłà da `src-tauri/build.rs` co 'l normal `rustc` a partir da `src-tauri/stub/stub.rs` e po incorporà inte l'aplicasion. Co 'l frontend el vien verto inte un normałe browser (`npm run dev`) vien doparà un pìcoło backend finto (`src/mock.ts`), comodo par laorar su l'intarfasa.

## Tradusion

Łe stringhe de l'intarfasa łe vive inte [`src/locales`](../../src/locales), un file JSON par łéngua (`en.json`, `ru.json`, ...). Zontar na łéngua vol dir zontar un file; nisuna modìfega al codexe. Varda [docs/TRANSLATING.md](../TRANSLATING.md) par el formato del file, un prompt pronto da doparar par ła tradusion automàtega e el script de vałidasion. Łe tradusion de sto README łe va in `docs/i18n/README.<code>.md`.

## Strutura del projeto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacy

- Decoy el dopara ła rete soło par descargar ła lista pùblega de riłevamento de Discord (al primo avio, po al màsimo na volta al dì o co te schici azorna) e, par ła vixuałizasion, łe icone e artwork dei zoghi da ła CDN pùblega de Discord.
- No 'l leze, no 'l salva e no 'l manda el to token de Discord o dati de l'account, e no 'l parla col client de Discord.
- Łe inpostasion (preferìi, łéngua, durade) łe ze salvàe łocalmente inte lo storage WebView de l'aplicasion; ła cache de ła lista dei zoghi e i file tenporànei dei decoy i sta in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nisuna anàłisi, nisuna segnałasion de crash, nisun account.

## Limiti conosùi

- Discord el pol canbiar el modo de riłevamento in cualsesia momento. Se un decoy smete de èsar reconosùo, par piazer verzi na segnałasion (issue).
- Alcune atività łe ga bezogno de calcosa de pì de un senplise proceso in esecusion (par exenpio èsar drento na serta esperiensa de na piataforma de zogo). Decoy el imita soło el proceso.
- Łe voxi sensa eseguìbiłi inte ła lista de Discord no łe pol èsar riłevàe.
- I software de seguresa ogni tanto i ponta el deo contro pìcołi eseguìbiłi no firmài che sta fermi in memòria. El decoy el ze open source e conpiłà da `src-tauri/stub/stub.rs`; te połi conpiłartelo da ti.
