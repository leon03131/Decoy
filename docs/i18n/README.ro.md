# Decoy

**Mici procese de substituție care fac Discord să creadă că un joc rulează.**

![Platformă](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Construit cu](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Licență](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca Decoy cu jocuri recente și grafică" />

</div>

Decoy menține în execuție un proces de substituție inofensiv, cu fereastră, sub numele executabilului unui joc, astfel încât detectarea jocurilor din Discord să arate că joci acel joc. Nu trebuie niciodată să instalezi sau să lansezi jocul real, așadar nimic voluminos nu ocupă spațiu pe disc.

Știe despre **fiecare joc pe care Discord îl poate detecta** (aproximativ 25.000 de intrări), deoarece citește lista publică de detecție a Discord și o menține actualizată de la sine.

> [!WARNING]
> Simularea unui joc în rulare poate încălca Termenii și Condițiile Discord, iar utilizarea Decoy se face **pe propriul risc**.
> Acest proiect nu este afiliat, aprobat sau asociat cu Discord Inc. Consultă [Declinarea responsabilității](#declinarea-responsabilității).

## Funcționalități

- **Tot ce poate detecta Discord.** Lista de jocuri este descărcată de la punctul final public de detecție Discord, stocată în memoria cache locală și actualizată zilnic. Jocurile noi și executabilele nou adăugate apar automat.
- **Căutare rapidă și eficientă.** Căutare instantanee după numele jocului sau executabil printre mii de jocuri, vizualizare grilă sau listă compactă, favorite și un rând „Recente”.
- **Un singur clic.** Alege un joc, alege executabilul (dacă există mai multe), alege cât timp să ruleze și apasă start. Un inel cu numărătoare inversă și o notificare te anunță când timpul a expirat.
- **Nu lasă urme.** Un decoy există doar în timp ce rulează: minusculul fișier exe este creat la pornire și șters la oprire. Totul este oprit la ieșire, iar fișierele rămase în urma unei opriri neașteptate sunt curățate la următoarea lansare.
- **Discret.** Rămâne în bara de sistem (system tray), fără ferestre sau butoane în bara de activități pentru decoy-urile în sine.
- **Traduceri deschise.** Interfața funcționează pe baza unor fișiere JSON simple, astfel încât adăugarea unei limbi necesită un singur fișier. Engleza și rusa sunt incluse.
- **Confidențialitate.** Fără cont, fără token Discord, fără telemetrie. Consultă [Confidențialitate](#confidențialitate).

## Cum funcționează

1. Discord determină dacă te joci analizând procesele care rulează pe PC-ul tău și comparând numele executabilelor acestora cu o listă publică (`/api/v9/applications/detectable`).
2. Decoy descarcă acea listă și, pentru jocul ales de tine, copiază un mic program de substituție (aproximativ 120 KB, scris în Rust și încorporat în Decoy) într-un folder temporar, folosind numele executabilului din listă, de exemplu `.../cod26-cod.exe`.
3. Programul de substituție nu face nimic altceva decât să dețină o fereastră de nivel superior, plasată mult în afara ecranului pentru a nu o vedea niciodată. Discord recunoaște doar procesele care dețin o fereastră, motiv pentru care un proces complet fără fereastră este ignorat.
4. În aproximativ 15 secunde, Discord afișează jocul ca activitate curentă.
5. Când cronometrul se termină sau apeși oprire, Decoy încheie procesul și șterge fișierul. Un obiect de tip Windows job garantează că procesele decoy se închid odată cu Decoy, chiar dacă acesta se blochează sau se oprește neașteptat.

## Instalare

Alege o versiune de pe pagina [Releases](../../../../releases):

| Descărcare | Destinație |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalator.** Per utilizator, nu necesită drepturi de administrator, adaugă o intrare în meniul Start și un utilitar de dezinstalare. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabil.** Dezarhivează oriunde și rulează `decoy.exe`. Toate datele rămân în folderul `data` de lângă el, nimic nu este scris în profilul tău de utilizator. Șterge folderul pentru a-l elimina. |

Verifică o descărcare folosind `SHA256SUMS.txt` (`Get-FileHash <fișier>` în PowerShell).

Windows SmartScreen poate afișa un avertisment legat de un editor nerecunoscut, deoarece versiunile nu sunt semnate digital; alege *Mai multe informații → Execută oricum* dacă ai încredere în build.

Cerințe: Windows 10 sau 11 (64 de biți) cu WebView2 runtime (deja inclus în Windows 11 și în actualizările recente de Windows 10).

## Utilizare

1. Deschide **Bibliotecă** și caută un joc, sau apasă `Ctrl` + `K` de oriunde.
2. Fă clic pe un joc. În panoul din dreapta alege procesul și numărul de minute pentru care să-l menții activ (activitățile Discord cer de obicei 15 minute).
3. Apasă **Pornește decoy**. Discord va afișa jocul după câteva secunde.
4. Urmărește-l în secțiunea **În rulare**, oprește unul sau toate oricând, sau lasă Decoy în bara de sistem.

Jocurile a căror intrare Discord nu are încă executabile asociate sunt ascunse în mod implicit (nu pot fi detectate). Activează *Afișează jocurile fără exe* pentru a le vedea; lista este actualizată zilnic, așa că acestea devin disponibile de îndată ce Discord adaugă un proces.

### Linie de comandă

```
decoy.exe --launch "<cale executabil din lista Discord>" [minute]
```

Pornește imediat un decoy, de exemplu `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilare din surse

Cerințe preliminare: [Node.js](https://nodejs.org) 20+, lanțul de instrumente stabil [Rust](https://rustup.rs) (ținta MSVC) cu instrumentele de compilare Visual Studio C++, și WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # rulare în modul de dezvoltare cu reîncărcare la cald
npm run tauri build    # generare instalator în src-tauri/target/release/bundle/nsis
```

Comenzi utile pentru verificare:

```bash
npm run check-locales  # validează fiecare fișier de traducere în raport cu ru.json
npx tsc --noEmit       # verificare tipuri frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Observații: fișierul exe decoy este compilat de `src-tauri/build.rs` folosind direct `rustc` din `src-tauri/stub/stub.rs` și este apoi încorporat în aplicație. Când interfața frontend rulează într-un browser obișnuit (`npm run dev`), este utilizat un backend demonstrativ mock (`src/mock.ts`), care este practic pentru dezvoltarea interfeței grafice.

## Traduceri

Șirurile de caractere ale interfeței se află în [`src/locales`](../../src/locales), câte un fișier JSON pentru fiecare limbă (`en.json`, `ru.json`, ...).
Adăugarea unei limbi presupune doar adăugarea unui fișier; fără modificări de cod. Consultă [docs/TRANSLATING.md](../TRANSLATING.md) pentru formatul fișierului, un prompt gata de utilizat pentru traducere automată și scriptul de validare. Traducerile acestui fișier README se salvează în `docs/i18n/README.<code>.md`.

## Structura proiectului

```
src/                    Frontend React + TypeScript
  components/           Bibliotecă, panou detalii, setări, ...
  locales/              fișiere de traducere (câte un JSON pentru fiecare limbă)
  i18n-core.ts          încărcare și căutare limbă
  store.ts              stare aplicație (zustand)
src-tauri/              Backend Rust (Tauri 2)
  src/lib.rs            bază de date jocuri, procese decoy, bară de sistem
  stub/stub.rs          programul de substituție care este încorporat
scripts/                scripturi ajutătoare (validare fișiere locale)
docs/                   ghid de traducere, capturi de ecran
```

## Confidențialitate

- Decoy folosește rețeaua doar pentru a descărca lista publică de detecție Discord (la prima pornire, apoi cel mult o dată pe zi sau când apeși pe actualizare) și, pentru afișare, pictogramele jocurilor și elementele grafice de pe CDN-ul public Discord.
- Nu citește, nu stochează și nu trimite tokenul tău Discord sau orice date asociate contului, și nu comunică cu clientul Discord.
- Setările (favorite, limbă, durate) sunt stocate local în spațiul de stocare WebView al aplicației; memoria cache a listei de jocuri și fișierele temporare decoy se află în `%LOCALAPPDATA%\app.decoy.desktop`.
- Fără analize de utilizare, fără rapoarte de eroare, fără conturi de utilizator.

## Limitări cunoscute

- Discord poate modifica mecanismul de detecție oricând. Dacă un decoy nu mai este recunoscut, te rugăm să deschizi o problemă (issue).
- Unele activități necesită mai mult decât un simplu proces în execuție (de exemplu, prezența în cadrul unei anumite experiențe a unei platforme de jocuri). Decoy doar imită procesul.
- Intrările care nu au executabile în lista Discord nu pot fi detectate.
- Programele de securitate semnalează ocazional fișiere executabile mici și nesemnate care rămân inactive în memorie. Decoy este open source și este compilat din `src-tauri/stub/stub.rs`; îl poți compila chiar tu.
