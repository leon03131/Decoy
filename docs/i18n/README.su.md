# Decoy

**Prosés gaganti leutik anu ngajadikeun Discord nganggap hiji kaulinan nuju jalan.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Pustaka Decoy kalawan kaulinan anyar sareng artwork" />

</div>

Decoy ngajaga prosés gaganti kajandéla anu henteu ngabahayakeun tetep jalan dina handapeun nami berkas éksekusi kaulinan, ku kituna detéksi kaulinan Discord ngalaporkeun anjeun nuju maénkeun éta kaulinan. Anjeun henteu kedah masang atanapi ngamimitian kaulinan aslina, janten teu aya koropak ageung anu nyéépkeun rohangan panyimpenan anjeun.

Aplikasi ieu terang ngeunaan **unggal kaulinan anu tiasa didetéksi ku Discord** (sakitar 25.000 éntri) margi maca daptar detéksi umum milik Discord nyalira sareng ngaropéana sacara otomatis.

> [!WARNING]
> Malsukeun kaulinan anu nuju jalan tiasa ngalanggar Sarat Layanan Discord sareng anjeun nganggo Decoy **kalayan résiko anjeun nyalira**.
> Proyék ieu henteu aya hubunganana sareng, dirojong ku, atanapi kaitan sareng Discord Inc. Tingal [Bantahan](#bantahan).

## Fitur

- **Sadayana anu tiasa didetéksi Discord.** Daptar kaulinan diunduh tina endpoint detéksi umum Discord, disimpen dina cache lokal, sareng diropéa unggal dinten. Kaulinan anyar sareng berkas éksekusi anu nembé ditambihkeun bakal némbongan sacara otomatis.
- **Milarian anu gancang.** Milarian instan dumasar nami kaulinan atanapi berkas éksekusi di antawis rébuan kaulinan, tampilan kotak atanapi daptar ringkes, paporit, sareng baris "Anyar".
- **Hiji klik.** Pilih kaulinan, pilih berkas éksekusi (upami aya sababaraha), pilih sababaraha lami badé dijagana teras pencét mimitian. Cincin étangan mundur sareng bérébéja bakal ngawartosan anjeun nalika waktosna séép.
- **Henteu nyésakeun nanaon.** Hiji decoy ngan saukur aya nalika nuju jalan: koropak exe leutik didamel nalika ngamimitian sareng dihapus nalika dieureunkeun. Sadayana dieureunkeun nalika anjeun kaluar, sareng sésa-sésa tina masalah (crash) bakal diberesihan dina peluncuran salajengna.
- **Tengtrem.** Cicing dina baki sistem (system tray), teu aya jandéla atanapi tombol bilah tugas (taskbar) pikeun decoy éta nyalira.
- **Tarjamahan kabuka.** Antarbeungeut dijalankeun ku koropak JSON biasa, janten nambihkeun basa anyar ngan saukur hiji koropak. Basa Inggris sareng Rusia parantos kalebet.
- **Privat.** Teu aya akun, teu aya token Discord, teu aya télémetri. Tingal [Privasi](#privasi).

## Cara damelna

1. Discord nangtukeun yén anjeun nuju maénkeun kaulinan ku ningali prosés anu nuju jalan dina PC anjeun sareng ngabandingkeun nami berkas éksekusina sareng daptar umum (`/api/v9/applications/detectable`).
2. Decoy ngaunduh daptar éta sareng, pikeun kaulinan anu anjeun pilih, nyalin program gaganti leutik (sakitar 120 KB, diserat dina Rust sareng diselapkeun kana Decoy) ka polder samentawis nganggo nami berkas éksekusi tina daptar éta, contona `.../cod26-cod.exe`.
3. Program gaganti henteu ngalakukeun nanaon salian ti gaduh hiji jandéla tingkat luhur (top-level window), anu diparkir tebih di luar layar ku kituna anjeun henteu kantos ningalna. Discord ngan ukur ngakuan prosés anu gaduh jandéla, ku sabab éta prosés anu teu aya jandélaan pisan bakal diabaikeun.
4. Dina sakitar 15 detik, Discord bakal némbongkeun kaulinan éta minangka kagiatan anjeun ayeuna.
5. Nalika pangétang waktos réngsé atanapi anjeun mencét eureun, Decoy ngeureunkeun prosés sareng ngahapus berkasna. Obyék tugas Windows (job object) mastikeun decoy paéh babarengan sareng Decoy, sanaos upami aplikasina ngalaman masalah (crash).

## Pamasangan

Pilih salah sahiji tina kaca [Rilis](../../../../releases):

| Unduhan | Kanggo |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Pamasang (Installer).** Per-pamaké, teu peryogi hak administrator, nambihkeun éntri ménu Mimitian (Start menu) sareng panghapus pamasangan (uninstaller). |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Ekstrak di mana waé sareng jalankeun `decoy.exe`. Sadaya data tetep aya dina polder `data` di gigireunana, teu aya anu diserat kana profil pamaké anjeun. Hapus polder pikeun ngahapusna. |

Parios unduhan nganggo `SHA256SUMS.txt` (`Get-FileHash <file>` di PowerShell).

Windows SmartScreen panginten tiasa ngingetkeun ngeunaan pamedal anu henteu dipikanyaho margi rakitan (build) henteu ditandatanganan sacara digital (code signed); pilih *More info → Run anyway* upami anjeun percanten kana rakitan éta.

Sarat: Windows 10 atanapi 11 (64-bit) kalawan WebView2 runtime (parantos kalebet dina Windows 11 sareng pembaruan Windows 10 panganyarna).

## Pamakéan

1. Buka **Pustaka** sareng milari kaulinan, atanapi pencét `Ctrl` + `K` ti mana waé.
2. Klik kaulinan. Dina panel di beulah katuhu, pilih prosés sareng sabaraha menit badé dijagana (kagiatan Discord biasana nyungkeun 15 menit).
3. Pencét **Mimitian decoy**. Discord bakal némbongkeun kaulinan saatos sababaraha detik.
4. Awaskeun dina bagian **Jalan**, eureunkeun salah sahiji atanapi sadayana iraha waé, atanapi antepkeun waé Decoy dina baki (tray).

Kaulinan anu éntri Discord-na tacan gaduh berkas éksekusi disumputkeun sacara standar (kaulinan henteu tiasa didetéksi). Hurungkeun *Témbongkeun kaulinan tanpa exe* pikeun ningalna; daptar ieu diropéa unggal dinten, ku kituna bakal sayogi pas Discord nambihkeun prosésna.

### Paréntah baris

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Ngamimitian decoy sacara langsung, contona `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ngawangun tina sumber

Prasarat: [Node.js](https://nodejs.org) 20+, toolchain [Rust](https://rustup.rs) stabil (target MSVC) sareng Visual Studio C++ build tools, sarta WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # ngajalankeun dina modeu pamekaran kalawan hot reload
npm run tauri build    # ngahasilkeun pamasang dina src-tauri/target/release/bundle/nsis
```

Pamariksaan anu mangpaat:

```bash
npm run check-locales  # mariksa unggal koropak tarjamahan dumasar kana ru.json
npx tsc --noEmit       # mariksa tipe frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Catetan: berkas exe decoy dikompilasi ku `src-tauri/build.rs` nganggo `rustc` standar tina `src-tauri/stub/stub.rs` teras diselapkeun kana aplikasi. Nalika frontend dijalankeun dina panyungsi biasa (`npm run dev`), backend tiruan (mock) leutik (`src/mock.ts`) bakal dianggo, anu pohara mangpaat pikeun ngerjakeun antarbeungeut (UI).

## Tarjamahan

Runtuyan string UI aya dina [`src/locales`](../../src/locales), hiji koropak JSON per basa (`en.json`, `ru.json`, ...). Nambihkeun basa hartosna ngan saukur nambihkeun hiji koropak; henteu kedah ngarobih kode. Tingal [docs/TRANSLATING.md](../TRANSLATING.md) pikeun format koropak, pamundut siap pakai pikeun tarjamahan mesin, sareng skrip validasi. Tarjamahan tina README ieu disimpen dina `docs/i18n/README.<code>.md`.

## Rarancang proyék

```
src/                    React + TypeScript frontend
  components/           Pustaka, panel detil, setélan, ...
  locales/              koropak tarjamahan (hiji JSON per basa)
  i18n-core.ts          ngamuat basa sareng pamilarian
  store.ts              kaayaan aplikasi (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            pangkalan data kaulinan, prosés decoy, baki (tray)
  stub/stub.rs          program gaganti anu diselapkeun
scripts/                skrip pangbantu (validasi locale)
docs/                   pituduh narjamahkeun, gambar layar
```

## Privasi

- Decoy ngan ukur nganggo jaringan pikeun ngaunduh daptar detéksi umum Discord (nalika mimiti dijalankeun, teras paling sering sakali sapoé atanapi nalika anjeun mencét ropéa) sareng, pikeun tampilan, ikon kaulinan sarta artwork tina CDN umum Discord.
- Aplikasi ieu henteu maca, nyimpen, atanapi ngirimkeun token Discord anjeun atanapi data akun naon waé, sareng henteu komunikasi sareng klien Discord.
- Setélan (paporit, basa, lilana) disimpen sacara lokal dina panyimpenan WebView aplikasi; panyimpenan samentawis daptar kaulinan sareng koropak decoy samentawis aya dina `%LOCALAPPDATA%\app.decoy.desktop`.
- Teu aya analitik, teu aya laporan masalah (crash), teu aya akun.

## Watesan anu dipikanyaho

- Discord tiasa ngarobih cara damel detéksi iraha waé. Upami decoy henteu deui dikenal, punten buka hiji isu (issue).
- Sababaraha kagiatan peryogi langkung ti saukur prosés anu jalan (contona aya dina pangalaman tinangtu dina platform kaulinan). Decoy ngan ukur nurutan prosésna waé.
- Éntri tanpa berkas éksekusi dina daptar Discord henteu tiasa didetéksi.
- Parangkat lunak kaamanan sakapeung nandaan berkas éksekusi leutik anu henteu ditandatanganan anu cicing di mémori. Decoy mangrupikeun sumber kabuka (open source) sareng diwangun tina `src-tauri/stub/stub.rs`; anjeun tiasa ngompilasina nyalira.

## Bantahan

Decoy disayogikeun "sakumaha ayana" pikeun tujuan pribadi, atikan, sareng tés. Nirukeun kaulinan anu nuju jalan tiasa ngalanggar Sarat Layanan Discord atanapi pamedal kaulinan, sareng tiasa nyababkeun tindakan kana akun anjeun. Anjeun nyalira anu nanggung résiko tina cara anjeun ngagunakeunana. "Discord" sareng sadaya nami kaulinan sarta logo mangrupikeun mérek dagang ti anu gaduhna masing-masing sareng ngan ukur dianggo di dieu pikeun ngaidéntifikasi parangkat lunak anu dimaksud.
