# Decoy

**Discord-ым джэгу макӏо къышӏогъэхъуным пае цӏыкӏу-цӏыкӏоу заглушкэ процессхэр.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотек мытэрэзэу джэгухэмрэ сурэтхэмрэ игъусэу" />

Decoy-м джэгум и exe файлым ыцӏэкӏэ зэрар зымыӏэ, шъхьангъупчъэ зиӏэ заглушкэ процесс гъэӏорышӏагъэу елъытэ, ащ къыхэкӏэу Discord-ым джэгур къыхэгъэщыным исистемэ о а джэгур джэгурэу къыбделъытэ. Шъыпкъэ джэгур гъэуцун е гъэӏорышӏэн ищыкӏагъэп, дискам зыпари хэмыушъхьафыкӏыгъэ темылъэу къанэ.

Ащ **Discord-ым къышӏэшъущт джэгу пстэури** ешӏэ (25 000 фэдиз тхыгъэ), сыда пӏомэ Discord-ым и зэӏухыгъэ тхылъпкъ ежь-ежьырэу къеджэ ыкӏи зэпытхэу кӏэкегъэцӏыкӏыжьы.

> [!WARNING]
> Джэгу гъэӏорышӏагъэм фэдэу къэгъэлъэгъоныр Discord-ым и Гъэфедэкӏэ Хабзэхэм акӏэмыкӏынкӏэ мэхъу, Decoy **уи кӏуэчӏэкӏи уи къинэпщыкӏи** мэлажьэ.
> Мы проект Discord Inc. компанием епхыгъэп, ащ ыштагъэп ыкӏи ыгъэунэфыгъэп. Еплъ: [Къинэпщыгъэ гъэунэфын](#къинэпщыгъэ-гъэунэфын).

## Амалхэр

- **Discord-ым къышӏэшъущт пстэури.** Джэгухэм ятхылъпкъ Discord-ым и зэӏухыгъэ хъостыр къыхахы, чӏыпӏэм къыщынафэ ыкӏи мафэ къэс кӏэкегъэцӏыкӏыжьы. Джэгу кӏэхэри кӏэу хигъэхъогъэ exe файлхэри ежь-ежьырэу къыхэфэх.
- **Псынкӏэ лъыхъон.** Мин пчъагъэ джэгухэм азыфагу джэгум ыцӏэкӏэ е exe файлкӏэ псынкӏэу лъыхъон, хьэбзэхэкӏэ е тхылъпкъкӏэ къэгъэлъэгъон, хэшыпыфыгъэхэмрэ «Мытэрэзэу» сатырымрэ.
- **Зы тепӏэгъокӏэ.** Джэгур къыхэх, exe файлыр къыхэх (бэ хъумэ), дакъикъэ тхьапшэ ӏыгъыщтыр гъэунэфи, заглушкэр гъэӏорышӏэ. Зэжэщт хъурэмрэ хигъэшӏэнымрэ уахътэр зыкӏэкӏэ къыбдаӏощт.
- **Лъэуж къинэрэп.** Заглушкэр щыӏэр лажьэзэ закъор ары: цӏыкӏу exe файлыр къызежьэкӏэ къэхъу, зыуцукӏэ тегъэкӏодагъэ мэхъу. Программэм узыхэкӏкӏэ пстэури мэуцу, къутамэ къыхэкӏэу къэнагъэхэр къыкӏэлъыкӏорэ зэӏухыгъэм егъэкъэбзажьы.
- **Жъугъо гущыӏэнчъэ.** Системнэ трейм щэпсэу, заглушкэхэм яшъхьаф шъхьангъупчъэхэр е кнопкэхэр яӏэхэп.
- **Зэӏухыгъэ зэдзэкӏыгъэхэр.** Интерфейсыр аткӏоу JSON файлхэм атет, ащ къыхэкӏэу бзэ хэгъэхъоныр — зы файл закъу. Инджылыбзэри урысыбзэри хэтхэу щытых.
- **Къабзэныгъэ шъэф.** Аккаунт ищыкӏагъэп, Discord токен щыӏэп, телеметри щыӏэп. Еплъ: [Къабзэныгъэ шъэф](#къабзэныгъэ-шъэф).

## Мыр зэрылажьэрэр

1. Discord-ым уи компьютерым щагъэӏорышӏэгъэ процессхэр уплъэкӏухэзэ, ахэм я exe файлхэм яцӏэхэр зэӏухыгъэ тхылъпкъым (`/api/v9/applications/detectable`) игъусэу зэрилъытэзэ, джэгум уджэгурэу къелъытэ.
2. Decoy-м а тхылъпкъыр къещэти, убгъэунэфыгъэ джэгум пае цӏыкӏу-цӏыкӏоу заглушкэ программэ (120 КБ фэдиз, Rust-кӏэ тхыгъэу Decoy-м хэлъыр) уахътэ папка тхылъпкъым къыхэкӏыгъэ exe цӏэкӏэ егъэкӏокӏы, гущыӏэм пае `.../cod26-cod.exe`.
3. Заглушкэм экраным бэ дэдэкӏэ пэчыжьэу щылъ зы шъхьангъупчъэ къызэӏухыгъэм фэшъхьаф зыпари ышӏэрэп, ащ къыхэкӏэу зыпари плъэгъущтэп. Discord-ым шъхьангъупчъэ зиӏэ процессхэр закъор ары къызэрилъытэрэр, шъхьангъупчъэнчъэ процессхэр къылъытэхэп.
4. Секунди 15 фэдиз тешӏэмэ Discord-ым а джэгур уи джыдэдэм щыӏэ ӏофшӏагъэу къегъэлъагъо.
5. Таймерыр зыухыкӏэ е гъэуцуным узепӏкӏэ, Decoy-м процессыр егъэуцу ыкӏи файлыр тегъэкӏодажьы. Windows-ым и job object системэм Decoy къутэгъэми заглушкэхэр зэдигъэуцущт.

## Гъэуцун

[Къыдэкӏыгъэхэм](../../../../releases) янапэкӏэ зы къыхэх:

| Къещэн | Сыдэу щыт |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Гъэуцупӏэ.** Зы гъэфедакӏом пае, администратор фитыныгъэ ищыкӏагъэп, «Пуск» менюм тхыгъэ хегъахьэ ыкӏи деинсталлятор иӏ. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативнэ.** Хэт чӏыпӏи зэӏухи `decoy.exe` гъэӏорышӏэ. Даннэ пстэури игъунэгъу `data` папкэм къэнафэ, гъэфедакӏом ипрофиль зыпари тетхэрэп. Текӏодэжьын пае папкэр птекӏод хъущт. |

Къещэгъэ файлыр `SHA256SUMS.txt` шаркӏэ уплъэкӏу (PowerShell-м `Get-FileHash <файл>`).

Windows SmartScreen-ым цӏэрыӏо мыхъугъэ тхэкӏо уиӏ аӏоу къин къыпфишӏынкӏэ мэхъу, сыда пӏомэ сборкэхэм цифрэ ӏэпыдз яӏэп; уфэсакъэу гугъэ уиӏэмэ *Нэмыкӏ къэбар → Сыд фэдэми гъэӏорышӏэн* хэх.

Щыкӏагъэхэр: Windows 10 е 11 (64-bit) WebView2 runtime игъусэу (Windows 11-ми Windows 10 кӏэ кӏэкегъэцӏыкӏыгъэхэми хэтхэу щыт).

## Гъэфедэкӏэ

1. **Библиотек** зэӏухи джэгум лъыхъу, е хэт чӏыпӏи `Ctrl` + `K` тепӏ.
2. Джэгум тепӏ. Ижь лъэныкъо панелым процессыр къыхэхи дакъикъэ тхьапшэ ӏыгъыщтыр гъэунаф (Discord ӏофшӏэгъэхэм хабзэу 15 ящыкӏагъ).
3. **Заглушкэр гъэӏорышӏэн** тепӏ. Секунд заул тешӏэмэ Discord-ым джэгур къегъэлъэгъощт.
4. **Гъэӏорышӏагъэхэр** вкладкэм чӏэлъэу еплъ, зыр е пстэури хэт уахътэми гъэуцу, е Decoy трейм чӏэбдзэ хъущт.

Discord базэм exe файлхэр джыри зыщымыӏэ джэгухэр хабзэу гъэбылъыгъэх (ахэр къэгъотышъущтэп). Ахэр плъэгъун пае *Exe зимыӏэхэр къэгъэлъэгъон* къэгъэнаф; тхылъпкъыр мафэ къэс кӏэкегъэцӏыкӏыжьы, ащ къыхэкӏэу Discord-ым процесс хигъэхъожьмэ, хьазыр хъущтых.

### Команднэ сатыр

```
decoy.exe --launch "<Discord тхылъпкъым къыхэкӏыгъэ exe гъогур>" [дакъикъэхэр]
```

Заглушкэр сыд уахътэми псынкӏэу егъэӏорышӏэ, гущыӏэм пае: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Хъостырым къыхэхыгъэу гъэпсын

Ищыкӏагъэхэр: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) хъостыр (MSVC target) Visual Studio C++ build tools игъусэу, ыкӏи WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload игъусэу разработка ражкӏэ гъэӏорышӏэн
npm run tauri build    # src-tauri/target/release/bundle/nsis чӏэгъ гъэуцупӏэр гъэхьэзырын
```

Уплъэкӏун ӏэпыӏэгъухэр:

```bash
npm run check-locales  # зэдзэкӏыгъэ файл пстэури ru.json-м елъытыгъэу уплъэкӏун
npx tsc --noEmit       # фронтендым и типхэр уплъэкӏун
cargo check --manifest-path src-tauri/Cargo.toml
```

Къэбархэр: заглушкэ exe-р `src-tauri/build.rs` скриптымкӏэ `rustc` амалкӏэ `src-tauri/stub/stub.rs` файл хэхагъэм къыхэхыгъэу компилировать ешӏи программэм хегъахьэ. Фронтендыр браузер къызэрыкӏом щылажьэкӏэ (`npm run dev`) цӏыкӏу мок-бэкенд (`src/mock.ts`) къэгъэфедагъэ мэхъу, интерфейсымкӏэ ӏоф пшӏэнэу ӏэрыфэгъу.

## Зэдзэкӏыгъэхэр

Интерфейсым игущыӏэхэр [`src/locales`](../../src/locales) чӏэлъых, бзэ къэс зы JSON файл (`en.json`, `ru.json`, ...). Бзэ хэгъэхъоным пае файл хэгъэхъон закъор ары — кодым зыпари зэблихъурэп. Файлхэм яформат, машинэм зэредзэкӏырэ промптыр ыкӏи валидацие скриптыр къэгъотын пае еплъ: [docs/TRANSLATING.md](../TRANSLATING.md). Мы README-м изэдзэкӏыгъэхэр `docs/i18n/README.<code>.md` папка итхэх.

## Проектым ишъпкъыгъэ

```
src/                    React + TypeScript фронтенд
  components/           Библиотек, нэмыкӏ къэбархэм япанель, гъэпсыкӏэхэр, ...
  locales/              зэдзэкӏыгъэ файлхэр (бзэ къэс зы JSON)
  i18n-core.ts          бзэр зэӏухыныр ыкӏи лъыхъоныр
  store.ts              приложением и щытыкӏэ (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            джэгухэм ябазэ, заглушкэ процессхэр, трей
  stub/stub.rs          чӏэгъэлъ заглушкэ программэр
scripts/                ӏэпыӏэгъу скриптхэр (локальхэр уплъэкӏун)
docs/                   зэдзэкӏыным игъогумэхъу, скриншотхэр
```

## Къабзэныгъэ шъэф

- Decoy-м сетьыр Discord-ым и зэӏухыгъэ тхылъпкъ къещэным пае закъор ары зыгъэфедэрэр (апэрэ зэӏухыгъэм, етӏанэ мафэм зэ е кӏэкегъэцӏыкӏыжьыным узепӏкӏэ) ыкӏи къэгъэлъэгъоным пае джэгу тамыгъэхэр Discord CDN хъостыр къыхех.
- Уи Discord токен е аккаунт даннэхэр еджэрэп, ӏыгъырэп, лъигъэӏэсырэп ыкӏи Discord клиентми епсалъэрэп.
- Гъэпсыкӏэхэр (хэшыпыфыгъэхэр, бзэр, уахътэр) чӏыпӏэмкӏэ приложением и WebView чӏэгъ къэнафэх; джэгу тхылъпкъым икэшрэ заглушкэм яуахътэ файлхэмрэ `%LOCALAPPDATA%\app.decoy.desktop` чӏэлъых.
- Аналитикэ щыӏэп, къутэгъэ отчёт щыӏэп, аккаунтхэр щыӏэхэп.

## Зэлъашӏэрэ гъэунэфыгъэхэр

- Discord-ым къэгъотыным и хабзэ хэт уахътэми зэблихъун ылъэкӏыщт. Заглушкэр къэмылъытэу хъумэ, issue къызэӏух.
- Зыгорэ ӏофшӏэгъэхэм пае лажьэрэ процесс закъор икъурэп (гущыӏэм пае джэгу платформым и хэхагъэ чӏыпӏэ ущыӏэн фае). Decoy-м процессыр закъор ары зэрилъытэрэр.
- Discord тхылъпкъым exe зимыӏэ тхыгъэхэр къэгъотышъущтэп.
- Хъурае программэхэм яӏэпэӏэгъу системэхэм памяти шъхьаджэу щылъ цифрэ ӏэпыдз зимыӏэ exe файлхэм къин къафашӏынкӏэ мэхъу. Заглушкэр зэӏухыгъэ код зиӏэу `src-tauri/stub/stub.rs` къыхэкӏыгъэу гъэпсыгъэ; ежь-ежьырэу компилировать пшӏы хъущт.

## Гъусэныгъэ

Хабзэ къутэгъэ къэбархэр, еплъыкӏэхэр ыкӏи зэдзэкӏыгъэхэр къэтштащтых. Тхьашъуегъэпсэу, апэ рахъоу [CONTRIBUTING.md](../../CONTRIBUTING.md) еплъ.

Decoy хэхагъэу, егъэджэн ыкӏи уплъэкӏун мурадхэм апае къытыгъэ. Гъэфедэкӏэм пае уежь-ежьырэу упшъэдэкӏыжь. «Discord» ыкӏи джэгу цӏэ пстэури я ежь-ежьырэ авторхэм я товар тамыгъэхэу щытых ыкӏи программэхэр къэгъэлъэгъоным пае закъор ары мыщ къызщыгъэфедагъэхэр.
