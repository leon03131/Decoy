# Decoy

**תהליכי דמה זעירים שגורמים ל-Discord לחשוב שמשחק פועל.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="ספריית Decoy עם משחקים אחרונים ותמונות" />

</div>

Decoy מריץ תהליך דמה בלתי-מזיק בעל חלון תחת שם קובץ ההפעלה של המשחק, כך שמנגנון זיהוי המשחקים של Discord מציג שאתם משחקים באותו משחק. אין צורך להתקין או להפעיל את המשחק האמיתי, כך ששום קובץ כבד אינו תופס מקום בדיסק שלכם.

הוא מכיר **כל משחק ש-Discord מסוגל לזהות** (כ-25,000 פריטים), מכיוון שהוא קורא את רשימת הזיהוי הציבורית של Discord עצמו ומעדכן אותה אוטומטית בעצמו.

> [!WARNING]
> זיוף משחק פועל עלול להפר את תנאי השימוש של Discord, והשימוש ב-Decoy הוא **על אחריותכם בלבד**.
> פרויקט זה אינו קשור ל-Discord Inc., אינו נתמך על ידה ואינו משויך אליה. ראו [כתב ויתור](#כתב-ויתור).

## תכונות

- **כל מה ש-Discord יכול לזהות.** רשימת המשחקים מורדת מנקודת הקצה הציבורית לזיהוי של Discord, נשמרת במטמון מקומי ומתרעננת מדי יום. משחקים חדשים וקבצי הפעלה שנוספו לאחרונה מופיעים מעצמם.
- **חיפוש מהיר ומתקדם.** חיפוש מיידי לפי שם המשחק או קובץ ההפעלה מתוך אלפי משחקים, תצוגת רשת או רשימה קומפקטית, מועדפים ושורת "אחרונים".
- **בלחיצה אחת.** בוחרים משחק, בוחרים את קובץ ההפעלה (אם ישנם כמה), קובעים לכמה זמן להשאיר אותו פעיל ולוחצים על הפעלה. טבעת ספירה לאחור והודעה יידעו אתכם כאשר הזמן יסתיים.
- **לא משאיר עקבות.** תהליך הדמה קיים רק בזמן פעולתו: קובץ ה-exe הזעיר נוצר בעת ההפעלה ונמחק בעת העצירה. הכל נעצר כשיוצאים מהתוכנה, ושאריות שנותרו עקב קריסה מנוקות בהפעלה הבאה.
- **שקט.** פועל במגש המערכת (system tray), ללא חלונות או כפתורים בשורת המשימות עבור תהליכי הדמה עצמם.
- **תרגומים פתוחים.** הממשק מונע על ידי קובצי JSON פשוטים, כך שהוספת שפה דורשת קובץ יחיד בלבד. אנגלית ורוסית כלולות מראש.
- **פרטי.** ללא צורך בחשבון, ללא אסימון (token) של Discord, וללא טלמטריה. ראו [פרטיות](#פרטיות).

## כיצד זה עובד

1. Discord קובע שאתם משחקים במשחק על ידי בדיקת התהליכים הפועלים במחשב שלכם והשוואת שמות קובצי ההפעלה שלהם לרשימה ציבורית (`/api/v9/applications/detectable`).
2. Decoy מוריד את הרשימה הזו ועבור המשחק שבחרתם מעתיק תוכנית דמה זעירה (כ-120 ק״ב, כתובה ב-Rust ומוטמעת בתוך Decoy) לתיקייה זמנית תוך שימוש בשם קובץ ההפעלה מתוך הרשימה, למשל `.../cod26-cod.exe`.
3. תוכנית הדמה אינה עושה דבר מלבד החזקת חלון ראשי יחיד, הממוקם הרחק מחוץ למסך כדי שלא תראו אותו לעולם. Discord מזהה רק תהליך שמחזיק בחלון, ומסיבה זו תהליך נטול חלונות לחלוטין זוכה להתעלמות.
4. בתוך כ-15 שניות בקירוב Discord מציג את המשחק כפעילות הנוכחית שלכם.
5. כאשר הטיימר מסתיים או שלוחצים על עצירה, Decoy מסיים את התהליך ומוחק את הקובץ. אובייקט עבודה של Windows‏ (job object) מוודא שתהליכי הדמה נסגרים יחד עם Decoy, גם במקרה של קריסה.

## התקנה

בחרו אחת מאפשרויות ההורדה בעמוד ה-[Releases](../../../../releases):

| הורדה | מיועד עבור |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **קובץ התקנה (Installer).** לכל משתמש, ללא צורך בהרשאות מנהל מערכת (Administrator), מוסיף קיצור לתפריט 'התחל' ומסיר התקנה. |
| `Decoy_x.y.z_x64-portable.zip` | **גרסה ניידת (Portable).** חלצו לכל מקום והפעילו את `decoy.exe`. כל הנתונים נשמרים בתיקיית `data` שלצידו, שום דבר אינו נכתב לפרופיל המשתמש שלכם. מחקו את התיקייה כדי להסיר אותו. |

אמתו את ההורדה באמצעות `SHA256SUMS.txt`‏ (`Get-FileHash <file>` ב-PowerShell).

‏Windows SmartScreen עשוי להציג אזהרה על מפתח לא מוכר מכיוון שהגרסאות אינן חתומות דיגיטלית; בחרו ב-*מידע נוסף ← הפעל בכל זאת* (*More info → Run anyway*) אם אתם בוטחים בגרסה שנבנתה.

דרישות: Windows 10 או 11 (גרסת 64 סיביות) עם סביבת ההרצה WebView2 (כבר כלולה ב-Windows 11 ובעדכונים אחרונים של Windows 10).

## שימוש

1. פתחו את **הספרייה (Library)** וחפשו משחק, או לחצו על `Ctrl` + `K` מכל מקום בתוכנה.
2. לחצו על משחק. בחלונית מימין בחרו את התהליך ולכמה דקות להחזיק אותו פעיל (משימות פעילות של Discord דורשות לרוב 15 דקות).
3. לחצו על **Start decoy** (הפעלת תהליך דמה). Discord יציג את המשחק לאחר מספר שניות.
4. עקבו אחריו תחת **פועל (Running)**, עצרו תהליך אחד או את כולם בכל עת, או פשוט השאירו את Decoy במגש המערכת.

משחקים שהרשומה שלהם ב-Discord אינה מכילה קובצי הפעלה מוסתרים כברירת מחדל (לא ניתן לזהות אותם). הפעילו את האפשרות *הצג משחקים ללא exe* (*Show games without exe*) כדי לצפות בהם; הרשימה מתרעננת מדי יום, כך שהם יהיו זמינים ברגע ש-Discord יוסיף תהליך עבורם.

### שורת הפקודה

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

מפעיל תהליך דמה באופן מיידי, לדוגמה `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## בנייה מקוד המקור

דרישות מוקדמות: [Node.js](https://nodejs.org) בגרסה 20 ואילך, ערכת הכלים היציבה של [Rust](https://rustup.rs) (יעד MSVC) יחד עם כלי הבנייה Visual Studio C++‎, וסביבת ההרצה WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

בדיקות שימושיות:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

הערות: קובץ ה-exe של ה-decoy מקומפל על ידי `src-tauri/build.rs` באמצעות `rustc` רגיל מתוך `src-tauri/stub/stub.rs` ולאחר מכן מוטמע בתוך היישום. כאשר ממשק המשתמש (frontend) רץ בדפדפן רגיל (`npm run dev`), נעשה שימוש בשרת מדמה קטן (`src/mock.ts`), דבר הנוח מאוד בעת עבודה על ממשק המשתמש.

## תרגומים

מחרוזות ממשק המשתמש נמצאות ב-[`src/locales`](../../src/locales), קובץ JSON אחד לכל שפה (`en.json`, `ru.json`, ...). הוספת שפה מסתכמת בהוספת קובץ בודד; ללא צורך בשינויי קוד. עיינו ב-[docs/TRANSLATING.md](../TRANSLATING.md) לקבלת פרטים על מבנה הקובץ, הנחיה מוכנה לשימוש עבור תרגום מכונה וסקריפט הבדיקה. תרגומים של קובץ README זה ממוקמים ב-`docs/i18n/README.<code>.md`.

## מבנה הפרויקט

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## פרטיות

- Decoy משתמש ברשת אך ורק כדי להוריד את רשימת הזיהוי הציבורית של Discord (בהפעלה הראשונה, ולאחר מכן לכל היותר פעם ביום או בעת לחיצה על רענון), ובנוסף לצורך הצגת סמלי משחקים ויצירות אמנות מ-CDN ציבורי של Discord.
- התוכנה אינה קוראת, אינה שומרת ואינה שולחת את אסימון ה-Discord‏ (token) שלכם או נתוני חשבון כלשהם, ואינה מתקשרת כלל עם תוכנת הלקוח של Discord.
- ההגדרות (מועדפים, שפה, משכי זמן) נשמרות מקומית באחסון ה-WebView של היישום; מטמון רשימת המשחקים וקובצי ה-decoy הזמניים שמורים ב-`%LOCALAPPDATA%\app.decoy.desktop`.
- ללא כלי ניתוח נתונים (analytics), ללא דיווחי קריסות, וללא חשבונות משתמש.

## מגבלות ידועות

- Discord עשוי לשנות את אופן פעולת הזיהוי בכל עת. אם תהליך דמה מפסיק להיות מזוהה, אנא פתחו דיווח (issue).
- פעילויות מסוימות דורשות יותר מאשר תהליך פועל בלבד (לדוגמה, שהייה בתוך חוויה ספציפית בפלטפורמת משחקים). Decoy מחקה את התהליך בלבד.
- רשומות ללא קובצי הפעלה ברשימה של Discord אינן ניתנות לזיהוי.
- תוכנות אבטחה מסמנות לעיתים קובצי הפעלה זעירים ללא חתימה דיגיטלית שאינם פעילים בזיכרון. קובץ ה-decoy הוא קוד פתוח ונבנה מ-`src-tauri/stub/stub.rs`; באפשרותכם לקמפל אותו בעצמכם.

## כתב ויתור

Decoy מסופק "כמות שהוא" (as is) למטרות אישיות, לימודיות ולבדיקה בלבד. חיקוי של משחק פועל עלול להפר את תנאי השימוש של Discord או של מפיצת המשחק, ועלול להוביל לנקיטת צעדים נגד חשבונכם. אתם בלבד נושאים באחריות על אופן השימוש בו. "Discord" וכל שמות המשחקים והסמלים המסחריים שייכים לבעליהם בהתאמה, ומשמשים כאן אך ורק לצורך זיהוי התוכנות שאליהן הם מתייחסים.
