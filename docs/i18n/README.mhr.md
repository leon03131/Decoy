# Decoy

**Discord модмаш кая манын шотлыже манын ыштыме изи заглушка-процесс-влак.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Шукертсе модмаш-влак да обложке дене Decoy библиотеке" />

Decoy модмашын ыштыше файлын лӱмжӧ дене эҥгекым ыштыдыме тӧздыран заглушка-процессым пашаште куча, сандене Discord-ын модмашым пален налме радамже тыйым тиде модмашым модат манын ончыкта. Тыланет чын модмашым шындаш але илышыш пурташ огеш кӱл, сандене дискыште нимогай кугу вер ок аҥыргалт.

Тудо **Discord пален налын кертме чыла модмашым** (25 000 наре возымашым) пала, вет тудо Discord-ын шке калык спискыжым лудеш да шкеак тудым кажне кечын уэмден шога.

> [!WARNING]
> Пашам ыштыше модмашым ончыктымаш Discord-ын Калык келшымаш («Terms of Service») правилжым пудыртышаш лийын кертеш, сандене Decoy дене **шке ӱшанет почеш** пайдалане.
> Тиде проект Discord Inc. компаний дене кылдалтын огыл, тудын дене пеҥгыдемдыме огыл да тудын полшымыж дене ыштыме огыл. [Шке семын яваплылык](#шке-семын-яваплылык) ончал.

## Тӱҥ ойыртем-влак

- **Discord пален налын кертме чыла вер.** Модмаш спискым Discord-ын калык серверже гыч вигак чумырат, верысе хранилищеште кодат да кажне кечын уэмдат. У модмаш-влак да у вереш пурталтше ыштыше файл-влак шке семынышт лектын толыт.
- **Писе кычалмаш.** Тӱжем дене модмаш кокла гыч модмашын лӱмжӧ але ыштыше файлже почеш вигак кычалмаш, плитке але изи список дене ончыктымаш, йӧратыме модмаш-влак да «Шукертсе» радамын улмыжо.
- **Ик темдалмаш дене.** Модмашым ойыро, ыштыше файлым ойыро (икмыняр гын), тудым мыняр минут кучышашым палемде да «Заглушкым тӱҥалаш» темдал. Жап шотлымо оҥго да шижтарымаш жап эртыме нерген увертарат.
- **Шеҥгелан нимат ок код.** Заглушка тудо пашам ыштыме жапыште гына ила: изи exe тӱҥалме годым ышталтеш да шогалтымек кораҥдалтеш. Программе гыч лектын кайымек чыла шогала, а вигак петырналтме деч вара кодшо файл-влак вес гана почын налме годым эрыкталтыт.
- **Шып паша.** Систем трейыште ила, заглушка-влаклан посна тӧздыр але задаче панельыште кнопке-влак уке улыт.
- **Почылтшо кусарымаш.** Интерфейс куштылго JSON-файл дене ышта, сандене у йылмым ешараш манын, ик файлым пурташ гына кӱлеш. Инглиз да руш йылме-влак пуртеныт.
- **Шылтыме шот.** Аккаунт уке, Discord токен ок кӱл, телеметрий уке. [Шылтыме шот](#шылтыме-шот) ончал.

## Кузе тиде ышта

1. Discord тыйын модмашым модметым компышто пашам ыштыше процесс-влакым терген да нунын ыштыше файлын лӱмыштым калык спискысе лӱм дене таҥастарен пала (`/api/v9/applications/detectable`).
2. Decoy тиде спискым возен налеш да тыйын ойыркалыме модмашетлан список гыч ыштыше файлын лӱмжӧ дене изи заглушка-программым (120 КБ наре, Rust йылме дене возымо да Decoy кӧргыш пӧртылтӧ) жаплан папкаш копируватла, мутлан `.../cod26-cod.exe`.
3. Тиде заглушка программыже экран деч ӧрдыжтӧ верланыше ик тӧздырым гына куча, сандене тый тудым от уж. Discord тӧздыран процесым гына пален налын кертеш, сандене тӧздырдымӧ процесс-влакым эскерыде кода.
4. 15 секунд наре гыч Discord тиде модмашым тыйын кызытсе пашает семын ончыкташ тӱҥалеш.
5. Таймер мучашталтмек але тый шогалтыме годым, Decoy процесым петыра да файлым кораҥда. Windows job object заглушка-влакын Decoy дене пырля пытымыштым терген шога, программе вучыдымын таркален гынат.

## Шындымаш

[Лукмо верси-влак вуйлэвеш гыч](../../../../releases) ойырен нал:

| Чоҥен налаш | Валли |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Шындыше программе (Installer).** Ик пайдаланышылан, администратор права ок кӱл, «Тӱҥалтыш» менюш пунктым да кораҥдыше программым ешара. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив (Portable).** Кирек-кушко вигак почын лук да `decoy.exe`-м тӱҥал. Чыла данный воктенысе `data` папкаште кодеш, профильыш нимат ок возалт. Кораҥдаш манын, тиде папкым шӱкалтыш пытарыза. |

Чоҥен налме файлын чынлыкшым `SHA256SUMS.txt` полшымыж дене тергыза (PowerShell-ыште: `Get-FileHash <file>`).

Windows SmartScreen палыдыме авторын улмыж нерген шижтарен кертеш, вет чумырымо программе-влакын цифран кидпалышт уке; сборкылан ӱшанет гын, *More info → Run anyway* (але *Подробнее → Выполнить в любом случае*) ойыро.

Кӱлешлык-влак: Windows 10 але 11 (64-бит) WebView2 runtime йӧн дене (Windows 11-ште да Windows 10-ын уэмдымашыштыже кызытат уло).

## Пайдаланымаш

1. **Библиотекым** поч да модмашым кычал, але кузе гынат `Ctrl` + `K` темдал.
2. Модмашыш темдал. Пурла велне панельыште процесым да мыняр минут кучышашым ойыро (Discord квестыште чӱчкыдын 15 минут кӱлеш).
3. **Заглушкым тӱҥалаш** темдал. Discord икмыняр секунд гыч модмашым ончыкташ тӱҥалеш.
4. Тудым **Тӱҥалтыме** ужашыште эскере, иктыжым але чыла шогалтен кертат, але Decoy-м трейыште кодо.

Discord спискыште exe файлже але уке модмаш-влак ончыкталт шогымо годым шылын толыт (нуным пален налаш ок лий). Нуным ужаш манын, *Exe деч посна модмашым ончыкташ* чӱктӧ; список кажне кечын уэмдалтеш, сандене Discord процесым ешарымеке, нуно вигак ямде лийыт.

### Команде корно

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Заглушкым вигак илышыш пурта, мутлан `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Изиж гыч чумырымаш

Кӱлешлык-влак: [Node.js](https://nodejs.org) 20+, келшыше [Rust](https://rustup.rs) ӱзгар-влак (MSVC target) Visual Studio C++ build tools дене, да WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload дене вияҥдыме режимште тӱҥалаш
npm run tauri build    # src-tauri/target/release/bundle/nsis верыште инсталляторым чумыраш
```

Пайдале тергымаш-влак:

```bash
npm run check-locales  # кажне кусарыме файлым ru.json дене таҥастарен тергымаш
npx tsc --noEmit       # фронтендын типжым тергымаш
cargo check --manifest-path src-tauri/Cargo.toml
```

Палемдымаш: заглушка exe `src-tauri/build.rs` скрипт дене ятыр куштылго `rustc` полшымо почеш `src-tauri/stub/stub.rs` гыч чумыралтеш да вара программе кӧргыш шындалтеш. Фронтенд браузерыште ыштыме годым (`npm run dev`) изи мок-бэкенд (`src/mock.ts`) кучылталтеш, тиде интерфейс дене ышташ питӓ йӧнан.

## Кусарымаш-влак

Интерфейс радамын мутшо-влак [`src/locales`](../../src/locales) папкаште верланат, кажне йылмылан ик JSON файл (`en.json`, `ru.json`, ...).
У йылмым ешараш манын, кодым вашталтыде ик у файлым пурташ гына кӱлеш. Файлын форматым, автоматик кусарымашлан ямде промптым да тергыме скриптым [docs/TRANSLATING.md](../TRANSLATING.md) гыч ончал. Тиде README-н кусарымыже-влак `docs/i18n/README.<code>.md` верыш пурат.

## Проект тудын чоҥалтмыже

```
src/                    React + TypeScript фронтенд
  components/           Библиотеке, пырдыж панель, келыштарымаш, ...
  locales/              кусарыме файл-влак (кажне йылмылан ик JSON)
  i18n-core.ts          йылмым вераҥдымаш да кычалмаш
  store.ts              программын состоянийже (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            модмаш базе, заглушка процесс-влак, трей
  stub/stub.rs          кӧргыш шындалтше заглушка программе
scripts/                полшышо скрипт-влак (локаль тергымаш)
docs/                   кусарыме йӧн нерген увер, скриншот-влак
```

## Шылтыме шот

- Decoy вот дене Discord-ын калык пален налме спискыжым возен налаш гына пайдалана (икымше тӱҥалме годым, вараже кечылан ик гана деч шукырак огыл але уэмдымек) да экранлан Discord-ын калык CDN-же гыч модмаш тамга ден обложкым налаш гына кучылталтеш.
- Тудо тыйын Discord токенет але аккаунт нерген данныйым ок луд, ок арале да нигушкат ок колто, тыгак Discord клиент дене ок кутыро.
- Келыштарымаш (йӧратыме модмаш-влак, йылме, жап кучымаш) верысе программын WebView хранилищыштыже аралалтеш; модмаш спискын кэшже да жаплан Decoy файл-влак `%LOCALAPPDATA%\app.decoy.desktop` папкаште верланат.
- Нимогай аналитике, сбой нерген увертарымаш, аккаунт уке.

## Палыме ситыдымаш-влак

- Discord модмашым пален налме радамжым кирек-могай жапыште вашталтен кертеш. Заглушка палдырнаш чарнен гын, issue-м почыса.
- Икмыняр модмаш пашалан пашам ыштыше процесс гына ок сите (мутлан, платформа кӧргысӧ посна режимште лийман). Decoy процессым гына ончыкта.
- Discord спискыште ыштыше файлже уке возымаш-влакым пален налаш ок лий.
- Шылтыме программым аралыше антивирус-влак южгунам шарнымаште шогышо изи цифровой кидпалыдыме файлым шижын кертыт. Заглушка программе почылтшо код дене возымо да тудо `src-tauri/stub/stub.rs` гыч чоҥалтеш; тый тудым шкеат чумырен кертат.

## Проектыш ушнымаш

Йоҥылыш нерген увер-влак, шонымаш да кусарымаш-влак кумылын вашталтыт. Эн ондак [CONTRIBUTING.md](../../CONTRIBUTING.md) материалым лудын лекса.

## Шке семын яваплылык

Decoy тиде шкешотан, тунемме да тергыме амал дене «кузе уло» семын пуалтеш. Ыштыше модмашым ончыктымаш Discord але модмашым савыкшын Калык келшымаш правилжым пудыртышаш лийын кертеш, да тыйын аккаунтетлан нелылыкым ыштен кертеш. Тудын дене кузе пайдаланымылан тый шкеак явап улат. «Discord» да чыла модмаш лӱм-влак ден логотип-влак шке озажын сату палышт улыт да тыште палемдалтын кертше программым умылтараш гына кучылталтыт.
