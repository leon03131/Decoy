# Decoy

**Minuscoli procesci de rimpiasso che fan credde a Discord che un zeugo o segge in ezecuçion.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibbiutêca de Decoy con zeughi recenti e inmàgini" />

</div>

Decoy o mantegne in ezecuçion un innoqente procèsso de rimpiasso con un barcon sotta o nómme de l'esegoìbile de 'n zeugo, de mòddo che a rilevaçion di zeughi de Discord a te mòstre cómme se ti fìsci aprêuvo a zeugâ a quello zeugo. No gh'é mâi de bezéugno d'instalâ ò aviâ o zeugo reâ, coscì ninte de pézante o rèsta in sciô teu disco.

O conòsce **tùtti i zeughi che Discord o pêu rilevâ** (ciù ò mêno 25.000 vôxi) perché o lêze a lìsta pùbblica de rilevamento de Discord e o a mantegne agiornâ da lê.

> [!WARNING]
> Simulâ un zeugo in ezecuçion o pêu anâ cóntra i Tèrmini de Serviçio de Discord e ti adêuvi Decoy **a teu réizego e perìcolo**.
> Sto progètto o no l'é afiçiòu, aprovòu ò colegòu a Discord Inc. Vanni a védde [Escluxon de responsabilitæ](#escluxon-de-responsabilitæ).

## Caraterìstiche

- **Tùtto quello che Discord o pêu rilevâ.** A lìsta di zeughi a vêgne scaregâ da l'endpoint pùbrico de rilevamento de Discord, sarvâ inta cache locâle e agiornâ ògni giórno. I nêuvi zeughi e i esegoìbili azónti de frésco conparìscian da lô.
- **Riçèrca ch'a têgne o passo.** Riçèrca istantànea pe nómme do zeugo ò pe esegoìbile tra migiæa de zeughi, vìsta a ciælle ò a lìsta conpàtta, preferîi e 'na rîa di “Recenti”.
- **Con un clic.** Çèrni un zeugo, çèrni l'esegoìbile (se ghe n'é ciù d'un), çèrni quànto ténpo mantegnîlo e sgnàcca avia. Un anello con o conto a-a revèrsa e 'na notìfica te dìxan quànde o ténpo o l'é finîo.
- **O no làscia ninte derê.** Un decoy o l'exìste sôlo méntre o gîra: o piccin exe o vêgne creòu a l'avio e scassòu a-o stop. Tùtto o vêgne fermòu quànde ti sciòrti, e i rèsti de 'n blòcco acidentâle vêgnan netezæ a l'avio sucescîvo.
- **Discrêto.** O vìve inta vaschétta de scistêma (tray), sénsa barcoin ò pomélli inta sbarra de l'aplicaçion pe-i decoy mæximi.
- **Traduçioin avèrte.** L'interfàccia a l'é goidâ da sénplici file JSON, coscì azónze 'na léngoa o veu dî azónze un sôlo file. L'ingléize e o rùscio són inclûxi.
- **Privadèssa.** Nisciùn account, nisciùn token de Discord, nisciùnna telemetrîa. Vanni a védde [Privadèssa](#privadèssa).

## Cómme o fonçionna

1. Discord o decìdde che ti stæ zeugando a 'n zeugo amiando i procesci in ezecuçion in sciô teu PC e confrontando i nómmi di esegoìbili con 'na lìsta pùbblica (`/api/v9/applications/detectable`).
2. Decoy o scarega quella lìsta e, pe-o zeugo che ti çèrni, o còpia un minuscolo progràmma de rimpiasso (ciù ò mêno 120 KB, scrîto in Rust e incorporòu in Decoy) inte 'na cartélla temporània deuviando o nómme de l'esegoìbile da-a lìsta, prezénpio `.../cod26-cod.exe`.
3. O progràmma de rimpiasso o no fa ninte âtro che avéi un barcon de prìmmo livèllo, parchezòu bén fêua da-o schermo pe no fâtelo védde mâi. Discord o riconòsce un procèsso sôlo se o gh'à un barcon, e l'é pe quello che un procèsso del tùtto privo de barcoin o vêgne ignoròu.
4. Inti giâi de 15 segóndi Discord o mòstra o zeugo cómme a teu ativitæ corènte.
5. Quànde o timer o finìsce ò ti sgnàcchi fèrma, Decoy o terìna o procèsso e o scassa o file. Un ògètto job de Windows o garantìsce che i decoy mêuan insemme a Decoy, ànche se gh'é un crascio.

## Instalaçion

Çèrnine un da-a pàgina de [Releases](../../../../releases):

| Scaregamento | Pe |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalatô.** Pe scìngolo utente, nisciùn privilêgio d'aministratô necesâio, o l'azonze 'na vôxe a-o menù Start e un disinstalatô. |
| `Decoy_x.y.z_x64-portable.zip` | **Portàtile.** Descarvugna da quæ se segge pàrte e avia `decoy.exe`. Tùtti i dæti rèstan inta cartélla `data` de fiànco, ninte vêgne scrîto into teu profîlo utente. Scassa a cartélla pe scassâlo. |

Verìfica un file scaregòu con `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen o pêu mostrâ un avîzo in sciô publicatô no conosciûo perché e build no són firmæ digitalménte; çèrni *Ciù informaçioin → Esegui comonque* se ti te fîdi da build.

Requixîi: Windows 10 ò 11 (a 64 bit) con o runtime WebView2 (za inclûzo in Windows 11 e inti agiornamenti recenti de Windows 10).

## Utilizzo

1. Àrvi **Bibbiutêca** e çèrca un zeugo, opûre sgnàcca `Ctrl` + `K` da quæ se segge pòsto.
2. Fæ clic in sciô zeugo. Into panèllo a drîta çèrni o procèsso e quànti menûti mantegnîlo (de sòlito e ativitæ de Discord domàndan 15 min).
3. Sgnàcca **Avia decoy**. Discord o mostriâ o zeugo dòppo quàrche segóndo.
4. Controllalo sotta **In ezecuçion**, fèrmane un ò tùtti in ciaschedùn moménto, opûre làscia sénpliçeménte Decoy inta vaschétta.

I zeughi a chi vôxe de Discord a no gh'à ancón di esegoìbili són ascôxi pe inpostaçion predefinîa (no pêuan êse rilevæ). Atîva *Móstra i zeughi sensa exe* pe védtili; a lìsta a l'é agiornâ ògni giórno, coscì che divegnan disponìbili a man a man che Discord o l'azonze un procèsso.

### Rîa de comandi

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

O l'avia un decoy a-o vêuo, prezénpio `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Conpilaçion da-o sorgénte

Prerequixîi: [Node.js](https://nodejs.org) 20+, a toolchain stàbile de [Rust](https://rustup.rs) (target MSVC) con i Visual Studio C++ Build Tools e o runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Contròlli ùtili:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Nòtte: l'exe do decoy o l'é conpilòu da `src-tauri/build.rs` co-o senpliçe `rustc` a partî da `src-tauri/stub/stub.rs` e pöi incorporòu inte l'app. Quànde o frontend o gîra inte un comùn navegatô (`npm run dev`), vêgne adêuviòu un piccin backend fìsio (`src/mock.ts`), ùtile pe travagiâ in sciâ UI.

## Traduçioin

E stringhe de l'interfàccia stàn in [`src/locales`](../../src/locales), un file JSON pe ciaschedùnn-a léngoa (`en.json`, `ru.json`, ...). Azónze 'na léngoa veu dî azónze un file; nisciùnn-a modìfica a-o còdice. Vanni a védde [docs/TRANSLATING.md](../TRANSLATING.md) pe-o formâto do file, un prompt prònto pe l'ûzo pe-a traduçion aotomàtica e o script de conproua. E traduçioin de sto README vàn mìsse in `docs/i18n/README.<code>.md`.

## Strutûa do progètto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privadèssa

- Decoy o dêuvia a ræ sôlo pe scaregâ a lìsta pùbblica de rilevamento de Discord (a-o prìmmo avio, pöi a-o màscimo 'na vòtta a-o giórno ò quànde ti sgnàcchi agiorna) e, pe móstrâli, e icònne e inmàgini di zeughi da-a CDN pùbblica de Discord.
- O no lêze, sarva ò invia o teu token de Discord ò di dæti de l'account, e o no pàrla co-o client de Discord.
- E inpostaçioin (preferîi, léngoa, dueræ) són sarvæ locâlménte into depòxito WebView de l'app; a cache da lìsta di zeughi e i file temporàni di decoy stàn in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nisciùnn-a anàlixi, nisciùnn-a segnalaçion de blòcchi, nisciùn account.

## Limitaçioin conosciûe

- Discord o pêu cangiâ cómme fonçionna o rilevamento in ciaschedùn moménto. Se un decoy o smette d'êse riconosciûo, pe cortexîa àrvi un'issue.
- Çèrte ativitæ gh'àn de bezéugno de ciù che de 'n sénpliçe procèsso in ezecuçion (prezénpio êse drento a 'na particolâ esperiénsa inte 'na piatafórma de zeugo). Decoy o l'imita sôlo o procèsso.
- E vôxi sénsa esegoìbili inta lìsta de Discord no pêuan êse rilevæ.
- I software de seguéssa quàrche vòtta bàllan con piccin esegoìbili sénsa fìrma ch'aspèttan in memöia. O decoy o l'é open source e costroîo a partî da `src-tauri/stub/stub.rs`; ti pêu conpilâlo ti mæximo.
