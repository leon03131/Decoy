# Decoy

**Discord-un bir oyunun işlədiyini düşünməsini təmin edən kiçik yer tutucu proseslər.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Son oyunlar və üz qabıqları ilə Decoy kitabxanası" />

</div>

Decoy bir oyunun icra olunan faylının adı altında pəncərəsi olan zərərsiz yer tutucu prosesi işlək vəziyyətdə saxlayır, beləliklə Discord-un oyun aşkarlama funksiyası həmin oyunu oynadığınızı bildirir. Əsl oyunu heç vaxt quraşdırmaq və ya başlatmaq lazım deyil, buna görə də diskinizdə böyük həcmli heç nə qalmır.

Discord-un özünün ictimai aşkarlama siyahısını oxuduğu və onu özü yenilədiyi üçün **Discord-un aşkarlaya biləcəyi hər oyunu** (təxminən 25.000 qeyd) tanıyır.

> [!WARNING]
> İşləyən bir oyunu saxtalaşdırmaq Discord-un Xidmət Şərtlərinə zidd ola bilər və Decoy-dan istifadənin **məsuliyyəti tamamilə sizin üzərinizdədir**.
> Bu layihə Discord Inc. ilə əlaqəli deyil, onun tərəfindən təsdiqlənməyib və ya dəstəklənmir. Bax: [İmtina](#imtina).

## Xüsusiyyətlər

- **Discord-un aşkarlaya biləcəyi hər şey.** Oyun siyahısı Discord-un ictimai aşkarlama son nöqtəsindən (endpoint) endirilir, yerli olaraq keşlənir və hər gün yenilənir. Yeni oyunlar və yeni əlavə edilmiş icra olunan fayllar avtomatik olaraq görünür.
- **Sürətli axtarış.** Minlərlə oyun arasında oyun adına və ya icra olunan fayla görə anında axtarış, tor və ya yığcam siyahı görünüşü, seçilmişlər və "Sonuncular" sətri.
- **Tək klik.** Oyunu seçin, (birdən çoxdursa) icra olunan faylı seçin, nə qədər saxlanılacağını təyin edin və başlat düyməsinə klikləyin. Geri sayım halqası və bildiriş vaxtın bitdiyini sizə xəbər verir.
- **Heç bir iz qoymur.** Decoy yalnız işlədiyi müddətcə mövcud olur: kiçik exe başladıldıqda yaradılır və dayandırıldıqda silinir. Proqramdan çıxdığınız zaman hər şey dayandırılır və qəza nəticəsində qalan qalıqlar növbəti açılışda təmizlənir.
- **Səssiz.** Sistem tepsisində (system tray) işləyir, decoy-ların özü üçün heç bir pəncərə və ya tapşırıq paneli düyməsi olmur.
- **Açıq tərcümələr.** İnterfeys sadə JSON faylları ilə idarə olunur, buna görə də yeni dil əlavə etmək sadəcə bir fayldan ibarətdir. İngilis və rus dilləri daxildir.
- **Məxfi.** Hesab yoxdur, Discord tokeni yoxdur, telemetriya yoxdur. Bax: [Məxfilik](#məxfilik).

## Necə işləyir

1. Discord kompüterinizdə işləyən proseslərə baxaraq və onların icra olunan fayl adlarını ictimai siyahı (`/api/v9/applications/detectable`) ilə müqayisə edərək oyun oynadığınıza qərar verir.
2. Decoy bu siyahını endirir və seçdiyiniz oyun üçün siyahıdakı icra olunan fayl adından istifadə edərək kiçik bir yer tutucu proqramı (təxminən 120 KB, Rust ilə yazılmış və Decoy daxilinə daxil edilmişdir) müvəqqəti qovluğa kopyalayır (məsələn, `.../cod26-cod.exe`).
3. Yer tutucu, heç vaxt görməyəcəyiniz şəkildə ekrandan kənarda yerləşdirilmiş tək bir yuxarı səviyyəli pəncərəyə sahib olmaqdan başqa heç nə etmir. Discord yalnız pəncərəsi olan prosesləri tanıyır, tamamilə pəncərəsiz prosesin nəzərə alınmamasının səbəbi də budur.
4. Təxminən 15 saniyə ərzində Discord oyunu cari fəaliyyətiniz kimi göstərir.
5. Taymer başa çatdıqda və ya dayandır düyməsini basdıqda, Decoy prosesi sonlandırır və faylı silir. Windows tapşırıq obyekti (job object) Decoy qəzaya uğrasa belə, decoy-ların da Decoy ilə birlikdə bağlanmasını təmin edir.

## Quraşdırma

[Releases](../../../../releases) səhifəsindən birini seçin:

| Yükləmə | Təyinatı |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Quraşdırıcı.** İstifadəçi üçündür, administrator hüquqları tələb olunmur, Başlat menyusuna qeyd və silmə proqramı (uninstaller) əlavə edir. |
| `Decoy_x.y.z_x64-portable.zip` | **Portativ.** İstədiyiniz yerə çıxarın və `decoy.exe` faylını işə salın. Bütün məlumatlar onun yanındakı `data` qovluğunda saxlanılır, istifadəçi profilinizə heç nə yazılmır. Silmək üçün qovluğu silmək kifayətdir. |

Yüklənmiş faylı `SHA256SUMS.txt` ilə yoxlayın (PowerShell-də `Get-FileHash <fayl>`).

Quruluşlar kod imzalı olmadığı üçün Windows SmartScreen tanınmayan naşir haqqında xəbərdarlıq edə bilər; əgər quruluşa etibar edirsinizsə, *Əlavə məlumat → Yenə də icra et* (More info → Run anyway) seçin.

Tələblər: WebView2 işləmə mühitinə malik Windows 10 və ya 11 (64-bit) (Windows 11-ə və son Windows 10 yeniləmələrinə artıq daxildir).

## İstifadə qaydası

1. **Kitabxana** bölməsini açın və oyun axtarın, yaxud istənilən yerdən `Ctrl` + `K` sıxın.
2. Oyuna klikləyin. Sağ tərəfdəki paneldə prosesi və onun neçə dəqiqə saxlanılacağını seçin (Discord fəaliyyətləri adətən 15 dəqiqə tələb edir).
3. **Decoy başlat** düyməsinə klikləyin. Bir neçə saniyədən sonra Discord oyunu göstərəcək.
4. **İşləyənlər** bölməsindən izləyin, istənilən vaxt birini və ya hamısını dayandırın, yaxud Decoy-u sadəcə sistem tepsisində saxlayın.

Discord qeydində hələlik icra olunan faylı olmayan oyunlar standart olaraq gizlədilir (onlar aşkarlana bilməz). Onları görmək üçün *exe-si olmayan oyunları göstər* seçimini aktivləşdirin; siyahı hər gün yenilənir, buna görə də Discord proses əlavə edən kimi onlar əlçatan olacaq.

### Əmr sətri

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy-u dərhal başladır, məsələn: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Mənbə kodundan qurma

İlkin şərtlər: [Node.js](https://nodejs.org) 20+, Visual Studio C++ qurma alətlərinə malik sabit [Rust](https://rustup.rs) alətlər dəsti (MSVC hədəfi) və WebView2 işləmə mühiti.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Faydalı yoxlamalar:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Qeydlər: decoy exe faylı `src-tauri/build.rs` tərəfindən birbaşa `rustc` ilə `src-tauri/stub/stub.rs` faylından tərtib edilir və sonra tətbiqə daxil edilir. Ön tərəf adi brauzerdə işlədildikdə (`npm run dev`), istifadəçi interfeysi üzərində işləmək üçün əlverişli olan kiçik bir sınaq arxa planı (`src/mock.ts`) istifadə olunur.

## Tərcümələr

İnterfeys mətnləri [`src/locales`](../../src/locales) qovluğundadır, hər dil üçün bir JSON faylı (`en.json`, `ru.json`, ...). Dil əlavə etmək sadəcə fayl əlavə etmək deməkdir; heç bir kod dəyişikliyi tələb olunmur. Fayl formatı, maşın tərcüməsi üçün hazır sorğu və yoxlama skripti üçün [docs/TRANSLATING.md](../TRANSLATING.md) faylına baxın. Bu README faylının tərcümələri `docs/i18n/README.<code>.md` ünvanına gedir.

## Layihə strukturu

```
src/                    React + TypeScript ön tərəfi
  components/           Kitabxana, detallar paneli, tənzimləmələr, ...
  locales/              tərcümə faylları (hər dil üçün bir JSON)
  i18n-core.ts          dilin yüklənməsi və axtarışı
  store.ts              tətbiq vəziyyəti (zustand)
src-tauri/              Rust arxa tərəfi (Tauri 2)
  src/lib.rs            oyun məlumat bazası, decoy prosesləri, trey
  stub/stub.rs          daxil edilən yer tutucu proqram
scripts/                köməkçi skriptlər (lokal yoxlanışı)
docs/                   tərcümə bələdçisi, ekran görüntüləri
```

## Məxfilik

- Decoy şəbəkədən yalnız Discord-un ictimai aşkarlama siyahısını endirmək üçün (ilk açılışda, daha sonra gündə ən çoxu bir dəfə və ya yenilə düyməsini basdıqda) və vizual nümayiş üçün Discord-un ictimai CDN-indən oyun nişanları və rəsmlərini gətirmək üçün istifadə edir.
- Discord tokeninizi və ya hər hansı hesab məlumatınızı oxumur, saxlamır və göndərmir, həmçinin Discord müştərisi ilə əlaqə saxlamır.
- Tənzimləmələr (seçilmişlər, dil, müddətlər) tətbiqin WebView yaddaşında yerli olaraq saxlanılır; oyun siyahısı keşi və müvəqqəti decoy faylları `%LOCALAPPDATA%\app.decoy.desktop` qovluğunda yerləşir.
- Analitika yoxdur, qəza hesabatı yoxdur, hesablar yoxdur.

## Məlum məhdudiyyətlər

- Discord aşkarlama mexanizmini istənilən vaxt dəyişə bilər. Əgər bir decoy tanınmamağa başlasa, lütfən məsələ (issue) açın.
- Bəzi fəaliyyətlər sadəcə işləyən prosesdən daha çoxunu tələb edir (məsələn, bir oyun platformasının müəyyən bir təcrübəsi daxilində olmaq). Decoy yalnız prosesi təqlid edir.
- Discord siyahısında icra olunan faylları olmayan qeydlər aşkarlana bilməz.
- Təhlükəsizlik proqramları bəzən yaddaşda hərəkətsiz qalan kiçik imzasız icra olunan faylları şübhəli hesab edə bilər. Decoy açıq mənbəlidir və `src-tauri/stub/stub.rs` faylından qurulub; onu özünüz də tərtib edə bilərsiniz.

## İmtina

Decoy şəxsi, tədris və sınaq məqsədləri üçün "olduğu kimi" təqdim olunur. İşləyən bir oyunu təqlid etmək Discord-un və ya oyun naşirinin Xidmət Şərtlərini poza bilər və hesabınıza qarşı tədbir görülməsinə səbəb ola bilər. Ondan necə istifadə edəcəyinizə yalnız siz cavabdehsiniz. "Discord" və bütün oyun adları və loqoları müvafiq sahiblərinin ticarət nişanlarıdır və burada yalnız aid olduqları proqram təminatını tanımaq üçün istifadə olunur.
