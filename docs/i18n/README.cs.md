# Decoy

**Drobné zástupné procesy, díky kterým si Discord myslí, že běží hra.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Knihovna Decoy s nedávnými hrami a obrázky" />

</div>

Decoy udržuje v chodu neškodný zástupný proces s oknem pod názvem spustitelného souboru hry, takže detekce her v Discordu hlásí, že danou hru hrajete. Skutečnou hru nemusíte nikdy instalovat ani spouštět, takže na vašem disku nezabírá žádné místo.

Ví o **každé hře, kterou Discord dokáže detekovat** (zhruba 25 000 položek), protože čte vlastní veřejný detekční seznam Discordu a sám jej udržuje aktuální.

> [!WARNING]
> Předstírání běžící hry může být v rozporu se smluvními podmínkami Discordu a Decoy používáte **na vlastní nebezpečí**.
> Tento projekt není spojen se společností Discord Inc., není jí podporován ani schválen. Viz [Vyloučení odpovědnosti](#vyloučení-odpovědnosti).

## Funkce

- **Vše, co Discord dokáže detekovat.** Seznam her se stahuje z veřejného koncového bodu Discordu pro detekci, ukládá se do místní mezipaměti a denně se obnovuje. Nové hry a nově přidané spustitelné soubory se objevují automaticky.
- **Vyhledávání, které drží krok.** Okamžité vyhledávání podle názvu hry nebo spustitelného souboru mezi tisíci her, zobrazení v mřížce nebo kompaktním seznamu, oblíbené položky a řádek „Nedávné“.
- **Jedno kliknutí.** Vyberte hru, zvolte spustitelný soubor (pokud je jich více), zvolte, jak dlouho má běžet, a stiskněte spustit. Odpočítávací kruh a oznámení vás upozorní, až čas vyprší.
- **Nezanechává po sobě nic.** Návnada existuje pouze po dobu svého běhu: drobný exe soubor se vytvoří při spuštění a smaže při zastavení. Vše se ukončí při zavření aplikace a případné zbytky po pádu se uklidí při dalším spuštění.
- **Nenápadný.** Běží v oznamovací oblasti (system tray), žádná okna ani tlačítka na hlavním panelu pro samotné procesy návnady.
- **Otevřené překlady.** Rozhraní je řízeno čistými JSON soubory, takže přidání jazyka znamená přidání jediného souboru. Angličtina a ruština jsou součástí.
- **Soukromý.** Žádný účet, žádný token Discordu, žádná telemetrie. Viz [Soukromí](#soukromí).

## Jak to funguje

1. Discord zjišťuje, že hrajete hru, kontrolou procesů běžících na vašem PC a porovnáváním názvů jejich spustitelných souborů s veřejným seznamem (`/api/v9/applications/detectable`).
2. Decoy tento seznam stáhne a pro vybranou hru zkopíruje drobný zástupný program (zhruba 120 KB, napsaný v Rustu a integrovaný v aplikaci Decoy) do dočasné složky pod názvem spustitelného souboru ze seznamu, například `.../cod26-cod.exe`.
3. Tento zástupný program nedělá nic kromě udržování jednoho okna nejvyšší úrovně umístěného daleko mimo obrazovku, takže jej nikdy neuvidíte. Discord rozpoznává pouze procesy, které vlastní okno – proces zcela bez oken ignoruje.
4. Během přibližně 15 sekund Discord zobrazí hru jako vaši aktuální aktivitu.
5. Když časovač vyprší nebo stisknete zastavit, Decoy proces ukončí a soubor smaže. Objekt úlohy systému Windows (job object) zajišťuje, že se návnady ukončí společně s Decoy, i kdyby aplikace neočekávaně spadla.

## Instalace

Vyberte si na stránce [Releases](../../../../releases):

| Ke stažení | Určení |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalátor.** Pro jednoho uživatele, bez nutnosti administrátorských práv, přidá položku do nabídky Start a odinstalátor. |
| `Decoy_x.y.z_x64-portable.zip` | **Přenosná verze (Portable).** Rozbalte kamkoli a spusťte `decoy.exe`. Všechna data zůstávají ve složce `data` vedle něj, do vašeho uživatelského profilu se nic nezapisuje. Chcete-li ji odstranit, stačí složku smazat. |

Stažený soubor ověřte pomocí `SHA256SUMS.txt` (`Get-FileHash <file>` v PowerShellu).

Windows SmartScreen může varovat před nerozpoznaným vydavatelem, protože sestavení nejsou digitálně podepsána. Pokud sestavení důvěřujete, zvolte *Další informace → Přesto spustit*.

Požadavky: Windows 10 nebo 11 (64bitové) s modulem runtime WebView2 (již součástí Windows 11 a nedávných aktualizací systému Windows 10).

## Použití

1. Otevřete **Knihovnu** a vyhledejte hru, nebo odkudkoli stiskněte `Ctrl` + `K`.
2. Klikněte na hru. V panelu vpravo vyberte proces a počet minut, po které má běžet (aktivity v Discordu obvykle vyžadují 15).
3. Stiskněte **Spustit návnadu**. Discord hru zobrazí po několika sekundách.
4. Sledujte proces v sekci **Běžící**, kdykoli můžete jeden nebo všechny zastavit, nebo nechte Decoy běžet v oznamovací oblasti.

Hry, jejichž záznam v Discordu zatím nemá žádné spustitelné soubory, jsou ve výchozím nastavení skryté (nelze je detekovat). Chcete-li je zobrazit, zapněte volbu *Zobrazit hry bez exe*; seznam se denně obnovuje, takže budou k dispozici, jakmile Discord příslušný proces přidá.

### Příkazový řádek

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Spustí návnadu okamžitě, například `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Sestavení ze zdrojového kódu

Požadavky: [Node.js](https://nodejs.org) 20+, stabilní toolchain [Rust](https://rustup.rs) (cíl MSVC) s nástroji pro sestavení Visual Studio C++ a runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Užitečné kontroly:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Poznámky: Spustitelný soubor pro decoy je kompilován pomocí `src-tauri/build.rs` běžným `rustc` ze souboru `src-tauri/stub/stub.rs` a poté vložen do aplikace. Když frontend běží v běžném prohlížeči (`npm run dev`), používá se malý napodobený backend (`src/mock.ts`), což je praktické pro práci na uživatelském rozhraní.

## Překlady

Texty uživatelského rozhraní se nacházejí v [`src/locales`](../../src/locales), jeden JSON soubor pro každý jazyk (`en.json`, `ru.json`, ...). Přidání jazyka znamená přidání souboru; nejsou potřeba žádné změny v kódu. Formát souboru, připravené zadání pro strojový překlad a ověřovací skript naleznete v [docs/TRANSLATING.md](../TRANSLATING.md). Překlady tohoto souboru README patří do `docs/i18n/README.<code>.md`.

## Struktura projektu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Soukromí

- Decoy využívá síť pouze ke stažení veřejného seznamu detekce Discordu (při prvním spuštění a poté maximálně jednou denně nebo po kliknutí na obnovení) a pro zobrazení ikon a obrázků her z veřejné CDN sítě Discordu.
- Nečte, neukládá ani neodesílá váš Discord token ani žádná data účtu a nekomunikuje s klientem Discordu.
- Nastavení (oblíbené položky, jazyk, doby trvání) se ukládají lokálně v úložišti WebView aplikace; mezipaměť seznamu her a dočasné soubory návnad se nacházejí v `%LOCALAPPDATA%\app.decoy.desktop`.
- Žádná analytika, žádná hlášení o chybách, žádné uživatelské účty.

## Známá omezení

- Discord může způsob detekce kdykoli změnit. Pokud přestane být decoy rozpoznáván, otevřete prosím hlášení o problému (issue).
- Některé aktivity vyžadují více než jen běžící proces (například přítomnost v konkrétním režimu či hře v rámci herní platformy). Decoy napodobuje pouze proces.
- Záznamy bez spustitelných souborů v seznamu Discordu nelze detekovat.
- Bezpečnostní software může občas označit malé nepodepsané spustitelné soubory, které nečinně běží v paměti. Decoy je open source a je sestaven ze souboru `src-tauri/stub/stub.rs`; můžete si jej zkompilovat sami.

## Vyloučení odpovědnosti

Decoy je poskytován „tak, jak je“, pro osobní, vzdělávací a testovací účely. Předstírání spuštěné hry může porušovat smluvní podmínky služby Discord nebo vydavatele hry a může vést k opatřením proti vašemu účtu. Za způsob použití nesete výhradní odpovědnost vy sami. „Discord“ a všechny názvy a loga her jsou ochrannými známkami příslušných vlastníků a jsou zde použity pouze k identifikaci softwaru, na který odkazují.
