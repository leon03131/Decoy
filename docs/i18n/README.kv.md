# Decoy

**Ичӧтик заглушка-процессъяс, кодъяс отсӧгӧн Discord чайтӧ, мый ворсӧм заводитӧма.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека важвылӧм ворсӧмъясӧн да обложкаясӧн" />

Decoy видзӧ лӧсьӧдӧм безопаснӧй ӧшиня заглушка-процесс ворсӧмлӧн файл ним улын, сы вӧсна Discord-лӧн ворсӧм тӧдмалан система мыччӧ, мый ті ворсаныд тайӧ ворсӧмсӧ. Сійӧ збыль ворсӧмсӧ пуктыны либӧ заводитны оз ков, сідзкӧ диск вылын нинӧм лишньӧй оз куйлӧ.

Сійӧ тӧдӧ **быд ворсӧм, кодӧс вермас тӧдмавны Discord** (гӧгӧр 25 000 гижӧд), сы понда мый лыддьӧ Discord-лысь ассьыс публичнӧй список да асшӧрӧн сійӧс выльмӧдӧ.

> [!WARNING]
> Заводитӧм ворсӧмсӧ имитируйтӧм вермас торкны Discord-лысь удж условиеяссӧ, Decoy-ӧн вӧдитчанныд **ас курччӧм серти**.
> Тайӧ проект абу йитчӧма Discord Inc. котыркӧд, абу сыӧн кывкӧртӧма да отсасьӧма. Видзӧд [Кывкӧртӧмтӧг олан йылысь](#кывкӧртӧмтӧг-олан-йылысь).

## Тӧдчанаторъяс

- **Ставсӧ, мый вермас тӧдмавны Discord.** Ворсӧм список босьтсьӧ Discord-лӧн публичнӧй серверысь, видзисьӧ ас компьютер вылын да выльмӧдсьӧ быд лун. Выль ворсӧмъяс да выль содтӧм процессъяс тырмигас тыдовтчӧны асьныс.
- **Ӧдйӧ корсьӧм.** Пырся корсьӧм ворсӧм ним либӧ файл серти уна сюрс ворсӧм пӧвстысь, плиткаяс либӧ списокӧн мыччӧм, медся мусаяс да «Важвылӧм» визь.
- **Ӧти либӧмӧн.** Бӧрйӧй ворсӧм, бӧрйӧй процесс (кӧть найӧ кымын), пуктӧй, кымын минут кутны, да либӧй «Заводитны заглушка». Бӧрӧ лыддян гӧгрӧс да юӧр висьталасны, кор кад помасис.
- **Нинӧм оз коль.** Заглушка эм сӧмын уджалігас: ичӧтик exe лӧсьӧдсьӧ заводитлігӧн да бырӧдсьӧ сувтӧдігӧн. Приложениеысь петигӧн ставыс сувтӧ, а мыжасьӧм бӧрын кольӧм файлъяс вештӧны мӧд заводитігӧн.
- **Шошын уджалӧ.** Олӧ системнӧй трейын, ас заглушкаяслы абу колана торъя ӧшиньяс либӧ пуск панель вылын кнопкаяс.
- **Восьса вуджӧдӧмъяс.** Интерфейс уджалӧ простӧй JSON-файлъяс вылын, сы понда выль кыв содтыны — тайӧ сӧмын ӧти файл. Англи да роч кывъяс нин пуктӧма.
- **Приватлун.** Аккаунттӧг, Discord токентӧг, телеметритӧг. Видзӧд [Приватлун](#приватлун).

## Кыдзи тайӧ уджалӧ

1. Discord чайтӧ, мый ті ворсаныд ворсӧмӧ, видзӧдігӧн компьютер вылын уджалысь процессъяс вылӧ да ӧткодялігӧн налысь нимъяссӧ публичнӧй списоккӧд (`/api/v9/applications/detectable`).
2. Decoy босьтӧ тайӧ список да бӧрйӧм ворсӧм понда вуджӧдӧ ичӧтик заглушка-программа (гӧгӧр 120 КБ, гижӧма Rust вылын да пыртӧма Decoy-ӧ) кадлысь папкаӧ списокысь ним серти, пример вылӧ `.../cod26-cod.exe`.
3. Заглушка нинӧм оз вӧч, сы кындзи мый видзӧ ӧти вылыс тшупӧда ӧшинь, кодӧс дзебӧма экран сайӧ, сы понда ті сійӧс век оз аддзӧй. Discord тӧдмавлӧ сӧмын ӧшиня процессъяс, сы вӧсна ӧшиньтӧм процессъяс оз лыддьысьны.
4. Гӧгӧр 15 секунд мысти Discord петкӧдлас тайӧ ворсӧмсӧ тіян ӧнія удж пыдди.
5. Кор таймер помасьӧ либӧ либӧй сувтӧдан кнопка, Decoy помалӧ процесс да бырӧдӧ файл. Windows job object видзӧ, медым заглушкаяс бырасны Decoy-кӧд ӧтвылысь, кӧть сійӧ мыжасьӧмӧн помасьӧ.

## Пуктӧм

Бӧрйӧй вариант [релизъяслӧн](../../../../releases) листбок вылысь:

| Босьтны | Мый понда |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталлер.** Ӧти морт понда, администратор инӧд оз ков, содтӧ пас Пуск менюӧ да вештан программа. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Восьтӧй кӧть кытчӧ да заводитӧй `decoy.exe`. Став юӧр видзисьӧ сы бокын `data` папкаын, морт профильӧ нинӧм оз гижсьы. Вештыны кӧ кӧсйанныд, сӧмын бырӧдӧй папка. |

Видзӧдлӧй босьтӧм файллысь SHA256 контрол лыд `SHA256SUMS.txt` отсӧгӧн (PowerShell-ын `Get-FileHash <файл>`).

Windows SmartScreen вермас тӧдчӧдны тӧдтӧм гижысь йылысь, мый вӧсна сборкаяслӧн абу цифровӧй пас; бӧрйӧй *More info → Run anyway* (*Подробнее → Выполнить в любом случае*), кӧть сборкалы эскысьӧныд.

Коланатор: Windows 10 либӧ 11 (64-бит) WebView2 runtime-кӧд (нин пыртӧма Windows 11-ӧ да Windows 10-лӧн выль выльмӧдӧмъясӧ).

## Вӧдитчӧм

1. Восьтӧй **Библиотека** да корсьӧй ворсӧм, либӧ либӧй `Ctrl` + `K` кӧть кытысь.
2. Либӧй ворсӧм вылӧ. Шуйга бокын бӧрйӧй процесс да кымын минут сійӧс кутны (Discord заданиеяс тшӧкыда корӧны 15).
3. Либӧй **Заводитны заглушка**. Discord мыччӧ тайӧ ворсӧмсӧ кымын секунд мысти.
4. Видзӧдӧй сійӧс **Заводитӧма** вкладкаын, сувтӧдӧй ӧти либӧ ставсӧ кӧть кор, либӧ кольӧй Decoy трейын.

Ворсӧмъяс, кодъяслы Discord списокас на абу процессъяс, стандарт серти дзебӧма (найӧс оз позь тӧдмавны). Восьтӧй *Мыччывны exe-тӧг*, медым найӧс аддзыны; список выльмӧдсьӧ быд лун, сідзкӧ найӧ лоӧны дась, кор Discord содтас процесс.

### Команд визь

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Заводитӧ заглушка пыр и пыр, пример вылӧ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сборка кодісь

Коланатор: [Node.js](https://nodejs.org) 20+, пырся [Rust](https://rustup.rs) инструментъяс (MSVC target) Visual Studio C++ сборан инструментъяскӧд да WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Колана видзӧдлӧмъяс:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Пасйӧд: заглушкалӧн exe сборитӧ `src-tauri/build.rs` ябай `rustc`-ӧн `src-tauri/stub/stub.rs` пыдди да сэсся пыртӧ сійӧс приложениеӧ. Кор фронтенд уджалӧ браузерын (`npm run dev`), вӧдитчӧ ичӧтик mock-бэкендӧн (`src/mock.ts`), мый кокнитӧ интерфейскӧд удж.

## Вуджӧдӧмъяс

Интерфейс кывъяс куйлӧны [`src/locales`](../../src/locales) пытшкын, быд кывлы ӧти JSON-файл (`en.json`, `ru.json`, ...).
Выль кыв содтӧм лоӧ сӧмын файл содтӧмӧн, код оз ков вежны. Видзӧд [docs/TRANSLATING.md](../TRANSLATING.md) файл формат йылысь, машиннӧй вуджӧдӧмлы дась текст да видзӧдлан скрипт. Тайӧ README-лӧн вуджӧдӧмъяс пуктӧны `docs/i18n/README.<code>.md` пытшкӧ.

## Проектлӧн тэчас

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Приватлун

- Decoy вӧдитчӧ сетьӧн сӧмын Discord-лӧн публичнӧй список кыскӧм понда (медводдза заводитігӧн, сэсся луннас ӧтчыдысь унджык оз, либӧ кор ті выльмӧданныд) да ворсӧм значок да обложкаяс мыччӧм понда Discord CDN-ысь.
- Сійӧ оз лыддьы, оз видз да оз ыст тіян Discord токен либӧ аккаунт юӧр, да оз сёрнитчы Discord клиенткӧд.
- Лӧсьӧдӧмъяс (медся мусаяс, кыв, кад) видзисьӧны компьютер вылын приложениелӧн WebView видзан инӧ; ворсӧм список кэш да кадлысь заглушка файлъяс олӧны `%LOCALAPPDATA%\app.decoy.desktop` папкаын.
- Аналитика абу, мыжасьӧм йылысь юӧр абу, аккаунтъяс абу.

## Тӧдса ограничениеяс

- Discord вермас вежны тӧдмалан ног кӧть кор. Кӧть заглушка дугдіс тыдавны, корсьӧй issue.
- Мукӧд заданиеяслы колана унджык, мый сӧмын заводитӧм процесс (пример вылӧ, ворсӧм платформалӧн торъя пытшкысь опыт пытшкын овны). Decoy сӧмын процесс имитируйтӧ.
- Discord списокас процессъястӧг гижӧдъяс оз позь тӧдмавны.
- Защитнӧй ПО корсюрӧ вермас мыччыны висьӧм вылӧ ичӧтик пасйӧттӧм файлъяс вылӧ, кодъяс пукалӧны паметяын. Заглушка эм восьса исходнӧй кодӧн да сборитӧма `src-tauri/stub/stub.rs` пытшкысь; ті верманныд сійӧс сборитны асьныд.

## Кывкӧртӧмтӧг олан йылысь

Decoy сетӧма «кыдзи эм» асморт, велӧдчан да тест нуӧдан могъяс серти. Заводитӧм ворсӧм имитируйтӧм вермас торкны Discord-лысь либӧ ворсӧм лӧсьӧдысьлысь удж условиеяссӧ, да вермас вайӧдны тіян аккаунтлы дзескӧдӧмъясӧ. Ті асьныд кывкутанныд вӧдитчӧм понда. «Discord» да став ворсӧм нимъяс да логотипъяс тайӧ налӧн асшӧр котыръяслӧн пас, да вӧдитчӧны тані сӧмын сы понда, медым тӧдмавны программнӧй продуктъяс.
