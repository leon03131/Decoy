# Decoy

**Ёмла процесс-заглушканят, конатнень вельде Discord-сь лувсы, бта налхкомась нолдаф.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-ть библиотекац аф курокстонь налхкомат ди обложкат мархта" />

</div>

Decoy кирди вальмя мархта безобиднай процесс-заглушкать налхкомать содаф нолдама файлть лемса, сянкса Discord-онь
налхкоматнень мума лувоц невтьсы, што тинь налхкат тя налхкомаса. Эрявикс налхкомать путомс эли нолдамс тейнть
аф эряви, сянкса дискса аш мезевок лама.

Сон содасы **эрь налхкомать, конань Discord-сь машты мумс** (малав 25 000 тяшкста), сяс мес морафцы Discord-онь
эсь пачк невтеви мума лушковксонц ди сонць ванфцы сонь актуальнайста.

> [!WARNING]
> Нолдаф налхкома лаца тиемась ули кода карси каршек Discord-онь вешфксонзонды, Decoy-ть тевс нолясасть **ськамозт**.
> Тя проектсь аф сотоф Discord Inc. мархта, ашезь кемокшнев ди аф кирдеви сонь вельде. Вантт [Ськамонь отвечать](#ськамонь-отвечась).

## Уликс тефтне

- **Сембе, мезе Discord-сь машты мумс.** Налхкоматнень лушковкссна тонгондови Discord-онь пачк невтеви лисьмаста, ванфтови
  эсь ширеса ди одкстомтови эрь шиня. Од налхкоматне ди одкс полафт нолдама файлатне лисихть эсь пачкозост.
- **Курок вешемась.** Эряскодсь вешемась налхкомать лемонц эли exe-нц коряс тёжятть налхкоматнень ёткста, невтемась плиткаса
  эли аф оцю лушковксса, кельктне ди «Аф курокстонь» строкась.
- **Фкя лепштемаса.** Кочкак налхкомать, кочкак exe файлть (кда синь ламот), макст, зяра минута кирдемс сонь ди лепштик «Нолдамс заглушкать».
  Мърдама пингонь крюнгесь ди пачфтемась пачфтихть, мзярда пингоц шумордави.
- **Аф кады кит-латкат.** Заглушкась эри аньцек мзярс покоди: ёмла exe-сь шачи нолдамаста ди нардави
  лоткафтомаста. Программаста лисемста сембось лоткафтови, а сбоень меле лятф файлатне ванфтовихть сай нолдамаста.
- **Шембра режимсь.** Эри системнай трейса, заглушкатненди аш кодамот вальмет эли кнопкат панельса.
- **Панжадот ютафтоматне.** Интерфейсось покай шовордай JSON файлатнень лангса, сянкса од кялень поладомась — тя фкя файл.
  Англань ди рузонь кяльхне нинге совафтфт.
- **Секретшись.** Аккаунтфтома, Discord токенфтома, телеметрияфтома. Вантт [Секретшись](#секретшись).

## Кода тя покай

1. Discord-сь содасы, што тинь налхкат налхкомаса, ванца запущеннай процесстнень компьютерсот ди ванонцы
   нолдама файлснон лемснон пачк невтеви лушковкс мархта (`/api/v9/applications/detectable`).
2. Decoy тонгондосы тя лушковксть ди кочкаф налхкомати сяви ёмла заглушка-программать (малав 120 КБ, сёрматф
   Rust кяльса ди встрояф Decoy-с) эсь пингонь папкас лушковксонь нолдама файлть лемса, кепотьксонди
   `.../cod26-cod.exe`.
3. Заглушкась мезьвок аф тиенди, аньцек кирди фкя вяре ащи вальмять, кона ащи ичкозе экранда,
   сянкса тинь сонь мзярдовок акасть няе. Discord-сь содасы аньцек вальмя мархта процессть, сянкса процесстне вальмяфтома ётневихть.
4. Малав 15 секундста Discord-сь невтьсы тя налхкомать тонь тевксетень.
5. Мзярда таймерсь шумордави эли тинь лепштясть лоткафтомать, Decoy лоткафтсы процессть ди нардасы файлть. Windows job object
   ванфцы, штоба заглушкатне лоткафтовлекшть Decoy мархта марса, кда программась аварияса пекставсь-ка.

## Путомась

Кочкак вариантть [релизнень лопаста](../../../../releases):

| Тонгомась | Тевсь |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Установщик.** Фкя тевс ноляйти, администраторонь прават аф эрявихть, полацы строкать «Пуск» менюс ди нардамать. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативнай версия.** Панжик эрь коза ди нолдак `decoy.exe`. Сембе датась кирдеви `data` папкаса сонь ваксса, тевс ноляйть профильс мезьвок аф сёрматкшневи. Нардаманди аньцек нардак папкать. |

Варчсек контрольнай суммать `SHA256SUMS.txt` вельде (`Get-FileHash <file>` PowerShell-са).

Windows SmartScreen-сь ули кода кевсти аф содаф нолдайдонть, сянкса што сбортненди цифровой тяшкс аш; кочкак
*Сяда тов → Нолдамс сякавок*, кда верондатада тя сборкати.

Эрявикс тефне: Windows 10 эли 11 (64-битонь) WebView2 runtime мархта (нинге путоф Windows 11-с ди од
Windows 10 одкстомтоматненди).

## Тевс нолямась

1. Панжик **Библиотекать** ди мук налхкомать, эли лепштик `Ctrl` + `K` эрь коста.
2. Лепштик налхкомать. Вити панельса кочкак процессть ди зяра минута сонь кирдемс (Discord-онь заданиятненди
   сидеста эряви 15).
3. Лепштик **Нолдамс заглушкать**. Discord-сь невтьсы налхкомать кържа секундста.
4. Ватт сонь лангс **Нолдаф** вкладкаса, лоткафтт фкя эли сембе эрь мзярда эли аньцек кадык Decoy-ть трейс.

Налхкоматне, конатненди Discord-онь базаса нинге аш exe файлат, кяшфт сембонди (синь мумс аф лиси). Панжик
*Невтемс exe-фтома*, штоба няемс синь; лушковксось одкстомтови эрь шиня, сянкса синь сатневихть, кода Discord полацы
процессть.

### Командань строясь

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Сеске нолдасы заглушкать, кепотьксонди: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сборкась лисьмапряста

Эрявикс кядьготне: [Node.js](https://nodejs.org) 20+, стабильнай кядьгоц [Rust](https://rustup.rs) (MSVC целень платформась)
Visual Studio C++ сборочнай кядьгот мархта ди WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # нолдамс разработчикнень режимса hot reload мархта
npm run tauri build    # тиемс установщикть src-tauri/target/release/bundle/nsis папкас
```

Пара варчсематне:

```bash
npm run check-locales  # варчсемс эрь кялень файлть ru.json лангс
npx tsc --noEmit       # фронтендонь типнень варчсемась
cargo check --manifest-path src-tauri/Cargo.toml
```

Тяшкстне: заглушкань exe файлсь смушкови `src-tauri/build.rs` скриптса ськамонь `rustc` вельде `src-tauri/stub/stub.rs` файласта ди меле
встрояви программас. Мзярда фронтендось нолдави ськамонь браузерса (`npm run dev`), тевс ноляви ёмла мок-бэкендсь
(`src/mock.ts`), тя пара интерфейсть лангса покодемста.

## Ютафтоматне

Интерфейсонь строкатне ащихть [`src/locales`](../../src/locales) папкаса, фкя JSON файл эрь кяльти (`en.json`, `ru.json`, ...).
Од кялень поладомась — тя аньцек од файлть каямась, кодонь полафтомафтома. Вантт [docs/TRANSLATING.md](../TRANSLATING.md) файлонь форматсь,
анок промптсь машинной ютафтоманди ди варчсемань скриптсь. Тя README-ть ютафтоманза ащихть
`docs/i18n/README.<code>.md` папкаса.

## Проектть структурац

```
src/                    React + TypeScript фронтенд
  components/           Библиотека, кучф панельсь, настройканят, ...
  locales/              ютафтомань файлатне (фкя JSON эрь кяльти)
  i18n-core.ts          кялень тонгомась ди мумась
  store.ts              программань состояниясь (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            налхкомань базась, заглушкань процесстне, трей
  stub/stub.rs          встрояви заглушка-программась
scripts/                лездамань скрипттне (локалень варчсемась)
docs/                   ютафтомань вятемась, скриншоттне
```
