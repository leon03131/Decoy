# Decoy

**Smáar staðgongilsprosessir, ið fáa Discord at halda, at eitt spæl koyrir.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy savn við nýliga brúktum spølum og myndum" />

</div>

Decoy heldur eina skaðaleysa staðgongilsprosess við glugga koyrandi undir heitinum á koyrifíluni (exe) hjá einum spæli, so spælavarningin hjá Discord vísir, at tú spælir tað spælið. Tú nýtist ongantíð at leggja ella byrja veruliga spælið inn, so einki plásskrævandi liggur á telduni.

Tað kennir **hvert einasta spæl, sum Discord kann varnast** (umleið 25.000 færslur), tí tað lesur almenna varningarlistan hjá Discord og dagførir hann sjálvvirkandi.

> [!WARNING]
> At herma eftir einum spæli, ið koyrir, kann stríða ímóti brúkaratreytunum (Terms of Service) hjá Discord, og tú brúkar Decoy **á egna ábyrgd**.
> Hendan verkætlanin er ikki knýtt at, stuðlað av ella partur av Discord Inc. Sí [Fyrivarni](#fyrivarni).

## Eginleikar

- **Alt sum Discord fær varnast.** Spælalistin verður heintaður frá almenna varningarendapunktinum hjá Discord, goymdur lokalt og dagførdur hvønn dag. Nýggj spøl og nýggjar koyrifílur vísa seg av sær sjálvum.
- **Leitan sum fylgir við.** Skjótleitan eftir spælaheiti ella exe millum túsundtals spøl, flísa- ella tætt listayvirlit, yndi og ein røð við „Seinastu“.
- **Eitt trýst.** Vel eitt spæl, vel koyrifíluna (um tær eru fleiri), vel hvussu leingi hon skal koyra og trýst á byrja. Ein niðurteljari og ein fráboðan siga tær frá, tá tíðin er úti.
- **Letur einki liggja eftir.** Eitt decoy er bert til meðan tað koyrir: tann lítla exe-fílan verður stovnað tá byrjað verður og strikað tá steðgað verður. Alt verður steðgað tá tú fer úr forritinum, og leivdir eftir eitt møguligt óhapp verða reinsaðar næstu ferð forritið byrjar.
- **Ljóðleyst.** Liggur í boðbakkanum, eingir gluggar ella knappar á uppgávubilkunum fyri decoy-prosessirnar sjálvar.
- **Opnar týðingar.** Brúkaramótið brúkar vanligar JSON-fílur, so at leggja eitt mál aftrat krevur bert eina fílu. Enskt og russiskt fylgja við.
- **Privatlív.** Ongin brúkari, onki Discord-token, ongar hagtalsmátingar. Sí [Persónsvernd](#persónsvernd).

## Hvussu tað virkar

1. Discord metir, at tú spælir eitt spæl, við at hyggja eftir teimum prosessum, sum koyra á telduni, og samanbera nøvnini á koyrifílunum við ein almennan lista (`/api/v9/applications/detectable`).
2. Decoy heintar henda listan og avritar – fyri spælið tú velur – eitt lítið staðgongilsforrit (umleið 120 KB, skrivað í Rust og innbygt í Decoy) til eina fyribilsmappu undir exe-navninum úr listanum, til dømis `.../cod26-cod.exe`.
3. Staðgongilsforritið ger einki annað enn at hava ein glugga á ovasta stigi, staðsettan langt uttan fyri skíggjan so tú aldri sært hann. Discord varnast bert eina prosess, sum eigur ein glugga, og tí verður ein heilt gluggaleys prosess ignorerað.
4. Eftir umleið 15 sekund vísir Discord spælið sum títt virksemi í løtuni.
5. Tá tíðarteljarin er liðugur ella tú trýstir á steðga, endar Decoy prosessið og strikar fíluna. Eitt Windows-arbeiðsevni (job object) tryggjar, at decoy-prosessir steðga saman við Decoy, sjálvt um forritið skuldi dottið niður.

## Innlegging

Vel eina útgávu á [Releases](../../../../releases)-síðuni:

| Niðurhal | Fyri |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Uppsetanarforrit.** Fyri hvønn brúkara, krevur ikki stjórnarrættindi, leggur eina færslu í Start-valmyndina og eitt avinnleggingarforrit. |
| `Decoy_x.y.z_x64-portable.zip` | **Føranligt (portable).** Lat upp úr zip-fíluni hvar sum helst og koyr `decoy.exe`. Øll dáta verða goymd í `data`-mappuni við liðina á tí, einki verður skrivað í brúkaraprofilin. Strika mappuna fyri at beina tað burtur. |

Vátta eitt niðurhal við `SHA256SUMS.txt` (`Get-FileHash <fíla>` í PowerShell).

Windows SmartScreen kann ávara um ein ókendan útgevara, tí útgávurnar ikki eru undirskrivaðar við loyvisbrævi; vel *More info → Run anyway* um tú vilt líta á útgávuna.

Krøv: Windows 10 ella 11 (64-bit) við WebView2-koyrilíki (longu við í Windows 11 og nýggjari Windows 10 dagføringum).

## Nýtsla

1. Lat **Savn** upp og leita eftir einum spæli, ella trýst á `Ctrl` + `K` hvar sum helst.
2. Trýst á eitt spæl. Í teiginum til høgru velur tú prosessið og hvussu nógvar minuttir tað skal haldast (Discord-uppgávur biðja vanliga um 15).
3. Trýst á **Byrja decoy**. Discord fer at vísa spælið eftir fá sekund.
4. Fylg við tí undir **Koyrir**, steðga einum ella øllum nær sum helst, ella lat Decoy bara liggja í boðbakkanum.

Spøl, har Discord-færslan ikki hevur nakra koyrifílu enn, eru fjaldir sum standard (tey kunnu ikki varnast). Tendra fyri *Vís spøl uttan exe* fyri at síggja tey; listin verður dagførdur hvønn dag, so tey verða tøk so skjótt sum Discord leggur eina prosess aftrat.

### Kommandolinja

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Byrjar eitt decoy beinanvegin, til dømis `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bygg úr keldutilfari

Krevur: [Node.js](https://nodejs.org) 20+, tað støðuga [Rust](https://rustup.rs)-amboðasettið (MSVC target) við Visual Studio C++ byggiamboðum, og WebView2-koyrilíki.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # koyr í menningarstøðu við beinleiðis endurlesing (hot reload)
npm run tauri build    # ger uppsetanarforritið í src-tauri/target/release/bundle/nsis
```

Hent royndaramboð:

```bash
npm run check-locales  # eftirkannar allar týðingarfílur móti ru.json
npx tsc --noEmit       # slagkannar framendann
cargo check --manifest-path src-tauri/Cargo.toml
```

Viðmerkingar: decoy-exe verður bygt av `src-tauri/build.rs` við vanligum `rustc` úr `src-tauri/stub/stub.rs` og síðani lagt inn í forritið. Tá framendin koyrir í einum vanligum kaga (`npm run dev`), verður ein lítil royndarbakendi (`src/mock.ts`) brúktur, sum er hentur tá arbeitt verður við brúkaramótinum.

## Týðingar

Tekstirnir í brúkaramótinum liggja í [`src/locales`](../../src/locales), ein JSON-fíla fyri hvørt mál (`en.json`, `ru.json`, ...). At leggja eitt mál aftrat krevur bert eina nýggja fílu; ongar broytingar í kotuni. Sí [docs/TRANSLATING.md](../TRANSLATING.md) fyri fíluforsnið, ein kláran fyrispurning til maskintýðing og kannanarhandritið. Týðingar av hesi README-fílu verða goymdar í `docs/i18n/README.<code>.md`.

## Bygnaður hjá verkætlanini

```
src/                    React + TypeScript framendi
  components/           Savn, smálutateigur, stillingar, ...
  locales/              týðingarfílur (ein JSON-fíla fyri hvørt mál)
  i18n-core.ts          innlesing og leitan eftir máli

  src/lib.rs            spæladátugrunnur, decoy-prosessir, boðbakki

scripts/                hjálparhandrit (kanning av málfílum)
docs/                   leiðbeining til týðing, skíggjamyndir
```

## Persónsvernd

- Decoy brúkar bert netið til at heinta almenna varningarlistan hjá Discord (fyrstu ferð forritið byrjar, síðani í mesta lagi eina ferð um dagin ella tá tú trýstir á dagfør) og, til vísing, spælamyndir og listarverk frá almenna CDN-netinum hjá Discord.
- Tað lesur, goymir ella sendir ikki títt Discord-token ella nakrar kontudáta, og tað tosar ikki við Discord-klientin.
- Stillingar (yndi, mál, tíðarlongdir) verða goymdar lokalt í WebView-goymsluni hjá forritinum; goymslan fyri spælalistan og fyribils decoy-fílur liggja í `%LOCALAPPDATA%\app.decoy.desktop`.
- Ongar brúkaragreiningar, ongar feilfráboðanir, ongir brúkarakontur.

## Kendar avmarkingar

- Discord kann broyta hvussu varning virkar nær sum helst. Um eitt decoy gevst við at verða varnast, vinarliga stovns eitt mál (issue).
- Summi virksemi krevja meira enn bert eina koyrandi prosess (til dømis at vera inni í einari serstakari uppliving á einum spælapall). Decoy hermir bert eftir prosessini.
- Færslur uttan koyrifílur í listanum hjá Discord kunnu ikki varnast.
- Trygdarforrit ávara viðhvørt um smáar óundirskrivaðar koyrifílur, ið liggja óvirknar í minninum. Decoy hevur opnan keldutekst og verður bygt úr `src-tauri/stub/stub.rs`; tú kanst byggja tað sjálv/ur.

## Ver við

Feilfráboðanir, hugskot og týðingar eru vælkomin. Vinarliga les [CONTRIBUTING.md](../../CONTRIBUTING.md) fyrst.

## Fyrivarni

Decoy verður latið „sum tað er og kann vera“ til persónligt, útbúgvingar- og royndarendamál. At herma eftir einum spæli, ið koyrir, kann bróta brúkaratreytirnar hjá Discord ella hjá útgevaranum av spælinum, og kann hava við sær revsing fyri tína konto. Tú ber eina ábyrgd av, hvussu tú brúkar tað. „Discord“ og øll spælanøvn og búmerki eru vørumerki hjá teirra ávísu eigarum og verða her bert nýtt til at eyðmerkja ritbúnaðin, víst verður til.
