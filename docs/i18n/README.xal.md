# Decoy

**Discord наадн көдлҗәнә гиҗ санхин төлә җиҗгхн орлулач-процесстнр.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Ойрх нааддта болн зургудта Decoy номин саң" />

</div>

Decoy наадна гүүлтн бичгин (executable) нерәр хор уга, цонхта орлулач-процессыг ар талд көдлүлҗ бәрнә, тиигхлә Discord-ин наад илдкх теткүл таниг эн наадар наадҗана гиҗ үзклнә. Танд үнн наад суулһх аль эклүлх керг уга, тиим учрар диск деер ямр чигн күнд юмн үлдхш.

Эн **Discord илдкҗ чадх цуг нааддыг** (25 000 шаху бичгдл) меднә, яһад гихлә Discord-ин ниит илдкх дансинь умшад, эврән өдр болһн шинрүлҗ бәәнә.

> [!WARNING]
> Көдлҗәх наад хуулҗ кехнь Discord-ин Ашглалтын болзориг эвдҗ болх, та Decoy-г **эврән сэрмҗәрн** олзлҗант.
> Эн төсөл Discord Inc.-тә ямр чигн залһлда уга, түүнәр демҗгдсн уга болн батлгдсн уга. [Сэрмҗлгч заалт](#сэрмҗлгч-заалт) хәләтн.

## Эв-арһуд

- **Discord илдкҗ чадх цуг юмн.** Нааддын данс Discord-ин ниит эндпоинтас татгдна, һазрт кэшлгднә болн өдр болһн шинрүлгднә. Шин наадд болн шинәр немгдсн гүүлтн бичгүд эврән үзгднә.
- **Түргн хәәвр.** Миңһн наадд дундас наадна нерәр аль гүүлтн бичгәр дольгатаг хәәх, хавтха аль җиҗг дансар үзклт, дурта наадд болн «Ойрх» мөр.
- **Нег дарасар.** Наад талтн, гүүлтн бичг талтн (кедү буслхла), кедү минут бәрхин заатн болн эклх дартн. Төгсхин бөлцг цаг болн зәңг цаг төгсв гиҗ танд медүлх.
- **Хөөнән туг чигн үлдхш.** Decoy зөвкн көдлҗәх цагтан бәәнә: бичкн exe эклхлә бүтнә болн зогсхла сорлгдна. Программаас һархла цуг юмн зогсх, сүйдсн хөөн үлдсн хог дарук эклцд цеврлгднә.
- **Дүүмн.** Системин трейд оршн бәәнә, орлулач-процесстнрт зокал цонх аль даалһврин самбарт товчлур уга.
- **Селәд кегдх орчуллһн.** Интерфейс бэлн JSON файлудар көдлнә, тиим учрар шин кел немхнь зөвкн нег файл болна. Англи болн орс келн бэлн орулгдсн.
- **Нууцллһн.** Аккаунт уга, Discord токен уга, телеметри уга. [Нууцллһн](#нууцллһн) хәләтн.

## Яһҗ көдлдг билә

1. Discord тана компьютерт көдлҗәх процесстнриг хәләҗ, эднә гүүлтн бичгин нериг ниит данста (`/api/v9/applications/detectable`) дүңнәд, та наад наадҗант гиҗ шииднә.
2. Decoy эн дансиг татад, тана суңһсн наадад зокал бичкн орлулач-программыг (120 КБ орчм, Rust дээр бичигдсн болн Decoy дотр суулһгдсн) түр хавтаст дансас авсн гүүлтн бичгин нерәр хуулна, үлгүрнь `.../cod26-cod.exe`.
3. Орлулач юн чигн кехш, ганцхан дээд зэргин цонх эзлнә, ону дэлгцнәс хол байрлулгдсн төлә та эниг кезә чигн үзхшйт. Discord зөвкн цонхта процесстыг меднә, тиим учрар цонх уга процесс тоолгдхш.
4. Ойрлцаһар 15 секунд болхла Discord эн наадыг тана ода көдлҗәх үй-үйл гиҗ үзклнә.
5. Цаг төгсхлә аль та зогсах товч дарсн цагт Decoy процессыг төгсхәд бичгиг устгна. Windows job object нь Decoy сүйрсн чигн цуг орлулач-процесстнр Decoy-та цуг зогсхыг батлна.

## Суулһлһн

[Һарлтын](../../../../releases) халхас негинь талтн:

| Татх | Зөрүлг |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Суулһач.** Хәрглгч болһнд, администраторин эрк керг уга, «Эклц» менюд бичгдл болн устгач немнә. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable (Зөөвр).** Ямаран чигн ормд задалад `decoy.exe` эклүлтн. Цуг өгүлл хаҗуднь бәәх `data` хавтаст хадһлгдна, тана ашглагчин намтарт юн чигн бичигдхш. Устгахын төлә эн хавтасыг арилһтн. |

Татсн бичгиг `SHA256SUMS.txt` тусар шалһтн (PowerShell-д `Get-FileHash <файл>`).

Windows SmartScreen үүдәгчнь медгдхш гиҗ сэрмҗлүлҗ болх, яһад гихлә сүүлин бэлдврт тоон темдг бәәхш; бэлдврт иткҗәхлә, *Дәкәд медүлг → Ямаран чигн болвза эклүлх* суңһтн.

Кергтә тоолвр: Windows 10 аль 11 (64-бит) WebView2 runtime-та (эннь Windows 11-д болн сүүлин Windows 10 шинрүллһнд бэлн бәәнә).

## Олзллһн

1. **Номин саң** секәд наад хәәтн, аль хаанас чигн болвза `Ctrl` + `K` дартн.
2. Наадн деер дартн. Барун тала самбарт процессыг суңһад, кедү минут бәрхин заатн (Discord даалһврт болвза 15 минут кергтә).
3. **Decoy эклүлх** дартн. Discord кедүхн секунд болхла наадыг үзклх.
4. **Көдлҗәнә** хавтха дор хәләҗ хәләтн, негиг аль цугинь зогсатн, аль Decoy-г трейд үлдәтн.

Discord-ин бэлн данст гүүлтн бичг нь уга наадд кевәр нуугдмал бәәнә (эдниг илрүлҗ болшго). Эдниг үзхин төлә *exe уга наадд үзклх* талтн; данс өдр болһн шинрүлгднә, тиим учрар Discord процесс немсн цагт бэлн болх.

### Заалтын мөр

```
decoy.exe --launch "<Discord дансас гүүлтн бичгин залһлда>" [минут]
```

Decoy-г шууд эклүлнә, үлгүрнь `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Эк код-бичгәс угсрлһн

Кергтә хүв-зүйл: [Node.js](https://nodejs.org) 20+, тогтвр бәәдлтә [Rust](https://rustup.rs) зер-зев (MSVC зокал) Visual Studio C++ угсралтын зевсгтә, болн WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # шинрүллһтә көглҗин бәәдлд эклүлх
npm run tauri build    # src-tauri/target/release/bundle/nsis дотр суулһач бүтәх
```

Туста шалһврмуд:

```bash
npm run check-locales  # цуг орчуллһны бичгүүдиг ru.json-та шалһх
npx tsc --noEmit       # интерфейсин бүтц шалһх
cargo check --manifest-path src-tauri/Cargo.toml
```

Темдглгдл: decoy-н exe-г `src-tauri/build.rs` дотр бэлн `rustc` ашглан `src-tauri/stub/stub.rs`-с бүтәнэ болн тегәд эв-арһ дотр суулһна. Хәрглгчин интерфейс йирн браузерт (`npm run dev`) көдлхлә, `src/mock.ts` мок-сервер олзлгдна, эннь UI деер көдлхд йир эвтәхн.

## Орчуллһн

Интерфейсин бичгүүд [`src/locales`](../../src/locales) хавтаст бәәнә, келн болһнд нег JSON файл (`en.json`, `ru.json`, ...). Шин кел немх гисн үг — ганцхан файл немх, кодын сольвр керг уга. Файлын бүтц, машин орчуллһнд бэлдсн сүв-сүвчлг болн шалһлтын скрипт [docs/TRANSLATING.md](../TRANSLATING.md) дотр бичигдсн. README-н орчуллһн `docs/i18n/README.<code>.md` хавтаст орна.

## Төслийн бүтэц

```
src/                    React + TypeScript интерфейс
  components/           Номин саң, делгрңгү самбар, келг-эндүр, ...
  locales/              орчуллһны файлуд (келн болһнд нег JSON)
  i18n-core.ts          келн оруллһн болн хәәвр
  store.ts              эв-арһин бәәдл (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            нааддын саң, decoy процесстнр, трей
  stub/stub.rs          дотр суулһгдх бичкн орлулач-программ
scripts/                нөкд скриптүүд (орчуллһн шалһх)
docs/                   орчуллһны заалт, дэлгцин зургуд
```

## Нууцллһн

- Decoy сүлҗиг ганцхан Discord-ин ниит илдкх дансиг татхин төлә (түрүн эклцд, тегәд өдрт хамгин иктә нег дәкәд аль шинрүлх товч дарсн цагт) болн Discord-ин ниит CDN-с наадна сүлд болн зургудыг үзклхин төлә олзлна.
- Эн тана Discord токен аль аккаунтын ямаран чигн өгүллиг умшхш, хадһлхш, йовулхш, болн Discord клиенттә яһад чигн күрхш.
- Келг-эндүр (дурта наадд, келн, цаг) эв-арһин WebView дотр һазрт хадһлгдна; нааддын данс кэш болн түр decoy файлуд `%LOCALAPPDATA%\app.decoy.desktop` хавтаст бәәнә.
- Аналитик уга, сүйдлин зәңгллһн уга, аккаунт уга.

## Медгдсн хязһрлалт

- Discord илдкх эв-арһан ямаран чигн цагт сольҗ болх. Керв decoy медгдхән уурхла, буйн болтха issue секҗ бичитн.
- Кезә-кезә даалһврт ганцхан көдлҗәх процесс биш, талдан юмн кергтә болна (үлгүрнь, наадна тогтолцан тусхай төләд бәәх). Decoy ганцхан процессыг дуран кеж дурална.
- Discord данст гүүлтн бичг уга бичгдл илдкҗ болшго.
- Хамгаллтын программ санах ойд зүгээр бәәх жижигхн темдг уга гүүлтн бичгүдиг заримдаа сэжиглҗ болх. Decoy-н эк код аһу селәтә болн `src-tauri/stub/stub.rs`-с бүтәгднә; та эниг эврән угсарҗ чаднат.

## Сэрмҗлгч заалт

Decoy эврән, сурһмҗин болн туршилтын хэрэгт «бәәҗәх кевәрн» өггднә. Көдлҗәх наад дуран кехнь Discord-ин аль наад кегчин Ашглалтын болзориг эвдҗ болх болн тана тооцоот бичгдлд (аккаунтд) арга-хемҗэ авгдҗ болх. Та эниг яһҗ ашглахарн ганцхан эврән дааврар харюцнавт. «Discord» болн цуг нааддын нерн, темдгүд эврә-эврән эзнрин эд-хорш болна болн энд зөвкн программин хань-ханцыг танин медүлэх төлә бичигдв.
