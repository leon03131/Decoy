# Decoy

**Discord-ка уен эшләп тора дип уйлатыр өчен кечкенә ялган процесслар.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Соңгы уеннар һәм тышлыклар белән Decoy китапханәсе" />

</div>

Decoy уенның башкарыла торган файлы исеме астында зарарсыз, тәрәзәле ялган процессны эшләтеп тота, шуңа күрә Discord уеннарны билгеләү системасы сезне шул уенны уйный дип күрсәтә. Сезгә чын уенны урнаштырырга яки эшләтеп җибәрергә кирәкми, шуңа күрә дискта бернинди зур файллар ятмый.

Ул **Discord билгели ала торган һәр уенны** белә (якынча 25 000 язма), чөнки ул Discord-ның үзенең ачык исемлеген укый һәм аны үзе яңартып тора.

> [!WARNING]
> Уенның эшләвен ялган итеп күрсәтү Discord-ның Хезмәт күрсәтү шартларына каршы килергә мөмкин, һәм сез Decoy-ны **үз җаваплылыгыгызда** кулланасыз.
> Бу проект Discord Inc. белән бәйләнмәгән, хупланмаган һәм аңа катнашы юк. [Җаваплылыктан баш тарту](#җаваплылыктан-баш-тарту) бүлеген карагыз.

## Мөмкинлекләр

- **Discord билгели алган бар нәрсә.** Уеннар исемлеге Discord-ның ачык билгеләү төененнән йөкләнә, локаль кэшлана һәм көн саен яңартыла. Яңа уеннар һәм яңа өстәлгән башкарыла торган файллар үзләре үк пәйда була.
- **Тиз эзләү.** Меңләгән уен арасында уен яки башкарыла торган файл исеме буенча тиз эзләү, плиткә яки кыска исемлек күренеше, сайланмалар һәм «Соңгылар» рәте.
- **Бер басуда.** Уенны сайлагыз, башкарыла торган файлны сайлагыз (берничә булса), аны күпме вакыт тотарга кирәклеген билгеләгез һәм башларга басыгыз. Кире санау боҗрасы һәм белдерү вакытның чыгуы турында хәбәр итә.
- **Бернинди эз калдырмый.** Decoy бары тик эшләгән вакытында гына яши: кечкенә exe башлап җибәргәндә ясала һәм туктатканда бетерелә. Кушымтадан чыкканда барысы да туктатыла, ә хаталар булганда калган калдыклар чираттагы җибәрү вакытында чистартыла.
- **Тыныч.** Система треенда яши, Decoy-ларның үзләре өчен бернинди тәрәзә яки мәсьәләләр тасмасында төймәләр юк.
- **Ачык тәрҗемәләр.** Интерфейс гади JSON файллары ярдәмендә эшли, шуңа күрә тел өстәү — бер генә файл өстәү дигән сүз. Инглиз һәм рус телләре кертелгән.
- **Шәхсилек.** Хисап язмасы, Discord токеннары һәм телеметрия юк. [Шәхсилек](#шәхсилек) бүлеген карагыз.

## Бу ничек эшли

1. Discord санакның эшләп торучы процессларын карап һәм аларның башкарыла торган файл исемнәрен ачык исемлек (`/api/v9/applications/detectable`) белән чагыштырып, сезне уен уйный дип билгели.
2. Decoy бу исемлекне йөкли һәм, сез сайлаган уен өчен, исемлектәге башкарыла торган файл исемен файдаланып (мәсәлән, `.../cod26-cod.exe`), вакытлы папкага кечкенә урынбасар программаны (якынча 120 КБ, Rust телендә язылган һәм Decoy эченә урнаштырылган) күчерә.
3. Урынбасар программа бернинди эш башкармый, бары тик сез аны беркайчан да күрмәсен өчен экран читеннән ерак урнашкан бер өске дәрәҗә тәрәзәгә ия була. Discord тәрәзәсе булган процессларны гына таный, шуңа күрә бөтенләй тәрәзәсез процесс игътибарсыз калдырыла.
4. Якынча 15 секунд эчендә Discord уенны сезнең агымдагы эшчәнлек итеп күрсәтә.
5. Таймер тәмамлангач яки туктатуга баскач, Decoy процессны тәмамлый һәм файлны бетерә. Windows job объекты хәтта Decoy көтелмәгәндә ябылса да, барлык Decoy процессларының аның белән бергә ябылуын тәэмин итә.

## Урнаштыру

[Releases](../../../../releases) битеннән берсен сайлагыз:

| Йөкләү | Максаты |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Урнаштыргыч.** Һәр кулланучы өчен, администратор хокуклары таләп ителми, «Башлау» (Start) менюсына язма һәм бетергеч (uninstaller) өсти. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Теләсә кайсы җиргә чыгарып, `decoy.exe` җибәрегез. Барлык мәгълүмат янәшәдәге `data` папкасында саклана, кулланучы профиленә берни дә язылмый. Бетерү өчен папканы юк итегез. |

Йөкләнгән файлны `SHA256SUMS.txt` ярдәмендә тикшерегез (PowerShell-да `Get-FileHash <файл>`).

Җыелмаларның санлы имзасы булмаганлыктан, Windows SmartScreen билгесез нәшер итүче турында кисәтергә мөмкин; әгәр сез җыелмага ышансагыз, *Төпле мәгълүмат (More info) → Барыбер җибәрергә (Run anyway)* сайлагыз.

Таләпләр: WebView2 runtime белән Windows 10 яки 11 (64-бит) (Windows 11 һәм соңгы Windows 10 яңартуларына кертелгән).

## Куллану

1. **Китапханә**не ачыгыз һәм уенны эзләгез, яки теләсә кайсы җирдән `Ctrl` + `K` төймәләренә басыгыз.
2. Уенга басыгыз. Уң яктагы панельдә процессны һәм аны ничә минут тотарга кирәклеген сайлагыз (Discord биремнәренә гадәттә 15 минут кирәк).
3. **Decoy башларга** төймәсенә басыгыз. Discord берничә секундтан соң уенны күрсәтер.
4. Аны **Эшли** бүлегеннән күзәтегез, теләсә кайсы вакытта берсен яки барысын да туктатыгыз, яисә Decoy-ны трейда гына калдырыгыз.

Discord язмасында әлегә башкарыла торган файллары булмаган уеннар гадәттә яшерелгән (алар билгеләнә алмый). Аларны күрү өчен *exe булмаган уеннарны күрсәтергә* көйләвен кабызыгыз; исемлек көн саен яңартыла, шуңа күрә Discord процессны өстәү белән алар кулланырлык була.

### Командалар юлы

```
decoy.exe --launch "<Discord исемлегендәге башкарыла торган файл юлы>" [минутлар]
```

Decoy-ны шундук башлап җибәрә, мәсәлән: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Чыганак кодтан җыю

Таләп ителә торган кораллар: [Node.js](https://nodejs.org) 20+, Visual Studio C++ төзү кораллары белән тотрыклы [Rust](https://rustup.rs) кораллар җыелмасы (MSVC target) һәм WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # кайнар яңарту (hot reload) белән эшләү режимында җибәрү
npm run tauri build    # урнаштыргычны src-tauri/target/release/bundle/nsis эчендә ясау
```

Файдалы тикшерүләр:

```bash
npm run check-locales  # һәр тәрҗемә файлын ru.json белән чагыштырып тикшерү
npx tsc --noEmit       # фронтенд типларын тикшерү
cargo check --manifest-path src-tauri/Cargo.toml
```

Искәрмәләр: decoy exe файлы `src-tauri/build.rs` ярдәмендә гади `rustc` белән `src-tauri/stub/stub.rs` чыганагыннан җыела һәм кушымта эченә урнаштырыла. Фронтенд гади браузерда эшләгәндә (`npm run dev`), кечкенә ялган бэкенд (`src/mock.ts`) кулланыла, бу UI белән эшләү өчен бик уңайлы.

## Тәрҗемәләр

Интерфейс юллары [`src/locales`](../../src/locales) эчендә, һәр тел өчен бер JSON файл булып саклана (`en.json`, `ru.json`, ...).
Тел өстәү бер яңа файл өстәүне аңлата; кодны үзгәртү кирәк түгел. Файл форматы, машина тәрҗемәсе өчен әзер сорау (prompt) һәм тикшерү скрипты өчен [docs/TRANSLATING.md](../TRANSLATING.md) файлын карагыз. Бу README файлын тәрҗемә итү `docs/i18n/README.<code>.md` файлына урнаштырыла.

## Проект төзелеше

```
src/                    React + TypeScript фронтенды
  components/           Китапханә, детальләр панеле, көйләүләр, ...
  locales/              тәрҗемә файллары (һәр тел өчен бер JSON)
  i18n-core.ts          телне йөкләү һәм табу
  store.ts              кушымта халәте (zustand)
src-tauri/              Rust бэкенды (Tauri 2)
  src/lib.rs            уеннар базасы, Decoy процесслары, трей
  stub/stub.rs          урнаштырыла торган урынбасар программа
scripts/                ярдәмче скриптлар (локальләрне тикшерү)
docs/                   тәрҗемә итү кулланмасы, скриншотлар
```

## Шәхсилек

- Decoy челтәрне бары тик Discord-ның ачык билгеләү исемлеген йөкләү өчен (беренче җибәргәндә, аннары көненә күп дигәндә бер тапкыр яки сез яңартуга басканда) һәм уен билгеләре белән тышлыкларын күрсәтү өчен Discord-ның ачык CDN челтәреннән йөкләү өчен генә куллана.
- Ул сезнең Discord токенын яки бернинди хисап мәгълүматларын укымый, сакламый һәм җибәрми, шулай ук Discord клиенты белән элемтәгә керми.
- Көйләүләр (сайланмалар, тел, дәвамлылык) кушымтаның WebView саклагычында җирле саклана; уеннар исемлеге кэшы һәм вакытлы Decoy файллары `%LOCALAPPDATA%\app.decoy.desktop` эчендә урнаша.
- Аналитика юк, авария хисаплары юк, хисап язмалары юк.

## Билгеле чикләүләр

- Discord уеннарны билгеләү ысулын теләсә кайсы вакытта үзгәртә ала. Әгәр дә Decoy танылмый башласа, зинһар, issue ачыгыз.
- Кайбер эшчәнлекләр бары тик процессның эшләвеннән тыш башка нәрсәләрне дә таләп итә (мәсәлән, уен платформасының билгеле бер тәҗрибәсендә булу). Decoy фәкать процессны гына охшата.
- Discord исемлегендә башкарыла торган файллары булмаган язмалар таныла алмый.
- Куркынычсызлык программалары хәтердә тик торган имзаланмаган кечкенә башкарыла торган файлларны кайвакыт шикле дип билгеләргә мөмкин. Decoy — ачык кодлы программа һәм ул `src-tauri/stub/stub.rs` чыганагыннан җыела; сез аны үзегез җыя аласыз.

## Җаваплылыктан баш тарту

Decoy шәхси, мәгариф һәм сынау максатлары өчен «булганча» бирелә. Эшләп торучы уенны ялган охшату Discord-ның яки уен нәшер итүчесенең Хезмәт күрсәтү шартларын бозырга мөмкин һәм сезнең хисап язмагызга карата чаралар күрүгә китерергә мөмкин. Аны ничек куллануыгыз өчен бары тик үзегез генә җаваплы. «Discord» һәм барлык уен исемнәре белән логотиплары аларның хокук ияләренең сәүдә билгеләре булып тора һәм монда алар бәйле булган программа тәэминатын билгеләү өчен генә кулланыла.
