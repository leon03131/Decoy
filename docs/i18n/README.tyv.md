# Decoy

**Discord оюн үнүп турар деп бодаар кылдыр ажылдаар бичии заглушка-процесстер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Сөөлгү оюннарлыг болгаш чуруктарлыг Decoy библиотеказы" />

</div>

Decoy оюннуң күүседикчи файлының (executable) ады-биле көрүнчүктүг, айыыл чок заглушка-процессти ажылдадып тудар, ынчангаш Discord силерни ол оюнну ойнап турар деп көргүзер. Шын оюнну компьютерге тургузар азы ажыдар херек чок, ол дээш дискте улуг чүүл чытпас.

Ол **Discord-туң илередип болур бүгү оюннарын** билир (25 000 хире бижик), чүге дээрге Discord-туң ажык илередилге даңзызын номчуп, ону боду чаартып тудар.

> [!WARNING]
> Ажылдап турар оюнну өттүнүп көргүзери Discord-туң ажыглал негелделеринге удур болуп болур, ынчангаш Decoy-ну **бодуңарның харыысалгаңар-биле** ажыглаар силер.
> Бо төлевилел Discord Inc. компаниязы-биле харылзаа чок, ооң талазындан деткиттинмээн болгаш бадылаттынмаан. [Харыысалгадан ойталал](#харыысалгадан-ойталал) деп чүүлдү көрүңер.

## Аргалары

- **Discord-туң илередип болур бүгү чүүлдери.** Оюннар даңзызы Discord-туң ажык эндпоинтизинден кииртинип, локалдыг кэште шыгжаттынар болгаш хүн бүрү чаартынар. Чаа оюннар биле чаа немешкен күүседикчи файлдар боттары көстүп кээр.
- **Дораан дилээри.** Муң-муң оюннар аразындан оюннуң ады-биле азы күүседикчи файлы-биле дораан дилээр, плиткалар азы сырый даңзы хевири, шилип алганнар болгаш «Сөөлгүлер» одуруу.
- **Чаңгыс базыышкын-биле.** Оюнну шилиңер, күүседикчи файлын шилиңер (хас-даа бар болза), каш үе дургузунда тударын шилээш, эгеледирин базыңар. Деспиктиг таймер биле дыңнадыышкын үе төнгенде дыңнадыр.
- **Артында чүү-даа арттырбас.** Заглушка чүгле ажылдап турар үезинде бар болур: бичии exe эгелээринде чаяаттынар болгаш доктаадырга соп кагдынар. Программадан үнериңерге дөгерези доктаай бээр, а компүтер соксаан соонда арткан чүүлдер дараазында ажыдарда арыглаттынар.
- **Оожум.** Система трейинде олурар, заглушкалар боттары көрүнчүктер азы сорулгалар самбыразынга олуттар ээлевес.
- **Ажык очулгалар.** Интерфейс бөдүүн JSON файлдар-биле ажылдаар, ынчангаш чаа дыл немелгези — чүгле чаңгыс файл болур. Англи болгаш орус дылдар кирген.
- **Хууда медээлер камгалалы.** Аккаунт чок, Discord токени чок, телеметрия чок. [Хууда медээлер камгалалы](#хууда-медээлер-камгалалы) деп чүүлдү көрүңер.

## Ол канчаар ажылдаарыл

1. Discord компүтерде ажылдап турар процесстерни хынап, оларның күүседикчи файлдарының аттарын ажык даңзы-биле (`/api/v9/applications/detectable`) деңнеп, силерниң оюн ойнап турарыңарны илередир.
2. Decoy ол даңзыны хайгаарап киирип ааш, шилээн оюнуңарга даңзыдан күүседикчи файлдың адын ажыглап (чижээ, `.../cod26-cod.exe`), бичии заглушка-программаны (120 КБ хире, Rust дылга бижиттинген болгаш Decoy иштинче киирген) түр үениң папказынче көжүрүп каар.
3. Заглушка экрандан ырак чажырттынган дээди деңнелдиг чаңгыс көрүнчүктү тударындан өске чүү-даа кылбас, ынчангаш ону кажан-даа көрбес силер. Discord чүгле көрүнчүктүг процессти таныыр, көрүнчүк чок процесс аайлашпас.
4. 15 секунда иштинде Discord бо оюнну силерниң амгы ажыл-херээңер кылдыр көргүзүп эгелээр.
5. Таймер төнерге азы доктаадыр деп базыптарга, Decoy процессти доозуп, файлды соп каар. Windows-туң job объектизи Decoy хагдынарга (ол ышкаш халдаашкын болганда-даа) заглушкалар ооң-биле кады доостурун хандырар.

## Тургузары

[Releases](../../../../releases) арынындан бирээзин шилип алыңар:

| Киирип алыры | Чүге |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Тургузукчу (Installer).** Ажыглакчы бүрүзүнге, администратор эргелери херек чок, «Пуск» менюзунче бижикти болгаш соп каар программаны (uninstaller) немеп бээр. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативтиг.** Кандыг-даа черге чазып алгаш, `decoy.exe` файлын ажылдадыңар. Бүгү медээлер ооң чанында `data` папказынга чыдар, ажыглакчының профилинче чүү-даа бижиттинмес. Соп каар дээш, папканы соп кааптар. |

Киирген файлды `SHA256SUMS.txt` дузазы-биле хынап алыңар (PowerShell-ге `Get-FileHash <файл>`).

Windows SmartScreen сборкалар санныг хол үжүү-биле бадылаттынмаан болганда билдинмес үндүрүкчү дугайында сануулга берип болур; аңаа бүзүреп турар болзуңарза, *Оон ыңай медээ (More info) → Кандыг-даа бол ажылдадыр (Run anyway)* деп шилиңер.

Негелделер: WebView2 runtime баар Windows 10 азы 11 (64-бит) (Windows 11-де болгаш Windows 10-нуң сөөлгү чаартылгаларында киирген).

## Ажыглаары

1. **Библиотеканы** ажыткаш, оюнну дилеңер, азы кандыг-даа черден `Ctrl` + `K` базыңар.
2. Оюнче базыңар. Оң талакы панельге процессти болгаш ону каш минут дургузунда тударын шилиңер (Discord онаалгалары колдуунда 15 минут негээр).
3. **Заглушканы ажылдадыр** деп базыңар. Discord каш секунда болганда оюнну көргүзүп эгелээр.
4. Ону **Ажылдап турар** деп черге хайгаараңар, кажан-даа чаңгыс азы бүгү заглушкаларны доктаадып болур силер, азы Decoy-ну трейге артырып каап болур.

Discord даңзызында күүседикчи файлы амдыгааш чок оюннар үндезининде чажырттынган турар (оларны илередип болбас). Оларны көөр дизе, *Exe чок оюннарны көргүзер* деп чүүлдү ажыдыңар; даңзы хүн бүрү чаартынар, ынчангаш Discord процесс немээрге-ле олар дораан ажык апаар.

### Команда одуруу

```
decoy.exe --launch "<Discord даңзызындан күүседикчи файлдың оруу>" [минуттар]
```

Заглушканы дораан ажылдадыр, чижээ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Үндезин кодундан чыыры

Баштайгы негелделер: [Node.js](https://nodejs.org) 20+, Visual Studio C++ чыыр херекселдерлиг турум [Rust](https://rustup.rs) херекселдер чыындызы (MSVC target), болгаш WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # чаартынып турар сайзырадылга хевиринде ажылдадыр
npm run tauri build    # src-tauri/target/release/bundle/nsis иштинге тургузукчуну чаяар
```

Ажыктыг хыналдалар:

```bash
npm run check-locales  # очулга бүрүзүн ru.json-биле деңнеп хынаар
npx tsc --noEmit       # фронтендтиң типтерин хынаар
cargo check --manifest-path src-tauri/Cargo.toml
```

Тайылбырлар: заглушка exe-зи `src-tauri/build.rs` дузазы-биле `src-tauri/stub/stub.rs` файлындан бөдүүн `rustc`-биле чыгдынгаш, программа иштинче кииртинер. Фронтенд бөдүүн браузерге ажылдап турар үеде (`npm run dev`), бичии мок-бэкенд (`src/mock.ts`) ажыглаттынар, ол UI-биле ажылдаарынга эптиг.

## Очулгалар

Интерфейстиң сөстери [`src/locales`](../../src/locales) иштинде чыдар, дыл бүрүзүнге чаңгыс JSON файл (`en.json`, `ru.json`, ...).
Дыл немеэри — чүгле файл немеэри болур, кодче өскерис киирбес. Файлдың форматын, очулгага белен промпту болгаш хыналда скриптин көөр дизе [docs/TRANSLATING.md](../TRANSLATING.md) көрүңер. Бо README-ниң очулгалары `docs/i18n/README.<code>.md` папказынче киргизилер.

## Хууда медээлер камгалалы

- Decoy четкини чүгле Discord-туң ажык илередилге даңзызын киирип алырынга (баштайгы эгелээшкинде, оон хүнде бир катаптан хөй эвес азы чаартылганы басканда) болгаш оюннарның демдектерин, чуруктарын Discord-туң ажык CDN-инден көргүзеринге ажыглаар.
- Ол силерниң Discord токениңерни азы аккаунт медээлерин номчувас, шыгжавас, чоргузпас болгаш Discord клиентизи-биле харылзашпас.
- Таарыштырыглар (шилип алганнар, дыл, үелер) программаның WebView шыгжамырынга локалдыг шыгжаттынар; оюннар даңзызының кэши болгаш түр заглушка файлдары `%LOCALAPPDATA%\app.decoy.desktop` иштинде чыдар.
- Аналитика чок, халдаашкыннар отчёду чок, аккаунттар чок.

## Билдингир кызыгаарлаашкыннар

- Discord илередилгениң канчаар ажылдаарын кажан-даа өскертип болур. Бир эвес заглушка илереттинмес апарза, бажыңай, issue ажыдыңар.
- Чамдык ажыл-херектер чүгле ажылдап турар процессти эвес, оон-даа хөйнү негээр (чижээ, оюн платформазының тускай серверинде азы делегейинде турары). Decoy чүгле процессти өттүнүп көргүзер.
- Discord даңзызында күүседикчи файлы чок бижиктер илереттинмес.
- Камгалал программалары (антивирустар) оперативтиг сактыышкынга куруг олурар бичии бадылаттынмаан күүседикчи файлдарга сануулга берип болур. Заглушка ажык үндезин кодтуг болгаш `src-tauri/stub/stub.rs` файлындан чыгдынган; ону бодуңар чыып ап болур силер.

## Харыысалгадан ойталал

Decoy боттуң, өөредилге болгаш хыналда сорулгалар-биле «баар хевээр» бээрилге болур. Ажылдап турар оюнну өттүнүп көргүзери Discord-туң азы оюн үндүрүкчүзүнүң ажыглал негелделерин үреп болур болгаш силерниң аккаунтуңарга шииткелче чедирип болур. Ону канчаар ажыглаары силерниң харыысалгаңар болур. «Discord» болгаш бүгү оюн аттары, логотиптери оларның ээлериниң бараан демдектери болуп турар болгаш мында чүгле хамааржыр программаларны тодарадыр сорулга-биле ажыглаттынган.
