# Decoy

**Kleine stand-in processen die Discord laete dienke dat er 'n game draoit.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-bibliotheek mie recente games en artwork" />

</div>

Decoy ouwt 'n onschäedelek plekhouwend proces mie 'n venster draoiend onder de naem van 't uutvoerbaere bestand van 'n game, zodanig dat de gamedetectie van Discord toônt daj die game an 't speulen bint. Je 'oeft de echte game noôit te installeren of te starte, waedeur d'r niks groôts ruumte inneemt op je schieve.

't Kent **aolle games die Discord kan detectere** (ongeveêr 25.000 vermeldiengen) omda 't Discord z'n eihen oôpenbaere detectielieste uutleest en vanzelve bie de tied ouwt.

> [!WARNING]
> 't Naebootsen van 'n draoiende game kan tehen de Dienstveurwaerden van Discord inhaen en je gebruukt Decoy **op eihen risico**.
> Dit project is glad nie verbonden mie, 'oedgekeurd deu of an'esloten bie Discord Inc. Zie [Disclaimer](#disclaimer).

## Functies

- **Aolles wat Discord kan detectere.** De gamelieste wor 'edownload van Discord z'n oôpenbaere detectie-eindpunt, lokaol 'ecachet en daehelijks biewerkt. Nieuwe games en nieuw toegevoehde exe-bestanden verschienen vanzelf.
- **Rizzeltant zoeke.** Direct zoeke op gamenaem of exe tussen duzenden games, tegel- of compacte liestweêrgaeve, favorieten en 'n riehe mie "Recent".
- **Eên klik.** Kies 'n game, kies de exe (as d'r meêrdere bin), kies oô lange 't mot draoie en druk op starte. 'n Aftelrink en 'n meldienge laete wete wanneer d'n tied omme is.
- **Laet niks achter.** 'n Decoy bestaet allene zolank ie draoit: 't kleine exe-bestand wor 'emaekt bie 't starte en gewist bie 't stoppe. Aolles wor 'estopt as je stopt, en overbluuvsels nae 'n crash worre bie de voôhnde start op'eruumpd.
- **Rustig.** Zitte in 't systeemvak, geên vensters of taekbalknoppen vò de decoys zelluf.
- **Oôpen vertaeliengen.** De interface wor an'estierd deu geweune JSON-bestanden, dus 'n taele toevoehe is maer eên bestand. Iengels en Russisch bin inbegrepe.
- **Privacy.** Geên account, geên Discord-token, geên telemetrie. Zie [Privacy](#privacy).

## Oô 't werkt

1. Discord beslist daj 'n game an 't speulen bint deu te kieken nae de actieve processen op je computer en under exe-naemen te vergelieken mie 'n oôpenbaere lieste (`/api/v9/applications/detectable`).
2. Decoy downloadt die lieste en kopieert vò de 'ekozen game 'n klein stand-in-programmatje (ongeveêr 120 KB, 'eschreven in Rust en in'ebouwd in Decoy) nae 'n tiedeleke map onder de exe-naem uut de lieste, bievooarbeêld `.../cod26-cod.exe`.
3. 't Stand-in-programma doet glad niks buuten 't bezitte van eên oôgste-niveau venster, dat verre buuten 't scherm 'eparkeerd staet zodanig daj 't noôit ziet. Discord herkent allene 'n proces dat 'n venster ei; 'n proces glad zonder venster wor daerom genegeerd.
4. Binnen zo'n 15 seconjen toônt Discord de game as je actuele bezihied.
5. As de timer ofloôpt of je drukt op stoppe, beëindigt Decoy 't proces en wist 't bestand. 'n Windows job object zurgt d'rveur dat decoys saeme mie Decoy doôdgae, zelfs as Decoy crasht.

## Installaosie

Kies d'r eêne van de [Releases](../../../../releases)-pagina:

| Download | Vò |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installaosieprogramma.** Per gebruker, geên beheerdersrechten nôdig, voegt 'n vermeldieng toe an 't Startmenu en 'n verwiederprogramma. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Pak 't overal uut en start `decoy.exe`. Aolle data bluuft in de `data`-map d'rneffens, d'r wor niks nae je gebrukersprofiel 'eschreven. Doet de map weg om 't heêl te verwiederen. |

Controleer 'n download mie `SHA256SUMS.txt` (`Get-FileHash <bestand>` in PowerShell).

Windows SmartScreen kan waerschuwe vò 'n onbekende uutgever omda de builds nie digitaol 'ehandteêkend bin; kies *Meêr informatie → Toch uutvoere* as je de build vertrouwt.

Vereisten: Windows 10 of 11 (64-bit) mie de WebView2-runtime (aol anwezig in Windows 11 en recente Windows 10-updates).

## Gebruuk

1. Oôpen de **Bibliotheek** en zoek 'n game, of druk overal op `Ctrl` + `K`.
2. Klik op 'n game. Kies in 't rechterpaneel 't proces en oôveêl menuutn je 't wilt laete draoie (Discord-activiteiten vraehe meêstentieds 15 menuutn).
3. Druk op **Decoy starte**. Discord toônt de game nae 'n paer seconjen.
4. Volg 't onder **Draoit nu**, stop d'r eêne of aolles wanneer je wilt, of laet Decoy geweun in 't systeemvak staen.

Games waervan de Discord-fiche nog geên exe-bestanden ei, bin standaerdoms weggestoopt (ze kunne nie 'edetecteerd worre). Zet *Games zonder exe toône* an om ze te ziene; de lieste wor daehelijks biewerkt, dus ze worre beschikbaar zodra Discord 'n proces toevoegt.

### Commandorehiel

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Start direct 'n decoy, bievooarbeêld `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bouwe vanof broncode

Vereisten: [Node.js](https://nodejs.org) 20+, de stabiele [Rust](https://rustup.rs)-toolchain (MSVC-target) mie de Visual Studio C++ build tools, en de WebView2-runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # draoie in ontwikkelmodus mie hot reload
npm run tauri build    # maekt de installer in src-tauri/target/release/bundle/nsis
```

Nuttige controles:

```bash
npm run check-locales  # valideer elk vertaelbestand tehen ru.json
npx tsc --noEmit       # type-check van de frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Opmerkiengen: 't decoy-exe-bestand wor 'ecompileerd deu `src-tauri/build.rs` mie geweune `rustc` vanuut `src-tauri/stub/stub.rs` en daernae in'ebouwd in de app. Wanneer de frontend in 'n geweune browser draoit (`npm run dev`), wor d'r 'n kleine mock-backend (`src/mock.ts`) gebruukt, wat handig is om an de UI te werke.

## Vertaeliengen

De interfacestriengs staen in [`src/locales`](../../src/locales), eên JSON-bestand per taele (`en.json`, `ru.json`, ...).
'n Taele toevoehe beteêkent enkel 'n bestandje toevoehe; geên codewiezihiengen nôdig. Zie [docs/TRANSLATING.md](../TRANSLATING.md) vò 't bestandsformaot, 'n klaere prompt vò machinevertaelieng en 't controlescript. Vertaeliengen van deêze README gaen nae `docs/i18n/README.<code>.md`.

## Projectindeêlienge

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)

  src/lib.rs            game database, decoy processes, tray

```

## Privacy

- Decoy gebruukt 't netwerk allene om Discord z'n oôpenbaere detectielieste te downloade (bie d'n eêste start, daernae oôhgstens eên keêr per dag of wanneer je op biewerke drukt) en om gamepictogrammen en artwork van Discord z'n oôpenbaere CDN te laete ziene.
- 't Leest, bewaert of verstuurt je Discord-token of accountgegevens nie, en praet nie mie de Discord-client.
- Instelliengen (favorieten, taele, tiedsduur) worre lokaol op'eslaehen in de WebView-opslag van de app; de cache van de gamelieste en tiedeleke decoy-bestanden staen in `%LOCALAPPDATA%\app.decoy.desktop`.
- Geên analyses, geên crashrapporterienge, geên accounts.

## Bekende beperkiengen

- Discord kan op elk moment verandere oô detectie werkt. As 'n decoy nie meêr 'erkend wor, oôpen dan gerust 'n issue.
- Sommige activiteiten è meêr nôdig as allene 'n draoiend proces (bievooarbeêld binnen 'n specifieke belevinge van 'n spelplatform zitte). Decoy bootst enkel 't proces nae.
- Vermeldiengen zonder exe-bestanden in de lieste van Discord kunne nie 'edetecteerd worre.
- Beveiligingssoftware markeert soms kleine, nie-'ehandteêkende exe-bestanden die rustig in 't geheugen staen. De decoy is open source en 'ebouwd vanuut `src-tauri/stub/stub.rs`; je kan 'm zelluf compileêre.
