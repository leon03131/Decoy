# Decoy

**Гыццыл процесс-заглушкæтæ, кæцыты руаджы Discord хъазт кусгæ æнхъæлы.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотекæ фæстаг хъæзтытимæ æмæ нывтæмæ" />

</div>

Decoy æдас, рудзынгимæ decoy процесс дары хъазты æххæстгæнæг файлы номимæ, уымæ гæсгæ Discord-ы
хъазт сбæрæг кæныны системæ дæ æвдисы ацы хъазтæй хъазгæ. Дæхæдæг æцæг хъазт сæвæрын кæнæ райдайын нæ хъæуы,
æмæ дискыл ницы стырдзинад баззайы.

Уый зоны **алкæцы хъазты тыххæй, кæцы Discord сбæрæг кæны** (25 000 бæрц фыстытæ), уымæн æмæ Discord-ы йæхи
æхсæнадон бæрæггæнæнты номхыгъд кæсы æмæ йæ йæхæдæг æдзух ног кæны.

> [!WARNING]
> Кусгæ хъазты имитаци кæнын гæнæн ис Discord-ы Пайдакæныны домæнтæм ныхмæ уа, æмæ Decoy-æй пайда кæныс **дæхи бæрныл**.
> Ацы проект Discord Inc.-имæ баст нæу, уыдонæй нæу къухфыст кæнæ æххуыстгонд. Кæс [Бæрндзинадæй æрвитæн](#бæрндзинадæй-æрвитæн).

## Миниуджытæ

- **Алцыдæр, цæй бæрæг кæнын Discord-æн йæ бон у.** Хъæзты номхыгъд æрбавгæд цæуы Discord-ы æхсæнадон ратæдзæнæй, бынаты
  кæшгонд æрцæуы æмæ алы бон ног кæны. Ног хъæзтытæ æмæ ног æххæстгæнæг файлтæ сæхæдæг фæзынынц.
- **Тагъд агуырд.** Тагъд агуырд хъазты номæй кæнæ æххæстгæнæг файлæй мингай хъæзтыты 'хсæн, плиткæтæй кæнæ æнгом
  номхыгъдæй, æвзæрст æмæ «Фæстагмæ» рæнхъ.
- **Иу æрхæцынæй.** Равзар хъазт, равзар æххæстгæнæг файл (бирæ куы уой), сбæрæг кæн цас минут дарын æмæ æрхæц «Decoy райдайын».
  Фæстæмæ нымайæн къулбас æмæ хъусынгæнинаг дзурдзысты, рæстæг куы ахицæн уа, уæд.
- **Фæдыл ницы ныууадзы.** Decoy æрмæст кусгæйæ ис: гыццыл exe равзæры райдайыныл æмæ ахафы
  урæдыл. Программæйæ рацыдæй иууылдæр фæурыйынц, бакъуылымпыйы фæстæ баззайæгтæ та сDaily кæнынц дарддæры байгомыл.
- **Сабыр.** Системæйы трейы цæры, decoy-тæн сæхæдæг рудзгуытæ кæнæ куысты фæйнæгыл төбæтæ нæй.
- **Гом тæлмацтæ.** Интерфейс кусы хуымæтæг JSON файлтыл, уымæ гæсгæ æвзаг баххæст кæнын у æрмæст иу файл.
  Англисаг æмæ уырыссаг ныридæгæн сты.
- **Хибардзинад.** Аккаунт нæй, Discord токен нæй, телеметри нæй. Кæс [Хибардзинад](#хибардзинад).

## Куыд кусы

1. Discord сбæрæг кæны, хъазтæй хъазгæ кæй дæ, дæ компьютеры кусгæ процесстæ фæлгæсгæйæ æмæ сæ æххæстгæнæг
   файлты нæмттæ æхсæнадон номхыгъдимæ бабар кæнгæйæ (`/api/v9/applications/detectable`).
2. Decoy уыцы номхыгъд æрбавгæны æмæ дæ равзæрст хъазтæн гыццыл decoy программæ (120 КБ бæрц, фыст
   Rust-ыл æмæ баст Decoy мидæг) рæстæгмæ папкæмæ скъопи кæны номхыгъды æххæстгæнæг файлы номимæ, зæгъæм
   `.../cod26-cod.exe`.
3. Decoy ницы кæны, иу уæлдæр æмвæзады рудзынг дарыны йеддæмæ, кæцы экраны фалейæ дард æвæрд у,
   уымæ гæсгæ уый никуы уындзынæ. Discord æрмæст рудзынг кæмæн ис, ахæм процесс бæрæг кæны, æнæ рудзынг процесс та ныууадзы.
4. 15 секунды бæрцмæ Discord хъазт дæ нырыккон архайды бынаты фæзынын кæндзæн.
5. Таймер куы ахицæн уа кæнæ урæды төбæйыл куы æрхæцай, Decoy процесс фæууы æмæ файл ахафы. Windows job object
   сбæрæг кæны, цæмæй decoy-тæ Decoy-имæ иумæ фесæфой, суанг æнæнхъæлæджы сæхгæд куы уа, уæддæр.

## Æвæрын

Равзар вариант [Релизты](../../../../releases) фарсæй:

| Æрбавгæнын | Кæмæн |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Æвæрæн программæ.** Иу архайæгæн, администраторы бартæ нæ хъæуы, «Пуск» менюмæ фæзыны æмæ деинсталлятор ис. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативон.** Басæт алы ран æмæ байгом кæн `decoy.exe`. Иууылдæр бæрæггæнæнтæ йæ фарсмæ `data` папкæйы дард вæййынц, архайæджы профильмæ ницы фыссы. Схафынæн æрмæст папкæ схаф. |

Æрбавгæд файл сбæрæг кæн `SHA256SUMS.txt`-имæ (`Get-FileHash <файл>` PowerShell-ы).

Windows SmartScreen гæнæн ис фæдзæхса æнæбæрæг рауадзæгыл, уымæн æмæ сæм цифрон къухфыст нæй; равзар
*Фылдæр информаци → Баххæст кæнын алы хабарæй дæр*, кæд æмбырдмæ æууæндыс.

Домæнтæ: Windows 10 кæнæ 11 (64-бит) WebView2 runtime-имæ (ныридæгæн ис Windows 11-ы æмæ фæстаг
Windows 10 ноггæндты).

## Пайда кæнын

1. Байгом кæн **Библиотекæ** æмæ агур хъазт, кæнæ æрхæц `Ctrl` + `K` кæцыфæнды ран.
2. Æрхæц хъазтыл. Рахиз панелы равзар процесс æмæ цас минут дарын хъæуы (Discord архæйдтытæн
   арæх 15 хъæуы).
3. Æрхæц **Decoy райдайын**. Discord хъазт фæзынын кæндзæн цалдæр секундмæ.
4. Кæс уымæ **Кусы** вкладкæйы, уромын гæнæн ис иу кæнæ иууылдæр кæцыфæнды рæстæг, кæнæ Decoy трейы ныууадз.

Хъæзтытæ, кæцыты Discord базæйы нырма æххæстгæнæг файлтæ нæй, æмбæрхст сты æвæрдæй (уыдон сбæрæг кæнæн нæй). Баиу кæн
*Æнæ exe хъæзтытæ æвдисын*, цæмæй сæ фенай; номхыгъд алы бон ног кæны, уымæ гæсгæ уыдон фæзындзысты, Discord
процесс куы баххæст кæна, уæд.

### Командæйы рæнхъ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy уайтагъд райдайы, зæгъæм `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сборкæ равзæрæнæй

Хъæугæ фæрæзтæ: [Node.js](https://nodejs.org) 20+, æнцойджын [Rust](https://rustup.rs) фæрæзты къорд (MSVC нысан) Visual Studio
C++ сборкæйы инструменттимæ, æмæ WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Пайдаджын бæрæггæнæнтæ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Фиппаинæгтæ: decoy exe æмбырд кæны `src-tauri/build.rs` хуымæтæг `rustc`-йæ `src-tauri/stub/stub.rs`-æй æмæ уый фæстæ
программæмæ баст цæуы. Фронтенд хуымæтæг браузеры куы кусы (`npm run dev`), уæд гыццыл mock-бэкендæй
(`src/mock.ts`) пайда цæуы, уый тынг æнцон у UI куыстæн.

форматы, машинæйы тæлмацы цæттæ промпты æмæ бæрæг кæныны скрипты тыххæй. Ацы README-йы тæлмацтæ цæуынц
`docs/i18n/README.<code>.md`-мæ.

## Хибардзинад

- Decoy хызæй пайда кæны æрмæст Discord-ы æхсæнадон бæрæггæнæнты номхыгъд æрбавгæнынæн (фыццаг райдайыныл, стæй бон иу хаттæй арæхдæр нæ,
