# Decoy

**Discord က ဂိမ်းတစ်ခု လည်ပတ်နေသည်ဟု ထင်မှတ်စေရန် ပြုလုပ်ပေးသည့် သေးငယ်သော အစားထိုး လုပ်ငန်းစဉ်များ။**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="လတ်တလော ဂိမ်းများနှင့် မျက်နှာဖုံးပုံများ ပါဝင်သော Decoy စာကြည့်တိုက်" />

</div>

Decoy သည် ဂိမ်းတစ်ခု၏ executable အမည်အောက်တွင် အန္တရာယ်မရှိသော၊ ဝင်းဒိုးတစ်ခုပါဝင်သည့် နေရာယူထားသော လုပ်ငန်းစဉ်ကို လည်ပတ်စေခြင်းဖြင့် Discord ၏ ဂိမ်းစစ်ဆေးမှုစနစ်က သင့်အား ထိုဂိမ်းကို ဆော့ကစားနေသည်ဟု ပြသစေပါသည်။ ဂိမ်းအစစ်ကို ထည့်သွင်းရန် သို့မဟုတ် စတင်ရန် မလိုအပ်သောကြောင့် သင့်ဒစ်ခ်ထဲတွင် နေရာအများကြီး ယူထားခြင်း မရှိပါ။

Discord စစ်ဆေးသိရှိနိုင်သော အများသုံးစာရင်းကို ဖတ်ရှုပြီး သူ့အလိုအလျောက် အမြဲတမ်း အသစ်တင်ပေးနေသောကြောင့် **Discord သိရှိနိုင်သော ဂိမ်းတိုင်းနီးပါး** (ခန့်မှန်းခြေ စာရင်း ၂၅,၀၀၀ ခန့်) ကို သိရှိနိုင်ပါသည်။

> [!WARNING]
> လည်ပတ်နေသော ဂိမ်းတစ်ခုကို အတုအယောင်ပြုလုပ်ခြင်းသည် Discord ၏ ဝန်ဆောင်မှုစည်းမျဉ်းများနှင့် ဆန့်ကျင်နိုင်ပြီး Decoy ကို အသုံးပြုခြင်းသည် **သင့်ကိုယ်ပိုင် တာဝန်သာ ဖြစ်ပါသည်**။
> ဤပရောဂျက်သည် Discord Inc. နှင့် သက်ဆိုင်ခြင်း၊ ထောက်ခံချက်ရယူထားခြင်း သို့မဟုတ် ချိတ်ဆက်ထားခြင်း မရှိပါ။ [တာဝန်ကင်းလွတ်ခွင့်](#တာဝန်ကင်းလွတ်ခွင့်) ကို ကြည့်ပါ။

## လုပ်ဆောင်ချက်များ

- **Discord စစ်ဆေးသိရှိနိုင်သမျှ အရာအားလုံး။** ဂိမ်းစာရင်းကို Discord ၏ အများသုံး detection endpoint မှ ဒေါင်းလုဒ်လုပ်ပြီး၊ စက်ထဲတွင် သိမ်းဆည်းကာ နေ့စဉ် အသစ်တင်ပေးပါသည်။ ဂိမ်းအသစ်များနှင့် အသစ်ထည့်သွင်းထားသော executable များသည် သူ့အလိုအလျောက် ပေါ်လာမည်ဖြစ်ပါသည်။
- **အမြန်ဆုံး ရှာဖွေနိုင်မှု။** ထောင်ပေါင်းများစွာသော ဂိမ်းများထဲမှ ဂိမ်းအမည် သို့မဟုတ် executable ဖြင့် ချက်ချင်းရှာဖွေနိုင်ခြင်း၊ အကွက်ပုံစံ သို့မဟုတ် စာရင်းပုံစံဖြင့် ကြည့်ရှုနိုင်ခြင်း၊ စိတ်ကြိုက်များနှင့် "လတ်တလော" အတန်း ပါဝင်ခြင်း။
- **ကလစ်တစ်ချက်နှိပ်ရုံသာ။** ဂိမ်းတစ်ခုကို ရွေးပါ၊ executable (အများအပြားရှိပါက) ကို ရွေးပါ၊ မည်မျှကြာကြာ လည်ပတ်ထားမည်ကို ရွေးချယ်ပြီး စတင်ပါကို နှိပ်ပါ။ အချိန်ပြည့်သွားပါက countdown စက်ဝိုင်းနှင့် အသိပေးချက်တို့က သင့်အား အသိပေးပါမည်။
- **ဘာမှ ကျန်ရစ်မနေစေပါ။** decoy သည် လည်ပတ်နေစဉ်အတွင်းသာ တည်ရှိပါသည်- သေးငယ်သော exe ကို စတင်ချိန်တွင် ဖန်တီးပြီး ရပ်တန့်ချိန်တွင် ဖျက်ပစ်ပါသည်။ သင် အက်ပ်မှ ထွက်ခွာသည့်အခါ အရာအားလုံးကို ရပ်တန့်ပေးပြီး ချို့ယွင်းချက်ကြောင့် ကျန်ခဲ့သော အရာများကိုလည်း နောက်တစ်ကြိမ် ဖွင့်ချိန်တွင် ရှင်းလင်းပေးပါသည်။
- **အနှောင့်အယှက်ကင်းခြင်း။** system tray ထဲတွင် တည်ရှိပြီး၊ decoy များအတွက် သီးခြား ဝင်းဒိုးများ သို့မဟုတ် taskbar ခလုတ်များ မရှိပါ။
- **လွတ်လပ်စွာ ဘာသာပြန်ဆိုနိုင်ခြင်း။** အင်တာဖေ့စ်ကို ရိုးရှင်းသော JSON ဖိုင်များဖြင့် လုပ်ဆောင်ထားသောကြောင့် ဘာသာစကားအသစ် ထည့်သွင်းရာတွင် ဖိုင်တစ်ခုတည်းသာ လိုအပ်ပါသည်။ အင်္ဂလိပ်နှင့် ရုရှားဘာသာစကားများ ပါဝင်ပြီးဖြစ်ပါသည်။
- **လုံခြုံစိတ်ချရသော ကိုယ်ရေးကိုယ်တာ။** အကောင့် မလိုအပ်ပါ၊ Discord token မလိုအပ်ပါ၊ မည်သည့် telemetry အချက်အလက်မှ စုဆောင်းခြင်း မရှိပါ။ [ကိုယ်ရေးကိုယ်တာ](#ကိုယ်ရေးကိုယ်တာ) ကို ကြည့်ပါ။

## လုပ်ဆောင်ပုံ အဆင့်ဆင့်

1. Discord သည် သင့် PC ပေါ်တွင် လည်ပတ်နေသော လုပ်ငန်းစဉ်များကို စစ်ဆေးပြီး ၎င်းတို့၏ executable အမည်များကို အများသုံးစာရင်း (`/api/v9/applications/detectable`) နှင့် နှိုင်းယှဉ်ကာ သင် ဂိမ်းဆော့နေကြောင်း ဆုံးဖြတ်ပါသည်။
2. Decoy သည် ထိုစာရင်းကို ဒေါင်းလုဒ်လုပ်ပြီး သင်ရွေးချယ်သော ဂိမ်းအတွက် အစားထိုး အစီအစဉ်ငယ် (Rust ဖြင့် ရေးသားထားပြီး Decoy တွင် ထည့်သွင်းထားသော ၁၂၀ KB ခန့်) ကို စာရင်းထဲမှ executable အမည်ဖြင့် ယာယီဖိုဒါသို့ ကူးယူပါသည် (ဥပမာ `.../cod26-cod.exe`)။
3. အဆိုပါ အစားထိုးပရိုဂရမ်သည် သင် မမြင်နိုင်စေရန် ဖန်သားပြင်၏ အဝေးတစ်နေရာတွင် ထားရှိထားသော top-level ဝင်းဒိုးတစ်ခုကို ဖွင့်ထားခြင်းမှလွဲ၍ အခြားဘာမှ မလုပ်ဆောင်ပါ။ Discord သည် ဝင်းဒိုးပိုင်ဆိုင်သော လုပ်ငန်းစဉ်ကိုသာ အသိအမှတ်ပြုသောကြောင့် ဝင်းဒိုးမရှိသော လုပ်ငန်းစဉ်ကို လျစ်လျူရှုထားခြင်း ဖြစ်ပါသည်။
4. ခန့်မှန်းခြေ ၁၅ စက္ကန့်အတွင်း Discord သည် အဆိုပါ ဂိမ်းကို သင်၏ လက်ရှိလှုပ်ရှားမှုအဖြစ် ပြသပေးပါမည်။
5. အချိန်မှတ်စနစ် ပြီးဆုံးသွားသည့်အခါ သို့မဟုတ် သင် ရပ်တန့်မည်ကို နှိပ်သည့်အခါ Decoy သည် လုပ်ငန်းစဉ်ကို အဆုံးသတ်ပြီး ဖိုင်ကို ဖျက်ပစ်ပါသည်။ Windows job object သည် Decoy ပျက်ကျသွားသည့်တိုင်အောင် decoy များကို Decoy နှင့်အတူ ရပ်တန့်စေရန် သေချာစေပါသည်။

## ထည့်သွင်းခြင်း

[Releases](../../../../releases) စာမျက်နှာမှ တစ်ခုခုကို ရွေးချယ်ပါ-

| ဒေါင်းလုဒ် | အသုံးပြုရန် |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installer။** သုံးစွဲသူအလိုက် ထည့်သွင်းခြင်းဖြစ်ပြီး administrator ခွင့်ပြုချက် မလိုအပ်ပါ၊ Start menu တွင် ဖြတ်လမ်းနှင့် uninstaller ထည့်သွင်းပေးပါသည်။ |
| `Decoy_x.y.z_x64-portable.zip` | **Portable။** မည်သည့်နေရာတွင်မဆို ဖြည်ချပြီး `decoy.exe` ကို ဖွင့်ပါ။ အချက်အလက်အားလုံးသည် ၎င်းဘေးရှိ `data` ဖိုဒါထဲတွင်သာ ရှိနေပြီး သင့် user profile ထဲသို့ မည်သည့်အရာမှ ရေးသားမည် မဟုတ်ပါ။ ဖယ်ရှားလိုပါက အဆိုပါ ဖိုဒါကို ဖျက်လိုက်ရုံသာ ဖြစ်ပါသည်။ |

ဒေါင်းလုဒ်ရယူထားသော ဖိုင်ကို `SHA256SUMS.txt` ဖြင့် စစ်ဆေးပါ (PowerShell တွင် `Get-FileHash <file>`)။

တည်ဆောက်ထားသော build များသည် code sign ပြုလုပ်ထားခြင်း မရှိသောကြောင့် Windows SmartScreen က အသိအမှတ်မပြုသော ပရိုဂရမ်ထုတ်လုပ်သူအဖြစ် သတိပေးနိုင်ပါသည်၊ ဖိုင်ကို ယုံကြည်ပါက *More info → Run anyway* ကို ရွေးချယ်ပါ။

စနစ်လိုအပ်ချက်များ- WebView2 runtime ပါဝင်သော Windows 10 သို့မဟုတ် 11 (64-bit) (Windows 11 နှင့် လတ်တလော Windows 10 update များတွင် ထည့်သွင်းပြီးဖြစ်ပါသည်)။

## အသုံးပြုနည်း

1. **စာကြည့်တိုက်** ကို ဖွင့်ပြီး ဂိမ်းတစ်ခုကို ရှာဖွေပါ၊ သို့မဟုတ် မည်သည့်နေရာမှမဆို `Ctrl` + `K` ကို နှိပ်ပါ။
2. ဂိမ်းတစ်ခုကို နှိပ်ပါ။ ညာဘက်ခြမ်းရှိ panel တွင် လုပ်ငန်းစဉ်နှင့် မည်မျှကြာကြာ (မိနစ်) ဖွင့်ထားမည်ကို ရွေးပါ (Discord quest များသည် ပုံမှန်အားဖြင့် ၁၅ မိနစ် လိုအပ်ပါသည်)။
3. **Decoy စတင်မည်** ကို နှိပ်ပါ။ Discord သည် စက္ကန့်အနည်းငယ်အတွင်း ဂိမ်းကို ပြသပေးပါမည်။
4. **လည်ပတ်နေဆဲ** အောက်တွင် ကြည့်ရှုပါ၊ တစ်ခုချင်းစီ သို့မဟုတ် အားလုံးကို အချိန်မရွေး ရပ်တန့်နိုင်ပါသည်၊ သို့မဟုတ် Decoy ကို tray ထဲတွင် ထားရှိနိုင်ပါသည်။

Discord စာရင်းတွင် executable မပါရှိသေးသော ဂိမ်းများကို မူလအားဖြင့် ဝှက်ထားပါသည် (၎င်းတို့ကို စစ်ဆေးသိရှိ၍ မရနိုင်ပါ)။ ၎င်းတို့ကို မြင်တွေ့လိုပါက *exe မရှိသော ဂိမ်းများကို ပြမည်* ကို ဖွင့်ပါ၊ စာရင်းကို နေ့စဉ် အသစ်တင်ပေးသောကြောင့် Discord က လုပ်ငန်းစဉ် ထည့်သွင်းပေးလိုက်သည်နှင့် အသုံးပြုနိုင်မည်ဖြစ်ပါသည်။

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy ကို ချက်ချင်း စတင်ပါသည်၊ ဥပမာ `decoy.exe --launch "robloxplayerbeta.exe" 15`။

## Source code မှ တည်ဆောက်ခြင်း

ကြိုတင်လိုအပ်ချက်များ- [Node.js](https://nodejs.org) 20+, Visual Studio C++ build tools ပါဝင်သော တည်ငြိမ်သည့် [Rust](https://rustup.rs) toolchain (MSVC target) နှင့် WebView2 runtime။

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

အသုံးဝင်သော စစ်ဆေးမှုများ-

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

မှတ်ချက်များ- decoy exe ကို `src-tauri/stub/stub.rs` မှ သာမန် `rustc` ဖြင့် `src-tauri/build.rs` က compile လုပ်ပြီး အက်ပ်ထဲသို့ ထည့်သွင်းထားပါသည်။ Frontend ကို သာမန် browser တွင် လည်ပတ်သည့်အခါ (`npm run dev`) အသေးစား mock backend (`src/mock.ts`) ကို အသုံးပြုထားသောကြောင့် UI ရေးဆွဲရာတွင် အဆင်ပြေစေပါသည်။

## ဘာသာပြန်ဆိုမှုများ

UI စာသားများသည် [`src/locales`](../../src/locales) တွင် ဘာသာစကားတစ်ခုလျှင် JSON ဖိုင်တစ်ခုစီဖြင့် တည်ရှိပါသည် (`en.json`၊ `ru.json` စသည်ဖြင့်)။ ဘာသာစကားအသစ် ထည့်သွင်းရာတွင် ဖိုင်တစ်ခု ဖြည့်စွက်ရုံသာဖြစ်ပြီး ကုဒ်ပြင်ဆင်ရန် မလိုပါ။ ဖိုင်ပုံစံ၊ စက်ဖြင့် ဘာသာပြန်ရန် အသင့်သုံး prompt နှင့် စစ်ဆေးသည့် script အတွက် [docs/TRANSLATING.md](../TRANSLATING.md) ကို ကြည့်ပါ။ ဤ README ၏ ဘာသာပြန်ဆိုချက်များကို `docs/i18n/README.<code>.md` တွင် ထားရှိပါသည်။

## ပရောဂျက် ဖွဲ့စည်းပုံ

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)

src-tauri/              Rust backend (Tauri 2)

scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## ကိုယ်ရေးကိုယ်တာ

- Decoy သည် အင်တာနက်ကွန်ရက်ကို Discord ၏ အများသုံး detection list အား ဒေါင်းလုဒ်လုပ်ရန် (ပထမဆုံးအကြိမ် စတင်ချိန်၊ ထို့နောက် အများဆုံး တစ်ရက်လျှင် တစ်ကြိမ် သို့မဟုတ် အသစ်တင်မည်ကို နှိပ်သည့်အခါ) နှင့် Discord ၏ အများသုံး CDN မှ ဂိမ်းအိုင်ကွန်များနှင့် မျက်နှာဖုံးပုံများကို ပြသရန်အတွက်သာ အသုံးပြုပါသည်။
- သင့် Discord token သို့မဟုတ် မည်သည့် အကောင့်ဒေတာကိုမျှ ဖတ်ရှုခြင်း၊ သိမ်းဆည်းခြင်း သို့မဟုတ် ပေးပို့ခြင်း မပြုလုပ်သလို Discord client နှင့်လည်း ဆက်သွယ်ခြင်း မရှိပါ။
- ဆက်တင်များ (စိတ်ကြိုက်များ၊ ဘာသာစကား၊ ကြာချိန်များ) ကို အက်ပ်၏ WebView သိုလှောင်မှုထဲတွင် စက်တွင်း၌သာ သိမ်းဆည်းထားပြီး ဂိမ်းစာရင်း cache နှင့် ယာယီ decoy ဖိုင်များသည် `%LOCALAPPDATA%\app.decoy.desktop` တွင် ရှိပါသည်။
- မည်သည့် analytics၊ crash reporting နှင့် အကောင့်စနစ်မျှ မပါဝင်ပါ။

## သိရှိထားသော ကန့်သတ်ချက်များ

- Discord သည် စစ်ဆေးသိရှိမှု လုပ်ဆောင်ပုံကို အချိန်မရွေး ပြောင်းလဲနိုင်ပါသည်။ decoy တစ်ခုကို စစ်ဆေးသိရှိခြင်း မရှိတော့ပါက ကျေးဇူးပြု၍ issue တစ်ခု ဖွင့်ပေးပါ။
- အချို့သော လှုပ်ရှားမှုများသည် လုပ်ငန်းစဉ်တစ်ခု လည်ပတ်နေရုံထက် ပိုမိုလိုအပ်ပါသည် (ဥပမာ ဂိမ်းပလက်ဖောင်းတစ်ခု၏ သီးခြား experience တစ်ခုအတွင်း ရှိနေခြင်း)။ Decoy သည် လုပ်ငန်းစဉ်ကိုသာ တုပပေးနိုင်ပါသည်။
- Discord စာရင်းတွင် executable မရှိသော အချက်အလက်များကို စစ်ဆေးသိရှိနိုင်မည် မဟုတ်ပါ။
- လုံခြုံရေးဆော့ဖ်ဝဲလ်များသည် memory ထဲတွင် ငြိမ်သက်စွာ ရပ်တန့်နေသော code-sign မလုပ်ထားသည့် executable အသေးစားများကို ရံဖန်ရံခါ သတိပေးတတ်ပါသည်။ decoy သည် open source ဖြစ်ပြီး `src-tauri/stub/stub.rs` မှ တည်ဆောက်ထားသောကြောင့် သင်ကိုယ်တိုင်လည်း compile လုပ်နိုင်ပါသည်။

## တာဝန်ကင်းလွတ်ခွင့်

Decoy ကို ကိုယ်ပိုင်၊ ပညာရေးနှင့် စမ်းသပ်လေ့လာမှု ရည်ရွယ်ချက်များအတွက် "ရှိရင်းစွဲအတိုင်း" ပံ့ပိုးပေးထားပါသည်။ လည်ပတ်နေသော ဂိမ်းတစ်ခုကို အတုအယောင်ပြုလုပ်ခြင်းသည် Discord သို့မဟုတ် ဂိမ်းထုတ်ဝေသူ၏ ဝန်ဆောင်မှုစည်းမျဉ်းများကို ချိုးဖောက်ရာရောက်နိုင်ပြီး သင့်အကောင့်အပေါ် အရေးယူမှုများ ဖြစ်ပေါ်စေနိုင်ပါသည်။ ၎င်းကို သင် မည်သို့အသုံးပြုသည်ဆိုခြင်းမှာ သင့်တွင်သာ လုံးလုံးတာဝန်ရှိပါသည်။ "Discord" နှင့် ဂိမ်းအမည်များ၊ လိုဂိုများအားလုံးသည် သက်ဆိုင်ရာ ပိုင်ရှင်များ၏ ကုန်အမှတ်တံဆိပ်များဖြစ်ပြီး ဤနေရာတွင် ၎င်းတို့ ရည်ညွှန်းသော ဆော့ဖ်ဝဲလ်ကို ခွဲခြားဖော်ပြရန်အတွက်သာ အသုံးပြုထားခြင်း ဖြစ်ပါသည်။
