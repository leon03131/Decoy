# Decoy

**Małke zastupne procesy, kótarež daju Discordoju měniś, až graśe běžy.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteka Decoy ze slědnymi graśami a wobrazami" />

</div>

Decoy wobchowujo nješkódny zástupny proces z woknom pód mjenim wuwjeźomneje dataje graśa w běgu, tak až spóznawanje graśow w Discordźe powěda, až toś to graśe grajośo. Nigda njetrjebaśo prawe graśe instalěrowaś abo startowaś, togodla na wašom plaśe nic wjelikego njelěžy.

Wón wě wó **kuždem graśu, kótarež Discord móžo spóznaś** (něźi 25.000 zapiskow), dokulaž cytajo swójsku zjawnú lisćinu spóznawanja Discorda a wobchowujo ju sam zaktualizěrowanu.

> [!WARNING]
> Falsowanje běžécego graśa móžo pśetergowaś wuměnjenja słužby Discorda a wužywaśo Decoy **na swójske riziko**.
> Toś ten projekt njejo zwězany z Discord Inc., njebu wót njogo pódpěrany ani z nim zjadnośony. Glědajśo [Wuzamknjenje zamólwitosći](#wuzamknjenje-zamólwitosći).

## Funkcije

- **Wšykno, což Discord móžo spóznaś.** Lisćina graśow se ze zjawnego spóznawańskego dypka Discorda ześěgujo, lokalnje pufrujo a kuždy źeń wobnowja. Nowe graśa a nowo pśidane wuwjeźomne dataje zjawiju se same wót sebie.
- **Pytanje, kótarež drochu wobchowujo.** Spěšne pytanje pó mjenju graśa abo wuwjeźomnej dataji mjazy tysacami graśow, pśeglěd w kachlach abo kompaktnej lisćinje, favority a smuga „Slědne“.
- **Jadno kliknjenje.** Wubjeŕśo graśe, wubjeŕśo wuwjeźomnu dataju (jolic jo jich wěcej), wubjeŕśo, kak dłujko ma se wobchowaś, a tłocćo na start. Wótběgowy krug a zdźělenje wam powědajotej, gaž cas wuběžy.
- **Njezawóstaja nic za sobu.** Decoy eksistěrujo jano tak dłujko, ako běžy: małki exe se pśi starśe napóra a pśi zastajenju wulašujo. Wšykno se zastaji, gaž nałoženje skóńcyśo, a zbytki pó spaźe se pśi pśiducem starśe wumjetu.
- **Śichy.** Běžy w pódawkowem rumje (system tray), bźez woknow abo tłocankow na rynce nadawkow za decoye same.
- **Wótwórjone pśełožki.** Pówjerch se pśez proste JSON-dataje rědujo, togodla jo pśidaśe rěcy jano jadna dataja. Engelšćina a rušćina stej zapśijetej.
- **Priwatnosć.** Žeden konto, žeden Discord-token, žedna telemetrija. Glědajśo [Priwatnosć](#priwatnosć).

## Kak to funkcioněrujo

1. Discord rozsuźijo, až graśe grajośo, pśez to až pśeglědujo procesy běžece na wašom PC a pśirownowujo jich mjenja wuwjeźomnych datajow ze zjawnú lisćinu (`/api/v9/applications/detectable`).
2. Decoy ześěgnjo toś tu lisćinu a skopěrujo za wubrane graśe małki zástupny program (něźi 120 KB, napisany w Rusće a zapśijety do Decoy) do nachylnego rědnika z mjenim wuwjeźomneje dataje z lisćiny, na pśikład `.../cod26-cod.exe`.
3. Zástupny program njecyni nic druge ako wobchowaś jadno wokno nejwušeje rowniny, parkowane daloko mimo wobrazowki, tak až jen nigda njewiźiśo. Discord spóznawa jano proces, kótaryž ma wokno, togodla se proces cele bźez woknow ignorěrujo.
4. Bźez małego za něźi 15 sekundow Discord pokažo graśe ako wašu aktualnu aktiwitu.
5. Gaž casoměr se skóńcy abo tłocyśo na zastajiś, Decoy skóńcy proces a dataju wulašujo. Rěd nadawkow Windows (job object) zawěsćujo, až decoye wumru zgromadnje z Decoy, lěcrownož wón spadnjo.

## Instalacija

Wubjeŕśo jadno z boka [Wersije (Releases)](../../../../releases):

| Ke ześěgnjenju | Za |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalator.** Za jadnotliwego wužywarja, bźez prawow administratora, pśida zapisk do startowego menija a wótsćěgowański program. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabelny.** Wupakujśo źožkuli a startujśo `decoy.exe`. Wšykne daty wóstanu w rědniku `data` pódla njogo, do wašogo wužywarskego profila se nic njezapišo. Zhašyśo rědnik, aby jen wótwónoźeł. |

Wobkšuśśo ześěgnjenu dataju pśez `SHA256SUMS.txt` (`Get-FileHash <dataja>` w PowerShellu).

Windows SmartScreen móžo warnowaś pśed njeznatym wudawarjom, dokulaž wersije njejsu digitalnje signěrowane; wubjeŕśo *Dalšne informacije → Wšojdno startowaś*, jolic wersiji dowěriśo.

Pominanja: Windows 10 abo 11 (64-bitowy) z wuwjeźeńskim rumom WebView2 (južo zapśijety w Windows 11 a njedawnych aktualizacijach Windows 10).

## Wužywanje

1. Wócyńśo **Biblioteku** a pytajśo za graśim, abo tłocćo `Ctrl` + `K` z kuždego městna.
2. Klikniśo na graśe. Na prawem panelu wubjeŕśo proces a kelko minutow ma se wobchowaś (Discord-aktiwity zwětšego pominaś 15).
3. Tłocćo na **Decoy startowaś**. Discord pokažo graśe pó někotarych sekundach.
4. Wobglědujśo jen pód **Běžece**, zastajśo jaden abo wšykne w kuždem casu, abo wóstajśo Decoy jadnorje w pódawkowem rumje.

Graśa, kótarychž Discord-zapisk hyšći njama wuwjeźomne dataje, su pó standarźe schowane (njemógu se spóznaś). Zmóžniśo *Graśa bźez exe pokazaś*, aby je wiźeł; lisćina se kuždy źeń aktualizěrujo, togodla budu k dispoziciji, tak skóro ako Discord pśida proces.

### Pśikazowa smuga

```
decoy.exe --launch "<wuwjeźomna droga z lisćiny Discorda>" [minuty]
```

Startujo decoy ned, na pśikład `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Wutwóriś ze žrědłowego koda

Pśedpokady: [Node.js](https://nodejs.org) 20+, stabilny gratowny kašćik [Rust](https://rustup.rs) (MSVC-cel) z rědami za natwarjenje Visual Studio C++, a wuwjeźeński rum WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # běžaś we wuwijarskem modusu z direktnym zacytowanim (hot reload)
npm run tauri build    # napóraś instalator w src-tauri/target/release/bundle/nsis
```

Wužytne kontrole:

```bash
npm run check-locales  # pśeglědowaś kuždu pśełožkowańsku dataju napśeśiwo ru.json
npx tsc --noEmit       # typowa kontrola frontend-koda
cargo check --manifest-path src-tauri/Cargo.toml
```

Pśipiski: Decoy exe se pśez `src-tauri/build.rs` z jadnorym `rustc` ze soubora `src-tauri/stub/stub.rs` kompilěrujo a pótom do nałoženja zapśijśo. Gaž frontend běży w jadnorem wobglědowaku (`npm run dev`), se wužywa małki imitěrowany backend (`src/mock.ts`), což jo rucne za źěło na pówjerchu.

## Pśełožki

Teksty pówjercha lěže w [`src/locales`](../../src/locales), jadna JSON-dataja na rěc (`en.json`, `ru.json`, ...). Pśidaśe rěcy wóznamjenijo pśidaśe dataje; žedne změny w koźe. Glědajśo [docs/TRANSLATING.md](../TRANSLATING.md) za format dataje, gótowy pšašak za mašinowe pśełožowanje a skript za pśeglědowanje. Pśełožki toś togo README du do `docs/i18n/README.<code>.md`.

## Struktura projekta

```
src/                    React + TypeScript frontend
  components/           Biblioteka, detailny panel, nastajenja, ...
  locales/              pśełožkowańske dataje (jadna JSON-dataja na rěc)
  i18n-core.ts          zacytowanje a pytanje rěcow
  store.ts              status nałoženja (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            datowa banka graśow, decoy-procesy, pódawkowy rum
  stub/stub.rs          zástupny program, kótaryž se zapśimje
scripts/                pomocne skripty (pśeglědowanje lokalizacijow)
docs/                   pśewodnik za pśełožowanje, fota wobrazowki
```

## Priwatnosć

- Decoy wužywa seś jano za ześěgnjenje zjawneje lisćiny spóznawanja Discorda (pśi prědnem starśe, pótom maksimalnje raz na źeń abo gaž tłocyśo na aktualizěrowaś) a za pokazowanje ikonow graśow a wobrazow ze zjawneje CDN Discorda.
- Wón njecyta, njeskładujo a njesćelo waš Discord-token ani žedne daty konta, a njerěcy z klientom Discorda.
- Nastajenja (favority, rěc, casy traśa) se lokalnje w skłaźišću WebView nałoženja składuju; pufer lisćiny graśow a nachylne decoy-dataje lěže w `%LOCALAPPDATA%\app.decoy.desktop`.
- Žedna analitika, žedne powěsći wó zmólkach, žedne konta.

## Znate wobgranicowanja

- Discord móžo wašnju spóznawanja kuždy cas změniś. Jolic decoy se wěcej njespóznawa, pšosym wócyńśo problem (issue).
- Někotare aktiwity trjebaju wěcej ako jano běžece procesy (na pśikład byś we wěstej dožywjenju graśoweje platformy). Decoy imitěrujo jano proces.
- Zapiski bźez wuwjeźomnych datajow w lisćinje Discorda njemógu se spóznaś.
- Wěstotny software wótergi markěrujo małe njezapokazane wuwjeźomne dataje, kótarež prozne w skłaźe lěže. Decoy jo wótwórjone žrědło a jo natwarjony z `src-tauri/stub/stub.rs`; móžośo jen sami kompilěrowaś.

## Wuzamknjenje zamólwitosći

Decoy se staja k dispoziciji „taki, kokiž jo“ za wósobinske, kubłańske a testowańske zaměry. Imitěrowanje běžecego graśa móžo pśetergowaś wuměnjenja słužby Discorda abo wudawarja graśa a móžo wjasć k sankcijam napśeśiwo wašomu kontoju. Wy sami sćo zamólwite za to, kak jen wužywaśo. „Discord“ a wšykne mjenja graśow a loga su wikowańske znamjenja jich wótpowědnych wobsejźarjow a wužywaju se how jano za identifikaciju softwary, na kótaruž se póśěguju.
