# Decoy

**નાની સ્ટેન્ડ-ઇન પ્રોસેસ જે Discord ને એવું દર્શાવે છે કે કોઈ ગેમ ચાલી રહી છે.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="તાજેતરની ગેમ્સ અને આર્ટવર્ક સાથે Decoy લાઇબ્રેરી" />

</div>

Decoy ગેમના એક્ઝિક્યુટેબલ (executable) નામ હેઠળ એક હાનિરહિત, વિન્ડોવાળી પ્લેસહોલ્ડર પ્રોસેસ ચાલુ રાખે છે, જેથી Discord નું ગેમ ડિટેક્શન એવું દર્શાવે છે કે તમે તે ગેમ રમી રહ્યા છો. તમારે ક્યારેય વાસ્તવિક ગેમ ઇન્સ્ટોલ કે લૉન્ચ કરવાની જરૂર પડતી નથી, તેથી તમારી ડિસ્ક પર કોઈ મોટી ફાઇલ રહેતી નથી.

તે **Discord ડિટેક્ટ કરી શકે તેવી દરેક ગેમ** (આશરે 25,000 એન્ટ્રીઓ) વિશે જાણે છે કારણ કે તે Discord ની પોતાની સાર્વજનિક ડિટેક્શન સૂચિ વાંચે છે અને તેને આપમેળે અદ્યતન રાખે છે.

> [!WARNING]
> ચાલુ ગેમનો ઢોંગ કરવો Discord ની સેવાની શરતો (Terms of Service) વિરુદ્ધ હોઈ શકે છે અને તમે Decoy નો ઉપયોગ **તમારા પોતાના જોખમે** કરો છો.
> આ પ્રોજેક્ટ Discord Inc. સાથે સંલગ્ન, સમર્થિત કે જોડાયેલ નથી. [અસ્વીકરણ](#અસ્વીકરણ) જુઓ.

## વિશેષતાઓ

- **Discord ડિટેક્ટ કરી શકે તે બધું.** ગેમ સૂચિ Discord ના સાર્વજનિક ડિટેક્શન એન્ડપોઇન્ટ પરથી ડાઉનલોડ થાય છે, સ્થાનિક રીતે કૅશ થાય છે અને દરરોજ રિફ્રેશ થાય છે. નવી ગેમ્સ અને નવી ઉમેરાયેલી એક્ઝિક્યુટેબલ ફાઇલો આપમેળે દેખાય છે.
- **ઝડપી અને સચોટ શોધ.** હજારો ગેમ્સમાં ગેમના નામ અથવા એક્ઝિક્યુટેબલ દ્વારા ત્વરિત શોધ, ગ્રીડ અથવા કોમ્પેક્ટ સૂચિ દૃશ્ય, મનપસંદ અને "તાજેતરનું" પંક્તિ.
- **એક ક્લિક.** કોઈ ગેમ પસંદ કરો, એક્ઝિક્યુટેબલ પસંદ કરો (જો એકથી વધુ હોય), તેને કેટલી મિનિટ ચાલુ રાખવી તે નક્કી કરો અને સ્ટાર્ટ દબાવો. કાઉન્ટડાઉન રિંગ અને નોટિફિકેશન તમને સમય પૂરો થવાની જાણ કરે છે.
- **પાછળ કશું છોડતું નથી.** Decoy માત્ર ત્યારે જ અસ્તિત્વમાં રહે છે જ્યારે તે ચાલુ હોય: નાની exe શરૂ થવા પર બનાવવામાં આવે છે અને બંધ થવા પર કાઢી નાખવામાં આવે છે. જ્યારે તમે બહાર નીકળો છો ત્યારે બધું બંધ થઈ જાય છે, અને ક્રેશના અવશેષો આગલી વખતે લૉન્ચ કરતી વખતે સાફ થઈ જાય છે.
- **શાંત.** સિસ્ટમ ટ્રેમાં રહે છે, decoys માટે પોતાની કોઈ વિન્ડો કે ટાસ્કબાર બટન હોતા નથી.
- **ખુલ્લા અનુવાદો.** ઇન્ટરફેસ સરળ JSON ફાઇલો દ્વારા સંચાલિત થાય છે, તેથી નવી ભાષા ઉમેરવી એ માત્ર એક ફાઇલ ઉમેરવા જેવું છે. અંગ્રેજી અને રશિયન સામેલ છે.
- **ખાનગી.** કોઈ ખાતું નહીં, કોઈ Discord ટોકન નહીં, કોઈ ટેલિમેટ્રી નહીં. [ગોપનીયતા](#ગોપનીયતા) જુઓ.

## તે કેવી રીતે કાર્ય કરે છે

1. Discord તમારા PC પર ચાલી રહેલી પ્રોસેસ જોઈને અને તેમના એક્ઝિક્યુટેબલ નામોની તુલના સાર્વજનિક સૂચિ (`/api/v9/applications/detectable`) સાથે કરીને નક્કી કરે છે કે તમે કોઈ ગેમ રમી રહ્યા છો.
2. Decoy તે સૂચિ ડાઉનલોડ કરે છે અને, તમે પસંદ કરેલ ગેમ માટે, સૂચિમાંથી એક્ઝિક્યુટેબલ નામના આધારે એક નાનો સ્ટેન્ડ-ઇન પ્રોગ્રામ (આશરે 120 KB, Rust માં લખાયેલ અને Decoy માં એમ્બેડ થયેલ) એક કામચલાઉ ફોલ્ડરમાં કૉપિ કરે છે, ઉદાહરણ તરીકે `.../cod26-cod.exe`.
3. સ્ટેન્ડ-ઇન માત્ર એક ટોપ-લેવલ વિન્ડો ધરાવવા સિવાય કશું કરતું નથી, જેને સ્ક્રીનથી ઘણી દૂર રાખવામાં આવે છે જેથી તમે તેને ક્યારેય જોઈ ન શકો. Discord માત્ર એવી પ્રોસેસને ઓળખે છે જેની પાસે વિન્ડો હોય, તેથી સંપૂર્ણપણે વિન્ડો-રહિત પ્રોસેસની અવગણના કરવામાં આવે છે.
4. આશરે 15 સેકન્ડમાં Discord તે ગેમને તમારી વર્તમાન પ્રવૃત્તિ તરીકે દર્શાવવા લાગે છે.
5. જ્યારે ટાઈમર સમાપ્ત થાય છે અથવા તમે સ્ટોપ દબાવો છો, ત્યારે Decoy પ્રોસેસ બંધ કરે છે અને ફાઇલ કાઢી નાખે છે. Windows જોબ ઑબ્જેક્ટ સુનિશ્ચિત કરે છે કે Decoy ક્રેશ થાય તો પણ decoys Decoy સાથે જ બંધ થઈ જાય.

| `Decoy_x.y.z_x64-setup.exe` | **ઇન્સ્ટોલર.** વપરાશકર્તા દીઠ, એડમિનિસ્ટ્રેટર અધિકારોની જરૂર નથી, સ્ટાર્ટ મેનૂ એન્ટ્રી અને અનઇન્સ્ટોલર ઉમેરે છે. |
| `Decoy_x.y.z_x64-portable.zip` | **પોર્ટેબલ.** ગમે ત્યાં અનઝિપ કરો અને `decoy.exe` ચલાવો. તમામ ડેટા તેની બાજુના `data` ફોલ્ડરમાં રહે છે, તમારી વપરાશકર્તા પ્રોફાઇલમાં કંઈ લખાતું નથી. તેને દૂર કરવા માટે ફોલ્ડર કાઢી નાખો. |

`SHA256SUMS.txt` વડે ડાઉનલોડ ચકાસો (PowerShell માં `Get-FileHash <file>`).

Windows SmartScreen અજાણ્યા પ્રકાશક (unrecognized publisher) વિશે ચેતવણી આપી શકે છે કારણ કે બિલ્ડ્સ કોડ-સાઇન કરેલા નથી; જો તમે બિલ્ડ પર વિશ્વાસ કરો છો તો *More info → Run anyway* પસંદ કરો.

જરૂરિયાતો: Windows 10 અથવા 11 (64-bit) સાથે WebView2 રનટાઇમ (Windows 11 અને તાજેતરના Windows 10 અપડેટ્સમાં પહેલેથી શામેલ છે).

## વપરાશ

1. **Library** ખોલો અને ગેમ શોધો, અથવા ગમે ત્યાંથી `Ctrl` + `K` દબાવો.
2. ગેમ પર ક્લિક કરો. જમણી બાજુના પેનલમાં પ્રોસેસ અને તેને કેટલી મિનિટ ચાલુ રાખવી તે પસંદ કરો (Discord પ્રવૃત્તિઓ માટે સામાન્ય રીતે 15 મિનિટની જરૂર હોય છે).
3. **Start decoy** દબાવો. થોડી સેકન્ડો પછી Discord ગેમ દર્શાવવા લાગશે.
4. તેને **Running** હેઠળ જુઓ, કોઈપણ સમયે એક અથવા બધાને રોકો, અથવા Decoy ને ટ્રેમાં રહેવા દો.

જે ગેમ્સની Discord એન્ટ્રીમાં હજી સુધી કોઈ એક્ઝિક્યુટેબલ નથી તે ડિફૉલ્ટ રૂપે છુપાયેલી હોય છે (તેમને ડિટેક્ટ કરી શકાતી નથી). તેમને જોવા માટે *Show games without exe* ચાલુ કરો; સૂચિ દરરોજ રિફ્રેશ થાય છે, તેથી Discord પ્રોસેસ ઉમેરે કે તરત જ તે ઉપલબ્ધ થઈ જાય છે.

### કમાન્ડ લાઇન

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

તરત જ decoy શરૂ કરે છે, ઉદાહરણ તરીકે `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## સોર્સ પરથી બિલ્ડ કરો

પૂર્વજરૂરિયાતો: [Node.js](https://nodejs.org) 20+, Visual Studio C++ બિલ્ડ ટૂલ્સ સાથે સ્થિર [Rust](https://rustup.rs) ટૂલચેન (MSVC ટાર્ગેટ), અને WebView2 રનટાઇમ.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ઉપયોગી ચકાસણીઓ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

નોંધ: decoy exe ફાઇલ `src-tauri/stub/stub.rs` પરથી સામાન્ય `rustc` સાથે `src-tauri/build.rs` દ્વારા કમ્પાઇલ કરવામાં આવે છે અને પછી એપમાં એમ્બેડ કરવામાં આવે છે. જ્યારે ફ્રન્ટએન્ડ સામાન્ય બ્રાઉઝરમાં ચાલે છે (`npm run dev`), ત્યારે નાનું મોક બેકએન્ડ (`src/mock.ts`) વપરાય છે, જે UI પર કામ કરવા માટે અનુકૂળ છે.

## અનુવાદો

UI સ્ટ્રિંગ્સ [`src/locales`](../../src/locales) માં રહે છે, ભાષા દીઠ એક JSON ફાઇલ (`en.json`, `ru.json`, ...).
નવી ભાષા ઉમેરવી એટલે એક ફાઇલ ઉમેરવી; કોઈ કોડ ફેરફાર નહીં. ફાઇલ ફોર્મેટ, મશીન અનુવાદ માટે તૈયાર પ્રોમ્પ્ટ અને માન્યતા સ્ક્રિપ્ટ માટે [docs/TRANSLATING.md](../TRANSLATING.md) જુઓ. આ README ના અનુવાદો `docs/i18n/README.<code>.md` માં જાય છે.

## પ્રોજેક્ટનું માળખું

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## ગોપનીયતા

- Decoy માત્ર નેટવર્કનો ઉપયોગ Discord ની સાર્વજનિક ડિટેક્શન સૂચિ ડાઉનલોડ કરવા (પ્રથમ શરૂઆત પર, પછી વધુમાં વધુ દિવસમાં એકવાર અથવા જ્યારે તમે રિફ્રેશ દબાવો છો ત્યારે) અને પ્રદર્શિત કરવા માટે Discord ના સાર્વજનિક CDN પરથી ગેમ આઇકન અને આર્ટવર્ક મેળવવા માટે કરે છે.
- તે તમારો Discord ટોકન અથવા કોઈપણ એકાઉન્ટ ડેટા વાંચતું, સંગ્રહતું કે મોકલતું નથી, અને તે Discord ક્લાયન્ટ સાથે વાત કરતું નથી.
- સેટિંગ્સ (મનપસંદ, ભાષા, અવધિ) સ્થાનિક રીતે એપના WebView સ્ટોરેજમાં સંગ્રહિત થાય છે; ગેમ સૂચિ કૅશ અને કામચલાઉ decoy ફાઇલો `%LOCALAPPDATA%\app.decoy.desktop` માં રહે છે.
- કોઈ એનાલિટિક્સ નથી, કોઈ ક્રેશ રિપોર્ટિંગ નથી, કોઈ એકાઉન્ટ નથી.

## જાણીતી મર્યાદાઓ

- Discord કોઈપણ સમયે ડિટેક્શન કેવી રીતે કાર્ય કરે છે તે બદલી શકે છે. જો કોઈ decoy ઓળખાવાનું બંધ થઈ જાય, તો કૃપા કરીને issue ખોલો.
- કેટલીક પ્રવૃત્તિઓ માટે માત્ર ચાલુ પ્રોસેસ કરતાં વધુની જરૂર હોય છે (ઉદાહરણ તરીકે ગેમ પ્લેટફોર્મના ચોક્કસ અનુભવની અંદર હોવું). Decoy માત્ર પ્રોસેસનું અનુકરણ કરે છે.
- Discord ની સૂચિમાં એક્ઝિક્યુટેબલ વગરની એન્ટ્રીઓ ડિટેક્ટ થઈ શકતી નથી.
- સુરક્ષા સોફ્ટવેર ક્યારેક મેમરીમાં નિષ્ક્રિય બેઠેલી નાની અનસાઇન્ડ (unsigned) એક્ઝિક્યુટેબલ ફાઇલોને ફ્લેગ કરી શકે છે. Decoy ઓપન સોર્સ છે અને `src-tauri/stub/stub.rs` પરથી બનાવવામાં આવ્યું છે; તમે તેને જાતે કમ્પાઇલ કરી શકો છો.

## અસ્વીકરણ

Decoy વ્યક્તિગત, શૈક્ષણિક અને પરીક્ષણ હેતુઓ માટે "જેમ છે તેમ" પૂરું પાડવામાં આવે છે. ચાલુ ગેમનું અનુકરણ કરવું Discord અથવા ગેમના પ્રકાશકની સેવાની શરતો (Terms of Service) નું ઉલ્લંઘન કરી શકે છે, અને તમારા એકાઉન્ટ સામે પગલાં લેવામાં આવી શકે છે. તમે તેનો કેવી રીતે ઉપયોગ કરો છો તેના માટે તમે એકલા જ જવાબદાર છો. "Discord" અને તમામ ગેમના નામો અને લોગો તેમના સંબંધિત માલિકોના ટ્રેડમાર્ક છે અને તેનો ઉપયોગ અહીં માત્ર જે સોફ્ટવેરનો સંદર્ભ આપે છે તેને ઓળખવા માટે જ થાય છે.
