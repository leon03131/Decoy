# Decoy

**Discord ахәмарра иаҿуп ҳәа иԥхьаӡарц азы зҵакы маҷу азаглушка-процессқәа.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy абиблиотека иҿыцу ахәмаррақәеи асахьақәеи рыла" />

Decoy ахәмарра иатәу апрограмма exe ахьӡ ала зҵакы маҷу, зышәарҭадароу, аԥенџьыр змоу азаглушка-процесс аус аура иаҿнакуеит, убри аҟынтә Discord ахәмаррақәа ралкаара асистема шәара уи ахәмарра шәаҿуп ҳәа ианарбоит. Иҵоурахь ахәмарра ашьақәыргылара ма аҿакра шәаҭахӡом, дискаҿгьы акагьы аанхаӡом.

Уи **Discord иалкаар зылшо ахәмаррақәа зегьы** еилыркаауеит (25 000 ҩыра раҟара), избанзар Discord ауаажәларратә сиа хаҭала иаԥхьаӡоит, насгьы хала иактуалу аҭагылазаашьаҿы иааннакылоит.

> [!WARNING]
> Ахәмарра аҿаԥшылара Discord Ахархәаразы аԥҟарақәа ирҿагылар алшоит, Decoy **шәхатә ҭакԥхықәрала** шәхы иашәырхәоит.
> Ари апроект Discord Inc. иадҳәалам, уи аҟынтә ишьақәырӷәӷәаӡам, ацхыраарагьы амоуӡом. Шәахәаԥш: [Аҭакԥхықәра мап ацәкра](#аҭакԥхықәра-мап-ацәкра).

## Аҟалорақәа

- **Discord иалкаар зылшо зегьы.** Ахәмаррақәа рсиа Discord ауаажәларратә хыҵхырҭа аҟынтә иҭагалоит, аҭыԥан еиқәырхоит, есымша иарҿыцуеит. Ахәмарра ҿыцқәеи ҿыц иацҵоу exe-фаилқәеи хала уахь иааиуеит.
- **Иласны аԥшаара.** Зықьҩыла ахәмаррақәа рыбжьара ахәмарра ахьӡ ма exe-фаил ала иласны аԥшаара, плиткала ма компактла сиала аарԥшра, иалкаауи «Иҿыцу» ацәаҳәеи.
- **Ақәыӷәӷәара заҵәык ала.** Ахәмарра шәалх, exe-фаил шәалх (урҭ рацәазар), шаҟа минут амакра шәахәаԥш, нас «Азаглушка аҿакра» шәақәыӷәӷәа. Аԥхьаӡара агәыԥи адырраҭареи аамҭа анҵәо шәеилыркаауеит.
- **Шьҭа ааннамыжьӡом.** Азаглушка аус шауа мацара иҟоуп: хәыҷы exe аҿакраан иаԥҵоит, аанкылараангьы ианыхуеит. Апрограмма аҭыҵраан зегьы иаангылоит, иаахысыз афаилқәа анаҩстәи аҿакраан ирыцқьахоит.
- **Имырӡҩоу арежим.** Асистематә трей аҿы аус ауеит, азаглушкақәа рхаҭа рзы аԥенџьырқәеи аусқәа рпанель аҿы ақәыӷәӷәагақәеи ыҟаӡам.
- **Аартту аиҭагарақәа.** Аинтерфеис имариоу JSON-фаилқәа рыла аус ауеит, убри аҟынтә абызшәа ацҵара фаил заҵәык ауп. Англыз бызшәеи аурыс бызшәеи уажәагьы иаҵанакуеит.
- **Аконфиденциалра.** Ааккаунт мап, Discord токен мап, телеметриа мап. Шәахәаԥш: [Аконфиденциалра](#аконфиденциалра).

## Убри шпусуа

1. Discord ахәмарра шәаҿуп ҳәа иалкаауеит шә-ПК аҿы аус зуа апроцессқәа гәаҭаны, урҭ р-exe ахьӡқәа ауаажәларратә сиа (`/api/v9/applications/detectable`) иаҿырԥшуа.
2. Decoy ари асиа ҭанагалоит, нас иалху ахәмарразы зҵакы маҷу азаглушка-программа (120 КБ раҟара, Rust ала иҩуп, Decoy аҩныҵҟа иаҵаҵоуп) аамҭалатәи апапка ахь иасиа аҟнытә exe ахьӡ ала акопиа ҟанаҵоит, иаҳҳәап `.../cod26-cod.exe`.
3. Азаглушка аекран анаҩс иҟоу хыхьтәи аҩаӡара змоу ԥенџьыр заҵәык аԥҵара ада акагьы ҟанаҵаӡом, убри аҟынтә шәара уи закәыцәгьы ишәбаӡом. Discord ԥенџьыр змоу апроцессқәа мацара иалкаауеит, убри аҟынтә ԥенџьырда апроцессқәа ирҿаԥшыӡом.
4. 15 секунд раҟара рышьҭахь Discord ари ахәмарра шә-уажәтәи актиураны ианарбоит.
5. Атаймер анҵәо ма шәара аанкылара ақәыӷәӷәага шәақәыӷәӷәазар, Decoy апроцесс хыркәшоит, афаилгьы ианыхуеит. Windows арусуратә обиект (job object) Decoy иацынҵаны азаглушкақәа раанкылара аҭакԥхықәра амоуп, апрограмма хала акаҳазарги.

## Ашьақәыргылара

[Арелизқәа рдаҟьаҿы](../../../../releases) авариант шәалх:

| Аҭагалара | Азҵаара |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Ашьақәыргылага.** Ахархәаҩ заҵәык изы, администратор ихьӡ ала азинқәа аҭахӡом, «Пуск» амениу аҿы апункт ацҵоит, адеинсталлиаторгьы иамоуп. |
| `Decoy_x.y.z_x64-portable.zip` | **Апортативтә версиа.** Иарбан ҭыԥзаалакгьы иҭышәх, нас `decoy.exe` шәаҿак. Адыррақәа зегьы уи иаԥну `data` апапкаҿы еиқәырхоуп, ахархәаҩ ипрофиль ахь акагьы ҩӡом. Ианыхырц азы, апапка шәаных заҵәык. |

`SHA256SUMS.txt` шәхы иашәырхәаны иҭагалоу афаил ако контролтә хыԥхьаӡара шәгәаҭа (PowerShell аҿы `Get-FileHash <file>`).

Windows SmartScreen еилкаам акьыԥхьҩы ҳәа шәагәнаҭар алшоит, сборкақәа ацифратә напынҵа рымам аҟынтә; сборка шәгәы ӷәӷәаны иазыҟазар, *Подробнее → Выполнить в любом случае* шәалх.

Аҭахрақәа: Windows 10 ма 11 (64-бит) WebView2 аамҭалатәи среда иацҵаны (Windows 11-и Windows 10 аҵыхәтәантәи арҿыцрақәеи рҿы уажәагьы иҟоуп).

## Ахархәара

1. **Абиблиотека** шәаарт, нас ахәмарра шәаԥшаа, ма апрограмма иарбан ҭыԥзаалакгьы `Ctrl` + `K` шәақәыӷәӷәа.
2. Ахәмарра шәақәыӷәӷәа. Аҵәаҳәа арӷьарахь апроцесси шаҟа минут амакреи шәалх (Discord аусқәа рҿы лассы-лассы 15 минут аҭахуп).
3. **Азаглушка аҿакра** шәақәыӷәӷәа. Discord маҷк секунд рышьҭахь ахәмарра аанарԥшуеит.
4. **Иаҿу** авкладкаҿы уи шәахәаԥш, иарбан аамҭазаалакгьы ак ма зегьы шәаанкыла, ма Decoy атрей аҿы шәаанрыжь.

Discord асиаҿы макьана exe-фаил змам ахәмаррақәа ишыҟоу еиԥш иҵәахуп (урҭ ралкаара ҟалаӡом). Урҭ рбаразы *exe змам ахәмаррақәа рбара* шәаҿак; асиа есымша иарҿыцуеит, убри аҟынтә Discord апроцесс аниациҵо, урҭ маҵзураны иҟалоит.

### Абуйруратә цәаҳәа

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Иаразнак азаглушка аҿанакуеит, иаҳҳәап: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ахыҵхырҭақәа рҟынтә аиқәыршәара

Аԥхьа иаҭаху: [Node.js](https://nodejs.org) 20+, ҭышәынтәалаз [Rust](https://rustup.rs) имаҵзуратә обиект (MSVC платформа) Visual Studio C++ ргыларатә маҵзурақәеи WebView2 средеи иацҵаны.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Ихәарҭоу агәаҭарақәа:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Азгәаҭарақәа: азаглушка апрограмма `src-tauri/build.rs` аскрипт ала ядибиль `rustc` маҵзурала `src-tauri/stub/stub.rs` аҟынтә икомпилируеит, анаҩс апрограмма аҩныҵҟа иаҵаҵоуп. Афронтенд ишыҟоу браузер аҿы аҿакраан (`npm run dev`) хәыҷы мок-бэкенд (`src/mock.ts`) рхы иадырхәоит, уи аинтерфеис аусуразы даара иманшәалоуп.

## Аиҭагарақәа

Аинтерфеис ацәаҳәақәа [`src/locales`](../../src/locales) аҿы иҟоуп, бызшәа цыԥхьаӡа JSON-фаилк ала (`en.json`, `ru.json`, ...).
Абызшәа ацҵара фаил заҵәык ацҵара ауп — акод аԥсахрада. Шәахәаԥш [docs/TRANSLATING.md](../TRANSLATING.md) афаилқәа рформати, зхиоу машинатә иҭагаразы апромпти, авалидациа аскрипти рыхцәажәаразы. Ари README аиҭагарақәа `docs/i18n/README.<code>.md` ахь иҭагалоит.

## Апроект аструктура

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Аконфиденциалра

- Decoy аҳауа ахы ианархәоит Discord ауаажәларратә сиа аҭагалара мацаразы (раԥхьатәи аҿакраан, насгьы амш аҿы зны еиҳамызтәи ма арҿыцра ақәыӷәӷәага анрықәыӷәӷәо) Discord ауаажәларратә CDN аҟынтә ахәмаррақәа рлоготипқәеи рсахьақәеи раарԥшразы.
- Апрограмма шә-Discord токен ма аккаунт адыррақәа акагьы аԥхьаӡом, еиқәнархаӡом, икнамырхуаӡом, насгьы Discord аклиент иацәажәаӡом.
- Апараметрқәа (иалкаау, абызшәа, аамҭа) апрограмма WebView аҭаҵәах аҿы аҭыԥан еиқәырхоуп; ахәмаррақәа рсиа акэши азаглушкақәа рамҭалатәи фаилқәеи `%LOCALAPPDATA%\app.decoy.desktop` аҿы иҟоуп.
- Аналитика мап, акаҳарақәа рганахьала ажәахәқәа мап, аккаунтқәа мап.

## Еицырдыруа аҳәаақәа

- Discord иарбан аамҭазаалакгьы ралкаара алогика аԥсахра алшоит. Азаглушка аилкаара анҵәо, агәаҭара (issue) шәаарт.
- Шьоукы адискуссиақәа рзы аус зуа апроцесс адагьы акагьы аҭахуп (иаҳҳәап, ҷыда хәмарратә ҭыԥ ма платформатә режим аҟны аҟазаара). Decoy апроцесс заҵәык аҿаԥшылоит.
- Discord асиаҿы exe-фаил змам ахәмаррақәа ралкаара ҟалаӡом.
- Ахьчаратә ПО лассы-лассы иҵабыргым, напынҵа змам хәыҷы exe-фаилқәа агәаларшәараҿы ишыҟоу рҿаԥшылар алшоит. Азаглушка аартту акод амоуп, `src-tauri/stub/stub.rs` аҟынтә еиқәыршәоуп; шәхаҭала уи аиқәыршәара шәылшоит.

## Аусура алахәылара

Агхақәа ргәаҭарақәа, абжьгарақәа, аиҭагарақәа гәырӷьарала идикылоит. Раԥхьа [CONTRIBUTING.md](../../CONTRIBUTING.md) шәахәаԥш.

## Аҭакԥхықәра мап ацәкра

Decoy «ишыҟоу еиԥш» хаҭалатәи, ҵарадырратә, гәаҭаратә хықәкқәа рзы иҟоуп. Ахәмарра аҿаԥшылара Discord ма ахәмарра акьыԥхьҩы Ахархәаразы аԥҟарақәа ирҿагылар алшоит, шә-аккаунт аҿаԥшыларагьы иахҟьар алшоит. Апрограмма ахархәаразы ҭакԥхықәра шәара шатәуп. «Discord», ахәмаррақәа рыхьӡқәа, алоготипқәа зегьы хаҭалатәи рзынҳәаҩцәа ртәы роуп, ара урҭ рпрограммақәа ралкаара мацаразы ихьчоуп.
