# Decoy

**Väikesed asendusprotsessid, mis panevad Discordi arvama, et mäng töötab.**

![Platvorm](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Ehitatud teegiga](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Litsents](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy teek hiljutiste mängude ja kujundusega" />

</div>

Decoy hoiab töös ohutut, aknaga asendusprotsessi mängu käivitatava faili nime all, nii et Discordi mängutuvastus näitab, et mängid seda mängu. Sul pole kunagi vaja päris mängu installida ega käivitada, seega ei võta miski kettal ruumi.

See teab **kõiki mänge, mida Discord suudab tuvastada** (umbes 25 000 kirjet), sest see loeb Discordi enda avalikku tuvastusloendit ja hoiab seda automaatselt ajakohasena.

> [!WARNING]
> Töötava mängu teesklemine võib olla vastuolus Discordi teenusetingimustega ja kasutad Decoyt **omal vastutusel**.
> See projekt ei ole seotud ettevõttega Discord Inc., toetatud ega heaks kiidetud selle poolt. Vaata [Lahtiütlus](#lahtiütlus).

## Funktsioonid

- **Kõik, mida Discord suudab tuvastada.** Mängude loend laaditakse alla Discordi avalikust tuvastuslõpp-punktist, vahemällu salvestatakse kohapeal ja värskendatakse iga päev. Uued mängud ja värskelt lisatud käivitatavad failid ilmuvad iseenesest.
- **Otsing, mis peab sammu.** Kiire otsing mängu või käivitatava faili nime järgi tuhandete mängude seast, ruudustik või kompaktne loendivaade, lemmikud ja „Hiljutised“ rida.
- **Üks klõps.** Vali mäng, vali käivitatav fail (kui neid on mitu), määra kestus ja vajuta käivita. Pöördloenduse ring ja teavitus annavad teada, kui aeg saab täis.
- **Ei jäta jälgi.** Decoy eksisteerib ainult töötamise ajal: pisike exe luuakse käivitamisel ja kustutatakse peatamisel. Kõik peatatakse väljumisel ja krahhist jäänud jäägid koristatakse järgmisel käivitamisel.
- **Märkamatu.** Asub süsteemisalves, asendusprotsesside endi jaoks pole aknaid ega tegumiriba nuppe.
- **Avatud tõlked.** Kasutajaliidest juhivad lihtsad JSON-failid, seega uue keele lisamine tähendab vaid ühe faili lisamist. Inglise ja vene keel on kaasas.
- **Privaatne.** Pole kontot, Discordi pääsutõendit ega telemeetriat. Vaata [Privaatsus](#privaatsus).

## Kuidas see töötab

1. Discord otsustab, et mängid mängu, vaadates sinu arvutis töötavaid protsesse ja võrreldes nende käivitatavate failide nimesid avaliku loendiga (`/api/v9/applications/detectable`).
2. Decoy laadib selle loendi alla ja kopeerib sinu valitud mängu jaoks pisikese asendusprogrammi (umbes 120 KB, kirjutatud Rustis ja manustatud Decoysse) ajutisse kausta, kasutades loendis olevat käivitatava faili nime, näiteks `.../cod26-cod.exe`.
3. Asendusprogramm ei tee muud, kui omab ühte ülataseme akent, mis on paigutatud ekraanilt kaugele välja, nii et sa ei näe seda kunagi. Discord tuvastab ainult akent omavaid protsesse, mistõttu täiesti aknata protsesse ignoreeritakse.
4. Umbes 15 sekundi jooksul kuvab Discord mängu sinu praeguse tegevusena.
5. Kui taimer lõpeb või vajutad peatamist, lõpetab Decoy protsessi ja kustutab faili. Windowsi „job object“ tagab, et asendusprotsessid suletakse koos Decoyga, isegi kui see kokku jookseb.

## Paigaldamine

Vali sobiv lehelt [Releases](../../../../releases):

| Allalaadimine | Sihtotstarve |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Paigaldaja.** Kasutajapõhine, administraatori õigusi pole vaja, lisab Start-menüü kirje ja eemaldaja. |
| `Decoy_x.y.z_x64-portable.zip` | **Kaasaskantav.** Paki lahti kuhu tahes ja käivita `decoy.exe`. Kõik andmed jäävad selle kõrval olevasse kausta `data`, sinu kasutajaprofiili ei kirjutata midagi. Eemaldamiseks kustuta kaust. |

Kontrolli allalaadimist failiga `SHA256SUMS.txt` (PowerShellis `Get-FileHash <fail>`).

Windows SmartScreen võib hoiatada tundmatu avaldaja eest, kuna järgud ei ole koodiallkirjastatud; vali *Lisateave → Käivita ikkagi*, kui usaldad järku.

Nõuded: Windows 10 või 11 (64-bitine) koos WebView2 käituskeskkonnaga (juba kaasas operatsioonisüsteemis Windows 11 ja hiljutistes Windows 10 värskendustes).

## Kasutamine

1. Ava **Teek** ja otsi mängu või vajuta ükskõik kust klahvikombinatsiooni `Ctrl` + `K`.
2. Klõpsa mängule. Vali parempoolses paneelis protsess ja kui mitu minutit seda töös hoida (Discordi tegevused nõuavad tavaliselt 15 minutit).
3. Vajuta **Käivita Decoy**. Discord kuvab mängu paari sekundi pärast.
4. Jälgi seda vaates **Töös**, peata üks või kõik igal ajal või jäta Decoy lihtsalt süsteemisalve.

Mängud, mille Discordi kirjes pole veel käivitatavaid faile, on vaikimisi peidetud (neid ei saa tuvastada). Lülita sisse *Kuva ilma exe-ta mängud*, et neid näha; loendit värskendatakse iga päev, nii et need muutuvad kättesaadavaks kohe, kui Discord lisab protsessi.

### Käsurida

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Käivitab decoy kohe, näiteks `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ehitamine lähtekoodist

Eeltingimused: [Node.js](https://nodejs.org) 20+, stabiilne [Rust](https://rustup.rs) tööriistakomplekt (MSVC sihtmärk) koos Visual Studio C++ ehitustööriistadega ja WebView2 käituskeskkond.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Kasulikud kontrollid:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Märkused: decoy exe kompileeritakse failiga `src-tauri/build.rs` tavalise `rustc` abil failist `src-tauri/stub/stub.rs` ja manustatakse seejärel rakendusse. Kui esisüsteem töötab tavalises brauseris (`npm run dev`), kasutatakse väikest mock-tagasüsteemi (`src/mock.ts`), mis on mugav kasutajaliidese kallal töötamiseks.

## Tõlked

Kasutajaliidese tekstid asuvad kaustas [`src/locales`](../../src/locales), üks JSON-fail iga keele kohta (`en.json`, `ru.json`, ...). Keele lisamine tähendab faili lisamist; koodimuudatusi pole vaja. Failivormingu, masintõlke jaoks valmis viiba ja valideerimisskripti leiad failist [docs/TRANSLATING.md](../TRANSLATING.md). Selle README tõlked lähevad asukohta `docs/i18n/README.<code>.md`.

## Projekti ülesehitus

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privaatsus

- Decoy kasutab võrku ainult Discordi avaliku tuvastusloendi allalaadimiseks (esimesel käivitamisel, seejärel maksimaalselt kord päevas või värskendamisnupu vajutamisel) ning kuvamiseks vajalike mänguikoonide ja kujunduse laadimiseks Discordi avalikust CDN-ist.
- See ei loe, salvesta ega saada sinu Discordi pääsutõendit ega kontoandmeid ning see ei suhtle Discordi kliendiga.
- Seaded (lemmikud, keel, kestused) salvestatakse kohapeal rakenduse WebView salvestusruumis; mänguloendi vahemälu ja ajutised decoy failid asuvad asukohas `%LOCALAPPDATA%\app.decoy.desktop`.
- Ei mingit analüütikat, krahhiraporteid ega kontosid.

## Teadaolevad piirangud

- Discord võib tuvastamise toimimist igal ajal muuta. Kui decoy'd enam ei tuvastata, ava palun probleemikirje (issue).
- Mõned tegevused vajavad enamat kui lihtsalt töötavat protsessi (näiteks viibimine mänguplatvormi kindlas kogemuses). Decoy jäljendab ainult protsessi.
- Kirjeid, millel puuduvad käivitatavad failid Discordi loendis, ei saa tuvastada.
- Turbetarkvara võib aeg-ajalt märgistada väikeseid allkirjastamata käivitatavaid faile, mis seisavad jõude mälus. Decoy on avatud lähtekoodiga ja ehitatud failist `src-tauri/stub/stub.rs`; saad selle ise kompileerida.

## Lahtiütlus

Decoy on pakutud põhimõttel „nagu on“ isiklikuks, hariduslikuks ja testimise eesmärgil. Töötava mängu jäljendamine võib rikkuda Discordi või mängu avaldaja teenusetingimusi ning võib kaasa tuua meetmeid sinu konto vastu. Vastutad selle kasutamise eest ainuisikuliselt. „Discord“ ja kõik mängude nimed ning logod on nende vastavate omanike kaubamärgid ja neid kasutatakse siin ainult viidatava tarkvara tuvastamiseks.
