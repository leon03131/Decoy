# Decoy

**Discord-ха оюн ойнала турады деп кёргюзтген гитче алдаучу процессле.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Ахыргы оюнла бла къаплары болгъан Decoy библиотекасы" />

</div>

Decoy оюнну толтуруучу файлыны аты бла хатасыз, терезеси болгъан алдаучу процессти ишлетип турады, аны ючюн Discord-ну оюнланы таныу системасы сиз ол оюнну ойнай турасыз деп кёргюзтеди. Керти оюнну орнатыргъа неда ийирге кереклиси джокъду, дискигизде уллу зат турмайды.

Ол **Discord таный билген хар оюнну** биледи (25 000 чакълы бир джазыу), нек десегиз Discord-ну кесини ачыкъ таныу списогун окъуйду эмда аны кеси джангыртып турады.

> [!WARNING]
> Ишлеген оюнну алдау халда кёргюзтюу Discord-ну Хайырланыу шартларына къаршчы болургъа боллукъду эмда сиз Decoy-ну **кесигиз къоркъуугъуз бла** хайырланасыз.
> Бу проект Discord Inc. компаниясы бла байламлы тюлдю, аны бла къабыл этилмегенди эмда анга къатышы джокъду. [Джууаблылыкъдан баш тартыу](#джууаблылыкъдан-баш-тартыу) бёлюмню къарагъыз.

## Хунарлыкълары

- **Discord таный билген бютеу зат.** Оюнланы списогу Discord-ну ачыкъ таныу къайнагъындан джюкленип алынады, локал кэшде сакъланады эмда кюн сайын джангыртылады. Джангы оюнла бла джангы къошулгъан толтуруучу файлла кеслери алларына кёрюнедиле.
- **Тири излеу.** Мингле бла оюнну ичинде оюнну аты неда толтуруучу файлы бла терк излеу, плиткала неда къысха список халда кёргюзтюу, сайланнганла эмда «Ахыргыла» сафы.
- **Бир басыу бла.** Оюнну сайлагъыз, толтуруучу файлны сайлагъыз (бир талай болса), къаллай бир минут тутаргъа кереклисин белгилегиз эмда ийиуню басыгъыз. Ызына санаучу халкъа бла билдириу заман бошалгъанын билдирирле.
- **Ызындан бир зат да къоймайды.** Алдаучу процесс (decoy) джангыз ишлеген заманында бар болады: гитче exe файл ийилгенде къуралады эмда тохтатылгъанда къоратылады. Программадан чыкъгъан заманда бары да тохтайды, программа бузулуп джабылса уа, къалгъан къалдыкъла эндиги ийилгенде тазаланадыла.
- **Шош.** Система трейде турады, decoy процесслени кеслери ючюн терезелери неда борчланы панелинде басмалары болмайды.
- **Ачыкъ кёчюрмеле.** Интерфейс ябай JSON файлла бла ишлейди, джангы тил къошуу джангыз бир файлды. Ингилиз бла орус тилле къошулуп турадыла.
- **Шайлылыкъ.** Аккаунтсуз, Discord токенсиз, телеметриясыз. [Шайлылыкъ](#шайлылыкъ) бёлюмню къарагъыз.

## Ол къалай ишлейди

1. Discord сиз оюнну ойнай турасыз деп компьютеригизде ишлеп тургъан процесслени ачыкъ список бла (`/api/v9/applications/detectable`) тенглешдирип ангылайды.
2. Decoy ол списокну джюклейди эмда сиз сайлагъан оюн ючюн гитче алдаучу программаны (120 КБ чакълы бир, Rust тилде джазылгъан эмда Decoy-ну ичине салыннган) заманлы папкагъа списокдагъы толтуруучу файлны аты бла джазады, сёз ючюн `.../cod26-cod.exe`.
3. Бу алдаучу программа бир баш терезени тутуудан башха бир зат да этмейди; ол терезе экрандан узакъда тохтатылады, аны ючюн сиз аны бир заманда да кёрмейсиз. Discord джангыз терезеси болгъан процесслени таныйды, терезесиз процесслени уа эслемейди.
4. 15 секунд чакълы бирни ичинде Discord ол оюнну сизни бусагъатдагъы ишигизча кёргюзтеди.
5. Таймер бошалгъанда неда сиз тохтатыу басманы басханыгъызда, Decoy процессти тохтатады эмда файлны къоратады. Windows job objectDecoy къазауатха учураса окъуна алдаучу процесслени аны бла бирге тохтауун баджарады.

## Орнатыу

[Релизле](../../../../releases) бетинден бирин сайлагъыз:

| Джюклерге | Нек |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Орнатыучу (Installer).** Бир къулланыучу ючюн, администратор эркинликле керек тюлдюле, «Пуск» менюге бёлюм эмда къоратыучуну къошады. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив (Portable).** Къайры болса да архивден чыгъарыгъыз эмда `decoy.exe`-ни ачыгъыз. Бютеу билгиле къатындагъы `data` папкада турадыла, къулланыучу профилине бир зат да джазылмайды. Къоратыр ючюн джангыз папканы кесин къоратыгъыз. |

Джюкленнген файлны `SHA256SUMS.txt` болушлугъу бла сынагъыз (PowerShell-де `Get-FileHash <file>`).

Сборкалада цифралы къол салынмагъаны ючюн Windows SmartScreen белгисиз басмалаучу деп билдирирге боллукъду; сборкагъа ышана эсегиз, *Кёбюрек билги (More info) → Барыбир бардырыргъа (Run anyway)* сайлагъыз.

Талаб этилген затла: WebView2 runtime болгъан Windows 10 неда 11 (64-битлик) (Windows 11-де эмда ахыргы Windows 10 джангыртыуларында барды).

## Хайырланыу

1. **Библиотеканы** ачыгъыз эмда оюнну излегиз, неда къайдан болса да `Ctrl` + `K` басыгъыз.
2. Оюннга басыгъыз. Онг джанындагъы панелде процессти эмда аны къаллай бир минут тутаргъа кереклисин сайлагъыз (Discord-ну джумушларына асламысында 15 минут соралады).
3. **Decoy-ну ийиу** басыгъыз. Discord оюнну талай секунддан кёргюзтерикди.
4. Анга **Ишлей турады** бёлюмде къарагъыз, бирин неда бютеуюн къайсы заманда да тохтатыгъыз, неда Decoy-ну джангыз трейде къоюгъуз.

Discord списогунда толтуруучу файллары болмагъан оюнла башланнганда букъдурулуп турадыла (ала танылыргъа болмайдыла). Аланы кёрюр ючюн *Exe-си болмагъан оюнланы кёргюзтюу* дегенни къошугъуз; список кюн сайын джангыртылады, ол сэбебли Discord процессни къошханлай ала ачыкъ боллукъдула.

### Команда тизгини

```
decoy.exe --launch "<Discord списогундан толтуруучу файлны джолу>" [минутла]
```

Алдаучу процессти терк иеди, сёз ючюн: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Исходникледен жыйыу

Ал шартла: [Node.js](https://nodejs.org) 20+, Visual Studio C++ жыйыу къураллары болгъан стабил [Rust](https://rustup.rs) инструментлери (MSVC target), эмда WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload бла айнытыу режиминде ийиу
npm run tauri build    # src-tauri/target/release/bundle/nsis ичинде къураучу файлны этиу
```

Пайдалы тинтиуле:

```bash
npm run check-locales  # ru.json бла хар кёчюрме файлны сынау
npx tsc --noEmit       # фронтендни типлерин тинтиу
cargo check --manifest-path src-tauri/Cargo.toml
```

Эсгертиуле: decoy exe файлы `src-tauri/build.rs` аркъалы `src-tauri/stub/stub.rs` кодундан ябай `rustc` бла жыйылады эмда программаны ичине салынады. Фронтенд ябай браузерде ишлеген заманда (`npm run dev`) гитче мок-бэкенд (`src/mock.ts`) хайырландырылады, бу интерфейс бла ишлерге къолайлыды.

## Кёчюрмеле

Интерфейс тизгинлери [`src/locales`](../../src/locales) ичинде турадыла, хар тил ючюн бир JSON файл (`en.json`, `ru.json`, ...).
Джангы тил къошуу жангыз бир файл къошууну билдиреди; кодха къошулуу керекмейди. Файлны форматы, машина кёчюрме ючюн хазыр промпт эмда тинтиу скрипти ючюн [docs/TRANSLATING.md](../TRANSLATING.md) файлын къарагъыз. Бу README-ни кёчюрмелери `docs/i18n/README.<code>.md` папкагъа салынадыла.


## Шайлылыкъ

- Decoy сетни джангыз Discord-ну ачыкъ таныу списогун джюклер ючюн (биринчи ийилгенде, андан сора кюнюне бирден кёб болмай неда джангыртыуну басханыгъызда) эмда Discord-ну CDN-инен оюнланы суратлары бла къапларын кёргюзтюр ючюн хайырланады.
- Ол сизнин Discord токенигизни неда аккаунт билгилеригизни окъумайды, сакъламайды эмда иймейди, Discord клиенти бла да байламлыкъ тутмайды.
- Жарашдырыула (сайланнганла, тил, заманла) программаны WebView сакълауунда локал сакъланадыла; оюн списокну кэши бла заманлы decoy файлла `%LOCALAPPDATA%\app.decoy.desktop` ичинде турадыла.
- Аналитика, авария отчетла, аккаунтла джокъдула.

## Белгили чеклениуле

- Discord оюнланы таныу къайдасын къайсы заманда да тюрлендирирге боллукъду. Алдаучу процесс танылмай къалса, тилейбиз, issue ачыгъыз.
- Бир къауум ишге ишлеп тургъан процесстен эсе артыкъ зат керек болады (сёз ючюн оюн платформаны белгили бир режиминде болуу). Decoy джангыз процессни алдайды.
- Discord списогунда толтуруучу файллары болмагъан оюнла танылыргъа болмайдыла.
- Къоруулау программала эсде бош тургъан къол салынмагъан гитче толтуруучу файллагъа сакъ къараргъа боллукъдула. Decoy-ну башлангъан коду ачыкъды эмда ол `src-tauri/stub/stub.rs` файлындан жыйылады; аны кесигиз жыяргъа боллукъсуз.

## Юлюш къошуу

Халатла юсюнден билдириуле, идеяла эмда кёчюрмеле къууанып къабыл этиледиле. Тилейбиз, алгъа [CONTRIBUTING.md](../../CONTRIBUTING.md) файлын окъугъуз.

## Джууаблылыкъдан баш тартыу

Decoy энчи, билим бериу эмда сынау муратла ючюн «къалай бар эсе алай» бериледи. Ишлеген оюнну имитация этиу Discord-ну неда оюнну чыгъарыучусуну Хайырланыу шартларын бузаргъа боллукъду эмда аккаунтугъузгъа чеклениулеге келтирирге болур. Аны къалай хайырландыргъаныгъыз ючюн джангыз кесигиз джууаблысыз. «Discord» эмда бютеу оюн атла бла логотипле кеслерини иелерини сатыу маркаларыдыла эмда мында джангыз тийишли программаны белгилер ючюн хайырландырыладыла.
