# Decoy

**Discord оонньуу үлэлии турар диэн саныырыгар анаммыт кыракый заглушка-бырассыастар.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Соторутааҥҥы оонньуулардаах уонна ойуулардаах Decoy библиотеката" />

</div>

Decoy оонньуу толорооччу билэтин (executable) аатынан куттала суох, түннүктээх заглушка-бырассыаһы ыытан тутар, онон Discord оонньууну булуу тиһигэ эһигини ол оонньууну оонньуу турар курдук көрдөрөр. Дьиҥнээх оонньууну туруоруохха эбэтэр ыытыахха наадата суох, онон диискэҕэ улахан туох да сыппат.

Кини **Discord булуон сөптөөх бары оонньууларын** билэр (25 000 кэриҥэ сурук), тоҕо диэтэххэ Discord бэйэтин аһаҕас тиһигин ааҕар уонна ону бэйэтэ саҥардан иһэр.

> [!WARNING]
> Үлэлии турар оонньууну үтүктүү Discord туттуутун быраабылатыгар сөп түбэспэт буолуон сөп уонна эһиги Decoy-ну **бэйэҕит сэрэххитигэр** туттаҕыт.
> Бу бырайыак Discord Inc. кытта сибээһэ суох, кинилэртэн өйөммөт уонна бигэргэтиллибэтэх. [Эппиэтинэстэн батыныы](#эппиэтинэстэн-батыныы) көрүҥ.

## Кыахтара

- **Discord булуон сөптөөх барыта.** Оонньуулар тиһиктэрэ Discord аһаҕас эндпоинтыттан хачаастанар, локальнайдык кэштэнэр уонна күн аайы саҥардыллар. Саҥа оонньуулар уонна саҥа эбиллибит толорооччу билэлэр бэйэлэрэ көстөн кэлэллэр.
- **Түргэн көрдөөһүн.** Тыһыынчанан оонньуулар истэригэр оонньуу аатынан эбэтэр толорооччу билэтинэн тута көрдөөһүн, плиткаларынан эбэтэр кыараҕас тиһигинэн көрүү, таллыллыбыттар уонна «Соторутааҕыта» устуруока.
- **Биир баттааһынан.** Оонньууну тал, толорооччу билэни тал (хас да буоллаҕына), төһө өр тутары ый уонна заглушканы ыыт баттаа. Төттөрү ааҕар тиэрбэс уонна биллэрии кэм бүппүтүн биллэриэхтэрэ.
- **Кэннигэр тугу да хаалларбат.** Заглушка үлэлии турар эрэ кэмигэр баар буолар: кырачаан exe ыытыллыыга оҥоһуллар уонна тохтотуллууга сотуллар. Култуураттан таҕыстахха барыта тохтуур, оттон моһуоктаныы кэнниттэн хаалбыт билэлэр кэлэр ыытыыга ыраастаналлар.
- **Чуумпу.** Систиэмэ трейигэр олорор, заглушкалар бэйэлэригэр соруктар паанелларыгар эбэтэр түннүктэр суохтар.
- **Аһаҕас тылбаастар.** Интерфейс судургу JSON билэлэринэн үлэлиир, онон тылы эбии — биир эрэ билэ. Английскай уонна нуучча тыллара киллэриллибиттэр.
- **Бүччүм буолуу.** Аккаунт суох, Discord токена суох, телеметрия суох. [Бүччүм буолуу](#бүччүм-буолуу) көрүҥ.

## Хайдах үлэлиирэ

1. Discord көмпүүтэргэ үлэлии турар бырассыастары бэрэбиэркэлээн уонна кинилэр толорооччу билэлэрин ааттарын аһаҕас тиһиги кытта (`/api/v9/applications/detectable`) тэҥнээн, эһиги оонньуу оонньуу сылдьаргытын быһаарар.
2. Decoy бу тиһиги хачаастыыр уонна талбыт оонньуугутугар тиһиктэн толорооччу билэ аатын туттан (холобур, `.../cod26-cod.exe`), кырачаан заглушка-бырагырааманы (120 КБ кэриҥэ, Rust тылыгар суруллубут уонна Decoy иһигэр киллэриллибит) быстах кэмҥэ туттуллар паапкаҕа куопуйалыыр.
3. Заглушка экраантан ыраах олорор үрдүкү таһымнаах биир түннүгү тутарын таһынан тугу да гыммат, онон эһиги кинини хаһан да көрбөккүт. Discord түннүктээх эрэ бырассыаһы билинэр, ол иһин түннүгэ суох бырассыас аахайыллыбат.
4. 15 сөкүүндэ иһинэн Discord бу оонньууну эһиги билиҥҥи дьарыккыт курдук көрдөрөр.
5. Таймер бүттэҕинэ эбэтэр тохтотууну баттаатахха, Decoy бырассыаһы түмүктүүр уонна билэни сотор. Windows job объекэ Decoy сабыллар кэмигэр, ол иһигэр көтөн түстэҕинэ даҕаны, заглушкалар кинини кытта бииргэ өлөллөрүн мэһэйдээбэккэ хааччыйар.

## Туруоруу

[Releases](../../../../releases) сирэйиттэн биири талыҥ:

| Хачаастааһын | Туохха |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Орнотооччу (Installer).** Биир туттааччыга анаммыт, администратор бырааба наадата суох, «Пуск» мэньюгэ суругу уонна суорааччыны (uninstaller) эбэр. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативнай.** Ханна баҕарар таһаарыҥ уонна `decoy.exe` ыытыҥ. Бары дааннайдар аттыгар баар `data` паапкатыгар хаалаллар, туттааччы профилигэр туох да суруллубат. Суох гынарга паапканы сотуҥ. |

Хачаастаммыт билэни `SHA256SUMS.txt` көмөтүнэн бэрэбиэркэлээҥ (PowerShell иһигэр `Get-FileHash <билэ>`).

Windows SmartScreen сыыппара илии баттааһына суох буолан биллибэт таһаарааччы туһунан сэрэтиэн сөп; сборкаҕа эрэнэр буоллаххына, *Сиһилии (More info) → Барытын үрдүнэн ыыт (Run anyway)* талыҥ.

Ирдэбиллэр: WebView2 runtime баар Windows 10 эбэтэр 11 (64-бит) (Windows 11 уонна Windows 10 кэнники саҥардыыларыгар киирэ сылдьар).

## Туттуу

1. **Библиотеканы** арыйыҥ уонна оонньууну көрдөөҥ, эбэтэр хантан баҕарар `Ctrl` + `K` баттааҥ.
2. Оонньууну баттааҥ. Уҥа паанелга бырассыаһы уонна хас мүнүүтэ тутары талыҥ (Discord сорудахтарыгар үксүгэр 15 мүнүүтэ көрдөнөр).
3. **Заглушканы ыыт** баттааҥ. Discord аҕыйах сөкүүндэнэн оонньууну көрдөрүөҕэ.
4. Кинини **Үлэлии турар** диэн сиргэ көрүҥ, ханнык баҕарар кэмҥэ биири эбэтэр барытын тохтотуҥ, эбэтэр Decoy-ну трейгэ хаалларыҥ.

Discord тиһигэр өссө толорооччу билэлэрэ суох оонньуулар анараа өттүгэр кистэнэллэр (кинилэри булар сатаммат). Кинилэри көрөргө *Exe суоҕу көрдөр* опцияны холбооҥ; тиһик күн аайы саҥардыллар, онон Discord бырассыаһы эппитин кытта кинилэр тута көстөн кэлиэхтэрэ.

### Хамаанда устуруоката

```
decoy.exe --launch "<Discord тиһигиттэн толорооччу билэ суола>" [мүнүүтэ]
```

Заглушканы тута ыытар, холобур `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Төрүт кодуттан хомуйуу

Бастакы ирдэбиллэр: [Node.js](https://nodejs.org) 20+, Visual Studio C++ хомуйар үнүстүрүмүөннэрдээх бигэ [Rust](https://rustup.rs) үнүстүрүмүөннэрин набора (MSVC target), уонна WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload-таах сайыннарыы эрэсимигэр ыытыы
npm run tauri build    # src-tauri/target/release/bundle/nsis иһигэр орнотооччуну оҥоруу
```

Туһалаах бэрэбиэркэлэр:

```bash
npm run check-locales  # хас биирдии тылбаас билэтин ru.json кытта тэҥнээн бэрэбиэркэлээһин
npx tsc --noEmit       # фронтенд тииптэрин бэрэбиэркэлээһин
cargo check --manifest-path src-tauri/Cargo.toml
```

Бэлиэтээһиннэр: заглушка exe-тэ `src-tauri/build.rs` көмөтүнэн `src-tauri/stub/stub.rs` билэтиттэн көннөрү `rustc` туттан хомуллаллар уонна сыһыарыы иһигэр кыбытыллаллар. Фронтенд судургу браузерга ыытылыннаҕына (`npm run dev`), кырачаан мок-бэкенд (`src/mock.ts`) туттуллар, бу UI оҥорорго табыгастаах.

## Тылбаастар

Интерфейс устуруокалара [`src/locales`](../../src/locales) иһигэр бааллар, хас биирдии тылга биирдии JSON билэ (`en.json`, `ru.json`, ...).
Тылы эбии диэн саҥа билэни эбии буолар; код уларыйбат. Билэ форматын, массыынанан тылбааска анаммыт бэлэм промпты уонна бэрэбиэркэлиир скриби көрөргө [docs/TRANSLATING.md](../TRANSLATING.md) көрүҥ. Бу README тылбаастара `docs/i18n/README.<code>.md` паапкаҕа киирэллэр.

## Бырайыак тутула

```
src/                    React + TypeScript фронтенд
  components/           Библиотека, сиһилии паанел, туруоруулар, ...
  locales/              тылбаас билэлэрэ (биир тылга биир JSON)
  i18n-core.ts          тылы хачаастааһын уонна көрдөөһүн
  store.ts              сыһыарыы туруга (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            оонньуулар базалара, заглушка-бырассыастар, трей
  stub/stub.rs          иһигэр киллэриллэр заглушка-бырагыраама
scripts/                көмө скриптэр (локаллары бэрэбиэркэлээһин)
docs/                   тылбаас салаата, скриншоттар
```

## Бүччүм буолуу

- Decoy ситими Discord аһаҕас тиһигин хачаастыырга эрэ туттар (бастакы ыытыыга, онтон сууккаҕа биирдэ эбэтэр саҥардыыны баттаатахха) уонна көрдөрөргө Discord аһаҕас CDN-иттэн оонньуу значоктарын уонна ойууларын ыларга.
- Кини эһиги Discord токеҥҥытын эбэтэр аккаунт ханнык да дааннайдарын аахпат, харайбат уонна ыыппат, ону тэҥэ Discord клиенын кытта кэпсэппэт.
- Туруоруулар (таллыллыбыттар, тыл, болдьохтор) сыһыарыы WebView харайыытыгар локальнайдык хараллаллар; оонньуулар тиһиктэрин кэшэ уонна быстах кэмнээх заглушка билэлэрэ `%LOCALAPPDATA%\app.decoy.desktop` иһигэр бааллар.
- Аналитика суох, моһуоктаныылар отчуоттара суох, аккаунт суох.

## Биллиилээх хааччахтар

- Discord көрдөөһүн хайдах үлэлиирин ханнык баҕарар кэмҥэ уларытыан сөп. Өскөтүн заглушка биллибэт буоллаҕына, баһаалыста, issue арыйыҥ.
- Сорох дьарыктарга үлэлии турар бырассыастааҕар элбэх ирдэнэр (холобур, оонньуу былаһааккатын биир эмэ эйгэтигэр киирэн олоруу). Decoy бырассыаһы эрэ үтүктэр.
- Discord тиһигэр толорооччу билэтэ суох суруктар булуллубаттар.
- Көмүскүүр программалар сороҕор өйдөбүлгэ (память) кураанах турар илии баттааһына суох кыра толорооччу билэлэргэ сэрэтиэхтэрин сөп. Заглушка аһаҕас кодтаах уонна `src-tauri/stub/stub.rs` билэтиттэн хомуллар; бэйэҕит хомуйуоххутун сөп.

## Үлэҕэ кыттыһыы

Сыыһалар тустарынан биллэриилэр, санаалар уонна тылбаастар кэлэллэрин үөрэ көрсөбүт. Бастаан [CONTRIBUTING.md](../../CONTRIBUTING.md) ааҕыҥ.

## Эппиэтинэстэн батыныы

Decoy тус бэйэ, үөрэх уонна бэрэбиэркэлиир сыалга «баарынан» бэриллэр. Үлэлии турар оонньууну үтүктүү Discord эбэтэр оонньуу таһаарааччытын туттуутун Быраабылаларын кэһиэн сөп уонна эһиги аккааккытыгар дьайыы оҥоһуллуон сөп. Кинини хайдах туттаргытыгар эһиги бэйэҕит эрэ эппиэтинэстээххит. «Discord» уонна бары оонньуу ааттара, логотиптара бэйэлэрин бас билээччилэрин саадабай мааркалара буолаллар уонна манна сыһыаннаах программаларын быһаарарга эрэ туттуллаллар.
