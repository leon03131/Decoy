# Decoy

**Proses pangganti cilik sing nggawe Discord ngira game lagi mlaku.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Kapustakan Decoy kanthi game anyar lan artwork" />

</div>

Decoy njaga proses pangganti sing ora mbebayani kanthi jendhela tetep mlaku nganggo jeneng berkas eksekusi game, saengga deteksi game Discord nglaporake yen sampeyan lagi main game kasebut. Sampeyan ora perlu masang utawa mbukak game asline, dadi ora ana berkas gedhe sing ngebak-ngebaki panyimpenan sampeyan.

Aplikasi iki ngerti babagan **saben game sing bisa dideteksi Discord** (udakara 25.000 entri) amarga maca dhaptar deteksi umum duweke Discord dhewe lan nganyari kanthi otomatis.

> [!WARNING]
> Malsokake game sing lagi mlaku bisa wae nglanggar Katemtuan Layanan Discord lan sampeyan nggunakake Decoy **kanthi resiko sampeyan dhewe**.
> Proyek iki ora ana sesambungane karo, ora disengkuyung dening, utawa disambungake karo Discord Inc. Deleng [Panyangkalan](#panyangkalan).

## Fitur

- **Kabeh sing bisa dideteksi Discord.** Dhaptar game diundhuh saka endpoint deteksi umum Discord, disimpen sacara lokal, lan dianyari saben dina. Game anyar lan berkas eksekusi sing mentas ditambahake bakal katon kanthi otomatis.
- **Panggolekan sing cepet.** Golek kanthi cepet miturut jeneng game utawa berkas eksekusi ing antarane ewonan game, tampilan kothak utawa dhaptar ringkes, pilihan, lan baris "Bubar iki".
- **Sak klik.** Pilih game, pilih berkas eksekusi (yen ana pirang-pirang), tentukake pira suwene arep njaga, banjur pencet wiwiti. Dering etungan mundur lan kabar bakal ngandhani yen wektune wis entek.
- **Ora ninggalake tilas.** Decoy mung ana nalika lagi mlaku: berkas exe cilik digawe nalika diwiwiti lan dibusak nalika dimandhegake. Kabeh dimandhegake nalika sampeyan metu, lan sisa-sisa amarga crash bakal diresiki nalika aplikasi dibukak maneh.
- **Meneng.** Manggon ing baki sistem (system tray), tanpa jendhela utawa tombol taskbar kanggo decoy kasebut dhewe.
- **Terjemahan tinarbuka.** Antarmuka diatur nganggo berkas JSON biasa, dadi nambahake basa anyar mung mbutuhake sak berkas. Basa Inggris lan Rusia wis klebu.
- **Privat.** Tanpa akun, tanpa token Discord, tanpa telemetri. Deleng [Privasi](#privasi).

## Cara kerja

1. Discord nemtokake manawa sampeyan lagi main game kanthi mriksa proses sing lagi mlaku ing PC sampeyan lan mbandhingake jeneng berkas eksekusi karo dhaptar umum (`/api/v9/applications/detectable`).
2. Decoy ngundhuh dhaptar kasebut lan, kanggo game sing sampeyan pilih, nyalin program pangganti cilik (udakara 120 KB, ditulis nganggo Rust lan dilebokake ing Decoy) menyang folder sauntara nggunakake jeneng berkas eksekusi saka dhaptar kasebut, contone `.../cod26-cod.exe`.
3. Program pangganti ora nindakake apa-apa kajaba duwe sak jendhela tingkat ndhuwur (top-level window), sing dipanggonake adoh ing njaba layar supaya sampeyan ora tau ndeleng. Discord mung ngenali proses sing duwe jendhela, mulane proses sing babar blas ora duwe jendhela bakal diabaikake.
4. Sajrone kira-kira 15 detik, Discord bakal nuduhake game kasebut minangka kagiyatan sampeyan saiki.
5. Nalika wektune entek utawa sampeyan mencet mandheg, Decoy mungkasi proses lan mbusak berkas kasebut. Windows job object mesthekake decoy mati bareng karo Decoy, sanajan aplikasi ngalami crash.

## Masang

Pilih salah siji saka kaca [Releases](../../../../releases):

| Undhuhan | Kanggo |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Pamasang.** Saben pangguna, ora butuh hak administrator, nambahake entri menu Wiwiti (Start menu) lan uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Ekstrak ing endi wae banjur bukak `decoy.exe`. Kabeh data tetep ana ing folder `data` ing sandhinge, ora ana sing ditulis menyang profil pangguna sampeyan. Busak foldere kanggo mbusak aplikasi. |

Priksa undhuhan nganggo `SHA256SUMS.txt` (`Get-FileHash <file>` ing PowerShell).

Windows SmartScreen bisa wae ngelingake babagan penerbit sing ora dingerteni amarga build ora ditandatangani nganggo sertifikat digital; pilih *More info → Run anyway* yen sampeyan percaya karo build kasebut.

Syarat: Windows 10 utawa 11 (64-bit) kanthi WebView2 runtime (wis klebu ing Windows 11 lan nganyari anyar Windows 10).

## Panganggo

1. Bukak **Kapustakan** lan golek game, utawa pencet `Ctrl` + `K` saka ngendi wae.
2. Klik sawijining game. Ing panel sisih tengen, pilih proses lan pira menit arep njaga (kagiyatan Discord biasane njaluk 15).
3. Pencet **Mulai decoy**. Discord bakal nuduhake game kasebut sawise sawetara detik.
4. Deleng ing bagean **Mlaku**, mandhegake siji utawa kabeh kapan wae, utawa cukup tinggalake Decoy ing tray.

Game sing entrine ing Discord durung duwe berkas eksekusi didelikake kanthi standar (game kasebut durung bisa dideteksi). Uripake *Tampilake game tanpa exe* kanggo ndeleng; dhaptar iki dianyari saben dina, dadi bakal kasedhiya sanalika Discord nambahake proses.

### Baris printah

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Miwiti decoy kanthi langsung, contone `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Mbangun saka sumber

Prasyarat: [Node.js](https://nodejs.org) 20+, toolchain [Rust](https://rustup.rs) stabil (target MSVC) kanthi piranti pambangun Visual Studio C++, lan WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # mlaku ing mode pangembangan kanthi hot reload
npm run tauri build    # ngasilake pamasang ing src-tauri/target/release/bundle/nsis
```

Pamariksaan sing migunani:

```bash
npm run check-locales  # mriksa saben berkas terjemahan marang ru.json
npx tsc --noEmit       # mriksa tipe ing frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Cathetan: berkas exe decoy dikompilasi dening `src-tauri/build.rs` nggunakake `rustc` standar saka `src-tauri/stub/stub.rs` banjur dilebokake menyang aplikasi. Nalika frontend mlaku ing browser biasa (`npm run dev`), backend tiruan (mock) cilik (`src/mock.ts`) bakal digunakake, sing trep banget kanggo nggarap UI.

## Terjemahan

Teks antarmuka pangguna manggon ing [`src/locales`](../../src/locales), sak berkas JSON saben basa (`en.json`, `ru.json`, ...). Nambah basa tegese cukup nambah sak berkas; ora perlu ngowahi kode. Deleng [docs/TRANSLATING.md](../TRANSLATING.md) kanggo format berkas, pituduh siap-pakai kanggo terjemahan mesin, lan skrip pamriksan. Terjemahan README iki disimpen ing `docs/i18n/README.<code>.md`.

## Tata letak proyek

```
src/                    Frontend React + TypeScript
  components/           Kapustakan, panel rincian, setelan, ...
  locales/              berkas terjemahan (sak JSON saben basa)
  i18n-core.ts          ngunggah basa lan panggolekan
  store.ts              kahanan aplikasi (zustand)
src-tauri/              Backend Rust (Tauri 2)
  src/lib.rs            basis data game, proses decoy, tray
  stub/stub.rs          program pangganti sing dilebokake
scripts/                skrip pambiyantu (pamriksan locale)
docs/                   pandhuan nerjemahake, tangkapan layar
```

## Privasi

- Decoy mung nggunakake jaringan kanggo ngundhuh dhaptar deteksi umum Discord (nalika wiwitan dibukak, banjur paling akeh sedina sepisan utawa nalika sampeyan mencet anyari) lan, kanggo tampilan, lambang game lan artwork saka CDN umum Discord.
- Aplikasi iki ora maca, nyimpen, utawa ngirim token Discord sampeyan utawa data akun apa wae, lan ora komunikasi karo klien Discord.
- Setelan (pilihan, basa, suwene) disimpen sacara lokal ing panyimpenan WebView aplikasi; cache dhaptar game lan berkas sauntara decoy manggon ing `%LOCALAPPDATA%\app.decoy.desktop`.
- Ora ana analitik, ora ana laporan crash, ora ana akun.

## Watesan sing dingerteni

- Discord bisa ngowahi cara kerja deteksi kapan wae. Yen decoy ora dingerteni maneh, mangga bukak issue.
- Sawetara kagiyatan mbutuhake luwih saka mung proses sing mlaku (contone ana ing pengalaman tartamtu ing platform game). Decoy mung nirokake prosese.
- Entri tanpa berkas eksekusi ing dhaptar Discord ora bisa dideteksi.
- Piranti lunak keamanan sok-sok nandhani berkas eksekusi cilik tanpa tandha tangan digital sing meneng ing memori. Decoy asipat sumber tinarbuka (open source) lan dibangun saka `src-tauri/stub/stub.rs`; sampeyan bisa ngompilasi dhewe.

## Pasumbang

Laporan bug, gagasan, lan terjemahan tansah ditampa kanthi seneng. Mangga waca [CONTRIBUTING.md](../../CONTRIBUTING.md) dhisik.

## Panyangkalan

Decoy disediyakake "apa anane" kanggo tujuan pribadi, pamulangan, lan uji coba. Nirokake game sing lagi mlaku bisa wae nglanggar Katemtuan Layanan Discord utawa penerbit game kasebut, lan bisa nyebabake tindakan marang akun sampeyan. Sampeyan dhewe sing tanggung jawab babagan carane nggunakake aplikasi iki. "Discord" lan kabeh jeneng game uga logo yaiku merek dagang saka pamilike dhewe-dhewe lan mung digunakake ing kene kanggo ngenali piranti lunak sing dirujuk.
