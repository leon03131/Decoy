# Decoy

**Discord-на ловзар латийна хетийта кегийра йолу процессаш.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека кесталера ловзаршца а, суьрташца а" />

</div>

Decoy-с ловзаран exe файлан цӀарца зен доцу, кор долу процесс-заглушка латийна латтайо, цундела Discord-ан
ловзарш билгалдахаран системо хьо и ловзар ловзуш гойту. Хьуна боккъала а долу ловзар хӀотто йа лато ца оьшу,
цундела диска тӀехь совнах хӀума ца дуьсу.

Цунна **Discord-на билгалдаккха хууш долу массо а ловзар** девза (25 000 гергга йаззам), хӀунда аьлча цо
Discord-ан шен йукъара могӀам йоьшу, тӀаккха ша иза керладаккхарца Ӏалашдо.

> [!WARNING]
> Ловзар харц латор Discord-ан Шерташца догӀуш ца хила тарло, Decoy **хьайн лаамехь а, кхерамехь а** леладо ахь.
> ХӀокху проектан Discord Inc. компаница йукъаметтиг йац, цо къобалйина йа гӀо лацан йац. Хьажа [Бехк цабиллар](#бехк-цабиллар).

## Билгалдахарш

- **Discord-на билгалдаккха хууш долу дерриге.** Ловзарийн могӀам Discord-ан йукъара хьостера схьаоьцу, локально
  кэш до, хӀора дийнахь керладоккху. Керла ловзарш а, керла тӀетоьхна exe файлаш а шаьш гучуйовлу.
- **Чехка лахар.** Эзарнаш ловзаршна йукъахь цӀарца йа exe файлца сихха лахар, уьнашца йа юткъа могӀамца гайтар,
  хаьржинарш а, «Кесталера» могӀа а.
- **Цхьаьна таӀорца.** Ловзар харжа, exe файл харжа (дуккха а елахь), мел минотана латто йеза билгаладе, тӀаккха латаде.
  Хан лоручу чӀагаро а, хаамо а хан чекхйаьлча хоуьйтур ду.
- **ТӀаьхьа лар ца йуьту.** Decoy иза болх бечу хенахь бен йац: жима exe латийначу хенахь кхоллало, сацийча дӀайовлу.
  Программера арадолуш дерриге а сацадо, ткъа харц сецначул тӀаьхьа йисина файлаш тӀаьхьа латош цӀанйо.
- **Тийна раж.** Системин трей чохь Ӏалашло, заглушкашна шайна лерина кораш йа панель тӀехь кнопкаш йац.
- **Йиллина гочдарш.** Интерфейс атта JSON файлаш тӀехь болх беш йу, цундела керла мотт тӀетохар — цхьа файл йу.
  Инглис а, оьрсийн а меттанаш чулаьцна ду.
- **Къайлахалла.** Аккаунт оьшуш йац, Discord токен йац, телеметри йац. Хьажа [Къайлахалла](#къайлахалла).

## Иза муха болх беш ду

1. Discord-о хьо компьютер тӀехь болх беш йолу процессашка хьаьжна, церан exe файлийн цӀераш шен йукъара
   могӀамца (`/api/v9/applications/detectable`) йустуш билгалдоккху ловзар ловзуш хилар.
2. Decoy-с и могӀам схьаоьцу, ахь хаьржинчу ловзарна цхьа жима программа-заглушка (120 KB гергга, Rust маттахь
   йазйина, Decoy чу хӀоттийна) ханна йолчу папка чу копи йо, могӀамера цӀарца, масала `.../cod26-cod.exe`.
3. Заглушко хӀумма а ца до, экранел арахьа дӀахӀоттийна цхьа кор бен. Discord-о кор долу процесс бен ца
   лоьру, цундела кор доцу процесс Ӏадйуьту.
4. 15 секунд гергга йаьлча Discord-о хьо оцу ловзарехь ловзуш ву аьлла гойту.
5. Таймер чекхйаьлча йа ахь сацийча, Decoy-с процесс дӀакъовлу, тӀаккха файл дӀайоккху. Windows job object-о
   Decoy-ца цхьаьна массо а заглушкаш дӀакъовлу, программа гӀалатца сецнехь а.

## ХӀоттор

[Releases](../../../../releases) агӀон тӀера харжа:

| Схьаэцар | Хьанна ду |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ХӀотторг (Installer).** ХӀора лелорхочунна, администраторан бакъонаш ца оьшу, «Пуск» меню чу тӀетуху, дӀайоккхург йу. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативни (Portable).** Муьлхха метте схьаделла, `decoy.exe` латаде. Массо хаамаш цуьнан уллерчу `data` папка чохь Ӏалашдо, лелорхочун профиле хӀумма а ца йаздо. ДӀайаккха папка дӀайаьккхича хьана ду. |

Схьаэцнарг `SHA256SUMS.txt` чохь талла (PowerShell чохь `Get-FileHash <file>`).

Windows SmartScreen-о билгал ца ваьккхинчу арахецархочун хьокъехь хаам бан тарло, хӀунда аьлча цифран куьг дац;
нагахь санна тешаш балахь, *More info → Run anyway* харжа.

Оьшурш: Windows 10 йа 11 (64-бит) WebView2 runtime-ца (Windows 11 чохь а, керлачу Windows 10 керладахаршкахь а хӀинцале ду).

## Лелор

1. **Библиотека** схьаелла, ловзар лаха, йа муьлхха меттехь `Ctrl` + `K` тӀетаӀаде.
2. Ловзаран тӀетаӀаде. Аьтту агӀор йолчу панелехь процесс харжа, мел минотана латто йеза билгалде (Discord квесташна дукха хьолахь 15 оьшу).
3. **Decoy лато** тӀетаӀаде. Масех секундехь Discord-о ловзар гучудоккхур ду.
4. **Латийна** вкладкехь хьажа, цхьаъ йа массо а сацо мегар ду, йа Decoy трей чохь дита.

Discord могӀамехь exe йоцу ловзарш Ӏадйитинчу кепара къайлаха йу (уьш билгалдан йиш йац). Уьш ган *Exe йоцу ловзарш гайта*
латийна хила деза; могӀам хӀора дийнахь керлабоккху, цундела Discord-о процесс тӀетоьхча уьш тӀекхочур ду.

### Командийн могӀа

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy сихха латадо, масала `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Хьостера гулйар

Оьшурш: [Node.js](https://nodejs.org) 20+, бакъ [Rust](https://rustup.rs) гӀирсаш (MSVC target)
Visual Studio C++ build tools-ца, кхин а WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # талларан ражехь латор hot reload-ца
npm run tauri build    # хӀотторг кхоллар src-tauri/target/release/bundle/nsis чохь
```

Пайден талламаш:

```bash
npm run check-locales  # массо гочдаран файл ru.json тӀехь таллар
npx tsc --noEmit       # фронтендан тайпанаш таллар
cargo check --manifest-path src-tauri/Cargo.toml
```

Билгалдахар: Decoy exe файл `src-tauri/build.rs` чохь ялсаманин `rustc` гӀоьнца `src-tauri/stub/stub.rs` файлах гулйо,
тӀаккха программа чу хӀоттайо. Фронтенд браузер чохь латийначу хенахь (`npm run dev`) жима mock backend
(`src/mock.ts`) леладо, иза UI-ца болх бан атта ду.

## Гочдарш

Интерфейсан могIанаш [`src/locales`](../../src/locales) чохь ду, хӀора маттана цхьа JSON файл (`en.json`, `ru.json`, ...).
Керла мотт тӀетохар — цхьа файл тӀетохар ду, код хийца ца оьшу. Хьажа [docs/TRANSLATING.md](../TRANSLATING.md) файлан формат
хьокъехь, машинаца гочдаран кийча промпт а, талларан скрипт а. ХӀокху README гочдарш `docs/i18n/README.<code>.md` чохь ду.

```
scripts/                гӀоьнчийн скрипташ (гочдарш таллар)
docs/                   гочдаран куьйгалла, скриншоташ
```

## Къайлахалла

- Decoy-с маша лелабо Discord-ан йукъара могӀам схьаэца (дуьххьара латийначу хенахь, тӀаккха дийнахь цкъа бен ца оьцу,
  йа керладоккхуш) а, Discord-ан CDN тӀера ловзарийн иконаш а, суьрташ а гайта.
- Цо хьан Discord токен йа аккаунт хаамаш ца йоьшу, ца Ӏалашйо, ца йохьуьйту, кхин а Discord клиентца ца къамел до.
- ГӀирсаш (хаьржинарш, мотт, хенан барам) локально WebView чохь Ӏалашдо; ловзарийн могӀам а, ханна йолу Decoy файлаш а
  `%LOCALAPPDATA%\app.decoy.desktop` чохь Ӏалашдо.
- Аналитика йац, хаамаш дӀасахьийсор дац, аккаунташ йац.

## Бевзаш болу дозанаш

- Discord-о муьлхха хенахь ша ловзар билгалдаккхар хийца тарло. Нагахь санна Decoy билгал ца даккхахь, issue схьаделла.
- Цхьацца белхашна процесс бен совнах хӀума оьшу (масала ловзаран платформа чура къаьстина меттиг). Decoy-с процесс бен харц ца латайо.
