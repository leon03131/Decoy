# Decoy

**Huch'uy rantin ruwaykuna, Discord huk pukllay purichkasqanta yuyanallanpaq.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy taqi chayllaraq pukllaykunawan rikch'akunawanpas" />

</div>

Decoy huk mana imatapas waqllichiq, ventanayuq rantin ruwayta pukllaypa executable sutinwan purichillan, chaynapim Discord pukllay riqsiyninpi chay pukllayta pukllachkasqaykita willakun. Manam chiqap pukllaytachu churana utaq qallarichina kanki, chayraykum discoykipiqa manam hatun willañiqikuna tiyanchu.

Discord **riqsiy atisqan llapa pukllaykunatam** riqsin (yaqa 25 000 qillqasqakuna), paypa kikin ch'uya riqsina sutisuyunta ñawirispa kikinllamanta sapa punchaw kunanchasqata waqaychasqanrayku.

> [!WARNING]
> Pukllay purichkaqta llullakuyqa Discord-pa Terms of Service nisqanta p'akiyta atinmanmi, Decoy nisqatataq **qam kikiypa saqillaykiman hinam** llamk'achinki.
> Kay rurayqa manam Discord Inc. nisqawan huñusqachu, qhawarisqachu nitaq paymanta hamuqchu. Qhaway [Sasachakuy mana chaskina](#sasachakuy-mana-chaskina).

## Imakunata ruwan

- **Discord-pa riqsiy atisqan tukuy imapas.** Pukllaykunap sutisuyunqa Discord-pa ch'uya riqsina pukyunmanta uraykachisqam, kaypi hallch'asqa sapa punchawtaq kunanchasqa. Musuq pukllaykuna musuq yapasqa executables nisqakunapas kikinllamanta rikurimunku.
- **Utqaylla maskhay.** Chaylla maskhay pukllay sutinpa utaq executable nisqapa sutinpa chawpinpi waranqantin pukllaykunapi, tawak'uchukunapi utaq huch'uy sutisuyupi qhaway, munasqakuna chaymanta «Chayllaraqkuna» siq'ipas.
- **Huk ñit'iylla.** Huk pukllayta akllay, executable nisqata akllay (achka kaptinqa), hayk'a pacha waqaychanata niy hinaspa qallariyta ñit'iy. Pacha puchukay muyu willakuywan willasunki pacha tukukuptin.
- **Manam imatapas qhipaman saqinchu.** Decoyqa purichkaspallam kawsan: huch'uy exe nisqa qallariptin kamasqa, sayaptintaq pichasqa. Tukuy imapas wichq'akuptin sayachisqa, manaraq suyasqa wichq'akuymanta puchuqkunapas qatiq qallariypi pichasqam kanku.
- **Ch'inlla.** Windows tray nisqapim tiyan, kikin decoykunapaq manam ventanakunachu manataq taskbar botonninkunachu kan.
- **Kichasqa t'ikraykuna.** Chawpin uyaqa ch'uya JSON willañiqikunallawanmi purin, chayraykum musuq simita yapayqa huklla willañiqim. English chaymanta Russian kachkanña.
- **Kikinpaq kay.** Manam yupaychu, manam Discord token nisqachu, manam telemetry nisqachu. Qhaway [Kikinpaq kay](#kikinpaq-kay).

## Imayna llamk'an

1. Discordqa PC nisqaykipi purichkaq ruwaykunata qhawaspa executable sutinkunata ch'uya sutisuyuwan (`/api/v9/applications/detectable`) tupachispa pukllachkasqaykita yachan.
2. Decoy chay sutisuyuta uraykachin, hinaspa akllasqayki pukllaypaq huk huch'uy rantin programata (yaqa 120 KB, Rust nisqapi qillqasqa Decoy ukumantaq churamusqa) mit'alla k'itiman sutisuyupi kaq executable sutinwan k'askachin, ahinataq `.../cod26-cod.exe`.
3. Kay rantinqa huk hanaq pata ventanallatam hap'in, qhawanamanta karupi sayachisqa mana rikunaykipaq. Discordqa ventanayuq ruwayllatam riqsin, chayraykum ch'usaq ventanayuq ruwaytaqa mana qhawanchu.
4. Yaqa 15 chinllipi Discordqa kunan ruwayniykipi chay pukllayta rikuchinña.
5. Pacha tukukuptin utaq sayachiyta ñit'iptiyki, Decoy ruwayta puchukachin willañiqitataq pichan. Windows job object nisqaqa Decoy pantaspa wichq'akuptinpas decoykuna Decoy-wan kuskalla wañunankutam qhawan.

## Churay

[Releases](../../../../releases) raphipi hukta akllay:

| Uraykachiymana | Kaypaq |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Churaq (Installer).** Sapa llamk'achiqpaq, mana kamachiq (admin) saqillayta munanchu, Qallariy akllanapi churana unanchata churan pichaqninwantaq. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Maymanpas kicharillay hinaspa `decoy.exe` nisqata purichiy. Tukuy willakuyqa kinrayninpi `data` k'itillapim qhipakun, manam imapas llamk'achiqpa qillqanchanman qillqakunchu. Qulluypaqqa chay carpetallata pichay. |

Uraykachisqaykita `SHA256SUMS.txt` nisqawan chiqaqchay (PowerShell nisqapi `Get-FileHash <willañiqi>`).

Windows SmartScreen mana riqsisqa pusaq nispa willayta atinmanmi ruwasqakuna mana digital takyasqarayku; *More info → Run anyway* akllay chay ruwasqata iñiptiykiqa.

Munasqakuna: Windows 10 utaq 11 (64-bit) WebView2 runtime nisqawan (Windows 11 nisqapipas musuq Windows 10 kunanchaykunapipas kachkanña).

## Llamk'achiy

1. **Taqi** nisqata kichay hinaspa huk pukllayta maskhay, utaq maymantaña `Ctrl` + `K` ñit'iy.
2. Huk pukllayta ñit'iy. Paña kaq panelespi ruwayta akllay hayk'a minutochá waqaychana (Discord questkunaqa yaqa 15 munanku).
3. **Decoy qallariy** ñit'iy. Discord huk iskay chinllikuna qhipaman pukllayta rikuchinqa.
4. **Purichkan** t'aqapi qhaway, hukta utaq tukuyninta munaspa sayachiy, utaq Decoy nisqata traypi saqillay.

Discord qillqasqanpi mana executables-niyuq pukllaykunaqa kikinmanta pakasqam kanku (manam riqsikuyta atikunkuchu). *Mana exe-niyuq pukllaykunata rikuchiy* nisqata kichay rikunaykipaq; sutisuyuqa sapa punchawmi kunanchakun, chayraykum Discord huk ruwayta yapariptinlla llamk'anqaku.

### Kamachina siq'i

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy nisqata chaylla qallarin, ahinataq `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Pukyu qillqamanta ruway

Ñawpaq munasqakuna: [Node.js](https://nodejs.org) 20+, takyasqa [Rust](https://rustup.rs) k'itillikuna (MSVC target) Visual Studio C++ ruwana yanapakuykunawan, WebView2 runtime nisqawanpas.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Allin llank'ana qhawaykuna:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Yuyarinakuna: decoy exe nisqaqa `src-tauri/build.rs` nisqawan `rustc` kikinmanta `src-tauri/stub/stub.rs` nisqamanta huñusqam hinaspa app ukupi churamusqa. Frontend ch'uya wamp'uqpi (`npm run dev`) puriptinqa huk huch'uy llulla backend (`src/mock.ts`) llamk'achisqam, chayqa UI nisqapi llamk'anapaq ancha allinmi.

## T'ikraykuna

Chawpin uya simikunaqa [`src/locales`](../../src/locales) k'itillipim kachkanku, sapa simipaq huk JSON willañiqi (`en.json`, `ru.json`, ...). Huk simita yapayqa huk willañiqita yapaymi; manam kódigo nisqata tikranachu. Qhaway [docs/TRANSLATING.md](../TRANSLATING.md) willañiqip rikch'ayninta, makillawan llamk'achina t'ikray mañakuyta chiqaqchanapaq script nisqatawan rikunaykipaq. Kay README nisqapa t'ikrasqankunaqa `docs/i18n/README.<code>.md` k'itimanmi rinku.

## Ruraypa t'aqankuna

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Kikinpaq kay

- Decoy llikataqa Discord-pa ch'uya riqsina sutisuyunta uraykachinallapaqmi llamk'achin (qallariypi, chaymantataq sapa punchawpi huk kutillata utaq kunanchayta ñit'iptiyki), rikuchinapaqtaq pukllay unanchakunata llimp'ikunatapas Discord-pa ch'uya CDN nisqanmanta chaskillan.
- Manam Discord token nisqaykitachu nitaq yupay willakuyniykitachu ñawirin, hallch'an utaq apachin, manataqmi Discord client nisqawan rimanchu.
- Allichanakuna (munasqakuna, simi, pachakuna) app-pa kikin WebView hallch'anallanpim waqaychasqa; pukllaykunap sutisuyun mit'alla decoy willañiqikunapas `%LOCALAPPDATA%\app.decoy.desktop` nisqapim kanku.
- Manam willay yupaykunachu (analytics), manam pantasqa willaykunachu, manam yupaykunachu.

## Riqsisqa saywakuna

- Discordqa imayna riqsinanta mayk'aqpas tikrayta atinmanmi. Huk decoy riqsikuyta saqiptinqa, ama hina kaspa huk issue nisqata kichariy.
- Wakin ruraykunaqa manam purichkaq ruwayllatachu munanku (ahinataq huk pukllana platform ukupi sapaq pukllaypi kayta). Decoy ruwayllatam pantachin.
- Discord sutisuyupi mana executables-niyuq qillqasqakunaqa manam riqsikuyta atikunkuchu.
- Waqaychanapaq softwarekuna wakinpi mana firmachasqa huch'uy executables yuyaypi tiyachkaqkunata mana allinpaq hapiyta atinku. Decoyqa kichasqa pukyum (open source) `src-tauri/stub/stub.rs` nisqamantataq huñusqa; qam kikiypas huñuyta atiwaqmi.
