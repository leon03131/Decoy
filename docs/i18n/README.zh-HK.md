# Decoy

**極小型替身進程，讓 Discord 誤以為遊戲正在運行。**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy 遊戲庫，包含最近運行的遊戲與封面插圖" />

</div>

Decoy 會以遊戲執行檔名稱在背景運行一個無害且帶有視窗的佔位進程，令 Discord 的遊戲偵測機制判定你正在遊玩該遊戲。你完全毋須安裝或啟動真正的遊戲，因此不會佔用大量硬碟空間。

它掌握 **Discord 能夠偵測到的所有遊戲**（約 25,000 款），因為它會讀取 Discord 官方公開的偵測清單，並自動保持最新狀態。

> [!WARNING]
> 偽造正在運行的遊戲可能違反 Discord 的服務條款，使用 Decoy 的**一切風險由你自行承擔**。
> 本專案與 Discord Inc. 並無任何關聯、認可或隸屬關係。詳情請參閱[免責聲明](#免責聲明)。

## 功能特色

- **支援 Discord 能偵測的一切遊戲。** 遊戲清單直接從 Discord 的公開偵測端點下載，於本機快取並每日自動更新。新遊戲以及新加入的執行檔會自動顯示。
- **迅速流暢的即時搜尋。** 支援在數千款遊戲中按遊戲名稱或執行檔名稱即時搜尋，支援圖示檢視與精簡清單檢視、我的最愛以及「最近」列。
- **一鍵運行。** 選擇一款遊戲，挑選執行檔（若有多個），設定維持運行的時長並點擊啟動。倒數計時環與系統通知會在時間到達時提醒你。
- **不留痕跡。** 替身進程僅在運行時存在：極小的 exe 於啟動時建立，並在停止時自動刪除。結束程式時所有進程都會停止，當機遺留的殘留檔案亦會在下次啟動時自動清理。
- **安靜無干擾。** 常駐於系統匣，替身進程本身不會彈出視窗，亦不會在工作列顯示按鈕。
- **開放翻譯。** 介面完全由純 JSON 檔案驅動，新增語言只需加入一個檔案。目前已內置英文與俄文。
- **注重私隱。** 毋須帳號，毋須 Discord Token，無任何遙測數據收集。詳情請參閱[私隱](#私隱)。

## 運作原理

1. Discord 透過檢查你電腦上正在運行的進程，並將其執行檔名稱與公開清單（`/api/v9/applications/detectable`）進行比對，以此判定你是否正在遊玩某款遊戲。
2. Decoy 會下載該清單，並針對你選擇的遊戲，將一個微型替身程式（約 120 KB，使用 Rust 編寫並內嵌於 Decoy 中）複製到暫存資料夾中，並命名為清單中的執行檔名稱（例如 `.../cod26-cod.exe`）。
3. 該替身程式除了持有一個頂層視窗外甚麼都不做，而且該視窗停留在螢幕視野之外，因此你完全看不到它。Discord 僅能識別擁有視窗的進程，這亦是完全無視窗進程會被忽略的原因。
4. 大約 15 秒內，Discord 就會將該遊戲顯示為你當前正在進行的活動。
5. 當計時結束或你點擊停止時，Decoy 會結束該進程並刪除對應檔案。透過 Windows 作業物件（Job Object），即使 Decoy 意外當機，替身進程亦會隨之結束。

## 安裝

前往 [Releases](../../../../releases) 頁面下載對應版本：

| 下載項目 | 說明 |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **安裝程式。** 單一使用者安裝，毋須管理員權限，會自動加入「開始」功能表捷徑與解除安裝程式。 |
| `Decoy_x.y.z_x64-portable.zip` | **免安裝版。** 解壓縮至任意位置即可執行 `decoy.exe`。所有資料均儲存在程式旁的 `data` 資料夾內，不會向使用者個人設定檔寫入任何內容。刪除該資料夾即可完全移除。 |

可透過 `SHA256SUMS.txt` 校驗下載的檔案（於 PowerShell 中執行 `Get-FileHash <檔案>`）。

由於建置產物未進行程式碼簽署，Windows SmartScreen 可能會提示未知發行者；如果你信任該建置版本，請點擊「*其他資訊 → 仍要執行*」。

系統需求：Windows 10 或 11（64 位元），並安裝有 WebView2 Runtime（Windows 11 及近期的 Windows 10 更新中已預設包含）。

## 使用說明

1. 開啟**遊戲庫**並搜尋遊戲，或於任何位置按下 `Ctrl` + `K`。
2. 點擊一款遊戲。於右側面板中選擇進程以及需要維持的分鐘數（Discord 活動任務通常需要 15 分鐘）。
3. 點擊**啟動替身**。數秒後 Discord 就會顯示該遊戲。
4. 可於**運行中**清單查看狀態，隨時停止單個或所有替身進程，亦可直接將 Decoy 最小化至系統匣。

Discord 項目中尚未包含執行檔的遊戲預設會被隱藏（因為無法被偵測）。開啟「*顯示無 exe 的遊戲*」即可查看它們；清單每天更新一次，一旦 Discord 加入了對應進程即可立即使用。

### 命令列

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

直接啟動替身，例如 `decoy.exe --launch "robloxplayerbeta.exe" 15`。

## 從原始碼建置

環境需求：[Node.js](https://nodejs.org) 20+、附帶 Visual Studio C++ 建置工具的穩定版 [Rust](https://rustup.rs) 工具鏈（MSVC 目標平台），以及 WebView2 Runtime。

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # 以開發模式執行並支援熱重載 (hot reload)
npm run tauri build    # 於 src-tauri/target/release/bundle/nsis 產生安裝程式
```

常用檢查指令：

```bash
npm run check-locales  # 對照 ru.json 驗證每個翻譯檔案
npx tsc --noEmit       # 對前端進行型別檢查
cargo check --manifest-path src-tauri/Cargo.toml
```

注意事項：替身 exe 是在 `src-tauri/build.rs` 中透過原生 `rustc` 從 `src-tauri/stub/stub.rs` 編譯並嵌入至主程式中。當在普通瀏覽器中執行前端時（`npm run dev`），程式會使用小型 mock 後端（`src/mock.ts`），方便開發調試介面。

## 翻譯

介面字串位於 [`src/locales`](../../src/locales)，每種語言對應一個 JSON 檔案（`en.json`、`ru.json` 等）。
新增一種語言只需加入一個檔案，毋須修改任何程式碼。有關檔案格式、可直接使用的機器翻譯提示詞以及驗證指令碼，請參閱 [docs/TRANSLATING.md](../TRANSLATING.md)。本 README 的翻譯檔案請放置於 `docs/i18n/README.<code>.md`。

## 專案結構

```
src/                    React + TypeScript 前端
  components/           遊戲庫、詳細資訊面板、設定等
  locales/              翻譯檔案（每種語言一個 JSON）
  i18n-core.ts          語言載入與查詢
  store.ts              應用程式狀態 (zustand)
src-tauri/              Rust 後端 (Tauri 2)
  src/lib.rs            遊戲資料庫、替身進程、系統匣
  stub/stub.rs          內嵌的替身程式
scripts/                輔助指令碼（語系驗證）
docs/                   翻譯指南、螢幕截圖
```

## 私隱

- Decoy 僅在下載 Discord 公開偵測清單（首次啟動時下載，之後最多每天一次或在你點擊更新時）以及顯示遊戲圖示和封面插圖（從 Discord 的公開 CDN 取得）時使用網路。
- 它不會讀取、儲存或發送你的 Discord Token 或任何帳號資料，亦不會與 Discord 客戶端通訊。
- 設定（我的最愛、語言、持續時長）儲存於應用程式的本機 WebView 儲存空間；遊戲清單快取與臨時替身檔案保存在 `%LOCALAPPDATA%\app.decoy.desktop`。
- 無資料分析，無當機回報，毋須帳號。

## 已知限制

- Discord 可能會隨時變更其偵測機制。若替身進程不再被識別，請提交 Issue。
- 某些活動需求不單只是運行中的進程（例如處於遊戲平台的特定體驗或關卡內）。Decoy 僅模擬進程本身。
- Discord 清單中沒有執行檔的項目無法被偵測。
- 安全防護軟體有時可能會警告在記憶體中處於閒置狀態的未簽署微型執行檔。替身程式完全開源並由 `src-tauri/stub/stub.rs` 建置；你可以自行編譯。
