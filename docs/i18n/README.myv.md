# Decoy

**Вишка печтькстнэ-процесстне, конатненень кородо Discord лови налксеманть молицякс.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотекась курок шкань налксематнень марто" />

</div>

Decoy нолды зыяновтомо вальмав печтьксэнь процесс налксемань нолдамо файланть лем ало, сень кувалма Discord налксемань муема лувозо кевксти, келя тынь налкситядо те налксемасо. Алкуксонь налксеманть путомс эли нолдамс эрявиксчи арась, секскак диск лангсо покш тарка а саеви.

Сон содасы **эрьва налксеманть, конанть муеви Discord-нэнь** (малав 25 000 сёрмадовкст), секс мекс сон ловны Discord-онь эсь вейсэнь списканзо ды одкстни сонзэ сонсь.

> [!WARNING]
> Молиця налксемань печтькстне каршо ульневельть Discord Терминтненень, ды тынь нолдатадо Decoy **эсь мельсэ**.
> Те проектэсь а сови Discord Inc. компаниянтень, а кемекстави ды а лезды тензэ. Ваныка [Прянь ванстомась](#прянь-ванстомась).

## Пек эрявикс тевтне

- **Весе, мезе муеви Discord-нэнь.** Налксемань спискась таргави Discord-онь вейсэнь спискастонзо, ванстови компьютерсэ ды одкстневи чинь-чинь. Од налксематне ды одкс путозь exe файлтнэ лисить ськамост.
- **Хват вешнема.** Курок вешнема налксемань лем коряс эли exe коряс тёжадо ламо налксематнестэ, плиткатнессэ эли спискасо невтема, вечкевикст ды «Курок шкань» ряд.
- **Вейке лепштямо.** Кочкика налксеманть, кочкика нолдамо файланть (бути сынь зярыя), путыка зяро минут кирдемс ды лепштика нолдамо. Шкань курок ловномань кирьксэсь ды явтамось пачтить зярдо шкась прядовсь.
- **Мезеяк кадовома а кадли.** Decoy ашти ансяк зярс сон важоди: вишка exe тееви нолдамсто ды нардави лоткавтомсто. Весе лоткавтови зярдо лиситядо, а сбоень мельга кадовкснэ чоподить омбоце нолдамсто.
- **Чатьмониця.** Эри системань трейсэ, печтькстнэнь туртов арасть вальмат эли важодемань панельсэ кнопкат.
- **Панжадо ютавтомат.** Интерфейсэсь теезь шожда JSON файлсэ, секскак од келень путомась — те ансяк вейке файл. Англань ды рузонь кельтне совавтозь.
- **Эсь тевень ванстома.** Аккаунт арась, Discord токен арась, телеметрия арась. Ваныка [Салавачись](#салавачись).

## Кода те важоди

1. Discord арси тынь налкситядо налксемасо, зярдо ванкшны компьютерсэ молиця процесстнень ды сравтни сынст нолдамо файлтнэнь лемест вейсэнь списка марто (`/api/v9/applications/detectable`).
2. Decoy таргасы те спишканть ды, кочказь налксеманть туртов, кучи вишка печтьксэнть программа (малав 120 КБ, сёрмадозь Rust кельсэ ды путозь Decoy потс) шкань папкас спискасто саезь лем марто, саемга `.../cod26-cod.exe`.
3. Печтьксэсь мезеяк а теи, ансяк кирди вейке верьце вальма, аравтозь овсе экрандонть ушодов, тынь сонзэ зярдояк а несазо. Discord муи ансяк вальма марто процессэнть, секс вальмавтомо процессэсь ютавтови.
4. Малав 15 секундань ютазь Discord невтьсы те налксеманть тынк тевекс.
5. Зярдо шкась прядови эли тынь лепштятадо лоткавтомо, Decoy лоткавтсы процессэнть ды нардасы файланть. Windows job object ваны седе, штобу печтькстнэ лоткавольть Decoy марто вейсэ, бути программась колавикскак.

## Путомазо

Кочкика вейке [Нолдавкстнэстэ](../../../../releases):

| Таргамо | Мезе туртов |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Путыцясь (Installer).** Эрьва нолдыцянтень, администраторонь прават а эрявить, путы «Ушодомс» менюс ды нардамо программа. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативной (Portable).** Панжыка ков мелеть ды нолдыка `decoy.exe`. Весе датась ашти `data` папкасо вакссо, тынк профильс мезеяк а сёрмадови. Нардамо туртов нардака папкась. |

Ванкшныка таргазенть `SHA256SUMS.txt` вельде (`Get-FileHash <file>` PowerShell-сэ).

Windows SmartScreen машты явтамо содавикстэме нолдыцядо, секс мекс сборкатне апак тешкстэ цифровой кедьпутомасо; бути тынь кемитядо сборкантень, кочкинк *Седе ламо (More info) → Свал нолдамс (Run anyway)*.

Эрявиксчи: Windows 10 эли 11 (64-бит) WebView2 runtime марто (тедеде уш совавтозь Windows 11 ды од Windows 10 одкстнематнесэ).

## Нолдамозо

1. Панжыка **Библиотека** ды вешнека налксема, эли лепштика `Ctrl` + `K` косто мелеть.
2. Лепштика налксема лангс. Вить кедь пелев панельсэ кочкика процессэнть ды зяро минут кирдемс (Discord тевтне сеедьстэ вештить 15).
3. Лепштика **Нолдамс печтьксэсь**. Discord невтьсы налксеманть зярыя секундань ютазь.
4. Ваныка сонзэ **Нолдазь** ало, лоткавтыка вейке эли весе зярдо мелеть, эли ансяк кадыка Decoy трейсэ.

Налксематне, конатнень Discord потсо эскэ арасть exe файлт, кекшезь (сынст муемс а маштови). Нолдыка *Невтемс exe-теме*, штобу неемс сынст; спискась одкстневи чинь-чинь, секскак сынь саевить кода Discord путы процесс.

### Командань строказэ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Нолды печтьксэнть куроксто, саемга `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сборкась лисьмапрястонть

Эрявикс япалат: [Node.js](https://nodejs.org) 20+, кеме [Rust](https://rustup.rs) инструментнэ (MSVC target) Visual Studio C++ build tools марто, ды WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Пек эрявикс ванкшномат:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Мельполадкст: decoy exe файлэсь кочкави `src-tauri/build.rs` вельде свалшкань `rustc` марто `src-tauri/stub/stub.rs` файлсто ды путови программа потс. Зярдо фронтендэсь важоди браузерсэ (`npm run dev`), важоди вишка мок-сервер (`src/mock.ts`), те пек паро интерфейсэнь теемстэ.

## Ютавтомат

Интерфейсэнь строкатне аштить [`src/locales`](../../src/locales) папкасо, вейке JSON файл эрьва кельсэ (`en.json`, `ru.json`, ...).
Од келень путомась — те кодамояк кодонь полавтомавтомо вейке од файлонь совавтома. Ваныка [docs/TRANSLATING.md](../TRANSLATING.md) файлонь форматонть туртов, анок машинань ютавтомань промптонть ды ванкшномань скриптэнть. Те README-нь ютавтоматне путовить `docs/i18n/README.<code>.md` папкас.

## Проектэнь структуразо

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Салавачись

- Decoy сетьсэ важоди ансяк Discord вейсэнь списканть таргамо туртов (васень нолдамсто, мейле чис весть седе сеедьстэ аволь эли зярдо лепштятадо одкстнеме) ды, невтема туртов, налксемань иконкатнень ды артовкстнэнь Discord CDN вельде.
- Сон а ловны, а ванстни ды а кучи тынк Discord токенэнть эли аккаунтонь дата, ды сон а кортась Discord клиент марто.
- Аравтоматне (вечкевикст, кель, кувалмот) ванстовить эсь компьютерсэ WebView ванстомасо; налксемань спискань кэшэсь ды шкань decoy файлтнэ аштить `%LOCALAPPDATA%\app.decoy.desktop` папкасо.
- Аналитика арась, колавомадо пачтямо арась, аккаунтт арасть.

## Содавикс анежедемат

- Discord машты полавтнеме кода муевить налксематне зярдо мелеть. Бути decoy эзизе содаво, инеськеть, панжыка issue.
- Кой-кона налксематненень эряви седе ламо, аволь ансяк молиця процесс (саемга, налксема платформань потсо эрявикс режимсэ аштемась). Decoy ансяк арси процессэкс.
- Сёрмадовкстнэ, конатнень Discord спискасо арасть exe, а муевить.
- Ванстомань программатне весть-весть сайть вишка апак тешкстэ exe файлтнэнь, конат аштить чатьмонезь памятьсэ. Decoy панжадо лисьмапря марто ды кочказь `src-tauri/stub/stub.rs` файлсто; тынь маштадо кочкамонзо эсь кедьсэ.

## Проектсэ лездамось

Колавомадо сёрмадовкстнэ, мельполадкстнэ ды ютавтоматне пек эрявиксэт. Инеськеть, васня ловныка [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Прянь ванстомась
