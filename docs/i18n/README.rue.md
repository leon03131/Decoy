# Decoy

**Маленькы процесы-заступы, дякуючі котрым Discord рахує, што бавка бѣжыть.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Бібліотека Decoy из недавнїма бавками та ілустраціями" />

</div>

Decoy держыть нешкодный процес-заступник из окном под назвов екзекутівного файлу бавкы, зато детекція бавок у Discord указує, же бавите тоту бавку. Не треба іншталовати ани запускати саму бавку, зато нїч велике не заберать мѣсто на диску.

Програма знає о **каждӯй бавцї, котру Discord годен розпӯзнати** (дас 25 000 записӯв), бо читає публічный список детекції самого Discord и сама го обновлює.

> [!WARNING]
> Імітація бѣжачой бавкы може быти против Правіл схоснованя Discord, зато хоснуєте Decoy **на властне різіко**.
> Тот проєкт нїяк не споєный, не підпорованый ани не схваленый компаніёв Discord Inc. Позерайте [Зречѣня одповідности](#зречѣня-одповідности).

## Функції

- **Вшытко, што Discord годен розпӯзнати.** Список бавок ся стягує з публічного кінцёвого пункта детекції Discord, кешує ся локално та обновлює каждый день. Новы бавкы тай новоприданы екзекутівны файлы ся указують самы.
- **Быстроє гляданя.** Миттєве гляданя подля назвы бавкы або екзекутівного файлу меджі тисячами бавок, звязане у плитках або компактнӯй листї, облиблены та рядок «Недавнї».
- **На єден клик.** Выберьте бавку, выберьте екзекутівный файл (як їх веце), звольте час держаня та кликнїть старт. Кӯльцо зворотного одрахованя та повѣдомлїня вас сповѣстять, коли выйде час.
- **Нич по собѣ незалишать.** Decoy є лем тогды, коли бѣжыть: маленькый exe файл ся створює при стартї тай змазує при заставлїню. Вшытко ся заставлять при выходї, а остаткы по збоях ся зачищають при далшӯм пустїню.
- **Тихонькый.** Бывать у системнӯм трею, нїякых окон або ґузликів на панели задач про самы decoys нїт.
- **Отверты переклады.** Інтерфейс функціонує на чістых файлах JSON, зато придати язык означає лем придати єден файл. Анґліцькый тай російськый суть уж включены.
- **Приватность.** Без конта, без токена Discord, без телеметрії. Позерайте [Приватность](#приватность).

## Як то фунґує

1. Discord рахує, же бавите бавку, перевѣряючи бѣжачі процесы на вашым компютерї та порӯвнуючи назвы їх екзекутівных файлӯв з публічным списком (`/api/v9/applications/detectable`).
2. Decoy стягує тот список и про выбрану бавку копірує маленьку програму-заступницю (дас 120 KB, написану на Rust тай вбудовану до Decoy) до дочасной папкы под назвов екзекутівного файлу зо списку, наприклад `.../cod26-cod.exe`.
3. Заступниця нїч не робить, окрем держаня єдного окна верьхнёго уровня, паркованого далеко за границями екрана, обы сьте го ниґда не видїли. Discord рахує лем процес, котрый мать окно, зато цїлком безвіконный процес ся іґнорує.
4. Приблизно за 15 секунд Discord указує бавку як вашу актуальну актівность.
5. Коли час выйде або кликнете заставити, Decoy заставлять процес и змазує файл. Обєкт задач Windows (job object) заручує, же decoys ся закончать вєдно з Decoy, ай кедь ся стане аварія.

## Іншталація

Выберьте собі на сторонцї [Releases](../../../../releases):

| Стягнути | Про што |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Іншталатор.** Про єдного хоснователя, непотребує прав адміністратора, придасть запис до меню Штарт та одіншталатор. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Розпакуйте даґде и запустїть `decoy.exe`. Вшыткы даты зостануть у папцї `data` коло нього, нїч ся незаписує до профілю хоснователя. Вымажте папку, обы го одстранити. |

Провѣрьте стягнутый файл через `SHA256SUMS.txt` (`Get-FileHash <file>` у PowerShell).

Windows SmartScreen може варіштовати перед непознатым выдавательом, бо білды не мають діґіталного підпису; выберьте *More info → Run anyway*, кедь білду довѣряєте.

Потрабы: Windows 10 або 11 (64-біт) из WebView2 runtime (уж є во Windows 11 та недавнїх обновлїнях Windows 10).

## Хоснованя

1. Отверьте **Бібліотеку** тай глядайте бавку, або кликнїть `Ctrl` + `K` з любого мѣста.
2. Кликнїть на бавку. У панелї напряво выберьте процес та кӯлько минут го держати (задачі Discord зазвычай жадають 15).
3. Кликнїть **Запустити decoy**. Discord укаже бавку за пару секунд.
4. Слїдуйте за нев под **Запущено**, заставте єдну або вшыткы коли вам треба, або зохабте Decoy у трею.

Бавкы, котрых запис у Discord щи не має екзекутівных файлӯв, суть подля зволїня скрыты (не мож їх розпӯзнати). Залучте *Указовати бавкы без exe*, обы їх увидїти; список ся обновлює каждый день, так же ся стануть доступны, як лем Discord придасть процес.

### Командный рядок

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Запустить decoy прямо нараз, наприклад `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Зборка з жрідлового коду

Потрабы: [Node.js](https://nodejs.org) 20+, стабілный toolchain [Rust](https://rustup.rs) (MSVC target) з інштрументами зборкы Visual Studio C++, тай WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # бѣжыть у девелоперскӯм режімї з hot reload
npm run tauri build    # вытворить іншталатор у src-tauri/target/release/bundle/nsis
```

Хасенны провѣрькы:

```bash
npm run check-locales  # провѣрить каждый файл перекладу по ru.json
npx tsc --noEmit       # провѣрка тіпів фронтенда
cargo check --manifest-path src-tauri/Cargo.toml
```

Позначкы: екзекутівный файл decoy ся компілює через `src-tauri/build.rs` з помочов простого `rustc` из `src-tauri/stub/stub.rs` тай пак вбудовує ся до аплікації. Кедь ся фронтенд запустить у звычайнӯм бравзерї (`npm run dev`), хоснує ся малый mock-бекенд (`src/mock.ts`), што є зручно про роботу на UI.

## Переклады

Стрінґы інтерфейсу суть у [`src/locales`](../../src/locales), єден JSON файл на каждый язык (`en.json`, `ru.json`, ...). Приданя языка означає приданя файлу; нїякых змїн у кодї. Позерайте [docs/TRANSLATING.md](../TRANSLATING.md) про формат файлу, готовый промпт про машыновый переклад та скріпт провѣрькы. Переклады сёго README ідуть до `docs/i18n/README.<code>.md`.

## Будова проєкту

```
src/                    React + TypeScript фронтенд
  components/           Бібліотека, деталный панел, наставлїня, ...
  locales/              файлы перекладӯв (єден JSON на язык)
  i18n-core.ts          начѐтованя языка та гляданя
  store.ts              стан аплікації (zustand)
src-tauri/              Rust бекенд (Tauri 2)
  src/lib.rs            база бавок, процесы decoy, трей
  stub/stub.rs          програма-заступниця, котра ся вбудовує
scripts/                помочны скріпты (провѣрька локалей)
docs/                   навӯд на переклад, скріншоты
```

## Приватность

- Decoy хоснує сїть лем про стягованя публічного списку детекції Discord (при першӯм стартї, пак найвеце раз на день або коли кликнете обновити) тай, про зображѣня, іконкы бавок та ілустрації з публічной CDN Discord.
- Вӯн не читає, не держыть ани непосылать ваш токен Discord ци даякі даты конта, тай не говорить з клієнтом Discord.
- Наставлїня (облиблены, язык, протяглости) ся держать локално у сховіщу WebView аплікації; кеш списку бавок та дочасны файлы decoy живуть у `%LOCALAPPDATA%\app.decoy.desktop`.
- Нїякой аналітикы, нїякых повідомлїнь о збоях, нїякых конт.

## Знамы огранїчѣня

- Discord може змїнити, як фунґує детекція, у хоць-якый час. Як decoy ся перестане розпӯзнавати, отворте просиме issue.
- Даякы актівности жадають веце як бѣжачый процес (наприклад быти во внутрї окремого искуства бавковой платформны). Decoy лем імітує процес.
- Записы без екзекутівных файлӯв у списку Discord не годни быти розпӯзнаны.
- Проґрамы безпекы даколи фіксують малы непідписаны файлы exe, котры стоять у памятї без дїла. Decoy мать отвертый код и будує ся з `src-tauri/stub/stub.rs`; можете го зкомпіловати самы.

## Зречѣня одповідности

Decoy ся поскытує «як є» про особны, едукативны та тестӯвны цїли. Імітованя бѣжачой бавкы може нарушовати Правіла схоснованя Discord або выдавателя бавкы, тай може вести до санкцій против вашого конта.
