Decoy האַלט אַן אומשעדלעכן פֿאַרטרעטער־פּראָצעס מיט אַ פֿענצטער לויפֿנדיק אונטער דעם נאָמען פֿונעם עקסיקיוטאַבאַל פֿון דער שפּיל, כּדי די שפּיל־דערקענונג פֿון Discord זאָל מעלדן אַז איר שפּילט יענע שפּיל. מען דאַרף קיינמאָל נישט אינסטאַלירן אָדער אָנצינדן די עכטע שפּיל, אַזוי בלײַבט גאָרנישט קיין גרויסס אויפֿן דיסק.

עס ווייסט וועגן **יעדער שפּיל וואָס Discord קען דערקענען** (בערך 25,000 אײַנסלאָגן), ווײַל עס לייענט די אייגענע עפֿנטלעכע דערקענונג־רשימה פֿון Discord און האַלט עס אַליין דערהײַנטיקט.

## מעלות

- **אַלץ וואָס Discord קען דערקענען.** די שפּיל־רשימה ווערט אַראָפּגעלאָדן פֿונעם עפֿנטלעכן דערקענונג־ענדפּוינט פֿון Discord, לאָקאַל קאַשירט און יעדן טאָג דערפֿרישט. נײַע שפּילן און פֿריש צוגעלייגטע עקסיקיוטאַבאַלס באַווײַזן זיך פֿון זיך אַליין.
- **שנעלע זוך וואָס האַלט שריט.** באַלדיקע זוך לויט שפּיל־נאָמען אָדער עקסיקיוטאַבאַל צווישן טויזנטער שפּילן, נעץ־ אָדער קאָמפּאַקטע רשימה־באַקוקונג, פֿאַוואָריטן און אַ „לעצטיקע“ שורה.
- **איין קליק.** קלײַבט אויס אַ שפּיל, קלײַבט דעם עקסיקיוטאַבאַל (אויב עס זײַנען פֿאַראַן עטלעכע), שטעלט אָן ווי לאַנג אים צו האַלטן און דריקט אָנהייבן. אַ צוריקציילונג־רינג און אַן אָנזאָג זאָגן אײַך ווען די צײַט איז אויסגעגאַנגען.
- **לאָזט גאָרנישט איבער.** אַ decoy עקזיסטירט נאָר בעת ער לויפֿט: דער קליינער exe ווערט באַשאַפֿן בײַם אָנהייב און פֿאַרמעקט בײַם אָפּשטעל. אַלץ ווערט אָפּגעשטעלט ווען איר גייט אַרויס, און איבערגעבליבענע רעשטלעך פֿון אַ קראַך ווערן אויסגעקערט בײַם נעקסטן אָנצינדן.
- **שטיל.** זיצט אינעם סיסטעם־טאַץ, אָן קיין פֿענצטער אָדער קנעפּלעך אויפֿן טאַסקבאַר פֿאַר די decoys אַליין.
- **אָפֿענע איבערזעצונגען.** דער אינטערפֿייס ווערט געפֿירט דורך פּשוטע JSON־טעקעס, אַזוי צולייגן אַ שפּראַך איז אַן איינציקע טעקע. ענגליש און רוסיש זײַנען שוין אַרײַנגערעכנט.
- **פּריוואַטקייט.** קיין קאָנטע, קיין Discord־טאָקען, קיין טעלעמעטריע. זעט [פּריוואַטקייט](#פּריוואַטקייט).

## ווי עס אַרבעט

1. Discord באַשליסט אַז איר שפּילט אַ שפּיל דורכן קוקן אויף די פּראָצעסן וואָס לויפֿן אויף אײַער קאָמפּיוטער און פֿאַרגלײַכן זייערע עקסיקיוטאַבאַל־נעמען מיט אַן עפֿנטלעכער רשימה (`/api/v9/applications/detectable`).
2. Decoy לאָדט אַראָפּ יענע רשימה און, פֿאַר דער אויסגעקליבענער שפּיל, קאָפּירט אַ קליינע פֿאַרטרעטער־פּראָגראַם (בערך 120 קב, אָנגעשריבן אין Rust און אײַנגעבויט אין Decoy) אין אַ צײַטווײַליקער פּאַפּקע מיט דעם עקסיקיוטאַבאַל־נאָמען פֿון דער רשימה, למשל `.../cod26-cod.exe`.
3. דער פֿאַרטרעטער טוט גאָרנישט אַחוץ פֿאַרמאָגן איין הויפּט־פֿענצטער, פּאַרקירט ווײַט פֿונעם עקראַן כּדי איר זאָלט עס קיינמאָל נישט זען. Discord דערקענט בלויז אַ פּראָצעס וואָס פֿאַרמאָגט אַ פֿענצטער, וואָס דערפֿאַר ווערט אַ גאָר פֿענצטערלאָזער פּראָצעס איגנאָרירט.
4. אינערהאַלב בערך 15 סעקונדעס ווײַזט Discord די שפּיל ווי אײַער לויפֿנדיקע טעטיקייט.
5. ווען דער זייגער ענדיקט זיך אָדער איר דריקט אָפּשטעלן, ענדיקט Decoy דעם פּראָצעס און מעקט אויס די טעקע. אַ Windows job object פֿאַרזיכערט אַז decoys שטאַרבן צוזאַמען מיט Decoy, אַפֿילו אויב עס קראַכט.

פֿאָדערונגען: Windows 10 אָדער 11 (64-ביט) מיט דער WebView2 runtime (שוין אַרײַנגערעכנט אין Windows 11 און לעצטיקע Windows 10 דערהײַנטיקונגען).

## באַניץ

1. עפֿנט די **ביבליאָטעק** און זוכט אַ שפּיל, אָדער דריקט `Ctrl` + `K` פֿון ערגעץ.
2. קליקט אויף אַ שפּיל. אינעם טאַפֿליע אויף רעכטס קלײַבט דעם פּראָצעס און וויפֿל מינוט אים צו האַלטן (Discord שליחותן פֿאָדערן געוויינטלעך 15).
3. דריקט **אָנהייבן decoy**. Discord וועט ווײַזן די שפּיל נאָך עטלעכע סעקונדעס.
4. קוקט דערויף אונטער **לויפֿנדיק**, שטעלט אָפּ איינע אָדער אַלע אין יעדער צײַט, אָדער לאָזט פּשוט Decoy אינעם טאַץ.

שפּילן וועמענס Discord־אײַנסלאָג האָט נאָך נישט קיין עקסיקיוטאַבאַלס זײַנען באַהאַלטן לויט סובסעקווענט (מען קען זיי נישט דערקענען). צינדט אָן *ווײַזן שפּילן אָן exe* זיי צו זען; די רשימה ווערט טעגלעך דערפֿרישט, אַזוי זיי ווערן פֿאַראַן ווי נאָר Discord לייגט צו אַ פּראָצעס.

### קאָמאַנדע־שורה

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

הייבט אָן אַ decoy גלײַך פֿון דער אָרט, למשל `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## בויען פֿון קוואַל־קאָד

פֿאָראויסבאדינגונגען: [Node.js](https://nodejs.org) 20+, די סטאַבילע [Rust](https://rustup.rs) מכשירים־קייט (MSVC target) צוזאַמען מיט די Visual Studio C++ בוי־געצייג, און די WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

נוצלעכע קאָנטראָלן:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

באַמערקונגען: דער decoy exe ווערט קאָמפּילירט דורך `src-tauri/build.rs` מיט געוויינטלעכן `rustc` פֿון `src-tauri/stub/stub.rs` און דערנאָך אײַנגעבויט אינעם אַפּ. ווען דער פֿראָנטענד לויפֿט אין אַ געוויינטלעכן בלעטערער (`npm run dev`), ווערט געניצט אַ קליינער נאָכגעמאַכטער באַקענד (`src/mock.ts`), וואָס איז באַקוועם פֿאַר אַרבעטן אויפֿן UI.

## איבערזעצונגען

די UI־סטרינגען געפֿינען זיך אין [`src/locales`](../../src/locales), איין JSON־טעקע פֿאַר יעדער שפּראַך (`en.json`, `ru.json`, ...). צולייגן אַ שפּראַך הייסט צולייגן אַ טעקע; קיין קאָד־ענדערונגען פֿאָדערן זיך נישט. זעט [docs/TRANSLATING.md](../TRANSLATING.md) פֿאַרן טעקע־פֿאָרמאַט, אַ גרייטע פּראָמפּט פֿאַר מאַשין־איבערזעצונג און דעם פּראָווירונג־סקריפּט. איבערזעצונגען פֿון דעם README גייען אין `docs/i18n/README.<code>.md`.

## פּראָיעקט־אויסשטעלונג

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## פּריוואַטקייט

- Decoy ניצט דעם נעץ בלויז כּדי אַראָפּצולאָדן די עפֿנטלעכע דערקענונג־רשימה פֿון Discord (בײַם ערשטן אָנצינדן, און דערנאָך מערסטנס איין מאָל אַ טאָג אָדער ווען איר דריקט דערפֿרישן) און, פֿאַרן ווײַזן, שפּיל־איקאָנען און קונסט פֿונעם עפֿנטלעכן CDN פֿון Discord.
- עס לייענט נישט, האַלט נישט און שיקט נישט אײַער Discord־טאָקען אָדער קיין קאָנטע־דאַטן, און רעדט נישט מיטן Discord־קליענט.
- אינסטאַלאַציעס (פֿאַוואָריטן, שפּראַך, געדויערן) ווערן געהיט לאָקאַל אין דער WebView־זאַפּאַס פֿונעם אַפּ; דער שפּיל־רשימה קאַש און צײַטווײַליקע decoy־טעקעס לעבן אין `%LOCALAPPDATA%\app.decoy.desktop`.
- קיין אַנאַליטיקס, קיין קראַך־מעלדונגען, קיין קאָנטעס.

## באַקאַנטע באַגרענעצונגען

- Discord קען ענדערן ווי אַזוי דערקענונג אַרבעט אין יעדער צײַט. אויב אַ decoy הערט אויף צו ווערן דערקענט, ביטע עפֿנט אַן issue.
- טייל אַקטיוויטעטן דאַרפֿן מער ווי בלויז אַ לויפֿנדיקן פּראָצעס (למשל זײַן אין אַ געוויסער דערפֿאַרונג אויף אַ שפּיל־פּלאַטפֿאָרמע). Decoy נאָכמאַכט בלויז דעם פּראָצעס.
- אײַנסלאָגן אָן עקסיקיוטאַבאַלס אין Discord'ס רשימה קענען נישט ווערן דערקענט.
- זיכערהייט־פּראָגראַמען וואָרענען טיילמאָל וועגן קליינע נישט־אונטערגעשריבענע עקסיקיוטאַבאַלס וואָס זיצן אומטעטיק אין זכּרון. דער decoy איז פֿרײַער קוואַל־קאָד און געבויט פֿון `src-tauri/stub/stub.rs`; איר קענט אים קאָמפּילירן אַליין.

## אָפּזאָג פֿון אַחריות

Decoy ווערט צוגעשטעלט „ווי עס איז“ פֿאַר פּערזענלעכע, בילדונגס־ און פּראָבע־צוועקן. נאָכמאַכן אַ לויפֿנדיקע שפּיל קען פֿאַרלעצן די תּנאָים פֿון Discord אָדער פֿונעם שפּיל־פֿאַרלעגער, און קען פֿירן צו שריט קעגן אײַער קאָנטע. איר אַליין זײַט פֿאַראַנטוואָרטלעך ווי איר ניצט עס. „Discord“ און אַלע שפּיל־נעמען און לאָגאָס זײַנען האַנדלסמאַרקס פֿון זייערע רעספּעקטיווע אייגנטימער און ווערן דאָ געניצט בלויז כּדי צו אידענטיפֿיצירן די פּראָגראַמוואַרג אויף וואָס זיי באַציִען זיך.
