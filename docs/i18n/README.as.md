# Decoy

**ক্ষুদ্ৰ ষ্টেণ্ড-ইন প্ৰক্ৰিয়া যিয়ে Discord-ক এটা গেম চলি থকা বুলি ভৱায়।**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)

Decoy-এ কোনো গেমৰ এক্সেকিউটেবল নামেৰে এটা নিৰীহ, উইণ্ড'যুক্ত প্লেচহোল্ডাৰ প্ৰক্ৰিয়া চলাই ৰাখে, যাৰ ফলত Discord-ৰ গেম চিনাক্তকৰণ ব্যৱস্থাই আপুনি সেই গেমটো খেলি থকা বুলি প্ৰদৰ্শন কৰে। আপুনি কেতিয়াও প্ৰকৃত গেমটো ইনষ্টল বা আৰম্ভ কৰিব নালাগে, গতিকে আপোনাৰ ডিস্কত কোনো ডাঙৰ ফাইল নাথাকে।

ই **Discord-এ চিনাক্ত কৰিব পৰা প্ৰতিটো গেমৰ** (প্ৰায় ২৫,০০০ টা এন্ট্ৰি) বিষয়ে জানে, কাৰণ ই Discord-ৰ নিজা ৰাজহুৱা চিনাক্তকৰণ তালিকা পঢ়ে আৰু নিজে নিজেই ইয়াক আপ-টু-ডেট ৰাখে।

> [!WARNING]
> চলি থকা গেম এটাৰ ভুৱা উপস্থিতি দেখুওৱাটো Discord-ৰ সেৱাৰ চৰ্তাবলীৰ (Terms of Service) বিৰোধী হ'ব পাৰে আৰু আপুনি **নিজৰ দায়িত্বত** Decoy ব্যৱহাৰ কৰিব লাগিব। এই প্ৰকল্পটো Discord Inc.-ৰ দ্বাৰা অনুমোদিত, সমৰ্থিত বা সংযুক্ত নহয়। [দায় অস্বীকাৰ](#দায়-অস্বীকাৰ) চাওক।

## বৈশিষ্ট্যসমূহ

- **Discord-এ চিনাক্ত কৰিব পৰা সকলো বস্তু।** গেমৰ তালিকাখন Discord-ৰ ৰাজহুৱা চিনাক্তকৰণ এণ্ডপইণ্টৰ পৰা ডাউনলোড কৰা হয়, স্থানীয়ভাৱে কেচ কৰা হয় আৰু প্ৰতিদিনে ৰিফ্ৰেছ কৰা হয়। নতুন গেম আৰু নতুনকৈ যোগ কৰা এক্সেকিউটেবলসমূহ নিজে নিজেই তালিকাত ওলাই পৰে।
- **দ্ৰুত সন্ধান।** হাজাৰ হাজাৰ গেমৰ মাজৰ পৰা গেমৰ নাম বা এক্সেকিউটেবলৰ দ্বাৰা তৎক্ষণাৎ সন্ধান, গ্ৰিড বা কমপেক্ট তালিকা ভিউ, প্ৰিয় তালিকা আৰু "Recent" (শেহতীয়া) শাৰী।
- **এটা ক্লিকতে সকলো।** এটা গেম বাছক, এক্সেকিউটেবল বাছনি কৰক (যদি কেইবাটাও থাকে), কিমান সময় চলাই ৰাখিব নিৰ্ধাৰণ কৰক আৰু ষ্টাৰ্ট টিপক। এটা কাউণ্টডাউন ৰিং আৰু জাননীয়ে সময় শেষ হ'লে আপোনাক জনাই দিব।
- **একো অৱশিষ্ট এৰি নাযায়।** এটা decoy কেৱল চলি থকা অৱস্থাতহে থাকে: ক্ষুদ্ৰ exe ফাইলটো আৰম্ভ হোৱাৰ সময়ত সৃষ্টি হয় আৰু বন্ধ হ'লে বিলোপ কৰা হয়। আপুনি প্ৰস্থান কৰিলে সকলো বন্ধ হৈ যায় আৰু ক্ৰেশ্বৰ পৰা ৰৈ যোৱা অৱশিষ্টসমূহ পৰৱৰ্তী আৰম্ভণিত চাফা কৰা হয়।
- **শান্ত আৰু নিৰৱ।** চিষ্টেম ট্ৰেত থাকে, decoy-সমূহৰ নিজা কোনো উইণ্ড' বা টাস্কবাৰ বুটাম নাথাকে।
- **উন্মুক্ত অনুবাদ ব্যৱস্থা।** ইণ্টাৰফেচটো সাধাৰণ JSON ফাইলৰ দ্বাৰা পৰিচালিত, গতিকে নতুন এটা ভাষা যোগ কৰাটো কেৱল এটা ফাইলৰ কাম। English আৰু Russian অন্তৰ্ভুক্ত কৰা হৈছে।
- **ব্যক্তিগত আৰু সুৰক্ষিত।** কোনো একাউণ্ট নাই, কোনো Discord টোকেন নাই, কোনো টেলিমেট্ৰি নাই। [গোপনীয়তা](#গোপনীয়তা) চাওক।

## ই কেনেকৈ কাম কৰে

1. Discord-এ আপোনাৰ কম্পিউটাৰত চলি থকা প্ৰক্ৰিয়াসমূহ নিৰীক্ষণ কৰি আৰু এটা ৰাজহুৱা তালিকাৰ (`/api/v9/applications/detectable`) সৈতে সেইবোৰৰ এক্সেকিউটেবল নাম তুলনা কৰি নিৰ্ধাৰণ কৰে যে আপুনি কোনো গেম খেলি আছে নে নাই।
2. Decoy-এ সেই তালিকাখন ডাউনলোড কৰে আৰু আপুনি বাছি লোৱা গেমটোৰ বাবে তালিকাৰ পৰা পোৱা এক্সেকিউটেবল নাম ব্যৱহাৰ কৰি এটা ক্ষুদ্ৰ ষ্টেণ্ড-ইন প্ৰগ্ৰাম (প্ৰায় ১২০ KB, Rust-ত লিখা আৰু Decoy-ৰ ভিতৰত এম্বেড কৰা) এটা অস্থায়ী ফোল্ডাৰলৈ কপি কৰে, উদাহৰণস্বৰূপে `.../cod26-cod.exe`।
3. ষ্টেণ্ড-ইন প্ৰগ্ৰামটোৱে কেৱল এটা টপ-লেভেল উইণ্ড' ধৰি ৰখাৰ বাহিৰে আন একো নকৰে, যিটো স্ক্ৰীণৰ বহু বাহিৰত ৰখা হয় যাতে আপুনি কেতিয়াও তাক নেদেখে। Discord-এ কেৱল সেইবোৰ প্ৰক্ৰিয়াকহে চিনাক্ত কৰে যাৰ এটা উইণ্ড' আছে, যাৰ বাবে সম্পূৰ্ণৰূপে উইণ্ড'বিহীন প্ৰক্ৰিয়াক আওকাণ কৰা হয়।
4. প্ৰায় ১৫ ছেকেণ্ডৰ ভিতৰত Discord-এ গেমটোক আপোনাৰ বৰ্তমান কাৰ্যকলাপ হিচাপে দেখুৱাবলৈ আৰম্ভ কৰে।
5. টাইমাৰ শেষ হ'লে বা আপুনি ষ্টপ টিপিলে, Decoy-এ প্ৰক্ৰিয়াটো শেষ কৰে আৰু ফাইলটো মচি পেলায়। এটা Windows job object-এ নিশ্চিত কৰে যে Decoy ক্ৰেশ্ব হ'লেও decoy প্ৰক্ৰিয়াসমূহ Decoy-ৰ সৈতেই একেলগে বন্ধ হৈ যাব।

## ইনষ্টলেশন

[Releases](../../../../releases) পৃষ্ঠাৰ পৰা এটা বাছি লওক:

| ডাউনলোড | যাৰ বাবে |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ইনষ্টলাৰ।** প্ৰতিজন ব্যৱহাৰকাৰীৰ বাবে (per-user), কোনো এডমিনিষ্ট্ৰেটৰ অধিকাৰৰ প্ৰয়োজন নাই, ষ্টাৰ্ট মেনুত এটা এন্ট্ৰি আৰু এটা আনইনষ্টলাৰ যোগ কৰে। |
| `Decoy_x.y.z_x64-portable.zip` | **পৰ্টেবল।** যিকোনো ঠাইতে আনজিপ কৰক আৰু `decoy.exe` চলাওক। সকলো ডাটা ইয়াৰ কাষৰ `data` ফোল্ডাৰত থাকে, আপোনাৰ ব্যৱহাৰকাৰী প্ৰফাইলত একো লিখা নহয়। ইয়াক আঁতৰাবলৈ কেৱল ফোল্ডাৰটো মচি পেলাওক। |

`SHA256SUMS.txt` ব্যৱহাৰ কৰি ডাউনলোড সত্যাপন কৰক (PowerShell-ত `Get-FileHash <file>`)।

বিল্ডসমূহত কোড স্বাক্ষৰ নকৰা বাবে Windows SmartScreen-এ অজ্ঞাত প্ৰকাশকৰ বিষয়ে সতৰ্ক কৰিব পাৰে; আপুনি যদি বিল্ডটোক বিশ্বাস কৰে তেন্তে *More info → Run anyway* বাছনি কৰক।

প্ৰয়োজনীয়তা: WebView2 ৰানটাইম সহ Windows 10 বা 11 (64-bit) (Windows 11 আৰু শেহতীয়া Windows 10 আপডেটসমূহত ইতিমধ্যে অন্তৰ্ভুক্ত আছে)।

## ব্যৱহাৰবিধি

1. **Library** খোলক আৰু এটা গেম সন্ধান কৰক, বা যিকোনো ঠাইৰ পৰা `Ctrl` + `K` টিপক।
2. এটা গেমত ক্লিক কৰক। সোঁফালৰ পেনেলত প্ৰক্ৰিয়াটো আৰু ইয়াক কিমান মিনিট চলাই ৰাখিব সেয়া বাছক (Discord কাৰ্যকলাপসমূহৰ বাবে সাধাৰণতে ১৫ মিনিটৰ প্ৰয়োজন হয়)।
3. **Start decoy** টিপক। কেইছেকেণ্ডমানৰ ভিতৰত Discord-এ গেমটো দেখুৱাব।
4. **Running**-ৰ অধীনত ইয়াক চাওক, যিকোনো সময়তে এটা বা সকলোবোৰ বন্ধ কৰক, নাইবা Decoy-ক ট্ৰেত এৰি দিয়ক।

যিবোৰ গেমৰ Discord এন্ট্ৰিত এতিয়াও কোনো এক্সেকিউটেবল নাই, সেইবোৰ ডিফল্টভাৱে লুকুৱাই ৰখা হয় (সেইবোৰ চিনাক্ত কৰিব নোৱাৰি)। সেইবোৰ চাবলৈ *Show games without exe* অন কৰক; তালিকাখন প্ৰতিদিনে ৰিফ্ৰেছ কৰা হয়, গতিকে Discord-এ কোনো প্ৰক্ৰিয়া যোগ কৰাৰ লগে লগে সেইবোৰ উপলব্ধ হৈ পৰে।

### কমাণ্ড লাইন

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

তৎক্ষণাৎ এটা decoy আৰম্ভ কৰে, উদাহৰণস্বৰূপে `decoy.exe --launch "robloxplayerbeta.exe" 15`।

## উৎস ক'ডৰ পৰা বিল্ড কৰা

পূৰ্বচৰ্ত: [Node.js](https://nodejs.org) 20+, Visual Studio C++ বিল্ড টুলছ সহ ষ্টেবল [Rust](https://rustup.rs) টুলচেইন (MSVC টাৰ্গেট), আৰু WebView2 ৰানটাইম।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

উপকাৰী পৰীক্ষাসমূহ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

টোকা: decoy exe ফাইলটো `src-tauri/build.rs` দ্বাৰা `src-tauri/stub/stub.rs`-ৰ পৰা সাধাৰণ `rustc` ব্যৱহাৰ কৰি কম্পাইল কৰা হয় আৰু তাৰ পিছত এপত এম্বেড কৰা হয়। যেতিয়া ফ্ৰন্টএণ্ড সাধাৰণ ব্ৰাউজাৰত চলে (`npm run dev`), তেতিয়া এটা সৰু মক বেকএণ্ড (`src/mock.ts`) ব্যৱহাৰ কৰা হয়, যিটো UI-ত কাম কৰাৰ বাবে উপযোগী।

## অনুবাদ

UI ষ্ট্ৰিংবোৰ [`src/locales`](../../src/locales)-ত থাকে, প্ৰতিটো ভাষাৰ বাবে এটা JSON ফাইল (`en.json`, `ru.json`, ...)। এটা ভাষা যোগ কৰা মানে কেৱল এটা ফাইল যোগ কৰা; কোনো ক'ড পৰিৱৰ্তন কৰিব নালাগে। ফাইল ফৰ্মেট, মেচিন অনুবাদৰ বাবে প্ৰস্তুত প্ৰম্প্ট আৰু বৈধকৰণ স্ক্ৰিপ্টৰ বাবে [docs/TRANSLATING.md](../TRANSLATING.md) চাওক। এই README-ৰ অনুবাদসমূহ `docs/i18n/README.<code>.md`-লৈ যায়।

## প্ৰকল্পৰ গঠন

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## গোপনীয়তা

- Decoy-এ কেৱল Discord-ৰ ৰাজহুৱা চিনাক্তকৰণ তালিকা ডাউনলোড কৰিবলৈ (প্ৰথম আৰম্ভণিত, তাৰ পিছত দিনত সৰ্বাধিক এবাৰ বা যেতিয়া আপুনি ৰিফ্ৰেছ টিপে) আৰু প্ৰদৰ্শনৰ বাবে Discord-ৰ ৰাজহুৱা CDN-ৰ পৰা গেমৰ আইকন আৰু আৰ্টৱৰ্ক আনিবলৈ নেটৱৰ্ক ব্যৱহাৰ কৰে।
- ই আপোনাৰ Discord টোকেন বা কোনো একাউণ্ট ডাটা নপঢ়ে, সংৰক্ষণ নকৰে বা প্ৰেৰণ নকৰে, আৰু ই Discord ক্লায়েণ্টৰ সৈতে যোগাযোগ নকৰে।
- ছেটিংছ (প্ৰিয়, ভাষা, সময়সীমা) স্থানীয়ভাৱে এপৰ WebView ষ্ট'ৰেজত সংৰক্ষিত হয়; গেম তালিকাৰ কেচ আৰু অস্থায়ী decoy ফাইলসমূহ `%LOCALAPPDATA%\app.decoy.desktop`-ত থাকে।
- কোনো বিশ্লেষণ (analytics) নাই, কোনো ক্ৰেশ্ব ৰিপৰ্টিং নাই, কোনো একাউণ্ট নাই।

## জ্ঞাত সীমাবদ্ধতাসমূহ

- Discord-এ যিকোনো সময়তে চিনাক্তকৰণ পদ্ধতি সলনি কৰিব পাৰে। যদি কোনো decoy চিনাক্ত নোহোৱা হয়, অনুগ্ৰহ কৰি এটা সমস্যা (issue) খোলক।
- কিছুমান কাৰ্যকলাপৰ বাবে চলি থকা প্ৰক্ৰিয়াতকৈও অধিক কিবা এটাৰ প্ৰয়োজন হয় (উদাহৰণস্বৰূপে গেম প্লেটফৰ্মৰ কোনো বিশেষ অভিজ্ঞতাৰ ভিতৰত থকা)। Decoy-এ কেৱল প্ৰক্ৰিয়াটোক অনুকৰণ কৰে।
- Discord-ৰ তালিকাত এক্সেকিউটেবল নথকা এন্ট্ৰিসমূহ চিনাক্ত কৰিব নোৱাৰি।
- মেমৰিত নিষ্ক্ৰিয় হৈ বহি থকা সৰু আনস্বাক্ষৰিত এক্সেকিউটেবলসমূহক সুৰক্ষা ছফ্টৱেৰে কেতিয়াবা সন্দেহজনক বুলি চিহ্নিত কৰিব পাৰে। Decoy হৈছে মুক্ত উৎস আৰু `src-tauri/stub/stub.rs`-ৰ পৰা তৈয়াৰী; আপুনি ইয়াক নিজে কম্পাইল কৰি ল'ব পাৰে।

## দায় অস্বীকাৰ

Decoy ব্যক্তিগত, শিক্ষামূলক আৰু পৰীক্ষামূলক উদ্দেশ্যত "যেনে আছে তেনে" (as is) ভিত্তিত প্ৰদান কৰা হৈছে। কোনো চলি থকা গেম অনুকৰণ কৰাটো Discord বা গেম প্ৰকাশকৰ সেৱাৰ চৰ্তাবলী উলংঘন কৰিব পাৰে, আৰু আপোনাৰ একাউণ্টৰ বিৰুদ্ধে ব্যৱস্থা গ্ৰহণৰ কাৰণ হ'ব পাৰে। আপুনি ইয়াক কেনেকৈ ব্যৱহাৰ কৰে তাৰ বাবে কেৱল আপুনিয়ে দায়বদ্ধ। "Discord" আৰু সকলো গেমৰ নাম আৰু লোগো নিজ নিজ স্বত্বাধিকাৰীৰ ট্ৰেডমাৰ্ক আৰু ইয়াত কেৱল ছফ্টৱেৰসমূহ চিনাক্ত কৰাৰ উদ্দেশ্যত ব্যৱহাৰ কৰা হৈছে।
