# Decoy

**მცირე შემცვლელი პროცესები, რომელთა მეშვეობითაც Discord თვლის, რომ თამაში გაშვებულია.**

Decoy უზრუნველყოფს უსაფრთხო, ფანჯრიანი შემცვლელი პროცესის მუშაობას თამაშის შემსრულებელი ფაილის სახელით, რის გამოც Discord-ის თამაშების ამოცნობის ფუნქცია აჩვენებს, რომ თქვენ თამაშობთ ამ თამაშს. თქვენ არასდროს გჭირდებათ ნამდვილი თამაშის დაყენება ან გაშვება, ამიტომ დისკზე არაფერი ზედმეტი არ რჩება.

მან იცის **ყველა თამაშის შესახებ, რისი ამოცნობაც Discord-ს შეუძლია** (დაახლოებით 25,000 ჩანაწერი), რადგან კითხულობს თავად Discord-ის საჯარო ამოცნობის სიას და მას დამოუკიდებლად აახლებს.

> [!WARNING]
> გაშვებული თამაშის იმიტაცია შეიძლება ეწინააღმდეგებოდეს Discord-ის მომსახურების პირობებს და თქვენ იყენებთ Decoy-ს **საკუთარი რისკით**.
> ეს პროექტი არ არის დაკავშირებული, მოწონებული ან მხარდაჭერილი Discord Inc.-ის მიერ. იხილეთ [პასუხისმგებლობის უარყოფა](#პასუხისმგებლობის-უარყოფა).

## შესაძლებლობები

- **ყველაფერი, რისი ამოცნობაც Discord-ს შეუძლია.** თამაშების სია იტვირთება Discord-ის საჯარო ამოცნობის ბოლო წერტილიდან, ქეშირდება ლოკალურად და ახლდება ყოველდღიურად. ახალი თამაშები და ახლად დამატებული გამშვები ფაილები თავისით ჩნდება.
- **სწრაფი ძებნა.** მყისიერი ძებნა თამაშის სახელით ან გამშვები ფაილით ათასობით თამაშს შორის, ბადისებრი ან კომპაქტური სიის ხედი, რჩეულები და „ბოლოდროინდელი“ სტრიქონი.
- **ერთი დაწკაპუნებით.** აირჩიეთ თამაში, აირჩიეთ გამშვები ფაილი (თუ რამდენიმეა), მიუთითეთ რამდენი ხნით დარჩეს და დააჭირეთ დაწყებას. უკუთვლის რგოლი და შეტყობინება გაცნობებთ, როდესაც დრო ამოიწურება.
- **უკვალოდ.** Decoy მხოლოდ გაშვებულ მდგომარეობაში არსებობს: პატარა exe იქმნება დაწყებისას და იშლება შეჩერებისას. ყველაფერი ჩერდება აპიდან გასვლისას, ხოლო ავარიული გათიშვის შემდეგ დარჩენილი ფაილები სუფთავდება შემდეგი გაშვებისას.
- **ჩუმი.** იმყოფება სისტემურ თრეიში, არანაირი ფანჯრები ან ამოცანათა პანელის ღილაკები თავად decoy-ებისთვის.
- **ღია თარგმანები.** ინტერფეისი მუშაობს მარტივ JSON ფაილებზე, ამიტომ ენის დამატება მხოლოდ ერთი ფაილია. ინგლისური და რუსული უკვე მოყვება.
- **კონფიდენციალური.** არანაირი ანგარიში, არანაირი Discord-ის ტოკენი, არანაირი ტელემეტრია. იხილეთ [კონფიდენციალურობა](#კონფიდენციალურობა).

## როგორ მუშაობს

1. Discord განსაზღვრავს, რომ თქვენ თამაშობთ თამაშს, თქვენს კომპიუტერზე გაშვებული პროცესების შემოწმებით და მათი გამშვები ფაილების სახელების შედარებით საჯარო სიასთან (`/api/v9/applications/detectable`).
2. Decoy ჩამოტვირთავს ამ სიას და თქვენ მიერ არჩეული თამაშისთვის აკოპირებს პატარა შემცვლელ პროგრამას (დაახლოებით 120 კბ, დაწერილია Rust-ზე და ჩაშენებულია Decoy-ში) დროებით საქაღალდეში სიიდან აღებული გამშვები ფაილის სახელით, მაგალითად `.../cod26-cod.exe`.
3. შემცვლელი პროგრამა არაფერს აკეთებს, გარდა ერთი უმაღლესი დონის ფანჯრის ქონისა, რომელიც ეკრანს მიღმა შორს არის განთავსებული, რათა ვერასდროს დაინახოთ. Discord ცნობს მხოლოდ იმ პროცესს, რომელიც ფლობს ფანჯარას, რის გამოც სრულიად უფანჯრო პროცესები იგნორირებულია.
4. დაახლოებით 15 წამში Discord აჩვენებს თამაშს თქვენს მიმდინარე აქტივობად.
5. როდესაც ტაიმერი ამოიწურება ან დააჭერთ შეჩერებას, Decoy ასრულებს პროცესს და შლის ფაილს. Windows-ის job ობიექტი უზრუნველყოფს decoy-ების შეწყვეტას Decoy-სთან ერთად, მაშინაც კი, თუ ის ავარიულად დაიხურება.

## გამოყენება

1. გახსენით **ბიბლიოთეკა** და მოძებნეთ თამაში, ან დააჭირეთ `Ctrl` + `K` ნებისმიერი ადგილიდან.
2. დააჭირეთ თამაშს. მარჯვენა პანელში აირჩიეთ პროცესი და რამდენი წუთით გსურთ მისი შენარჩუნება (Discord-ის დავალებები ჩვეულებრივ მოითხოვს 15 წუთს).
3. დააჭირეთ **Decoy-ს გაშვება**. Discord რამდენიმე წამში აჩვენებს თამაშს.
4. აკონტროლეთ ის განყოფილებაში **გაშვებული**, შეაჩერეთ ერთი ან ყველა ნებისმიერ დროს, ან უბრალოდ დატოვეთ Decoy თრეიში.

თამაშები, რომელთა Discord-ის ჩანაწერს ჯერ არ აქვს გამშვები ფაილი, ნაგულისხმევად დამალულია (მათი ამოცნობა შეუძლებელია). ჩართეთ *exe-ის გარეშე თამაშების ჩვენება* მათ სანახავად; სია ყოველდღიურად ახლდება, ამიტომ ისინი ხელმისაწვდომი გახდება, როგორც კი Discord დაამატებს პროცესს.

### ბრძანების სტრიქონი

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

იწყებს decoy-ს პირდაპირ, მაგალითად `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## აწყობა წყაროდან

წინაპირობები: [Node.js](https://nodejs.org) 20+, სტაბილური [Rust](https://rustup.rs) ხელსაწყოები (MSVC სამიზნე) Visual Studio C++ build tools-თან ერთად, და WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # გაშვება დეველოპერის რეჟიმში hot reload-ით
npm run tauri build    # ინსტალერის შექმნა src-tauri/target/release/bundle/nsis საქაღალდეში
```

სასარგებლო შემოწმებები:

```bash
npm run check-locales  # ყოველი თარგმანის ფაილის ვალიდაცია ru.json-თან შედარებით
npx tsc --noEmit       # frontend-ის ტიპების შემოწმება
cargo check --manifest-path src-tauri/Cargo.toml
```

შენიშვნები: decoy exe კომპილირდება `src-tauri/build.rs`-ის მიერ ჩვეულებრივი `rustc`-ით `src-tauri/stub/stub.rs`-დან და შემდეგ ჩაშენებულია აპლიკაციაში. როდესაც frontend ეშვება ჩვეულებრივ ბრაუზერში (`npm run dev`), გამოიყენება მცირე იმიტირებული backend (`src/mock.ts`), რაც მოსახერხებელია UI-ზე მუშაობისთვის.

## თარგმანები

ინტერფეისის სტრიქონები მოთავსებულია [`src/locales`](../../src/locales) საქაღალდეში, თითო JSON ფაილი თითო ენაზე (`en.json`, `ru.json`, ...). ახალი ენის დამატება ნიშნავს ახალი ფაილის დამატებას; კოდში ცვლილებები საჭირო არ არის. ფაილის ფორმატისთვის, მანქანური თარგმანის მზა მოთხოვნისა (prompt) და ვალიდაციის სკრიპტისთვის იხილეთ [docs/TRANSLATING.md](../TRANSLATING.md). ამ README-ს თარგმანები ინახება `docs/i18n/README.<code>.md` ფაილებში.

## კონფიდენციალურობა

- Decoy იყენებს ქსელს მხოლოდ Discord-ის საჯარო ამოცნობის სიის ჩამოსატვირთად (პირველი გაშვებისას, შემდეგ კი მაქსიმუმ დღეში ერთხელ ან განახლების ღილაკზე დაჭერისას) და, გამოსახვის მიზნით, თამაშების ხატულებისა და ყდების ჩამოსატვირთად Discord-ის საჯარო CDN-დან.
- ის არ კითხულობს, არ ინახავს და არ აგზავნის თქვენს Discord-ის ტოკენს ან ანგარიშის რაიმე მონაცემს, და არ უკავშირდება Discord-ის კლიენტს.
- პარამეტრები (რჩეულები, ენა, ხანგრძლივობები) ინახება ლოკალურად აპის WebView მეხსიერებაში; თამაშების სიის ქეში და დროებითი decoy ფაილები განთავსებულია `%LOCALAPPDATA%\app.decoy.desktop`-ში.
- არანაირი ანალიტიკა, არანაირი ავარიული შეტყობინებები, არანაირი ანგარიშები.

## ცნობილი შეზღუდვები

- Discord-ს შეუძლია ნებისმიერ დროს შეცვალოს ამოცნობის მუშაობის პრინციპი. თუ decoy-ს ამოცნობა შეწყდება, გთხოვთ, გახსენით issue.
- ზოგიერთ აქტივობას სჭირდება მეტი, ვიდრე უბრალოდ გაშვებული პროცესი (მაგალითად, თამაშის პლატფორმის კონკრეტულ გამოცდილებაში ყოფნა). Decoy ახდენს მხოლოდ პროცესის იმიტაციას.
- Discord-ის სიაში გამშვები ფაილების გარეშე არსებული ჩანაწერების ამოცნობა შეუძლებელია.
- უსაფრთხოების პროგრამებმა (ანტივირუსებმა) შესაძლოა დროდადრო მცდარად მონიშნონ პატარა ხელმოუწერელი გამშვები ფაილები, რომლებიც მეხსიერებაში უმოქმედოდ იმყოფება. Decoy არის ღია კოდის მქონე და აწყობილია `src-tauri/stub/stub.rs`-დან; შეგიძლიათ თავად დააკომპილიროთ იგი.
