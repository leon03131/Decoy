# Decoy

**Małe procesy zastympcze, bez kere Discord myśli, że szpil dźoło.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibliytyka Decoy ze śwjyżymi szpilami i grafikami" />

</div>

Decoy utrzimuje ńyzkodliwy proces zastympczy ze uoknym pod mjanym pliku wykonywalnygo szpilu, skiż czygo wykrywańy szpilůw we Discordźe godo, że szpilosz we tyn szpil. Ńigdy ńy musisz instalować ańi sztartować richtich szpilu, tůż żodno rubyńizna ńy leży na dysku.

Zno **kożdy szpil, kery Discord potrefi wykryć** (kole 25 000 pozycyji), bo czyto publiczno lista wykrywańo Discorda i samo dba uo jeij aktualność.

> [!WARNING]
> Falszowańy włůnczůnygo szpilu może być sprzeczne ze Warůnkami usługi Discord i używosz Decoy **na własne ryzyko**.
> Tyn projekt ńy mo nic spůlnygo ze Discord Inc., ńy je bez ńich wspiyrany ańi powiůnzany. Uobocz [Zrzeczyńy uodpedźalnośći](#zrzeczyńy-uodpedźalnośći).

## Fůnkcyje

- **Wszyjsko, co Discord poradźi wykryć.** Lista szpilůw je pobiyrano ze publicznygo kůńca api Discorda, spamiytowano lokalńy i uodśwjyżano co dziyń. Nowe szpile i nowe pliki exe pokozujům sie same.
- **Szpancowańy, kere dowo rada.** Wartke szukańy po mjańe szpilu abo pliku exe pośrůd tyśyncy szpilůw, widok kaflůw abo zartyj listy, ulybjůne a tyż rajka „Świyże”.
- **Jedno klikńyńćy.** Wybjyr szpil, wybjyr plik exe (jak je jejich wiyncyj), uokryśl czas dźołańo i wćiśnij sztart. Pjyrśćyń uodliczańo i powjadůmjyńy dowajům znać, kej czas minie.
- **Ńic po sobjy ńy zostawjo.** Atrapa żyje ino wtynczos, kej dźoło: mały plik exe je robjůny na sztarće i ciulany na stopje. Wszyjsko je zastawiane przi zawarću, a resztki po awarii sům sprzůntane przi nastympnym włůnczyńu.
- **Cichy.** Żyje we zasobńiku systemowym (tray), żodnych uokiyn ańi knefli na pasku zadań lo samych atrap.
- **Uotwarte przekłady.** Interfejs dźoło na prostych plikach JSON, tůż dowańy godki to je jedyn plik. Angielski i ruski sům w zestowje.
- **Prywatność.** Bez kůnta, bez tokena Discorda, bez telemetryje. Uobocz [Prywatność](#prywatność).

## Jak to dźoło

1. Discord decyduje, że szpilosz we szpil, filujůnc na procesy włůnczůne na Twojim kůmputrze i porůwnujůnc mjana ich plikůw exe ze publicznům listům (`/api/v9/applications/detectable`).
2. Decoy pobjyro ta lista i lo wybranygo szpilu kopiuje mały program zastympczy (kole 120 KB, naszkryflany we Rust i wbudowany do Decoy) do folderu tymczasowygo pod mjanym pliku exe ze listy, na przikład `.../cod26-cod.exe`.
3. Program zastympczy ńic ńy robi, krům tygo że mo jedne uokno nojwyższygo poziomu, postawiůne daleko poza ekranym, coby go ńigdy ńy bůło widać. Discord wykrywo ino procesy majůnce uokno, skiż czygo proces blank bezuokiynny je ignorowany.
4. We czas jakichś 15 sekund Discord pokozuje szpil kej Twoja aktualno aktywność.
5. Kej czas minie abo wciśńysz stop, Decoy kůńczy proces i ciulo plik. Uobjekt zadania Windows (job object) dowo zicher, że atrapy zakůńczům dźołać razym ze Decoy, nawyt kej aplikacyjo padńy.

## Instalacyjo

Wybjyr ze strůny [Releases](../../../../releases):

| Plik do pobrańo | Do czygo |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalator.** Lo kożdygo używocza, bez praw administratora, dowo wpis we menu Sztart i deinstalator. |
| `Decoy_x.y.z_x64-portable.zip` | **Wersyjo portable.** Rozpakuj kaj chcesz i włůncz `decoy.exe`. Wszyjske dane uostowajům we folderze `data` kole programu, ńic ńy je szkryflane do profilu używocza. Skasuj folder, coby go usunůńć. |

Zweryfikuj pobrany plik bez `SHA256SUMS.txt` (`Get-FileHash <file>` we PowerShellu).

Windows SmartScreen może pokozać uostrzeżyńy uo ńyznanym wydawcy, skiż tygo że kompilacyje ńy majům cyfrowygo podpisu; wybjyr *Wjyncyj informacyji → Uruchom mimo to*, kej dowosz wjara tyj kompilacyji.

Wymogańa: Windows 10 abo 11 (64-bit) ze środowiskym uruchůmjyńowym WebView2 (znajduje sie już we Windows 11 a tyż we nowszych aktualizacyjach Windows 10).

## Jak używać

1. Uotwůrz **Bibliytyka** i znojdź szpil, abo wciśnij `Ctrl` + `K` uobojyntńy kaj.
2. Kliknij na szpil. We panelu na prawo wybjyr proces i wjela minut mo trwać (questy Discorda nojczyńśćij chcům 15).
3. Wciśnij **Włůncz atrapa**. Discord pokoże szpil po paru sekundach.
4. Filuj na ńa we **Włůnczůne**, zastow jedna abo wszyske kej chcesz, abo uostow Decoy we zasobńiku.

Szpile, kere we wpisach Discorda ńy majům jeszcze plikůw exe, sům důmylńy skryte (ńy idźe ich wykryć). Włůncz *Pokoż szpile bez exe*, coby je widźeć; lista je uodśwjyżano co dziyń, tůż bydům dostympne kej ino Discord dodo proces.

### Wjyrsz polecyń

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Włůnczo atrapa uod razu, na przikład `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Budowańy ze zdrzudeł

Wymogi: [Node.js](https://nodejs.org) 20+, stabilny cug norzyndźi [Rust](https://rustup.rs) (cel MSVC) ze norzyndźůma kompilacyji C++ Visual Studio i środowisko WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # włůncz we trybje deweloperskim ze hot reloadym
npm run tauri build    # zrychtuj instalator we src-tauri/target/release/bundle/nsis
```

Przidatne spróbůnki:

```bash
npm run check-locales  # sprŏwdź kożdy plik przekładu wzglyndym ru.json
npx tsc --noEmit       # kůntrola typůw lo frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Pozůr: plik exe atrapy je kůmpilowany bez `src-tauri/build.rs` zwykłym `rustc` ze pliku `src-tauri/stub/stub.rs`, a potym wkludzony do aplikacyji. Kej frontend dźoło we zwykłyj przeglůndarce (`npm run dev`), używany je mały mock backend (`src/mock.ts`), co je fest porynczne przi robje nad interfejsym.

## Przekłady

Napisy interfejsu sům we [`src/locales`](../../src/locales), jedyn plik JSON na godka (`en.json`, `ru.json`, ...). Dodańy godki uoznaczo dodańy pliku; żodnych zmian we kodźe. Uobocz [docs/TRANSLATING.md](../TRANSLATING.md) lo formatu pliku, gotowygo promptu do maszynowygo przekładu a tyż skryptu do sprŏwdzańo. Przekłady tygo README idům do `docs/i18n/README.<code>.md`.

## Prywatność

- Decoy używo neca ino coby pobrać publiczno lista wykrywańo ze Discorda (przi pjyrszym włůnczyńu, a potym nojwyżyj roz na dziyń abo kej wciśńysz uodśwjyżańy) i do wyśwjytlańo ikůn oraz grafik ze publicznygo CDN Discorda.
- Ńy czyto, ńy spamiytuje ańi ńy wysyło Twojigo tokena Discord ańi żodnych danych kůnta, i ńy godo ze klijyntym Discorda.
- Nasztalowańa (ulybjůne, godka, czas trwańo) sům spamiytane lokalńy we magazynie WebView aplikacyji; podrynczno pamiynć bazy szpilůw i pliki tymczasowe atrap sům we `%LOCALAPPDATA%\app.decoy.desktop`.
- Żodnyj telemetryje, żodnygo zbyranio raportůw uo awariach, żodnych kůnt.

## Znane uograńiczyńa

- Discord może we kożdyj chwili pomjyńać spůsůb wykrywańo. Kej atrapa przestanie być widźano, uotwůrz issue.
- Niykere aktywnośći potrzebujům wiyncyj aniżeli ino włůnczůny proces (na przikład byńdźe we uokryślůnym świecie platformy). Decoy udowo ino proces.
- Wpisy bez plikůw exe na liście Discorda ńy mogům być wykryte.
- Programy antywirusowe czasym oznaczajům małe, ńypodpisane pliki exe, kere bezczynńy siedzům we pamiynći. Atrapa je uotwartoźrúdłowo i budowano ze `src-tauri/stub/stub.rs`; můżesz jům skompilować sům.

## Zrzeczyńy uodpedźalnośći

Decoy je dany „tak jak je” do cwekůw prywatnych, edukacyjnych i testowych. Symulowańy włůnczůnygo szpilu może łůmać Regulamiyn usługi Discord abo wydawcy szpilu i może skludzić kory na Twoje kůnto. Ty sam ponosisz uodpedźalność za to, jak go używosz. „Discord” i wszyjske mjana szpilůw oraz loga to znaki towarowe ich rechtownych posiedzicieli i sům użyte sam ino coby pokozać uo jake software sie rozchodzi.
