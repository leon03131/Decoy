# Decoy

**Lítil staðgenglaferli sem láta Discord halda að leikur sé í gangi.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy leikjasafn með nýlegum leikjum og myndum" />

</div>

Decoy heldur skaðlausu staðgenglaferli með glugga gangandi undir keyrsluskrárheiti (exe) leiks, þannig að leikjagreining Discord sýnir að þú sért að spila þann leik. Þú þarft aldrei að setja upp eða ræsa raunverulega leikinn, þannig að ekkert plássfrekt situr á disknum þínum.

Forritið þekkir **alla leiki sem Discord getur greint** (um 25.000 færslur) vegna þess að það les opinbera greiningarlista Discord og heldur honum sjálfkrafa uppfærðum.

> [!WARNING]
> Að herma eftir leik í gangi getur brotið gegn þjónustuskilmálum Discord og þú notar Decoy **á eigin ábyrgð**.
> Þetta verkefni er ekki tengt, stutt af eða tengt Discord Inc. á nokkurn hátt. Sjá [Fyrirvari](#fyrirvari).

## Eiginleikar

- **Allt sem Discord getur greint.** Leikjalistanum er hlaðið niður frá opinberum endastöðvum Discord, hann vistaður staðbundið og endurnýjaður daglega. Nýir leikir og nýlega bættar keyrsluskrár birtast sjálfkrafa.
- **Leit sem fylgir þér.** Snögg leit eftir heiti leiks eða keyrsluskrá yfir þúsundir leikja, reita- eða þjappað listayfirlit, eftirlæti og röð með „Nýlegt“.
- **Einn smellur.** Veldu leik, veldu keyrsluskrána (ef þær eru fleiri en ein), veldu hversu lengi á að halda honum gangandi og smelltu á byrja. Niðurtalningarhringur og tilkynning láta þig vita þegar tíminn er liðinn.
- **Skilur ekkert eftir.** Decoy er aðeins til á meðan það keyrir: örsmá exe-skrá er búin til við ræsingu og henni eytt við stöðvun. Öllu er lokað þegar þú hættir, og leifar eftir hugsanlegt hrun eru hreinsaðar við næstu ræsingu.
- **Hljóðlátt.** Dvelur í kerfisbakkanum, engir gluggar eða stikutakkar fyrir decoy-ferlin sjálf.
- **Opnar þýðingar.** Viðmótið notar einfaldar JSON-skrár, svo að bæta við tungumáli krefst aðeins einnar skrár. Enska og rússneska fylgja með.
- **Persónuvernd.** Enginn aðgangur, ekkert Discord-tákn (token), engin fjarvöktun eða gagnasöfnun. Sjá [Persónuvernd](#persónuvernd).

## Hvernig það virkar

1. Discord ákveður að þú sért að spila leik með því að skoða ferlin sem eru í gangi á tölvunni þinni og bera saman heiti keyrsluskránna við opinberan lista (`/api/v9/applications/detectable`).
2. Decoy sækir þann lista og afritar, fyrir valinn leik, lítið staðgenglaforrit (um 120 KB, skrifað í Rust og innfellt í Decoy) í tímabundna möppu undir keyrsluskrárheiti af listanum, til dæmis `.../cod26-cod.exe`.
3. Staðgengillinn gerir ekkert annað en að eiga einn glugga á efsta stigi, staðsettan langt utan skjásins svo þú sérð hann aldrei. Discord greinir aðeins ferli sem eiga glugga, þess vegna er litið fram hjá ferli sem hefur engan glugga.
4. Innan um það bil 15 sekúndna sýnir Discord leikinn sem núverandi virkni þína.
5. Þegar tímamælirinn rennur út eða þú ýtir á stöðva lýkur Decoy ferlinu og eyðir skránni. Windows-starfshlutur (job object) tryggir að decoy-ferli stöðvist ásamt Decoy, jafnvel þótt forritið hrynji.

## Uppsetning

Veldu útgáfu af [Releases](../../../../releases)-síðunni:

| Niðurhal | Fyrir |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Uppsetningarforrit.** Fyrir hvern notanda, krefst ekki stjórnandaréttinda, bætir við færslu í Start-valmyndina og afsetningarforriti. |
| `Decoy_x.y.z_x64-portable.zip` | **Færanlegt (portable).** Afþjappaðu hvar sem er og keyrðu `decoy.exe`. Öll gögn haldast í `data`-möppunni við hliðina á því, ekkert er skrifað í notandasniðið þitt. Eyddu möppunni til að fjarlægja það. |

Staðfestu niðurhal með `SHA256SUMS.txt` (`Get-FileHash <skrá>` í PowerShell).

Windows SmartScreen gæti varað við óþekktum útgefanda vegna þess að útgáfurnar eru ekki kóðaundirritaðar; veldu *Nánari upplýsingar → Keyra samt* ef þú treystir útgáfunni.

Kröfur: Windows 10 eða 11 (64-bita) með WebView2-keyrsluumhverfi (þegar innifalið í Windows 11 og nýlegum Windows 10 uppfærslum).

## Notkun

1. Opnaðu **Safn** og leitaðu að leik, eða ýttu á `Ctrl` + `K` hvar sem er.
2. Smelltu á leik. Í spjaldinu til hægri velurðu ferlið og hversu margar mínútur á að halda því (Discord-verkefni biðja venjulega um 15).
3. Smelltu á **Ræsa decoy**. Discord mun sýna leikinn eftir nokkrar sekúndur.
4. Fylgstu með honum undir **Í gangi**, stöðvaðu eitt eða öll hvenær sem er, eða leyfðu Decoy einfaldlega að liggja í kerfisbakkanum.

Leikir þar sem Discord-færslan hefur engar keyrsluskrár ennþá eru sjálfgefið faldir (ekki er hægt að greina þá). Kveiktu á *Sýna leiki án exe* til að sjá þá; listinn er uppfærður daglega, svo þeir verða tiltækir um leið og Discord bætir við ferli.

### Skipanalína

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Ræsir decoy samstundis, til dæmis `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Byggja úr kóða

Forkröfur: [Node.js](https://nodejs.org) 20+, stöðugt [Rust](https://rustup.rs)-verkfærasett (MSVC mark) með Visual Studio C++ byggingartólum, og WebView2-keyrsluumhverfið.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # keyra í þróunarham með heitri endurhleðslu (hot reload)
npm run tauri build    # búa til uppsetningarforritið í src-tauri/target/release/bundle/nsis
```

Gagnlegar prófanir:

```bash
npm run check-locales  # sannprófa allar þýðingarskrár gagnvart ru.json
npx tsc --noEmit       # gerðaprófa (type-check) framendann
cargo check --manifest-path src-tauri/Cargo.toml
```

Athugasemdir: decoy exe er þýtt af `src-tauri/build.rs` með venjulegu `rustc` úr `src-tauri/stub/stub.rs` og síðan fellt inn í forritið. Þegar framendinn keyrir í venjulegum vafra (`npm run dev`) er lítið gervi-bakendi (`src/mock.ts`) notað, sem er hentugt til að vinna í notendaviðmótinu.

## Þýðingar

Viðmótsstrengirnir eru staðsettir í [`src/locales`](../../src/locales), ein JSON-skrá fyrir hvert tungumál (`en.json`, `ru.json`, ...). Að bæta við tungumáli þýðir að bæta við skrá; engar kóðabreytingar. Sjá [docs/TRANSLATING.md](../TRANSLATING.md) fyrir skráarsnið, tilbúna skipun fyrir vélþýðingu og sannprófunarskriftu. Þýðingar á þessari README-skrá fara í `docs/i18n/README.<code>.md`.

```

  components/           Safn, upplýsingaspjald, stillingar, ...

```

## Persónuvernd

- Decoy notar aðeins netið til að sækja opinberan greiningarlista Discord (við fyrstu ræsingu, síðan að hámarki einu sinni á dag eða þegar þú ýtir á að uppfæra) og, til birtingar, leikjatákn og myndir af opinberu efnisveitukerfi (CDN) Discord.
- Það les ekki, geymir né sendir Discord-tákn þitt eða nokkur reikningsgögn, og það hefur ekki samskipti við Discord-forritið.
- Stillingar (eftirlæti, tungumál, tímalengdir) eru vistaðar staðbundið í WebView-geymslu forritsins; skyndiminni leikjalistans og tímabundnar decoy-skrár eru í `%LOCALAPPDATA%\app.decoy.desktop`.
- Engin greiningartölfræði, engar hrunskýrslur, engir reikningar.

## Þekktar takmarkanir

- Discord getur breytt því hvernig greining virkar hvenær sem er. Ef decoy hættir að greinast skaltu opna mál (issue).
- Sumar athafnir krefjast meira en aðeins ferlis í gangi (til dæmis að vera inni í ákveðinni upplifun á leikjavettvangi). Decoy hermir aðeins eftir ferlinu.
- Ekki er hægt að greina færslur án keyrsluskráa í lista Discord.
- Öryggishugbúnaður flaggar stundum litlum óundirrituðum keyrsluskrám sem sitja óvirkar í minni. Decoy er opinn hugbúnaður og byggður úr `src-tauri/stub/stub.rs`; þú getur þýtt hann sjálfur.

## Framlög

Villutilkynningar, hugmyndir og þýðingar eru vel þegnar. Vinsamlegast lestu [CONTRIBUTING.md](../../CONTRIBUTING.md) fyrst.

## Fyrirvari

Decoy er veitt „eins og það kemur fyrir“ í persónulegum, fræðslutilgangi og prófunartilgangi. Að herma eftir leik í gangi getur brotið gegn þjónustuskilmálum Discord eða útgefanda leiksins, og getur leitt til aðgerða gegn reikningi þínum. Þú berð einn ábyrgð á því hvernig þú notar það. „Discord“ og öll leikjaheiti og vörumerki eru eign viðkomandi eigenda og eru hér aðeins notuð til að auðkenna hugbúnaðinn sem vísað er til.
