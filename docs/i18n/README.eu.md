# Decoy

**Discord-ek joko bat martxan dagoela pentsarazten duten ordezko prozesu ñimiñoak.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-ren liburutegia azken jokoekin eta irudiekin" />

</div>

Decoy-k leiho bat duen ordezko prozesu kaltegabe bat mantentzen du martxan joko baten exekutagarriaren izenarekin, Discord-en jokoak detektatzeko sistemak joko horretara jolasten ari zarela jakinaraz dezan. Ez duzu benetako jokoa instalatu edo abiarazi beharrik inoiz, beraz, ezer handirik ez da zure diskoan geratuko.

Discord-ek **detekta dezakeen joko bakoitza** ezagutzen du (25.000 sarrera inguru), Discord-en detekzio-zerrenda publikoa irakurtzen duelako eta bere kabuz eguneratuta mantentzen duelako.

> [!WARNING]
> Martxan dagoen joko bat simulatzea Discord-en Zerbitzu Baldintzen aurkakoa izan daiteke eta Decoy **zure ardurapean** erabiltzen duzu.
> Proiektu hau ez dago Discord Inc.-ekin lotuta, babestuta edo afiliatuta. Ikusi [Erantzukizunaren muga](#erantzukizunaren-muga).

## Ezaugarriak

- **Discord-ek detekta dezakeen guztia.** Jokoen zerrenda Discord-en detekzio-zerbitzu publikotik deskargatzen da, lokalean gordetzen da cachean eta egunero berritzen da. Joko berriak eta gehitutako exekutagarri berriak beren kabuz agertzen dira.
- **Mugitzen jarraitzen duen bilaketa.** Jokoaren izenaren edo exekutagarriaren araberako berehalako bilaketa milaka jokoren artean, sareta edo zerrenda trinkoaren ikuspegia, gogokoak eta «Azkenak» errenkada.
- **Klik bakar bat.** Aukeratu joko bat, hautatu exekutagarria (batzuk badaude), aukeratu zenbat denboraz mantendu eta sakatu hasi. Atzerako kontaketa-eraztun batek eta jakinarazpen batek abisatuko dizute denbora amaitzen denean.
- **Ez du arrastorik uzten.** Ordezko bat (decoy) martxan dagoen bitartean bakarrik existitzen da: exe ñimiñoa hastean sortzen da eta gelditzean ezabatzen da. Dena gelditzen da irtetean, eta kraskatze baten hondarrak hurrengo abiaraztean garbitzen dira.
- **Isila.** Sistemaren erretiluan bizi da, ez dago leihorik edo ataza-barrako botoirik decoy-entzat beraientzat.
- **Itzulpen irekiak.** Interfazea JSON fitxategi arrunten bidez kudeatzen da, beraz, hizkuntza bat gehitzea fitxategi bakar bat gehitzea da. Ingelesa eta errusiera sartuta daude.
- **Pribatua.** Konturik gabe, Discord-en tokenik gabe, telemetriarik gabe. Ikusi [Pribatutasuna](#pribatutasuna).

## Nola funtzionatzen duen

1. Discord-ek joko batera jolasten ari zarela erabakitzen du zure PCan martxan dauden prozesuak aztertuz eta haien exekutagarrien izenak zerrenda publiko batekin konparatuz (`/api/v9/applications/detectable`).
2. Decoy-k zerrenda hori deskargatzen du eta, aukeratzen duzun jokoarentzat, ordezko programa ñimiño bat (120 KB ingurukoa, Rust-en idatzia eta Decoy-n txertatua) aldi baterako karpeta batera kopiatzen du zerrendako exekutagarriaren izena erabiliz, adibidez `.../cod26-cod.exe`.
3. Ordezkoak ez du ezer egiten goiko mailako leiho baten jabe izatea izan ezik, pantailatik oso urrun kokatuta sekula ikus ez dezazun. Discord-ek leiho baten jabe den prozesu bat bakarrik aitortzen du; horregatik, leihorik gabeko prozesu bat erabat baztertzen da.
4. Gutxi gorabehera 15 segundotan, Discord-ek jokoa erakusten du zure uneko jarduera gisa.
5. Tenporizadorea amaitzen denean edo gelditzeko botoia sakatzen duzunean, Decoy-k prozesua amaitu eta fitxategia ezabatzen du. Windows-eko «job object» batek bermatzen du decoy-ak Decoy-rekin batera amaitzen direla, kraskatzen bada ere.

## Instalazioa

Aukeratu bat [Argitalpenak](../../../../releases) orritik:

| Deskarga | Norentzat |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalatzailea.** Erabiltzaile bakoitzeko, ez da administratzaile-baimenik behar, Hasiera menuan sarrera bat eta desinstalatzaile bat gehitzen ditu. |
| `Decoy_x.y.z_x64-portable.zip` | **Eramangarria.** Deskonprimitu edozein lekutan eta exekutatu `decoy.exe`. Datu guztiak bere ondoan dagoen `data` karpetan geratzen dira, ez da ezer idazten zure erabiltzaile-profilean. Ezabatu karpeta hura kentzeko. |

Egiaztatu deskarga bat `SHA256SUMS.txt` erabiliz (`Get-FileHash <fitxategia>` PowerShell-en).

Windows SmartScreen-ek abisu bat eman dezake aitortu gabeko editore bati buruz, konpilazioak ez daudelako digitalki sinatuta; aukeratu *Informazio gehiago → Exekutatu hala ere* konpilazioan fidatzen bazara.

Baldintzak: Windows 10 edo 11 (64 bitekoa) WebView2 exekuzio-ingurunearekin (lehendik sartuta dago Windows 11n eta Windows 10eko azken eguneratzeetan).

## Erabilera

1. Ireki **Liburutegia** eta bilatu joko bat, edo sakatu `Ctrl` + `K` edonondik.
2. Egin klik joko batean. Eskuineko panelean, aukeratu prozesua eta zenbat minutuz mantendu (Discord-eko jarduerek 15 eskatu ohi dituzte).
3. Sakatu **Hasi decoy**. Discord-ek jokoa erakutsiko du segundo batzuk igaro ondoren.
4. Ikusi **Martxan** atalean, gelditu bat edo guztiak edozein unetan, edo utzi Decoy sistemaren erretiluan.

Discord-eko sarreran oraindik exekutagarririk ez duten jokoak ezkutatuta daude lehenespenez (ezin dira detektatu). Aktibatu *Erakutsi exe gabeko jokoak* horiek ikusteko; zerrenda egunero berritzen da, beraz, eskuragarri egongo dira Discord-ek prozesu bat gehitu bezain laster.

### Komando-lerroa

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy bat berehala abiarazten du, adibidez `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Iturburutik konpilatzea

Aurrebaldintzak: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) tresna-kate egonkorra (MSVC helburua) Visual Studio C++ konpilazio-tresnekin, eta WebView2 exekuzio-ingurunea.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Egiaztapen baliagarriak:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Oharrak: decoy-aren exe-a `src-tauri/build.rs` bidez konpilatzen da `rustc` arruntarekin `src-tauri/stub/stub.rs` fitxategitik eta gero aplikazioan txertatzen da. Frontend-a nabigatzaile arrunt batean exekutatzen denean (`npm run dev`), backend simulatu txiki bat (`src/mock.ts`) erabiltzen da, interfazean lan egiteko oso erabilgarria dena.

## Itzulpenak

Interfazearen testuak [`src/locales`](../../src/locales) direktorioan daude, hizkuntza bakoitzeko JSON fitxategi bat (`en.json`, `ru.json`, ...). Hizkuntza bat gehitzeak fitxategi bat gehitzea dakar; kode-aldaketarik gabe. Ikusi [docs/TRANSLATING.md](../TRANSLATING.md) fitxategiaren formatua, itzulpen automatikorako gonbita prest eta balioztatze-scripta ezagutzeko. README honen itzulpenak `docs/i18n/README.<code>.md` helbidera doaz.

## Proiektuaren egitura

```
src/                    React + TypeScript frontend-a
  components/           Liburutegia, xehetasun-panela, ezarpenak, ...
  locales/              itzulpen-fitxategiak (JSON bat hizkuntza bakoitzeko)
  i18n-core.ts          hizkuntza kargatzea eta bilatzea
  store.ts              aplikazioaren egoera (zustand)
src-tauri/              Rust backend-a (Tauri 2)
  src/lib.rs            jokoen datu-basea, decoy prozesuak, erretilua
  stub/stub.rs          txertatzen den ordezko programa
scripts/                laguntza-scriptak (lokalen balioztatzea)
docs/                   itzulpen-gida, pantaila-argazkiak
```

## Pribatutasuna

- Decoy-k sarea soilik erabiltzen du Discord-en detekzio-zerrenda publikoa deskargatzeko (lehenengo abiaraztean, eta gero gehienez egunean behin edo berritzeko botoia sakatzean) eta, bistaratzeko, jokoen ikonoak eta irudiak Discord-en CDN publikotik eskuratzeko.
- Ez du zure Discord tokenik edo kontuko daturik irakurtzen, gordetzen edo bidaltzen, eta ez da Discord bezeroarekin komunikatzen.
- Ezarpenak (gogokoak, hizkuntza, iraupenak) lokalean gordetzen dira aplikazioaren WebView biltegian; jokoen zerrendaren cachea eta aldi baterako decoy fitxategiak `%LOCALAPPDATA%\app.decoy.desktop` helbidean daude.
- Analitikarik gabe, kraskatze-txostenik gabe, konturik gabe.

## Muga ezagunak

- Discord-ek detekzioak nola funtzionatzen duen alda dezake edozein unetan. Decoy bat aitortzeari uzten bazaio, ireki arazo bat (issue).
- Zenbait jarduerak martxan dagoen prozesu bat baino gehiago behar dute (adibidez, joko-plataforma bateko esperientzia jakin baten barruan egotea). Decoy-k prozesua soilik imitatzen du.
- Discord-en zerrendan exekutagarririk ez duten sarrerak ezin dira detektatu.
- Segurtasun-softwareak batzuetan memorian inaktibo geratzen diren sinatu gabeko exekutagarri txikiak markatzen ditu. Decoy-a iturburu irekikoa da eta `src-tauri/stub/stub.rs` fitxategitik eraikita dago; zuk zeuk konpila dezakezu.

Akats-txostenak, ideiak eta itzulpenak ongi etorriak dira. Mesedez, irakurri [CONTRIBUTING.md](../../CONTRIBUTING.md) lehenik.

## Erantzukizunaren muga

Decoy "dagoen bezala" ematen da erabilera pertsonal, hezigarri eta probetarako. Martxan dagoen joko bat imitatzeak Discord-en edo jokoaren argitaratzailearen Zerbitzu Baldintzak urratu ditzake, eta zure kontuaren aurkako neurriak ekar ditzake. Zeu zara hura nola erabiltzen duzunaren erantzule bakarra. "Discord" eta jokoen izen eta logotipo guztiak dagozkien jabeen marka erregistratuak dira eta hemen aipatzen duten softwarea identifikatzeko soilik erabiltzen dira.
