# Decoy

**Ndondomeko zazing'ono zoyimilira zomwe zimachititsa Discord kuganiza kuti masewera akuyenda.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Laibulale ya Decoy yokhala ndi masewera aposachedwa ndi zojambulajambula" />

</div>

Decoy imasunga ndondomeko yoyimilira yopanda vuto yokhala ndi zenera ikuyenda pansi pa dzina la exe la masewera, kotero kuti kuzindikira masewera kwa Discord kumanena kuti mukusewera masewerawa. Simukufunika kuyika kapena kuyambitsa masewera enieni, motero palibe chachikulu chomwe chimakhala pa diski yanu.

Imadziwa za **masewera aliwonse omwe Discord ingazindikire** (pafupifupi zolowa 25,000) chifukwa imawerenga mndandanda wodziwika wapoyera wa Discord ndikuusunga kukhala watsopano yokha.

> [!WARNING]
> Kunamizira masewera omwe akuyenda kungakhale kusemphana ndi Migwirizano ya Ntchito ya Discord ndipo mumagwiritsa ntchito Decoy **mwakufuna kwanu**.
> Ntchitoyi siyogwirizana ndi, kuvomerezedwa ndi kapena kulumikizidwa ndi Discord Inc. Onani [Chodzikanira](#chodzikanira).

## Mbali Zake

- **Chilichonse chomwe Discord ingazindikire.** Mndandanda wa masewera umatsitsidwa kuchokera pa malo opezeka anthu onse a Discord, kusungidwa pa chipangizocho ndi kutsitsimutsidwa tsiku lililonse. Masewera atsopano ndi mafayilo a exe omwe angowonjezeredwa kumene amawonekera okha.
- **Kusaka komwe kumagwirizana ndi liwiro.** Kusaka pompopompo ndi dzina la masewera kapena exe m'masauzande a masewera, mawonekedwe a matailosi kapena mndandanda wocheperako, zomwe mumakonda komanso mzere wa "Zaposachedwa".
- **Kudina kamodzi.** Sankhani masewera, sankhani exe (ngati alipo angapo), sankhani nthawi yoti muisunge ndikudina yambitsani. Mphete yowerengera nthawi komanso chidziwitso zimakuuzani nthawi ikakwana.
- **Sisiya kalikonse m'mbuyo.** Decoy imakhalapo pokhapokha ikuyenda: fayilo yaying'ono ya exe imapangidwa poyambira ndikufufutidwa poimitsa. Chilichonse chimaimitsidwa mukatuluka, ndipo zotsalira zakulephera kwa pulogalamu zimasesedwa pakuyambitsa kwina.
- **Bata.** Imakhala mu thireyi ya makina, palibe mawindo kapena mabatani pa taskbar a ma decoy omwe.
- **Mamasuliridwe otseguka.** Mawonekedwe amayendetsedwa ndi mafayilo a JSON osavuta, chifukwa chake kuwonjezera chilankhulo ndi fayilo imodzi yokha. Chingerezi ndi Chirasha zaphatikizidwa.
- **Zinsinsi.** Palibe akaunti, palibe tokeni ya Discord, palibe telemetry. Onani [Zinsinsi](#zinsinsi).

## Momwe zimagwirira ntchito

1. Discord imaganiza kuti mukusewera masewera poyang'ana ndondomeko zomwe zikuyenda pa PC yanu ndikuyerekeza mayina awo a exe ndi mndandanda wapoyera (`/api/v9/applications/detectable`).
2. Decoy imatsitsa mndandandawu ndipo, pamasewera omwe mwasankha, imakopera pulogalamu yaying'ono yoyimilira (pafupifupi 120 KB, yolembedwa mu Rust ndikuyikidwa mkati mwa Decoy) kupita ku foda yakanthawi pogwiritsa ntchito dzina la exe lochokera pamndandanda, mwachitsanzo `.../cod26-cod.exe`.
3. Pulogalamu yoyimilira siichita chilichonse kupatula kukhala ndi zenera limodzi lapamwamba, loyimitsidwa kutali ndi chophimba kuti musalione konse. Discord imazindikira kokha ndondomeko yomwe ili ndi zenera, ndichifukwa chake ndondomeko yopanda zenera imanyalanyazidwa.
4. M'kati mwa pafupifupi masekondi 15 Discord imawonetsa masewerawa ngati zochitika zanu zamakono.
5. Nthawi ikatha kapena mukadina imitsani, Decoy imathetsa ndondomekoyi ndikuchotsa fayiloyo. Chinthu cha ntchito cha Windows (job object) chimawonetsetsa kuti ma decoy amafera limodzi ndi Decoy, ngakhale italephera kugwira ntchito.

## Kuyika

Sankhani imodzi kuchokera patsamba la [Releases](../../../../releases):

| Kutsitsa | Za |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Choyikira.** Cha aliyense wogwiritsa ntchito, palibe maufulu a woyang'anira (administrator) omwe akufunika, chimawonjezera zolowa pa menyu ya Start ndi chochotsa pulogalamu. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Masulani zip kulikonse ndikuyendetsa `decoy.exe`. Deta yonse imatsala mu foda ya `data` pafupi nayo, palibe chomwe chimalembedwa ku mbiri yanu ya wogwiritsa ntchito. Chotsani fodacho kuti muchotse. |

Tsimikizirani kutsitsa ndi `SHA256SUMS.txt` (`Get-FileHash <file>` mu PowerShell).

Windows SmartScreen ingachenjeze za wofalitsa wosadziwika chifukwa zopangidwazo sizinasainidwe ndi zizindikiro za digito; sankhani *Zambiri zowonjezera → Yendetsani mulimonse* ngati mukukhulupirira pulogalamuyo.

Zofunika: Windows 10 kapena 11 (64-bit) yokhala ndi WebView2 runtime (yaphatikizidwa kale mu Windows 11 ndi zosintha zaposachedwa za Windows 10).

## Kagwiritsidwe Ntchito

1. Tsegulani **Laibulale** ndikusaka masewera, kapena dinani `Ctrl` + `K` kuchokera kulikonse.
2. Dinani pamasewera. Pagulu lakumanja sankhani ndondomeko ndi mphindi zingati zoti muzisunge (zochitika za Discord nthawi zambiri zimafuna 15).
3. Dinani **Yambitsani decoy**. Discord idzawonetsa masewerawa pakadutsa masekondi ochepa.
4. Yang'anirani pansi pa **Zikuyenda**, imitsani imodzi kapena zonse nthawi iliyonse, kapena ingosiyani Decoy mu thireyi.

Masewera omwe zolowa zawo mu Discord zilibe ma exe obisika mwachisawawa (sangazindikiridwe). Yatsani *Onetsani masewera opanda exe* kuti muwawone; mndandanda umatsitsimutsidwa tsiku lililonse, motero amayamba kupezeka Discord ikangowonjezera ndondomeko.

### Laini ya lamulo

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Imayambitsa decoy nthawi yomweyo, mwachitsanzo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kupanga kuchokera ku magwero

Zoyenera kukhalapo: [Node.js](https://nodejs.org) 20+, zida zokhazikika za [Rust](https://rustup.rs) (MSVC target) pamodzi ndi zida zopangira za Visual Studio C++, ndi WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # yendetsani m'mawonekedwe opanga ndi kutsegulanso pompopompo
npm run tauri build    # pangani choyikira mu src-tauri/target/release/bundle/nsis
```

Macheke othandiza:

```bash
npm run check-locales  # tsimikizirani fayilo iliyonse yomasulira motsutsana ndi ru.json
npx tsc --noEmit       # onani mitundu ya mafayilo a frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Zolemba: exe ya decoy imapangidwa ndi `src-tauri/build.rs` pogwiritsa ntchito `rustc` wamba kuchokera ku `src-tauri/stub/stub.rs` ndikuyikidwa mkati mwa pulogalamuyo. Frontend ikamayenda mu msakatuli wamba (`npm run dev`) backend yaying'ono yongoyerekeza (`src/mock.ts`) imagwiritsidwa ntchito, yomwe ndi yabwino pakugwira ntchito pa UI.

## Mamasuliridwe

Zolemba za UI zimakhala mu [`src/locales`](../../src/locales), fayilo imodzi ya JSON pachilankhulo chilichonse (`en.json`, `ru.json`, ...). Kuwonjezera chilankhulo kumatanthauza kuwonjezera fayilo; palibe kusintha kwa ma code. Onani [docs/TRANSLATING.md](../TRANSLATING.md) pamawonekedwe a fayilo, chiwongolero chokonzekera kugwiritsidwa ntchito pamasuliridwe a makina ndi script yotsimikizira. Mamasuliridwe a README iyi amapita ku `docs/i18n/README.<code>.md`.

## Kapangidwe ka pulojekiti

```
src/                    React + TypeScript frontend
  components/           Laibulale, gulu la tsatanetsatane, zokonda, ...
  locales/              mafayilo omasulira (JSON imodzi pachilankhulo chilichonse)
  i18n-core.ts          kukopera chilankhulo ndi kufufuza
  store.ts              mkhalidwe wa pulogalamu (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            nkhokwe ya masewera, ndondomeko za decoy, thireyi
  stub/stub.rs          pulogalamu yoyimilira yomwe imayikidwa mkati
scripts/                ma script othandizira (kutsimikizira zilankhulo)
docs/                   kalozera wamasuliridwe, zithunzi za screen
```

## Zinsinsi

- Decoy imagwiritsa ntchito intaneti pokhapokha kutsitsa mndandanda wodziwika wa Discord (pakuyamba koyamba, kenako osachepera kamodzi patsiku kapena mukadina kutsitsimutsa) ndipo, powonetsa, zithunzi za masewera ndi zojambulajambula kuchokera ku CDN ya Discord ya anthu onse.
- Siiwerenga, kusunga kapena kutumiza tokeni yanu ya Discord kapena deta iliyonse ya akaunti, ndipo siilankhula ndi kasitomala wa Discord.
- Zokonda (zomwe mumakonda, chilankhulo, nthawi) zimasungidwa kwanuko mu nkhokwe ya WebView ya pulogalamuyi; nkhokwe yosungirako mndandanda wamasewera ndi mafayilo akanthawi a decoy amakhala mu `%LOCALAPPDATA%\app.decoy.desktop`.
- Palibe ma analytics, palibe malipoti a zolakwika, palibe maakaunti.

## Zolephera zodziwika

- Discord ikhoza kusintha momwe kuzindikira kumagwirira ntchito nthawi iliyonse. Ngati decoy isiyidwa kuzindikirika, chonde tsegulani vuto (issue).
- Zochitika zina zimafuna zambiri kuposa ndondomeko yomwe ikuyenda (mwachitsanzo kukhala mkati mwazochitika zinazake papulatifomu yamasewera). Decoy imangotsanzira ndondomekoyi.
- Zolowa zopanda ma exe pamndandanda wa Discord sizingathe kuzindikirika.
- Mapulogalamu achitetezo nthawi zina amakayikira ma exe ang'onoang'ono osasainidwa omwe amangokhala m'chikumbukiro popanda kuchita chilichonse. Decoy ndi yotseguka ndipo yapangidwa kuchokera ku `src-tauri/stub/stub.rs`; mutha kuyipanga nokha.

## Kuthandizira

Malipoti a zolakwika, malingaliro ndi mamasuliridwe ndiolandiridwa. Chonde werengani [CONTRIBUTING.md](../../CONTRIBUTING.md) kaye.

## Chodzikanira

Decoy imaperekedwa "monga momwe ilili" pazifukwa zaumwini, maphunziro ndi zoyeserera. Kutengera masewera omwe akuyenda kungaphwanye Migwirizano ya Ntchito ya Discord kapena ya wofalitsa masewerawo, ndipo kungapangitse kuti akaunti yanu ilandiridwe chilango. Inu nokha ndinu amene muli ndi udindo pa momwe mumaigwiritsira ntchito. "Discord" ndi mayina onse a masewera ndi ma logo ndi zizindikiro za eni ake ndipo zikugwiritsidwa ntchito pano pokhapokha kuzindikiritsa pulogalamu yomwe ikutanthauzidwa.
