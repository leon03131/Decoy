# Decoy

**सानो स्ट्यान्ड-इन प्रोसेस जसले Discord लाई खेल चलिरहेको महसुस गराउँछ।**

![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="भर्खरका खेलहरू र आर्टवर्कसहित Decoy लाइब्रेरी" />

Decoy ले कुनै खेलको executable नाम अन्तर्गत विन्डो भएको हानिरहित प्लेसहोल्डर प्रोसेस चालू राख्छ, जसले गर्दा Discord को खेल पत्ता लगाउने प्रणालीले तपाईंलाई त्यो खेल खेलिरहेको देखाउँछ। तपाईंले वास्तविक खेल कहिल्यै इन्स्टल वा सुरु गर्नुपर्दैन, त्यसैले तपाईंको डिस्कमा कुनै ठूलो फाइल बस्दैन।

यसलाई **Discord ले पत्ता लगाउन सक्ने प्रत्येक खेल** थाहा हुन्छ (लगभग २५,००० प्रविष्टिहरू), किनकि यसले Discord को आफ्नै सार्वजनिक पत्ता लगाउने सूची पढ्छ र यसलाई आफैं अद्यावधिक राख्छ।

> [!WARNING]
> चलिरहेको खेलको नक्कली देखावा गर्नु Discord को सेवाका सर्तहरू (Terms of Service) विपरीत हुन सक्छ र तपाईंले Decoy **आफ्नै जोखिममा** प्रयोग गर्नुहुन्छ।
> यो परियोजना Discord Inc. सँग सम्बद्ध, समर्थित वा जोडिएको छैन। [अस्वीकरण](#अस्वीकरण) हेर्नुहोस्।

## विशेषताहरू

- **Discord ले पत्ता लगाउन सक्ने सबै कुरा।** खेल सूची Discord को सार्वजनिक डिटेक्सन एन्डपोइन्टबाट डाउनलोड गरिन्छ, स्थानीय रूपमा क्यास गरिन्छ र दैनिक ताजा गरिन्छ। नयाँ खेलहरू र भर्खरै थपिएका executables आफैं देखा पर्छन्।
- **छिटो र प्रभावकारी खोज।** हजारौं खेलहरूमा खेलको नाम वा executable द्वारा तुरुन्त खोज, ग्रिड वा कम्प्याक्ट सूची दृश्य, मनपर्नेहरू र "भर्खरका" पंक्ति।
- **एक क्लिक।** कुनै खेल छान्नुहोस्, executable छान्नुहोस् (यदि धेरै छन् भने), यसलाई कति समयसम्म चलाइराख्ने छान्नुहोस् र स्टार्ट थिच्नुहोस्। काउन्टडाउन घडी र सूचनाले तपाईंलाई समय समाप्त भएको जानकारी दिनेछन्।
- **पछाडि केही बाँकी छोड्दैन।** एउटा decoy यो चलिरहँदा मात्र रहन्छ: सानो exe सुरु गर्दा बनाइन्छ र रोक्दा मेटाइन्छ। तपाईंले बन्द गर्दा सबै कुरा रोकिन्छ, र कुनै क्र्यास भएमा अर्को पटक सुरु गर्दा बाँकी अवशेषहरू सफा गरिन्छ।
- **शान्त।** सिस्टम ट्रेमा बस्छ, decoys का लागि आफ्नै कुनै विन्डो वा टास्कबार बटनहरू हुँदैनन्।
- **खुला अनुवादहरू।** इन्टरफेस साधारण JSON फाइलहरूद्वारा संचालित छ, त्यसैले भाषा थप्नु भनेको एउटा फाइल थप्नु मात्र हो। अंग्रेजी र रूसी समावेश छन्।
- **निजी।** कुनै खाता छैन, कुनै Discord टोकन छैन, कुनै टेलिमेट्री छैन। [गोपनीयता](#गोपनीयता) हेर्नुहोस्।

## यो कसरी काम गर्छ

1. Discord ले तपाईंको कम्प्युटरमा चलिरहेका प्रोसेसहरू हेरेर र तिनीहरूका executable नामहरू सार्वजनिक सूची (`/api/v9/applications/detectable`) सँग तुलना गरेर तपाईंले खेल खेलिरहनुभएको छ भनी निर्णय गर्छ।
2. Decoy ले त्यो सूची डाउनलोड गर्छ र तपाईंले छानेको खेलका लागि, सूचीको executable नाम प्रयोग गरी एउटा सानो स्ट्यान्ड-इन कार्यक्रम (लगभग १२० KB, Rust मा लेखिएको र Decoy भित्र इम्बेड गरिएको) अस्थायी फोल्डरमा प्रतिलिपि गर्छ, उदाहरणका लागि `.../cod26-cod.exe`।
3. स्ट्यान्ड-इनले एउटा शीर्ष-स्तरीय (top-level) विन्डो राख्ने बाहेक केही गर्दैन, जुन स्क्रिनभन्दा धेरै टाढा राखिएको हुन्छ ताकि तपाईंले यसलाई कहिल्यै नदेख्नुहोस्। Discord ले विन्डो भएको प्रोसेसलाई मात्र पहिचान गर्छ, त्यसैले पूरै विन्डोरहित प्रोसेसलाई बेवास्ता गरिन्छ।
4. लगभग १५ सेकेन्डभित्र Discord ले उक्त खेललाई तपाईंको हालको गतिविधिको रूपमा देखाउँछ।
5. टाइमर समाप्त भएपछि वा तपाईंले स्टप थिचेपछि, Decoy ले प्रोसेस समाप्त गर्छ र फाइल मेटाउँछ। Windows job object ले Decoy क्र्यास भए पनि decoys Decoy सँगै समाप्त हुने कुरा सुनिश्चित गर्छ।

आवश्यकताहरू: WebView2 रनटाइम सहितको Windows 10 वा 11 (64-bit) (Windows 11 र हालका Windows 10 अपडेटहरूमा पहिले नै समावेश छ)।

## उपयोग

1. **लाइब्रेरी** खोल्नुहोस् र खेल खोज्नुहोस्, वा जहाँसुकैबाट पनि `Ctrl` + `K` थिच्नुहोस्।
2. कुनै खेलमा क्लिक गर्नुहोस्। दायाँपट्टिको प्यानलमा प्रोसेस र कति मिनेट राख्ने छान्नुहोस् (Discord गतिविधिहरूलाई सामान्यतया १५ मिनेट चाहिन्छ)।
3. **Decoy सुरु गर्नुहोस्** थिच्नुहोस्। Discord ले केही सेकेन्डपछि खेल देखाउनेछ।
4. यसलाई **चलिरहेको** अन्तर्गत हेर्नुहोस्, जुनसुकै बेला एउटा वा सबैलाई रोक्नुहोस्, वा Decoy लाई ट्रेमा छाड्नुहोस्।

Discord प्रविष्टिमा हालसम्म कुनै executables नभएका खेलहरू पूर्वनिर्धारित रूपमा लुकाइएका हुन्छन् (तिनीहरू पत्ता लगाउन सकिँदैन)। तिनीहरूलाई हेर्न *exe नभएका खेलहरू देखाउनुहोस्* खोल्नुहोस्; सूची दैनिक रूपमा ताजा हुन्छ, त्यसैले Discord ले कुनै प्रोसेस थप्ने बित्तिकै तिनीहरू उपलब्ध हुन्छन्।

### कमान्ड लाइन

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

तुरुन्तै एउटा decoy सुरु गर्छ, उदाहरणका लागि `decoy.exe --launch "robloxplayerbeta.exe" 15`।

## स्रोतबाट बिल्ड गर्नुहोस्

पूर्वशर्तहरू: [Node.js](https://nodejs.org) 20+, Visual Studio C++ बिल्ड टूल्स सहितको स्थिर [Rust](https://rustup.rs) टूलचेन (MSVC लक्ष्य), र WebView2 रनटाइम।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

उपयोगी जाँचहरू:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

नोटहरू: decoy exe लाई `src-tauri/build.rs` द्वारा साधारण `rustc` मार्फत `src-tauri/stub/stub.rs` बाट कम्पाइल गरिन्छ र त्यसपछि एपमा इम्बेड गरिन्छ। जब फ्रन्टएन्ड सामान्य ब्राउजरमा चल्छ (`npm run dev`), एउटा सानो मक ब्याकएन्ड (`src/mock.ts`) प्रयोग गरिन्छ, जुन UI मा काम गर्न उपयोगी हुन्छ।

## अनुवादहरू

UI स्ट्रिङहरू [`src/locales`](../../src/locales) मा रहन्छन्, प्रति भाषा एउटा JSON फाइल (`en.json`, `ru.json`, ...)।
भाषा थप्नु भनेको फाइल थप्नु हो; कुनै कोड परिवर्तन गर्नु पर्दैन। फाइल ढाँचा, मेसिन अनुवादका लागि प्रयोग गर्न तयार प्रम्प्ट र प्रमाणीकरण स्क्रिप्टका लागि [docs/TRANSLATING.md](../TRANSLATING.md) हेर्नुहोस्। यस README का अनुवादहरू `docs/i18n/README.<code>.md` मा जान्छन्।

## परियोजना संरचना

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## गोपनीयता

- Decoy ले Discord को सार्वजनिक पत्ता लगाउने सूची डाउनलोड गर्न (पहिलो सुरुमा, त्यसपछि दैनिक बढीमा एक पटक वा तपाईंले रिफ्रेस थिच्दा) र प्रदर्शनका लागि Discord को सार्वजनिक CDN बाट खेलका आइकनहरू र आर्टवर्क डाउनलोड गर्न मात्र नेटवर्क प्रयोग गर्छ।
- यसले तपाईंको Discord टोकन वा कुनै खाता डेटा पढ्दैन, भण्डारण गर्दैन वा पठाउँदैन, र यसले Discord क्लाइन्टसँग कुरा गर्दैन।
- सेटिङहरू (मनपर्ने, भाषा, अवधिहरू) एपको WebView भण्डारणमा स्थानीय रूपमा भण्डारण गरिन्छ; खेल सूची क्यास र अस्थायी decoy फाइलहरू `%LOCALAPPDATA%\app.decoy.desktop` मा रहन्छन्।
- कुनै एनालिटिक्स छैन, कुनै क्र्यास रिपोर्टिङ छैन, कुनै खाता छैन।

## ज्ञात सीमाहरू

- Discord ले पत्ता लगाउने तरिका जुनसुकै बेला परिवर्तन गर्न सक्छ। यदि कुनै decoy पहिचान हुन छोड्यो भने, कृपया एउटा issue खोल्नुहोस्।
- केही गतिविधिहरूका लागि चलिरहेको प्रोसेसभन्दा बढी आवश्यक पर्दछ (उदाहरणका लागि कुनै खेल प्लेटफर्मको कुनै विशेष अनुभव भित्र हुनु)। Decoy ले प्रोसेसको मात्र अनुकरण गर्छ।
- Discord को सूचीमा executables नभएका प्रविष्टिहरू पत्ता लगाउन सकिँदैन।
- सुरक्षा सफ्टवेयरले कहिलेकाहीँ मेमोरीमा निष्क्रिय बस्ने साना अहस्ताक्षरित executables लाई फ्ल्याग गर्न सक्छ। Decoy खुला स्रोत हो र `src-tauri/stub/stub.rs` बाट निर्मित छ; तपाईं यसलाई आफैं कम्पाइल गर्न सक्नुहुन्छ।

## अस्वीकरण

Decoy व्यक्तिगत, शैक्षिक र परीक्षण उद्देश्यका लागि "जस्तो छ त्यस्तै" प्रदान गरिएको छ। चलिरहेको खेलको अनुकरण गर्नाले Discord वा खेल प्रकाशकको सेवाका सर्तहरू उल्लङ्घन हुन सक्छ, र तपाईंको खाता विरुद्ध कारबाही हुन सक्छ। तपाईंले यसलाई कसरी प्रयोग गर्नुहुन्छ भन्ने कुराको लागि तपाईं एक्लै जिम्मेवार हुनुहुन्छ। "Discord" र सबै खेल नाम तथा लोगोहरू तिनीहरूका सम्बन्धित मालिकहरूका ट्रेडमार्क हुन् र यहाँ तिनीहरूले उल्लेख गर्ने सफ्टवेयर पहिचान गर्न मात्र प्रयोग गरिएको छ।
