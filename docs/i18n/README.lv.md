# Decoy

**Nelieli viettura procesi, kas liek Discord uzskatīt, ka tiek spēlēta spēle.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy bibliotēka ar nesenajām spēlēm un vākiem" />

</div>

Decoy uztur nekaitīgu procesa vietturi ar logu zem spēles izpildāmā faila nosaukuma, lai Discord spēļu noteikšanas sistēma rādītu, ka spēlējat šo spēli. Jums nekad nav jāinstalē vai jāpalaiž pati spēle, tādēļ diskā netiek aizņemta vieta.

Lietotne zina par **katru spēli, ko Discord spēj atpazīt** (aptuveni 25 000 ierakstu), jo tā nolasa paša Discord publisko noteikšanas sarakstu un patstāvīgi uztur to aktuālu.

> [!WARNING]
> Spēles darbības imitēšana var pārkāpt Discord pakalpojumu sniegšanas noteikumus (Terms of Service), un jūs izmantojat Decoy **uz savu risku**.
> Šis projekts nav saistīts ar Discord Inc., kā arī Discord Inc. to nav apstiprinājis vai atbalstījis. Skatiet [Atruna](#atruna).

## Iespējas

- **Viss, ko Discord spēj atpazīt.** Spēļu saraksts tiek lejupielādēts no Discord publiskā noteikšanas galapunkta, kešots lokāli un atjaunināts katru dienu. Jaunas spēles un nesen pievienotie izpildāmie faili parādās paši.
- **Ātra meklēšana.** Tūlītēja meklēšana pēc spēles nosaukuma vai izpildāmā faila starp tūkstošiem spēļu, režģa vai kompakta saraksta skats, izlase un rinda “Nesenās”.
- **Viens klikšķis.** Izvēlieties spēli, izvēlieties izpildāmo failu (ja to ir vairāki), norādiet, cik ilgi to uzturēt, un nospiediet “Palaist Decoy”. Laika atskaites aplis un paziņojums informēs, kad laiks būs beidzies.
- **Neatstāj pēdas.** Vietturis pastāv tikai tik ilgi, kamēr darbojas: mazais exe fails tiek izveidots palaišanas brīdī un dzēsts pēc apturēšanas. Viss tiek apturēts, izejot no programmas, un avārijas gadījumā palikušie faili tiek notīrīti nākamajā palaišanas reizē.
- **Kluss darbs.** Dzīvo sistēmas teknē (tray), bez logiem vai uzdevumjoslas pogām pašiem vietturiem.
- **Atvērti tulkojumi.** Saskarnes darbību nodrošina vienkārši JSON faili, tādēļ jaunas valodas pievienošanai nepieciešams tikai viens fails. Angļu un krievu valoda jau ir iekļauta.
- **Privātums.** Nav konta, nav Discord pilnvaras (token), nav telemetrijas. Skatiet [Privātums](#privātums).

## Kā tas darbojas

1. Discord nosaka, ka spēlējat spēli, aplūkojot datorā palaistos procesus un salīdzinot to izpildāmo failu nosaukumus ar publisko sarakstu (`/api/v9/applications/detectable`).
2. Decoy lejupielādē šo sarakstu un jūsu izvēlētajai spēlei iekopē nelielu viettura programmu (aptuveni 120 KB, rakstīta Rust un iegulta Decoy) pagaidu mapē, izmantojot sarakstā norādīto izpildāmā faila nosaukumu, piemēram, `.../cod26-cod.exe`.
3. Šis vietturis nedara neko citu, kā vien uztur vienu augstākā līmeņa logu, kas novietots tālu ārpus ekrāna robežām, lai jūs to nekad neredzētu. Discord atpazīst tikai procesu, kuram pieder logs, tādēļ process bez loga tiek ignorēts.
4. Aptuveni 15 sekunžu laikā Discord parāda spēli kā jūsu pašreizējo aktivitāti.
5. Kad taimeris beidzas vai nospiežat apturēt, Decoy pabeidz procesu un izdzēš failu. Windows darba objekts (job object) nodrošina, ka vietturi beidz darbu kopā ar Decoy pat avārijas gadījumā.

## Instalēšana

Izvēlieties vienu no lapas [Releases](../../../../releases):

| Lejupielāde | Kam paredzēts |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalators.** Lietotāja līmeņa, administratora tiesības nav nepieciešamas, pievieno ierakstu izvēlnē Sākt un atinstalētāju. |
| `Decoy_x.y.z_x64-portable.zip` | **Pārnēsājama versija (Portable).** Atarhivējiet jebkur un palaidiet `decoy.exe`. Visi dati paliek blakus esošajā mapē `data`, nekas netiek rakstīts jūsu lietotāja profilā. Lai to noņemtu, vienkārši izdzēsiet mapi. |

Pārbaudiet lejupielādēto failu ar `SHA256SUMS.txt` (`Get-FileHash <fails>` programmā PowerShell).

Windows SmartScreen var parādīt brīdinājumu par neatpazītu izdevēju, jo laidieni nav parakstīti ar koda parakstīšanas sertifikātu; izvēlieties *Papildinformācija → Palaist vienalga*, ja uzticaties šim laidienam.

Prasības: Windows 10 vai 11 (64-bit) ar WebView2 izpildlaiku (jau iekļauts operētājsistēmā Windows 11 un jaunākajos Windows 10 atjauninājumos).

## Lietošana

1. Atveriet sadaļu **Bibliotēka** un meklējiet spēli, vai nospiediet `Ctrl` + `K` no jebkuras vietas.
2. Noklikšķiniet uz spēles. Labajā panelī izvēlieties procesu un to, cik minūtes to uzturēt (Discord aktivitātēm parasti nepieciešamas 15 minūtes).
3. Nospiediet **Palaist Decoy**. Pēc dažām sekundēm Discord parādīs spēli.
4. Pārraugiet to sadaļā **Palaistie**, apturiet vienu vai visus jebkurā laikā, vai vienkārši atstājiet Decoy sistēmas teknē.

Spēles, kuru Discord ierakstā vēl nav izpildāmo failu, pēc noklusējuma ir paslēptas (tās nevar noteikt). Ieslēdziet *Rādīt spēles bez exe*, lai tās redzētu; saraksts tiek atjaunināts katru dienu, tāpēc tās kļūs pieejamas, tiklīdz Discord pievienos procesu.

### Komandrinda

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Uzreiz palaiž vietturi, piemēram, `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Būvēšana no pirmkoda

Priekšnosacījumi: [Node.js](https://nodejs.org) 20+, stabila [Rust](https://rustup.rs) rīku kopa (MSVC mērķis) ar Visual Studio C++ būvēšanas rīkiem un WebView2 izpildlaiks.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # palaist izstrādes režīmā ar karsto pārlādi (hot reload)
npm run tauri build    # izveidot instalatoru mapē src-tauri/target/release/bundle/nsis
```

Noderīgas pārbaudes:

```bash
npm run check-locales  # pārbaudīt katru tulkojuma failu pret ru.json
npx tsc --noEmit       # pārbaudīt priekšgala tipus
cargo check --manifest-path src-tauri/Cargo.toml
```

Piezīmes: viettura exe failu kompilē `src-tauri/build.rs` ar vienkāršu `rustc` no faila `src-tauri/stub/stub.rs`, un pēc tam tas tiek iegults lietotnē. Kad priekšgals darbojas parastā pārlūkprogrammā (`npm run dev`), tiek izmantots neliels imitācijas aizmugursistēmas modulis (`src/mock.ts`), kas ir ērti, strādājot pie saskarnes.

## Tulkojumi

Saskarnes rindas atrodas mapē [`src/locales`](../../src/locales), pa vienam JSON failam katrai valodai (`en.json`, `ru.json`, ...). Valodas pievienošana nozīmē tikai faila pievienošanu bez izmaiņām kodā. Skatiet [docs/TRANSLATING.md](../TRANSLATING.md), lai uzzinātu par faila formātu, gatavu vaicājumu mašīntulkošanai un validācijas skriptu. Šī README faila tulkojumi atrodas mapē `docs/i18n/README.<code>.md`.

## Projekta struktūra

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privātums

- Decoy izmanto tīklu tikai tam, lai lejupielādētu Discord publisko noteikšanas sarakstu (pirmajā palaišanas reizē, pēc tam ne biežāk kā reizi dienā vai nospiežot atjaunināšanas pogu) un lai attēlotu spēļu ikonas un vākus no Discord publiskā CDN.
- Tas nenolasa, nesaglabā un nepārsūta jūsu Discord pilnvaru (token) vai jebkādus konta datus, kā arī nesazinās ar Discord klientu.
- Iestatījumi (izlase, valoda, ilgumi) tiek glabāti lokāli lietotnes WebView krātuvē; spēļu saraksta kešatmiņa un pagaidu vietturu faili atrodas `%LOCALAPPDATA%\app.decoy.desktop`.
- Nav analītikas, nav avāriju ziņojumu, nav lietotāju kontu.

## Zināmie ierobežojumi

- Discord var mainīt noteikšanas mehānismu jebkurā laikā. Ja kāds vietturis vairs netiek atpazīts, lūdzu, atveriet pieteikumu (issue).
- Dažām aktivitātēm ir nepieciešams vairāk nekā tikai palaists process (piemēram, atrašanās noteiktā spēļu platformas pieredzē). Decoy imitē tikai procesu.
- Ierakstus bez izpildāmajiem failiem Discord sarakstā nevar atpazīt.
- Drošības programmatūra dažkārt reaģē uz maziem neparakstītiem izpildāmajiem failiem, kas bezdarbībā atrodas atmiņā. Vietturis ir atvērtā koda un tiek būvēts no `src-tauri/stub/stub.rs`; jūs varat to kompilēt paši.

## Kā iesaistīties

Kļūdu ziņojumi, idejas un tulkojumi ir laipni gaidīti. Lūdzu, vispirms izlasiet [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Atruna

Decoy tiek nodrošināts "tāds, kāds tas ir" personīgiem, izglītojošiem un testēšanas mērķiem. Palaistas spēles imitēšana var pārkāpt Discord vai spēles izdevēja pakalpojumu sniegšanas noteikumus un var izraisīt sankcijas pret jūsu kontu. Jūs vienpersoniski uzņematies atbildību par tā lietošanu. "Discord" un visi spēļu nosaukumi un logotipi ir to attiecīgo īpašnieku preču zīmes un šeit tiek izmantoti tikai, lai identificētu programmatūru, uz kuru tie attiecas.
