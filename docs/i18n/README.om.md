# Decoy

**Adeemsota bakka-bu'oo xixiqqoo kanneen Discord akka waan taphni hojjechaa jiruutti amansiisan.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Kuusaa Decoy taphoota dhiyeenyaa fi fakkiiwwan faana" />

</div>

Decoy'n adeemsa bakka-bu'aa foddaa qabuufi miidhaa hin qabne maqaa faayilii exe taphichaa jalatti akka hojjetu taasisa, kanaanis sirni adda baafannaa taphaa Discord akka ati tapha sana taphachaa jirtu gabaasa. Tapha isa dhugaa fe'uu ykn jalqabsiisuun matumaa si hin barbaachisu, kanaafuu wanti ulfaataan diskiikee irra hin taa'u.

Waa'ee **tapha Discord adda baasuu danda'u hundaa** (tilmaamaan galmoota 25,000) beeka, sababiin isaas tarree adda baafannaa uummataa kan Discord ofii isaa dubbisaatii ofumaan haaromsa.

> [!WARNING]
> Tapha hojjechaa jiru sobsiisuun Seera Tajaajilaa Discord cabsuu danda'a, Decoy kan fayyadamtu **itti gaafatamummaa keetiini**.
> Pirojektiin kun Discord Inc. wajjin hidhata hin qabu, hin deeggaramne ykn walitti dhufeenya hin qabu. [Itti Gaafatamummaa Irraa Bilisa Ta'uu](#itti-gaafatamummaa-irraa-bilisa-tauu) ilaalaa.

## Amalaalee

- **Wanti Discord adda baasuu danda'u hundi.** Tarreen taphootaa endpoint adda baafannaa uummataa Discord irraa buufama, asuma keessatti kuufamee guyyaa guyyaan haaromsama. Taphoonni haaraafi faayiloonni exe haaraa dabalatan ofumaan mul'atu.
- **Barbaacha saffisaa.** Barbaacha battalaa maqaa taphaatiin ykn exe'n taphoota kumaatama keessaa, akka taayiliitti ykn tarree gabaabduun ilaaluu, filatamoofi sarara "Dhiyeenya kana".
- **Cuqqaasuu tokko.** Tapha filadhu, faayilii exe filadhu (yoo tokkoo ol ta'an), hanga yoomiitti akka turu murteessiitii jalqabi cuqqaasi. Geengoon lakkoofsa gadii fi beeksisni yeroon yemmuu xumuramu sitti himu.
- **Duubatti homaa hin dhiisu.** Decoy'n kan jiraatu yeroo inni hojjetu qofa: exe'n xinnoon yeroo jalqabamu uumama, yeroo dhaabbatus ni haqama. Yeroo baatu wanti hundi ni dhaabbata, hambaan sababa kuffaatiitiin dhufe yeroo itti aanutti yommuu banamu qulqulleeffama.
- **Cal-jedhaa.** Tireeyii sirnaa keessa jiraata, foddaan ykn bataniin taskbar decoywwaniif mataa isaaniitiif hin jiru.
- **Tafsiiroota banaa.** Agarsiiftuun faayiloota JSON salphaadhaan hoogganama, kanaafuu afaan dabalachuun faayilii tokko qofa. Afaan Ingiliffaafi Raashiyaa of keessaa qaba.
- **Dhuunfaa.** Herrega hin barbaadu, tookenii Discord hin jiru, daataa fageenyaa (telemetry) hin qabu. [Iccitummaa](#iccitummaa) ilaalaa.

## Akkaataa inni itti hojjetu

1. Discord'n adeemsota PC kee irratti hojjechaa jiran ilaaluun fi maqaa exe isaanii tarree uummataa (`/api/v9/applications/detectable`) wajjin wal bira qabuun akka ati tapha taphachaa jirtu murteessa.
2. Decoy'n tarree sana buusaatii, tapha ati filatteef, sagantaa bakka-bu'aa xinnoo (tilmaamaan 120 KB, Rust'n barreeffamee Decoy keessatti kan qabate) maqaa exe tarree sana keessa jiruun gara gola yerootti kooppii godha, fakkeenyaaf `.../cod26-cod.exe`.
3. Bakka-bu'aan kun foddaa sadarkaa olaanaa tokko qabaachuu malee homaa hin hojjetu, inis akka ati hin arginetti iskiriinii irraa fagaatee dhaabbata. Discord'n adeemsa foddaa qabu qofa beeka, sababiin adeemsi foddaa hin qabne itti dhiifamuufis kanuma.
4. Seekondii 15 keessatti Discord'n taphicha akka socho'a kee ammayyaatti agarsiisa.
5. Yeroon yemmuu dhumatu ykn yemmuu dhaabi cuqqaastu, Decoy'n adeemsicha xumuraatii faayilicha haqa. Wanti Windows job object decoywwan Decoy wajjin du'uu isaanii mirkaneessa, yoo inni kufeeyyuu.

## Fe'iinsa

Fuula [Releases](../../../../releases) irraa tokko filadhaa:

| Buufadhaa | Maaliif |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Fe'aa (Installer).** Fayyadamaa qofaaf, mirgi bulchaa (administrator) hin barbaachisu, filannoo Start menu fi kan fe'iinsa balleessu dabala. |
| `Decoy_x.y.z_x64-portable.zip` | **Sochoofamaa (Portable).** Bakka barbaaddetti baasiitii `decoy.exe` hojjechiisi. Daataan hundi gola `data` isa cinaa jiru keessatti hafa, piroofaayilii kee irratti homaa hin barreeffamu. Balleessuuf galmee sana haqi. |

Buufata `SHA256SUMS.txt` tiin mirkaneeffadhaa (PowerShell keessatti `Get-FileHash <file>`).

Windows SmartScreen dhiheessaa hin beekamne sababa ijaarsi mallattoo koodii hin qabneef akeekkachiisuu danda'a; yoo ijaarsicha amante *More info → Run anyway* filadhu.

Ulaagaalee: Windows 10 ykn 11 (64-bit) waliin WebView2 runtime (kanaan dura Windows 11 fi haaromsa dhiyeenyaa Windows 10 keessatti hammatameera).

## Itti fayyadama

1. **Kuusaa** baniitii tapha barbaadi, ykn bakka kamiyyuu taatee `Ctrl` + `K` dhiibi.
2. Tapha tokko cuqqaasi. Paanaalii mirgaa keessatti adeemsaafi daqiiqaa meeqaaf akka turu filadhu (socho'oonni Discord yeroo baay'ee 15 gaafatu).
3. **Decoy jalqabi** cuqqaasi. Seekondii muraasa booda Discord taphicha ni agarsiisa.
4. Jalatti **Hojjechaa jira** hordofi, tokko ykn hundumaa yeroo barbaaddetti dhaabi, ykn Decoy tireeyii keessatti dhiisi.

Taphoonni galmeen Discord isaanii ammaaf exe hin qabne dursee dhokfamu (adda baafamuu hin danda'an). Isaaniin arguuf *Taphoota exe hin qabne agarsiisi* banaa; tarreen guyyaa guyyaan waan haaromfamuuf, akkuma Discord adeemsa dabaleen ni argamu.

### Sarara ajajaa

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy battalatti jalqaba, fakkeenyaaf `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Madda irraa ijaaruu

Ulaagaalee dursaa: [Node.js](https://nodejs.org) 20+, meeshaalee [Rust](https://rustup.rs) dhaabbataa (MSVC target) kan meeshaalee ijaarsaa Visual Studio C++ qabu, fi WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # haala misoomaa keessatti fe'iinsa battalaa wajjin hojjechiisi
npm run tauri build    # fe'aa src-tauri/target/release/bundle/nsis keessatti oomisha
```

Qorannoowwan fayyadan:

```bash
npm run check-locales  # faayilii hiikkaa hunda ru.json irratti hundaa'uun mirkaneessi
npx tsc --noEmit       # koodii frontend qoradhu (type-check)
cargo check --manifest-path src-tauri/Cargo.toml
```

Hubachiisa: exe'n decoy `src-tauri/build.rs` tiin `rustc` salphaadhaan `src-tauri/stub/stub.rs` irraa walitti qabamee ergasii appilikeeshinicha keessatti qabata. Yommuu frontend birowzara salphaa keessatti hojjetu (`npm run dev`) backend fakkeessituu xiqqoon (`src/mock.ts`) fayyadamu, kunis UI irratti hojjechuuf gargaara.

## Tafsiirootni

Jechootni agarsiiftuu [`src/locales`](../../src/locales) keessa jiru, afaan tokkoof faayilii JSON tokko (`en.json`, `ru.json`, ...). Afaan dabaluun faayilii dabaluudha; jijjiiramni koodii hin jiru. Haala faayilii, ajaja qophaa'aa hiikkaa maashiniitiif ta'uufi iskriptii mirkaneessaa argachuuf [docs/TRANSLATING.md](../TRANSLATING.md) ilaalaa. Hiikkaan README kanaa gara `docs/i18n/README.<code>.md` dhaqa.

## Caasaa pirojektichaa

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Iccitummaa

- Decoy'n tarree adda baafannaa uummataa Discord buusuuf qofa intarneetii fayyadama (yeroo jalqabaa, ergasii yoo baay'ate guyyaatti al-tokko ykn yeroo haaromsuu cuqqaastu) akkasumas agarsiisuuf, asxaa taphootaafi fakkii CDN uummataa Discord irraa fayyadama.
- Tookenii Discord keessanii ykn daataa herregaa kamiyyuu hin dubbisu, hin olkaa'u ykn hin ergu, akkasumas kilayentii Discord wajjin hin haasa'u.
- Qindaa'inoonni (filatamoowwan, afaan, turtiiwwan) kuusaa WebView appilikeeshinii keessatti bakka kanatti olkaa'amu; kaashii tarree taphootaafi faayiloonni yeroo decoy `%LOCALAPPDATA%\app.decoy.desktop` keessa jiru.
- Xin-xiilallii hin qabu, gabaasa kuffaatii hin qabu, herregni hin jiru.

## Daangeffamoota beekaman

- Discord yeroo kamiyyuu akkaataa adda baafannaan itti hojjetu jijjiiruu danda'a. Yoo decoy'n adda baafamuu dhaabe, maaloo dhimma (issue) bani.
- Socho'oonni tokko tokko adeemsa hojjetu qofa caalaa barbaadu (fakkeenyaaf muuxannoo addaa jidduu gala taphaa keessa ta'uu). Decoy'n adeemsicha qofa fakkeessa.
- Galmoonni tarree Discord keessatti faayilii exe hin qabne adda baafamuu hin danda'an.
- Sooftiweeronni nageenyaa yeroo tokko tokko faayiloota exe xixiqqoo mallattoo hin qabneefi yaadannoo (memory) keessa taa'an akka waan shakkisiisaatti ilaalu. Decoy'n madda banaa waan ta'eef `src-tauri/stub/stub.rs` irraa ijaarama; mataa keetiin ijaaruu dandeessa.

## Itti Gaafatamummaa Irraa Bilisa Ta'uu

Decoy dhimmoota dhuunfaa, barnootaafi qormaataaf qofa "akkuma jirutti" kennama. Tapha hojjechaa jiru fakkeessuun Seera Tajaajilaa Discord ykn maxxansaa taphichaa cabsuu danda'a, akkasumas herrega kee irratti tarkaanfiin akka fudhatamu gochuu danda'a. Itti fayyadama keetiif situ itti gaafatamummaa qaba. "Discord" fi maqaan taphootaa hunduu mallattoo daldalaa abbootii qabeenyaa isaaniiti, asittis sooftiweerii isaan ibsan adda baasuuf qofa itti fayyadamne.
