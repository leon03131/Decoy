# Decoy

**Равандҳои хурди ивазкунанда, ки ба Discord нишон медиҳанд, ки бозӣ дар ҳоли иҷро аст.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Китобхонаи Decoy бо бозиҳои охирин ва муқоваҳо" />

</div>

Decoy кори як раванди безарари ивазкунанда бо тирезаро таҳти номи файли иҷрошавандаи бозӣ нигоҳ медорад, бинобар ин системаи муайянкунии бозиҳои Discord шуморо ҳамчун бозигари он бозӣ нишон медиҳад. Ба шумо лозим нест, ки бозии аслиро насб кунед ё оғоз намоед, бинобар ин дар диски шумо ягон файли калон ҷой намегирад.

Он **ҳамаи бозиҳоеро, ки Discord метавонад муайян кунад** (тақрибан 25 000 сабт), медонад, зеро он рӯйхати умумии муайянкунии худи Discord-ро мехонад ва онро мустақилона ҳамеша навсозӣ мекунад.

> [!WARNING]
> Тақлиди бозии иҷрошаванда метавонад ба Шартҳои хизматрасонии Discord мухолиф бошад ва шумо Decoy-ро **бо масъулияти худатон** истифода мебаред.
> Ин лоиҳа ба Discord Inc. вобастагӣ надорад, аз ҷониби он тасдиқ нашудааст ё пуштибонӣ намешавад. Ба бахши [Радди масъулият](#радди-масъулият) нигаред.

## Имкониятҳо

- **Ҳама чизе, ки Discord метавонад муайян кунад.** Рӯйхати бозиҳо аз сарчашмаи кушодаи Discord зеркашӣ мешавад, ба таври маҳаллӣ кэш мегардад ва ҳаррӯза навсозӣ мешавад. Бозиҳои нав ва файлҳои иҷрошавандаи нав иловашуда худ аз худ пайдо мешаванд.
- **Ҷустуҷӯи фаврӣ.** Ҷустуҷӯи фаврӣ аз рӯи номи бозӣ ё файли иҷрошаванда дар байни ҳазорон бозиҳо, намуди плиткавӣ ё рӯйхати паймон, баргузидаҳо ва сатри «Охиринҳо».
- **Бо як клик.** Бозиро интихоб кунед, файли иҷрошавандаро интихоб намоед (агар якчандто бошад), муддати нигоҳ доштанро муайян кунед ва оғозро пахш намоед. Ҳалқаи ҳисоби баръакс ва огоҳинома ба шумо хабар медиҳанд, ки вақт тамом шуд.
- **Ҳеҷ гуна из боқӣ намегузорад.** Decoy танҳо ҳангоми иҷро шуданаш мавҷуд аст: exe-и хурд ҳангоми оғоз сохта мешавад ва ҳангоми қатъ кардан нест карда мешавад. Ҳангоми баромадан аз барнома ҳама чиз қатъ карда мешавад ва пасмондаҳои пас аз садамаи эҳтимолӣ ҳангоми оғози навбатӣ тоза карда мешаванд.
- **Ором.** Дар трейи системавӣ ҷойгир мешавад, барои худи decoy-ҳо ягон тиреза ё тугма дар панели вазифаҳо пайдо намешавад.
- **Тарҷумаҳои кушода.** Интерфейс тавассути файлҳои оддии JSON кор мекунад, бинобар ин илова кардани забон танҳо аз як файл иборат аст. Забонҳои англисӣ ва русӣ аллакай ворид карда шудаанд.
- **Маҳрамона.** Бе ҳисоб, бе токени Discord, бе телеметрия. Ба бахши [Маҳрамонагӣ](#маҳрамонагӣ) нигаред.

## Тарзи кор

1. Discord муайян мекунад, ки шумо бозӣ карда истодаед, тавассути санҷиши равандҳои иҷрошаванда дар компютери шумо ва муқоисаи номҳои файлҳои иҷрошавандаи онҳо бо рӯйхати умумӣ (`/api/v9/applications/detectable`).
2. Decoy ин рӯйхатро зеркашӣ мекунад ва барои бозии интихобкардаи шумо як барномаи хурди ивазкунандаро (тақрибан 120 КБ, бо забони Rust навишта шуда ва дар дохили Decoy ҷой дода шудааст) ба папкаи муваққатӣ бо номи файли иҷрошаванда аз рӯйхат нусхабардорӣ мекунад, масалан `.../cod26-cod.exe`.
3. Ивазкунанда ба ҷуз сохтани як тирезаи сатҳи болоӣ, ки хеле дур аз экран гузошта шудааст, то шумо онро ҳаргиз набинед, кори дигаре намекунад. Discord танҳо равандҳоеро эътироф мекунад, ки тиреза доранд, бинобар ин раванди комилан бе тиреза нодида гирифта мешавад.
4. Тақрибан пас аз 15 сония Discord бозиро ҳамчун фаъолияти ҷории шумо нишон медиҳад.
5. Вақте ки таймер ба охир мерасад ё шумо тугмаи қатъро пахш мекунед, Decoy равандро анҷом медиҳад ва файлро нест мекунад. Объект-вазифаи Windows (job object) кафолат медиҳад, ки decoy-ҳо якҷоя бо Decoy хотима меёбанд, ҳатто агар барнома ба садама дучор шавад.

## Насбкунӣ

Якеро аз саҳифаи [Нашрҳо](../../../../releases) интихоб кунед:

| Зеркашӣ | Барои |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Насбкунанда.** Барои як корбар, бидуни ниёз ба ҳуқуқҳои мудир (administrator), сабти менюи «Оғоз» (Start) ва барномаи несткуниро илова мекунад. |
| `Decoy_x.y.z_x64-portable.zip` | **Нусхаи сайёр (Portable).** Ба дилхоҳ ҷой кушоед ва `decoy.exe`-ро ба кор дароред. Ҳамаи додаҳо дар папкаи `data` дар паҳлӯи он нигоҳ дошта мешаванд, дар профили корбар чизе навишта намешавад. Барои нест кардан, танҳо папкаро нест кунед. |

Бо ёрии `SHA256SUMS.txt` эътибори зеркаширо санҷед (`Get-FileHash <file>` дар PowerShell).

Windows SmartScreen метавонад дар бораи ношири номаълум ҳушдор диҳад, зеро сохтҳо имзои рақамӣ надоранд; агар шумо ба сохт эътимод дошта бошед, *Муфассал → Ба ҳар ҳол иҷро кардан* (More info → Run anyway)-ро интихоб намоед.

Талабот: Windows 10 ё 11 (64-битӣ) бо муҳити иҷрои WebView2 (аллакай дар Windows 11 ва навсозиҳои охирини Windows 10 мавҷуд аст).

## Истифода

1. **Китобхона**-ро кушоед ва бозиро ҷӯед, ё аз дилхоҳ ҷой `Ctrl` + `K`-ро пахш кунед.
2. Бозиро клик кунед. Дар панели рост раванд ва чанд дақиқа нигоҳ доштани онро интихоб кунед (барои вазифаҳои Discord одатан 15 дақиқа лозим мешавад).
3. **Оғози decoy**-ро пахш кунед. Discord пас аз чанд сония бозиро намоиш медиҳад.
4. Онро дар бахши **Дар ҳоли иҷро** назорат кунед, якто ё ҳамаашро дар дилхоҳ вақт қатъ намоед ё танҳо Decoy-ро дар трей гузоред.

Бозиҳое, ки сабти Discord-и онҳо то ҳол файли иҷрошаванда надорад, ба таври пешфарз пинҳон карда мешаванд (онҳоро муайян кардан ғайриимкон аст). Барои дидани онҳо *Нишон додани бозиҳои бе exe*-ро фаъол кунед; рӯйхат ҳар рӯз нав мешавад, бинобар ин ҳамин ки Discord равандро илова намояд, онҳо дастрас мегарданд.

### Сатри фармон

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy-ро фавран оғоз мекунад, масалан: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сохтан аз сарчашма

Пешниёзҳо: [Node.js](https://nodejs.org) 20+, маҷмӯи абзорҳои устувори [Rust](https://rustup.rs) (ҳадафи MSVC) бо абзорҳои сохти Visual Studio C++ ва муҳити иҷрои WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # дар ҳолати таҳия бо боркунии гарм иҷро кардан
npm run tauri build    # омода кардани насбкунанда дар src-tauri/target/release/bundle/nsis
```

Санҷишҳои муфид:

```bash
npm run check-locales  # санҷиши ҳар як файли тарҷума нисбат ба ru.json
npx tsc --noEmit       # санҷиши намудҳои frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Эзоҳ: exe-и decoy аз ҷониби `src-tauri/build.rs` бо ёрии `rustc`-и оддӣ аз `src-tauri/stub/stub.rs` компилятсия шуда, сипас ба барнома ворид карда мешавад. Вақте ки frontend дар браузери оддӣ иҷро мешавад (`npm run dev`), як бэкенди сохтаи хурд (`src/mock.ts`) истифода мешавад, ки барои кор бо интерфейс хеле мувофиқ аст.

## Тарҷумаҳо

Сатрҳои интерфейс дар [`src/locales`](../../src/locales) қарор доранд, як файли JSON барои ҳар як забон (`en.json`, `ru.json`, ...).
Илова кардани забон маънои илова кардани файлро дорад; бидуни тағйироти код. Барои формати файл, дархости тайёр барои тарҷумаи мошинӣ ва скрипти санҷиш ба [docs/TRANSLATING.md](../TRANSLATING.md) муроҷиат кунед. Тарҷумаҳои ин README ба `docs/i18n/README.<code>.md` гузошта мешаванд.

## Сохтори лоиҳа

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Маҳрамонагӣ

- Decoy шабакаро танҳо барои зеркашии рӯйхати умумии муайянкунии Discord (ҳангоми оғози аввал, сипас на бештар аз як маротиба дар як рӯз ё ҳангоми пахш кардани тугмаи навсозӣ) ва барои намоиши нишонаҳо ва муқоваҳои бозӣ аз CDN-и умумии Discord истифода мебарад.
- Он токени Discord ё ягон маълумоти ҳисоби шуморо намехонад, нигоҳ намедорад ва намефиристад, инчунин бо барномаи Discord мустақиман иртибот надорад.
- Танзимот (баргузидаҳо, забон, муддатҳо) дар нигаҳдории WebView-и худи барнома ба таври маҳаллӣ маҳфузанд; кэши рӯйхати бозиҳо ва файлҳои муваққатии decoy дар `%LOCALAPPDATA%\app.decoy.desktop` ҷойгиранд.
- Бидуни таҳлилҳо, бидуни гузориши садамаҳо ва бидуни ҳисобҳо.

## Маҳдудиятҳои маълум

- Discord метавонад тарзи муайянкуниро дар дилхоҳ вақт тағйир диҳад. Агар decoy муайян нашавад, лутфан issue кушоед.
- Баъзе фаъолиятҳо на танҳо раванди корӣ, балки бештар аз онро талаб мекунанд (масалан, будан дар дохили як фазо ё режими муайяни платформаи бозӣ). Decoy танҳо равандро тақлид мекунад.
- Сабтҳое, ки дар рӯйхати Discord файли иҷрошаванда надоранд, муайян карда намешаванд.
- Нармафзори амниятӣ баъзан файлҳои хурди имзонашудаи иҷрошавандаро, ки бефаъолият дар хотира қарор доранд, шубҳанок медонад. Decoy сарчашмаи кушода дорад ва аз `src-tauri/stub/stub.rs` сохта мешавад; шумо метавонед онро худатон компилятсия кунед.

## Радди масъулият

Decoy «чунон ки ҳаст» танҳо барои мақсадҳои шахсӣ, таълимӣ ва санҷишӣ пешниҳод мешавад. Тақлиди бозии дар ҳоли иҷро метавонад Шартҳои хизматрасонии Discord ё ношири бозиро вайрон кунад ва боиси чораҳо нисбати ҳисоби шумо гардад. Шумо барои тарзи истифодаи он танҳо худатон масъул ҳастед. «Discord» ва ҳамаи номҳо ва тамғаҳои бозиҳо тамғаҳои молии соҳибони мувофиқашон мебошанд ва дар ин ҷо танҳо барои шиносоии нармафзоре, ки ба он ишора мекунанд, истифода мешаванд.
