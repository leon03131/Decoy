# Decoy

**Proses pengganti kecil yang membuatkan Discord menganggap sesuatu permainan sedang dimainkan.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Pustaka Decoy dengan permainan terkini dan karya seni" />

</div>

Decoy mengekalkan proses pemegang tempat (placeholder) yang tidak berbahaya dan mempunyai tetingkap berjalan di bawah nama fail boleh laku permainan, supaya pengesanan permainan Discord melaporkan anda sedang bermain permainan tersebut. Anda tidak perlu memasang atau melancarkan permainan sebenar, jadi tiada fail bersaiz besar yang memenuhi ruang cakera anda.

Ia mengenali **setiap permainan yang boleh dikesan oleh Discord** (kira-kira 25,000 entri) kerana ia membaca senarai pengesanan awam Discord sendiri dan mengemas kininya secara automatik.

> [!WARNING]
> Memalsukan permainan yang sedang berjalan boleh melanggar Terma Perkhidmatan Discord dan anda menggunakan Decoy **atas risiko anda sendiri**.
> Projek ini tidak bergabung dengan, disokong oleh atau berkaitan dengan Discord Inc. Lihat [Penafian](#penafian).

## Ciri-ciri

- **Semua yang boleh dikesan oleh Discord.** Senarai permainan dimuat turun daripada titik akhir pengesanan awam Discord, dicache secara setempat dan disegarkan setiap hari. Permainan baharu dan fail boleh laku yang baru ditambah akan muncul dengan sendirinya.
- **Carian pantas.** Carian segera mengikut nama permainan atau fail boleh laku merentasi ribuan permainan, paparan grid atau senarai padat, kegemaran dan baris "Terkini".
- **Satu klik.** Pilih permainan, pilih fail boleh laku (jika terdapat beberapa pilihan), tetapkan tempoh masa untuk mengekalkannya dan tekan mula. Gegelung kiraan detik dan pemberitahuan akan memberitahu anda apabila masa tamat.
- **Tidak meninggalkan sebarang kesan.** Decoy hanya wujud semasa ia berjalan: fail exe kecil dicipta semasa bermula dan dipadamkan apabila dihentikan. Semuanya dihentikan apabila anda keluar, dan sisa akibat ranap sistem akan dibersihkan pada pelancaran seterusnya.
- **Senyap.** Berjalan di dulang sistem (system tray), tanpa sebarang tetingkap atau butang bar tugas untuk decoy itu sendiri.
- **Terjemahan terbuka.** Antara muka digerakkan oleh fail JSON biasa, jadi menambah bahasa hanya memerlukan satu fail. Bahasa Inggeris dan Rusia disertakan.
- **Peribadi.** Tiada akaun, tiada token Discord, tiada telemetri. Lihat [Privasi](#privasi).

## Cara ia berfungsi

1. Discord menentukan anda sedang bermain sesuatu permainan dengan memeriksa proses yang berjalan pada PC anda dan membandingkan nama fail boleh laku dengan senarai awam (`/api/v9/applications/detectable`).
2. Decoy memuat turun senarai tersebut dan, bagi permainan yang anda pilih, menyalin program pengganti kecil (kira-kira 120 KB, ditulis dalam Rust dan terbina di dalam Decoy) ke folder sementara menggunakan nama fail boleh laku daripada senarai, contohnya `.../cod26-cod.exe`.
3. Program pengganti tidak melakukan apa-apa selain memiliki satu tetingkap peringkat teratas, yang diletakkan jauh di luar skrin supaya anda tidak akan melihatnya. Discord hanya mengenali proses yang memiliki tetingkap, itulah sebabnya proses tanpa tetingkap sama sekali akan diabaikan.
4. Dalam masa sekitar 15 saat, Discord akan memaparkan permainan tersebut sebagai aktiviti semasa anda.
5. Apabila pemasa tamat atau anda menekan berhenti, Decoy menamatkan proses dan memadamkan fail tersebut. Windows job object memastikan decoy ditamatkan bersama-sama dengan Decoy, walaupun ia mengalami ranap sistem.

## Pemasangan

Pilih salah satu daripada halaman [Keluaran](../../../../releases):

| Muat turun | Untuk |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Pemasang.** Mengikut pengguna, tidak memerlukan hak pentadbir, menambah entri menu Start dan penyahpasang. |
| `Decoy_x.y.z_x64-portable.zip` | **Mudah alih.** Ekstrak di mana-mana sahaja dan jalankan `decoy.exe`. Semua data kekal di dalam folder `data` bersebelahannya, tiada apa yang ditulis pada profil pengguna anda. Padamkan folder tersebut untuk membuangnya. |

Sahkan fail muat turun dengan `SHA256SUMS.txt` (`Get-FileHash <file>` dalam PowerShell).

Windows SmartScreen mungkin memberi amaran tentang penerbit yang tidak dikenali kerana binaan ini tidak ditandatangani secara digital (code signed); pilih *More info → Run anyway* jika anda mempercayai binaan tersebut.

Keperluan: Windows 10 atau 11 (64-bit) dengan WebView2 runtime (sudah disertakan dalam Windows 11 dan kemas kini terkini Windows 10).

## Penggunaan

1. Buka **Pustaka** dan cari permainan, atau tekan `Ctrl` + `K` dari mana-mana sahaja.
2. Klik sesuatu permainan. Pada panel di sebelah kanan, pilih proses dan bilangan minit untuk mengekalkannya (aktiviti Discord biasanya memerlukan 15 minit).
3. Tekan **Mula decoy**. Discord akan memaparkan permainan tersebut selepas beberapa saat.
4. Pantau di bawah **Sedang Berjalan**, hentikan satu atau kesemuanya pada bila-bila masa, atau biarkan Decoy berada di dulang sistem.

Permainan yang entri Discord-nya belum mempunyai fail boleh laku disembunyikan secara lalai (ia tidak boleh dikesan). Hidupkan *Tunjukkan permainan tanpa exe* untuk melihatnya; senarai ini disegarkan setiap hari, jadi ia akan tersedia sebaik sahaja Discord menambah sesuatu proses.

### Baris arahan

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Memulakan decoy serta-merta, contohnya `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bina daripada sumber

Prasyarat: [Node.js](https://nodejs.org) 20+, toolchain [Rust](https://rustup.rs) yang stabil (sasaran MSVC) dengan Visual Studio C++ build tools, dan WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # jalankan dalam mod pembangunan dengan hot reload
npm run tauri build    # hasilkan pemasang dalam src-tauri/target/release/bundle/nsis
```

Pemeriksaan berguna:

```bash
npm run check-locales  # sahkan setiap fail terjemahan berbanding ru.json
npx tsc --noEmit       # semakan jenis frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Nota: fail exe decoy dikompilasi oleh `src-tauri/build.rs` menggunakan `rustc` biasa daripada `src-tauri/stub/stub.rs` dan kemudian disematkan ke dalam aplikasi. Apabila frontend dijalankan dalam pelayar biasa (`npm run dev`), bahagian belakang olok-olok kecil (`src/mock.ts`) digunakan, yang sangat memudahkan kerja-kerja antara muka pengguna (UI).

## Terjemahan

Rentetan UI disimpan dalam [`src/locales`](../../src/locales), satu fail JSON untuk setiap bahasa (`en.json`, `ru.json`, ...). Menambah bahasa hanya memerlukan penambahan satu fail; tiada perubahan kod diperlukan. Lihat [docs/TRANSLATING.md](../TRANSLATING.md) untuk format fail, gesaan sedia guna bagi terjemahan mesin dan skrip pengesahan. Terjemahan README ini diletakkan di `docs/i18n/README.<code>.md`.

## Susun atur projek

```

```

## Privasi

- Decoy hanya menggunakan rangkaian untuk memuat turun senarai pengesanan awam Discord (semasa pelancaran pertama, kemudian paling kerap sekali sehari atau apabila anda menekan butang segar semula) dan, untuk paparan, ikon permainan serta karya seni daripada CDN awam Discord.
- Ia tidak membaca, menyimpan atau menghantar token Discord anda atau sebarang data akaun, dan ia tidak berkomunikasi dengan klien Discord.
- Tetapan (kegemaran, bahasa, tempoh) disimpan secara setempat dalam storan WebView aplikasi; cache senarai permainan dan fail decoy sementara disimpan di `%LOCALAPPDATA%\app.decoy.desktop`.
- Tiada analitik, tiada laporan ranap sistem, tiada akaun.

## Batasan yang diketahui

- Discord boleh mengubah cara pengesanan berfungsi pada bila-bila masa. Jika sesuatu decoy tidak lagi dikenali, sila buka isu (issue).
- Sesetengah aktiviti memerlukan lebih daripada sekadar proses yang berjalan (contohnya berada di dalam pengalaman tertentu pada platform permainan). Decoy hanya meniru proses tersebut.
- Entri tanpa fail boleh laku dalam senarai Discord tidak dapat dikesan.
- Perisian keselamatan kadangkala menandakan fail boleh laku kecil yang tidak ditandatangani dan melahu dalam memori. Decoy adalah sumber terbuka dan dibina daripada `src-tauri/stub/stub.rs`; anda boleh mengompilasinya sendiri.

## Penafian

Decoy disediakan "seadanya" untuk tujuan peribadi, pendidikan dan pengujian. Meniru permainan yang sedang berjalan mungkin melanggar Terma Perkhidmatan Discord atau penerbit permainan tersebut, dan boleh membawa kepada tindakan terhadap akaun anda. Anda sendiri yang bertanggungjawab terhadap cara anda menggunakannya. "Discord" dan semua nama permainan serta logo ialah tanda dagangan pemilik masing-masing dan digunakan di sini hanya untuk mengenal pasti perisian yang dirujuk.
