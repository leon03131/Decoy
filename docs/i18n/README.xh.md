# Decoy

**Iinkqubo ezincinci ezimeleyo ezenza i-Discord icinge ukuba umdlalo uyaqhuba.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Ilayibrari ye-Decoy enemidlalo yakutsha nje nemifanekiso" />

</div>

I-Decoy igcina inkqubo yesibambeli engenabungozi kwaye enefestile iqhuba phantsi kwegama lefayile ephunyezwako (executable) yomdlalo, ukuze ukubona komdlalo kwe-Discord kuxele ukuba udlala loo mdlalo. Awusoze ufune ukufaka okanye ukuqalisa owona mdlalo wokwenyani, ngoko akukho nto inkulu ihlala kwidisk yakho.

Yazi nge-**midlalo yonke enokufunyanwa yi-Discord** (iingeniso ezimalunga nama-25,000) kuba ifunda uluhlu lukawonke-wonke lokubona lwe-Discord ngokwayo kwaye ilugcina luhlaziyekile ngokwayo.

> [!WARNING]
> Ukwenza ngathi umdlalo uyaqhuba kunokuchasana neMimiselo yeNkonzo ye-Discord kwaye usebenzisa i-Decoy **ngomngcipheko wakho**.
> Le projekthi ayihambelani, ayixhaswanga okanye ayiqhagamshelwanga ne-Discord Inc. Jonga [Ukhululo luxanduva](#ukhululo-luxanduva).

## Iimpawu

- **Yonke into enokubonwa yi-Discord.** Uluhlu lwemidlalo lukhutshelwa kwindawo kawonke-wonke yokubona ye-Discord, lugcinwe kwikhompyutha yakho kwaye luhlaziywe yonke imihla. Imidlalo emitsha kunye neefayile eziphunyezwako ezisandul' ukongezwa zivela ngokwazo.
- **Ukukhangela okukhawulezayo.** Ukukhangela ngoko nangoko ngegama lomdlalo okanye ifayile ephunyezwako phakathi kwamawaka emidlalo, ukujonga ngeethayile okanye uluhlu olubambeneyo, izintandokazi kunye nomqolo othi "Kutsha nje".
- **Unqakrazo olunye.** Khetha umdlalo, khetha ifayile ephunyezwako (ukuba zininzi), khetha ixesha lokuyigcina uze ucofe qala. Isangqa sokubala wehla kunye nesaziso zikuxelela xa ixesha liphelile.
- **Ayishiyi nto ngasemva.** I-decoy ibakho kuphela logama iqhuba: i-exe encinci idalwa xa kuqalwa kwaye icinywe xa kumiswa. Yonke into iyamiswa xa uphuma, kwaye intsalela yokuwa kwenkqubo iyatshayelwa kuqaliselo olulandelayo.
- **Iyazola.** Ihlala kwitreyi yenkqubo, akukho zifestile okanye amaqhosha e-taskbar kuma-decoy ngokwawo.
- **Uguqulelo oluvulekileyo.** Isonxibelelwano siqhutywa ziifayile ze-JSON ezicacileyo, ngoko ukongeza ulwimi yifayile enye nje. IsiNgesi nesiRashiya zifakiwe.
- **Yabucala.** Akukho akhawunti, akukho thokheni ye-Discord, akukho telemetry. Jonga [Ubumfihlo](#ubumfihlo).

## Indlela esebenza ngayo

1. I-Discord igqiba kwelokuba udlala umdlalo ngokujonga iinkqubo eziqhuba kwi-PC yakho nokuthelekisa amagama azo aphunyezwako noluhlu lukawonke-wonke (`/api/v9/applications/detectable`).
2. I-Decoy ikhuphela olo luhlu kwaye, kumdlalo owukhethayo, ikopele inkqubo encinci emele umdlalo (emalunga ne-120 KB, ebhalwe nge-Rust kwaye yafakwa ngaphakathi kwi-Decoy) kwifolda yethutyana isebenzisa igama eliphunyezwako elisuka kuluhlu, umzekelo `.../cod26-cod.exe`.
3. Inkqubo emele umdlalo ayenzi nto ngaphandle kokuba nefestile enye ekwinqanaba eliphezulu, epakishwe kude lee kwikhusi ukuze ungaze uyibone. I-Discord ibona kuphela inkqubo enefestile, yiyo loo nto inkqubo engenafestile konke konke ingahoywa.
4. Kwisithuba semizuzwana emalunga ne-15 i-Discord ibonisa umdlalo njengomsebenzi wakho wangoku.
5. Xa isibali-xesha siphela okanye ucofa misa, i-Decoy iphelisa inkqubo ize icime ifayile. Into yomsebenzi ye-Windows (job object) iqinisekisa ukuba ama-decoy afela kunye ne-Decoy, nokuba ingantlitheka.

## Ukufaka

Khetha enye kwiphepha le-[Releases](../../../../releases):

| Khuphela | Yenzelwe |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Isifaki.** Somsebenzisi ngamnye, akukho malungelo omlawuli adingekayo, yongeza ungeniso kwimenyu yokuqala kunye nesikhuphi. |
| `Decoy_x.y.z_x64-portable.zip` | **Ephathekayo (Portable).** Zikhulule (unzip) naphi na uze uqhube `decoy.exe`. Yonke idatha ihlala kwifolda ye-`data` ecaleni kwayo, akukho nto ibhalwayo kwiprofayili yakho yomsebenzisi. Cima ifolda ukuyisusa. |

Qinisekisa ukhuphelo nge-`SHA256SUMS.txt` (`Get-FileHash <file>` kwi-PowerShell).

I-Windows SmartScreen isenokulumkisa ngompapashi ongaziwayo kuba izakhiwo azisayinwanga ngekhowudi; khetha *More info → Run anyway* ukuba uyasithemba isakhiwo eso.

Iimfuneko: Windows 10 okanye 11 (64-bit) ene-WebView2 runtime (esele ifakiwe kwi-Windows 11 nakuhlaziyo lwakutsha nje lwe-Windows 10).

## Ukusetyenziswa

1. Vula i-**Library** uze ukhangele umdlalo, okanye ucofe u-`Ctrl` + `K` ukusuka naphi na.
2. Cofa umdlalo. Kwiqela lenkqubo elingasekunene khetha inkqubo kunye nemizuzu yokuyibamba (imisebenzi ye-Discord idla ngokucela eyi-15).
3. Cofa u-**Start decoy**. I-Discord iza kubonisa umdlalo emva kwemizuzwana embalwa.
4. Yibukele phantsi kwe-**Running**, misa ibenye okanye zonke nanini na, okanye vele ushiye i-Decoy kwitreyi.

Imidlalo engenazo iifayile eziphunyezwako kuluhlu lwe-Discord ifihliwe ngokungagqibekanga (ayinako ukubonwa). Vula *Show games without exe* ukuze uzibone; uluhlu luhlaziywa yonke imihla, ngoko ziyafumaneka kamsinya nje zakuba i-Discord yongeze inkqubo.

### Umgca womyalelo

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Iqala i-decoy kwangoko, umzekelo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ukwakha kwikhowudi engumthombo

Iimfuneko zangaphambili: [Node.js](https://nodejs.org) 20+, isixhobo esizinzileyo se-[Rust](https://rustup.rs) (ekujoliswe kuyo i-MSVC) kunye nezixhobo zokwakha ze-Visual Studio C++, kunye ne-WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # qhuba kwimo yophuhliso elayisha ngokutsha ngokukhawuleza
npm run tauri build    # velisa isifaki kwi-src-tauri/target/release/bundle/nsis
```

Iitshekhi eziluncedo:

```bash
npm run check-locales  # qinisekisa yonke ifayile yoguqulelo xa ithelekiswa ne-ru.json
npx tsc --noEmit       # tshekisha iindidi zangaphambili (frontend)
cargo check --manifest-path src-tauri/Cargo.toml
```

Amanqaku: i-exe ye-decoy iqulunqwa ngu-`src-tauri/build.rs` nge-`rustc` ecacileyo ukusuka ku-`src-tauri/stub/stub.rs` ize ifakwe ngaphakathi kwi-app. Xa i-frontend iqhuba kwisikhangeli esiqhelekileyo (`npm run dev`) kusetyenziswa i-mock backend encinci (`src/mock.ts`), eluncedo kakhulu ekusebenzeni kwi-UI.

## Uguqulelo

Imitya ye-UI ihlala kwi-[`src/locales`](../../src/locales), ifayile enye ye-JSON kulwimi ngalunye (`en.json`, `ru.json`, ...). Ukongeza ulwimi kuthetha ukongeza ifayile; akukho zinguqu zekhowudi. Jonga i-[docs/TRANSLATING.md](../TRANSLATING.md) ukufumana ulwakhiwo lwefayile, umyalelo olungele ukusetyenziswa kumatshini woguqulelo kunye nesikripthi sokuqinisekisa. Uguqulelo lwale README luya kwi-`docs/i18n/README.<code>.md`.

## Ubumfihlo

- I-Decoy isebenzisa inethiwekhi kuphela ukukhuphela uluhlu lukawonke-wonke lokubona lwe-Discord (kuqaliselo lokuqala, emva koko ubuncinane kanye ngosuku okanye xa ucofa hlaziya) kwaye, ngokomboniso, ii-icon zomdlalo nemifanekiso evela kwi-CDN kawonke-wonke ye-Discord.
- Ayifundi, ayigcini okanye ayithumeli ithokheni yakho ye-Discord okanye nayiphi na idatha yeakhawunti, kwaye ayithethi nomxhasi we-Discord.
- Izicwangciso (izintandokazi, ulwimi, amaxesha) zigcinwa kwikhompyutha yakho kwisitoreji se-WebView se-app; i-cache yoluhlu lwemidlalo kunye neefayile zethutyana ze-decoy zihlala kwi-`%LOCALAPPDATA%\app.decoy.desktop`.
- Akukho zibalo (analytics), akukho ngxelo yokuwa kwenkqubo, akukho ziiakhawunti.

## Imida eyaziwayo

- I-Discord inokutshintsha indlela ukubona okusebenza ngayo nanini na. Ukuba i-decoy iyayeka ukubonwa, nceda uvule umba (issue).
- Eminye imisebenzi idinga okungaphezulu kwenkqubo eqhubayo (umzekelo ukuba ngaphakathi kwamava athile eqonga lomdlalo). I-Decoy ixelisa inkqubo kuphela.
- Iingeniso ezingenazo iifayile eziphunyezwako kuluhlu lwe-Discord azinako ukubonwa.
- Isoftware yokhuseleko ngamaxesha athile iphawula iifayile ezincinci ezingasayinwanga eziphunyezwako ezihlala zingasebenzi kwimemori. I-decoy ngumthombo ovulekileyo kwaye yakhiwe ukusuka ku-`src-tauri/stub/stub.rs`; ungaziqulunqela yona ngokwakho.

## Ukhululo luxanduva

I-Decoy ibonelelwa "njengoko injalo" ngenjongo yobuqu, ezemfundo nezovavanyo. Ukuxelisa umdlalo oqhubayo kusenokwaphula iMimiselo yeNkonzo ye-Discord okanye yompapashi womdlalo, kwaye kusenokukhokelela kwinyathelo elichasene neakhawunti yakho. Wena wedwa unoxanduva lwendlela oyisebenzisa ngayo. "Discord" nawo onke amagama emidlalo kunye neelogo ziimpawu zorhwebo zabanini bazo kwaye zisetyenziswe apha kuphela ukuchonga isoftware ezibhekisa kuyo.
