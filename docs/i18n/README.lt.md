# Decoy

**Nedideli pakaitiniai procesai, priverčiantys Discord manyti, kad žaidimas yra paleistas.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy biblioteka su neseniai naudotais žaidimais ir iliustracijomis" />

</div>

Decoy palaiko veikiantį nekenksmingą pakaitinį procesą su langu po žaidimo vykdomojo failo pavadinimu, todėl Discord žaidimų aptikimo sistema rodo, kad žaidžiate tą žaidimą. Jums niekada nereikia įdiegti ar paleisti tikro žaidimo, todėl jokie dideli failai neužima vietos diske.

Ji žino apie **kiekvieną žaidimą, kurį gali aptikti Discord** (apie 25 000 įrašų), nes nuskaito paties Discord viešą aptikimo sąrašą ir pati automatiškai jį atnaujina.

> [!WARNING]
> Žaidimo vykdymo imitavimas gali prieštarauti Discord paslaugų teikimo sąlygoms ir jūs naudojate Decoy **savo rizika**.
> Šis projektas nėra susijęs su Discord Inc., jos patvirtintas ar kaip nors su ja susietas. Žr. [Atsakomybės apribojimas](#atsakomybės-apribojimas).

## Funkcijos

- **Viskas, ką gali aptikti Discord.** Žaidimų sąrašas atsiunčiamas iš viešo Discord aptikimo taško, išsaugomas talpykloje vietoje ir atnaujinamas kasdien. Nauji žaidimai ir naujai pridėti vykdomieji failai atsiranda savaime.
- **Sparčioji paieška.** Greita paieška pagal žaidimo pavadinimą arba vykdomąjį failą tarp tūkstančių žaidimų, tinklelio arba kompaktiško sąrašo rodinys, mėgstamiausi ir skiltis „Neseniai naudoti“.
- **Vienas paspaudimas.** Pasirinkite žaidimą, pasirinkite vykdomąjį failą (jei jų yra keli), pasirinkite, kiek laiko jį palaikyti, ir spustelėkite paleisti. Laikmačio žiedas ir pranešimas informuos, kai laikas baigsis.
- **Nepaliekama jokių pėdsakų.** Imitacija egzistuoja tik tol, kol ji vykdoma: nedidelis exe failas sukuriamas paleidžiant ir ištrinamas sustabdžius. Viskas sustabdoma išėjus iš programos, o gedimo atveju likę failai išvalomi per kitą paleidimą.
- **Tyli.** Veikia sistemos dėkle, pačioms imitacijoms nėra jokių atskirų langų ar užduočių juostos mygtukų.
- **Atviri vertimai.** Sąsaja valdoma paprastais JSON failais, todėl norint pridėti kalbą pakanka vieno failo. Anglų ir rusų kalbos jau įtrauktos.
- **Privatu.** Nėra paskyros, jokio Discord prieigos rakto, jokios telemetrijos. Žr. [Privatumas](#privatumas).

## Kaip tai veikia

1. Discord nusprendžia, kad žaidžiate žaidimą, tikrindamas jūsų kompiuteryje vykdomus procesus ir lygindamas jų vykdomųjų failų pavadinimus su viešu sąrašu (`/api/v9/applications/detectable`).
2. Decoy atsisiunčia šį sąrašą ir jūsų pasirinktam žaidimui nukopijuoja nedidelę pakaitinę programą (apie 120 KB, parašytą su Rust ir integruotą į Decoy) į laikinąjį aplanką, panaudodama vykdomojo failo pavadinimą iš sąrašo, pavyzdžiui, `.../cod26-cod.exe`.
3. Pakaitinė programa nieko nedaro, išskyrus tai, kad valdo vieną viršutinio lygio langą, patalpintą toli už ekrano ribų, kad jo niekada nepamatytumėte. Discord atpažįsta tik procesą, valdantį langą, todėl procesas visiškai be lango būtų ignoruojamas.
4. Maždaug per 15 sekundžių Discord parodo šį žaidimą kaip jūsų dabartinę veiklą.
5. Pasibaigus laikmačiui arba paspaudus sustabdyti, Decoy užbaigia procesą ir ištrina failą. Windows užduočių objektas (job object) užtikrina, kad imitacijos bus sustabdytos kartu su Decoy, net jei ji užstrigtų ar netikėtai išsijungtų.

## Įdiegimas

Pasirinkite vieną iš [Releases](../../../../releases) puslapio:

| Atsisiuntimas | Paskirtis |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Diegimo programa.** Skirta vartotojui, administratoriaus teisių nereikia, prideda įrašą į Pradžios meniu ir pašalinimo programą. |
| `Decoy_x.y.z_x64-portable.zip` | **Nešiojamoji versija.** Išpakuokite bet kur ir paleiskite `decoy.exe`. Visi duomenys lieka šalia esančiame aplanke `data`, niekas nerašoma į jūsų vartotojo profilį. Norėdami pašalinti, tiesiog ištrinkite aplanką. |

Patvirtinkite atsisiuntimą naudodami `SHA256SUMS.txt` (`Get-FileHash <failas>` programoje PowerShell).

Windows SmartScreen gali įspėti apie neatpažintą leidėją, nes kompiliuoti failai nėra pasirašyti kodo parašu; jei pasitikite versija, pasirinkite *Daugiau informacijos → Vykdyti bet kokiu atveju*.

Reikalavimai: Windows 10 arba 11 (64 bitų) su WebView2 vykdymo aplinka (jau įtraukta į Windows 11 ir naujesnius Windows 10 atnaujinimus).

## Naudojimas

1. Atverkite **Biblioteka** ir ieškokite žaidimo, arba bet kur paspauskite `Ctrl` + `K`.
2. Spustelėkite žaidimą. Skydelyje dešinėje pasirinkite procesą ir kiek minučių jį palaikyti (Discord veikloms paprastai reikia 15).
3. Paspauskite **Paleisti imitaciją**. Discord parodys žaidimą po kelių sekundžių.
4. Stebėkite jį skiltyje **Vykdomi**, bet kada sustabdykite vieną ar visus, arba tiesiog palikite Decoy sistemos dėkle.

Žaidimai, kurių Discord įrašas dar neturi vykdomųjų failų, pagal numatytuosius nustatymus yra paslėpti (jų negalima aptikti). Įjunkite *Rodyti be exe failų*, kad juos pamatytumėte; sąrašas atnaujinamas kasdien, todėl jie tampa pasiekiami, kai tik Discord prideda procesą.

### Komandinė eilutė

```
decoy.exe --launch "<vykdomojo failo kelias iš Discord sąrašo>" [minutės]
```

Paleidžia imitaciją iš karto, pavyzdžiui, `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kompiliavimas iš šaltinio kodo

Būtinosios sąlygos: [Node.js](https://nodejs.org) 20+, stabili [Rust](https://rustup.rs) įrankių grandinė (MSVC taikinys) su Visual Studio C++ kūrimo įrankiais ir WebView2 vykdymo aplinka.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # paleisti kūrimo režimu su automatiniu atnaujinimu
npm run tauri build    # sugeneruoti diegimo programą aplanke src-tauri/target/release/bundle/nsis
```

Naudingi patikrinimai:

```bash
npm run check-locales  # patvirtinti kiekvieną vertimo failą pagal ru.json
npx tsc --noEmit       # patikrinti priekinės dalies tipus
cargo check --manifest-path src-tauri/Cargo.toml
```

Pastabos: imitacijos exe failą kompiliuoja `src-tauri/build.rs` naudodamas tiesiogiai `rustc` iš `src-tauri/stub/stub.rs` ir po to integruoja į programą. Kai priekinė dalis paleidžiama paprastoje naršyklėje (`npm run dev`), naudojama maža fiktyvi programų sąsaja (`src/mock.ts`), kuri yra patogi dirbant su vartotojo sąsaja.

## Vertimai

Vartotojo sąsajos tekstai yra aplanke [`src/locales`](../../src/locales), po vieną JSON failą kiekvienai kalbai (`en.json`, `ru.json`, ...). Norint pridėti kalbą, tereikia pridėti failą; jokių kodo pakeitimų. Žr. [docs/TRANSLATING.md](../TRANSLATING.md), kur rasite failo formatą, paruoštą užklausą mašininiam vertimui ir patvirtinimo scenarijų. Šio README vertimai pateikiami faile `docs/i18n/README.<code>.md`.

## Projekto struktūra

```
src/                    React + TypeScript vartotojo sąsaja
  components/           Biblioteka, išsamios informacijos skydelis, nustatymai, ...
  locales/              vertimų failai (po vieną JSON kiekvienai kalbai)
  i18n-core.ts          kalbos įkėlimas ir paieška
  store.ts              programos būsena (zustand)
src-tauri/              Rust galinė dalis (Tauri 2)
  src/lib.rs            žaidimų duomenų bazė, imitacijų procesai, sistemos dėklas
  stub/stub.rs          integruojama pakaitinė programa
scripts/                pagalbiniai scenarijai (vertimų patvirtinimas)
docs/                   vertimo vadovas, ekrano nuotraukos
```

## Privatumas

- Decoy naudoja tinklą tik viešam Discord aptikimo sąrašui atsisiųsti (per pirmąjį paleidimą, vėliau ne dažniau kaip kartą per dieną arba paspaudus atnaujinti) ir, atvaizdavimui, žaidimų piktogramoms bei iliustracijoms iš Discord viešojo CDN gauti.
- Ji nenuskaito, nesaugo ir nesiunčia jūsų Discord prieigos rakto ar bet kokių paskyros duomenų, taip pat nebendrauja su pačia Discord programa.
- Nustatymai (mėgstamiausi, kalba, trukmė) saugomi vietoje programos WebView saugykloje; žaidimų sąrašo talpykla ir laikinieji imitacijų failai yra `%LOCALAPPDATA%\app.decoy.desktop`.
- Jokios analitikos, jokių strigčių ataskaitų, jokių paskyrų.

## Žinomi apribojimai

- Discord gali bet kada pakeisti aptikimo veikimo principą. Jei imitacija nustoja būti atpažįstama, atverkite klaidų pranešimą (issue).
- Kai kurioms veikloms reikia daugiau nei tik veikiančio proceso (pavyzdžiui, buvimo konkrečiame žaidimų platformos pasaulyje). Decoy imituoja tik procesą.
- Įrašai be vykdomųjų failų Discord sąraše negali būti aptikti.
- Saugumo programinė įranga kartais gali įspėti dėl mažų nepasirašytų vykdomųjų failų, kurie neveiksnūs lieka atmintyje. Imitacija yra atvirojo kodo ir sukurta iš `src-tauri/stub/stub.rs`; galite ją sukompiliuoti patys.

## Atsakomybės apribojimas

Decoy pateikiama tokia, kokia yra („as is“), asmeniniais, mokomaisiais ir testavimo tikslais. Veikiančio žaidimo imitavimas gali pažeisti Discord arba žaidimo leidėjo paslaugų teikimo sąlygas ir gali sukelti veiksmų prieš jūsų paskyrą. Tik jūs patys esate atsakingi už jos naudojimą. „Discord“ ir visi žaidimų pavadinimai bei logotipai yra jų atitinkamų savininkų prekių ženklai ir čia naudojami tik nurodyti programinę įrangą, apie kurią kalbama.
