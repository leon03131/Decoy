# Decoy

**Малки заместващи процеси, които карат Discord да мисли, че дадена игра е пусната.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Библиотека на Decoy със скорошни игри и изображения" />

</div>

Decoy поддържа безобиден прозоречен заместващ процес под името на изпълнимия файл на играта, така че
засичането на игри в Discord отчита, че играете тази игра. Никога не е нужно да инсталирате или пускате
истинската игра, така че нищо голямо не заема място на диска ви.

Знае за **всяка игра, която Discord може да засече** (около 25 000 записа), защото чете публичния
списък за засичане на самия Discord и го поддържа актуален самостоятелно.

> [!WARNING]
> Симулирането на работеща игра може да противоречи на Общите условия на Discord и използвате Decoy **на свой собствен риск**.
> Този проект не е свързан с, одобрен от или асоцииран с Discord Inc. Вижте [Отказ от отговорност](#отказ-от-отговорност).

## Възможности

- **Всичко, което Discord може да засече.** Списъкът с игри се изтегля от публичната крайна точка за засичане на Discord,
  кешира се локално и се обновява ежедневно. Нови игри и новодобавени изпълними файлове се появяват автоматично.
- **Бързо търсене.** Моментално търсене по име на игра или изпълним файл сред хиляди игри, изглед като плочки или
  компактен списък, любими и ред със „Скорошни“.
- **С един клик.** Изберете игра, изберете изпълнимия файл (ако са няколко), задайте колко време да се поддържа и натиснете старт.
  Пръстен за обратно броене и известие ви уведомяват, когато времето изтече.
- **Не оставя нищо след себе си.** Даден decoy съществува само докато работи: малкият exe файл се създава при стартиране и се изтрива
  при спиране. Всичко спира при изход, а остатъци от евентуален срив се изчистват при следващото пускане.
- **Дискретен.** Стои в системната лента, без прозорци или бутони в лентата на задачите за самите decoys.
- **Отворени преводи.** Интерфейсът се управлява от обикновени JSON файлове, така че добавянето на нов език е един файл.
  Включени са английски и руски.
- **Поверителност.** Без акаунт, без Discord токен, без телеметрия. Вижте [Поверителност](#поверителност).

## Как работи

1. Discord определя дали играете игра, като проверява процесите, работещи на вашия компютър, и сравнява имената
   на техните изпълними файлове с публичен списък (`/api/v9/applications/detectable`).
2. Decoy изтегля този списък и за избраната от вас игра копира малка заместваща програма (около 120 KB, написана на
   Rust и вградена в Decoy) във временна папка, използвайки името на изпълнимия файл от списъка, например
   `.../cod26-cod.exe`.
3. Заместващата програма не прави нищо, освен да притежава един прозорец от най-високо ниво, разположен далеч извън екрана,
   така че никога да не го видите. Discord разпознава само процеси, притежаващи прозорец, поради което напълно безпрозоречните процеси се игнорират.
4. В рамките на около 15 секунди Discord показва играта като текуща активност.
5. Когато таймерът изтече или натиснете спиране, Decoy прекратява процеса и изтрива файла. Windows job object
   гарантира, че процесите decoys се затварят заедно с Decoy, дори ако приложението се срине.

## Инсталиране

Изберете вариант от страницата с [Версии](../../../../releases):

| Изтегляне | Предназначение |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталатор.** За текущия потребител, не са необходими администраторски права, добавя запис в стартовото меню и инструмент за деинсталиране. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативна версия.** Разархивирайте където пожелаете и стартирайте `decoy.exe`. Всички данни остават в папка `data` до него, нищо не се записва в потребителския профил. Изтрийте папката, за да го премахнете. |

Проверете изтегления файл с `SHA256SUMS.txt` (`Get-FileHash <file>` в PowerShell).

Windows SmartScreen може да покаже предупреждение за неизвестен издател, тъй като компилациите нямат цифров подпис; изберете
*More info → Run anyway* (Повече информация → Изпълнение въпреки това), ако се доверявате на компилацията.

Изисквания: Windows 10 или 11 (64-битов) с WebView2 runtime (вече включен в Windows 11 и скорошните
актуализации на Windows 10).

## Начин на употреба

1. Отворете **Библиотека** и потърсете игра, или натиснете `Ctrl` + `K` от всяко място.
2. Кликнете върху игра. В панела отдясно изберете процеса и за колко минути да се поддържа (активностите
   в Discord обикновено изискват 15).
3. Натиснете **Стартиране на decoy**. Discord ще покаже играта след няколко секунди.
4. Наблюдавайте я в раздел **Стартирани**, спирайте отделни или всички процеси по всяко време, или просто оставете Decoy в системната лента.

Игрите, чийто запис в Discord все още няма изпълними файлове, са скрити по подразбиране (не могат да бъдат засечени). Включете
*Показване на игри без exe*, за да ги видите; списъкът се обновява ежедневно, така че те стават налични веднага щом Discord добави
процес.

### Команден ред

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Стартира decoy веднага, например `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Компилиране от изходен код

Предварителни изисквания: [Node.js](https://nodejs.org) 20+, стабилен инструментариум на [Rust](https://rustup.rs) (MSVC target) с
инструментите за компилиране на C++ във Visual Studio и WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Полезни проверки:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Бележки: exe файлът на decoy се компилира от `src-tauri/build.rs` с обикновен `rustc` от `src-tauri/stub/stub.rs` и след това
се вгражда в приложението. Когато клиентската част (frontend) работи в обикновен браузър (`npm run dev`), се използва малък симулиран бекенд
(`src/mock.ts`), което е удобно за работа по потребителския интерфейс.

## Преводи

Низовете на интерфейса се намират в [`src/locales`](../../src/locales), по един JSON файл за всеки език (`en.json`, `ru.json`, ...).
Добавянето на език означава добавяне на файл; без промени в кода. Вижте [docs/TRANSLATING.md](../TRANSLATING.md) за формата
на файла, готов промпт за машинен превод и скрипта за проверка. Преводите на това README се записват в
`docs/i18n/README.<code>.md`.

## Структура на проекта

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Поверителност

- Decoy използва мрежата единствено за изтегляне на публичния списък за засичане на Discord (при първо пускане, след това най-много веднъж на ден
  или при натискане на обновяване) и за показване на икони на игри и изображения от публичния CDN на Discord.
- Не чете, не съхранява и не изпраща вашия Discord токен или каквито и да е данни за профила и не комуникира с клиента на Discord.
- Настройките (любими, език, продължителност) се съхраняват локално в паметта на WebView на приложението; кешът на списъка с игри и
  временните decoy файлове се намират в `%LOCALAPPDATA%\app.decoy.desktop`.
- Без анализи, без доклади за сривове, без акаунти.

## Известни ограничения

- Discord може да промени начина на засичане по всяко време. Ако даден decoy спре да бъде разпознаван, моля, отворете проблем (issue).
- Някои активности изискват повече от работещ процес (например престой в конкретно преживяване на игрова
  платформа). Decoy имитира само процеса.
- Записи без изпълними файлове в списъка на Discord не могат да бъдат засечени.
- Софтуерът за сигурност понякога маркира малки неподписани изпълними файлове, които стоят неактивни в паметта. Decoy е с отворен код
  и е компилиран от `src-tauri/stub/stub.rs`; можете да го компилирате сами.
