# Decoy

**Àwọn ìlànà kéékèèké afidípò tí ń jẹ́ kí Discord rò pé eré kan ń lọ lọ́wọ́.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Àkójọ Decoy pẹ̀lú àwọn eré àìpẹ́ àti iṣẹ́ ọnà" />

</div>

Decoy ń mú kí ìlànà afidípò oníwíndò kan tí kò léwu máa ṣiṣẹ́ lábẹ́ orúkọ fáìlì aṣeéṣe (executable) ti eré kan, kí ìmọ̀lára eré ti Discord lè ròyìn pé o ń gbá eré náà. O kò nílò láti fi eré gidi sori kọ̀mpútà tàbí láti bẹ̀rẹ̀ rẹ̀ láé, nítorí náà kò sí nǹkan ńlá kankan tí yóò gba àyè lórí àwo-fáìlì (disk) rẹ.

Ó mọ̀ nípa **gbogbo eré tí Discord lè rí** (nǹkan bí àwọn eré 25,000) nítorí ó ń ka àkójọ ìmọ̀lára ti gbogbo ènìyàn ti Discord fúnra rẹ̀, ó sì ń ṣe àtúnṣe rẹ̀ fúnra rẹ̀ nígbà gbogbo.

> [!WARNING]
> Fífi ẹ̀tàn ṣe bíi pé eré kan ń ṣiṣẹ́ lè lòdì sí Àwọn Àdéhùn Ìṣe ti Discord, o sì ń lo Decoy **lábẹ́ ewu ti ara rẹ**.
> Iṣẹ́ àkànṣe yìí kò ní ìbáṣepọ̀ kankan pẹ̀lú, kò gba ìtìlẹ́yìn láti ọ̀dọ̀, bẹ́ẹ̀ ni kò sí ìsopọ̀ pẹ̀lú Discord Inc. Wo [Àlàyé Ìdásílẹ̀](#àlàyé-ìdásílẹ̀).

## Àwọn Ẹ̀yà

- **Gbogbo nǹkan tí Discord lè rí.** A ń gba àkójọ eré wọlé láti ojú-ọ̀nà ìmọ̀lára gbangba ti Discord, a ń tọ́jú rẹ̀ sí kọ̀mpútà rẹ, a sì ń sọ di tuntun lójoojúmọ́. Àwọn eré titun àti àwọn fáìlì aṣeéṣe tí a ṣẹ̀ṣẹ̀ fi kún un máa ń hàn fúnrawọn.
- **Ìwárí tí kì í dẹ́kun.** Ìwárí lẹ́sẹ̀kẹsẹ̀ nípa orúkọ eré tàbí executable kọjá àwọn ẹgbẹẹgbẹ̀rún eré, ìwò àpótí tàbí àtòjọ fífún, àwọn ayànfẹ́ àti ìlà "Tí a lò lẹ́nu àìpẹ́".
- **Ẹyọ tẹ̀mọ́lẹ̀ kan ṣoṣo.** Yan eré kan, yan executable náà (tí wọ́n bá pọ̀), yan bí yóò ti pẹ́ tó tí yóò fi ṣiṣẹ́ kí o sì tẹ bẹ̀rẹ̀. Òbírí kíkà-àkókò-sẹ́yìn àti ìfitónilétí yóò sọ fún ọ nígbà tí àkókò bá parí.
- **Kò fi nǹkan kankan sílẹ̀.** Decoy wà nígbà tí ó bá ń ṣiṣẹ́ nìkan: a ń dá exe kékeré náà sílẹ̀ nígbà ìbẹ̀rẹ̀, a sì ń pa á rẹ́ nígbà ìdúró. Gbogbo nǹkan ni a máa dá dúró nígbà tí o bá jáde, àti àwọn àṣẹ́kù látàrí ìkùnà ètò ni a máa gbá kúrò nígbà ìbẹ̀rẹ̀ tí ó kàn.
- **Dákẹ́ rọ́rọ́.** Ó máa ń wà ní pẹpẹ ètò (system tray), kò sí wíndò tàbí bọ́tìnì pẹpẹ iṣẹ́ (taskbar) fún àwọn decoy fúnrawọn.
- **Àwọn ìyípadà èdè tí ó ṣí sílẹ̀.** Àwọn ọ̀rọ̀ ojú-ìbòjú ni a ń darí pẹ̀lú àwọn fáìlì JSON lásán, nítorí náà fífi èdè kún jẹ́ fáìlì kan péré. Èdè Gẹ̀ẹ́sì àti Rọ́ṣíà wà nínú rẹ̀.
- **Àdáni.** Kò sí àkántì, kò sí àmì ìdánimọ̀ (token) ti Discord, kò sí tẹlifóònù dátà (telemetry). Wo [Àkíyèsí Àdáni](#àkíyèsí-àdáni).

## Bí ó ṣe ń ṣiṣẹ́

1. Discord ń pinnu pé o ń gbá eré kan nípa wíwo àwọn ìlànà (processes) tí ń ṣiṣẹ́ lórí PC rẹ àti fífi àwọn orúkọ executable wọn wéra pẹ̀lú àkójọ gbangba kan (`/api/v9/applications/detectable`).
2. Decoy ń gba àkójọ yẹn wọlé, àti fún eré tí o bá yàn, ó ń ṣe ẹ̀dà ètò afidípò kékeré kan (nǹkan bí 120 KB, tí a kọ ní Rust tí a sì fi sínú Decoy) sí àpò-fáìlì fún ìgbà díẹ̀ pẹ̀lú lílo orúkọ executable láti inú àkójọ náà, fún àpẹẹrẹ `.../cod26-cod.exe`.
3. Ètò afidípò náà kò ṣe nǹkan kankan bí kò ṣe láti ní wíndò orí-ìpele kan, tí a gbé sí ibi jíjìnnà rékọjá ojú-ìbòjú kí o má baà rí i láé. Discord máa ń mọ ìlànà tí ó ní wíndò nìkan, èyí sì ni ìdí tí a kò fi ka ìlànà tí kò ní wíndò kankan sí.
4. Láàárín nǹkan bí ìṣẹ́jú-àáyá 15, Discord yóò fi eré náà hàn bí iṣẹ́ rẹ lọ́wọ́lọ́wọ́.
5. Nígbà tí àkókò bá parí tàbí tí o bá tẹ dúró, Decoy yóò fòpin sí ìlànà náà yóò sì pa fáìlì náà rẹ́. Nǹkan iṣẹ́ (job object) ti Windows ń rí i dájú pé àwọn decoy kú pa pọ̀ pẹ̀lú Decoy, kódà bí ó bá kùnà lójijì.

## Ìfisípò

Yan ọ̀kan láti ojú-ewé [Àwọn Ìtújáde](../../../../releases):

| Ìgbasílẹ̀ | Fún |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Olùfisípò.** Fún olùlò kọ̀ọ̀kan, kò nílò ẹ̀tọ́ alábòójútó (administrator), ó ń fi àkọsílẹ̀ sí àtòjọ Bẹ̀rẹ̀ (Start menu) àti olùyọkúrò. |
| `Decoy_x.y.z_x64-portable.zip` | **Èyí tí a lè gbé kiri.** Tú u sí ibikíbi kí o sì ṣí `decoy.exe`. Gbogbo dátà yóò wà nínú àpò-fáìlì `data` lẹ́gbẹ̀ẹ́ rẹ̀, kò sí ohun tí a kọ sínú profaili olùlò rẹ. Pa àpò-fáìlì náà rẹ́ láti yọ ọ́ kúrò. |

Ṣe àmúdájú ìgbasílẹ̀ pẹ̀lú `SHA256SUMS.txt` (`Get-FileHash <file>` nínú PowerShell).

Windows SmartScreen lè kìlọ̀ nípa olùtẹ̀jáde tí a kò mọ̀ nítorí àwọn àgbékalẹ̀ kò ní àwọn ìfọwọ́sí kóòdù; yan *More info → Run anyway* tí o bá gbẹ́kẹ̀lé àgbékalẹ̀ náà.

Àwọn ohun tí a nílò: Windows 10 tàbí 11 (64-bit) pẹ̀lú àkókò-ìṣiṣẹ́ WebView2 (ó ti wà nínú Windows 11 àti àwọn àtúnṣe Windows 10 àìpẹ́).

## Ìlò

1. Ṣí **Àkójọ** kí o sì wá eré kan, tàbí tẹ `Ctrl` + `K` láti ibikíbi.
2. Tẹ eré kan. Nínú pẹpẹ tí ó wà ní apá ọ̀tún, yan ìlànà náà àti iye ìṣẹ́jú tí o fẹ́ fi pamọ́ (àwọn ìgbòkègbodò Discord sábà máa ń béèrè fún 15).
3. Tẹ **Bẹ̀rẹ̀ decoy**. Discord yóò fi eré náà hàn lẹ́yìn ìṣẹ́jú-àáyá díẹ̀.
4. Wò ó lábẹ́ **Ń ṣiṣẹ́**, dá ọ̀kan tàbí gbogbo wọn dúró ní àkókò eyikeyii, tàbí kàn fi Decoy sílẹ̀ nínú pẹpẹ ètò (tray).

Àwọn eré tí àkọsílẹ̀ Discord wọn kò tíì ní àwọn executable jẹ́ fífipamọ́ látìbẹ̀rẹ̀ (wọn kò ṣeé rí). Tan *Fi àwọn eré tí kò ní exe hàn* láti rí wọn; a máa ń sọ àkójọ náà di tuntun lójoojúmọ́, nítorí náà wọ́n máa wà ní àrọ́wọ́tó gbàrà tí Discord bá fi ìlànà kún un.

### Laini àṣẹ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Ó ń bẹ̀rẹ̀ decoy lẹ́sẹ̀kẹsẹ̀, fún àpẹẹrẹ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kíkọ láti orísun

Àwọn ohun pàtàkì: [Node.js](https://nodejs.org) 20+, irinṣẹ́ [Rust](https://rustup.rs) tí ó dúró ṣinṣin (MSVC target) pẹ̀lú àwọn irinṣẹ́ kíkọ Visual Studio C++, àti àkókò-ìṣiṣẹ́ WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Àwọn àyẹ̀wò tí ó wúlò:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Àwọn àkíyèsí: exe decoy ni a kọ pẹ̀lú `src-tauri/build.rs` pẹ̀lú `rustc` lásán láti `src-tauri/stub/stub.rs` tí a sì fi sínú àmúlò náà. Nígbà tí ojú-ewé iwájú bá ń ṣiṣẹ́ nínú àwárí-ayélujára lásán (`npm run dev`), backend àpẹẹrẹ kékeré kan (`src/mock.ts`) ni a ń lò, èyí tí ó rọrùn fún ṣíṣiṣẹ́ lórí UI.

## Àwọn Ìtumọ̀ Èdè

Àwọn ọ̀rọ̀ UI wà nínú [`src/locales`](../../src/locales), fáìlì JSON kan fún èdè kọ̀ọ̀kan (`en.json`, `ru.json`, ...). Fífi èdè kún túmọ̀ sí fífi fáìlì kún; kò sí àtúnṣe kóòdù kankan. Wo [docs/TRANSLATING.md](../TRANSLATING.md) fún ìrísí fáìlì náà, àkọlé tí a pèsè sílẹ̀ fún ìyípadà ẹ̀rọ àti ìwé-àṣẹ ìfọwọ́sowọ́pọ̀. Àwọn ìtumọ̀ ti README yìí máa ń lọ sí `docs/i18n/README.<code>.md`.

## Ètò iṣẹ́ àkànṣe

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Àkíyèsí Àdáni

- Decoy ń lo nẹ́tíwọ́ọ̀kì nìkan láti gba àkójọ ìmọ̀lára gbangba ti Discord wọlé (nígbà ìbẹ̀rẹ̀ àkọ́kọ́, lẹ́yìn náà ní kété jùlọ lẹ́ẹ̀kan lójúmọ́ tàbí nígbà tí o bá tẹ sọ di tuntun) àti, fún ìfihàn, àwọn àmì eré àti iṣẹ́ ọnà láti CDN gbangba ti Discord.
- Kò ka, kò tọ́jú bẹ́ẹ̀ ni kò fi àmì ìdánimọ̀ (token) Discord rẹ tàbí dátà àkántì kankan ránṣẹ́, kò sì bá oníbàárà Discord sọ̀rọ̀.
- Àwọn ètò (àwọn ayànfẹ́, èdè, àwọn àkókò) ni a tọ́jú sí kọ̀mpútà lábẹ́ ìtọ́jú WebView ti àmúlò náà; àkójọ àfipamọ́ eré àti àwọn fáìlì decoy fún ìgbà díẹ̀ wà nínú `%LOCALAPPDATA%\app.decoy.desktop`.
- Kò sí ìtúpalẹ̀ (analytics), kò sí ìjábọ̀ ìkùnà ètò, kò sí àwọn àkántì.

## Àwọn Ààlà tí a mọ̀

- Discord lè yí bí ìmọ̀lára ṣe ń ṣiṣẹ́ padà nígbàkúgbà. Tí a kò bá mọ decoy mọ́, jọ̀wọ́ ṣí ìṣòro (issue) kan.
- Àwọn ìgbòkègbodò kan nílò ju ìlànà tí ń ṣiṣẹ́ lọ (fún àpẹẹrẹ wíwà nínú ìrírí pàtó kan ti pẹpẹ eré kan). Decoy ń ṣàfarawé ìlànà náà nìkan.
- Àwọn àkọsílẹ̀ tí kò ní àwọn executable nínú àkójọ Discord kò ṣeé rí.
- Sọfitiwia ààbò máa ń fi àmì sí àwọn executable kéékèèké tí kò ní ìfọwọ́sí tí ó jókòó lásán nínú ìrántí (memory) lẹ́ẹ̀kọ̀ọ̀kan. Decoy jẹ́ orísun ṣíṣí (open source) tí a kọ láti `src-tauri/stub/stub.rs`; o lè ṣe àkópọ̀ rẹ̀ fúnra rẹ.

## Ìkópa

Àwọn ìjábọ̀ àbùkù, àwọn èrò àti àwọn ìtumọ̀ jẹ́ ohun tí a tẹ́wọ́gbà. Jọ̀wọ́ ka [CONTRIBUTING.md](../../CONTRIBUTING.md) kọ́kọ́.

## Àlàyé Ìdásílẹ̀

A pèsè Decoy "bí ó ṣe wà" fún àwọn ète ti ara ẹni, ẹ̀kọ́ àti ìdánwò. Ṣíṣàfarawé eré tí ń ṣiṣẹ́ lè rú Àwọn Àdéhùn Ìṣe ti Discord tàbí ti olùtẹ̀jáde eré náà, ó sì lè yọrí sí ìgbése lòdì sí àkántì rẹ. Ìwọ nìkan ló ní ojúṣe fún bí o ṣe lò ó. "Discord" àti gbogbo àwọn orúkọ eré àti àwọn àmì ìdánimọ̀ jẹ́ àmì-ìdánimọ̀ ti àwọn olúwa wọn gidi, a sì lò wọ́n níhìn-ín kìkì láti dá sọfitiwia tí wọ́n tọ́ka sí mọ̀.
