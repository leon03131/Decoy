# Decoy

**ഒരു ഗെയിം പ്രവർത്തിക്കുന്നതായി Discord-നെ വിശ്വസിപ്പിക്കുന്ന ചെറിയ പകരക്കാരൻ പ്രോസസുകൾ.**

![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)

ഒരു ഗെയിമിന്റെ എക്സിക്യൂട്ടബിൾ നാമത്തിന് കീഴിൽ നിരുപദ്രവകരമായ, വിൻഡോയോടുകൂടിയ ഒരു പ്ലേസ്‌ഹോൾഡർ പ്രോസസ് Decoy പ്രവർത്തിപ്പിച്ചുകൊണ്ടിരിക്കുന്നു, അതിനാൽ നിങ്ങൾ ആ ഗെയിം കളിക്കുന്നതായി Discord-ന്റെ ഗെയിം ഡിറ്റക്ഷൻ കാണിക്കുന്നു. നിങ്ങൾ ഒരിക്കലും യഥാർത്ഥ ഗെയിം ഇൻസ്റ്റാൾ ചെയ്യുകയോ ആരംഭിക്കുകയോ ചെയ്യേണ്ടതില്ല, അതിനാൽ വലിയ ഫയലുകളൊന്നും നിങ്ങളുടെ ഡിസ്കിൽ സൂക്ഷിക്കേണ്ടി വരുന്നില്ല.

Discord-ന് **തിരിച്ചറിയാൻ കഴിയുന്ന എല്ലാ ഗെയിമുകളെക്കുറിച്ചും** (ഏകദേശം 25,000 എൻട്രികൾ) ഇതിനറിയാം, കാരണം ഇത് Discord-ന്റെ സ്വന്തം പബ്ലിക് ഡിറ്റക്ഷൻ ലിസ്റ്റ് വായിക്കുകയും സ്വയം കാലികമായി സൂക്ഷിക്കുകയും ചെയ്യുന്നു.

> [!WARNING]
> പ്രവർത്തിക്കുന്ന ഗെയിം വ്യാജമായി കാണിക്കുന്നത് Discord-ന്റെ സേവന നിബന്ധനകൾക്ക് വിരുദ്ധമായേക്കാം, ഒപ്പം നിങ്ങൾ Decoy ഉപയോഗിക്കുന്നത് **നിങ്ങളുടെ സ്വന്തം ഉത്തരവാദിത്തത്തിലാണ്**.
> ഈ പ്രോജക്റ്റ് Discord Inc.-മായി അഫിലിയേറ്റ് ചെയ്തതോ അംഗീകരിച്ചതോ ബന്ധപ്പെട്ടതോ അല്ല. [ബാധ്യതാ നിരാകരണം](#ബാധ്യതാ-നിരാകരണം) കാണുക.

## സവിശേഷതകൾ

- **Discord-ന് കണ്ടെത്താൻ കഴിയുന്ന എല്ലാം.** ഗെയിം ലിസ്റ്റ് Discord-ന്റെ പബ്ലിക് ഡിറ്റക്ഷൻ എൻഡ്‌പോയിന്റിൽ നിന്ന് ഡൗൺലോഡ് ചെയ്യുകയും ലോക്കലായി കാഷെ ചെയ്യുകയും ദിവസവും പുതുക്കുകയും ചെയ്യുന്നു. പുതിയ ഗെയിമുകളും പുതുതായി ചേർത്ത എക്സിക്യൂട്ടബിളുകളും സ്വയമേവ ദൃശ്യമാകും.
- **വേഗതയേറിയ തിരച്ചിൽ.** ആയിരക്കണക്കിന് ഗെയിമുകളിലുടനീളം ഗെയിമിന്റെ പേര് അല്ലെങ്കിൽ എക്സിക്യൂട്ടബിൾ ഉപയോഗിച്ചുള്ള തൽക്ഷണ തിരച്ചിൽ, ഗ്രിഡ് അല്ലെങ്കിൽ കോംപാക്റ്റ് ലിസ്റ്റ് കാഴ്‌ച, പ്രിയപ്പെട്ടവ, "സമീപകാലത്തുള്ളവ" എന്ന നിര.
- **ഒറ്റ ക്ലിക്ക്.** ഒരു ഗെയിം തിരഞ്ഞെടുക്കുക, എക്സിക്യൂട്ടബിൾ തിരഞ്ഞെടുക്കുക (ഒന്നിലധികം ഉണ്ടെങ്കിൽ), എത്ര സമയം സൂക്ഷിക്കണമെന്ന് തീരുമാനിക്കുക, ആരംഭിക്കുക അമർത്തുക. സമയം കഴിയുമ്പോൾ ഒരു കൗണ്ട്ഡൗൺ റിംഗും അറിയിപ്പും നിങ്ങളെ അറിയിക്കും.
- **അവശിഷ്ടങ്ങൾ അവശേഷിപ്പിക്കുന്നില്ല.** പ്രവർത്തിക്കുമ്പോൾ മാത്രമേ ഒരു decoy നിലനിൽക്കൂ: ആരംഭിക്കുമ്പോൾ ചെറിയ exe സൃഷ്ടിക്കപ്പെടുകയും നിർത്തുമ്പോൾ ഇല്ലാതാക്കപ്പെടുകയും ചെയ്യുന്നു. നിങ്ങൾ ആപ്പ് നിർത്തുമ്പോൾ എല്ലാം നിർത്തപ്പെടുന്നു, കൂടാതെ ക്രാഷ് സംഭവിച്ചാലുണ്ടാകുന്ന ശേഷിപ്പുകൾ അടുത്ത തവണ ആരംഭിക്കുമ്പോൾ മായ്‌ക്കപ്പെടും.
- **ശല്യപ്പെടുത്താത്തത്.** സിസ്റ്റം ട്രേയിലാണ് പ്രവർത്തിക്കുന്നത്, decoy-കൾക്കായി പ്രത്യേക വിൻഡോകളോ ടാസ്‌ക്ബാർ ബട്ടണുകളോ ഇല്ല.
- **തുറന്ന വിവർത്തനങ്ങൾ.** ഇന്റർഫേസ് ലളിതമായ JSON ഫയലുകളാലാണ് പ്രവർത്തിക്കുന്നത്, അതിനാൽ ഒരു ഭാഷ ചേർക്കാൻ ഒരു ഫയൽ മാത്രം മതിയാകും. ഇംഗ്ലീഷും റഷ്യനും ഉൾപ്പെടുത്തിയിട്ടുണ്ട്.
- **സ്വകാര്യമായത്.** അക്കൗണ്ടില്ല, Discord ടോക്കണില്ല, ടെലിമെട്രിയില്ല. [സ്വകാര്യത](#സ്വകാര്യത) കാണുക.

## ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

1. നിങ്ങളുടെ പിസിയിൽ പ്രവർത്തിക്കുന്ന പ്രോസസുകൾ പരിശോധിച്ച് അവയുടെ എക്സിക്യൂട്ടബിൾ പേരുകൾ ഒരു പബ്ലിക് ലിസ്റ്റുമായി (`/api/v9/applications/detectable`) താരതമ്യം ചെയ്താണ് നിങ്ങൾ ഒരു ഗെയിം കളിക്കുന്നതായി Discord നിശ്ചയിക്കുന്നത്.
2. Decoy ആ ലിസ്റ്റ് ഡൗൺലോഡ് ചെയ്യുകയും, നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ഗെയിമിനായി ലിസ്റ്റിൽ നിന്നുള്ള എക്സിക്യൂട്ടബിൾ നാമം ഉപയോഗിച്ച് ഒരു ചെറിയ പകരക്കാരൻ പ്രോഗ്രാം (ഏകദേശം 120 KB, Rust-ൽ എഴുതി Decoy-ൽ ഉൾപ്പെടുത്തിയത്) ഒരു താൽക്കാലിക ഫോൾഡറിലേക്ക് പകർത്തുകയും ചെയ്യുന്നു (ഉദാഹരണത്തിന് `.../cod26-cod.exe`).
3. ഈ പ്രോഗ്രാം ഒരു ടോപ്പ്-ലെവൽ വിൻഡോ കൈവശം വയ്ക്കുകയല്ലാതെ മറ്റൊന്നും ചെയ്യുന്നില്ല. നിങ്ങൾ ഒരിക്കലും കാണാതിരിക്കാൻ ഈ വിൻഡോ സ്ക്രീനിന് വളരെ ദൂരെയായി സ്ഥാപിച്ചിരിക്കുന്നു. ഒരു വിൻഡോ ഉള്ള ഒരു പ്രോസസ്സിനെ മാത്രമേ Discord തിരിച്ചറിയൂ, അതിനാലാണ് വിൻഡോ ഇല്ലാത്ത പ്രോസസ്സുകൾ പൂർണ്ണമായും അവഗണിക്കപ്പെടുന്നത്.
4. ഏകദേശം 15 സെക്കൻഡിനുള്ളിൽ Discord നിങ്ങളുടെ നിലവിലെ ആക്റ്റിവിറ്റിയായി ആ ഗെയിം കാണിക്കുന്നു.
5. ടൈമർ അവസാനിക്കുമ്പോഴോ നിങ്ങൾ സ്റ്റോപ്പ് അമർത്തുമ്പോഴോ, Decoy പ്രോസസ് അവസാനിപ്പിക്കുകയും ഫയൽ ഇല്ലാതാക്കുകയും ചെയ്യുന്നു. ആപ്പ് ക്രാഷായാൽ പോലും decoy-കൾ Decoy-നൊപ്പം അവസാനിക്കുന്നുവെന്ന് ഒരു Windows ജോബ് ഒബ്‌ജക്റ്റ് ഉറപ്പാക്കുന്നു.

## ഇൻസ്റ്റാളേഷൻ

[Releases](../../../../releases) പേജിൽ നിന്ന് ഒരെണ്ണം തിരഞ്ഞെടുക്കുക:

| ഡൗൺലോഡ് | അനുയോജ്യമായത് |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ഇൻസ്റ്റാളർ.** ഓരോ ഉപയോക്താവിനും പ്രത്യേകം (per-user), അഡ്മിനിസ്ട്രേറ്റർ അനുമതികൾ ആവശ്യമില്ല, Start മെനു എൻട്രിയും അൺഇൻസ്റ്റാളറും നൽകുന്നു. |
| `Decoy_x.y.z_x64-portable.zip` | **പോർട്ടബിൾ.** എവിടെയും അൺസിപ്പ് ചെയ്ത് `decoy.exe` പ്രവർത്തിപ്പിക്കുക. എല്ലാ ഡാറ്റയും അതിനടുത്തുള്ള `data` ഫോൾഡറിൽ സൂക്ഷിക്കുന്നു, നിങ്ങളുടെ ഉപയോക്തൃ പ്രൊഫൈലിലേക്ക് ഒന്നും എഴുതപ്പെടുന്നില്ല. ഇത് നീക്കംചെയ്യാൻ ഫോൾഡർ ഇല്ലാതാക്കിയാൽ മതിയാകും. |

`SHA256SUMS.txt` ഉപയോഗിച്ച് ഡൗൺലോഡ് പരിശോധിക്കുക (PowerShell-ൽ `Get-FileHash <file>`).

ബിൽഡുകൾ കോഡ് സൈൻ ചെയ്യാത്തതിനാൽ Windows SmartScreen തിരിച്ചറിയപ്പെടാത്ത പ്രസാധകനെക്കുറിച്ച് മുന്നറിയിപ്പ് നൽകിയേക്കാം; നിങ്ങൾ ബിൽഡ് വിശ്വസിക്കുന്നുവെങ്കിൽ *More info → Run anyway* തിരഞ്ഞെടുക്കുക.

ആവശ്യകതകൾ: WebView2 റൺടൈം ഉള്ള Windows 10 അല്ലെങ്കിൽ 11 (64-bit) (ഇതിനകം Windows 11-ലും സമീപകാല Windows 10 അപ്‌ഡേറ്റുകളിലും ഉൾപ്പെടുത്തിയിട്ടുണ്ട്).

## ഉപയോഗം

1. **Library** തുറന്ന് ഒരു ഗെയിമിനായി തിരയുക, അല്ലെങ്കിൽ എവിടെനിന്നും `Ctrl` + `K` അമർത്തുക.
2. ഒരു ഗെയിമിൽ ക്ലിക്ക് ചെയ്യുക. വലതുവശത്തുള്ള പാനലിൽ പ്രോസസ്സും എത്ര മിനിറ്റ് നിലനിർത്തണമെന്നും തിരഞ്ഞെടുക്കുക (Discord ആക്റ്റിവിറ്റികൾക്ക് സാധാരണയായി 15 മിനിറ്റ് ആവശ്യമാണ്).
3. **Start decoy** അമർത്തുക. ഏതാനും സെക്കൻഡുകൾക്ക് ശേഷം Discord ആ ഗെയിം കാണിക്കും.
4. **Running** എന്നതിന് കീഴിൽ ഇത് നിരീക്ഷിക്കുക, ഏത് സമയത്തും ഒന്നോ അല്ലെങ്കിൽ എല്ലാം തന്നെയോ നിർത്തുക, അല്ലെങ്കിൽ Decoy സിസ്റ്റം ട്രേയിൽ വിടുക.

Discord ലിസ്റ്റിൽ എക്സിക്യൂട്ടബിളുകൾ ഇല്ലാത്ത ഗെയിമുകൾ ഡിഫോൾട്ടായി മറച്ചിരിക്കുന്നു (അവ കണ്ടെത്താനാകില്ല). അവ കാണുന്നതിന് *Show games without exe* ഓണാക്കുക; ലിസ്റ്റ് ദിവസവും പുതുക്കുന്നതിനാൽ Discord പ്രോസസ് ചേർത്താലുടൻ അവ ലഭ്യമാകും.

### കമാൻഡ് ലൈൻ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ഒരു decoy ഉടനടി ആരംഭിക്കുന്നു, ഉദാഹരണത്തിന് `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## സോഴ്സ് കോഡിൽ നിന്ന് നിർമ്മിക്കുക

മുൻവ്യവസ്ഥകൾ: [Node.js](https://nodejs.org) 20+, Visual Studio C++ ബിൽഡ് ടൂളുകളുള്ള സ്ഥിരതയുള്ള [Rust](https://rustup.rs) ടൂൾചെയിൻ (MSVC ടാർഗെറ്റ്), WebView2 റൺടൈം.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ഉപയോഗപ്രദമായ പരിശോധനകൾ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

കുറിപ്പുകൾ: `src-tauri/stub/stub.rs`-ൽ നിന്നുള്ള decoy exe സാധാരണ `rustc` ഉപയോഗിച്ച് `src-tauri/build.rs` വഴി കംപൈൽ ചെയ്ത് ആപ്പിൽ ഉൾപ്പെടുത്തുന്നു. ഒരു സാധാരണ ബ്രൗസറിൽ ഫ്രണ്ട്എൻഡ് പ്രവർത്തിക്കുമ്പോൾ (`npm run dev`) ഒരു ചെറിയ മോക്ക് ബാക്കെൻഡ് (`src/mock.ts`) ഉപയോഗിക്കുന്നു, ഇത് UI വികസനത്തിന് വളരെ സൗകര്യപ്രദമാണ്.

## വിവർത്തനങ്ങൾ

UI സ്ട്രിംഗുകൾ [`src/locales`](../../src/locales)-ൽ സ്ഥിതിചെയ്യുന്നു, ഒരു ഭാഷയ്ക്ക് ഒരു JSON ഫയൽ വീതം (`en.json`, `ru.json`, ...). ഒരു ഭാഷ ചേർക്കുക എന്നാൽ ഒരു ഫയൽ ചേർക്കുക എന്നാണ്; കോഡ് മാറ്റങ്ങൾ ആവശ്യമില്ല. ഫയൽ ഫോർമാറ്റിനും മെഷീൻ വിവർത്തന പ്രോംപ്റ്റിനും വാലിഡേഷൻ സ്ക്രിപ്റ്റിനുമായി [docs/TRANSLATING.md](../TRANSLATING.md) കാണുക. ഈ README-ന്റെ വിവർത്തനങ്ങൾ `docs/i18n/README.<code>.md`-ലേക്ക് ചേർക്കാവുന്നതാണ്.

## പ്രോജക്റ്റ് ഘടന

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## സ്വകാര്യത

- Discord-ന്റെ പൊതുവായ ഡിറ്റക്ഷൻ ലിസ്റ്റ് ഡൗൺലോഡ് ചെയ്യുന്നതിനും (ആദ്യമായി ആരംഭിക്കുമ്പോഴും തുടർന്ന് പരമാവധി ദിവസത്തിൽ ഒരിക്കലും അല്ലെങ്കിൽ നിങ്ങൾ റിഫ്രഷ് ചെയ്യുമ്പോഴും) ഗെയിം ഐക്കണുകളും ആർട്ട്‌വർക്കുകളും Discord-ന്റെ പബ്ലിക് CDN-ൽ നിന്ന് പ്രദർശിപ്പിക്കുന്നതിനും മാത്രമാണ് Decoy ഇന്റർനെറ്റ് ഉപയോഗിക്കുന്നത്.
- ഇത് നിങ്ങളുടെ Discord ടോക്കണോ അക്കൗണ്ട് ഡാറ്റയോ വായിക്കുകയോ സംഭരിക്കുകയോ അയക്കുകയോ ചെയ്യുന്നില്ല, കൂടാതെ ഇത് Discord ക്ലയന്റുമായി ആശയവിനിമയം നടത്തുന്നില്ല.
- ക്രമീകരണങ്ങൾ (പ്രിയപ്പെട്ടവ, ഭാഷ, ദൈർഘ്യങ്ങൾ) ആപ്പിന്റെ WebView സ്റ്റോറേജിൽ ലോക്കലായി സംഭരിക്കപ്പെടുന്നു; ഗെയിം ലിസ്റ്റ് കാഷെയും താൽക്കാലിക decoy ഫയലുകളും `%LOCALAPPDATA%\app.decoy.desktop`-ൽ സൂക്ഷിക്കുന്നു.
- അനലിറ്റിക്‌സ് ഇല്ല, ക്രാഷ് റിപ്പോർട്ടിംഗ് ഇല്ല, അക്കൗണ്ടുകൾ ആവശ്യമില്ല.

## ബാധ്യതാ നിരാകരണം

വ്യക്തിപരവും വിദ്യാഭ്യാസപരവും പരിശോധനാപരവുമായ ആവശ്യങ്ങൾക്കായി Decoy "ഉള്ളതുപോലെ" (as is) നൽകിയിരിക്കുന്നു. പ്രവർത്തിക്കുന്ന ഗെയിം വ്യാജമായി കാണിക്കുന്നത് Discord-ന്റെയോ ഗെയിം പ്രസാധകന്റെയോ സേവന നിബന്ധനകൾ ലംഘിച്ചേക്കാം, കൂടാതെ നിങ്ങളുടെ അക്കൗണ്ടിനെതിരായ നടപടിക്ക് കാരണമായേക്കാം. നിങ്ങൾ ഇത് എങ്ങനെ ഉപയോഗിക്കുന്നു എന്നതിന് നിങ്ങൾ മാത്രമായിരിക്കും പൂർണ്ണ ഉത്തരവാദി. "Discord"-ഉം എല്ലാ ഗെയിം നാമങ്ങളും ലോഗോകളും അതത് ഉടമസ്ഥരുടെ വ്യാപാരമുദ്രകളാണ്, അവ പരാമർശിക്കുന്ന സോഫ്റ്റ്‌വെയറിനെ തിരിച്ചറിയാൻ മാത്രമാണ് ഇവിടെ ഉപയോഗിച്ചിരിക്കുന്നത്.
