Decoy រក្សាដំណើរការតំណាងបណ្តោះអាសន្នគ្មានគ្រោះថ្នាក់ដែលមានផ្ទាំងវិនដូ ឱ្យដំណើរការក្រោមឈ្មោះឯកសារដែលអាចប្រតិបត្តិបាន (executable) នៃហ្គេម ដូច្នេះមុខងាររាវរកហ្គេមរបស់ Discord នឹងបង្ហាញថាអ្នកកំពុងលេងហ្គេមនោះ។ អ្នកមិនចាំបាច់ដំឡើង ឬបើកដំណើរការហ្គេមពិតប្រាកដនោះទេ ដូច្នេះគ្មានទិន្នន័យធំៗណាមួយទន្ទ្រានយកទំហំថាសរបស់អ្នកឡើយ។

វាស្គាល់ **គ្រប់ហ្គេមទាំងអស់ដែល Discord អាចរាវរកបាន** (ប្រហែល ២៥.០០០ ធាតុ) ពីព្រោះវាអានបញ្ជីរាវរកជាសាធារណៈរបស់ Discord ដោយផ្ទាល់ និងរក្សាវាឱ្យទាន់សម័យដោយស្វ័យប្រវត្តិ។

## លក្ខណៈពិសេស

- **អ្វីៗគ្រប់យ៉ាងដែល Discord អាចរាវរកបាន។** បញ្ជីហ្គេមត្រូវបានទាញយកពី endpoint រាវរកជាសាធារណៈរបស់ Discord ដោយរក្សាទុកក្នុងឃ្លាំងសម្ងាត់មូលដ្ឋាន (cache) និងធ្វើបច្ចុប្បន្នភាពរាល់ថ្ងៃ។ ហ្គេមថ្មីៗ និងឯកសារ executable ដែលទើបបន្ថែមនឹងបង្ហាញឡើងដោយខ្លួនឯង។
- **ការស្វែងរកលឿនរហ័ស។** ស្វែងរកភ្លាមៗតាមឈ្មោះហ្គេម ឬឯកសារ executable ក្នុងចំណោមហ្គេមរាប់ពាន់ មានទិដ្ឋភាពជាក្រឡាចត្រង្គ ឬបញ្ជីបង្រួម មានបញ្ជីដែលចូលចិត្ត (favorites) និងជួរ "ថ្មីៗ"។
- **ចុចតែម្តងប៉ុណ្ណោះ។** ជ្រើសរើសហ្គេម ជ្រើសរើសឯកសារ executable (ប្រសិនបើមានច្រើន) កំណត់រយៈពេលដែលត្រូវរក្សាវា ហើយចុចចាប់ផ្តើម។ រង្វង់រាប់ថយក្រោយ និងការជូនដំណឹងនឹងប្រាប់អ្នកនៅពេលអស់ពេលកំណត់។
- **មិនបន្សល់ទុកស្លាកស្នាមអ្វីឡើយ។** decoy មានវត្តមានតែនៅពេលដែលវាកំពុងដំណើរការប៉ុណ្ណោះ៖ ឯកសារ exe តូចមួយត្រូវបានបង្កើតឡើងនៅពេលចាប់ផ្តើម និងត្រូវបានលុបចេញនៅពេលបញ្ឈប់។ អ្វីៗទាំងអស់នឹងត្រូវបញ្ឈប់នៅពេលអ្នកចាកចេញពីកម្មវិធី ហើយកាកសំណល់ដែលនៅសល់ពីការគាំងនឹងត្រូវបោសសម្អាតនៅពេលបើកដំណើរការលើកក្រោយ។
- **ស្ងាត់ល្អ។** ស្ថិតនៅក្នុង system tray គ្មានផ្ទាំងវិនដូ ឬប៊ូតុងនៅលើ taskbar សម្រាប់ដំណើរការ decoy ដោយផ្ទាល់ឡើយ។
- **ការបកប្រែបើកចំហ។** ចំណុចប្រទាក់ត្រូវបានដំណើរការដោយឯកសារ JSON ធម្មតា ដូច្នេះការបន្ថែមភាសាថ្មីគឺត្រូវការតែឯកសារមួយប៉ុណ្ណោះ។ មានរួមបញ្ចូលភាសាអង់គ្លេស និងភាសារុស្ស៊ីរួចជាស្រេច។
- **ឯកជនភាព។** មិនត្រូវការគណនី មិនត្រូវការ token Discord មិនមាន telemetry (ការប្រមូលទិន្នន័យពីចម្ងាយ)។ សូមមើល [ឯកជនភាព](#ឯកជនភាព)។

## ការប្រើប្រាស់

1. បើក **Library** ហើយស្វែងរកហ្គេម ឬចុច `Ctrl` + `K` ពីកន្លែងណាក៏បាន។
2. ចុចលើហ្គេមណាមួយ។ នៅក្នុងបន្ទះខាងស្តាំ ជ្រើសរើសដំណើរការ (process) និងចំនួននាទីដែលត្រូវរក្សាវា (សកម្មភាព Discord ជាធម្មតាទាមទារ 15 នាទី)។
3. ចុច **Start decoy**។ Discord នឹងបង្ហាញហ្គេមបន្ទាប់ពីពីរបីវិនាទី។
4. តាមដានវានៅក្រោម **Running** បញ្ឈប់មួយ ឬទាំងអស់នៅពេលណាក៏បាន ឬគ្រាន់តែទុក Decoy នៅក្នុង system tray។

ហ្គេមដែលធាតុ Discord របស់វាមិនទាន់មានឯកសារ executable នឹងត្រូវបានលាក់តាមលំនាំដើម (ពួកវាមិនអាចរាវរកបានទេ)។ បើកជម្រើស *Show games without exe* ដើម្បីមើលពួកវា។ បញ្ជីនេះត្រូវបានធ្វើបច្ចុប្បន្នភាពរាល់ថ្ងៃ ដូច្នេះពួកវានឹងមានភ្លាមៗនៅពេល Discord បន្ថែមដំណើរការ។

### បន្ទាត់ពាក្យបញ្ជា (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ចាប់ផ្តើមដំណើរការ decoy ភ្លាមៗ ឧទាហរណ៍ `decoy.exe --launch "robloxplayerbeta.exe" 15`។

## បង្កើតពីកូដប្រភព (Build from source)

តម្រូវការជាមុន៖ [Node.js](https://nodejs.org) 20+, កញ្ចប់ឧបករណ៍ [Rust](https://rustup.rs) កំណែស្ថិរភាព (MSVC target) ជាមួយ Visual Studio C++ build tools និង WebView2 runtime។

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ការត្រួតពិនិត្យដែលមានប្រយោជន៍៖

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ចំណាំ៖ ឯកសារ decoy exe ត្រូវបានចងក្រង (compiled) ដោយ `src-tauri/build.rs` ដោយប្រើ `rustc` ធម្មតាចេញពី `src-tauri/stub/stub.rs` ហើយបន្ទាប់មកត្រូវបានបង្កប់ទៅក្នុងកម្មវិធី។ នៅពេលដែល frontend ដំណើរការលើកម្មវិធីរុករកធម្មតា (`npm run dev`) mock backend តូចមួយ (`src/mock.ts`) ត្រូវបានប្រើប្រាស់ ដែលមានភាពងាយស្រួលសម្រាប់ការអភិវឌ្ឍ UI។

Decoy ត្រូវបានផ្តល់ជូន "ដូចដែលមាន" សម្រាប់គោលបំណងផ្ទាល់ខ្លួន ការអប់រំ និងការសាកល្បងតែប៉ុណ្ណោះ។ ការក្លែងបន្លំហ្គេមកំពុងដំណើរការអាចនឹងបំពានលើលក្ខខណ្ឌនៃសេវាកម្មរបស់ Discord ឬរបស់អ្នកបោះពុម្ពផ្សាយហ្គេម ហើយអាចនាំឱ្យមានចំណាត់ការលើគណនីរបស់អ្នក។ អ្នកតែម្នាក់គត់ដែលទទួលខុសត្រូវចំពោះរបៀបដែលអ្នកប្រើប្រាស់វា។ "Discord" ព្រមទាំងឈ្មោះហ្គេម និងរូបសញ្ញាទាំងអស់គឺជាពាណិជ្ជសញ្ញារបស់ម្ចាស់កម្មសិទ្ធិរៀងៗខ្លួន ហើយត្រូវបានប្រើប្រាស់នៅទីនេះដើម្បីកំណត់អត្តសញ្ញាណកម្មវិធីដែលពួកគេសំដៅលើតែប៉ុណ្ណោះ។
