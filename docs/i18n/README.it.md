# Decoy

**Piccoli processi sostitutivi che fanno credere a Discord che un gioco sia in esecuzione.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Libreria di Decoy con giochi recenti e artwork" />

</div>

Decoy mantiene in esecuzione un innocuo processo segnaposto dotato di finestra con il nome dell'eseguibile di un gioco, in modo che il rilevamento dei giochi di Discord ti mostri come se stessi giocando a quel gioco. Non è mai necessario installare né avviare il gioco reale, quindi nulla di pesante occuperà spazio sul disco.

Riconosce **tutti i giochi che Discord può rilevare** (circa 25.000 voci) perché legge l'elenco pubblico di rilevamento di Discord e lo mantiene aggiornato automaticamente.

> [!WARNING]
> Simulare un gioco in esecuzione può violare i Termini di Servizio di Discord e l'utilizzo di Decoy è **a proprio rischio e pericolo**.
> Questo progetto non è affiliato, approvato o collegato a Discord Inc. Vedi [Limitazione di responsabilità](#limitazione-di-responsabilità).

## Funzionalità

- **Tutto ciò che Discord è in grado di rilevare.** L'elenco dei giochi viene scaricato dall'endpoint pubblico di rilevamento di Discord, salvato nella cache locale e aggiornato quotidianamente. I nuovi giochi e gli eseguibili aggiunti di recente compaiono automaticamente.
- **Ricerca sempre al passo.** Ricerca istantanea per nome del gioco o dell'eseguibile tra migliaia di giochi, visualizzazione a griglia o a elenco compatto, preferiti e una riga per i «Recenti».
- **In un solo clic.** Scegli un gioco, seleziona l'eseguibile (se ce n'è più d'uno), imposta per quanto tempo mantenerlo e premi avvia. Un anello con conto alla rovescia e una notifica ti avvisano allo scadere del tempo.
- **Non lascia tracce.** Un decoy esiste solo mentre è in esecuzione: il piccolo file exe viene creato all'avvio ed eliminato all'arresto. Tutto viene interrotto alla chiusura dell'applicazione, e gli eventuali residui di un arresto anomalo vengono ripuliti all'avvio successivo.
- **Discreto.** Risiede nell'area di notifica di sistema (tray), senza finestre né pulsanti nella barra delle applicazioni per i decoy stessi.
- **Traduzioni aperte.** L'interfaccia è gestita tramite semplici file JSON, perciò aggiungere una lingua richiede solo un singolo file. L'inglese e il russo sono già inclusi.
- **Riservato.** Nessun account, nessun token di Discord, nessuna telemetria. Vedi [Privacy](#privacy).

## Come funziona

1. Discord stabilisce che stai giocando a un determinato gioco esaminando i processi in esecuzione sul tuo PC e confrontando i loro nomi di eseguibile con un elenco pubblico (`/api/v9/applications/detectable`).
2. Decoy scarica tale elenco e, per il gioco selezionato, copia un minuscolo programma sostitutivo (circa 120 KB, scritto in Rust e incorporato in Decoy) in una cartella temporanea utilizzando il nome dell'eseguibile presente nell'elenco, ad esempio `.../cod26-cod.exe`.
3. Il programma sostitutivo non fa altro che possedere una finestra di primo livello, posizionata molto al di fuori dello schermo in modo che tu non la veda mai. Discord riconosce un processo solo se possiede una finestra, ed è per questo motivo che un processo del tutto privo di finestre viene ignorato.
4. Entro circa 15 secondi Discord mostra il gioco come attività corrente.
5. Allo scadere del timer o quando premi interrompi, Decoy termina il processo ed elimina il file. Un oggetto job di Windows assicura che i decoy vengano terminati insieme a Decoy, anche in caso di arresto anomalo.

## Installazione

Scegline uno dalla pagina delle [Releases](../../../../releases):

| Download | Per |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Programma di installazione.** Per singolo utente, non richiede privilegi di amministratore, aggiunge una voce al menu Start e un programma di disinstallazione. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabile.** Estrai l'archivio ovunque ed esegui `decoy.exe`. Tutti i dati rimangono nella cartella `data` adiacente, nulla viene scritto nel tuo profilo utente. Elimina la cartella per rimuoverlo. |

Verifica l'integrità del download con `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen potrebbe mostrare un avviso relativo a un autore non riconosciuto poiché le build non sono dotate di firma digitale; scegli *Ulteriori informazioni → Esegui comunque* se ritieni la build attendibile.

Requisiti: Windows 10 o 11 (a 64 bit) con il runtime WebView2 (già incluso in Windows 11 e nei recenti aggiornamenti di Windows 10).

## Utilizzo

1. Apri **Libreria** e cerca un gioco, oppure premi `Ctrl` + `K` da qualsiasi posizione.
2. Fai clic su un gioco. Nel pannello a destra, scegli il processo e per quanti minuti mantenerlo (le attività di Discord richiedono di solito 15 minuti).
3. Premi **Avvia decoy**. Discord mostrerà il gioco dopo alcuni secondi.
4. Monitoralo in **In esecuzione**, arrestane uno o tutti in qualsiasi momento, oppure lascia semplicemente Decoy nell'area di notifica.

I giochi la cui voce su Discord non ha ancora eseguibili sono nascosti per impostazione predefinita (non possono essere rilevati). Attiva *Mostra giochi senza exe* per visualizzarli; l'elenco viene aggiornato quotidianamente, quindi saranno disponibili non appena Discord aggiungerà un processo.

### Riga di comando

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Avvia immediatamente un decoy, ad esempio `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilazione dal codice sorgente

Prerequisiti: [Node.js](https://nodejs.org) 20+, la toolchain stabile di [Rust](https://rustup.rs) (target MSVC) con i Visual Studio C++ Build Tools e il runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Verifiche utili:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Note: l'eseguibile del decoy viene compilato da `src-tauri/build.rs` con il normale `rustc` a partire da `src-tauri/stub/stub.rs` e quindi incorporato nell'applicazione. Quando il frontend viene eseguito in un normale browser (`npm run dev`), viene utilizzato un piccolo backend fittizio (`src/mock.ts`), utile per sviluppare l'interfaccia utente.

## Traduzioni

Le stringhe dell'interfaccia risiedono in [`src/locales`](../../src/locales), un file JSON per ciascuna lingua (`en.json`, `ru.json`, ...). Aggiungere una lingua significa semplicemente aggiungere un file, senza alcuna modifica al codice. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) per il formato del file, un prompt pronto all'uso per la traduzione automatica e lo script di convalida. Le traduzioni di questo README vanno collocate in `docs/i18n/README.<code>.md`.

## Struttura del progetto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacy

- Decoy utilizza la rete esclusivamente per scaricare l'elenco pubblico di rilevamento di Discord (al primo avvio, poi al massimo una volta al giorno o quando premi aggiorna) e, a scopo di visualizzazione, le icone e gli artwork dei giochi dalla CDN pubblica di Discord.
- Non legge, memorizza né invia il tuo token di Discord o dati dell'account, e non interagisce con il client di Discord.
- Le impostazioni (preferiti, lingua, durate) vengono salvate localmente nello storage WebView dell'applicazione; la cache dell'elenco dei giochi e i file temporanei dei decoy risiedono in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nessun dato analitico, nessuna segnalazione di arresti anomali, nessun account.

## Limitazioni note

- Discord può modificare le modalità di rilevamento in qualsiasi momento. Se un decoy cessa di essere riconosciuto, apri una segnalazione (issue).
- Alcune attività richiedono più di un semplice processo in esecuzione (ad esempio trovarsi all'interno di una determinata esperienza su una piattaforma di gioco). Decoy si limita a emulare il processo.
- Le voci senza eseguibili nell'elenco di Discord non possono essere rilevate.
- Talvolta i software di sicurezza possono contrassegnare piccoli eseguibili non firmati che rimangono inattivi in memoria. Il decoy è open source e compilato a partire da `src-tauri/stub/stub.rs`; puoi compilarlo tu stesso.
