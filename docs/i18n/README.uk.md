# Decoy

**Крихітні процеси-заглушки, завдяки яким Discord вважає, що гра запущена.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Бібліотека Decoy з нещодавніми іграми та обкладинками" />

</div>

Decoy підтримує роботу нешкідливого фонового процесу-заглушки з вікном під назвою виконуваного файлу гри, тому функція виявлення ігор у Discord відображає, що ви граєте в цю гру. Вам ніколи не потрібно встановлювати або запускати саму гру, тому нічого важкого не займає місце на вашому диску.

Він знає про **кожну гру, яку здатний виявити Discord** (близько 25 000 записів), оскільки читає власний загальнодоступний список виявлення Discord і самостійно підтримує його в актуальному стані.

> [!WARNING]
> Імітація запущеної гри може суперечити Умовам використання Discord, тому ви використовуєте Decoy **на власний ризик**.
> Цей проєкт не пов'язаний із компанією Discord Inc., не схвалений нею і не має до неї стосунку. Див. [Відмова від відповідальності](#відмова-від-відповідальності).

## Можливості

- **Усе, що здатен виявити Discord.** Список ігор завантажується із загальнодоступного ендпойнта виявлення Discord, кешується локально та оновлюється щодня. Нові ігри та щойно додані виконувані файли з'являються автоматично.
- **Швидкий та зручний пошук.** Миттєвий пошук за назвою гри або виконуваним файлом серед тисяч ігор, подання у вигляді сітки або компактного списку, обране та рядок «Нещодавні».
- **В один клік.** Оберіть гру, виберіть виконуваний файл (якщо їх кілька), вкажіть тривалість і натисніть «Старт». Кільце зворотного відліку та сповіщення повідомлять, коли час вийде.
- **Жодних слідів у системі.** Заглушка існує лише під час роботи: крихітний exe створюється під час запуску та видаляється після зупинки. Усе зупиняється під час закриття програми, а будь-які залишки після збою видаляються під час наступного запуску.
- **Тихий режим.** Працює в системному треї; для самих заглушок немає жодних вікон або кнопок на панелі завдань.
- **Відкритий для перекладу.** Інтерфейс побудований на звичайних файлах JSON, тому для додавання мови достатньо створити один файл. Англійська та російська вже включені.
- **Конфіденційність.** Без облікових записів, без токенів Discord, без телеметрії. Див. [Конфіденційність](#конфіденційність).

## Як це працює

1. Discord визначає, що ви граєте в гру, перевіряючи запущені процеси на вашому ПК і зіставляючи назви їхніх виконуваних файлів із загальнодоступним списком (`/api/v9/applications/detectable`).
2. Decoy завантажує цей список і для обраної гри копіює крихітну програму-заглушку (близько 120 КБ, написану на Rust та вбудовану в Decoy) у тимчасову папку під назвою виконуваного файлу зі списку, наприклад `.../cod26-cod.exe`.
3. Заглушка не робить нічого, окрім створення одного вікна верхнього рівня, розміщеного далеко за межами екрана, щоб ви його не бачили. Discord розпізнає лише процеси, які мають вікно, тому повністю безвіконні процеси ігноруються.
4. Приблизно протягом 15 секунд Discord починає відображати гру як вашу поточну активність.
5. Коли таймер завершується або ви натискаєте кнопку зупинки, Decoy завершує процес і видаляє файл. Об'єкт завдань Windows (job object) гарантує, що заглушки завершать роботу разом із Decoy, навіть якщо станеться збій.

## Встановлення

Оберіть потрібний варіант на сторінці [Releases](../../../../releases):

| Завантаження | Призначення |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Інсталятор.** Встановлюється для поточного користувача, не потребує прав адміністратора, додає пункт у меню «Пуск» та програму видалення. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативна версія.** Розархівуйте будь-куди та запустіть `decoy.exe`. Усі дані зберігаються в папці `data` поруч із ним, нічого не записується у ваш профіль користувача. Для видалення просто видаліть папку. |

Перевірте завантажений файл за допомогою `SHA256SUMS.txt` (`Get-FileHash <file>` у PowerShell).

Windows SmartScreen може попередити про невідомого видавця, оскільки збірки не мають цифрового підпису; виберіть *Докладніше → Виконати в будь-якому разі* (*More info → Run anyway*), якщо довіряєте збірці.

Вимоги: Windows 10 або 11 (64-розрядна) з середовищем виконання WebView2 (вже входить до складу Windows 11 та останніх оновлень Windows 10).

## Використання

1. Відкрийте **Бібліотеку** і знайдіть гру або натисніть `Ctrl` + `K` з будь-якого місця.
2. Натисніть на гру. На панелі праворуч виберіть процес і вкажіть, скільки хвилин його тримати (для завдань у Discord зазвичай потрібно 15).
3. Натисніть **Запустити заглушку**. За кілька секунд Discord покаже гру.
4. Слідкуйте за нею у вкладці **Запущено**, зупиняйте окремі або всі заглушки в будь-який момент чи просто залиште Decoy у треї.

Ігри, для яких у базі Discord ще немає виконуваних файлів, приховані за замовчуванням (їх неможливо виявити). Увімкніть опцію *Показувати без exe*, щоб побачити їх; список оновлюється щодня, тому вони стануть доступними, щойно Discord додасть процес.

### Командний рядок

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Запускає заглушку відразу, наприклад: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Збирання з вихідного коду

Попередні вимоги: [Node.js](https://nodejs.org) 20+, стабільний набір інструментів [Rust](https://rustup.rs) (MSVC target) разом із Visual Studio C++ build tools та середовище виконання WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Корисні перевірки:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Примітки: виконуваний файл заглушки компілюється за допомогою `src-tauri/build.rs` через звичайний `rustc` із `src-tauri/stub/stub.rs` і потім вбудовується в додаток. Коли фронтенд запускається у звичайному браузері (`npm run dev`), використовується невеликий mock-бекенд (`src/mock.ts`), що зручно для роботи над інтерфейсом.

## Переклади

Рядки інтерфейсу знаходяться у [`src/locales`](../../src/locales), по одному файлу JSON на кожну мову (`en.json`, `ru.json`, ...). Додавання нової мови — це просто додавання файлу, без змін у коді. Див. [docs/TRANSLATING.md](../TRANSLATING.md), де описано формат файлу, наведено готовий промпт для машинного перекладу та скрипт валідації. Переклади цього README зберігаються в `docs/i18n/README.<code>.md`.

## Структура проєкту

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Конфіденційність

- Decoy використовує мережу лише для завантаження загальнодоступного списку виявлення Discord (під час першого запуску, далі — щонайбільше раз на день або коли ви натискаєте «Оновити»), а також для відображення іконок та обкладинок ігор із загальнодоступної CDN Discord.
- Програма не зчитує, не зберігає та не надсилає ваш токен Discord або будь-які дані облікового запису, а також не взаємодіє з клієнтом Discord.
- Налаштування (обране, мова, тривалість) зберігаються локально у сховищі WebView додатка; кеш списку ігор і тимчасові файли заглушок розміщуються в `%LOCALAPPDATA%\app.decoy.desktop`.
- Без аналітики, без звітів про збої, без облікових записів.

## Відомі обмеження

- Discord може змінити спосіб виявлення в будь-який час. Якщо заглушка перестає розпізнаватися, будь ласка, створіть issue.
- Деякі активності вимагають більшого, ніж просто запущений процес (наприклад, перебування в певному плейсі ігрової платформи). Decoy лише імітує процес.
- Записи без виконуваних файлів у списку Discord не можуть бути виявлені.
- Антивірусне програмне забезпечення іноді може реагувати на невеликі непідписані виконувані файли, що бездіяльно перебувають у пам'яті. Заглушка має відкритий вихідний код і збирається з `src-tauri/stub/stub.rs`; ви можете скомпілювати її самостійно.

## Відмова від відповідальності

Decoy надається «як є» для особистих, освітніх та ознайомлювальних цілей. Імітація запущеної гри може порушувати Умови використання Discord або видавця гри та може призвести до санкцій щодо вашого облікового запису. Ви несете одноосібну відповідальність за те, як використовуєте цю програму. «Discord», а також усі назви ігор та логотипи є товарними знаками відповідних власників і використовуються тут виключно для ідентифікації відповідного програмного забезпечення.
