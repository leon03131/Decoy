# Decoy

**Discord にゲームが起動中であると認識させる極小のダミープロセス。**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="最近のゲームとアートワークが表示された Decoy ライブラリ" />

</div>

Decoy は、ゲームの実行ファイル名で無害なウィンドウ付きプレースホルダープロセスを動作させ、Discord のゲーム検出機能にそのゲームをプレイ中と認識させます。本物のゲームをインストールしたり起動したりする必要は一切ないため、ストレージ容量を圧迫することもありません。

Discord 自身の公開検出リストを読み込み、自動的に最新の状態へ更新するため、**Discord が検出可能なすべてのゲーム**（約 25,000 タイトル）に対応しています。

> [!WARNING]
> ゲームの起動状態を偽装することは Discord の利用規約に抵触する可能性があり、Decoy の使用は**自己責任**となります。
> 本プロジェクトは Discord Inc. と提携、承認、または関連するものではありません。[免責事項](#免責事項)をご覧ください。

## 機能

- **Discord が検出可能なすべてに対応。** ゲームリストは Discord の公開検出エンドポイントからダウンロードされ、ローカルにキャッシュされて毎日自動更新されます。新しいゲームや新しく追加された実行ファイルも自動で反映されます。
- **高速な検索。** 数千タイトルの中からゲーム名や実行ファイル名で即座にインクリメンタル検索できます。グリッド表示またはコンパクトなリスト表示、お気に入り機能、「最近」使った行も備えています。
- **ワンクリック操作。** ゲームを選び、実行ファイルを選択し（複数ある場合）、維持する時間を選んでスタートを押すだけです。カウントダウンリングと通知で残り時間が終了したことをお知らせします。
- **痕跡を残さない。** ダミー（decoy）は実行中のみ存在します。極小の exe ファイルが起動時に作成され、停止時に削除されます。アプリ終了時にはすべて停止し、クラッシュによる残留ファイルも次回起動時に自動クリーンアップされます。
- **静かに動作。** システムトレイに常駐し、ダミープロセス自体のウィンドウやタスクバーボタンは一切表示されません。
- **オープンな翻訳設計。** インターフェースはシンプルな JSON ファイルで管理されており、ファイルを追加するだけで新しい言語に対応できます。初期状態で英語とロシア語が含まれています。
- **プライバシー重視。** アカウント登録不要、Discord トークン不要、テレメトリなし。[プライバシー](#プライバシー)をご覧ください。

## 仕組み

1. Discord は、PC 上で実行されているプロセスを確認し、その実行ファイル名を公開リスト（`/api/v9/applications/detectable`）と照合することで、ゲームをプレイ中かどうかを判定します。
2. Decoy はそのリストをダウンロードし、選択したゲームに応じて、極小のダミープログラム（約 120 KB、Rust 製で Decoy に内蔵）をリスト内の実行ファイル名（例: `.../cod26-cod.exe`）として一時フォルダーにコピーします。
3. このダミープログラムは、画面外のはるか遠くに配置された最上位ウィンドウを 1 つ保持する以外には何もしません。Discord はウィンドウを持つプロセスのみを認識するため、完全にウィンドウのないプロセスは無視されてしまうからです。
4. およそ 15 秒以内に、Discord 上でそのゲームが現在のアクティビティとして表示されます。
5. タイマーが終了するか停止ボタンを押すと、Decoy はプロセスを終了してファイルを削除します。Windows のジョブオブジェクト（Job Object）により、万が一 Decoy がクラッシュした場合でも、ダミープロセスは確実に一緒に終了します。

## インストール

[Releases](../../../../releases) ページからいずれかを選択してください:

| ダウンロード | 用途 |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **インストーラー。** ユーザー単位、管理者権限不要、スタートメニューへの登録とアンインストーラーが含まれます。 |
| `Decoy_x.y.z_x64-portable.zip` | **ポータブル版。** 任意の場所に解凍して `decoy.exe` を実行します。すべてのデータは実行ファイルと同じ場所にある `data` フォルダーに保存され、ユーザープロファイルには何も書き込まれません。削除する際はフォルダーごと削除してください。 |

ダウンロードしたファイルは `SHA256SUMS.txt`（PowerShell の `Get-FileHash <file>`）で検証できます。

ビルドにはコード署名が行われていないため、Windows SmartScreen から発行元不明の警告が表示される場合があります。ビルドを信頼する場合は、*詳細情報 → 実行* を選択してください。

必要環境: Windows 10 または 11（64 ビット）、WebView2 ランタイム（Windows 11 および近年の Windows 10 アップデートにはすでに標準搭載されています）。

## 使い方

1. **ライブラリ** を開いてゲームを検索するか、任意の場所で `Ctrl` + `K` を押します。
2. ゲームをクリックします。右側のパネルでプロセスと維持する時間（分）を選択します（Discord のアクティビティクエスト等は通常 15 分が要求されます）。
3. **Start decoy** を押します。数秒後に Discord 上にゲームが表示されます。
4. **実行中** で状態を確認できます。いつでも個別または一括で停止でき、Decoy をトレイに常駐させたままにしておくことも可能です。

Discord の登録情報にまだ実行ファイルが存在しないゲームは、デフォルトで非表示になっています（検出できないため）。これらを表示するには *exe のないゲームを表示* をオンにします。リストは毎日更新されるため、Discord 側にプロセスが追加され次第利用可能になります。

### コマンドライン

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ダミーを直接起動します（例: `decoy.exe --launch "robloxplayerbeta.exe" 15`）。

## ソースからビルド

前提条件: [Node.js](https://nodejs.org) 20+、Visual Studio C++ ビルドツールを含む安定版 [Rust](https://rustup.rs) ツールチェーン（MSVC ターゲット）、および WebView2 ランタイム。

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

便利なチェックコマンド:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

備考: decoy exe は `src-tauri/build.rs` 内で `src-tauri/stub/stub.rs` から通常の `rustc` でコンパイルされ、アプリ本体に埋め込まれます。フロントエンドを通常のブラウザで実行する場合（`npm run dev`）、軽量なモックバックエンド（`src/mock.ts`）が使用されるため、UI の開発に便利です。

## 翻訳

UI の文字列は [`src/locales`](../../src/locales) に配置されており、言語ごとに 1 つの JSON ファイル（`en.json`、`ru.json` など）で管理されています。
コードの変更は不要で、ファイルを追加するだけで新しい言語を追加できます。ファイル形式、機械翻訳用のプロンプト、および検証スクリプトについては [docs/TRANSLATING.md](../TRANSLATING.md) をご覧ください。本 README の翻訳は `docs/i18n/README.<code>.md` に配置します。

## プロジェクト構成

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## プライバシー

- Decoy がネットワークを使用するのは、Discord の公開検出リストのダウンロード（初回起動時、以降は最大 1 日 1 回または更新ボタン押下時）と、表示用のゲームアイコンおよびアートワークを Discord の公開 CDN から取得するときのみです。
- Discord トークンやアカウントデータの読み取り、保存、送信は一切行わず、Discord クライアントとの通信も行いません。
- 設定（お気に入り、言語、時間）はアプリの WebView ローカルストレージに保存されます。ゲームリストのキャッシュと一時的なダミーファイルは `%LOCALAPPDATA%\app.decoy.desktop` に保存されます。
- アナリティクスなし、クラッシュレポートなし、アカウント登録不要。

## 既知の制限事項

- Discord は検出の仕組みをいつでも変更する可能性があります。ダミーが認識されなくなった場合は、Issue を作成してお知らせください。
- 一部のアクティビティでは、プロセスの実行以上の条件（例: ゲームプラットフォーム内の特定のエクスペリエンスやワールドに入っていることなど）が必要となる場合があります。Decoy はプロセスのみを模倣します。
- Discord のリストに実行ファイルが登録されていないゲームは検出できません。
- メモリ上でアイドル状態にある小さな未署名の実行ファイルは、セキュリティソフトによって誤検知されることがあります。ダミーはオープンソースであり `src-tauri/stub/stub.rs` からビルドされています。必要に応じてご自身でコンパイルすることも可能です。
