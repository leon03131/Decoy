# Decoy

**Discord-то наадан ябуулагдажа байна гэжэ харуулдаг бишыхан орлуулагч процессууд.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Һүүлшын нааданууд болон ковер зурагууд бүхы Decoy номой сан" />

</div>

Decoy нааданай ажаллаха файлай нэрээр (exe) хор хүнөөлгүй, сонхо бүхы орлуулагш процессые ажаллажа байха байдалаар баридаг тула Discord-ой наадан элирүүлхэ систем таниие тэрэ наада наадажа байна гэжэ тоосодог. Танд жэнхэни нааданиие һуурилуулха гү, али ябуулха хэрэггүй, тиимэһээ диск дээрэтнай ямаршье үлүү хүндэ файл хадагалагдахагүй.

Энэнь Discord-ой ниитын элирүүлэлтын дансые уншажа, өөрөө автоматаар шэнэдхэжэ байдаг тула **Discord-ой элирүүлжэ шадаха бүхы наадануудые** (багсаагаар 25 000 бэшэлгэ) мэдэнэ.

> [!WARNING]
> Ябуулагдажа байһан нааданиие хуурмаглан харуулха явдал Discord-ой Хэрэглэхэ нүхэсэлдэ харшалжа болозошгүй ба та Decoy-е **өөрын эрсдэлээр** хэрэглэнэ гээшэ.
> Энэ түсэл Discord Inc. компанитай ямаршье холбоогүй, дэмжэгдээгүй ба хамаадалгүй юм. [Харюусалгаһаа татгалзалга](#харюусалгаһаа-татгалзалга) бүлэгые үзэгты.

## Боломжонууд

- **Discord-ой элирүүлжэ шадаха бүхы юумэн.** Наадануудай данса Discord-ой ниитын серверһээ татагдан, локаль байдалаар хадагалагдажа үдэр бүри шэнэдхэгдэнэ. Шэнэ нааданууд болон шэнээр нэмэгдэһэн ажаллаха файлууд өөһэдөө бии боложо харагдана.
- **Түргэн бэдэрэгшэ.** Мянга мянган наадануудай дундаһаа нэрээр гү, али exe-гээр доронь бэдэрхэ, хабтангууд гү, али хуряамгай дансаар хараха, шэлэгдэмэлнүүд ба «Һүүлшын» мүр.
- **Нэгэ даралга.** Нааданаа шэлэгты, ажаллаха файлыень заагты (хэрбээ хэд хэдэн байбал), тэрэниие хэды минут барихаяа тохируулаад «эхилүүлхэ» дарагты. Тоололтын сахирга болон мэдэгдэл саг дүүрэхэ үедэ танда дуулгаха.
- **Үлэгдэл үлөөхэгүй.** Decoy зүбхэн ажаллажа байха үедөө лэ оршоно: бишыхан exe эхилхэдэ бии болоод, зогсооходо усадхагдана. Гарахада бүгэдэ зогсоно, харин программын гэнтэ хаагдаһан үлэгдэлнүүдые дараашын ябуулга дээрэ сэбэрлэнэ.
- **Аниргүй.** Системиин трей соо оршоно, decoy процессуудта зорюулһан тусдаа сонхо гү, али taskbar дээрэ тобшолуур байхагүй.
- **Нээлтэтэй оршуулганууд.** Интерфейс нь энгын JSON файлуудаар хүдэлдэг тула шэнэ хэлэ нэмэхэдэ гансал файл хэрэгтэй. Англи болон Ород хэлэнүүд багтаагдаһан.
- **Нюусалал.** Бүридхэл үгы, Discord токен ашаглахагүй, телеметри үгы. [Нюусалал](#нюусалал) бүлэгые үзэгты.

## Хэрхэн ажалладаг бэ

1. Discord танай компьютер дээрэ ажаллажа байгаа процессуудые шалгажа, тэдэнэй exe нэрэнүүдые ниитын дансатай (`/api/v9/applications/detectable`) харисуулха замаар таниие наада наадажа байна гэжэ үзэдэг.
2. Decoy тэрэ дансые татажа абаад, танай шэлэһэн нааданда зорюулжа бишыхан орлуулагш программые (ойролсоогоор 120 КБ, Rust дээрэ бэшэгдэһэн ба Decoy дотор багтаагдаһан) данса доторхи exe нэрээр түр зуурын хабтаһан соо хуулдаг, жэшээнь `.../cod26-cod.exe`.
3. Орлуулагш программ нь танда харагдахагүйгөөр дэлгэсэй гадуур оршохо дээдэ зэргын ганса сонхые ажаллахаһаа бэшэ юуншье хэхэгүй. Discord гансал сонхотой процессуудые танидаг ба огто сонхогүй процессуудые анхардаггүй ушар иимэ бүтэсэтэй юм.
4. Ойролсоогоор 15 секундын дотор Discord тэрэ нааданиие танай мүнөөнэй эдэбхитэй ажаллалга гэжэ харуулна.
5. Саг дүүрэхэдэ гү, али та зогсоохо дарахада Decoy процессые дуусгажа, файлые усадхана. Windows-ой хүдэлмэриин объект (job object) нь Decoy унаһаншье һаа decoy процессууд суг хаагдахые баталгаажуулдаг.

## Һуурилуулга

[Хубилбаринууд](../../../../releases) хуудаһанһаа шэлэгты:

| Татаха | Зориг |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Һуурилуулагш программ.** Нэгэ хэрэглэгшэдэ зорюулагдаһан, админ эрхэ эрилгүй, Эхилхэ менюдэ холбооһон болон усадхагшые нэмэнэ. |
| `Decoy_x.y.z_x64-portable.zip` | **Зөөбэриин хубилбари.** Хаанашье хамаагүй задалаад `decoy.exe` ябуулагты. Бүхы мэдээлэл хажууда байһан `data` хабтаһан соо хадагалагдаха ба хэрэглэгшын системдэ юуншье бэшэгдэхэгүй. Усадхахадаа хабтаһыень арилгахада хангалтатай. |

Татажа абаһан файлаа `SHA256SUMS.txt`-ээр баталгаажуулагты (PowerShell дээрэ `Get-FileHash <file>`).

Бүтээсэдэ тоон гар бэшэг табигдаагүй тула Windows SmartScreen үл мэдэгдэхэ хүгжүүлэгшын талаар һэрэмжэлүүлжэ боложо болзошгүй; хэрбээ та энэ бүтээсэдэ этигэжэ байгаа һаа *Дэлгэрэнгүй мэдээлэл → Ямаршье һаа ажаллаха* (More info → Run anyway) шэлэгты.

Табигдаха эрилтэнүүд: Windows 10 гү, али 11 (64-бит), WebView2 runtime (Windows 11 болон һүүлшын үеын Windows 10 шэнэдхэлнүүдтэ аль хэдийнэ багтаһан байдаг).

## Хэрэглэлгэ

1. **Номой сан** нээгээд наадан бэдэрэгты, гү, али хаанаһаашье `Ctrl` + `K` дарагты.
2. Наадан дээрэ дарагты. Баруун талада байһан самбарта процессые шэлэжэ, хэды минут ябуулхаяа тохируулагты (Discord даабаринуудта ехэнхидээ 15 минут хэрэгтэй байдаг).
3. **Decoy эхилүүлхэ** дарагты. Хэдэн секундын дараа Discord нааданиие харуулха болоно.
4. **Ябуулагдаһан** цонхоһоо хинажа, аль нэгэнииень гү, али бүгэдыень дуратай сагтаа зогсоожо болоно, эсэбэл Decoy-е зүгээр лэ систем трей соо үлөөгты.

Discord-ой дансада одоодоо exe файлгүй байгаа нааданууд үндэһэн байдалаараа нюугдаһан байдаг (тэдэниие элирүүлхэ аргагүй). Тэдэниие харахын тулада *Exe-гүй наадануудые харуулха* асаагты; данса үдэр бүри шэнэдхэгдэдэг тула Discord процесс нэмэмэс тэдэ боломжотой болоно.

### Тушаалай мүр

```
decoy.exe --launch "<Discord дансаһаа абаһан ажаллаха файлай харгы>" [минут]
```

Decoy-е шууд ябуулна, жэшээнь `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Эхи кодһоо суглуулха

Уридшалан табигдаха эрилтэнүүд: [Node.js](https://nodejs.org) 20+, Visual Studio C++ суглуулалтын зэмсэгүүд бүхы тогтомол [Rust](https://rustup.rs) хэрэгсэлнүүдэй багса (MSVC зорилто), болон WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload бүхы хүгжүүлэлтын горимдо ажаллаха
npm run tauri build    # src-tauri/target/release/bundle/nsis хабтаһан соо һуурилуулагшые бүтээхэ
```

Хэрэгтэй шалгалтууд:

```bash
npm run check-locales  # оршуулгын файл бүриие ru.json-той харисуулан шалгаха
npx tsc --noEmit       # фронтендай түрэлые шалгаха (type-check)
cargo check --manifest-path src-tauri/Cargo.toml
```

Тэмдэглэл: decoy exe-е `src-tauri/build.rs` нь `src-tauri/stub/stub.rs`-һээ энгын `rustc`-ээр хүрэбүүлжэ, удаань программа соо шингээдэг. Фронтенд энгын браузер дээрэ ажаллаха үедэ (`npm run dev`) бишыхан mock бэкенд (`src/mock.ts`) хэрэглэгдэдэг бөгөөд энэнь UI дээрэ хүдэлхэдэ аятайхан байдаг.

## Оршуулга

Интерфейсэй текстүүд [`src/locales`](../../src/locales) хабтаһан соо хэлэн бүридэ нэгэ JSON файл хэлбэрээр байрлана (`en.json`, `ru.json`, ...).
Шэнэ хэлэ нэмэхэдэ ямаршье кодой хубилалтагүйгөөр гансал файл нэмэхэ хэрэгтэй. Файлай формат, машинаар оршуулхада бэлэн заабари болон шалгаха скриптые [docs/TRANSLATING.md](../TRANSLATING.md)-һээ үзэгты. Энэ README-н оршуулганууд `docs/i18n/README.<code>.md` хабтаһан соо хадагалагдана.

## Түсэлэй бүтэсэ

```
src/                    React + TypeScript фронтенд
  components/           Номой сан, дэлгэрэнгүй самбар, тохиргоо, ...
  locales/              оршуулгын файлууд (хэлэн тус бүридэ нэгэ JSON)
  i18n-core.ts          хэлэ ашаалха болон бэдэрхэ логик
  store.ts              программын байдал (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            наадануудай мэдээлэлэй сан, decoy процессууд, систем трей
  stub/stub.rs          һуулгагдаха орлуулагш программ
scripts/                туһаламжын скриптүүд (оршуулгые шалгаха)
docs/                   оршуулгын заабари, скриншотууд
```

## Нюусалал

- Decoy һүлжээе зүбхэн Discord-ой ниитын элирүүлэлтын дансые татажа абахада (анханай эхилэлгэ дээрэ, дараань үдэртөө эгээн олондоо нэгэ удаа гү, али та шэнэдхэхэ тобшо дараха үедэ) болон Discord-ой ниитын CDN-һээ нааданай тэмдэг, ковер зурагые харуулхада лэ ашагладаг.
- Энэ нь танай Discord токен гү, али дансанай ямаршье мэдээлэлые уншадаггүй, хадагалдаггүй, дамжуулдаггүй ба Discord клиенттэй сэхэ холбогдодоггүй.
- Тохиргоо (шэлэгдэмэл нааданууд, хэлэн, сагай хугасаа) нь программын WebView хадагалалтада дотооддоо хадагалагдана; наадануудай дансын кэш болон түр зуурын decoy файлууд `%LOCALAPPDATA%\app.decoy.desktop` хабтаһан соо байрлана.
- Аналитик үгы, алдуу дуулгаха үгы, бүридхэл байхагүй.

## Мэдэгдэжэ байһан хизаарлалтанууд

- Discord наадан элирүүлхэ ажаллалгаяа дуратай үедөө хубилгажа болоно. Хэрбээ decoy элирүүлэгдэхээ болибол issue нээгты.
- Зарим ажаллалгада зүбхэн ябуулагдажа байһан процессһоо үлүү юумэн шаардагдадаг (жэшээнь нааданай платформын тусхай сервер, таһалга соо байха). Decoy зүбхэн процессые лэ дуурайдаг.
- Discord-ой данса соо exe файлгүй байгаа бэшэлгэнүүдые элирүүлхэ аргагүй.
- Аюулгүй байдалай программууд (антивирус) һанаан соо һула байһан бишыхан, баталамжагүй exe файлуудые заримдаа һэжэглэжэ болозошгүй. Decoy нь нээлтэтэй эхи кодтой бөгөөд `src-tauri/stub/stub.rs`-һээ суглуулагдадаг; та үүниие өөрөө суглуулжа болоно.

## Хуби нэмэри оруулалга

Алдаануудай тухай дуулгаха, шэнэ һанаа болон оршуулгануудые баяртайгаар угтан абана. Эхилээд [CONTRIBUTING.md](../../CONTRIBUTING.md)-тэй танилсагты.

## Харюусалгаһаа татгалзалга

Decoy нь хубиин, һуралсалай болон туршалтын зорилгоор «байгаа байдалаараа» (as is) хангагдана. Ябуулагдажа байһан нааданиие хуурмаглан дуурайлгаха явдал Discord гү, али наада нийтэлэгшын Хэрэглэхэ нүхэсэлдэ харшалжа болозошгүй ба танай дансанда арга хэмжээ абаха эрсдэлтэй. Та үүниие хэрхэн хэрэглэхэдээ гансал өөрөө бүрин харюусалга хүлеэнэ. «Discord» болон бүхы нааданай нэрэ, лого нь өөһэдын эзэмшэгшэдэй худалдаанай тэмдэгүүд бөгөөд эндэ зүбхэн тэрэ программын хангамжые таниха зорилгоор хэрэглэгдэнэ.
