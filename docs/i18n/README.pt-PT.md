# Decoy

**Processos substitutos minúsculos que fazem o Discord pensar que um jogo está em execução.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca do Decoy com jogos recentes e ilustrações" />

</div>

O Decoy mantém em execução um processo fictício inofensivo com janela sob o nome do executável de um jogo, para que a deteção de jogos do Discord indique que está a jogar esse jogo. Nunca precisa de instalar ou iniciar o jogo real, pelo que nada pesado ocupa espaço no seu disco.

Conhece **todos os jogos que o Discord consegue detetar** (cerca de 25.000 entradas), uma vez que lê a própria lista pública de deteção do Discord e mantém-na atualizada de forma autónoma.

> [!WARNING]
> Simular um jogo em execução pode violar os Termos de Serviço do Discord e utiliza o Decoy **por sua conta e risco**.
> Este projeto não é afiliado, recomendado ou associado à Discord Inc. Consulte o [Aviso Legal](#aviso-legal).

## Funcionalidades

- **Tudo o que o Discord consegue detetar.** A lista de jogos é descarregada do endpoint público de deteção do Discord, guardada em cache localmente e atualizada diariamente. Novos jogos e executáveis adicionados recentemente aparecem automaticamente.
- **Pesquisa que acompanha o ritmo.** Pesquisa instantânea por nome do jogo ou executável entre milhares de jogos, vista em grelha ou lista compacta, favoritos e uma linha de "Recentes".
- **Um clique.** Escolha um jogo, selecione o executável (se existirem vários), defina durante quanto tempo o quer manter e clique em iniciar. Um anel de contagem decrescente e uma notificação avisam quando o tempo terminar.
- **Não deixa vestígios.** Um decoy só existe enquanto está em execução: o pequeno exe é criado ao iniciar e eliminado ao parar. Tudo é terminado quando fecha a aplicação, e resíduos de encerramentos inesperados são limpos no arranque seguinte.
- **Silencioso.** Permanece na área de notificação do sistema, sem janelas ou botões na barra de tarefas para os próprios decoys.
- **Traduções abertas.** A interface é baseada em ficheiros JSON simples, pelo que adicionar um idioma requer apenas um ficheiro. O inglês e o russo estão incluídos.
- **Privado.** Sem conta, sem token do Discord, sem telemetria. Consulte [Privacidade](#privacidade).

## Como funciona

1. O Discord determina que está a jogar através da análise dos processos em execução no seu PC e da comparação dos respetivos nomes de executável com uma lista pública (`/api/v9/applications/detectable`).
2. O Decoy descarrega essa lista e, para o jogo escolhido, copia um pequeno programa substituto (cerca de 120 KB, escrito em Rust e incorporado no Decoy) para uma pasta temporária utilizando o nome de executável da lista, por exemplo `.../cod26-cod.exe`.
3. O substituto não faz nada além de manter uma janela de nível superior posicionada bem fora do ecrã para que nunca a veja. O Discord só reconhece processos que possuem uma janela, razão pela qual um processo totalmente sem janela é ignorado.
4. Em cerca de 15 segundos, o Discord apresentará o jogo como a sua atividade atual.
5. Quando o temporizador termina ou clica em parar, o Decoy termina o processo e elimina o ficheiro. Um job object do Windows garante que os decoys são terminados juntamente com o Decoy, mesmo em caso de falha.

## Instalação

Escolha uma opção na página de [Lançamentos](../../../../releases):

| Transferência | Para |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por utilizador, sem necessidade de privilégios de administrador, adiciona uma entrada no menu Iniciar e um desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portátil.** Descompacte em qualquer pasta e execute o `decoy.exe`. Todos os dados permanecem na pasta `data` junto ao executável, nada é gravado no seu perfil de utilizador. Basta eliminar a pasta para o remover. |

Verifique a transferência com o ficheiro `SHA256SUMS.txt` (`Get-FileHash <ficheiro>` no PowerShell).

O Windows SmartScreen pode alertar sobre um publicador não reconhecido porque os ficheiros compilados não têm assinatura digital; escolha *Mais informações → Executar de qualquer modo* caso confie na compilação.

Requisitos: Windows 10 ou 11 (64 bits) com o WebView2 runtime (já incluído no Windows 11 e em atualizações recentes do Windows 10).

## Como utilizar

1. Abra a **Biblioteca** e pesquise por um jogo, ou prima `Ctrl` + `K` a partir de qualquer ecrã.
2. Clique num jogo. No painel à direita, escolha o processo e quantos minutos deseja mantê-lo (as atividades do Discord normalmente pedem 15).
3. Prima **Iniciar decoy**. O Discord apresentará o jogo após alguns segundos.
4. Acompanhe em **Em execução**, pare um ou todos a qualquer altura, ou simplesmente deixe o Decoy na área de notificação.

Os jogos cuja entrada no Discord ainda não tem executáveis associados ficam ocultos por predefinição (não podem ser detetados). Ative *Mostrar jogos sem exe* para os ver; a lista é atualizada diariamente, pelo que ficarão disponíveis assim que o Discord adicionar um processo.

### Linha de comandos

```
decoy.exe --launch "<caminho do executável da lista do Discord>" [minutos]
```

Inicia um decoy de imediato, por exemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar a partir do código-fonte

Pré-requisitos: [Node.js](https://nodejs.org) 20+, toolchain estável de [Rust](https://rustup.rs) (alvo MSVC) com as ferramentas de compilação C++ do Visual Studio e o WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # executar em modo de desenvolvimento com hot reload
npm run tauri build    # gerar o instalador em src-tauri/target/release/bundle/nsis
```

Verificações úteis:

```bash
npm run check-locales  # validar todos os ficheiros de tradução em relação a ru.json
npx tsc --noEmit       # verificar os tipos do frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notas: o executável do decoy é compilado pelo `src-tauri/build.rs` utilizando `rustc` padrão a partir de `src-tauri/stub/stub.rs` e depois incorporado na aplicação. Quando o frontend corre num navegador convencional (`npm run dev`), é utilizado um pequeno backend de simulação (`src/mock.ts`), muito prático para trabalhar na interface.

## Traduções

Os textos da interface encontram-se em [`src/locales`](../../src/locales), um ficheiro JSON por idioma (`en.json`, `ru.json`, ...).
Adicionar um idioma resume-se a adicionar um ficheiro; sem alterações no código. Consulte [docs/TRANSLATING.md](../TRANSLATING.md) para consultar o formato do ficheiro, um prompt pronto para tradução automática e o script de validação. As traduções deste README são guardadas em `docs/i18n/README.<code>.md`.

## Estrutura do projeto

```
src/                    Frontend em React + TypeScript
  components/           Biblioteca, painel de detalhes, definições, ...
  locales/              ficheiros de tradução (um JSON por idioma)
  i18n-core.ts          carregamento e consulta de idiomas
  store.ts              estado da aplicação (zustand)
src-tauri/              Backend em Rust (Tauri 2)
  src/lib.rs            base de dados de jogos, processos decoy, área de notificação
  stub/stub.rs          o programa substituto que é incorporado
scripts/                scripts auxiliares (validação de idiomas)
docs/                   guia de tradução, capturas de ecrã
```

## Privacidade

- O Decoy apenas utiliza a ligação de rede para descarregar a lista pública de deteção do Discord (no primeiro arranque e, posteriormente, no máximo uma vez por dia ou ao clicar em atualizar) e, para visualização, ícones de jogos e ilustrações da CDN pública do Discord.
- Não lê, não armazena nem envia o seu token do Discord nem quaisquer dados da sua conta, e não comunica com o cliente do Discord.
- As definições (favoritos, idioma, durações) são armazenadas localmente no armazenamento WebView da aplicação; a cache da lista de jogos e os ficheiros temporários dos decoys ficam guardados em `%LOCALAPPDATA%\app.decoy.desktop`.
- Sem telemetria, sem relatórios de falhas, sem contas de utilizador.

## Limitações conhecidas

- O Discord pode alterar o método de deteção a qualquer momento. Se um decoy deixar de ser reconhecido, agradecemos a abertura de um issue.
- Algumas atividades exigem mais do que apenas um processo em execução (por exemplo, estar dentro de uma experiência específica numa plataforma de jogos). O Decoy apenas simula o processo.
- Entradas sem executáveis na lista do Discord não podem ser detetadas.
- O software de segurança pode, por vezes, sinalizar pequenos executáveis não assinados que permanecem inativos em memória. O decoy é de código aberto e compilado a partir de `src-tauri/stub/stub.rs`; pode compilá-lo você mesmo.
