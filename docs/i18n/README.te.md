# Decoy

**Discord లో గేమ్ నడుస్తున్నట్లు కనిపించేలా చేసే చిన్న స్టాండ్-ఇన్ ప్రాసెస్‌లు.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="ఇటీవలి గేమ్‌లు మరియు ఆర్ట్‌వర్క్‌తో Decoy లైబ్రరీ" />

</div>

గేమ్ యొక్క ఎగ్జిక్యూటబుల్ పేరుతో హానిచేయని, విండో ఉన్న ప్లేస్‌హోల్డర్ ప్రాసెస్‌ను Decoy నడుపుతూ ఉంచుతుంది, తద్వారా Discord గేమ్ డిటెక్షన్ మీరు ఆ గేమ్‌ను ఆడుతున్నట్లు చూపిస్తుంది. మీరు ఎప్పుడూ నిజమైన గేమ్‌ను ఇన్‌స్టాల్ చేయవలసిన లేదా లాంచ్ చేయవలసిన అవసరం లేదు, కాబట్టి మీ డిస్క్‌లో ఎటువంటి పెద్ద ఫైల్స్ ఉండవు.

Discord గుర్తించగలిగే **ప్రతి గేమ్ గురించి ఇది తెలుసుకుంటుంది** (సుమారు 25,000 ఎంట్రీలు), ఎందుకంటే ఇది Discord యొక్క స్వంత పబ్లిక్ డిటెక్షన్ జాబితాను చదువుతుంది మరియు దానికదే అప్‌డేట్ చేసుకుంటూ ఉంటుంది.

> [!WARNING]
> నడుస్తున్న గేమ్‌ను అనుకరించడం Discord సేవా నిబంధనలకు (Terms of Service) విరుద్ధం కావచ్చు మరియు మీరు Decoy ని **మీ స్వంత రిస్క్‌తో** ఉపయోగిస్తున్నారు.
> ఈ ప్రాజెక్ట్ Discord Inc. తో అనుబంధించబడలేదు, ఆమోదించబడలేదు లేదా అనుసంధానించబడలేదు. [నిరాకరణ](#నిరాకరణ) చూడండి.

## ఫీచర్‌లు

- **Discord గుర్తించగలిగే ప్రతి ఒక్కటీ.** గేమ్ జాబితా Discord పబ్లిక్ డిటెక్షన్ ఎండ్‌పాయింట్ నుండి డౌన్‌లోడ్ చేయబడుతుంది, స్థానికంగా కాష్ చేయబడుతుంది మరియు ప్రతిరోజూ రిఫ్రెష్ అవుతుంది. కొత్త గేమ్‌లు మరియు కొత్తగా జోడించిన ఎగ్జిక్యూటబుల్స్ దానంతట అవే కనిపిస్తాయి.
- **వేగవంతమైన శోధన.** వేలాది గేమ్‌లలో గేమ్ పేరు లేదా ఎగ్జిక్యూటబుల్ ద్వారా తక్షణ శోధన, గ్రిడ్ లేదా కాంపాక్ట్ జాబితా వీక్షణ, ఇష్టమైనవి మరియు ఒక "Recent" వరుస.
- **ఒకే క్లిక్.** గేమ్‌ను ఎంచుకోండి, ఎగ్జిక్యూటబుల్‌ను ఎంచుకోండి (ఒకటి కంటే ఎక్కువ ఉంటే), దాన్ని ఎంత సమయం ఉంచాలో నిర్ణయించండి మరియు స్టార్ట్ నొక్కండి. సమయం ముగిసినప్పుడు కౌంట్‌డౌన్ రింగ్ మరియు నోటిఫికేషన్ మీకు తెలియజేస్తాయి.
- **వెనుక ఏమీ వదిలిపెట్టదు.** decoy నడుస్తున్నంత వరకు మాత్రమే ఉంటుంది: చిన్న exe ప్రారంభంలో సృష్టించబడుతుంది మరియు ఆపివేసినప్పుడు తొలగించబడుతుంది. మీరు నిష్క్రమించినప్పుడు అంతా ఆగిపోతుంది, మరియు యాప్ క్రాష్ అయితే మిగిలిపోయినవి తదుపరి లాంచ్‌లో క్లియర్ చేయబడతాయి.
- **నిశ్శబ్దంగా ఉంటుంది.** సిస్టమ్ ట్రేలో ఉంటుంది, decoy ల కోసం ఎటువంటి విండోలు లేదా టాస్క్‌బార్ బటన్‌లు ఉండవు.
- **ఓపెన్ అనువాదాలు.** ఇంటర్‌ఫేస్ సాదా JSON ఫైల్స్ ద్వారా నడపబడుతుంది, కాబట్టి భాషను జోడించడం ఒకే ఒక్క ఫైల్ పని. ఇంగ్లీష్ మరియు రష్యన్ చేర్చబడ్డాయి.
- **ప్రైవేట్.** ఎటువంటి ఖాతా లేదు, Discord టోకెన్ లేదు, టెలిమెట్రీ లేదు. [గోప్యత](#గోప్యత) చూడండి.

## ఇది ఎలా పనిచేస్తుంది

1. మీ PC లో నడుస్తున్న ప్రాసెస్‌లను పరిశీలించడం ద్వారా మరియు వాటి ఎగ్జిక్యూటబుల్ పేర్లను పబ్లిక్ జాబితా (`/api/v9/applications/detectable`) తో పోల్చడం ద్వారా మీరు గేమ్ ఆడుతున్నట్లు Discord నిర్ణయిస్తుంది.
2. Decoy ఆ జాబితాను డౌన్‌లోడ్ చేస్తుంది మరియు మీరు ఎంచుకున్న గేమ్ కోసం, జాబితాలోని ఎగ్జిక్యూటబుల్ పేరును ఉపయోగించి ఒక చిన్న స్టాండ్-ఇన్ ప్రోగ్రామ్‌ను (సుమారు 120 KB, Rust లో వ్రాయబడి Decoy లో పొందుపరచబడింది) తాత్కాలిక ఫోల్డర్‌లోకి కాపీ చేస్తుంది, ఉదాహరణకు `.../cod26-cod.exe`.
3. ఈ స్టాండ్-ఇన్ ఒక ఉన్నత-స్థాయి (top-level) విండోను కలిగి ఉండటం మినహా ఏమీ చేయదు, మీరు దాన్ని ఎప్పటికీ చూడకుండా ఉండేందుకు ఆ విండో స్క్రీన్‌కు చాలా దూరంగా ఉంచబడుతుంది. విండో ఉన్న ప్రాసెస్‌ను మాత్రమే Discord గుర్తిస్తుంది, అందుకే పూర్తిగా విండో లేని ప్రాసెస్‌ను విస్మరిస్తుంది.
4. దాదాపు 15 సెకన్లలో Discord ఆ గేమ్‌ను మీ ప్రస్తుత యాక్టివిటీగా చూపిస్తుంది.
5. టైమర్ ముగిసినప్పుడు లేదా మీరు స్టాప్ నొక్కినప్పుడు, Decoy ప్రాసెస్‌ను ముగిస్తుంది మరియు ఫైల్‌ను తొలగిస్తుంది. ఒక Windows జాబ్ ఆబ్జెక్ట్ Decoy క్రాష్ అయినా కూడా decoy లు Decoy తో పాటే ముగిసేలా నిర్ధారిస్తుంది.

## ఇన్‌స్టాల్ చేయడం

[Releases](../../../../releases) పేజీ నుండి ఒకదాన్ని ఎంచుకోండి:

| డౌన్‌లోడ్ | దీని కోసం |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ఇన్‌స్టాలర్.** ఒక్కో యూజర్‌కు, అడ్మినిస్ట్రేటర్ హక్కులు అవసరం లేదు, స్టార్ట్ మెనూ ఎంట్రీని మరియు అన్‌ఇన్‌స్టాలర్‌ను జోడిస్తుంది. |
| `Decoy_x.y.z_x64-portable.zip` | **పోర్టబుల్.** ఎక్కడైనా అన్‌జిప్ చేసి `decoy.exe` ని రన్ చేయండి. మొత్తం డేటా దాని పక్కనే ఉన్న `data` ఫోల్డర్‌లో ఉంటుంది, మీ యూజర్ ప్రొఫైల్‌కు ఏదీ వ్రాయబడదు. దాన్ని తీసివేయడానికి ఫోల్డర్‌ను తొలగించండి. |

`SHA256SUMS.txt` తో డౌన్‌లోడ్‌ను ధృవీకరించండి (PowerShell లో `Get-FileHash <file>`).

బిల్డ్‌లు కోడ్ సంతకం (code signed) చేయబడనందున Windows SmartScreen గుర్తించబడని పబ్లిషర్ గురించి హెచ్చరించవచ్చు; మీరు బిల్డ్‌ను విశ్వసిస్తే *More info → Run anyway* ఎంచుకోండి.

అవసరాలు: WebView2 రన్‌టైమ్‌తో Windows 10 లేదా 11 (64-bit) (ఇప్పటికే Windows 11 మరియు ఇటీవలి Windows 10 అప్‌డేట్‌లలో చేర్చబడింది).

## ఉపయోగం

1. **Library** తెరిచి గేమ్ కోసం వెతకండి, లేదా ఎక్కడి నుండైనా `Ctrl` + `K` నొక్కండి.
2. గేమ్‌పై క్లిక్ చేయండి. కుడి వైపున ఉన్న ప్యానెల్‌లో ప్రాసెస్‌ను మరియు దాన్ని ఎన్ని నిమిషాలు ఉంచాలో ఎంచుకోండి (Discord యాక్టివిటీలకు సాధారణంగా 15 నిమిషాలు అవసరం).
3. **Start decoy** నొక్కండి. కొన్ని సెకన్ల తర్వాత Discord గేమ్‌ను చూపిస్తుంది.
4. దీన్ని **Running** క్రింద చూడండి, ఎప్పుడైనా ఒకటి లేదా అన్నింటినీ ఆపివేయండి, లేదా Decoy ని ట్రేలో వదిలివేయండి.

Discord ఎంట్రీలో ఇంకా ఎగ్జిక్యూటబుల్స్ లేని గేమ్‌లు డిఫాల్ట్‌గా దాచబడతాయి (వాటిని గుర్తించలేము). వాటిని చూడటానికి *Show games without exe* ఆన్ చేయండి; జాబితా ప్రతిరోజూ రిఫ్రెష్ చేయబడుతుంది, కాబట్టి Discord ప్రాసెస్‌ను జోడించిన వెంటనే అవి అందుబాటులోకి వస్తాయి.

### కమాండ్ లైన్

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

వెంటనే decoy ని ప్రారంభిస్తుంది, ఉదాహరణకు `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## సోర్స్ నుండి బిల్డ్ చేయడం

ముందస్తు అవసరాలు: [Node.js](https://nodejs.org) 20+, Visual Studio C++ బిల్డ్ టూల్స్‌తో స్థిరమైన [Rust](https://rustup.rs) టూల్‌చెయిన్ (MSVC టార్గెట్), మరియు WebView2 రన్‌టైమ్.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ఉపయోగకరమైన తనిఖీలు:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

గమనికలు: decoy exe అనేది `src-tauri/build.rs` ద్వారా సాదా `rustc` తో `src-tauri/stub/stub.rs` నుండి కంపైల్ చేయబడుతుంది మరియు తర్వాత యాప్‌లో పొందుపరచబడుతుంది. ఫ్రంట్‌ఎండ్ సాధారణ బ్రౌజర్‌లో నడుస్తున్నప్పుడు (`npm run dev`), ఒక చిన్న మాక్ బ్యాకెండ్ (`src/mock.ts`) ఉపయోగించబడుతుంది, ఇది UI పై పనిచేయడానికి అనుకూలంగా ఉంటుంది.

## అనువాదాలు

UI స్ట్రింగ్స్ [`src/locales`](../../src/locales) లో నివసిస్తాయి, ప్రతి భాషకు ఒక JSON ఫైల్ (`en.json`, `ru.json`, ...).
భాషను జోడించడం అంటే ఫైల్‌ను జోడించడమే; కోడ్ మార్పులు లేవు. ఫైల్ ఫార్మాట్, మెషిన్ అనువాదం కోసం సిద్ధంగా ఉన్న ప్రాంప్ట్ మరియు ధృవీకరణ స్క్రిప్ట్ కోసం [docs/TRANSLATING.md](../TRANSLATING.md) చూడండి. ఈ README యొక్క అనువాదాలు `docs/i18n/README.<code>.md` కి వెళ్తాయి.

## ప్రాజెక్ట్ లేఅవుట్

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## గోప్యత

- Discord పబ్లిక్ డిటెక్షన్ జాబితాను డౌన్‌లోడ్ చేయడానికి (మొదటి ప్రారంభంలో, ఆపై రోజుకు గరిష్టంగా ఒకసారి లేదా మీరు రిఫ్రెష్ నొక్కినప్పుడు) మరియు డిస్‌ప్లే కోసం Discord పబ్లిక్ CDN నుండి గేమ్ చిహ్నాలు మరియు ఆర్ట్‌వర్క్‌ను డౌన్‌లోడ్ చేయడానికి మాత్రమే Decoy నెట్‌వర్క్‌ను ఉపయోగిస్తుంది.
- ఇది మీ Discord టోకెన్ లేదా ఏదైనా ఖాతా డేటాను చదవదు, నిల్వ చేయదు లేదా పంపదు మరియు ఇది Discord క్లయింట్‌తో మాట్లాడదు.
- సెట్టింగ్‌లు (ఇష్టమైనవి, భాష, వ్యవధులు) యాప్ యొక్క WebView స్టోరేజ్‌లో స్థానికంగా నిల్వ చేయబడతాయి; గేమ్ జాబితా కాష్ మరియు తాత్కాలిక decoy ఫైల్స్ `%LOCALAPPDATA%\app.decoy.desktop` లో ఉంటాయి.
- ఎటువంటి అనలిటిక్స్ లేవు, క్రాష్ రిపోర్టింగ్ లేదు, ఖాతాలు లేవు.

## తెలిసిన పరిమితులు

- గుర్తింపు ఎలా పనిచేస్తుందో Discord ఎప్పుడైనా మార్చవచ్చు. ఒక decoy గుర్తించబడటం ఆగిపోతే, దయచేసి ఒక సమస్యను (issue) తెరవండి.
- కొన్ని కార్యకలాపాలకు నడుస్తున్న ప్రాసెస్ కంటే ఎక్కువ అవసరం (ఉదాహరణకు గేమ్ ప్లాట్‌ఫారమ్ యొక్క నిర్దిష్ట అనుభవంలో ఉండటం). Decoy కేవలం ప్రాసెస్‌ను మాత్రమే అనుకరిస్తుంది.
- Discord జాబితాలో ఎగ్జిక్యూటబుల్స్ లేని ఎంట్రీలను గుర్తించలేము.
- మెమరీలో నిష్క్రియంగా ఉండే చిన్న సంతకం చేయని (unsigned) ఎగ్జిక్యూటబుల్స్‌ను సెక్యూరిటీ సాఫ్ట్‌వేర్ అప్పుడప్పుడు ఫ్లాగ్ చేస్తుంది. decoy ఓపెన్ సోర్స్ మరియు `src-tauri/stub/stub.rs` నుండి నిర్మించబడింది; మీరు దాన్ని స్వయంగా కంపైల్ చేసుకోవచ్చు.
