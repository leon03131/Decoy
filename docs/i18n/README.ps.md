# Decoy

**کوچنۍ فرضي پروسې چې Discord فکر کوي یوه لوبه روانه ده.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="د Decoy کتابتون له وروستیو لوبو او انځورونو سره" />

</div>

Decoy د لوبې د اجرايي فایل (executable name) تر نوم لاندې یوه بې ضرره، کړکۍ لرونکې فرضي پروسه پرانیستې ساتي، ترڅو د Discord د لوبې موندنې سیسټم دا وښيي چې تاسو هغه لوبه کوئ. تاسو اړتیا نلرئ اصلي لوبه نصب یا پیل کړئ، نو ستاسو په ډیسک کې هېڅ دروند شی نه پاتې کېږي.

دا **د هرې هغې لوبې په اړه پوهېږي چې Discord یې پېژندلی شي** (شاوخوا ۲۵،۰۰۰ برخې) ځکه چې دا د Discord خپله د موندنې عامه لړليک لولي او په خپله یې تازه ساتي.

> [!WARNING]
> د روانې لوبې جوړول ممکن د Discord د خدمت د شرایطو خلاف وي او تاسو Decoy **په خپل خطر** کاروئ.
> دا پروژه د Discord Inc. لخوا نه ده تایید شوې، ورپورې تړلې یا اړونده نه ده. وګورئ [رد مسؤلیت](#رد-مسؤلیت).

## ځانګړتیاوې

- **هر څه چې Discord یې پېژندلی شي.** د لوبو لړليک د Discord له عامه موندنې پایلې (endpoint) څخه کښته کېږي، په ځايي ډول زیرمه کېږي او هره ورځ تازه کېږي. نوې لوبې او نوي ورزیات شوي اجرايي فایلونه په خپله ښکاري.
- **ګړندۍ لټون.** په زرګونو لوبو کې د لوبې د نوم یا اجرايي فایل له مخې سملاسي لټون، د ټایلونو یا لنډ لړليک بڼه، خوښ شوي او د "وروستي" قطار.
- **یو کلیک.** یوه لوبه وټاکئ، اجرايي فایل وټاکئ (که څو وي)، موده وټاکئ چې څومره وخت وساتل شي او د پیل تڼۍ ووهئ. یوه شاتنۍ شمېرنه او خبرتیا تاسو ته ښيي کله چې وخت پوره شي.
- **هېڅ اضافي شی نه پرېږدي.** یو decoy یوازې هغه وخت شتون لري کله چې روان وي: کوچنی exe په پیل کې جوړېږي او په درېدو سره ړنګېږي. کله چې تاسو ووځئ ټول شیان درول کېږي، او د کریش پاتې شوني په راتلونکي پیل کې پاکېږي.
- **بې غږه.** د سیسټم په ټرې (tray) کې پاتې کېږي، د پخپله decoys لپاره هېڅ کړکۍ یا د ټاسک بار تڼۍ نه وي.
- **خلاص ژباړې.** کارن مخ د عامو JSON فایلونو په واسطه اداره کېږي، نو د یوې نوې ژبې اضافه کول یوازې د یوه فایل کار دی. انګلیسي او روسي پکې شامل دي.
- **شخصي او خوندي.** هېڅ ګڼون نشته، هېڅ د Discord ټوکن نشته، هېڅ ټیلیمیټري نشته. وګورئ [محرمیت](#محرمیت).

## دا څنګه کار کوي

1. Discord د دې معلومولو لپاره چې تاسو لوبه کوئ، ستاسو په کمپیوټر کې روانې پروسې ګوري او د هغوی د اجرايي فایل نومونه له خپل عامه لړليک (`/api/v9/applications/detectable`) سره پرتله کوي.
2. Decoy دا لړليک کښته کوي او، ستاسو د ټاکل شوې لوبې لپاره، یو کوچنی فرضي پروګرام (شاوخوا ۱۲۰ KB، په Rust کې لیکل شوی او په Decoy کې ځای پر ځای شوی) په یوه موقتي پوښۍ کې د لړليک د اجرايي نوم په کارولو کاپي کوي، د بېلګې په توګه `.../cod26-cod.exe`.
3. دا فرضي پروګرام هېڅ نه کوي پرته له دې چې یوه لوړه سطحه کړکۍ لري، چې له سکرین څخه ډېره لرې درول شوې ترڅو تاسو یې هېڅکله ونه ګورئ. Discord یوازې هغه پروسه پېژني چې کړکۍ ولري، له همدې امله په بشپړه توګه بې کړکۍ پروسه له پامه غورځول کېږي.
4. شاوخوا په ۱۵ ثانیو کې Discord لوبه ستاسو د اوسني فعالیت په توګه ښيي.
5. کله چې ټایمر پای ته ورسېږي یا تاسو سټاپ ووهئ، Decoy پروسه پای ته رسوي او فایل ړنګوي. د Windows job object ډاډ ورکوي چې decoys پخپله د Decoy سره یوځای له منځه ځي، حتی که دا کریش هم شي.

## لګول (Install)

له [Releases](../../../../releases) پاڼې څخه یو وټاکئ:

| کښته کول | لپاره |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **انسټالر.** د هر کارن لپاره، د اډمین اجازه لازمي نه ده، د پیل مینو داخله او یو انسټالر ورزیاتوي. |
| `Decoy_x.y.z_x64-portable.zip` | **پورټېبل.** په هر ځای کې یې ان‌زپ کړئ او `decoy.exe` وچلوئ. ټول معلومات د هغې تر څنګ په `data` پوښۍ کې پاتې کېږي، ستاسو د کارن پروفایل کې هېڅ نه لیکل کېږي. د لرې کولو لپاره پوښۍ ړنګه کړئ. |

کښته شوی فایل د `SHA256SUMS.txt` له لارې تایید کړئ (په PowerShell کې `Get-FileHash <file>`).

د Windows SmartScreen ممکن د ناپېژندل شوي خپروونکي خبرداری ورکړي ځکه چې بېلډونه په کوډ لاسلیک شوي نه دي؛ که تاسو په بېلډ باور لرئ نو *More info → Run anyway* وټاکئ.

اړتیاوې: Windows 10 یا 11 (64-bit) د WebView2 رن‌ټایم سره (چې دمخه په Windows 11 او د Windows 10 وروستیو تازه معلوماتو کې شامل دي).

## د کارولو لارښود

1. **کتابتون** پرانیزئ او د لوبې پلټنه وکړئ، یا له هر ځای څخه `Ctrl` + `K` کېکاږئ.
2. په یوه لوبه کلیک وکړئ. په ښي پینل کې پروسه او دقیقې وټاکئ چې څومره وخت وساتل شي (د Discord فعالیتونه معمولاً ۱۵ دقیقې غواړي).
3. **Decoy پیل کول** ووهئ. Discord به له څو ثانیو وروسته لوبه وښيي.
4. په **په کار بوخت** برخه کې یې وڅارئ، یوه یا ټولې په هر وخت کې ودروئ، یا یوازې Decoy په ټرې (tray) کې پرېږدئ.

هغه لوبې چې د Discord په لړليک کې تر اوسه اجرايي فایلونه نه لري په تلوالیز ډول پټې دي (هغوی نشي پېژندل کېدای).
*بې exe لوبې ښودل* فعال کړئ ترڅو یې وګورئ؛ لړليک هره ورځ تازه کېږي، نو کله چې Discord کومه پروسه ورزیاته کړي هغوی سملاسي د لاسرسي وړ ګرځي.

### د کمانډ لاین

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

سملاسي یوه decoy پیلوي، د بېلګې په توګه `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## له سرچینې څخه جوړول (Build from source)

اړین توکي: [Node.js](https://nodejs.org) 20+، مستحکم [Rust](https://rustup.rs) ټول‌چین (د MSVC هدفي بڼه) له Visual Studio C++ جوړونې توکو سره، او WebView2 رن‌ټایم.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # په پرمختیایي حالت کې له ژوندي تازه والي سره چلول
npm run tauri build    # په src-tauri/target/release/bundle/nsis کې انسټالر جوړول
```

ګټورې پلټنې:

```bash
npm run check-locales  # هره ژباړه د ru.json په وړاندې تاییدول
npx tsc --noEmit       # د فرنټ اینډ ټایپونه کتل
cargo check --manifest-path src-tauri/Cargo.toml
```

یادښتونه: د decoy exe د `src-tauri/build.rs` له لارې په ساده `rustc` سره له `src-tauri/stub/stub.rs` جوړېږي او بیا په اپلیکیشن کې ځای پر ځای کېږي. کله چې فرنټ اینډ په یو عادي براوزر کې چلیږي (`npm run dev`) نو یو کوچنی موک بیک اینډ (`src/mock.ts`) کارول کېږي، چې د UI پرمختګ لپاره اسانه دی.

## ژباړې

د UI متنونه په [`src/locales`](../../src/locales) کې پراته دي، د هرې ژبې لپاره یو JSON فایل (`en.json`, `ru.json`, ...).
د یوې ژبې ورزیاتول یوازې د یو فایل اضافه کول دي؛ په کوډ کې هېڅ بدلون نه راځي. د فایل بڼې، د ماشیني ژباړې پرامپټ او د تایید سکریپټ لپاره [docs/TRANSLATING.md](../TRANSLATING.md) وګورئ. د دې لارښود ژباړې په `docs/i18n/README.<code>.md` کې دي.

## د پروژې جوړښت

```
src/                    د React + TypeScript فرنټ اینډ
  components/           کتابتون، د جزیاتو پینل، امستنې، ...
  locales/              د ژباړې فایلونه (د هرې ژبې یو JSON)
  i18n-core.ts          د ژبې لوستل او پلټنه
  store.ts              د اپلیکیشن حالت (zustand)
src-tauri/              د Rust شالید (Tauri 2)
  src/lib.rs            د لوبو ډیټابیس، decoy پروسې، ټرې
  stub/stub.rs          فرضي پروګرام چې پکې ځای پر ځای کېږي
scripts/                مرستندویه سکریپټونه (د بڼې تایید)
docs/                   د ژباړې لارښود، انځورونه
```

## محرمیت

- Decoy انټرنیټ یوازې د Discord د عامه موندنې لړليک کښته کولو لپاره کاروي (په لومړي پیل کې، بیا په ورځ کې تر ټولو ډېر یو ځل یا کله چې تاسو تازه کول ووهئ) او د ښودلو لپاره، د Discord له عامه CDN څخه د لوبې شبیه او انځورونه راوړي.
- دا ستاسو د Discord ټوکن یا د حساب هېڅ ډول معلومات نه لولي، نه ذخیره کوي او نه یې لېږي، او د Discord له کلائنټ سره اړیکه نه نیسي.
- امستنې (خوښ شوي، ژبه، مودې) د اپلیکیشن په WebView حافظه کې په ځايي توګه خوندي کېږي؛ د لوبو لړليک کیش او موقتي decoy فایلونه په `%LOCALAPPDATA%\app.decoy.desktop` کې ځای پر ځای کېږي.
- هېڅ انالیټکس نشته، هېڅ د کریش راپور نشته، هېڅ حساب نشته.

## معلوم محدودیتونه

- Discord کولی شي په هر وخت کې د فعالیتونو د موندلو بڼه بدله کړي. که یوه decoy نه پېژندل کېږي، مهرباني وکړئ یو issue پرانیزئ.
- ځینې فعالیتونه له یوازې یوې روانې پروسې څخه زیاتو شیانو ته اړتیا لري (د بېلګې په توګه د لوبې په پلیټفارم کې دننه یوې ځانګړې تجربې ته ننوتل). Decoy یوازې پروسه تقلید کوي.
- د Discord په لړليک کې بې اجرايي فایلونو برخې نشي پېژندل کېدای.
- امنیتي سافټویر کله ناکله په کوچنیو بې لاسلیک اجرايي فایلونو باندې شک کوي چې په حافظه کې بې کاره ناست وي. Decoy پرانیستې سرچینه ده او له `src-tauri/stub/stub.rs` جوړه شوې ده؛ تاسو یې پخپله کمپایل کولی شئ.

## ونډه اخیستنه

د ستونزو راپورونه، نظریات او ژباړې د هرکلي وړ دي. مهرباني وکړئ لومړی [CONTRIBUTING.md](../../CONTRIBUTING.md) ولولئ.

## رد مسؤلیت

Decoy د شخصي، روزنیزو او ازمایښتي موخو لپاره "لکه څنګه چې دی" وړاندې کېږي. د روانې لوبې جوړول او تقلید ممکن د Discord یا د لوبې خپروونکي د خدماتو له شرایطو سرغړونه وي، او ستاسو د اکاونټ په وړاندې اقدام لامل شي. یوازې تاسو پخپله د هغې د کارولو مسؤل یاست. "Discord" او د لوبو ټول نومونه او لوګوګانې د هغوی د اړوندو مالکانو سوداګریزې نښې دي او دلته یوازې د هغو ساوتریو د پېژندنې لپاره کارول شوي چې دوی ورته اشاره کوي.
