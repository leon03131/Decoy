# Decoy

**Крошечные процессы-заглушки, благодаря которым Discord считает, что запущена игра.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Библиотека Decoy с недавними играми и обложками" />

</div>

Decoy поддерживает работу безобидного процесса-заглушки с окном под именем исполняемого файла игры, поэтому
система обнаружения игр Discord отображает вас играющим в эту игру. Вам не нужно устанавливать или запускать
саму игру, так что на диске не остаётся ничего лишнего.

Оно знает обо **всех играх, которые может обнаружить Discord** (около 25 000 записей), поскольку считывает собственный
публичный список обнаружения Discord и автоматически поддерживает его в актуальном состоянии.

> [!WARNING]
> Имитация запущенной игры может противоречить Условиям обслуживания Discord, вы используете Decoy **на свой страх и риск**.
> Этот проект не связан с Discord Inc., не одобрен и не поддерживается им. См. [Отказ от ответственности](#отказ-от-ответственности).

## Возможности

- **Всё, что может обнаружить Discord.** Список игр загружается из публичного источника Discord, кэшируется
  локально и обновляется ежедневно. Новые игры и недавно добавленные исполняемые файлы появляются сами собой.
- **Быстрый поиск.** Мгновенный поиск по названию игры или исполняемому файлу среди тысяч игр, отображение плитками
  или компактным списком, избранное и строка «Недавние».
- **В один клик.** Выберите игру, выберите исполняемый файл (если их несколько), укажите, сколько минут держать, и нажмите «Запустить заглушку».
  Кольцо обратного отсчёта и уведомление сообщат, когда время выйдет.
- **Не оставляет следов.** Заглушка существует только пока работает: крошечный exe создаётся при запуске и удаляется
  при остановке. При выходе из приложения всё останавливается, а оставшиеся после сбоя файлы очищаются при следующем запуске.
- **Тихий режим.** Живёт в системном трее, никаких окон или кнопок на панели задач для самих заглушек.
- **Открытые переводы.** Интерфейс работает на простых JSON-файлах, поэтому добавление языка — это один файл.
  Английский и русский уже включены.
- **Конфиденциальность.** Без аккаунта, без токена Discord, без телеметрии. См. [Конфиденциальность](#конфиденциальность).

## Как это работает

1. Discord определяет, что вы играете в игру, проверяя запущенные процессы на вашем ПК и сравнивая имена их
   исполняемых файлов с публичным списком (`/api/v9/applications/detectable`).
2. Decoy скачивает этот список и для выбранной игры копирует крошечную программу-заглушку (около 120 КБ, написана на
   Rust и встроена в Decoy) во временную папку под именем исполняемого файла из списка, например
   `.../cod26-cod.exe`.
3. Заглушка ничего не делает, кроме создания одного окна верхнего уровня, расположенного далеко за пределами экрана,
   так что вы его никогда не увидите. Discord распознаёт только процессы с окном, поэтому процессы совсем без окон игнорируются.
4. Примерно через 15 секунд Discord отображает эту игру в качестве вашей текущей активности.
5. Когда таймер заканчивается или вы нажимаете кнопку остановки, Decoy завершает процесс и удаляет файл. Объект задания Windows (job object)
   гарантирует завершение заглушек вместе с Decoy, даже если приложение аварийно завершит работу.

## Установка

Выберите вариант на странице [релизов](../../../../releases):

| Скачать | Назначение |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Установщик.** Для одного пользователя, права администратора не требуются, добавляет пункт в меню «Пуск» и деинсталлятор. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативная версия.** Распакуйте в любое место и запустите `decoy.exe`. Все данные хранятся в папке `data` рядом с ним, в профиль пользователя ничего не записывается. Чтобы удалить, просто удалите папку. |

Проверьте контрольную сумму загруженного файла с помощью `SHA256SUMS.txt` (`Get-FileHash <file>` в PowerShell).

Windows SmartScreen может предупредить о неизвестном издателе, поскольку сборки не имеют цифровой подписи; выберите
*Подробнее → Выполнить в любом случае*, если вы доверяете сборке.

Требования: Windows 10 или 11 (64-битная) со средой выполнения WebView2 (уже включена в Windows 11 и последние
обновления Windows 10).

## Использование

1. Откройте **Библиотеку** и найдите игру, либо нажмите `Ctrl` + `K` в любом месте приложения.
2. Нажмите на игру. В панели справа выберите процесс и сколько минут его держать (для заданий Discord
   обычно требуется 15).
3. Нажмите **Запустить заглушку**. Discord отобразит игру через несколько секунд.
4. Следите за ней во вкладке **Запущено**, остановите одну или все в любой момент либо просто оставьте Decoy в трее.

Игры, для которых в базе Discord пока нет исполняемых файлов, по умолчанию скрыты (их невозможно обнаружить). Включите
*Показывать без exe*, чтобы увидеть их; список обновляется ежедневно, поэтому они станут доступны, как только Discord добавит
процесс.

### Командная строка

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Сразу запускает заглушку, например: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сборка из исходников

Предварительные требования: [Node.js](https://nodejs.org) 20+, стабильный набор инструментов [Rust](https://rustup.rs) (целевая платформа MSVC) со
средствами сборки C++ Visual Studio и среда выполнения WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Полезные проверки:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Примечания: исполняемый файл заглушки компилируется скриптом `src-tauri/build.rs` с помощью обычного `rustc` из `src-tauri/stub/stub.rs` и затем
встраивается в приложение. При запуске фронтенда в обычном браузере (`npm run dev`) используется небольшой мок-бэкенд
(`src/mock.ts`), что удобно для работы над интерфейсом.

## Переводы

Строки интерфейса находятся в [`src/locales`](../../src/locales), по одному JSON-файлу на язык (`en.json`, `ru.json`, ...).
Добавление языка означает просто добавление файла — без изменений в коде. См. [docs/TRANSLATING.md](../TRANSLATING.md) для получения информации о
формате файлов, готового промпта для машинного перевода и скрипта валидации. Переводы этого README помещаются в
`docs/i18n/README.<code>.md`.

## Структура проекта

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Конфиденциальность

- Decoy использует сеть только для загрузки публичного списка обнаружения Discord (при первом запуске, затем не чаще одного раза в день
  или при нажатии кнопки обновления) и для отображения иконок и обложек игр из публичного CDN Discord.
- Приложение не считывает, не сохраняет и не передаёт ваш токен Discord или какие-либо данные аккаунта, а также не взаимодействует с клиентом Discord.
- Настройки (избранное, язык, длительность) хранятся локально в хранилище WebView приложения; кэш списка игр и
  временные файлы заглушек находятся в `%LOCALAPPDATA%\app.decoy.desktop`.
- Никакой аналитики, никаких отчётов о сбоях, никаких аккаунтов.

## Известные ограничения

- Discord может изменить логику обнаружения в любое время. Если заглушка перестанет распознаваться, пожалуйста, откройте issue.
- Для некоторых активностей требуется больше, чем просто запущенный процесс (например, нахождение в определённом плейсе или режиме игровой
  платформы). Decoy имитирует только процесс.
- Записи без исполняемых файлов в списке Discord не могут быть обнаружены.
- Защитное ПО иногда реагирует на небольшие неподписанные исполняемые файлы, простаивающие в памяти. Заглушка имеет открытый исходный код
  и собирается из `src-tauri/stub/stub.rs`; вы можете скомпилировать её самостоятельно.
