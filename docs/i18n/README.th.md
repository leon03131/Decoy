# Decoy

**โพรเซสจำลองขนาดเล็กที่ทำให้ Discord คิดว่ามีเกมกำลังทำงานอยู่**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="คลัง Decoy พร้อมเกมล่าสุดและภาพหน้าปก" />

</div>

Decoy จะรักษาโพรเซสจำลองแบบมีหน้าต่างที่ไม่เป็นอันตรายให้ทำงานอยู่ภายใต้ชื่อไฟล์ปฏิบัติการของเกม ทำให้ระบบตรวจจับเกมของ Discord รายงานว่าคุณกำลังเล่นเกมนั้นอยู่ คุณไม่จำเป็นต้องติดตั้งหรือเปิดเกมจริงขึ้นมา จึงไม่มีไฟล์ขนาดใหญ่กินพื้นที่ในดิสก์ของคุณ

โปรแกรมนี้รู้จัก **ทุกเกมที่ Discord สามารถตรวจจับได้** (ประมาณ 25,000 รายการ) เพราะโปรแกรมอ่านรายการตรวจจับสาธารณะของ Discord เองและคอยอัปเดตให้เป็นปัจจุบันอยู่เสมอโดยอัตโนมัติ

> [!WARNING]
> การจำลองเกมที่กำลังทำงานอยู่อาจขัดต่อข้อกำหนดในการให้บริการของ Discord และคุณใช้งาน Decoy **ด้วยความเสี่ยงของคุณเอง**
> โปรเจกต์นี้ไม่มีส่วนเกี่ยวข้อง ได้รับการรับรอง หรือเชื่อมโยงกับ Discord Inc. แต่อย่างใด ดูที่ [ข้อจำกัดความรับผิดชอบ](#ข้อจำกัดความรับผิดชอบ)

## ฟีเจอร์

- **ครอบคลุมทุกสิ่งที่ Discord ตรวจจับได้** รายชื่อเกมจะถูกดาวน์โหลดจาก endpoint ตรวจจับสาธารณะของ Discord โดยจะแคชไว้ในเครื่องและรีเฟรชใหม่ทุกวัน เกมใหม่และไฟล์ปฏิบัติการที่เพิ่งเพิ่มเข้ามาจะปรากฏขึ้นเองโดยอัตโนมัติ
- **ค้นหาได้รวดเร็วทันใจ** ค้นหาทันทีตามชื่อเกมหรือไฟล์ปฏิบัติการจากเกมหลายพันเกม พร้อมมุมมองแบบตารางหรือรายการแบบกะทัดรัด รายการโปรด และแถว "ล่าสุด"
- **คลิกเดียวจบ** เลือกเกม เลือกไฟล์ปฏิบัติการ (หากมีหลายไฟล์) กำหนดระยะเวลาที่ต้องการเปิดไว้ แล้วกดเริ่ม วงแหวนนับถอยหลังและการแจ้งเตือนจะบอกให้คุณทราบเมื่อหมดเวลา
- **ไม่ทิ้งร่องรอยไว้เบื้องหลัง** Decoy จะมีอยู่เฉพาะในขณะที่ทำงานเท่านั้น: ไฟล์ exe ขนาดเล็กจะถูกสร้างขึ้นเมื่อเริ่มต้นและถูกลบทิ้งเมื่อหยุดทำงาน ทุกอย่างจะหยุดลงเมื่อคุณออกจากโปรแกรม และไฟล์ตกค้างจากการปิดตัวผิดปกติจะถูกเก็บกวาดในการเปิดใช้งานครั้งถัดไป
- **เงียบและไม่รบกวน** ทำงานอยู่ใน system tray ไม่มีหน้าต่างหรือปุ่มบน taskbar สำหรับตัว decoy เอง
- **เปิดกว้างสำหรับการแปล** อินเทอร์เฟซทำงานผ่านไฟล์ JSON ทั่วไป ดังนั้นการเพิ่มภาษาใหม่จึงทำได้ด้วยไฟล์เดียว มีภาษาอังกฤษและภาษารัสเซียรวมมาให้แล้ว
- **เป็นส่วนตัว** ไม่ต้องใช้บัญชี ไม่ต้องใช้โทเค็น Discord ไม่มีการเก็บข้อมูลการใช้งาน (telemetry) ดูที่ [ความเป็นส่วนตัว](#ความเป็นส่วนตัว)

## หลักการทำงาน

1. Discord จะตรวจสอบว่าคุณกำลังเล่นเกมอยู่หรือไม่ โดยดูจากโพรเซสที่กำลังทำงานบนพีซีของคุณ และเปรียบเทียบชื่อไฟล์ปฏิบัติการกับรายการสาธารณะ (`/api/v9/applications/detectable`)
2. Decoy จะดาวน์โหลดรายการดังกล่าว และสำหรับเกมที่คุณเลือก โปรแกรมจะคัดลอกโปรแกรมจำลองขนาดจิ๋ว (ประมาณ 120 KB เขียนด้วย Rust และฝังไว้ใน Decoy) ไปยังโฟลเดอร์ชั่วคราว โดยใช้ชื่อไฟล์ปฏิบัติการจากรายการ เช่น `.../cod26-cod.exe`
3. โปรแกรมจำลองนี้จะไม่ทำสิ่งใดเลยนอกจากถือครองหน้าต่างระดับบนสุดหนึ่งบาน ซึ่งถูกวางไว้นอกจอทำให้คุณมองไม่เห็น Discord จะตรวจพบเฉพาะโพรเซสที่มีหน้าต่างเท่านั้น นี่คือเหตุผลที่โพรเซสที่ไม่มีหน้าต่างโดยสิ้นเชิงจะถูกเพิกเฉย
4. ภายในเวลาประมาณ 15 วินาที Discord จะแสดงเกมนั้นเป็นกิจกรรมปัจจุบันของคุณ
5. เมื่อตัวจับเวลาสิ้นสุดลงหรือคุณกดหยุด Decoy จะยุติโพรเซสและลบไฟล์ทิ้ง Windows job object จะช่วยรับประกันว่าตัว decoy จะถูกปิดลงพร้อมกับ Decoy เสมอ แม้ว่าโปรแกรมจะปิดตัวผิดปกติก็ตาม

## การติดตั้ง

เลือกดาวน์โหลดได้จากหน้า [Releases](../../../../releases):

| ดาวน์โหลด | สำหรับ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ตัวติดตั้ง (Installer)** ติดตั้งแยกตามผู้ใช้ ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ เพิ่มรายการในเมนู Start และมีตัวถอนการติดตั้ง |
| `Decoy_x.y.z_x64-portable.zip` | **แบบพกพา (Portable)** แตกไฟล์ที่ใดก็ได้แล้วเปิดใช้งาน `decoy.exe` ข้อมูลทั้งหมดจะถูกเก็บไว้ในโฟลเดอร์ `data` ข้างๆ โปรแกรม ไม่มีการเขียนข้อมูลลงในโปรไฟล์ผู้ใช้ ลบโฟลเดอร์ทิ้งเพื่อถอนการติดตั้ง |

ตรวจสอบความถูกต้องของไฟล์ที่ดาวน์โหลดได้ด้วย `SHA256SUMS.txt` (ใช้คำสั่ง `Get-FileHash <file>` ใน PowerShell)

Windows SmartScreen อาจแสดงการแจ้งเตือนเกี่ยวกับผู้พัฒนาที่ไม่รู้จักเนื่องจากตัวบิลด์ไม่มีการลงลายมือชื่อดิจิทัล (code signed) ให้เลือก *More info → Run anyway* หากคุณเชื่อถือไฟล์บิลด์นี้

ความต้องการของระบบ: Windows 10 หรือ 11 (64-bit) พร้อมด้วย WebView2 runtime (มีรวมมาให้อยู่แล้วใน Windows 11 และการอัปเดตล่าสุดของ Windows 10)

## การใช้งาน

1. เปิด **Library** แล้วค้นหาเกม หรือกด `Ctrl` + `K` ได้จากทุกหน้า
2. คลิกเลือกเกม ในแผงควบคุมด้านขวา ให้เลือกโพรเซสและจำนวนนาทีที่ต้องการเปิดค้างไว้ (ภารกิจกิจกรรม Discord มักต้องการ 15 นาที)
3. กด **Start decoy** Discord จะแสดงเกมหลังจากนั้นไม่กี่วินาที
4. ดูสถานะได้ในส่วน **Running** คุณสามารถหยุดรายการใดรายการหนึ่งหรือทั้งหมดได้ตลอดเวลา หรือจะปล่อย Decoy ไว้ในถาดระบบ (tray) ก็ได้

เกมที่ในฐานข้อมูล Discord ยังไม่มีไฟล์ปฏิบัติการจะถูกซ่อนไว้โดยค่าเริ่มต้น (เนื่องจากไม่สามารถตรวจจับได้) ให้เปิดตัวเลือก *Show games without exe* เพื่อดูรายการเหล่านั้น รายชื่อเกมจะได้รับการอัปเดตใหม่ทุกวัน ดังนั้นเกมจะพร้อมใช้งานทันทีที่ Discord เพิ่มโพรเซสเข้ามา

### บรรทัดคำสั่ง

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

เปิดใช้งาน decoy ได้ทันที เช่น `decoy.exe --launch "robloxplayerbeta.exe" 15`

## การบิลด์จากซอร์สโค้ด

สิ่งที่ต้องเตรียม: [Node.js](https://nodejs.org) 20+, ทูลเชน [Rust](https://rustup.rs) รุ่นเสถียร (เป้าหมาย MSVC) พร้อมด้วย Visual Studio C++ build tools และ WebView2 runtime

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

คำสั่งตรวจสอบที่มีประโยชน์:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

หมายเหตุ: ไฟล์ exe ของ decoy ถูกคอมไพล์โดย `src-tauri/build.rs` ด้วย `rustc` ปกติจาก `src-tauri/stub/stub.rs` แล้วจึงฝังลงในแอป เมื่อรันส่วนหน้า (frontend) บนเบราว์เซอร์ทั่วไป (`npm run dev`) จะมีการใช้ม็อกแบ็กเอนด์ขนาดเล็ก (`src/mock.ts`) ซึ่งสะดวกมากสำหรับการพัฒนา UI

## การแปลภาษา

ข้อความใน UI จะอยู่ที่ [`src/locales`](../../src/locales) แยกเป็นหนึ่งไฟล์ JSON ต่อหนึ่งภาษา (`en.json`, `ru.json`, ...) การเพิ่มภาษาใหม่ทำได้เพียงแค่เพิ่มไฟล์ โดยไม่ต้องแก้ไขโค้ดใดๆ ดูที่ [docs/TRANSLATING.md](../TRANSLATING.md) สำหรับรูปแบบไฟล์ พรอมต์พร้อมใช้สำหรับการแปลภาษาด้วย AI และสคริปต์ตรวจสอบความถูกต้อง ส่วนคำแปลของ README นี้จะอยู่ที่ `docs/i18n/README.<code>.md`

## โครงสร้างโปรเจกต์

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## ความเป็นส่วนตัว

- Decoy ใช้งานเครือข่ายเพื่อดาวน์โหลดรายการตรวจจับสาธารณะของ Discord เท่านั้น (เมื่อเปิดใช้งานครั้งแรก จากนั้นไม่เกินวันละหนึ่งครั้ง หรือเมื่อคุณกดรีเฟรช) และเพื่อแสดงไอคอนเกมกับภาพหน้าปกจาก CDN สาธารณะของ Discord
- โปรแกรมจะไม่เปิดอ่าน จัดเก็บ หรือส่งต่อโทเค็น Discord หรือข้อมูลบัญชีใดๆ ของคุณ และไม่มีการติดต่อสื่อสารกับไคลเอนต์ Discord แต่อย่างใด
- การตั้งค่าต่างๆ (รายการโปรด ภาษา ระยะเวลา) จะถูกจัดเก็บไว้ในเครื่องในพื้นที่เก็บข้อมูล WebView ของแอป สำหรับแคชรายการเกมและไฟล์จำลอง decoy ชั่วคราวจะอยู่ใน `%LOCALAPPDATA%\app.decoy.desktop`
- ไม่มีการเก็บข้อมูลการวิเคราะห์ ไม่มีการส่งรายงานข้อขัดข้อง และไม่มีระบบบัญชีผู้ใช้

## ข้อจำกัดที่ทราบ

- Discord อาจเปลี่ยนแปลงระบบการตรวจจับได้ตลอดเวลา หาก decoy ไม่ได้รับการตรวจจับอีกต่อไป โปรดเปิด issue แจ้งปัญหา
- กิจกรรมบางอย่างต้องการมากกว่าแค่โพรเซสที่กำลังทำงานอยู่ (เช่น การอยู่ภายในประสบการณ์หรือแมปเฉพาะของแพลตฟอร์มเกมนั้นๆ) โดย Decoy จะจำลองเฉพาะตัวโพรเซสเท่านั้น
- รายการที่ไม่มีไฟล์ปฏิบัติการในรายชื่อของ Discord จะไม่สามารถตรวจจับได้
- บางครั้งซอฟต์แวร์ความปลอดภัยอาจแจ้งเตือนเกี่ยวกับไฟล์ปฏิบัติการขนาดเล็กที่ไม่ได้ลงลายมือชื่อดิจิทัลและเปิดค้างอยู่ในหน่วยความจำ โปรแกรม decoy เป็นโอเพนซอร์สและสร้างขึ้นจาก `src-tauri/stub/stub.rs` คุณสามารถคอมไพล์ด้วยตัวเองได้

## ข้อจำกัดความรับผิดชอบ

Decoy จัดทำขึ้นในลักษณะ "ตามที่เป็นอยู่" เพื่อวัตถุประสงค์ส่วนบุคคล การศึกษา และการทดสอบเท่านั้น การจำลองเกมที่กำลังทำงานอยู่อาจละเมิดข้อกำหนดในการให้บริการของ Discord หรือของผู้เผยแพร่เกม และอาจส่งผลให้บัญชีของคุณถูกดำเนินการได้ คุณต้องรับผิดชอบต่อการใช้งานด้วยตนเองแต่เพียงผู้เดียว "Discord" รวมถึงชื่อเกมและโลโก้ทั้งหมดเป็นเครื่องหมายการค้าของเจ้าของที่เกี่ยวข้อง และใช้ในที่นี้เพื่อระบุถึงซอฟต์แวร์ที่อ้างถึงเท่านั้น
