# Decoy

**Пичи заглушка-процессъёс, кудъёсызлы луыса Discord шудон ужа шуыса малпа.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека берпуметӥ шудонъёсын но суредъёсын" />

</div>

Decoy шудонлэн быдэстӥськись файлэзлэн нимыныз уксёез лэсьтыса лӧсьӧтэм кышкыттэм укноен заглушка-процессэз ужась возё, соин ик Discord-лэн шудонъёсты чаклан системаез тӥлесьтыд та шудонэн шудэмдэс возьматэ. Зэмос шудонэз пуктыны яке ӧдъяны кулэ ӧвӧл, соин диск вылын номыр лишней уг кельшы.

Со Discord **тодманы быгатӥсь вань шудонъёсты** тодэ (25 000 пала пыртэм пусъёс), малы ке шуоно Discord-лэсь ассьыс паськыт тодман лыдметсэ лыдӟе но сое ачиз выльдӥсь возё.

> [!WARNING]
> Шудонэз ӧнертомон ӧдъян Discord-лэн луонлыкез кутон условиосызлы пумит луыны быгатэ, тӥ Decoy-ен **ас кышкантэмдыя** ужаськоды.
> Та проект Discord Inc. огазеяськонэн герӟаськемын ӧвӧл, соин дурбасьтэмын яке юрттэмын ӧвӧл. Учке [Кыл кутонлэсь куштӥськон](#кыл-кутонлэсь-куштӥськон).

## Луонлыкъёс

- **Ваньмыз, мае тодманы быгатэ Discord.** Шудонъёслэн лыдметсы Discord-лэн паськыт версысьтыз поныса кельтӥське, компьютер вылын возиське но котькуд нунал выльдэмемын луэ. Выль шудонъёс но выль ватсам быдэстӥськись файлъёс асьсэос тырмо.
- **Ӵош ужась утчан.** Сюрс шудонъёс пӧлысь шудонлэн нимыз яке быдэстӥськись файлъя ӝог утчан, плиткаосын яке компактной лыдметэн возьматон, яратоноос но «Берпуметӥосыз» чур.
- **Одӥг зӥбонэн.** Бырйе шудонэз, бырйе быдэстӥськись файлэз (кӧня ке ке луиз), пуктэ, кӧня минут кутыны, но «Заглушкаез ӧдъяны» зӥбе. Берлань лыдъян котыр но ивортон ивортӥзы, куке вакыт быроз.
- **Номыр уг кельты.** Заглушка ужакуз гинэ луэ: пичи exe ӧдъяку лэсьтӥське но дугдытыку быдтэмын луэ. Приложениысь потыку ваньмыз дугдэ, но куке программа шекшеськиз ке, кылем файлъёс вуоно ӧдъяку чылкытатӥсько.
- **Ӵошкыт режим.** Системной трейын улэ, заглушкаослы асьсэослы нимаз укноос яке пуск панель вылын ӧжытъёс кулэ ӧвӧл.
- **Усьтэм берыктонъёс.** Интерфейс капчи JSON-файлъёсын ужа, соин выль кыл ватсан — со одӥг файл гинэ. Англи но ӟуч кылъёс пуктэмын ни.
- **Валэктӥсьтэм луонлык.** Аккаунттэк, Discord торентэк, телеметритэк. Учке [Валэктӥсьтэм луонлык](#валэктӥсьтэм-луонлык).

## Кызьы со ужа

1. Discord тӥлесьтыд шудонэн шудэмдэс лыдъя, компьютерысьтыды ужась процессъёсты учкыса но соослэсь файл нимъёссэс паськыт лыдметэн ӵошатыса (`/api/v9/applications/detectable`).
2. Decoy та лыдметэз поныса кельтэ но быръем шудон понна пичи заглушка-программаез (120 КБ пала, Rust кылын гожтэмын но Decoy пушкы ватсамын) дырлы быдэс папкае лыдметысь файл нимын копия каре, кылсярысь `.../cod26-cod.exe`.
3. Заглушка номыр уг кары, одӥг экран сайын сылӥсь вылӥ тшуплэн укнозэ гинэ возе, тӥ сое ноку уд адӟе. Discord укноен процессъёсты гинэ тодма, соин укнотэк процессъёсыз уг чакла.
4. 15 секунд мында ортчыса Discord та шудонэз тӥляд али ужды шуыса возьматэ.
5. Куке таймер йылпумъяське яке тӥ дугдытон зӥбетэз зӥбиськоды, Decoy процессэз быдэстэ но файлэз быдтӥське. Windows-лэн ужпум объектез (job object) заглушкаос Decoy-ен ӵош бырозы шуыса тупатэ, приложение аварийно быриз ке но.

## Пуктон

[Релизъёс](../../../../releases) бамысь бырйе:

| Поныса кельтон | Малы |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталлер.** Одӥг юзерлы, администратор инты уг кулэ, «Пуск» менюе пункт но деинсталлятор ватса. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативной.** Котькытчы паськытатӥське но `decoy.exe` ӧдъялэ. Вань ивортос дораз сылӥсь `data` папкаын возиське, юзерлэн профиляз номыр уг гожтӥськы. Быдтыны понна папкаез гинэ быдтэ. |

Поныса кельтэм файллэсь SHA256 контрольной лыдзэ `SHA256SUMS.txt` юрттэмен эскере (PowerShell пушкын `Get-FileHash <file>`).

Windows SmartScreen тодмотэм поттӥсь сярысь визь-кенеш сётыны быгатэ, малы ке шуоно сборилэн цифровой пусэз ӧвӧл; *More info → Run anyway* (*Подробнее → Выполнить в любом случае*) бырйе, сборилы оскоды ке.

Куронъёс: Windows 10 яке 11 (64-бит) WebView2 runtime средаен (Windows 11 пушкы но берпуметӥ Windows 10 выльдонъёсы пыртэмын ни).

## Кутон

1. **Библиотекаез** усьтэ но шудонэз утчалэ, яке котькытысь `Ctrl` + `K` зӥбе.
2. Шудон вылэ зӥбе. Бур пал панельын бырйе процессэз но кӧня минут кутыны (Discord ужпумъёс ялан 15 минут курыло).
3. **Заглушкаез ӧдъяны** зӥбе. Discord кӧня ке секунд ортчыса шудонэз возьматоз.
4. Сое **Ужасьёс** ӧжытын эскере, одӥгзэ яке ваньзэ котьку дугдытэ, яке Decoy-ез трейын кельтэ.

Шудонъёс, кудъёсызлэн Discord лыдметын быдэстӥськись файлъёссы ай ӧвӧл, огшорыен ватэмын (соосыз шедьтыны уг луы). Соосыз адӟон понна *Exe-тэк шудонъёсыз возьматыны* усьтэ; лыдмет котькуд нунал выльдӥське, соин Discord процесс ватсамем бере соос ужаны кутскозы.

### Команда чурен

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Заглушкаез ӝог ӧдъя, кылсярысь `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Исходникъёсысь сборка

Кулэ луисьёс: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) инструментъёслэн юн люкетсы (MSVC target) Visual Studio C++ сборан инструментъёсын ӵош но WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Пайдаё эскэронъёс:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Валэктон: заглушкалэн exe-ез `src-tauri/build.rs` скриптен огшоры `rustc`-ен `src-tauri/stub/stub.rs` пӧлысь сборитӥське но собере приложени пушкы пыртӥське. Куке фронтенд огшоры браузерын ужа (`npm run dev`), пичи мок-бэкенд (`src/mock.ts`) кутӥське, со интерфейсэн ужаку пайдаё.

## Берыктонъёс

Интерфейс чуръёс [`src/locales`](../../src/locales) пушкын интыясько, быд кыллы одӥг JSON-файл (`en.json`, `ru.json`, ...).
Выль кыл ватсон — со пыр-поч файл ватсон гинэ, кодэз воштытэк. Учке [docs/TRANSLATING.md](../TRANSLATING.md) файлъёслэн форматсы, машинаен берыктонлы дась промпт но эскерон скрипт сярысь. Та README-лэсь берыктонъёссэ `docs/i18n/README.<code>.md` интые пуктӥсько.

## Проектлэн пуштросэз

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Валэктӥсьтэм луонлык

- Decoy вотсэтэз Discord-лэн паськыт тодман лыдметсэ поныса кельтон понна гинэ кутэ (нырысь ӧдъяку, собере нуналаз одӥг поллэсь уно ӧвӧл яке куке выльдон зӥбетэз зӥбиськоды) но Discord CDN-ысь шудонъёслэсь ярлыкъёссэс но обложкаоссэс возьматон понна.
- Приложение тӥляд Discord токендэс яке аккаунт тодэтъёстэс уг лыдӟы, уг возы но уг кельты, озьы ик Discord клиентэн уг вераськы.
- Тупатонъёс (яратоноос, кыл, вакыт) компьютер вылын приложениелэн WebView интыяз кельтӥсько; шудон лыдметлэн кэшез но дырлы заглушка файлъёс `%LOCALAPPDATA%\app.decoy.desktop` пушкын возисько.
- Аналитика ӧвӧл, сӧриськон сярысь ивортонъёс ӧвӧл, аккаунтъёс ӧвӧл.

## Тодмо куронъёс

- Discord тодман радлыксэ котьку воштыны быгатэ. Заглушка тодматскытэк луиз ке, мылкыд карыса issue усьтэ.
- Ог-ог ужпумъёслы ужась процесслэсь уно кулэ (кылсярысь шудон платформалэн пӧртэм плейсаз яке режимаз луон). Decoy процессэз гинэ ӧнертомон каре.
- Discord лыдметын быдэстӥськись файлъёстэк пусъёс тодматскыны уг быгато.
- Утись ПО куд-ог дыръя тодмотэм пичи файлъёс вылэ кышкамон пусъёс пуктыны быгатэ. Заглушкалэн усьтэм кодэз луэ но `src-tauri/stub/stub.rs` пӧлысь сборитӥське; тӥ сое асьтэос сборка карыны быгатӥськоды.

## Ужаны пыриськон

Шекшеськон сярысь ивортонъёс, малпанъёс но берыктонъёс шумпотымон пумисьтӥсько. Мылкыд карыса нырысь ик [CONTRIBUTING.md](../../CONTRIBUTING.md) лыдӟе.

## Кыл кутонлэсь куштӥськон

Decoy асьсэ понна, дышетскон но эскерон понна «кызьы вань» сётӥське. Ужась шудонэз ӧнертомон карон Discord-лэн яке шудон поттӥсьлэн кутон правилоосызлы пумит луыны быгатэ но тӥляд аккаунттылы куронъёс лыдӟыны быгатэ. Кутон понна тӥ асьтэос кыл кутӥськоды. «Discord» но шудонъёслэн нимыз но логотипсы ас кузёоссылэн пусэз луо но татын соос герӟаськем программаосты тодмон карон понна гинэ кутӥсько.
