# Decoy

**Argerdhow byghan a representations a wra dhe Discord tybi bos gwari ow resek.**

![Platfform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Drehevys gans](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Kummyas](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Lyverva Decoy gans gwariow a-dhiwedhes hag art" />

</div>

Decoy a syns argerdh le-dalgher diles gans fenester ow resek yn-dann hanow gwhedhadow gwari, rag may hwra diskwedhyans gwari Discord derivas agas bos ow kwari an gwari na. Nyns eus edhomm vyth dhywgh a stalia po dalleth an gwir wari, ytho nyns eus travyth bras ow triga war agas plasenn.

Ev a wor a-dro dhe **bub gwari a yll Discord diskwedhes** (a-dro dhe 25,000 entry) drefen ev dhe redya rol dhiskwedhes gyffredin Discord y honan ha'y synsi nowedhhes dreza y honan.

> [!WARNING]
> Falsya gwari ow resek a yll mos erbynn Termow Servis Discord hag y devnydhyowgh Decoy **war agas peryl agas honan**.
> Nyns yw an ragdres ma kelmys gans, skoodhys gans po kevrennys dhe Discord Inc. Gwelowgh [Denagh](#denagh).

## Gnasow

- **Pub tra a yll Discord diskwedhes.** Rol an gwariow yw iskargys dhyworth poynt-fin diskwedhes kyffredin Discord, kudhys yn leel ha nowedhhes pub dydh. Gwariow nowydh ha restrow gwhedhadow keworrys a-dhiwedhes a dhiskwedh dhedha i aga honan.
- **Hwilas a gemmer prys.** Hwilas desempis dre hanow gwari po restren whedhadow a-dreus milyow a wariow, gwel kribell po rol vyghan, kevnidheg ha rew "A-dhiwedhes".
- **Unn klyck.** Dewisowgh gwari, dewisowgh an restren whedhadow (mar kyns lies), dewisowgh kemmys termyn dhe'y synsi ha gweskowgh dalleth. Bylgh nivera war-lergh ha kemenans a lever dhywgh pan vo an prys leun.
- **Ny as travyth a-dhelergh.** Decoy a exist hepken tra vo ow resek: an exe byghan yw gwrys orth dalleth ha delys orth hedhi. Pub tra yw hedhys pan dhiberthowgh, ha remenans dhyworth terredh yw klerhes orth an nessa dalleth.
- **Kosel.** Trigys yn tirek an system, fenester vyth po botonyow bar oberennow vyth rag an decoyow aga honan.
- **Treylyansow ygor.** An ynterfas yw relys gans restrow JSON sempel, ytho keworra yeth yw unn restren hepken. Kernowek, Sowsnek ha Russek yw komprehendys.
- **Privad.** Reknans vyth, token Discord vyth, telemetrieth vyth. Gwelowgh [Privader](#privader).

## Fatell wra oberi

1. Discord a dhewis agas bos ow kwari gwari der viras orth an argerdhow ow resek war agas PC ha keheveli aga henwyn gwhedhadow gans rol gyffredin (`/api/v9/applications/detectable`).
2. Decoy a iskarg an rol na ha, rag an gwari a dhewisowgh, eila programm byghan le-dalgher (a-dro dhe 120 KB, skrifys yn Rust ha kemyskys yn Decoy) dhe folder tridhydhyek ow devnydhya an hanow gwhedhadow dhyworth an rol, rag ensampel `.../cod26-cod.exe`.
3. Ny wra an le-dalgher travyth marnas perhengi unn fenester a-wartha, parkys pell dhyworth an skrin may na wellowgh vyth henna. Discord a aswon hepken argerdh a berhen fenester, ha drefen henna argerdh heb fenester vyth yw hegarhes.
4. A-berth a-dro dhe 15 eylen Discord a dhiskwedh an gwari avel agas gweythres a-lemmyn.
5. Pan vo an amseryer leun po pan weskowgh hedhi, Decoy a dhiwedh an argerdh ha dilea an restren. Tra gweyth Windows a wra sur bos decoyow ow merwel war-barth gans Decoy, kyn hwrello terri.

## Enstallya

Dewisowgh unn dhyworth an folen [Releases](../../../../releases):

| Iskarg | Rag |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Enstallyer.** Rag pub devnydhyer, nyns eus edhomm gwiryow menystrer, a geworr entry dhe'n rol Dalleth ha dienstallyer. |
| `Decoy_x.y.z_x64-portable.zip` | **Degadow.** Digompressya yn neb le ha resek `decoy.exe`. Pub data a drig y'n folder `data` rybdo, ny skrifir travyth dhe agas profil devnydhyer. Dileowgh an folder rag y dhilea. |

Gwirya iskarg gans `SHA256SUMS.txt` (`Get-FileHash <file>` yn PowerShell).

Windows SmartScreen a yll gwarnya a-dro dhe dhyller anaswonys drefen na vo an drehevyansow sinys gans kod; dewisowgh *Moy aKedhlow → Resek byttegyns* mar krysowgh an drehevyans.

Ethegommow: Windows 10 po 11 (64-bit) gans an amgylchva resek WebView2 (komprehendys dija yn Windows 11 ha nowedhansow a-dhiwedhes Windows 10).

## Devnydh

1. Ygeryowgh **Lyverva** ha hwilas gwari, po gweskowgh `Ctrl` + `K` dhyworth neb le.
2. Klyckyowgh gwari. Y'n panel a-dhyhow dewisowgh an argerdh ha pygemmys a vynysennow dhe'y synsi (gweythresow Discord a berdh 15 yn fenowgh).
3. Gweskowgh **Dalleth decoy**. Discord a dhiskwedh an gwari wosa nebes eylennyow.
4. Miror orth y dhiskwedhes yn-dann **Ow resek**, hedhi unn po pubonan orth neb prys, po gasa Decoy y'n tirek.

Gwariow nag eus dhedha restrow gwhedhadow hwath yn entry Discord yw kudhys dre ragdhewis (ny yllons bos diskwedhys). Gweythresowgh *Diskwedhes gwariow heb exe* rag aga gweles; an rol yw nowedhhes pub dydh, ytho i a vydh kavadow a-dhesempis pan geworro Discord argerdh.

### Linen arhadow

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

A dhell decoy a-dhesempis, rag ensampel `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Drehevel dhyworth an fenten

Rag-edhommow: [Node.js](https://nodejs.org) 20+, an ostel daffar [Rust](https://rustup.rs) sad (targys MSVC) gans daffar drehevel C++ Visual Studio, ha'n amgylchva resek WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # resek yn modh displegya gans eildommder
npm run tauri build    # askorra an enstallyer yn src-tauri/target/release/bundle/nsis
```

Gwiriansow dhevnydhus:

```bash
npm run check-locales  # gwirya pub restren dreylyans erbynn ru.json
npx tsc --noEmit       # gwirya eghennow an ragva
cargo check --manifest-path src-tauri/Cargo.toml
```

Notennow: an exe decoy yw komprehendys gans `src-tauri/build.rs` gans `rustc` sempel dhyworth `src-tauri/stub/stub.rs` hag ena kemyskys y'n gweythres. Pan res an ragva yn peurel sempel (`npm run dev`) kilva mock vyghan (`src/mock.ts`) yw devnydhys, hag yw hegas rag oberi war an ynterfas.

## Treylyansow

Linennow an ynterfas a drig yn [`src/locales`](../../src/locales), unn restren JSON rag pub yeth (`en.json`, `ru.json`, ...).
Keworra yeth a styr keworra restren; chanj vyth y'n kod. Gwelowgh [docs/TRANSLATING.md](../TRANSLATING.md) rag format an restren, profyans parys rag treylyans jynn ha'n skript gwirya. Treylyansow a'n README ma a dryg yn `docs/i18n/README.<code>.md`.

## Format an ragdres

```
src/                    Ragva React + TypeScript
  components/           Lyverva, panel manylyon, settyansow, ...
  locales/              restrow treylyans (unn JSON rag pub yeth)
  i18n-core.ts          karga ha hwilas yeth
  store.ts              studh an gweythres (zustand)
src-tauri/              Kilva Rust (Tauri 2)
  src/lib.rs            sel-data gwariow, argerdhow decoy, tirek
  stub/stub.rs          an programm le-dalgher kemyskys
scripts/                skriptys gweres (gwirya yethow)
docs/                   kynnik treylya, skeusennow skrin
```

## Privader

- Ny wra Decoy devnydhya an rosweyth marnas rag iskarga rol dhiskwedhes gyffredin Discord (orth an dalleth kensa, ena dhe'n moyha unnweyth an dydh po pan weskowgh nowedhhe) ha, rag diskwedhes, arwodhyow gwariow hag art dhyworth CDN kyffredin Discord.
- Ny wra redya, gwitha po danvon agas token Discord po data reknans vyth, ha ny gows gans kliyent Discord.
- Settyansow (kevnidheg, yeth, prysow) yw gwithys yn leel yn gwithas WebView an gweythres; kovva rol an gwariow ha restrow decoy tridhydhyek a drig yn `%LOCALAPPDATA%\app.decoy.desktop`.
- Dadelfennans vyth, derivas terredh vyth, reknans vyth.

## Bevennow aswonys

- Discord a yll chanjya fatell wra diskwedhes oberi orth neb prys. Mar kens decoy bos aswonys, ygerowgh kudyn mar pleg.
- Nebes gweythresow a berdh moy ages argerdh ow resek (rag ensampel bos a-berth yn arbrov dibarow a blatfform gwari). Decoy a wra hepken ladra an argerdh.
- Entris heb restrow gwhedhadow yn rol Discord ny yllons bos diskwedhys.
- Medhelweyth sawder a yll treweythyow merkya restrow gwhedhadow byghan heb sinans a esedh yn kosel y'n kov. An decoy yw fenten ygor ha drehevys dhyworth `src-tauri/stub/stub.rs`; hwi a yll y gomprehendya agas honan.

## Kevrenna

Derivadow troblys, tybyansow ha treylyansow yw wolkommys. Redyowgh [CONTRIBUTING.md](../../CONTRIBUTING.md) yn kensa mar pleg.

## Denagh

Decoy yw res "kepar dell yw" rag amkanow personel, adhyskansel ha previ. Ladra gwari ow resek a yll terri Termow Servis Discord po dhyller an gwari, ha gallos dres dhe dherevel erbynn agas reknans. Hwi agas honan yw omgemeryansek rag fatell y's devnydhyowgh. "Discord" ha pub hanow gwari hag arwodh yw merkys kenwerth aga ferhennoryon ha devnydhys omma hepken rag aswon an medhelweyth mayth erons ow kows dhedha.
