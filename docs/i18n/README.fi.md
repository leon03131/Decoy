# Decoy

**Pieniä valeprosesseja, jotka saavat Discordin luulemaan pelin olevan käynnissä.**

![Alusta](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Rakennettu työkalulla](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Lisenssi](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-kirjasto viimeaikaisine peleineen ja kuvituksineen" />

</div>

Decoy pitää käynnissä vaarattoman ikkunallisen valeprosessin pelin suoritettavan tiedoston nimellä, jolloin Discordin pelintunnistus näyttää sinun pelaavan kyseistä peliä. Oikeaa peliä ei tarvitse koskaan asentaa tai käynnistää, joten levytilaa ei kulu turhaan.

Se tuntee **jokaisen pelin, jonka Discord voi tunnistaa** (noin 25 000 kohdetta), koska se lukee Discordin omaa julkista tunnistuslistaa ja pitää sen automaattisesti ajan tasalla.

> [!WARNING]
> Käynnissä olevan pelin jäljitteleminen voi olla Discordin käyttöehtojen vastaista, ja käytät Decoyta **omalla vastuullasi**.
> Tämä projekti ei ole sidoksissa Discord Inc. -yhtiöön, eikä se ole sen tukema tai hyväksymä. Katso [Vastuuvapauslauseke](#vastuuvapauslauseke).

## Ominaisuudet

- **Kaikki, mitä Discord voi tunnistaa.** Peliluettelo ladataan Discordin julkisesta tunnistusrajapinnasta, tallennetaan välimuistiin paikallisesti ja päivitetään päivittäin. Uudet pelit ja äskettäin lisätyt suoritettavat tiedostot ilmestyvät näkyviin automaattisesti.
- **Pysyy mukana haussa.** Välitön haku pelin tai suoritettavan tiedoston nimellä tuhansien pelien joukosta, ruudukko- tai tiivis luettelonäkymä, suosikit ja ”Viimeisimmät”-rivi.
- **Yhdellä napsautuksella.** Valitse peli, valitse suoritettava tiedosto (jos niitä on useita), valitse kesto ja paina käynnistä. Ajastinrengas ja ilmoitus kertovat, kun aika on kulunut umpeen.
- **Ei jätä jälkiä.** Valeprosessi on olemassa vain suorituksen aikana: pieni exe luodaan käynnistettäessä ja poistetaan pysäytettäessä. Kaikki pysäytetään sovelluksesta poistuttaessa, ja mahdolliset kaatumisen jäljiltä jääneet tiedostot siivotaan seuraavalla käynnistyskerralla.
- **Huomaamaton.** Toimii ilmoitusalueella, eikä itse valeprosesseille näytetä ikkunoita tai tehtäväpalkin painikkeita.
- **Avoimet käännökset.** Käyttöliittymä toimii tavallisten JSON-tiedostojen pohjalta, joten kielen lisääminen vaatii vain yhden tiedoston. Englanti ja venäjä ovat mukana valmiina.
- **Yksityinen.** Ei käyttäjätiliä, ei Discord-tunnistetta, ei telemetriaa. Katso [Yksityisyys](#yksityisyys).

## Miten se toimii

1. Discord päättelee sinun pelaavan peliä tarkastelemalla tietokoneellasi käynnissä olevia prosesseja ja vertaamalla niiden suoritettavien tiedostojen nimiä julkiseen luetteloon (`/api/v9/applications/detectable`).
2. Decoy lataa kyseisen luettelon ja kopioi valitsemallesi pelille pienen sijaisohjelman (noin 120 kt, kirjoitettu Rustilla ja upotettu Decoyhin) väliaikaiseen kansioon luettelossa olevalla suoritettavan tiedoston nimellä, esimerkiksi `.../cod26-cod.exe`.
3. Sijaisohjelma ei tee muuta kuin omistaa yhden ylätason ikkunan, joka on sijoitettu kauas näytön ulkopuolelle, jotta et koskaan näe sitä. Discord tunnistaa vain prosessin, jolla on ikkuna, minkä vuoksi täysin ikkunattomat prosessit jätetään huomiotta.
4. Noin 15 sekunnin kuluessa Discord näyttää pelin nykyisenä aktiviteettinasi.
5. Kun ajastin päättyy tai painat pysäytyspainiketta, Decoy lopettaa prosessin ja poistaa tiedoston. Windowsin job object -mekanismi varmistaa, että valeprosessit sulkeutuvat aina yhdessä Decoyn kanssa, vaikka se kaatuisi.

## Asennus

Valitse haluamasi vaihtoehto [Releases](../../../../releases) -sivulta:

| Lataus | Soveltuvuus |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Asennusohjelma.** Käyttäjäkohtainen, ei vaadi järjestelmänvalvojan oikeuksia, lisää Käynnistä-valikon kuvakkeen ja poisto-ohjelman. |
| `Decoy_x.y.z_x64-portable.zip` | **Kannettava.** Pura mihin tahansa ja käynnistä `decoy.exe`. Kaikki tiedot säilytetään sen vieressä olevassa `data`-kansiossa, mitään ei kirjoiteta käyttäjäprofiiliisi. Poista kansio poistaaksesi sovelluksen. |

Tarkista ladatun tiedoston eheys `SHA256SUMS.txt`-tiedoston avulla (`Get-FileHash <tiedosto>` PowerShellissä).

Windows SmartScreen saattaa varoittaa tuntemattomasta julkaisijasta, koska koontiversioita ei ole koodiallekirjoitettu; valitse *Lisätietoja → Suorita silti*, jos luotat versioon.

Järjestelmävaatimukset: Windows 10 tai 11 (64-bittinen) ja WebView2-suoritusympäristö (sisältyy jo Windows 11:een ja tuoreisiin Windows 10 -päivityksiin).

## Käyttö

1. Avaa **Kirjasto** ja hae peliä tai paina `Ctrl` + `K` missä tahansa sovelluksessa.
2. Napsauta peliä. Valitse oikeanpuoleisesta paneelista prosessi ja se, kuinka monta minuuttia sitä pidetään käynnissä (Discordin aktiviteetit vaativat yleensä 15 minuuttia).
3. Napsauta **Käynnistä decoy**. Discord näyttää pelin muutaman sekunnin kuluttua.
4. Seuraa tilaa osiossa **Käynnissä**, pysäytä yksi tai kaikki milloin tahansa, tai jätä Decoy ilmoitusalueelle.

Pelit, joiden Discord-tiedoissa ei vielä ole suoritettavia tiedostoja, on piilotettu oletuksena (niitä ei voida tunnistaa). Ota käyttöön *Näytä pelit ilman exeä* nähdäksesi ne; luettelo päivitetään päivittäin, joten ne tulevat saataville heti, kun Discord lisää prosessin.

### Komentorivi

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Käynnistää valeprosessin välittömästi, esimerkiksi `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kokoaminen lähdekoodista

Esivaatimukset: [Node.js](https://nodejs.org) 20+, vakaa [Rust](https://rustup.rs) -työkaluketju (MSVC-kohde) sekä Visual Studion C++ -käännöstyökalut ja WebView2-suoritusympäristö.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Hyödyllisiä tarkistuksia:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Huomautuksia: valeprosessin exe käännetään tiedostolla `src-tauri/build.rs` käyttäen tavallista `rustc`-kääntäjää lähdekoodista `src-tauri/stub/stub.rs`, ja se upotetaan sovellukseen. Kun käyttöliittymää suoritetaan tavallisessa selaimessa (`npm run dev`), käytetään pientä mock-taustajärjestelmää (`src/mock.ts`), mikä on kätevää käyttöliittymän kehitystyössä.

## Käännökset

Käyttöliittymän merkkijonot sijaitsevat hakemistossa [`src/locales`](../../src/locales), yksi JSON-tiedosto kieltä kohden (`en.json`, `ru.json`, ...). Kielen lisääminen tarkoittaa vain uuden tiedoston lisäämistä ilman koodimuutoksia. Katso tiedostomuoto, valmis kehote konekääntämistä varten sekä tarkistusskripti ohjeesta [docs/TRANSLATING.md](../TRANSLATING.md). Tämän README-tiedoston käännökset tallennetaan polkuun `docs/i18n/README.<code>.md`.

## Projektin rakenne

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Yksityisyys

- Decoy käyttää verkkoyhteyttä vain Discordin julkisen tunnistusluettelon lataamiseen (ensimmäisellä käynnistyskerralla, sen jälkeen korkeintaan kerran päivässä tai päivitystä painettaessa) sekä pelikuvakkeiden ja kuvitusten näyttämiseen Discordin julkisesta CDN-verkosta.
- Se ei lue, tallenna tai lähetä Discord-tunnistettasi tai mitään tilitietojasi, eikä se kommunikoi Discord-asiakasohjelman kanssa.
- Asetukset (suosikit, kieli, kestot) tallennetaan paikallisesti sovelluksen WebView-tallennustilaan; peliluettelon välimuisti ja tilapäiset valeprosessitiedostot sijaitsevat kansiossa `%LOCALAPPDATA%\app.decoy.desktop`.
- Ei analytiikkaa, ei kaatumisraportointia, ei käyttäjätilejä.

## Tunnetut rajoitukset

- Discord voi muuttaa tunnistuksen toimintatapaa milloin tahansa. Jos valeprosessia ei enää tunnisteta, avaa ongelmaraportti (issue).
- Jotkin aktiviteetit vaativat enemmän kuin pelkän käynnissä olevan prosessin (esimerkiksi olemisen tietyssä pelialustan pelitilassa tai kokemuksessa). Decoy jäljittelee vain prosessia.
- Kohteita, joilla ei ole suoritettavia tiedostoja Discordin luettelossa, ei voida tunnistaa.
- Tietoturvaohjelmat saattavat toisinaan varoittaa pienistä allekirjoittamattomista suoritettavista tiedostoista, jotka ovat käyttämättöminä muistissa. Decoy on avointa lähdekoodia ja se rakennetaan tiedostosta `src-tauri/stub/stub.rs`; voit kääntää sen itse.

## Vastuuvapauslauseke

Decoy toimitetaan ”sellaisena kuin se on” henkilökohtaiseen, koulutukselliseen ja testaustarkoitukseen. Käynnissä olevan pelin jäljitteleminen saattaa rikkoa Discordin tai pelijulkaisijan käyttöehtoja ja voi johtaa tiliisi kohdistuviin toimenpiteisiin. Olet yksin vastuussa sen käytöstä. ”Discord” ja kaikki pelien nimet sekä logot ovat omistajiensa tavaramerkkejä, ja niitä käytetään tässä yhteydessä vain viittaamaan kyseisiin ohjelmistoihin.
