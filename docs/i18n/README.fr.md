# Decoy

**De minuscules processus leurres qui font croire à Discord qu'un jeu est en cours d'exécution.**

![Plateforme](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Développé avec](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Licence](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibliothèque Decoy avec les jeux récents et leurs illustrations" />

</div>

Decoy maintient un processus fictif inoffensif avec fenêtre sous le nom de l'exécutable d'un jeu, de sorte que la détection de jeux de Discord indique que vous jouez à ce jeu. Vous n'avez jamais besoin d'installer ni de lancer le vrai jeu, rien d'encombrant n'occupe donc votre disque.

Il connaît **tous les jeux que Discord peut détecter** (environ 25 000 entrées) en lisant directement la liste de détection publique de Discord et en la maintenant à jour automatiquement.

> [!WARNING]
> Simuler un jeu en cours d'exécution peut enfreindre les Conditions d'utilisation de Discord et vous utilisez Decoy **à vos propres risques**.
> Ce projet n'est ni affilié à, ni approuvé par, ni associé à Discord Inc. Voir [Avertissement](#avertissement).

## Fonctionnalités

- **Tout ce que Discord peut détecter.** La liste des jeux est téléchargée depuis le point de terminaison public de détection de Discord, mise en cache localement et actualisée chaque jour. Les nouveaux jeux et les exécutables récemment ajoutés s'affichent automatiquement.
- **Une recherche performante.** Recherche instantanée par nom de jeu ou nom d'exécutable parmi des milliers de jeux, affichage sous forme de grille ou de liste compacte, favoris et section « Récents ».
- **En un clic.** Choisissez un jeu, sélectionnez l'exécutable (s'il y en a plusieurs), choisissez la durée de maintien et appuyez sur démarrer. Un anneau de compte à rebours et une notification vous avertissent lorsque le temps est écoulé.
- **Ne laisse aucune trace.** Un leurre n'existe que pendant son exécution : le minuscule exe est créé au lancement et supprimé à l'arrêt. Tout s'arrête lorsque vous quittez l'application, et les résidus éventuels d'un plantage sont nettoyés au lancement suivant.
- **Discret.** Reste dans la zone de notification, sans aucune fenêtre ni bouton dans la barre des tâches pour les leurres eux-mêmes.
- **Traductions ouvertes.** L'interface s'appuie sur de simples fichiers JSON, ajouter une langue se résume donc à ajouter un seul fichier. L'anglais et le russe sont inclus.
- **Respect de la vie privée.** Aucun compte, aucun jeton Discord, aucune télémétrie. Voir [Confidentialité](#confidentialité).

## Comment ça marche

1. Discord détermine que vous jouez à un jeu en examinant les processus en cours d'exécution sur votre PC et en comparant leurs noms d'exécutables avec une liste publique (`/api/v9/applications/detectable`).
2. Decoy télécharge cette liste et, pour le jeu choisi, copie un minuscule programme de remplacement (environ 120 Ko, écrit en Rust et intégré dans Decoy) dans un dossier temporaire en reprenant le nom de l'exécutable figurant dans la liste, par exemple `.../cod26-cod.exe`.
3. Le programme de remplacement ne fait rien d'autre que détenir une fenêtre de premier niveau, placée bien en dehors de l'écran pour que vous ne la voyiez jamais. Discord ne reconnaît qu'un processus qui détient une fenêtre, ce qui explique pourquoi un processus totalement dépourvu de fenêtre est ignoré.
4. En l'espace d'environ 15 secondes, Discord affiche le jeu comme votre activité actuelle.
5. Lorsque le minuteur arrive à son terme ou que vous cliquez sur arrêter, Decoy termine le processus et supprime le fichier. Un objet job Windows garantit que les leurres s'arrêtent en même temps que Decoy, même en cas de plantage inopiné.

## Installation

Choisissez-en un sur la page des [Releases](../../../../releases) :

| Téléchargement | Pour |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installateur.** Par utilisateur, aucun droit d'administrateur requis, ajoute une entrée dans le menu Démarrer et un outil de désinstallation. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Décompressez l'archive où vous le souhaitez et lancez `decoy.exe`. Toutes les données restent dans le dossier `data` à côté de l'exécutable, rien n'est écrit dans votre profil utilisateur. Supprimez simplement le dossier pour le désinstaller. |

Vérifiez l'intégrité d'un téléchargement avec `SHA256SUMS.txt` (`Get-FileHash <fichier>` dans PowerShell).

Windows SmartScreen peut afficher un avertissement indiquant un éditeur non reconnu car les exécutables ne sont pas signés numériquement ; cliquez sur *Informations complémentaires → Exécuter quand même* si vous faites confiance au fichier.

Configuration requise : Windows 10 ou 11 (64 bits) avec le runtime WebView2 (déjà inclus dans Windows 11 et les mises à jour récentes de Windows 10).

## Utilisation

1. Ouvrez la **Bibliothèque** et recherchez un jeu, ou appuyez sur `Ctrl` + `K` depuis n'importe où.
2. Cliquez sur un jeu. Dans le panneau de droite, choisissez le processus et le nombre de minutes pendant lesquelles le maintenir (les activités Discord demandent généralement 15 minutes).
3. Cliquez sur **Démarrer le leurre**. Discord affichera le jeu au bout de quelques secondes.
4. Surveillez-le dans **En cours**, arrêtez un ou tous les leurres à tout moment, ou laissez simplement Decoy dans la zone de notification.

Les jeux dont la fiche Discord ne comporte pas encore d'exécutables sont masqués par défaut (ils ne peuvent pas être détectés). Activez l'option *Afficher les jeux sans exe* pour les afficher ; la liste est actualisée quotidiennement, ils deviennent donc disponibles dès que Discord ajoute un processus.

### Ligne de commande

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Lance immédiatement un leurre, par exemple `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilation depuis les sources

Prérequis : [Node.js](https://nodejs.org) 20+, la chaîne d'outils stable de [Rust](https://rustup.rs) (cible MSVC) avec les outils de compilation C++ de Visual Studio, et le runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Vérifications utiles :

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Remarques : l'exécutable du leurre est compilé par `src-tauri/build.rs` avec un simple `rustc` à partir de `src-tauri/stub/stub.rs`, puis intégré dans l'application. Lorsque le frontend s'exécute dans un simple navigateur (`npm run dev`), un léger backend fictif (`src/mock.ts`) est utilisé, ce qui s'avère très pratique pour travailler sur l'interface graphique.

## Traductions

Les textes de l'interface résident dans [`src/locales`](../../src/locales), à raison d'un fichier JSON par langue (`en.json`, `ru.json`, ...).
Ajouter une langue consiste simplement à ajouter un fichier, sans aucune modification du code source. Consultez [docs/TRANSLATING.md](../TRANSLATING.md) pour obtenir la structure du fichier, un prompt prêt à l'emploi pour la traduction automatique et le script de validation. Les traductions de ce README sont placées dans `docs/i18n/README.<code>.md`.

## Structure du projet

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Confidentialité

- Decoy utilise le réseau uniquement pour télécharger la liste publique de détection de Discord (au premier lancement, puis au maximum une fois par jour ou lorsque vous cliquez sur actualiser) et, pour l'affichage, les icônes et illustrations de jeux depuis le CDN public de Discord.
- Il ne lit, n'enregistre ni ne transmet aucun jeton Discord ni aucune donnée de compte, et ne communique aucunement avec le client Discord.
- Les paramètres (favoris, langue, durées) sont conservés localement dans le stockage WebView de l'application ; le cache de la liste des jeux et les fichiers temporaires des leurres résident dans `%LOCALAPPDATA%\app.decoy.desktop`.
- Aucun outil d'analyse, aucun rapport de plantage, aucun compte utilisateur.

## Limitations connues

- Discord peut modifier le fonctionnement de sa détection à tout moment. Si un leurre n'est plus reconnu, n'hésitez pas à ouvrir un ticket (issue).
- Certaines activités requièrent davantage qu'un processus en cours d'exécution (par exemple, être dans une expérience particulière d'une plateforme de jeu). Decoy imite uniquement le processus.
- Les entrées ne possédant aucun exécutable dans la liste de Discord ne peuvent pas être détectées.
- Les logiciels de sécurité signalent parfois de petits exécutables non signés restant inactifs en mémoire. Le leurre est open source et compilé à partir de `src-tauri/stub/stub.rs` ; vous pouvez le compiler vous-même.
