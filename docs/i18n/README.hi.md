# Decoy

**छोटे स्टैंड-इन प्रोसेस जो Discord को दिखाते हैं कि कोई गेम चल रहा है।**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="हाल के गेम्स और आर्टवर्क के साथ Decoy लाइब्रेरी" />

</div>

Decoy किसी गेम के executable नाम के तहत एक हानिरहित, विंडो वाला प्लेसहोल्डर प्रोसेस चालू रखता है, जिससे Discord का गेम डिटेक्शन आपको वह गेम खेलते हुए दिखाता है। आपको कभी भी असली गेम को इंस्टॉल या लॉन्च करने की आवश्यकता नहीं होती, इसलिए आपकी डिस्क पर कोई भारी फ़ाइल नहीं रहती।

यह **हर उस गेम को पहचानता है जिसे Discord डिटेक्ट कर सकता है** (लगभग 25,000 प्रविष्टियाँ), क्योंकि यह Discord की अपनी सार्वजनिक डिटेक्शन सूची को पढ़ता है और इसे अपने आप अपडेट रखता है।

> [!WARNING]
> चलते हुए गेम का दिखावा करना Discord की सेवा की शर्तों (Terms of Service) के विरुद्ध हो सकता है और आप Decoy का उपयोग **अपने जोखिम पर** करते हैं।
> यह प्रोजेक्ट Discord Inc. से संबद्ध, समर्थित या जुड़ा हुआ नहीं है। [अस्वीकरण](#अस्वीकरण) देखें।

## विशेषताएँ

- **वह सब कुछ जिसे Discord डिटेक्ट कर सकता है।** गेम सूची Discord के सार्वजनिक डिटेक्शन एंडपॉइंट से डाउनलोड की जाती है, स्थानीय रूप से कैश की जाती है और प्रतिदिन रीफ़्रेश होती है। नए गेम्स और नई जोड़ी गई executables अपने आप दिखाई देने लगती हैं।
- **तेज़ और सटीक खोज।** हज़ारों गेम्स में गेम के नाम या executable द्वारा त्वरित खोज, ग्रिड या कॉम्पैक्ट सूची दृश्य, पसंदीदा और एक "Recent" पंक्ति।
- **एक क्लिक।** कोई गेम चुनें, executable चुनें (यदि कई हों), तय करें कि इसे कितनी देर तक चलाना है और स्टार्ट दबाएँ। एक उलटी गिनती (काउंटडाउन) रिंग और नोटिफिकेशन आपको समय पूरा होने की सूचना देते हैं।
- **पीछे कुछ नहीं छोड़ता।** एक decoy केवल तभी तक रहता है जब तक वह चलता है: छोटी exe फ़ाइल शुरू होने पर बनाई जाती है और बंद होने पर हटा दी जाती है। आपके बाहर निकलने पर सब कुछ बंद हो जाता है, और क्रैश के बचे हुए अवशेष अगले लॉन्च पर साफ़ कर दिए जाते हैं।
- **शांत।** सिस्टम ट्रे में रहता है, decoys के लिए स्वयं कोई विंडो या टास्कबार बटन नहीं होते।
- **खुले अनुवाद।** इंटरफ़ेस साधारण JSON फ़ाइलों द्वारा संचालित होता है, इसलिए नई भाषा जोड़ना केवल एक फ़ाइल का काम है। अंग्रेज़ी और रूसी शामिल हैं।
- **निजी।** कोई खाता नहीं, कोई Discord टोकन नहीं, कोई टेलीमेट्री नहीं। [गोपनीयता](#गोपनीयता) देखें।

## यह कैसे काम करता है

1. Discord आपके PC पर चल रहे प्रोसेसों को देखकर और उनके executable नामों की तुलना एक सार्वजनिक सूची (`/api/v9/applications/detectable`) से करके यह निर्धारित करता है कि आप कोई गेम खेल रहे हैं।
2. Decoy उस सूची को डाउनलोड करता है और, आपके द्वारा चुने गए गेम के लिए, सूची से executable नाम का उपयोग करके एक छोटे स्टैंड-इन प्रोग्राम (लगभग 120 KB, Rust में लिखा गया और Decoy में अंतर्निहित) को एक अस्थायी फ़ोल्डर में कॉपी करता है, उदाहरण के लिए `.../cod26-cod.exe`।
3. यह स्टैंड-इन एक शीर्ष-स्तरीय (top-level) विंडो रखने के अलावा कुछ नहीं करता, जिसे स्क्रीन से काफी दूर रखा जाता है ताकि आप इसे कभी न देखें। Discord केवल उस प्रोसेस को पहचानता है जिसके पास एक विंडो होती है, यही कारण है कि पूरी तरह से विंडो-रहित प्रोसेस को अनदेखा कर दिया जाता है।
4. लगभग 15 सेकंड के भीतर Discord उस गेम को आपकी वर्तमान गतिविधि के रूप में दिखाने लगता है।
5. जब टाइमर समाप्त हो जाता है या आप स्टॉप दबाते हैं, तो Decoy प्रोसेस को समाप्त कर देता है और फ़ाइल को हटा देता है। एक Windows जॉब ऑब्जेक्ट यह सुनिश्चित करता है कि Decoy क्रैश होने पर भी decoys Decoy के साथ ही बंद हो जाएँ।

## इंस्टॉल करें

[Releases](../../../../releases) पेज से एक विकल्प चुनें:

| डाउनलोड | के लिए |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **इन्स्टॉलर।** प्रति-उपयोगकर्ता, व्यवस्थापक (administrator) अधिकारों की आवश्यकता नहीं है, स्टार्ट मेनू में एक प्रविष्टि और एक अनइन्स्टॉलर जोड़ता है। |
| `Decoy_x.y.z_x64-portable.zip` | **पोर्टेबल।** कहीं भी अनज़िप करें और `decoy.exe` चलाएँ। सारा डेटा इसके बगल में स्थित `data` फ़ोल्डर में रहता है, आपके उपयोगकर्ता प्रोफ़ाइल में कुछ भी नहीं लिखा जाता है। इसे हटाने के लिए फ़ोल्डर को हटा दें। |

`SHA256SUMS.txt` के साथ डाउनलोड की पुष्टि करें (PowerShell में `Get-FileHash <file>`)।

Windows SmartScreen किसी अपरिचित प्रकाशक (unrecognized publisher) के बारे में चेतावनी दे सकता है क्योंकि बिल्ड कोड-साइन नहीं किए गए हैं; यदि आप बिल्ड पर भरोसा करते हैं तो *More info → Run anyway* चुनें।

आवश्यकताएँ: Windows 10 या 11 (64-bit) के साथ WebView2 रनटाइम (पहले से ही Windows 11 और हाल के Windows 10 अपडेट में शामिल है)।

## उपयोग

1. **Library** खोलें और किसी गेम को खोजें, या कहीं से भी `Ctrl` + `K` दबाएँ।
2. किसी गेम पर क्लिक करें। दाईं ओर के पैनल में प्रोसेस चुनें और यह चुनें कि इसे कितने मिनट तक चलाना है (Discord गतिविधियों के लिए आमतौर पर 15 मिनट की आवश्यकता होती है)।
3. **Start decoy** दबाएँ। Discord कुछ सेकंड के बाद गेम दिखाने लगेगा।
4. इसे **Running** के अंतर्गत देखें, किसी भी समय एक या सभी को रोकें, या Decoy को सिस्टम ट्रे में छोड़ दें।

वे गेम जिनकी Discord प्रविष्टि में अभी तक कोई executables नहीं हैं, डिफ़ॉल्ट रूप से छिपे होते हैं (उन्हें डिटेक्ट नहीं किया जा सकता)। उन्हें देखने के लिए *Show games without exe* चालू करें; सूची प्रतिदिन रीफ़्रेश होती है, इसलिए जैसे ही Discord कोई प्रोसेस जोड़ता है, वे उपलब्ध हो जाते हैं।

### कमांड लाइन

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

तुरंत एक decoy शुरू करता है, उदाहरण के लिए `decoy.exe --launch "robloxplayerbeta.exe" 15`।

## सोर्स से बिल्ड करें

पूर्वापेक्षाएँ: [Node.js](https://nodejs.org) 20+, Visual Studio C++ बिल्ड टूल्स के साथ स्थिर [Rust](https://rustup.rs) टूलचेन (MSVC टारगेट), और WebView2 रनटाइम।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

उपयोगी जाँच:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

नोट्स: decoy exe को `src-tauri/build.rs` द्वारा साधारण `rustc` के साथ `src-tauri/stub/stub.rs` से संकलित किया जाता है और फिर ऐप में अंतर्निहित किया जाता है। जब फ्रंटएंड एक सामान्य ब्राउज़र में चलता है (`npm run dev`), तो एक छोटा मॉक बैकएंड (`src/mock.ts`) उपयोग किया जाता है, जो UI पर काम करने के लिए सुविधाजनक है।

## अनुवाद

UI स्ट्रिंग्स [`src/locales`](../../src/locales) में रहती हैं, प्रति भाषा एक JSON फ़ाइल (`en.json`, `ru.json`, ...)।
एक भाषा जोड़ने का अर्थ है एक फ़ाइल जोड़ना; कोई कोड परिवर्तन नहीं। फ़ाइल प्रारूप, मशीन अनुवाद के लिए एक तैयार प्रॉम्प्ट और सत्यापन स्क्रिप्ट के लिए [docs/TRANSLATING.md](../TRANSLATING.md) देखें। इस README के अनुवाद `docs/i18n/README.<code>.md` में जाते हैं।

## प्रोजेक्ट संरचना

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## गोपनीयता

- Decoy केवल Discord की सार्वजनिक डिटेक्शन सूची (पहली बार शुरू होने पर, फिर दिन में अधिक से अधिक एक बार या जब आप रीफ़्रेश दबाते हैं) और डिस्प्ले के लिए Discord के सार्वजनिक CDN से गेम आइकन और आर्टवर्क डाउनलोड करने के लिए नेटवर्क का उपयोग करता है।
- यह आपके Discord टोकन या किसी भी खाता डेटा को नहीं पढ़ता, संग्रहीत नहीं करता या भेजता नहीं है, और यह Discord क्लाइंट से बात नहीं करता है।
- सेटिंग्स (पसंदीदा, भाषा, अवधि) स्थानीय रूप से ऐप के WebView स्टोरेज में संग्रहीत की जाती हैं; गेम सूची कैश और अस्थायी decoy फ़ाइलें `%LOCALAPPDATA%\app.decoy.desktop` में रहती हैं।
- कोई एनालिटिक्स नहीं, कोई क्रैश रिपोर्टिंग नहीं, कोई खाता नहीं।

## ज्ञात सीमाएँ

- Discord किसी भी समय डिटेक्शन के काम करने के तरीके को बदल सकता है। यदि कोई decoy पहचाना जाना बंद हो जाता है, तो कृपया एक issue खोलें।
- कुछ गतिविधियों के लिए केवल एक चलते हुए प्रोसेस से अधिक की आवश्यकता होती है (उदाहरण के लिए किसी गेम प्लेटफ़ॉर्म के किसी विशेष अनुभव के अंदर होना)। Decoy केवल प्रोसेस की नकल करता है।
- Discord की सूची में बिना executables वाली प्रविष्टियों को डिटेक्ट नहीं किया जा सकता है।
- सुरक्षा सॉफ़्टवेयर कभी-कभी छोटी अहस्ताक्षरित (unsigned) executables को फ़्लैग कर देते हैं जो मेमोरी में निष्क्रिय बैठी रहती हैं। Decoy ओपन सोर्स है और `src-tauri/stub/stub.rs` से बनाया गया है; आप इसे स्वयं संकलित कर सकते हैं।
