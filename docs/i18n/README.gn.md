# Decoy

**Mba'apo michĩ omyengoviáva ha ombotavýva Discord-pe oimo'ã hag̃ua peteĩ ñembosarái oiko hína.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy mba'ehechaha ñembosarái pyahu ha ta'angakuéra reheve" />

</div>

Decoy oñongatu peteĩ mba'apo michĩ oventánava ha ndojapóiva mba'eve ivaíva, peteĩ ñembosarái réra guýpe, ikatu hag̃uáicha Discord ñembosarái jejuhu he'i reñembosarái hína upe ñembosaráipe. Natekotevẽi remohenda térã emoñepyrũ añeteguáva ñembosarái, upévare mba'eve tuicháva ndopytái ne mohendahára ryru rehe.

Oikuaa **opaite ñembosarái Discord ikatúva ojuhu** (amo 25.000 rupi) omoñe'ẽgui Discord tysýi opavave pegua ha ombopyahu ijehegui voi ára ha ára.

> [!WARNING]
> Ñembosarái oikóva mbotavy ikatu oñemoĩ Discord Jepuru Léi rehe ha eipuru Decoy **nde jehegui mante**.
> Ko tembiapo ndorekói joaju, ñepytyvõ térã teko Discord Inc ndive. Ehecha [Ñemombyrýva](#ñemombyrýva).

## Mba'erepykuéra

- **Opa mba'e Discord ikatúva ojuhu.** Ñembosarái rysýi oñemboguejy Discord ykua opavave peguágui, oñeñongatu mohendahárape ha oñembopyahu káda ára. Ñembosarái pyahu ha mba'apo pyahukuéra ojehechauka ijehegui voi.
- **Hekaha ipy'apóva.** Heka pya'e ñembosarái réra térã exe rupive hetaiterei ñembosarái apytépe, ta'anga michĩ térã tysýi michĩme, oñemboheravéva ha peteĩ tenda "Ipyahuvéva".
- **Peteĩ jekutu.** Eiporavo peteĩ ñembosarái, eiporavo mba'apo (oĩramo heta), emohenda mboy aravo'ípa oñeñongatúta ha eikutu moñepyrũ. Peteĩ apu'a oipapáva tapykue gotyo ha peteĩ marandu he'íta ndéve opa vove aravo.
- **Ndohejái mba'eve tapykuépe.** Decoy oiko oñemomba'apo aja mante: exe michĩ oñemoheñói oñepyrũvo ha oñembogue oñembotývo. Opa mba'e oñembota resẽvo, ha tembyre ho'a rire oñemopotĩ oñemoñepyrũ jey vove.
- **Kirirĩme.** Oiko ta'angaryrúpe (system tray), ndaipóri oventána térã votõ tembiapo rendápe decoy-kuérape g̃uarã.
- **Ñe'ẽmbohasa ijurujáva.** Mba'ehecha oiko JSON marandurenda rupive, upévare emoĩ hag̃ua ambue ñe'ẽ tekotevẽ peteĩ marandurenda mante. Inglés ha ruso oike pype.
- **Ñemi.** Ndaipóri mba'ete (cuenta), ndaipóri Discord token, ndaipóri telemetría. Ehecha [Ñemigua](#ñemigua).

## Mba'éichapa omba'apo

1. Discord oikuaa reñembosarái hína ohechávo umi mba'apo (processes) oikóva ne mohendahárape ha ombojoja héra peteĩ tysýi opavave pegua ndive (`/api/v9/applications/detectable`).
2. Decoy omboguejy upe tysýi ha, pe ñembosarái reiporavóvape g̃uarã, ombohasa peteĩ tembipuru'i michĩ (amo 120 KB rupi, ojehaipyre Rust-pe ha oñemoĩva Decoy pype) peteĩ ryru sapy'aguápe oipurúvo pe téra tysýi peguáva, techapyrã ramo `.../cod26-cod.exe`.
3. Ko tembipuru'i ndojapói mba'eve, oreko peteĩ oventána yvateve pegua mante, oñemohendáva mombyry ojehecha'ỹ hag̃ua. Discord ohechakuaa umi mba'apo orekóva peteĩ oventána añoite, upévare peteĩ mba'apo ndorekóiva oventána oñemboyke.
4. Amo 15 aravo'ipuku mboyve Discord ohechauka upe ñembosarái nde rembiapo ramo ko'ág̃a.
5. Aravo opávo térã eikutu vove mombota, Decoy ombopaha mba'apo ha ombogue marandurenda. Peteĩ Windows job object ohecha decoy omanoha Decoy ndive, ho'árõ jepe.

## Ñemohenda

Eiporavo peteĩ [Releases](../../../../releases) rendágui:

| Ñemboguejy | Mba'épe g̃uarã |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Mohendaha (Installer).** Peteĩteĩ puruhárape g̃uarã, noikotevẽi derécho mburuvicha rehegua, omoĩ ñepyrũha poravoha ha peteĩ mbogueha. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Epe'a oimeraẽ hendápe ha emoñepyrũ `decoy.exe`. Opaite marandu opyta `data` ryru ykére, mba'eve noñeñongatúi ne mba'ete ryru pype. Embogue pe ryru reipe'ase vove. |

Ehechajey ñemboguejy `SHA256SUMS.txt` reheve (`Get-FileHash <file>` PowerShell-pe).

Windows SmartScreen ikatu he'i ndoikuaáiha myasãihárape ndorekóigui kuatiahaipyre mboherapyre; eiporavo *More info → Run anyway* eroviáramo ko marandurenda.

Oñekotevẽva: Windows 10 térã 11 (64-bit) WebView2 runtime reheve (oĩmavavoi Windows 11-pe ha Windows 10 pyahuvévape).

## Jepuru

1. Epe'a **Mba'ehechaha** ha eheka peteĩ ñembosarái, térã eikutu `Ctrl` + `K` oimeraẽ hendágui.
2. Eikutu peteĩ ñembosarái. Pe yke akatúa peguápe eiporavo mba'apo ha mboy aravo'ípa reñongatúta (Discord tembiapo jepive ojerure 15).
3. Eikutu **Moñepyrũ decoy**. Discord ohechaukáta ñembosarái mbovymi aravo'ipukúpe.
4. Ehecha **Oikóva hína** guýpe, embota peteĩ térã opavave oimeraẽ jave, térã eheja Decoy ta'angaryrúpe.

Umi ñembosarái Discord rysýipe ndorekóiva gueteri exe oñemokañy jepive (ndaikatúi ojejuhu). Emohenda *Hechauka ñembosarái ndorekóiva exe* rehecha hag̃ua chupekuéra; pe tysýi oñembopyahu káda ára, upévare oñeme'ẽta Discord omoĩ vove peteĩ mba'apo.

### Tembiapoukaha rysýi (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Omoñepyrũ peteĩ decoy voi, techapyrã `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Mopu'ã ykua guive (Build from source)

Tekotevẽva mboyve: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) pyenda imbaretéva (MSVC target) Visual Studio C++ build tools ndive, ha WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # oiko ñemoheñói rekópe ñembopyahu pya'e reheve
npm run tauri build    # ojapo mohendaha ko'ápe: src-tauri/target/release/bundle/nsis
```

Jehechajey iporãva:

```bash
npm run check-locales  # ohechajey opa ñe'ẽmbohasa marandurenda ru.json reheve
npx tsc --noEmit       # ohechajey frontend mbo'e
cargo check --manifest-path src-tauri/Cargo.toml
```

Jesarekorã: decoy exe oñemboheko `src-tauri/build.rs` rupive `rustc` reheve `src-tauri/stub/stub.rs` guive ha upéi oñemoinge tembipuru'i pype. Frontend omba'apo jave kundahárape (`npm run dev`) ojeipuru peteĩ backend gua'u (`src/mock.ts`), iporãva omba'apo hag̃ua UI rehe.

## Ñe'ẽmbohasakuéra

UI ñe'ẽ oĩ [`src/locales`](../../src/locales) ryru pype, peteĩ JSON marandurenda ñe'ẽte peteĩteĩme g̃uarã (`en.json`, `ru.json`, ...). Emoĩ hag̃ua ñe'ẽ pyahu tekotevẽ emoĩ peteĩ marandurenda mante; natekotevẽi oñemoambue kódigo. Ehecha [docs/TRANSLATING.md](../TRANSLATING.md) reikuaa hag̃ua mba'éichapa oñemboheko, peteĩ marandu oñembosako'íva moñe'ẽhára mákinape g̃uarã ha script jehechajey rehegua. Ko README ñe'ẽmbohasakuéra oho `docs/i18n/README.<code>.md`-pe.

## Tembiapo mohenda

```
src/                    React + TypeScript frontend

  i18n-core.ts          ñe'ẽ myenyhẽ ha jekuaa
  store.ts              tembipuru'i teko (zustand)

docs/                   ñe'ẽmbohasa rape, ta'angakuéra
```

## Ñemigua

- Decoy oipuru ñanduti omboguejy hag̃ua Discord jejuhu tysýi opavave pegua mante (ñepyrũrãme, upéi peteĩ jey káda ára térã eikutu vove mbopyahu) ha, ohechauka hag̃ua, ñembosarái ra'angakuéra Discord CDN opavave peguágui.
- Ndoikuaái, noñongatúi ha nomondói ne Discord token térã mba'ete marandu, ha noñe'ẽi Discord client ndive.
- Mohendahakuéra (oñemboheravéva, ñe'ẽ, aravokuéra) oñeñongatu tembipuru'i WebView ryru pype; ñembosarái tysýi ñongatupyre ha decoy marandurenda sapy'agua oĩ `%LOCALAPPDATA%\app.decoy.desktop`-pe.
- Ndaipóri jekuaauka (analytics), ndaipóri marandu ho'a jave (crash reporting), ndaipóri mba'ete (accounts).

## Aparypy ojekuaáva

- Discord ikatu omoambue jejuhu omba'apo lája oimeraẽ árape. Peteĩ decoy ndojejuhuvéiramo, epe'a peteĩ apañuãi (issue).
- Heta tembiapo oikotevẽ hetave mba'e peteĩ mba'apógui añoite (techapyrã ramo oĩvo peteĩ tembiasa pype ñembosarái platapórmape). Decoy ombotavy mba'apo mante.
- Umi ndorekóiva exe Discord rysýipe ndaikatúi ojejuhu.
- Tembipuru tekorã rehegua sapy'ánte oikuaauka exe michĩ ndorekóiva kuatiahaipyre ha opytáva kirirĩme mandu'arãme. Decoy ha'e kódigo ijurujáva ha oñemopu'ã `src-tauri/stub/stub.rs` guive; ikatúma emboheko nde voi.

## Ñemombyrýva

Decoy oñeme'ẽ "oĩháicha" puruhára mba'épe g̃uarã, ñehekombo'e ha ñeha'ãrãme. Peteĩ ñembosarái oikóva mbotavy ikatu omohembiapo vai Discord Jepuru Léi térã ñembosarái myasãihára léi rehe, ha ikatu ogueru apañuãi ne mba'etépe. Nde añoite reñangareko mba'éichapa reipuru. "Discord" ha opaite ñembosarái réra ha ta'angakuéra ha'e ijajarakuéra mba'e ha ojeipuru ko'ápe oñemombe'u hag̃ua mavapepa oñeñe'ẽ mante.
