# Decoy

**Мали замрзнути процеси-лажњаци због којих Discord мисли да се игра покреће.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека са недавним играма и сликама" />

</div>

Decoy одржава покренутим безопасан процес-лажњак са прозором под именом извршне датотеке игре, тако да Discord-ово
препознавање игара приказује да играте ту игру. Никада не морате да инсталирате или покренете праву игру, па вам
ништа велико не заузима простор на диску.

Зна за **сваку игру коју Discord може да препозна** (око 25.000 ставки) јер чита сопствену јавну листу за
препознавање са Discord-а и аутоматски је ажурира.

> [!WARNING]
> Лажирање покренуте игре може бити у супротности са Discord-овим условима коришћења (Terms of Service) и Decoy користите **на сопствени ризик**.
> Овај пројекат није повезан са, подржан од стране, нити спонзорисан од стране Discord Inc. Погледајте [Одрицање од одговорности](#одрицање-од-одговорности).

## Могућности

- **Све што Discord може да препозна.** Листа игара се преузима са јавног Discord сервера за детекцију, кешира
  локално и освежава свакодневно. Нове игре и новододати програми појављују се сами од себе.
- **Претрага која прати корак.** Тренутна претрага по називу игре или извршној датотеци кроз хиљаде игара, приказ у мрежи или
  компактној листи, омиљено и ред „Недавно”.
- **Један клик.** Изаберите игру, изаберите извршну датотеку (ако их има више), одаберите колико дуго да траје и притисните покрени.
  Прстен са одбројавањем и обавештење јављају када време истекне.
- **Не оставља ништа за собом.** Лажњак постоји само док ради: мали exe се креира при покретању и брише при
  заустављању. Све се зауставља када изађете, а остаци након пада програма се чисте при следећем покретању.
- **Тихо.** Налази се у системској траци (tray), без прозора или дугмади на траци задатака за саме лажњаке.
- **Отворени преводи.** Интерфејс покрећу обичне JSON датотеке, па је додавање новог језика само једна датотека.
  Енглески и руски су укључени.
- **Приватност.** Без налога, без Discord токена, без телеметрије. Погледајте [Приватност](#приватност).

## Како ради

1. Discord утврђује да играте игру тако што проверава покренуте процесе на вашем рачунару и упоређује њихова
   имена извршних датотека са јавном листом (`/api/v9/applications/detectable`).
2. Decoy преузима ту листу и, за игру коју одаберете, копира мали програм-лажњак (око 120 KB, написан у
   Rust-у и уграђен у Decoy) у привремену фасциклу користећи назив извршне датотеке са листе, на пример
   `.../cod26-cod.exe`.
3. Лажњак не ради ништа осим што поседује један прозор највишег нивоа, постављен далеко ван екрана како га никада не бисте видели. Discord
   препознаје само процес који има прозор, због чега се процес потпуно без прозора игнорише.
4. За приближно 15 секунди Discord приказује игру као вашу тренутну активност.
5. Када тајмер истекне или притиснете заустави, Decoy прекида процес и брише датотеку. Windows job објекат
   осигурава да се лажњаци угасе заједно са Decoy-ем, чак и ако дође до пада програма.

## Инсталација

Изаберите једно са странице са [издањима](../../../../releases):

| Преузимање | За |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталатер.** По кориснику, нису потребне администраторске привилегије, додаје ставку у Start мени и програм за деинсталацију. |
| `Decoy_x.y.z_x64-portable.zip` | **Преносна верзија (Portable).** Распакујте било где и покрените `decoy.exe`. Сви подаци остају у фасцикли `data` поред њега, ништа се не уписује у ваш кориснички профил. Обришите фасциклу да бисте га уклонили. |

Проверите преузимање помоћу `SHA256SUMS.txt` (`Get-FileHash <file>` у PowerShell-у).

Windows SmartScreen може упозорити на непрепознатог издавача јер верзије немају дигитални потпис кода; изаберите
*More info → Run anyway* ако верујете овој верзији.

Захтеви: Windows 10 или 11 (64-битни) са WebView2 окружењем (већ укључено у Windows 11 и новијим
ажурирањима за Windows 10).

## Коришћење

1. Отворите **Библиотека** и потражите игру, или притисните `Ctrl` + `K` било где.
2. Кликните на игру. У панелу са десне стране изаберите процес и колико минута да га држите (Discord активности
   обично траже 15).
3. Притисните **Покрени лажњак**. Discord ће приказати игру након неколико секунди.
4. Пратите га у одељку **Покренуто**, зауставите један или све у било ком тренутку, или једноставно оставите Decoy у системској траци.

Игре чији Discord унос још увек нема извршне датотеке су подразумевано сакривене (не могу се препознати). Укључите
*Прикажи игре без exe* да бисте их видели; листа се ажурира свакодневно, тако да постају доступне чим Discord дода
процес.

### Командна линија

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Покреће лажњак одмах, на пример `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Израда из изворног кода

Предуслови: [Node.js](https://nodejs.org) 20+, стабилан [Rust](https://rustup.rs) скуп алата (MSVC мета) са
Visual Studio C++ алатима за израду, и WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Корисне провере:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Напомене: лажњак exe се компајлира помоћу `src-tauri/build.rs` са обичним `rustc` из `src-tauri/stub/stub.rs` и затим
уграђује у апликацију. Када се фронтенд покреће у обичном прегледачу (`npm run dev`), користи се мали симулирани бекенд
(`src/mock.ts`), што је згодно за рад на корисничком интерфејсу.

## Преводи

Стрингови корисничког интерфејса налазе се у [`src/locales`](../../src/locales), једна JSON датотека по језику (`en.json`, `ru.json`, ...).
Додавање језика значи додавање датотеке; без промена у коду. Погледајте [docs/TRANSLATING.md](../TRANSLATING.md) за
формат датотеке, спреман шаблон за машинско превођење и скрипту за валидацију. Преводи овог README фајла иду у
`docs/i18n/README.<code>.md`.

## Структура пројекта

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Приватност

- Decoy користи мрежу само за преузимање јавне листе детекције са Discord-а (при првом покретању, затим највише једном дневно
  или када притиснете освежи) и, за приказ, иконица и слика игара са јавног Discord CDN-а.
- Не чита, не чува нити шаље ваш Discord токен или било какве податке о налогу, и не комуницира са Discord клијентом.
- Подешавања (омиљено, језик, трајања) чувају се локално у складишту апликације WebView; кеш листе игара и
  привремене датотеке лажњака налазе се у `%LOCALAPPDATA%\app.decoy.desktop`.
- Нема аналитике, нема извештавања о падовима система, нема налога.

## Позната ограничења

- Discord може у било ком тренутку да промени начин на који препознавање ради. Ако лажњак престане да буде препознат, отворите issue.
- Неке активности захтевају више од покренутог процеса (на пример, налажење унутар одређеног искуства на платформи за
  игре). Decoy само опонаша процес.
- Ставке без извршних датотека у Discord-овој листи не могу бити препознате.
- Безбедносни софтвер повремено означава мале непотписане извршне датотеке које мирују у меморији. Лажњак је отвореног кода
  и прави се из `src-tauri/stub/stub.rs`; можете га и сами компајлирати.

Услове коришћења сервиса Discord или издавача игре и може довести до мера против вашег налога. Ви сами сносите

овде се користе искључиво ради идентификације софтвера на који се односе.
