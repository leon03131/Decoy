# Decoy

**Discord-ҡа уйын уйнала тип күрһәткән бәләкәй алдаҡсы процестар.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Һуңғы уйындар һәм тышлыҡтар менән Decoy китапханаһы" />

</div>

Decoy уйындың башҡарылыусы файлы исеме аҫтында зарарһыҙ, тәҙрәле алдаҡсы процесты эшләтеп тота, шуға күрә Discord-тың уйындарҙы билдәләү системаһы һеҙҙе шул уйынды уйнай тип иҫәпләй. Ысын уйынды ҡуйырға йәки ебәрергә кәрәкмәй, шуға күрә дискығыҙҙа ҙур урын биләнмәй.

Ул **Discord таный алған һәр уйынды** белә (яҡынса 25 000 яҙма), сөнки Discord-тың үҙенең асыҡ билдәләү исемлеген уҡый һәм уны үҙаллы яңыртып тора.

> [!WARNING]
> Эшләп торған уйынды ялған күрһәтеү Discord-тың Ҡулланыу шарттарына ҡаршы килеүе мөмкин һәм һеҙ Decoy-ҙы **үҙ хәүефегеҙ менән** ҡулланаһығыҙ.
> Был проект Discord Inc. компанияһы менән бәйле түгел, хупланмаған һәм ҡатнашы юҡ. [Яуаплылыҡтан баш тартыу](#яуаплылыҡтан-баш-тартыу) бүлеген ҡарағыҙ.

## Мөмкинлектәр

- **Discord таный алған барыһы ла.** Уйындар исемлеге Discord-тың асыҡ серверынан йөкләнә, локаль һаҡлана һәм көн һайын яңыртыла. Яңы уйындар һәм яңы өҫтәлгән башҡарылыусы файлдар үҙҙәренән-үҙҙәре күренәсәк.
- **Шәп эҙләү.** Меңдәрсә уйын араһынан уйын исеме йәки exe буйынса тиҙ арала эҙләү, плиткалар йәки ҡыҫҡа исемлек күренеше, һайланғандар һәм «Һуңғылар» юлы.
- **Бер тапҡыр баҫыу.** Уйынды һайлағыҙ, башҡарылыусы файлды күрһәтегеҙ (бер нисәү булһа), уны нисә минут тоторға икәнен билдәләгеҙ һәм «ебәрергә» баҫығыҙ. Кире иҫәпләү ҡулсаһы һәм белдереү ваҡыттың бөтөүен хәбәр итер.
- **Үҙенән һуң бер нимә лә ҡалдырмай.** Алдаҡсы процесс (decoy) эшләп торған ваҡытта ғына йәшәй: бәләкәй exe ебәргәндә төҙөлә һәм туҡтатҡанда юйыла. Сыҡҡанда барыһы ла туҡтатыла, ә программа боҙолоп ябылһа, ҡалдыҡтар киләһе ҡабыҙыуҙа таҙартыла.
- **Тыныс.** Трейҙа урынлаша, decoy процестары үҙҙәре өсөн бер ниндәй ҙә тәҙрә йәки бурыстар панелендә төймәләр сығармай.
- **Асыҡ тәржемәләр.** Интерфейс ябай JSON файлдары аша көйләнә, яңы тел өҫтәү өсөн бер генә файл кәрәк. Инглиз һәм урыҫ телдәре индерелгән.
- **Серлек.** Хисап яҙмаһы, Discord токендары, телеметрия юҡ. [Серлек](#серлек) бүлеген ҡарағыҙ.

## Ҡалай эшләй

1. Discord һеҙҙең компьютерҙа эшләп торған процестарҙы ҡарап һәм уларҙың башҡарылыусы файл атамаларын асыҡ исемлек менән (`/api/v9/applications/detectable`) сағыштырып уйын уйнауығыҙҙы билдәләй.
2. Decoy был исемлекте йөктәй һәм һеҙ һайлаған уйын өсөн исемлектәге башҡарылыусы файл исемен файҙаланып (мәҫәлән, `.../cod26-cod.exe`), ваҡытлы папкаға бәләкәй генә алдаҡсы программаны (яҡынса 120 КБ, Rust телендә яҙылған һәм Decoy эсенә ҡуйылған) күсерә.
3. Был программа экрандан ситтә урынлашҡан һәм һеҙгә бер ҡасан да күренмәгән берҙән-бер тәҙрәгә эйә булыуҙан башҡа бер нимә лә эшләмәй. Discord тик тәҙрәһе булған процесты ғына таный, шуға күрә тәҙрәһеҙ процесҡа иғтибар итмәй.
4. Яҡынса 15 секунд эсендә Discord был уйынды һеҙҙең ағымдағы шөғөлөгөҙ итеп күрһәтә.
5. Таймер бөткәс йәки туҡтатыуға баҫҡас, Decoy процесты тамамлай һәм файлды юя. Windows job объекты Decoy ҡапыл өҙөлөп ябылғанда ла алдаҡсы процестарҙың Decoy менән бергә бөтөрөлөүен тәьмин итә.

## Ҡуйыу

[Releases](../../../../releases) битенән береһен һайлағыҙ:

| Йөкләү | Тәғәйенләнеше |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Ҡуйғыс (Installer).** Һәр ҡулланыусы өсөн, администратор хоҡуҡтары кәрәкмәй, «Башланғыс» (Start) менюһына яҙма һәм юйғыс өҫтәй. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Ҡайҙа теләһәгеҙ шунда сығарып, `decoy.exe` ебәрегеҙ. Бөтә мәғлүмәттәр уның эргәһендәге `data` папкаһында һаҡлана, ҡулланыусы профиленә бер нимә лә яҙылмай. Юйыр өсөн папканы юйыу етә. |

Йөкләнгән файлды `SHA256SUMS.txt` аша тикшерегеҙ (PowerShell-да `Get-FileHash <файл>`).

Windows SmartScreen программаларҙың цифрлы ҡултамғаһы булмау сәбәпле билдәһеҙ нәшерсе тураһында киҫәтергә мөмкин; әгәр төҙөлөшкә ышанһағыҙ, *Тулыраҡ (More info) → Барыбер башҡарырға (Run anyway)* һайлағыҙ.

Талаптар: WebView2 runtime булған 64-битлы Windows 10 йәки 11 (Windows 11 һәм яңыраҡ Windows 10 яңыртыуҙарында индерелгән).

## Ҡулланыу

1. **Китапхананы** асып, уйынды эҙләгеҙ йәки теләһә ҡайһы ерҙән `Ctrl` + `K` төймәләренә баҫығыҙ.
2. Уйынға баҫығыҙ. Уң яҡтағы панелдә процесты һәм уны нисә минут тоторға кәрәклеген һайлағыҙ (Discord бурыстары ғәҙәттә 15 минут һорай).
3. **Decoy ебәрергә** баҫығыҙ. Discord бер нисә секундтан һуң уйынды күрһәтәсәк.
4. Уны **Эшләп тора** бүлегендә күҙәтегеҙ, теләһә ҡайһы ваҡытта береһен йәки бөтәһен дә туҡтатығыҙ, йәки Decoy-ҙы трейҙа ҡалдырығыҙ.

Discord исемлегендә әлегә башҡарылыусы файлдары булмаған уйындар ғәҙәттә йәшерелгән (уларҙы билдәләп булмай). Уларҙы күрер өсөн *exe булмағандарҙы күрһәтергә* төймәһен ҡабыҙығыҙ; исемлек көн һайын яңыртыла, шуға күрә Discord процесс өҫтәү менән улар асыласаҡ.

### Командалар юлы

```
decoy.exe --launch "<Discord исемлегендәге башҡарылыусы файл юлы>" [минут]
```

Decoy-ҙы туранан-тура ебәрә, мәҫәлән: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Сығанаҡ кодтан йыйыу

Кәрәкле шарттар: [Node.js](https://nodejs.org) 20+, Visual Studio C++ йыйыу ҡоралдары менән тотороҡло [Rust](https://rustup.rs) ҡоралдар йыйылмаһы (MSVC target) һәм WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload менән эшләү режимында ебәреү
npm run tauri build    # src-tauri/target/release/bundle/nsis эсендә ҡуйғыс төҙөү
```

Файҙалы тикшереүҙәр:

```bash
npm run check-locales  # һәр тәржемә файлын ru.json менән сағыштырып тикшереү
npx tsc --noEmit       # фронтенд типтарын тикшереү
cargo check --manifest-path src-tauri/Cargo.toml
```

Иҫкәрмәләр: decoy exe файлы `src-tauri/build.rs` аша `src-tauri/stub/stub.rs` кодынан ябай `rustc` менән йыйыла һәм программа эсенә ҡуйыла. Фронтенд ябай браузерҙа эшләгәндә (`npm run dev`) бәләкәй ялған бэкенд (`src/mock.ts`) ҡулланыла, был интерфейс өҫтөндә эшләү өсөн уңайлы.

## Тәржемәләр

Интерфейс юлдары [`src/locales`](../../src/locales) эсендә һаҡлана, һәр тел өсөн бер JSON файл (`en.json`, `ru.json`, ...).
Яңы тел өҫтәү бер файл өҫтәүҙе генә аңлата; кодты үҙгәртеү кәрәкмәй. Файл форматы, машина тәржемәһе өсөн әҙер һорау (prompt) һәм тикшереү скрипты өсөн [docs/TRANSLATING.md](../TRANSLATING.md) файлын ҡарағыҙ. Был README файлының тәржемәләре `docs/i18n/README.<code>.md` эсендә һаҡлана.

## Проект төҙөлөшө

```

  components/           Китапхана, ентекле мәғлүмәт панеле, көйләүҙәр, ...
  locales/              тәржемә файлдары (һәр телгә бер JSON)
  i18n-core.ts          телде йөкләү һәм эҙләү

  src/lib.rs            уйындар базаһы, decoy процестары, трей
  stub/stub.rs          эскә ҡуйыла торған программа

docs/                   тәржемә буйынса ҡулланма, скриншоттар
```

## Серлек

- Decoy селтәрҙе тик Discord-тың асыҡ билдәләү исемлеген йөкләү (беренсе ҡабыҙғанда, унан һуң көнөнә бер тапҡырҙан күп түгел йәки яңыртыуға баҫҡанда) һәм уйын билдәләре менән тышлыҡтарын күрһәтеү өсөн генә ҡуллана.
- Ул һеҙҙең Discord токенын йәки ниндәй ҙә булһа хисап мәғлүмәттәрен уҡымай, һаҡламай һәм ебәрмәй, шулай уҡ Discord клиенты менән бәйләнешкә инмәй.
- Көйләүҙәр (һайланғандар, тел, ваҡыттар) ҡушымтаның WebView һаҡлағысында һаҡлана; уйындар исемлеге кэшы һәм ваҡытлы decoy файлдары `%LOCALAPPDATA%\app.decoy.desktop` эсендә урынлаша.
- Аналитика, өҙөклөктәр тураһында отчеттар, хисап яҙмалары юҡ.

## Билдәле сикләүҙәр

- Discord уйындарҙы билдәләү тәртибен теләһә ҡайһы ваҡытта үҙгәртә ала. Әгәр алдаҡсы процесс танылмай башлаһа, issue асығыҙ.
- Ҡайһы бер шөғөлдәр эшләп торған процестан тыш күберәк нәрсәне талап итә (мәҫәлән, уйын платформаһындағы билдәле бер режимда булыу). Decoy тик процесты ғына алдай.
- Discord исемлегендә башҡарылыусы файлдары булмаған уйындар билдәләнә алмай.
- Ҡайһы бер һаҡлау программалары хәтерҙә буш ултырған ҡултамғаһыҙ бәләкәй exe файлдарға шикләнеп ҡарарға мөмкин. Decoy асыҡ сығанаҡ кодлы һәм `src-tauri/stub/stub.rs` аша төҙөлгән; уны үҙегеҙ йыя алаһығыҙ.

Decoy шәхси, мәғариф һәм һынау маҡсаттары өсөн «нисек бар, шулай» бирелә.
