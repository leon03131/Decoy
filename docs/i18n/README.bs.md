# Decoy

**Mali zamjenski procesi zbog kojih Discord misli da je igra pokrenuta.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy biblioteka s nedavnim igrama i slikama" />

</div>

Decoy održava bezopasan zamjenski proces s prozorom pod nazivom izvršne datoteke igre, tako da
Discordovo otkrivanje igara prikazuje da igrate tu igru. Nikada ne morate instalirati niti pokrenuti
pravu igru, tako da vam ništa veliko ne zauzima prostor na disku.

Zna za **svaku igru koju Discord može otkriti** (oko 25.000 unosa) jer čita Discordov vlastiti
javni spisak za otkrivanje i samostalno ga ažurira.

> [!WARNING]
> Lažiranje pokrenute igre može biti u suprotnosti s Discordovim Uslovima korištenja i Decoy koristite
> **na vlastiti rizik**. Ovaj projekat nije povezan s Discord Inc., niti ga oni podržavaju ili odobravaju.
> Pogledajte [Odricanje od odgovornosti](#odricanje-od-odgovornosti).

## Mogućnosti

- **Sve što Discord može otkriti.** Spisak igara preuzima se s Discordove javne krajnje tačke za otkrivanje,
  sprema se lokalno i osvježava svakodnevno. Nove igre i novododane izvršne datoteke pojavljuju se same od sebe.
- **Pretraga koja drži korak.** Trenutna pretraga po nazivu igre ili izvršnoj datoteci među hiljadama
  igara, prikaz u obliku mreže ili kompaktne liste, favoriti i red „Nedavno”.
- **Jedan klik.** Izaberite igru, izaberite izvršnu datoteku (ako ih ima više), izaberite koliko dugo želite
  zadržati proces i pritisnite start. Krug s odbrojavanjem i obavještenje javit će vam kada vrijeme istekne.
- **Ne ostavlja ništa za sobom.** Decoy postoji samo dok radi: mali exe se stvara pri pokretanju i briše pri
  zaustavljanju. Sve se zaustavlja kada zatvorite program, a ostaci nakon pada čiste se pri sljedećem pokretanju.
- **Tih.** Nalazi se u sistemskoj traci (system tray), bez prozora ili dugmadi na traci zadataka za same zamjenske procese.
- **Otvoreni prijevodi.** Interfejs se pokreće putem običnih JSON datoteka, pa je dodavanje jezika samo jedna datoteka.
  Engleski i ruski su uključeni.
- **Privatno.** Bez naloga, bez Discord tokena, bez telemetrije. Pogledajte [Privatnost](#privatnost).

## Kako radi

1. Discord utvrđuje igrate li igru pregledavanjem procesa pokrenutih na vašem računaru i upoređivanjem njihovih
   naziva izvršnih datoteka s javnim spiskom (`/api/v9/applications/detectable`).
2. Decoy preuzima taj spisak i, za igru koju izaberete, kopira mali zamjenski program (oko 120 KB, napisan u
   Rustu i ugrađen u Decoy) u privremeni folder koristeći naziv izvršne datoteke sa spiska, na primjer
   `.../cod26-cod.exe`.
3. Zamjenski program ne radi ništa osim što posjeduje jedan prozor najvišeg nivoa, smješten daleko izvan ekrana
   tako da ga nikada ne vidite. Discord prepoznaje samo proces koji posjeduje prozor, zbog čega se proces potpuno
   bez prozora ignoriše.
4. Za otprilike 15 sekundi Discord prikazuje igru kao vašu trenutnu aktivnost.
5. Kada tajmer istekne ili pritisnete zaustavi, Decoy prekida proces i briše datoteku. Windows objekt zadatka
   (job object) osigurava da se zamjenski procesi ugase zajedno s aplikacijom Decoy, čak i ako se ona sruši.

## Instalacija

Izaberite verziju sa stranice [Releases](../../../../releases):

| Preuzimanje | Za |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalater.** Po korisniku, nisu potrebne administratorske privilegije, dodaje unos u Start meni i program za deinstalaciju. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabilna verzija (Portable).** Raspakujte bilo gdje i pokrenite `decoy.exe`. Svi podaci ostaju u folderu `data` pored njega, ništa se ne upisuje u vaš korisnički profil. Obrišite folder da biste ga uklonili. |

Provjerite preuzetu datoteku pomoću `SHA256SUMS.txt` (`Get-FileHash <datoteka>` u programu PowerShell).

Windows SmartScreen može upozoriti na nepoznatog izdavača jer verzije nisu digitalno potpisane; izaberite
*Više informacija → Pokreni svejedno* ako vjerujete preuzetoj verziji.

Zahtjevi: Windows 10 ili 11 (64-bit) sa WebView2 runtimeom (već uključen u Windows 11 i novijim ažuriranjima za
Windows 10).

## Korištenje

1. Otvorite **Biblioteka** i pretražite igru, ili pritisnite `Ctrl` + `K` bilo gdje.
2. Kliknite na igru. Na panelu s desne strane izaberite proces i koliko minuta ga želite zadržati (Discord aktivnosti
   obično traže 15).
3. Pritisnite **Pokreni decoy**. Discord će prikazati igru nakon nekoliko sekundi.
4. Pratite je pod **Pokrenuto**, zaustavite jedan ili sve u bilo kojem trenutku, ili jednostavno ostavite Decoy u sistemskoj traci.

Igre čiji unos na Discordu još nema izvršne datoteke sakrivene su prema zadanim postavkama (ne mogu se otkriti). Uključite
*Prikaži igre bez exe* da biste ih vidjeli; spisak se osvježava svakodnevno, pa postaju dostupne čim Discord doda
proces.

### Komandna linija

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Pokreće decoy odmah, na primjer `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Izgradnja iz izvornog koda

Preduvjeti: [Node.js](https://nodejs.org) 20+, stabilan [Rust](https://rustup.rs) alatni lanac (MSVC cilj) s
Visual Studio C++ alatima za izgradnju i WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # pokretanje u razvojnom režimu s automatskim osvježavanjem
npm run tauri build    # kreiranje instalatera u src-tauri/target/release/bundle/nsis
```

Korisne provjere:

```bash
npm run check-locales  # provjera svake datoteke prijevoda u odnosu na ru.json
npx tsc --noEmit       # provjera tipova interfejsa
cargo check --manifest-path src-tauri/Cargo.toml
```

Napomene: izvršna datoteka zamjenskog programa (decoy exe) prevodi se pomoću `src-tauri/build.rs` običnim `rustc` alatom iz `src-tauri/stub/stub.rs` i zatim
se ugrađuje u aplikaciju. Kada interfejs radi u običnom pregledniku (`npm run dev`), koristi se mali imitirani backend
(`src/mock.ts`), što je prikladno za rad na korisničkom interfejsu.

## Prijevodi

Tekstovi korisničkog interfejsa nalaze se u [`src/locales`](../../src/locales), jedna JSON datoteka po jeziku (`en.json`, `ru.json`, ...).
Dodavanje jezika znači dodavanje jedne datoteke; bez promjena koda. Pogledajte [docs/TRANSLATING.md](../TRANSLATING.md) za format
datoteke, gotov upit za mašinsko prevođenje i skriptu za provjeru ispravnosti. Prijevodi ove README datoteke spremaju se u
`docs/i18n/README.<code>.md`.

## Struktura projekta

```
src/                    React + TypeScript interfejs
  components/           Biblioteka, panel s detaljima, postavke, ...
  locales/              datoteke prijevoda (jedan JSON po jeziku)
  i18n-core.ts          učitavanje i pretraga jezika
  store.ts              stanje aplikacije (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            baza podataka igara, decoy procesi, sistemska traka
  stub/stub.rs          zamjenski program koji se ugrađuje
scripts/                pomoćne skripte (provjera ispravnosti prijevoda)
docs/                   vodič za prevođenje, snimci ekrana
```

## Privatnost

- Decoy koristi mrežu samo za preuzimanje Discordovog javnog spiska za otkrivanje (pri prvom pokretanju, a zatim najviše
  jednom dnevno ili kada pritisnete osvježi) i, radi prikaza, ikona igara i slika s Discordovog javnog CDN-a.
- Ne čita, ne pohranjuje niti šalje vaš Discord token ili bilo kakve podatke o nalogu, i ne komunicira s Discord klijentom.
- Postavke (favoriti, jezik, trajanja) pohranjuju se lokalno u WebView skladištu aplikacije; keš spiska igara i
  privremene datoteke zamjenskih procesa nalaze se u `%LOCALAPPDATA%\app.decoy.desktop`.
- Bez analitike, bez izvještaja o padu sistema, bez naloga.

## Poznata ograničenja

- Discord može u bilo kojem trenutku promijeniti način otkrivanja. Ako se decoy prestane prepoznavati, otvorite prijavu problema (issue).
- Neke aktivnosti zahtijevaju više od samog pokrenutog procesa (na primjer, boravak unutar određenog iskustva na
  platformi za igre). Decoy imitira samo proces.
- Unosi bez izvršnih datoteka na Discordovom spisku ne mogu se otkriti.
- Sigurnosni softver povremeno može označiti male nepotpisane izvršne datoteke koje neaktivno stoje u memoriji. Decoy je otvorenog
  koda i izgrađen je iz `src-tauri/stub/stub.rs`; možete ga sami kompajlirati.

## Odricanje od odgovornosti

Decoy se pruža „kakav jeste” u lične, obrazovne svrhe i svrhe testiranja. Imitiranje pokrenute igre može kršiti
Uslove korištenja za Discord ili izdavača igre te može dovesti do mjera protiv vašeg naloga. Vi sami snosite
isključivu odgovornost za način na koji ga koristite. „Discord” i svi nazivi i logotipi igara zaštitni su znakovi
svojih odgovarajućih vlasnika i ovdje se koriste samo za identifikaciju softvera na koji se odnose.
