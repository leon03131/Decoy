# Decoy

**Discord ನಲ್ಲಿ ಆಟ ಚಾಲನೆಯಲ್ಲಿದೆ ಎಂದು ಭಾವಿಸುವಂತೆ ಮಾಡುವ ಸಣ್ಣ ಸ್ಟ್ಯಾಂಡ್‌-ಇನ್ ಪ್ರಕ್ರಿಯೆಗಳು.**

ಆಟದ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಹೆಸರಿನಲ್ಲಿ ಹಾನಿರಹಿತ, ವಿಂಡೋ ಹೊಂದಿರುವ ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್ ಪ್ರಕ್ರಿಯೆಯನ್ನು Decoy ಚಾಲನೆಯಲ್ಲಿರಿಸುತ್ತದೆ, ಇದರಿಂದ Discord ಆಟ ಪತ್ತೆಹಚ್ಚುವಿಕೆಯು ನೀವು ಆ ಆಟವನ್ನು ಆಡುತ್ತಿದ್ದೀರಿ ಎಂದು ತೋರಿಸುತ್ತದೆ. ನೀವು ನಿಜವಾದ ಆಟವನ್ನು ಎಂದಿಗೂ ಸ್ಥಾಪಿಸುವ ಅಥವಾ ಪ್ರಾರಂಭಿಸುವ ಅಗತ್ಯವಿಲ್ಲ, ಆದ್ದರಿಂದ ನಿಮ್ಮ ಡಿಸ್ಕ್‌ನಲ್ಲಿ ಯಾವುದೇ ದೊಡ್ಡ ಫೈಲ್‌ಗಳು ಇರುವುದಿಲ್ಲ.

Discord ಪತ್ತೆಹಚ್ಚಬಹುದಾದ **ಪ್ರತಿಯೊಂದು ಆಟದ ಬಗ್ಗೆ ಇದು ತಿಳಿದಿದೆ** (ಸುಮಾರು 25,000 ನಮೂದುಗಳು), ಏಕೆಂದರೆ ಇದು Discord ನ ಸ್ವಂತ ಸಾರ್ವಜನಿಕ ಪತ್ತೆಹಚ್ಚುವಿಕೆ ಪಟ್ಟಿಯನ್ನು ಓದುತ್ತದೆ ಮತ್ತು ತನ್ನಷ್ಟಕ್ಕೆ ತಾನೇ ನವೀಕೃತವಾಗಿರಿಸಿಕೊಳ್ಳುತ್ತದೆ.

> ಚಾಲನೆಯಲ್ಲಿರುವ ಆಟವನ್ನು ನಕಲಿ ಮಾಡುವುದು Discord ನ ಸೇವಾ ನಿಯಮಗಳಿಗೆ (Terms of Service) ವಿರುದ್ಧವಾಗಿರಬಹುದು ಮತ್ತು ನೀವು Decoy ಅನ್ನು **ನಿಮ್ಮ ಸ್ವಂತ ಅಪಾಯದಲ್ಲಿ** ಬಳಸುತ್ತೀರಿ.

## ವೈಶಿಷ್ಟ್ಯಗಳು

- **Discord ಪತ್ತೆಹಚ್ಚಬಹುದಾದ ಪ್ರತಿಯೊಂದೂ.** ಆಟದ ಪಟ್ಟಿಯನ್ನು Discord ನ ಸಾರ್ವಜನಿಕ ಪತ್ತೆಹಚ್ಚುವಿಕೆ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ನಿಂದ ಡೌನ್‌ಲೋಡ್ ಮಾಡಲಾಗುತ್ತದೆ, ಸ್ಥಳೀಯವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಪ್ರತಿದಿನ ರಿಫ್ರೆಶ್ ಮಾಡಲಾಗುತ್ತದೆ. ಹೊಸ ಆಟಗಳು ಮತ್ತು ಹೊಸದಾಗಿ ಸೇರಿಸಲಾದ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್‌ಗಳು ತಾವಾಗಿಯೇ ಗೋಚರಿಸುತ್ತವೆ.
- **ವೇಗದ ಹುಡುಕಾಟ.** ಸಾವಿರಾರು ಆಟಗಳಲ್ಲಿ ಆಟದ ಹೆಸರು ಅಥವಾ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಮೂಲಕ ತಕ್ಷಣದ ಹುಡುಕಾಟ, ಗ್ರಿಡ್ ಅಥವಾ ಕಾಂಪ್ಯಾಕ್ಟ್ ಪಟ್ಟಿ ವೀಕ್ಷಣೆ, ಮೆಚ್ಚಿನವುಗಳು ಮತ್ತು "Recent" ಸಾಲು.
- **ಒಂದೇ ಕ್ಲಿಕ್.** ಆಟವನ್ನು ಆರಿಸಿ, ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಅನ್ನು ಆರಿಸಿ (ಹಲವಾರು ಇದ್ದರೆ), ಅದನ್ನು ಎಷ್ಟು ಸಮಯ ಇರಿಸಬೇಕೆಂದು ನಿರ್ಧರಿಸಿ ಮತ್ತು ಪ್ರಾರಂಭ ಒತ್ತಿ. ಸಮಯ ಮುಗಿದಾಗ ಕೌಂಟ್‌ಡೌನ್ ರಿಂಗ್ ಮತ್ತು ಅಧಿಸೂಚನೆ ನಿಮಗೆ ತಿಳಿಸುತ್ತದೆ.
- **ಹಿನ್ನೆಲೆಯಲ್ಲಿ ಏನನ್ನೂ ಬಿಡುವುದಿಲ್ಲ.** Decoy ಚಾಲನೆಯಲ್ಲಿರುವಾಗ ಮಾತ್ರ ಇರುತ್ತದೆ: ಸಣ್ಣ exe ಪ್ರಾರಂಭದಲ್ಲಿ ರಚಿಸಲ್ಪಡುತ್ತದೆ ಮತ್ತು ನಿಲ್ಲಿಸಿದಾಗ ಅಳಿಸಲ್ಪಡುತ್ತದೆ. ನೀವು ನಿರ್ಗಮಿಸಿದಾಗ ಎಲ್ಲವೂ ನಿಲ್ಲುತ್ತದೆ, ಮತ್ತು ಕ್ರ್ಯಾಶ್‌ನಿಂದ ಉಳಿದಿರುವವುಗಳನ್ನು ಮುಂದಿನ ಪ್ರಾರಂಭದಲ್ಲಿ ಸ್ವಚ್ಛಗೊಳಿಸಲಾಗುತ್ತದೆ.
- **ಶಾಂತವಾಗಿರುತ್ತದೆ.** ಸಿಸ್ಟಮ್ ಟ್ರೇನಲ್ಲಿ ಇರುತ್ತದೆ, decoy ಗಳಿಗೆ ಯಾವುದೇ ಪ್ರತ್ಯೇಕ ವಿಂಡೋಗಳು ಅಥವಾ ಟಾಸ್ಕ್‌ಬಾರ್ ಬಟನ್‌ಗಳು ಇರುವುದಿಲ್ಲ.
- **ಮುಕ್ತ ಅನುವಾದಗಳು.** ಇಂಟರ್ಫೇಸ್ ಸರಳ JSON ಫೈಲ್‌ಗಳಿಂದ ನಿಯಂತ್ರಿಸಲ್ಪಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಭಾಷೆಯನ್ನು ಸೇರಿಸುವುದು ಕೇವಲ ಒಂದೇ ಫೈಲ್ ಕೆಲಸ. ಇಂಗ್ಲಿಷ್ ಮತ್ತು ರಷ್ಯನ್ ಒಳಗೊಂಡಿದೆ.
- **ಖಾಸಗಿ.** ಯಾವುದೇ ಖಾತೆ ಇಲ್ಲ, Discord ಟೋಕನ್ ಇಲ್ಲ, ಟೆಲಿಮೆಟ್ರಿ ಇಲ್ಲ. [ಗೌಪ್ಯತೆ](#ಗೌಪ್ಯತೆ) ನೋಡಿ.

## ಇದು ಹೇಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ

1. ನಿಮ್ಮ PC ಯಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರುವ ಪ್ರಕ್ರಿಯೆಗಳನ್ನು ಪರಿಶೀಲಿಸುವ ಮೂಲಕ ಮತ್ತು ಅವುಗಳ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಹೆಸರುಗಳನ್ನು ಸಾರ್ವಜನಿಕ ಪಟ್ಟಿಗೆ (`/api/v9/applications/detectable`) ಹೋಲಿಸುವ ಮೂಲಕ ನೀವು ಆಟವನ್ನು ಆಡುತ್ತಿದ್ದೀರಿ ಎಂದು Discord ನಿರ್ಧರಿಸುತ್ತದೆ.
2. Decoy ಆ ಪಟ್ಟಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಆಟಕ್ಕಾಗಿ, ಪಟ್ಟಿಯಲ್ಲಿನ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಹೆಸರನ್ನು ಬಳಸಿಕೊಂಡು ಸಣ್ಣ ಸ್ಟ್ಯಾಂಡ್‌-ಇನ್ ಪ್ರೋಗ್ರಾಂ ಅನ್ನು (ಸುಮಾರು 120 KB, Rust ನಲ್ಲಿ ಬರೆಯಲಾಗಿದೆ ಮತ್ತು Decoy ನಲ್ಲಿ ಎಂಬೆಡ್ ಮಾಡಲಾಗಿದೆ) ತಾತ್ಕಾಲಿಕ ಫೋಲ್ಡರ್‌ಗೆ ನಕಲಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ `.../cod26-cod.exe`.
3. ಈ ಸ್ಟ್ಯಾಂಡ್‌-ಇನ್ ಒಂದು ಉನ್ನತ ಮಟ್ಟದ (top-level) ವಿಂಡೋವನ್ನು ಹೊಂದುವುದನ್ನು ಬಿಟ್ಟು ಬೇರೇನೂ ಮಾಡುವುದಿಲ್ಲ, ನೀವು ಅದನ್ನು ಎಂದಿಗೂ ನೋಡದಂತೆ ಆ ವಿಂಡೋವನ್ನು ಪರದೆಯಿಂದ ದೂರದಲ್ಲಿ ಇರಿಸಲಾಗುತ್ತದೆ. ವಿಂಡೋವನ್ನು ಹೊಂದಿರುವ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಮಾತ್ರ Discord ಗುರುತಿಸುತ್ತದೆ, ಅದಕ್ಕಾಗಿಯೇ ಸಂಪೂರ್ಣವಾಗಿ ವಿಂಡೋ ಇಲ್ಲದ ಪ್ರಕ್ರಿಯೆಯನ್ನು ನಿರ್ಲಕ್ಷಿಸಲಾಗುತ್ತದೆ.
4. ಸರಿಸುಮಾರು 15 ಸೆಕೆಂಡುಗಳಲ್ಲಿ Discord ಆಟವನ್ನು ನಿಮ್ಮ ಪ್ರಸ್ತುತ ಚಟುವಟಿಕೆಯಾಗಿ ತೋರಿಸುತ್ತದೆ.
5. ಟೈಮರ್ ಮುಗಿದಾಗ ಅಥವಾ ನೀವು ನಿಲ್ಲಿಸು ಒತ್ತಿದಾಗ, Decoy ಪ್ರಕ್ರಿಯೆಯನ್ನು ಕೊನೆಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಫೈಲ್ ಅನ್ನು ಅಳಿಸುತ್ತದೆ. Windows ಜಾಬ್ ಆಬ್ಜೆಕ್ಟ್ Decoy ಕ್ರ್ಯಾಶ್ ಆದರೂ ಸಹ decoy ಗಳು Decoy ಜೊತೆಗೆ ಕೊನೆಗೊಳ್ಳುವುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ.

ಅಗತ್ಯತೆಗಳು: WebView2 ರನ್‌ಟೈಮ್‌ನೊಂದಿಗೆ Windows 10 ಅಥವಾ 11 (64-bit) (ಈಗಾಗಲೇ Windows 11 ಮತ್ತು ಇತ್ತೀಚಿನ Windows 10 ನವೀಕರಣಗಳಲ್ಲಿ ಸೇರಿಸಲಾಗಿದೆ).

## ಬಳಕೆ

1. **Library** ತೆರೆಯಿರಿ ಮತ್ತು ಆಟವನ್ನು ಹುಡುಕಿ, ಅಥವಾ ಎಲ್ಲಿಂದಲಾದರೂ `Ctrl` + `K` ಒತ್ತಿ.
2. ಆಟದ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ. ಬಲಭಾಗದಲ್ಲಿರುವ ಫಲಕದಲ್ಲಿ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಮತ್ತು ಅದನ್ನು ಎಷ್ಟು ನಿಮಿಷಗಳ ಕಾಲ ಇರಿಸಬೇಕೆಂದು ಆಯ್ಕೆಮಾಡಿ (Discord ಚಟುವಟಿಕೆಗಳಿಗೆ ಸಾಮಾನ್ಯವಾಗಿ 15 ನಿಮಿಷ ಬೇಕಾಗುತ್ತದೆ).
3. **Decoy ಪ್ರಾರಂಭಿಸಿ** ಒತ್ತಿ. ಕೆಲವು ಸೆಕೆಂಡುಗಳ ನಂತರ Discord ಆಟವನ್ನು ತೋರಿಸುತ್ತದೆ.
4. ಇದನ್ನು **Running** ಅಡಿಯಲ್ಲಿ ವೀಕ್ಷಿಸಿ, ಯಾವುದೇ ಸಮಯದಲ್ಲಿ ಒಂದು ಅಥವಾ ಎಲ್ಲವನ್ನೂ ನಿಲ್ಲಿಸಿ, ಅಥವಾ Decoy ಅನ್ನು ಟ್ರೇನಲ್ಲಿ ಬಿಡಿ.

Discord ನಮೂದಿನಲ್ಲಿ ಇನ್ನೂ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್‌ಗಳು ಇಲ್ಲದ ಆಟಗಳನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಮರೆಮಾಡಲಾಗುತ್ತದೆ (ಅವುಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಲು ಸಾಧ್ಯವಿಲ್ಲ). ಅವುಗಳನ್ನು ನೋಡಲು *Show games without exe* ಆನ್ ಮಾಡಿ; ಪಟ್ಟಿಯನ್ನು ಪ್ರತಿದಿನ ನವೀಕರಿಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ Discord ಪ್ರಕ್ರಿಯೆಯನ್ನು ಸೇರಿಸಿದ ತಕ್ಷಣ ಅವು ಲಭ್ಯವಾಗುತ್ತವೆ.

### ಕಮಾಂಡ್ ಲೈನ್

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ತಕ್ಷಣವೇ decoy ಅನ್ನು ಪ್ರಾರಂಭಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## ಮೂಲದಿಂದ ಬಿಲ್ಡ್ ಮಾಡುವುದು

ಪೂರ್ವಾಪೇಕ್ಷಿತಗಳು: [Node.js](https://nodejs.org) 20+, Visual Studio C++ ಬಿಲ್ಡ್ ಪರಿಕರಗಳೊಂದಿಗೆ ಸ್ಥಿರವಾದ [Rust](https://rustup.rs) ಟೂಲ್‌ಚೈನ್ (MSVC ಟಾರ್ಗೆಟ್), ಮತ್ತು WebView2 ರನ್‌ಟೈಮ್.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # ಹಾಟ್ ರಿಲೋಡ್‌ನೊಂದಿಗೆ ಅಭಿವೃದ್ಧಿ ಮೋಡ್‌ನಲ್ಲಿ ರನ್ ಮಾಡಿ
npm run tauri build    # src-tauri/target/release/bundle/nsis ನಲ್ಲಿ ಇನ್‌ಸ್ಟಾಲರ್ ಅನ್ನು ಉತ್ಪಾದಿಸಿ
```

ಉಪಯುಕ್ತ ಪರಿಶೀಲನೆಗಳು:

```bash
npm run check-locales  # ru.json ವಿರುದ್ಧ ಪ್ರತಿಯೊಂದು ಅನುವಾದ ಫೈಲ್ ಅನ್ನು ಮೌಲ್ಯೀಕರಿಸಿ
npx tsc --noEmit       # ಮುಂಭಾಗದ (frontend) ಪ್ರಕಾರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ
cargo check --manifest-path src-tauri/Cargo.toml
```

ಟಿಪ್ಪಣಿಗಳು: decoy exe ಅನ್ನು `src-tauri/build.rs` ಮೂಲಕ ಸರಳ `rustc` ನೊಂದಿಗೆ `src-tauri/stub/stub.rs` ನಿಂದ ಕಂಪೈಲ್ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ನಂತರ ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಎಂಬೆಡ್ ಮಾಡಲಾಗುತ್ತದೆ. ಫ್ರಂಟ್‌ಎಂಡ್ ಸಾಮಾನ್ಯ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ರನ್ ಆಗುತ್ತಿರುವಾಗ (`npm run dev`), ಒಂದು ಸಣ್ಣ ಮಾಕ್ ಬ್ಯಾಕೆಂಡ್ (`src/mock.ts`) ಬಳಸಲಾಗುತ್ತದೆ, ಇದು UI ನಲ್ಲಿ ಕೆಲಸ ಮಾಡಲು ಅನುಕೂಲಕರವಾಗಿದೆ.

## ಅನುವಾದಗಳು

UI ಸ್ಟ್ರಿಂಗ್‌ಗಳು [`src/locales`](../../src/locales) ನಲ್ಲಿ ನೆಲೆಗೊಂಡಿವೆ, ಪ್ರತಿ ಭಾಷೆಗೆ ಒಂದು JSON ಫೈಲ್ (`en.json`, `ru.json`, ...).
ಭಾಷೆಯನ್ನು ಸೇರಿಸುವುದು ಎಂದರೆ ಫೈಲ್ ಅನ್ನು ಸೇರಿಸುವುದು; ಯಾವುದೇ ಕೋಡ್ ಬದಲಾವಣೆಗಳಿಲ್ಲ. ಫೈಲ್ ಫಾರ್ಮ್ಯಾಟ್, ಯಂತ್ರ ಅನುವಾದಕ್ಕಾಗಿ ಬಳಸಲು ಸಿದ್ಧವಾಗಿರುವ ಪ್ರಾಂಪ್ಟ್ ಮತ್ತು ಮೌಲ್ಯೀಕರಣ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಾಗಿ [docs/TRANSLATING.md](../TRANSLATING.md) ನೋಡಿ. ಈ README ನ ಅನುವಾದಗಳು `docs/i18n/README.<code>.md` ಗೆ ಹೋಗುತ್ತವೆ.

## ಗೌಪ್ಯತೆ

- Discord ನ ಸಾರ್ವಜನಿಕ ಪತ್ತೆಹಚ್ಚುವಿಕೆ ಪಟ್ಟಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು (ಮೊದಲ ಪ್ರಾರಂಭದಲ್ಲಿ, ನಂತರ ದಿನಕ್ಕೆ ಗರಿಷ್ಠ ಒಮ್ಮೆ ಅಥವಾ ನೀವು ರಿಫ್ರೆಶ್ ಒತ್ತಿದಾಗ) ಮತ್ತು ಪ್ರದರ್ಶನಕ್ಕಾಗಿ Discord ನ ಸಾರ್ವಜನಿಕ CDN ನಿಂದ ಆಟದ ಐಕಾನ್‌ಗಳು ಮತ್ತು ಕಲಾಕೃತಿಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು ಮಾತ್ರ Decoy ನೆಟ್‌ವರ್ಕ್ ಅನ್ನು ಬಳಸುತ್ತದೆ.
- ಇದು ನಿಮ್ಮ Discord ಟೋಕನ್ ಅಥವಾ ಯಾವುದೇ ಖಾತೆ ಡೇಟಾವನ್ನು ಓದುವುದಿಲ್ಲ, ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ ಅಥವಾ ಕಳುಹಿಸುವುದಿಲ್ಲ ಮತ್ತು ಇದು Discord ಕ್ಲೈಂಟ್‌ನೊಂದಿಗೆ ಸಂವಹನ ನಡೆಸುವುದಿಲ್ಲ.
- ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು (ಮೆಚ್ಚಿನವುಗಳು, ಭಾಷೆ, ಅವಧಿಗಳು) ಅಪ್ಲಿಕೇಶನ್‌ನ WebView ಸಂಗ್ರಹಣೆಯಲ್ಲಿ ಸ್ಥಳೀಯವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ; ಆಟದ ಪಟ್ಟಿ ಸಂಗ್ರಹ (cache) ಮತ್ತು ತಾತ್ಕಾಲಿಕ decoy ಫೈಲ್‌ಗಳು `%LOCALAPPDATA%\app.decoy.desktop` ನಲ್ಲಿ ನೆಲೆಗೊಂಡಿವೆ.
- ಯಾವುದೇ ಅನಾಲಿಟಿಕ್ಸ್ ಇಲ್ಲ, ಕ್ರ್ಯಾಶ್ ವರದಿ ಮಾಡುವಿಕೆ ಇಲ್ಲ, ಖಾತೆಗಳಿಲ್ಲ.

## ತಿಳಿದಿರುವ ಮಿತಿಗಳು

- ಪತ್ತೆಹಚ್ಚುವಿಕೆ ಹೇಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ ಎಂಬುದನ್ನು Discord ಯಾವುದೇ ಸಮಯದಲ್ಲಿ ಬದಲಾಯಿಸಬಹುದು. ಒಂದು decoy ಗುರುತಿಸಲ್ಪಡುವುದು ನಿಂತರೆ, ದಯವಿಟ್ಟು ಸಮಸ್ಯೆಯನ್ನು (issue) ತೆರೆಯಿರಿ.
- ಕೆಲವು ಚಟುವಟಿಕೆಗಳಿಗೆ ಕೇವಲ ಚಾಲನೆಯಲ್ಲಿರುವ ಪ್ರಕ್ರಿಯೆಗಿಂತ ಹೆಚ್ಚಿನ ಅಗತ್ಯವಿರುತ್ತದೆ (ಉದಾಹರಣೆಗೆ ಆಟದ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ನ ನಿರ್ದಿಷ್ಟ ಅನುಭವದ ಒಳಗೆ ಇರುವುದು). Decoy ಕೇವಲ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಮಾತ್ರ ಅನುಕರಿಸುತ್ತದೆ.
- Discord ಪಟ್ಟಿಯಲ್ಲಿ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್‌ಗಳಿಲ್ಲದ ನಮೂದುಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಲು ಸಾಧ್ಯವಿಲ್ಲ.
- ಮೆಮೊರಿಯಲ್ಲಿ ನಿಷ್ಕ್ರಿಯವಾಗಿರುವ ಸಣ್ಣ ಅನ್‌ಸೈನ್ಡ್ ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್‌ಗಳನ್ನು ಸೆಕ್ಯುರಿಟಿ ಸಾಫ್ಟ್‌ವೇರ್ ಸಾಂದರ್ಭಿಕವಾಗಿ ಫ್ಲ್ಯಾಗ್ ಮಾಡುತ್ತದೆ. Decoy ಮುಕ್ತ ಮೂಲವಾಗಿದೆ ಮತ್ತು `src-tauri/stub/stub.rs` ನಿಂದ ನಿರ್ಮಿಸಲಾಗಿದೆ; ನೀವು ಅದನ್ನು ಸ್ವತಃ ಕಂಪೈಲ್ ಮಾಡಬಹುದು.

## ಕೊಡುಗೆ ನೀಡುವುದು

ದೋಷ ವರದಿಗಳು, ಕಲ್ಪನೆಗಳು ಮತ್ತು ಅನುವಾದಗಳು ಸ್ವಾಗತಾರ್ಹ. ದಯವಿಟ್ಟು ಮೊದಲು [CONTRIBUTING.md](../../CONTRIBUTING.md) ಓದಿ.

## ಹಕ್ಕುತ್ಯಾಗ

Decoy ಅನ್ನು ವೈಯಕ್ತಿಕ, ಶೈಕ್ಷಣಿಕ ಮತ್ತು ಪರೀಕ್ಷಾ ಉದ್ದೇಶಗಳಿಗಾಗಿ "ಇರುವಂತೆಯೇ" ಒದಗಿಸಲಾಗಿದೆ. ಚಾಲನೆಯಲ್ಲಿರುವ ಆಟವನ್ನು ಅನುಕರಿಸುವುದು Discord ಅಥವಾ ಆಟದ ಪ್ರಕಾಶಕರ ಸೇವಾ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು ಮತ್ತು ನಿಮ್ಮ ಖಾತೆಯ ವಿರುದ್ಧ ಕ್ರಮಕ್ಕೆ ಕಾರಣವಾಗಬಹುದು. ನೀವು ಅದನ್ನು ಹೇಗೆ ಬಳಸುತ್ತೀರಿ ಎಂಬುದಕ್ಕೆ ನೀವು ಮಾತ್ರ ಜವಾಬ್ದಾರರಾಗಿರುತ್ತೀರಿ. "Discord" ಮತ್ತು ಎಲ್ಲಾ ಆಟದ ಹೆಸರುಗಳು ಮತ್ತು ಲೋಗೋಗಳು ಅವುಗಳ ಸಂಬಂಧಿತ ಮಾಲೀಕರ ಟ್ರೇಡ್‌ಮಾರ್ಕ್‌ಗಳಾಗಿವೆ ಮತ್ತು ಅವು ಉಲ್ಲೇಖಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ಅನ್ನು ಗುರುತಿಸಲು ಮಾತ್ರ ಇಲ್ಲಿ ಬಳಸಲಾಗುತ್ತದೆ.
