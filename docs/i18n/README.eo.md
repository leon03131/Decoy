# Decoy

**Malgrandegaj anstataŭaj procezoj, kiuj kredigas al Discord, ke ludo rulas.**

![Platformo](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Kreita per](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Permesilo](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-biblioteko kun lastatempaj ludoj kaj grafikoj" />

</div>

Decoy tenas sendanĝeran fenestran anstataŭan procezon rulanta sub la dosiernomo de la plenumebla dosiero de ludo, por ke la luda detektado de Discord raportu, ke vi ludas tiun ludon. Vi neniam bezonas instali aŭ lanĉi la veran ludon, do nenio granda okupas lokon sur via disko.

Ĝi konas **ĉiun ludon, kiun Discord povas detekti** (ĉirkaŭ 25 000 listeroj), ĉar ĝi legas la publikan detektliston de Discord mem kaj ĝisdatigas ĝin aŭtomate.

> [!WARNING]
> Falsi rulantan ludon povas kontraŭi la Servkondiĉojn de Discord kaj vi uzas Decoy **je via propra risko**.
> Ĉi tiu projekto ne estas asociita kun, subtenata de aŭ konektita al Discord Inc. Vidu [Malgarantion](#malgarantio).

## Trajtoj

- **Ĉio, kion Discord povas detekti.** La ludlisto estas elŝutata de la publika detekta finpunkto de Discord, kaŝmemorigata loke kaj ĝisdatigata ĉiutage. Novaj ludoj kaj nove aldonitaj plenumeblaj dosieroj aperas memstare.
- **Rapida serĉo, kiu sukcesas sekvi.** Tuja serĉo laŭ ludnomo aŭ plenumebla dosiero inter miloj da ludoj, krada aŭ kompakta lista vido, favoratoj kaj vico «Lastatempaj».
- **Unu klako.** Elektu ludon, elektu la plenumeblan dosieron (se estas pluraj), elektu kiom longe konservi ĝin kaj premu starton. Retronombra ringo kaj sciigo informas vin kiam la tempo finiĝas.
- **Lasas nenion post si.** Decoy ekzistas nur dum ĝi rulas: la eta exe kreiĝas ĉe la starto kaj forviŝiĝas ĉe la halto. Ĉio estas haltigata kiam vi eliras, kaj restaĵoj de paneo estas purigataj ĉe la sekva lanĉo.
- **Kvieta.** Rulas en la taskopleto, sen fenestroj aŭ taskobreto-butonoj por la decoy-oj mem.
- **Malfermitaj tradukoj.** La fasado estas stirata de simplaj JSON-dosieroj, do aldoni lingvon estas ununura dosiero. La angla kaj la rusa estas inkluzivitaj.
- **Privata.** Neniu konto, neniu Discord-ĵetono, neniu telemetrio. Vidu [Privatecon](#privateco).

## Kiel ĝi funkcias

1. Discord decidas, ke vi ludas ludon, rigardante la procezojn rulantajn sur via komputilo kaj komparante iliajn plenumeblajn dosiernomojn kun publika listo (`/api/v9/applications/detectable`).
2. Decoy elŝutas tiun liston kaj, por la ludo kiun vi elektas, kopias etan anstataŭan programon (ĉirkaŭ 120 KB, verkita en Rust kaj enkonstruita en Decoy) al provizora dosierujo uzante la plenumeblan dosiernomon el la listo, ekzemple `.../cod26-cod.exe`.
3. La anstataŭa programo faras nenion krom posedi unu supra-nivelan fenestron, parkitan malproksime ekster la ekrano por ke vi neniam vidu ĝin. Discord rekonas nur procezon, kiu posedas fenestron, tial tute senfenestra procezo estas ignorata.
4. Post proksimume 15 sekundoj Discord montras la ludon kiel vian nunan aktivecon.
5. Kiam la tempigilo finiĝas aŭ vi premas halton, Decoy finas la procezon kaj forviŝas la dosieron. Windows-taskobjekto (job object) certigas, ke decoy-oj ĉesas kune kun Decoy, eĉ se ĝi paneas.

## Instalado

Elektu unu el la paĝo de [Eldonoj](../../../../releases):

| Elŝuto | Por |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalilo.** Por-uzanta, neniuj administraj rajtoj bezonataj, aldonas eniron en la Start-menuon kaj malinstalilon. |
| `Decoy_x.y.z_x64-portable.zip` | **Portebla.** Malpaku ie ajn kaj rulu `decoy.exe`. Ĉiuj datumoj restas en la apuda dosierujo `data`, nenio estas skribata al via uzantprofilo. Forviŝu la dosierujon por forigi ĝin. |

Kontrolu elŝuton per `SHA256SUMS.txt` (`Get-FileHash <file>` en PowerShell).

Windows SmartScreen eble avertos pri nerekonita eldonisto ĉar la konstruaĵoj ne estas kodsubskribitaj; elektu *Pli da informoj → Ruli ĉiukaze* se vi fidas la konstruaĵon.

Postuloj: Windows 10 aŭ 11 (64-bita) kun la rultempo WebView2 (jam inkluzivita en Windows 11 kaj freŝaj ĝisdatigoj de Windows 10).

## Uzado

1. Malfermu **Bibliotekon** kaj serĉu ludon, aŭ premu `Ctrl` + `K` de ie ajn.
2. Alklaku ludon. En la dekstra panelo elektu la procezon kaj kiom da minutoj konservi ĝin (Discord-aktivecoj kutime postulas 15).
3. Premu **Lanĉi decoy**. Discord montros la ludon post kelkaj sekundoj.
4. Rigardu ĝin sub **Rulanta**, haltigu unu aŭ ĉiujn iam ajn, aŭ simple lasu Decoy en la taskopleto.

Ludoj, kies Discord-eniro ankoraŭ ne havas plenumeblajn dosierojn, estas kaŝitaj defaŭlte (ili ne povas esti detektitaj). Enŝaltu *Montri ludojn sen exe* por vidi ilin; la listo estas ĝisdatigata ĉiutage, do ili fariĝas disponeblaj tuj kiam Discord aldonas procezon.

### Komandlinio

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Lanĉas decoy tuj, ekzemple `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Konstrui el fontkodo

Antaŭkondiĉoj: [Node.js](https://nodejs.org) 20+, la stabila ilaro de [Rust](https://rustup.rs) (MSVC-celo) kun la konstruiloj de Visual Studio C++, kaj la rultempo WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Utilaj kontroloj:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notoj: la decoy-exe estas kompilata per `src-tauri/build.rs` per simpla `rustc` el `src-tauri/stub/stub.rs` kaj poste enkonstruata en la aplikaĵon. Kiam la fasado rulas en ordinara retumilo (`npm run dev`), malgranda ŝajniga servilo (`src/mock.ts`) estas uzata, kio estas oportuna por labori pri la fasado.

## Tradukoj

La fasadaj tekstoj troviĝas en [`src/locales`](../../src/locales), unu JSON-dosiero por ĉiu lingvo (`en.json`, `ru.json`, ...).
Aldoni lingvon signifas aldoni dosieron; neniuj kodŝanĝoj. Vidu [docs/TRANSLATING.md](../TRANSLATING.md) por la dosierformato, preta instrukcio por maŝintradukado kaj la validiga skripto. Tradukoj de ĉi tiu README iras al `docs/i18n/README.<code>.md`.

## Projekta strukturo

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privateco

- Decoy uzas la reton nur por elŝuti la publikan detektliston de Discord (ĉe la unua starto, poste maksimume unufoje tage aŭ kiam vi premas refreŝigon) kaj, por montrado, ludajn piktogramojn kaj grafikaĵojn de la publika CDN de Discord.
- Ĝi ne legas, konservas aŭ sendas vian Discord-ĵetonon aŭ ajnajn kontodatenojn, kaj ĝi ne komunikas kun la Discord-kliento.
- Agordoj (favoratoj, lingvo, daŭroj) estas konservataj loke en la WebView-stokado de la aplikaĵo; la ludlista kaŝmemoro kaj provizoraj decoy-dosieroj troviĝas en `%LOCALAPPDATA%\app.decoy.desktop`.
- Neniu analitiko, neniu paneoraportado, neniuj kontoj.

## Konataj limigoj

- Discord povas ŝanĝi kiel detektado funkcias iam ajn. Se decoy ĉesas esti rekonata, bonvolu malfermi problemraporton.
- Kelkaj aktivecoj bezonas pli ol nur rulantan procezon (ekzemple esti ene de specifa sperto de luda platformo). Decoy nur imitas la procezon.
- Listeroj sen plenumeblaj dosieroj en la listo de Discord ne povas esti detektitaj.
- Sekureca programaro foje markas malgrandajn nesubskribitajn plenumeblajn dosierojn, kiuj sidas senfaraj en memoro. Decoy estas malfermitkoda kaj konstruata el `src-tauri/stub/stub.rs`; vi povas kompili ĝin mem.

## Kontribuado

Cimraportoj, ideoj kaj tradukoj estas bonvenaj. Bonvolu legi [CONTRIBUTING.md](../../CONTRIBUTING.md) unue.

## Malgarantio

Decoy estas provizita «kiel ĝi estas» por personaj, edukaj kaj testaj celoj. Imiti rulantan ludon povas malobservi la Servkondiĉojn de Discord aŭ de la ludeldonisto, kaj povas kaŭzi agojn kontraŭ via konto. Vi sole respondecas pri kiel vi uzas ĝin. «Discord» kaj ĉiuj ludnomoj kaj emblemoj estas varmarkoj de siaj respektivaj posedantoj kaj estas uzataj ĉi tie nur por identigi la programaron al kiu ili rilatas.
