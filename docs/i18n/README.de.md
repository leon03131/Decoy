# Decoy

**Winzige Platzhalter-Prozesse, die Discord vorgaukeln, dass ein Spiel läuft.**

![Plattform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Erstellt mit](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Lizenz](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-Bibliothek mit zuletzt genutzten Spielen und Grafiken" />

</div>

Decoy hält einen harmlosen Platzhalter-Prozess mit eigenem Fenster unter dem Namen der ausführbaren Datei eines Spiels am Laufen, sodass Discords Spielerkennung anzeigt, dass du dieses Spiel spielst. Du musst das eigentliche Spiel weder installieren noch starten, sodass keine großen Dateien deinen Speicherplatz belegen.

Es kennt **jedes Spiel, das Discord erkennen kann** (etwa 25.000 Einträge), da es die öffentliche Erkennungsliste von Discord ausliest und sich selbstständig auf dem neuesten Stand hält.

> [!WARNING]
> Das Vortäuschen eines laufenden Spiels kann gegen die Nutzungsbedingungen von Discord verstoßen; die Nutzung von Decoy erfolgt **auf eigene Gefahr**.
> Dieses Projekt steht in keinerlei Verbindung zu Discord Inc., wird nicht von Discord unterstützt oder empfohlen. Siehe [Haftungsausschluss](#haftungsausschluss).

## Funktionen

- **Alles, was Discord erkennen kann.** Die Spieleliste wird vom öffentlichen Erkennungs-Endpunkt von Discord heruntergeladen, lokal zwischengespeichert und täglich aktualisiert. Neue Spiele und neu hinzugefügte ausführbare Dateien erscheinen automatisch.
- **Schnelle Suche, die Schritt hält.** Sofortige Suche nach Spielname oder ausführbarer Datei über Tausende von Spielen hinweg, Raster- oder Kompaktlistenansicht, Favoriten und eine Zeile mit den zuletzt genutzten Spielen („Zuletzt“).
- **Mit einem Klick.** Spiel auswählen, ausführbare Datei wählen (falls mehrere vorhanden sind), gewünschte Laufzeit festlegen und auf Start drücken. Ein Countdown-Ring und eine Benachrichtigung informieren dich, sobald die Zeit abgelaufen ist.
- **Hinterlässt keine Rückstände.** Ein Decoy existiert nur, während er läuft: Die winzige exe wird beim Start erstellt und beim Beenden gelöscht. Beim Schließen des Programms wird alles beendet, und eventuelle Überbleibsel eines Absturzes werden beim nächsten Start bereinigt.
- **Unauffällig.** Befindet sich im Infobereich der Taskleiste (System-Tray), ohne Fenster oder Taskleistenschaltflächen für die Decoys selbst.
- **Offene Übersetzungen.** Die Benutzeroberfläche basiert auf einfachen JSON-Dateien – das Hinzufügen einer neuen Sprache erfordert lediglich eine einzige Datei. Englisch und Russisch sind bereits enthalten.
- **Privatsphäre garantiert.** Kein Benutzerkonto, kein Discord-Token, keine Telemetrie. Siehe [Datenschutz](#datenschutz).

## Funktionsweise

1. Discord stellt fest, dass du ein Spiel spielst, indem es die auf deinem PC laufenden Prozesse prüft und deren Namen ausführbarer Dateien mit einer öffentlichen Liste abgleicht (`/api/v9/applications/detectable`).
2. Decoy lädt diese Liste herunter und kopiert für das ausgewählte Spiel ein winziges Platzhalter-Programm (etwa 120 KB, in Rust geschrieben und in Decoy eingebettet) unter dem Namen der ausführbaren Datei aus der Liste in einen temporären Ordner, zum Beispiel `.../cod26-cod.exe`.
3. Der Platzhalter tut nichts weiter, als ein einzelnes Hauptfenster zu besitzen, das weit außerhalb des Bildschirms platziert ist, sodass du es nie siehst. Discord erkennt nur Prozesse, die ein Fenster besitzen – weshalb ein komplett fensterloser Prozess ignoriert wird.
4. Nach etwa 15 Sekunden zeigt Discord das Spiel als deine aktuelle Aktivität an.
5. Wenn der Timer abläuft oder du auf Stopp drückst, beendet Decoy den Prozess und löscht die Datei. Ein Windows-Job-Objekt stellt sicher, dass Decoys zusammen mit Decoy beendet werden, selbst bei einem Absturz.

## Installation

Wähle ein Paket von der [Releases](../../../../releases)-Seite:

| Download | Für |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installer.** Pro Benutzer, keine Administratorrechte erforderlich, fügt einen Startmenü-Eintrag sowie ein Deinstallationsprogramm hinzu. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Beliebig entpacken und `decoy.exe` starten. Alle Daten verbleiben im danebenliegenden Ordner `data`, es wird nichts in dein Benutzerprofil geschrieben. Zum Entfernen einfach den Ordner löschen. |

Verifiziere den Download mit `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen warnt möglicherweise vor einem unbekannten Herausgeber, da die Builds nicht digital signiert sind; wähle *Weitere Informationen → Trotzdem ausführen*, wenn du dem Build vertraust.

Voraussetzungen: Windows 10 oder 11 (64-Bit) mit der WebView2-Runtime (in Windows 11 und aktuellen Updates für Windows 10 bereits enthalten).

## Verwendung

1. Öffne die **Bibliothek** und suche nach einem Spiel, oder drücke von überall `Strg` + `K`.
2. Klicke auf ein Spiel. Wähle im rechten Bereich den Prozess und die Dauer in Minuten aus (Discord-Aktivitäten erfordern in der Regel 15 Minuten).
3. Klicke auf **Decoy starten**. Discord zeigt das Spiel nach wenigen Sekunden an.
4. Behalte den Status unter **Laufend** im Blick, beende einzelne oder alle Prozesse jederzeit, oder minimiere Decoy einfach in den Infobereich.

Spiele, deren Discord-Eintrag noch keine ausführbaren Dateien enthält, sind standardmäßig ausgeblendet (sie können nicht erkannt werden). Aktiviere *Spiele ohne exe anzeigen*, um sie zu sehen; die Liste wird täglich aktualisiert, sodass sie verfügbar werden, sobald Discord einen Prozess hinzufügt.

### Befehlszeile

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Startet direkt einen Decoy, zum Beispiel `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Aus dem Quellcode bauen

Voraussetzungen: [Node.js](https://nodejs.org) 20+, die stabile [Rust](https://rustup.rs)-Toolchain (MSVC-Zielplattform) mit den Visual Studio C++-Buildtools sowie die WebView2-Runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Nützliche Überprüfungen:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Hinweise: Die Decoy-exe wird von `src-tauri/build.rs` mit regulärem `rustc` aus `src-tauri/stub/stub.rs` kompiliert und anschließend in die Anwendung eingebettet. Wenn das Frontend in einem normalen Browser läuft (`npm run dev`), kommt ein kleines Mock-Backend (`src/mock.ts`) zum Einsatz, was für die Arbeit an der Benutzeroberfläche praktisch ist.

## Übersetzungen

Die Texte der Benutzeroberfläche befinden sich in [`src/locales`](../../src/locales), jeweils eine JSON-Datei pro Sprache (`en.json`, `ru.json`, ...).
Das Hinzufügen einer Sprache erfordert lediglich eine neue Datei – keinerlei Änderungen am Code. Siehe [docs/TRANSLATING.md](../TRANSLATING.md) für das
Dateiformat, einen fertigen Prompt für maschinelle Übersetzungen und das Validierungsskript. Übersetzungen dieser README gehören nach
`docs/i18n/README.<code>.md`.

## Projektstruktur

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Datenschutz

- Decoy nutzt das Netzwerk ausschließlich, um die öffentliche Erkennungsliste von Discord herunterzuladen (beim ersten Start, danach höchstens einmal täglich oder beim manuellen Aktualisieren) sowie zur Anzeige von Spiel-Icons und Grafiken über das öffentliche CDN von Discord.
- Es liest, speichert oder überträgt weder dein Discord-Token noch irgendwelche Kontodaten und kommuniziert nicht mit dem Discord-Client.
- Einstellungen (Favoriten, Sprache, Zeitdauern) werden lokal im WebView-Speicher der App gesichert; der Cache der Spieleliste und temporäre Decoy-Dateien liegen in `%LOCALAPPDATA%\app.decoy.desktop`.
- Keine Analysen, keine Absturzberichte, keine Benutzerkonten.

## Bekannte Einschränkungen

- Discord kann die Funktionsweise der Erkennung jederzeit ändern. Falls ein Decoy nicht mehr erkannt wird, erstelle bitte ein Issue.
- Einige Aktivitäten erfordern mehr als nur einen laufenden Prozess (zum Beispiel der Aufenthalt in einer bestimmten Spielerfahrung auf einer Spieleplattform). Decoy imitiert ausschließlich den Prozess.
- Einträge ohne ausführbare Dateien in Discords Liste können nicht erkannt werden.
- Sicherheitssoftware stuft gelegentlich kleine, nicht signierte Programme, die unbeschäftigt im Speicher liegen, als verdächtig ein. Der Decoy ist open source und wird aus `src-tauri/stub/stub.rs` gebaut; du kannst ihn selbst kompilieren.
