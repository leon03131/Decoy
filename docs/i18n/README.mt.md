# Decoy

**Proċessi żgħar ta' sostituzzjoni li jġiegħlu lil Discord jaħseb li hemm logħba qed taħdem.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Librerija ta' Decoy b'logħob riċenti u grafika" />

</div>

Decoy iżomm proċess fittizju, bla periklu u bit-tieqa jaħdem taħt l-isem eżekwibbli ta' logħba, sabiex id-detezzjoni tal-logħob ta' Discord turi li qed tilgħab dik il-logħba. Qatt ma jkollok bżonn tinstalla jew tixgħel il-logħba vera, u għalhekk xejn kbir ma jieħu spazju fuq id-diska tiegħek.

Jaf b'**kull logħba li Discord jista' jidentifika** (madwar 25,000 dħul) għaliex jaqra l-lista pubblika ta' detezzjoni ta' Discord stess u jżommha aġġornata waħdu.

> [!WARNING]
> Li tiffalsifika logħba mixgħula jista' jmur kontra t-Termini tas-Servizz ta' Discord u tuża Decoy **għar-riskju tiegħek stess**.
> Dan il-proġett mhuwiex affiljat ma', approvat minn jew konness b'xi mod ma' Discord Inc. Ara [Ċaħda ta' Responsabbiltà](#ċaħda-ta-responsabbiltà).

## Karatteristiċi

- **Kull ma Discord jista' jidentifika.** Il-lista tal-logħob titniżżel mill-endpoint pubbliku ta' detezzjoni ta' Discord, tiġi kkaxxjata lokalment u tiġġedded kuljum. Logħob ġdid u eżekwibbli li għadhom kif ġew miżjuda jidhru waħedhom.
- **Tiftix mgħaġġel li jlaħħaq.** Tiftix istantanju skont l-isem tal-logħba jew l-eżekwibbli fost eluf ta' logħob, dehra f'forma ta' kaxxi jew lista kompatta, favoriti u ringiela għal logħob "Riċenti".
- **Bi klikk waħda.** Agħżel logħba, agħżel l-eżekwibbli (jekk hemm diversi), iddeċiedi kemm tridu jibqa' għaddej u agħfas ibda. Ċirku tal-għadd lura u notifika jgħarrfuk meta jiskadi l-ħin.
- **Ma jħalli xejn warajh.** Decoy jeżisti biss waqt li jkun qed jaħdem: l-exe żgħir jinħoloq mal-bidu u jitħassar malli jieqaf. Kollox jintemm meta toħroġ, u kwalunkwe fdal minn xi għeluq ħabta u sabta jitnaddaf mal-ftuħ li jmiss.
- **Kwit.** Jgħix fit-trej tas-sistema, mingħajr twieqi jew buttuni fuq it-taskbar għad-decoys stess.
- **Traduzzjonijiet miftuħa.** L-interface taħdem b'fajls JSON sempliċi, u b'hekk iż-żieda ta' lingwa teħtieġ fajl wieħed biss. L-Ingliż u r-Russu huma diġà inklużi.
- **Privat.** Ebda kont, ebda token ta' Discord, ebda telemetrija. Ara [Privatezza](#privatezza).

## Kif jaħdem

1. Discord jiddeċiedi li qed tilgħab logħba billi jara l-proċessi li qed jaħdmu fuq il-PC tiegħek u jqabbel l-ismijiet tal-eżekwibbli tagħhom ma' lista pubblika (`/api/v9/applications/detectable`).
2. Decoy iniżżel dik il-lista u, għal-logħba li tagħżel, jikkopja programm fittizju żgħir ħafna (madwar 120 KB, miktub f'Rust u inkorporat f'Decoy) ġo fowlder temporanju bl-isem tal-eżekwibbli mil-lista, per eżempju `.../cod26-cod.exe`.
3. Il-programm fittizju ma jagħmel xejn ħlief li jkollu tieqa waħda tal-ogħla livell, ipparkjata 'l barra mill-iskrin b'tali mod li qatt ma taraha. Discord jagħraf biss proċess li għandu tieqa, u għalhekk proċess għalkollox mingħajr tieqa jiġi injorat.
4. Fi żmien bejn wieħed u ieħor 15-il sekonda Discord juri l-logħba bħala l-attività kurrenti tiegħek.
5. Meta jiskadi t-tajmer jew tagħfas waqqaf, Decoy itemm il-proċess u jħassar il-fajl. Windows job object jiżgura li d-decoys jintemmu flimkien ma' Decoy, anke jekk jieqaf ħabta u sabta.

## Installa

Agħżel wieħed mill-paġna ta' [Releases](../../../../releases):

| Niżżel | Għal |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installatur.** Għal kull utent individwali, m'hemmx bżonn drittijiet ta' amministratur, iżid dħul fil-menu Start u uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabbli.** Ħoll l-arkivju zip fejn trid u ħaddem `decoy.exe`. Id-data kollha tibqa' fil-fowlder `data` maġenbu, xejn ma jinkiteb fil-profil tal-utent tiegħek. Ħassar il-fowlder biex tneħħih. |

Ivvifika t-tniżżil b'`SHA256SUMS.txt` (`Get-FileHash <file>` f'PowerShell).

Windows SmartScreen jista' javża dwar pubblikatur mhux rikonoxxut għax il-builds mhumiex iffirmati b'kodiċi diġitali; agħżel *More info → Run anyway* jekk tafda l-build.

Rekwiżiti: Windows 10 jew 11 (64-bit) bir-runtime WebView2 (diġà inkluż f'Windows 11 u fl-aġġornamenti reċenti ta' Windows 10).

## Użu

1. Iftaħ **Librerija** u fittex logħba, jew agħfas `Ctrl` + `K` minn kwalunkwe post fl-app.
2. Ikklikkja fuq logħba. Fil-pannell tal-lemin agħżel il-proċess u kemm trid minuti żżommu (l-attivitajiet ta' Discord normalment jitolbu 15).
3. Agħfas **Ibda decoy**. Discord se juri l-logħba wara ftit sekondi.
4. Segwiha taħt **Għaddejjin**, waqqaf waħda jew kollha f'kull ħin, jew sempliċement ħalli lil Decoy fit-trej.

Logħob li d-dħul tagħhom f'Discord għad m'għandux eżekwibbli huma moħbija b'mod awtomatiku (ma jistgħux jiġu identifikati). Ixgħel *Uri logħob mingħajr exe* biex tarahom; il-lista tiġġedded kuljum, u għalhekk isiru disponibbli malli Discord iżid proċess.

### Linja tal-kmand

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Jibda decoy minnufih, per eżempju `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ibni mis-sors

Prerekwiżiti: [Node.js](https://nodejs.org) 20+, it-toolchain stabbli ta' [Rust](https://rustup.rs) (MSVC target) bil-Visual Studio C++ build tools, u r-runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # ħaddem fil-mod ta' żvilupp b'hot reload
npm run tauri build    # ipproduċi l-installatur f'src-tauri/target/release/bundle/nsis
```

Kontrolli utli:

```bash
npm run check-locales  # ivvalida kull fajl ta' traduzzjoni ma' ru.json
npx tsc --noEmit       # iċċekkja t-tipi tal-frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Noti: l-exe tad-decoy jiġi kkompilat minn `src-tauri/build.rs` permezz ta' `rustc` ordinarju minn `src-tauri/stub/stub.rs` u mbagħad inkorporat fl-applikazzjoni. Meta l-frontend jaħdem f'browser komuni (`npm run dev`) jintuża mock backend żgħir (`src/mock.ts`), li huwa utli ħafna meta tkun qed taħdem fuq l-UI.

## Traduzzjonijiet

Is-sensieli tal-UI jinsabu f'[`src/locales`](../../src/locales), fajl JSON wieħed għal kull lingwa (`en.json`, `ru.json`, ...). Li żżid lingwa jfisser biss li żżid fajl; ebda bidla fil-kodiċi. Ara [docs/TRANSLATING.md](../TRANSLATING.md) għall-format tal-fajl, prompt lest biex jintuża għat-traduzzjoni awtomatika u l-iskript ta' validazzjoni. Traduzzjonijiet ta' dan ir-README jmorru f'`docs/i18n/README.<code>.md`.


## Privatezza

- Decoy juża n-netwerk biss biex iniżżel il-lista pubblika ta' detezzjoni ta' Discord (mal-ewwel tħaddim, u wara mhux aktar minn darba kuljum jew meta tagħfas aġġorna) u, għall-wiri, ikoni tal-logħob u grafika mill-CDN pubbliku ta' Discord.
- Ma jaqrax, ma jaħżinx u ma jibgħatx it-token tiegħek ta' Discord jew xi data tal-kont, u ma jikkomunikax mal-klijent ta' Discord.
- Is-settings (favoriti, lingwa, tul ta' ħin) huma maħżuna lokalment fil-ħażna tal-WebView tal-app; il-cache tal-lista tal-logħob u l-fajls temporanji tad-decoy jinżammu f'`%LOCALAPPDATA%\app.decoy.desktop`.
- Ebda analitika, ebda rappurtar ta' ħabtiet, ebda kontijiet.

## Limitazzjonijiet magħrufa

- Discord jista' jbiddel kif taħdem id-detezzjoni fi kwalunkwe ħin. Jekk decoy ma jibqax jintgħaraf, jekk jogħġbok iftaħ issue.
- Xi attivitajiet jeħtieġu aktar minn proċess li qed jaħdem (per eżempju li tkun ġewwa esperjenza partikolari ta' pjattaforma tal-logħob). Decoy jissimula biss il-proċess.
- Dħul mingħajr eżekwibbli fil-lista ta' Discord ma jistgħux jiġu identifikati.
- Softwer tas-sigurtà kultant jissuspettu f'eżekwibbli żgħar mhux iffirmati li jibqgħu inattivi fil-memorja. Id-decoy huwa ta' sors miftuħ u mibni minn `src-tauri/stub/stub.rs`; tista' tikkompilah int stess.
