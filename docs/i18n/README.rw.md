# Decoy

**Porogaramu nto z'urwiganwa zituma Discord itekereza ko umukino uri gukora.**

![Urubuga](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Yubatswe na](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Uruhushya](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Isomero rya Decoy hamwe n'imikino iheruka n'amashusho yayo" />

</div>

Decoy igumisha porogaramu y'urwiganwa idateje akaga ifite idirishya ikora munsi y'izina rya exe y'umukino, ku buryo uburyo bwo kumenya imikino bwa Discord bugaragaza ko uri gukina uwo mukino. Ntabwo ukeneye kwinjiza cyangwa gufungura umukino nyakuri, bityo nta kintu kinini gisigara ku bubiko bwa mudasobwa yawe.

Izi **buri mukino wose Discord ishobora kumenya** (hafi imikino 25,000) kubera ko isoma urutonde rusange rwa Discord ubwayo rukoreshwa mu kumenya imikino kandi ikaruvugurura ubwayo.

> [!WARNING]
> Kwigana umukino uri gukora bishobora kunyuranya n'Amategeko y'Imikoreshereze ya Discord kandi ukoresha Decoy **ku ngaruka zawe bwite**.
> Uyu mushinga nta sano ufitanye na Discord Inc., ntiwashyizweho umukono na yo cyangwa ngo uyishamikeho. Reba [Icyitonderwa](#icyitonderwa).

## Ibiranga

- **Buri kintu cyose Discord ishobora kumenya.** Urutonde rw'imikino ruturuka ku rubuga rusange rwa Discord rwo kumenya imikino, rukabikwa muri mudasobwa kandi rukavugururwa buri munsi. Imikino mishya n'amadosiye ya exe yongewemo mashya byizana ubwabyo.
- **Gushakisha kwihuta cyane.** Gushakisha ako kanya ku izina ry'umukino cyangwa dosiye ya exe mu mikino ibihumbi n'ibihumbi, kureba mu buryo bw'utwito cyangwa urutonde ruto, ibyatoranyijwe n'umurongo w'“Ibiheruka”.
- **Kanda rimwe gusa.** Hitamo umukino, hitamo dosiye ya exe (niba ari nyinshi), hitamo igihe imara ikora hanyuma ukande tangiza. Uruziga rw'ibarira-gihe n'integuza bizakumenyesha igihe kirangiye.
- **Nta kintu gisigara inyuma.** Decoy ibaho gusa mu gihe ikora: dosiye nto ya exe iremwa igihe itangiye kandi igahanagurwa iyo ihagaze. Byose birahagarara iyo usohotse muri porogaramu, kandi ibyasigaye bitewe no gufunga nabi bihanagurwa igihe wongeye kuyifungura.
- **Ituje.** Iguma mu gashushanyo k'akabati ka sisitemu (system tray), nta madirishya cyangwa buto zo ku murongo w'imirimo (taskbar) kuri decoy ubwazo.
- **Ubusobanuro bufunguye.** Imigaragarire ya porogaramu iyoborwa n'amadosiye asanzwe ya JSON, bityo kongeramo ururimi bisaba gusa dosiye imwe. Icyongereza n'Ikirusiya birimo.
- **Ibwitondere (ibanga).** Nta konti ikenerwa, nta kimenyetso cya Discord (token), nta makuru y'imikoreshereze akusanywa (telemetry). Reba [Ibwitondere](#ibwitondere).

## Uko ikora

1. Discord ifata icyemezo cy'uko uri gukina umukino isuzumye porogaramu ziri gukora kuri mudasobwa yawe no kugereranya amazina yazo ya exe n'urutonde rusange (`/api/v9/applications/detectable`).
2. Decoy ikura urwo rutonde kuri interineti maze, ku mukino wahisemo, ikoporora porogaramu ntoya y'urwiganwa (hafi KB 120, yanditswe muri Rust kandi yinjijwe muri Decoy) ikayishyira mu bubiko bw'agateganyo ikoresheje izina rya exe rivuye ku rutonde, urugero `.../cod26-cod.exe`.
3. Porogaramu y'urwiganwa nta kindi ikora usibye kugira idirishya rimwe ry'urwego rwo hejuru, ryihishe kure y'ubuso bwa ekara ku buryo utaryigera ubona. Discord imenya gusa porogaramu ifite idirishya, ari yo mpamvu porogaramu idafite idirishya na rimwe yirengagizwa.
4. Mu masegonda asaga 15 Discord igaragaza umukino nk'ibyo uri gukora muri uwo mwanya.
5. Iyo ibarira-gihe rirangiye cyangwa ukanda hagarika, Decoy ihagarika porogaramu igahanagura na dosiye. Igikoresho cya Windows gishinzwe imirimo (job object) kireba ko decoy zihagararira rimwe na Decoy, n'ubwo yafunga nabi mu buryo butunguranye.

## Kwinjiza muri mudasobwa

Hitamo imwe ku rupapuro rwa [Releases](../../../../releases):

| Icyakuwe | Icyo kigenewe |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Uwashyira muri mudasobwa (Installer).** Kuri buri mukoresha, nta burenganzira bw'ubuyobozi bwa mudasobwa (administrator) bukenewe, yongeraho ahanditse Tangira (Start menu) n'uburyo bwo kuyikuramo. |
| `Decoy_x.y.z_x64-portable.zip` | **Igitwarika (Portable).** Gupfundura ahantu aho ari ho hose hanyuma ugakora kuri `decoy.exe`. Amakuru yose aguma mu bubiko bwa `data` buyiri iruhande, nta kintu cyandikwa mu mwirondoro w'umukoresha. Siba ubwo bubiko kugira ngo uyikuremo. |

Genyura dosiye wamanuye ukoresheje `SHA256SUMS.txt` (`Get-FileHash <file>` muri PowerShell).

Windows SmartScreen ishobora kuguha integuza ku bijyanye n'umwanditsi utazwi kubera ko dosiye zitarashyirwaho umukono w'umutekano (code signed); hitamo *Amakuru arambuye → Komeza ukore (More info → Run anyway)* niba wiringiye iyi dosiye.

Ibisabwa: Windows 10 cyangwa 11 (ya 64-bit) ifite WebView2 runtime (isanzwe iboneka muri Windows 11 no mu mavugurura ya vuba ya Windows 10).

## Imikoreshereze

1. Fungura **Isomero** maze ushake umukino, cyangwa ukande `Ctrl` + `K` aho waba uri hose.
2. Kanda ku mukino. Mu gice cy'iburyo hitamo porogaramu n'iminota y'igihe ishobora kumara ikora (imikoro ya Discord isanzwe isaba 15).
3. Kanda **Tangiza decoy**. Discord izerekana umukino nyuma y'amasegonda make.
4. Byitegereze munsi y'ahavuga **Ibikora**, hagarika imwe cyangwa zose igihe icyo ari cyo cyose, cyangwa se usige Decoy mu gashushanyo k'akabati.

Imikino ifite amakuru muri Discord ariko itarabona amadosiye ya exe irahishwa mu buryo busanzwe (ntiyashobora kumenyekana). Emeza *Erekana imikino idafite exe* kugira ngo uyibone; urutonde ruvugururwa buri munsi, bityo iboneka hejuru igihe cyose Discord yongereyemo porogaramu.

### Umurongo w'amabwiriza (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Itangiza decoy ako kanya, urugero `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kubaka uhereye ku nkomoko y'inyandiko

Ibyangombwa: [Node.js](https://nodejs.org) 20+, ibikoresho byizewe bya [Rust](https://rustup.rs) (MSVC target) hamwe n'ibikoresho byo kubaka bya Visual Studio C++, na WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # gukora mu buryo bw'iterambere no kuvugurura ako kanya
npm run tauri build    # gukora dosiye yinjiza muri src-tauri/target/release/bundle/nsis
```

Igenzura ry'ingirakamaro:

```bash
npm run check-locales  # kugenzura buri dosiye y'ururimi ugereranyije na ru.json
npx tsc --noEmit       # kugenzura ubwoko bwa kodi bw'imbere (frontend)
cargo check --manifest-path src-tauri/Cargo.toml
```

Icyitonderwa: dosiye ya exe ya decoy ikorwa na `src-tauri/build.rs` ikoresheje `rustc` isanzwe iva muri `src-tauri/stub/stub.rs` hanyuma ikinjizwa muri porogaramu. Iyo igice cy'imbere gikora muri mushakisha isanzwe (`npm run dev`), uburyo bw'icyitegererezo bwa backend (`src/mock.ts`) burakoreshwa, ibyo bikaba byiza mu gukorera ku migaragarire (UI).

## Ubusobanuro mu zindi ndimi

Amagambo y'imigaragarire y'umukoresha ari muri [`src/locales`](../../src/locales), dosiye imwe ya JSON kuri buri rurimi (`en.json`, `ru.json`, ...). Kongeramo ururimi bivuze kongeramo dosiye; nta guhindura kodi. Reba [docs/TRANSLATING.md](../TRANSLATING.md) kugira ngo umenye imiterere ya dosiye, amabwiriza yiteguye gukoreshwa kuri mudasobwa isobanura n'inyandiko igenzura. Ubusobanuro bw'iyi README bujyana muri `docs/i18n/README.<code>.md`.

## Ibwitondere

- Decoy ikoresha gusa umuyoboro wa interineti mugihe ikura urutonde rusange rwa Discord rwo kumenya imikino (ku nshuro ya mbere ifunguwe, nyuma rimwe gusa ku munsi cyangwa se igihe ukande vugurura) no kwerekana udufuka n'amashusho y'imikino bituruka ku bubiko bwa CDN bwa Discord.
- Ntisoma, ntibika cyangwa ngo yohereze ikimenyetso cyawe cya Discord (token) cyangwa amakuru y'umwirondoro wawe, kandi ntiyigera ivugana na porogaramu ya Discord ubwayo.
- Igenamiterere (ibyatoranyijwe, ururimi, ibihe by'imikoreshereze) ribikwa imbere muri mudasobwa mu bubiko bwa WebView bwa porogaramu; urutonde rw'imikino rwabitswe by'agateganyo n'amadosiye ya decoy bibikwa muri `%LOCALAPPDATA%\app.decoy.desktop`.
- Nta bipimo by'imikoreshereze (analytics), nta raporo z'amakosa zoherezwa, nta makonti.

## Imbogamizi zizwi

- Discord ishobora guhindura uburyo bwo kumenya imikino igihe icyo ari cyo cyose. Niba decoy itangiye kutagaragara, turagusaba gufungura ikibazo (issue).
- Imwe mu mirimo isaba ibirenze porogaramu iri gukora gusa (urugero kuba uri muri serivisi runaka y'umukino). Decoy yigana porogaramu gusa.
- Imikino itagira amadosiye ya exe ku rutonde rwa Discord ntiyashobora kumenyekana.
- Porogaramu zishinzwe umutekano rimwe na rimwe zishobora gukeka amadosiye mato ya exe adafite ibimenyetso by'umukono w'umutekano akorera mu rwibutso rwa mudasobwa. Decoy ifite kodi ifunguye kandi ikorwa ivuye muri `src-tauri/stub/stub.rs`; ushobora kuyiyubakira wowe ubwawe.

## Gutanga umusanzu

Raporo z'amakosa, ibitekerezo n'ubusobanuro birakirwa neza. Turagusaba kubanza gusoma [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Icyitonderwa

Decoy itangwa "nk'uko iri" ku mpamvu z'ubumenyi bwite, uburezi no kugerageza. Kwigana umukino uri gukora bishobora kunyuranya n'Amategeko y'Imikoreshereze ya Discord cyangwa y'uwatanze umukino, kandi bishobora gutuma hafatwa ingamba kuri konti yawe. Ni wowe wenyine ufite inshingano z'uburyo uyikoresha. "Discord" n'amazina yose y'imikino n'ibirango ni iby'ababyandikishije kandi byakoreshejwe hano gusa mu kumenyekanisha porogaramu bivugaho.
