# Decoy

**Piscitt process de sostituzion che fann cred a Discord che un gioeugh el sia dree a girà.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Libreria de Decoy cont i gioeugh recent e i figure" />

</div>

Decoy el tegn in esecuzion un process innozent cont una finestra sota el nom de l'eseguibil d'un gioeugh, inscì che el sistema de rilevament di gioeugh de Discord el te mostra 'me dree a sgiugà a quell gioeugh lì. Gh'è mai de besogn de installà o fà partì el gioeugh ver, donca negot de pesant el resta in sul to disch.

El cognoss **tucc i gioeugh che Discord el poeu rilevà** (circa 25.000 vos) per via che el lensg la lista publica de rilevament de Discord e la tegn agiornada deperlù.

> [!WARNING]
> Fà finta de fà girà un gioeugh el poeu andà contra i Condizion de Servizzi de Discord e te doperet Decoy **a to ris'c**.
> 'Sto proget l'è minga afiliad, aprovad o ligad a Discord Inc. Varda la [Declinazion de responsabilitaa](#declinazion-de-responsabilitaa).

## Carateristeghe

- **Tutcòss che Discord el poeu rilevà.** La lista di gioeugh l'è scaregada del pont de rilevament publich de Discord, salvada in local e agiornada ogni dì. I gioeugh noeuv e i eseguibij giontaa de recent vegnen foeura deperlór.
- **Ricerca svelta e precisa.** Ricerca istantanea per nom del gioeugh o de l'eseguibil intra miara de gioeugh, visualizazion a grilia o a lista compata, preferii e una riga cont i «Recent».
- **Cont un sol clicch.** Scerniss un gioeugh, scerniss l'eseguibil (se ghe n'è pussee de vun), catta foeura per quant tegnìll e schiscia start. Un anell con cont a la reversa e una notifica te disen quand che el temp l'è finii.
- **El lassa indree negot.** Un decoy l'esist domà intanta che el gira: el piscitt exe l'è creaa a la partenza e scancellaa a la fermada. Tutcòss el se ferma quand che te veet foeura, e i vanzadure d'un crash vegnen nettaa a la partenza che vegn.
- **Discret.** El viv in del tray de sistema, senza finestre o botton in de la barra di aplicazion per i decoy medesim.
- **Traduzion averte.** L'interfacia l'è gestida con sempliz file JSON, donca giontà una lengua l'è domà un singol file. Ingles e Russ hinn denter.
- **Privad.** Nissun account, nissun token de Discord, nissuna telemetria. Varda [Privacy](#privacy).

## Come che 'l fonziona

1. Discord el decid che te seet dree a sgiugà a un gioeugh cont el vardà i process vert in sul to PC e cont el confrontà i nom di eseguibij con una lista publica (`/api/v9/applications/detectable`).
2. Decoy el scarega 'sta lista e, per el gioeugh che te scernisset, el copia un piscitt programa sostitutiv (circa 120 KB, scrivud in Rust e incorporad in Decoy) in d'una cartella temporanea cont el nom de l'eseguibil de la lista, per esempi `.../cod26-cod.exe`.
3. El sostitut el fa negot foeura che 'vèghe una finestra de primm nivell, mituda lontan de 'l schermo inscì che te la vedet mai. Discord el recognoss domà un process che 'l gh'ha una finestra, e l'è per quest che un process senza finestre el ven ignorad.
4. Intra circa 15 segond Discord el mostra el gioeugh 'me ativitaa corenta.
5. Quand che el timer el finiss o te schisciet ferma, Decoy el ferma el process e 'l scancella el file. Un oget de lavorà de Windows (job object) el garantiss che i decoy moeuren insema a Decoy, anca se 'l va in crash.

## Installazion

Catta foeura vun de la pagina di [Releases](../../../../releases):

| Scarega | Per |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Programa de installazion.** Per utent singol, gh'è minga besogn di diricc de ministrador, el gionta una vos al menu Start e un programa de disinstallazion. |
| `Decoy_x.y.z_x64-portable.zip` | **Portatil.** Descomprimel indova che te voeuret e faa partì `decoy.exe`. Tucc i dacc resten in de la cartella `data` arent a lù, negot ven scrivud in del to profil utent. Scancella la cartella per tràll via. |

Verifega un download con `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen el poeu mandà foeura un avis in su un autor minga cognossuu per via che i compilazion hinn senza firma digital; cerniss *Pussee informazion → Esegui comunque* se te gh'heet fiducia in de la build.

Requisii: Windows 10 o 11 (64-bit) con el runtime WebView2 (giamò dent in Windows 11 e in di agiornament recent de Windows 10).

## Utilizazion

1. Derva la **Libreria** e cerca un gioeugh, o schiscia `Ctrl` + `K` de ogni sit.
2. Fà clicch in su un gioeugh. In del pannell a drizza scerniss el process e quanc menut tegnìll (i ativitaa de Discord de solet ciamen 15).
3. Schiscia **Fà partì el decoy**. Discord el mostrarà el gioeugh despess dopu quai segond.
4. Tienel d'oeugg sota **In esecuzion**, fermann vun o tucc in ogni moment, o lassa domà Decoy in del tray.

I gioeugh che la soa vos in Discord la gh'ha an'mò nissun eseguibil vegnen scondud de default (pœuden minga vess rilevaad). Ativa *Fa vedé i gioeugh senza exe* per vedéj; la lista la ven refrescada ogni dì, donca vegnen disponibil apena che Discord el gionta un process.

### Riga de comand

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

El fa partì un decoy subet, per esempi `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilazion de la sorgent

Requisii: [Node.js](https://nodejs.org) 20+, la toolchain stabil de [Rust](https://rustup.rs) (target MSVC) cont i Visual Studio C++ build tools, e el runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Controll util:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Not: l'exe del decoy l'è compilaa de `src-tauri/build.rs` con sempliz `rustc` a partì de `src-tauri/stub/stub.rs` e poeu integraa in de l'aplicazion. Quand che el frontend el gira in d'un normal browser (`npm run dev`) el ven doperaa un piscitt backend fint (`src/mock.ts`), comud per lavorà in su l'interfacia.

## Traduzion

I stringhe de l'interfacia se troeuven in [`src/locales`](../../src/locales), un file JSON per ogne lengua (`en.json`, `ru.json`, ...). Giontà una lengua voeul dì giontà un file; nissuna modifega al codesg. Varda [docs/TRANSLATING.md](../TRANSLATING.md) per el format del file, un prompt pront per la traduzion automatega e 'l script de convalida. I traduzion de 'sto README vann in `docs/i18n/README.<code>.md`.

## Strutura del proget

```
src/                    Frontend React + TypeScript
  components/           Libreria, pannell de detai, impostazion, ...
  locales/              file de traduzion (un JSON per lengua)
  i18n-core.ts          caregament e ricerca de la lengua
  store.ts              stat de l'aplicazion (zustand)
src-tauri/              Backend Rust (Tauri 2)
  src/lib.rs            bas de dacc di gioeugh, process decoy, tray
  stub/stub.rs          el programa sostitutiv che ven integraa
scripts/                script de jut (convalida di locale)
docs/                   guida a la traduzion, schirmoeude
```

## Privacy

- Decoy el dopera la red domà per scaregà la lista publica de rilevament de Discord (a la prima partenza, poeu al massim una voeulta al dì o quand che te schisciet agiorna) e, per la visualizazion, i icone e i figure di gioeugh del CDN publich de Discord.
- El lensg minga, el salva minga e 'l manda minga el to token de Discord o i dacc de l'account, e 'l parla minga cont el client de Discord.
- I impostazion (preferii, lengua, durade) vegnen salvad in local in del spazzi WebView de l'aplicazion; la cache de la lista di gioeugh e i file temporani di decoy viven in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nissuna analisi, nissuna relazion in sui crash, nissun account.

## Limitazion cognossude

- Discord el poeu mudà el moeud che 'l dopera per rilevà in ogni moment. Se un decoy el desmet de vess recognossuu, per piasé derva una issue.
- Certe ativitaa hann de besogn de pussee d'un process dree a girà (per esempi vess denter a una specifica esperienza d'una piataforma de gioeugh). Decoy el fa domà l'imitazion del process.
- I vos senza eseguibij in de la lista de Discord pœuden minga vess rilevaad.
- I antivirus e i software de sigurezza di voeulte segnalen piscitt eseguibij senza firma che resten inativ in memoria. El decoy l'è a codesg avert e compilaa de `src-tauri/stub/stub.rs`; te poeudet compilàll deperlì.
