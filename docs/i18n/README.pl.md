# Decoy

**Niewielkie procesy zastępcze sprawiające, że Discord uznaje grę za uruchomioną.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteka Decoy z ostatnimi grami i grafikami" />

</div>

Decoy utrzymuje nieszkodliwy proces zastępczy posiadający okno pod nazwą pliku wykonywalnego gry, dzięki czemu system wykrywania gier w Discordzie informuje, że w nią grasz. Nigdy nie musisz instalować ani uruchamiać prawdziwej gry, więc nic ciężkiego nie zalega na Twoim dysku.

Zna **każdą grę, którą Discord potrafi wykryć** (około 25 000 pozycji), ponieważ pobiera publiczną listę wykrywania samego Discorda i automatycznie dba o jej aktualność.

> [!WARNING]
> Symulowanie uruchomionej gry może naruszać Warunki korzystania z usługi Discord i używasz Decoy **na własne ryzyko**.
> Ten projekt nie jest powiązany z firmą Discord Inc., przez nią wspierany ani w żaden sposób z nią zrzeszony. Zobacz [Zrzeczenie się odpowiedzialności](#zrzeczenie-się-odpowiedzialności).

## Funkcje

- **Wszystko, co Discord potrafi wykryć.** Lista gier jest pobierana z publicznego punktu końcowego wykrywania Discorda, zapisywana lokalnie w pamięci podręcznej i odświeżana codziennie. Nowe gry oraz nowo dodane pliki wykonywalne pojawiają się automatycznie.
- **Wyszukiwarka, która dotrzymuje tempa.** Błyskawiczne wyszukiwanie po nazwie gry lub pliku wykonywalnym wśród tysięcy gier, widok siatki lub zwartej listy, ulubione oraz wiersz „Ostatnie”.
- **Jedno kliknięcie.** Wybierz grę, wybierz plik wykonywalny (jeśli jest ich kilka), określ czas działania i kliknij uruchom. Pierścień odliczania oraz powiadomienie poinformują Cię, gdy czas dobiegnie końca.
- **Nie pozostawia po sobie śladów.** Atrapa istnieje tylko wtedy, gdy działa: miniaturowy plik exe jest tworzony przy uruchomieniu i usuwany przy zatrzymaniu. Wszystko zostaje zatrzymane po zamknięciu aplikacji, a pozostałości po ewentualnej awarii są usuwane przy następnym uruchomieniu.
- **Dyskretny.** Działa w zasobniku systemowym, brak okien i przycisków na pasku zadań dla samych atrap.
- **Otwarte tłumaczenia.** Interfejs opiera się na prostych plikach JSON, więc dodanie nowego języka to kwestia jednego pliku. Język angielski i rosyjski są dołączone.
- **Prywatność.** Bez konta, bez tokena Discorda, bez telemetrii. Zobacz [Prywatność](#prywatność).

## Jak to działa

1. Discord stwierdza, że grasz w grę, sprawdzając procesy uruchomione na Twoim komputerze i porównując nazwy ich plików wykonywalnych z publiczną listą (`/api/v9/applications/detectable`).
2. Decoy pobiera tę listę i dla wybranej przez Ciebie gry kopiuje miniaturowy program zastępczy (około 120 KB, napisany w Rust i wbudowany w Decoy) do folderu tymczasowego, nadając mu nazwę pliku wykonywalnego z listy, na przykład `.../cod26-cod.exe`.
3. Program zastępczy nie robi nic poza posiadaniem jednego okna najwyższego poziomu, zaparkowanego daleko poza ekranem, tak aby nigdy nie było go widać. Discord rozpoznaje wyłącznie procesy posiadające okno — dlatego proces całkowicie bezokienny jest ignorowany.
4. W ciągu około 15 sekund Discord zaczyna pokazywać grę jako Twoją bieżącą aktywność.
5. Gdy czas minie lub klikniesz zatrzymaj, Decoy zamyka proces i usuwa plik. Obiekt zadania Windows (job object) zapewnia, że atrapy zakończą działanie razem z Decoy, nawet w razie awarii aplikacji.

## Instalacja

Wybierz jedną z opcji na stronie [Releases](../../../../releases):

| Plik do pobrania | Zastosowanie |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalator.** Dla pojedynczego użytkownika, nie wymaga uprawnień administratora, dodaje pozycję w menu Start oraz dezinstalator. |
| `Decoy_x.y.z_x64-portable.zip` | **Wersja przenośna (portable).** Rozpakuj w dowolnym miejscu i uruchom `decoy.exe`. Wszystkie dane pozostają w folderze `data` obok programu, nic nie jest zapisywane w profilu użytkownika. Aby usunąć program, po prostu skasuj folder. |

Zweryfikuj pobrany plik za pomocą `SHA256SUMS.txt` (`Get-FileHash <file>` w PowerShellu).

Windows SmartScreen może wyświetlić ostrzeżenie o nierozpoznanym wydawcy, ponieważ kompilacje nie są podpisane cyfrowo; wybierz *Więcej informacji → Uruchom mimo to*, jeśli ufasz tej kompilacji.

Wymagania: Windows 10 lub 11 (64-bitowy) ze środowiskiem uruchomieniowym WebView2 (znajduje się już w systemie Windows 11 oraz w nowszych aktualizacjach Windows 10).

## Sposób użycia

1. Otwórz **Bibliotekę** i wyszukaj grę lub naciśnij `Ctrl` + `K` w dowolnym miejscu.
2. Kliknij grę. W panelu po prawej stronie wybierz proces i liczbę minut, przez jaki ma być utrzymywany (zadania w Discordzie zwykle wymagają 15).
3. Kliknij **Uruchom atrapę**. Discord wyświetli grę po kilku sekundach.
4. Obserwuj ją w zakładce **Uruchomione**, zatrzymaj pojedynczą lub wszystkie atrapy w dowolnym momencie albo po prostu pozostaw Decoy w zasobniku systemowym.

Gry, których wpis w bazie Discorda nie zawiera jeszcze plików wykonywalnych, są domyślnie ukryte (nie można ich wykryć). Włącz opcję *Pokaż gry bez exe*, aby je zobaczyć; lista jest odświeżana codziennie, więc staną się dostępne, gdy tylko Discord doda odpowiedni proces.

### Wiersz poleceń

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Uruchamia atrapę od razu, na przykład `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kompilacja ze źródeł

Wymagania wstępne: [Node.js](https://nodejs.org) 20+, stabilny zestaw narzędzi [Rust](https://rustup.rs) (cel MSVC) z narzędziami kompilacji C++ programu Visual Studio oraz środowisko uruchomieniowe WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Przydatne polecenia sprawdzające:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Uwagi: plik exe atrapy jest kompilowany przez `src-tauri/build.rs` za pomocą zwykłego `rustc` z pliku `src-tauri/stub/stub.rs`, a następnie osadzany w aplikacji. Gdy frontend działa w zwykłej przeglądarce (`npm run dev`), używany jest mały backend zastępczy (`src/mock.ts`), co ułatwia pracę nad interfejsem użytkownika.

## Tłumaczenia

Teksty interfejsu znajdują się w [`src/locales`](../../src/locales), po jednym pliku JSON na język (`en.json`, `ru.json`, ...). Dodanie języka oznacza dodanie pliku; bez zmian w kodzie. Zobacz [docs/TRANSLATING.md](../TRANSLATING.md), aby poznać format pliku, gotowy prompt do tłumaczenia maszynowego oraz skrypt walidacyjny. Tłumaczenia tego pliku README trafiają do `docs/i18n/README.<code>.md`.

## Struktura projektu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Prywatność

- Decoy korzysta z sieci wyłącznie w celu pobrania publicznej listy wykrywania Discorda (przy pierwszym uruchomieniu, a potem maksymalnie raz dziennie lub po kliknięciu przycisku odświeżania) oraz do wyświetlania ikon i grafik gier z publicznego CDN Discorda.
- Nie odczytuje, nie zapisuje ani nie wysyła Twojego tokena Discorda ani żadnych danych konta i nie komunikuje się z klientem Discord.
- Ustawienia (ulubione, język, czasy trwania) są zapisywane lokalnie w magazynie WebView aplikacji; pamięć podręczna listy gier oraz tymczasowe pliki atrap znajdują się w `%LOCALAPPDATA%\app.decoy.desktop`.
- Brak telemetrii, brak raportowania awarii, brak konieczności posiadania konta.

## Znane ograniczenia

- Discord może w dowolnym momencie zmienić sposób działania wykrywania. Jeśli atrapa przestanie być rozpoznawana, prosimy o zgłoszenie problemu (issue).
- Niektóre aktywności wymagają czegoś więcej niż tylko uruchomionego procesu (na przykład przebywania w konkretnym świecie lub trybie danej platformy gier). Decoy imituje wyłącznie proces.
- Pozycje bez plików wykonywalnych na liście Discorda nie mogą zostać wykryte.
- Oprogramowanie zabezpieczające sporadycznie oznacza małe, niepodpisane pliki wykonywalne, które bezczynnie spoczywają w pamięci. Atrapa jest otwartoźródłowa i kompilowana z `src-tauri/stub/stub.rs`; możesz ją skompilować samodzielnie.

## Udział w projekcie

Zgłoszenia błędów, pomysły i tłumaczenia są mile widziane. Prosimy o wcześniejsze zapoznanie się z plikiem [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Zrzeczenie się odpowiedzialności

Decoy jest udostępniany „tak jak jest” do celów osobistych, edukacyjnych i testowych. Symulowanie uruchomionej gry może naruszać Warunki korzystania z usługi Discord lub wydawcy danej gry i może skutkować podjęciem działań wobec Twojego konta. Wyłącznie Ty ponosisz odpowiedzialność za to, w jaki sposób korzystasz z programu. „Discord” oraz wszelkie nazwy gier i znaki graficzne są znakami towarowymi ich prawowitych właścicieli i zostały użyte tutaj wyłącznie w celu identyfikacji oprogramowania, do którego się odnoszą.
