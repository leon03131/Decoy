# Decoy

**Små stedfortræderprocesser, der får Discord til at tro, at et spil kører.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Bygget med](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Licens](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-bibliotek med seneste spil og illustrationer" />

</div>

Decoy holder en harmløs pladsholderproces med et vindue kørende under et spils eksekverbare filnavn, så Discords spildetektering rapporterer, at du spiller det spil. Du behøver aldrig at installere eller starte det rigtige spil, så intet fylder på din disk.

Den kender til **alle spil, Discord kan registrere** (omkring 25.000 poster), fordi den læser Discords egen offentlige registreringsliste og selv holder den opdateret.

> [!WARNING]
> Simulering af et kørende spil kan være i strid med Discords servicevilkår, og du bruger Decoy **på eget ansvar**.
> Dette projekt er hverken tilknyttet, godkendt af eller forbundet med Discord Inc. Se [Ansvarsfraskrivelse](#ansvarsfraskrivelse).

## Funktioner

- **Alt hvad Discord kan registrere.** Spillisten downloades fra Discords offentlige endpoint til detektering, gemmes lokalt og fornys dagligt. Nye spil og nyligt tilføjede eksekverbare filer dukker op af sig selv.
- **Søgning, der følger med.** Øjeblikkelig søgning efter spilnavn eller eksekverbar fil på tværs af tusindvis af spil, gittervisning eller kompakt listevisning, favoritter og en »Seneste«-række.
- **Ét klik.** Vælg et spil, vælg den eksekverbare fil (hvis der er flere), vælg hvor længe den skal køre, og tryk på start. En nedtællingsring og en underretning giver besked, når tiden er gået.
- **Efterlader intet.** En decoy eksisterer kun, mens den kører: den lille exe-fil oprettes ved start og slettes ved stop. Alt stoppes, når du afslutter, og eventuelle efterladenskaber fra et nedbrud ryddes op ved næste start.
- **Lydløs.** Ligger i proceslinjens meddelelsesområde (systembakken), uden vinduer eller proceslinjeknapper til selve decoys.
- **Åbne oversættelser.** Brugergrænsefladen drives af almindelige JSON-filer, så tilføjelse af et sprog kræver kun en enkelt fil. Engelsk og russisk er inkluderet.
- **Privat.** Ingen konto, ingen Discord-token, ingen telemetri. Se [Privatliv](#privatliv).

## Sådan fungerer det

1. Discord registrerer, at du spiller et spil, ved at kigge på de processer, der kører på din pc, og sammenligne deres eksekverbare filnavne med en offentlig liste (`/api/v9/applications/detectable`).
2. Decoy downloader denne liste og kopierer for det valgte spil et lille stedfortræderprogram (ca. 120 KB, skrevet i Rust og indlejret i Decoy) til en midlertidig mappe under det eksekverbare filnavn fra listen, for eksempel `.../cod26-cod.exe`.
3. Stedfortræderprogrammet gør intet andet end at eje et enkelt vindue på øverste niveau, placeret langt uden for skærmen, så du aldrig ser det. Discord genkender kun processer, der ejer et vindue, hvorfor en proces helt uden vindue ignoreres.
4. Inden for omtrent 15 sekunder viser Discord spillet som din aktuelle aktivitet.
5. Når timeren udløber, eller du trykker på stop, afslutter Decoy processen og sletter filen. Et Windows-jobobjekt sikrer, at decoys lukkes sammen med Decoy, selv hvis programmet bryder ned.

## Installation

Vælg en fra siden [Releases](../../../../releases):

| Download | Til |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installationsprogram.** Pr. bruger, kræver ikke administratorrettigheder, tilføjer en genvej i Start-menuen og et afinstallationsprogram. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Udpak hvor som helst og kør `decoy.exe`. Alle data gemmes i mappen `data` ved siden af programmet, intet skrives til din brugerprofil. Slet mappen for at fjerne det. |

Bekræft en download med `SHA256SUMS.txt` (`Get-FileHash <fil>` i PowerShell).

Windows SmartScreen advarer muligvis om en ukendt udgiver, fordi versionerne ikke er kodesignerede; vælg *Flere oplysninger → Kør alligevel*, hvis du stoler på programmet.

Krav: Windows 10 eller 11 (64-bit) med WebView2-runtime (allerede inkluderet i Windows 11 og nyere Windows 10-opdateringer).

## Brug

1. Åbn **Bibliotek** og søg efter et spil, eller tryk på `Ctrl` + `K` hvor som helst.
2. Klik på et spil. Vælg processen i panelet til højre og hvor mange minutter, den skal holdes i gang (Discord-aktiviteter beder normalt om 15).
3. Tryk på **Start decoy**. Discord viser spillet efter få sekunder.
4. Følg den under **Kører**, stop en eller alle når som helst, eller lad blot Decoy blive i systembakken.

Spil, hvis Discord-post endnu ikke har nogen eksekverbare filer, er skjult som standard (de kan ikke registreres). Slå *Vis spil uden exe* til for at se dem; listen fornys dagligt, så de bliver tilgængelige, så snart Discord tilføjer en proces.

### Kommandolinje

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Starter en decoy med det samme, for eksempel `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Byg fra kildekode

Forudsætninger: [Node.js](https://nodejs.org) 20+, det stabile [Rust](https://rustup.rs)-toolchain (MSVC-target) med Visual Studio C++-byggeprogrammer samt WebView2-runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Nyttige kontroller:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Bemærkninger: decoy-exe'en kompileres af `src-tauri/build.rs` med almindelig `rustc` fra `src-tauri/stub/stub.rs` og indlejres derefter i appen. Når frontend'en kører i en almindelig browser (`npm run dev`), anvendes en lille mock-backend (`src/mock.ts`), hvilket er praktisk under udvikling af brugerfladen.

## Oversættelser

Teksterne til brugergrænsefladen findes i [`src/locales`](../../src/locales), én JSON-fil pr. sprog (`en.json`, `ru.json`, ...). Tilføjelse af et sprog betyder blot at tilføje en fil; ingen kodeændringer er nødvendige. Se [docs/TRANSLATING.md](../TRANSLATING.md) for filformatet, en brugsklar prompt til maskinoversættelse og valideringsscriptet. Oversættelser af denne README placeres i `docs/i18n/README.<code>.md`.

## Projektstruktur

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privatliv

- Decoy bruger kun netværket til at downloade Discords offentlige registreringsliste (ved første start, og derefter højst én gang om dagen, eller når du trykker på opdater) samt til visning af spilikoner og illustrationer fra Discords offentlige CDN.
- Programmet læser, gemmer eller sender ikke din Discord-token eller nogen form for kontodata, og det kommunikerer ikke med Discord-klienten.
- Indstillinger (favoritter, sprog, varigheder) gemmes lokalt i appens WebView-lager; cachen for spillisten og midlertidige decoy-filer placeres i `%LOCALAPPDATA%\app.decoy.desktop`.
- Ingen analyseværktøjer, ingen fejlrapportering, ingen konti.

## Kendte begrænsninger

- Discord kan til enhver tid ændre, hvordan registreringen fungerer. Hvis en decoy holder op med at blive genkendt, bedes du oprette et issue.
- Visse aktiviteter kræver mere end blot en kørende proces (for eksempel at være inde i en bestemt oplevelse på en spilplatform). Decoy efterligner kun processen.
- Poster uden eksekverbare filer i Discords liste kan ikke registreres.
- Sikkerhedssoftware advarer undertiden om små usignerede eksekverbare filer, der ligger inaktive i hukommelsen. Decoy er open source og bygget ud fra `src-tauri/stub/stub.rs`; du kan selv kompilere den.

## Ansvarsfraskrivelse

Decoy leveres »som det er« til personlige, uddannelsesmæssige og testmæssige formål. Efterligning af et kørende spil kan overtræde servicevilkårene for Discord eller spillets udgiver og kan føre til sanktioner mod din konto. Du er alene ansvarlig for, hvordan du bruger det. »Discord« samt alle spilnavne og logoer er varemærker tilhørende deres respektive ejere og bruges her udelukkende til at identificere den software, de refererer til.
