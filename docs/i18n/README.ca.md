# Decoy

**Processos substituts minúsculs que fan creure a Discord que s'està executant un joc.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca de Decoy amb jocs recents i il·lustracions" />

</div>

Decoy manté en execució un procés substitut inofensiu amb finestra sota el nom de l'executable d'un joc, de manera que la detecció de jocs de Discord indica que estàs jugant a aquest joc. Mai cal instal·lar ni iniciar el joc real, de manera que res pesant ocupa espai al teu disc.

Reconeix **tots els jocs que Discord pot detectar** (unes 25.000 entrades) perquè llegeix la llista pública de detecció del mateix Discord i la manté actualitzada automàticament.

> [!WARNING]
> Simular un joc en execució pot infringir els Termes del Servei de Discord i utilitzes Decoy **sota la teva pròpia responsabilitat**.
> Aquest projecte no està afiliat, patrocinat ni vinculat a Discord Inc. Consulta l'[Exempció de responsabilitat](#exempció-de-responsabilitat).

## Característiques

- **Tot el que Discord pot detectar.** La llista de jocs es descarrega des de l'extrem públic de detecció de Discord, s'emmagatzema a la memòria cau localment i s'actualitza diàriament. Els jocs nous i els executables afegits recentment apareixen per si mateixos.
- **Cerca que manté el ritme.** Cerca instantània per nom de joc o executable entre milers de jocs, visualització en quadrícula o llista compacta, preferits i una fila de «Recents».
- **Un sol clic.** Tria un joc, tria l'executable (si n'hi ha diversos), tria quants minuts mantenir-lo i prem iniciar. Un anell de compte enrere i una notificació t'avisen quan s'ha esgotat el temps.
- **No deixa rastre.** Un decoy només existeix mentre s'executa: el petit exe es crea en iniciar i s'elimina en aturar. Tot s'atura quan surts, i les restes després d'un tancament inesperat es netegen en el proper llançament.
- **Discret.** Viu a la safata del sistema, sense finestres ni botons a la barra de tasques per als mateixos decoys.
- **Traduccions obertes.** La interfície funciona amb fitxers JSON senzills, de manera que afegir un idioma requereix un únic fitxer. S'inclouen anglès i rus.
- **Privat.** Sense compte, sense token de Discord, sense telemetria. Consulta [Privadesa](#privadesa).

## Com funciona

1. Discord determina que estàs jugant a un joc examinant els processos en execució al teu PC i comparant els seus noms d'executable amb una llista pública (`/api/v9/applications/detectable`).
2. Decoy descarrega aquesta llista i, per al joc que triïs, copia un programa substitut minúscul (d'uns 120 KB, escrit en Rust i incrustat a Decoy) a una carpeta temporal utilitzant el nom de l'executable de la llista, per exemple `.../cod26-cod.exe`.
3. El substitut no fa res més que posseir una finestra de nivell superior, situada lluny fora de la pantalla perquè no la vegis mai. Discord només reconeix un procés que tingui una finestra, motiu pel qual un procés completament sense finestra s'ignora.
4. En aproximadament 15 segons, Discord mostra el joc com la teva activitat actual.
5. Quan acaba el temporitzador o prems aturar, Decoy finalitza el procés i elimina el fitxer. Un objecte de treball de Windows (job object) assegura que els decoys es tanquin juntament amb Decoy, fins i tot si es tanca inesperadament.

## Instal·lació

Tria'n un de la pàgina de [Releases](../../../../releases):

| Descàrrega | Per a |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instal·lador.** Per usuari, sense necessitat de permisos d'administrador, afegeix una entrada al menú Inici i un desinstal·lador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Descomprimeix a qualsevol lloc i executa `decoy.exe`. Totes les dades es queden a la carpeta `data` del costat, no s'escriu res al teu perfil d'usuari. Elimina la carpeta per esborrar-lo. |

Verifica una descàrrega amb `SHA256SUMS.txt` (`Get-FileHash <file>` a PowerShell).

Windows SmartScreen pot advertir sobre un editor no reconegut perquè les compilacions no estan signades amb codi; tria *Més informació → Executa de totes maneres* si confies en la compilació.

Requisits: Windows 10 o 11 (64 bits) amb el temps d'execució WebView2 (ja inclòs a Windows 11 i en actualitzacions recents de Windows 10).

## Ús

1. Obre la **Biblioteca** i cerca un joc, o prem `Ctrl` + `K` des de qualsevol lloc.
2. Fes clic en un joc. Al tauler de la dreta, tria el procés i quants minuts mantenir-lo (les activitats de Discord solen demanar-ne 15).
3. Prem **Inicia el decoy**. Discord mostrarà el joc al cap d'uns segons.
4. Observa'l a **En execució**, atura'n un o tots en qualsevol moment, o simplement deixa Decoy a la safata del sistema.

Els jocs la fitxa dels quals a Discord encara no tingui executables estan amagats per defecte (no es poden detectar). Activa *Mostra jocs sense exe* per veure'ls; la llista s'actualitza diàriament, de manera que estaran disponibles tan bon punt Discord afegeixi un procés.

### Línia d'ordres

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Inicia un decoy immediatament, per exemple `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilació des del codi font

Requisits previs: [Node.js](https://nodejs.org) 20+, la cadena d'eines estable de [Rust](https://rustup.rs) (objectiu MSVC) amb les eines de compilació de Visual Studio C++, i el temps d'execució WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Comprovacions útils:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notes: l'exe del decoy és compilat per `src-tauri/build.rs` amb `rustc` directe a partir de `src-tauri/stub/stub.rs` i després s'incrusta a l'aplicació. Quan el frontend s'executa en un navegador convencional (`npm run dev`), s'utilitza un petit backend simulat (`src/mock.ts`), la qual cosa resulta pràctica per treballar en la interfície d'usuari.

## Traduccions

Les cadenes de la interfície d'usuari resideixen a [`src/locales`](../../src/locales), un fitxer JSON per idioma (`en.json`, `ru.json`, ...). Afegir un idioma significa afegir un fitxer; sense canvis de codi. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) per conèixer el format del fitxer, una plantilla d'indicacions a punt per a la traducció automàtica i l'script de validació. Les traduccions d'aquest README van a `docs/i18n/README.<code>.md`.

## Estructura del projecte

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privadesa

- Decoy només utilitza la xarxa per descarregar la llista pública de detecció de Discord (al primer inici, i després com a màxim un cop al dia o quan prems actualitzar) i, per a la visualització, les icones i il·lustracions dels jocs des de la CDN pública de Discord.
- No llegeix, no emmagatzema ni envia el teu token de Discord ni cap dada del compte, i no es comunica amb el client de Discord.
- La configuració (preferits, idioma, durades) s'emmagatzema localment a l'emmagatzematge WebView de l'aplicació; la memòria cau de la llista de jocs i els fitxers temporals de decoy resideixen a `%LOCALAPPDATA%\app.decoy.desktop`.
- Sense analítiques, sense informes d'errors i sense comptes.

## Limitacions conegudes

- Discord pot canviar el funcionament de la detecció en qualsevol moment. Si un decoy deixa de ser reconegut, si us plau obre una incidència.
- Algunes activitats necessiten més que un procés en execució (per exemple, ser dins d'una experiència concreta d'una plataforma de jocs). Decoy només imita el procés.
- Les entrades sense executables a la llista de Discord no es poden detectar.
- El programari de seguretat de vegades assenyala petits executables no signats que romanen inactius a la memòria. El decoy és de codi obert i està compilat a partir de `src-tauri/stub/stub.rs`; pots compilar-lo tu mateix.
