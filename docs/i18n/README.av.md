# Decoy

**Discord-алда хӀай хӀалтӀулеб бугин ккезабулел гьитӀинал процессал.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy тӀехьалда гьанжесел хӀаялгун ва суратазулгун" />

</div>

Decoy-алъ хӀаялъул exe цӀаралда гъоркь зарал гьечӀеб, гордо бугеб процесс хӀалтӀулаго ккола, гьединлъидал Discord-алъул
хӀаял лъазарулеб системаялъ нуж гьеб хӀай хӀалел ругин рихьизарула. ХӀакъикъияб хӀай лъезе яги бачине нужее къваригӀунаро,
гьединлъидал дискалда тӀад кӀудияб щибго хутӀуларо.

Гьелъие **Discord-алда лъазе кӀолеб щибаб хӀай** лъала (25 000 гӀанасеб хъвай-хъвагӀай), щай гурелъул гьелъ
Discord-алъул жамгӀияб сияхӀ цӀалула ва жибго гьеб цӀигьабун ккола.

> [!WARNING]
> ХӀалтӀулеб хӀай рихьизаби Discord-алъул Къануназда данде ккезе бегьула, Decoy хӀалтӀизаби буго **нужерго хӀинкъиялда**.
> Гьаб проект Discord Inc. компаниягун хурхараб, гьелъ тасдикъ гьабураб яги гьелъ гӀодоб ккураб гуро. Ралагье [Жавабчилъи нахъчӀвай](#жавабчилъи-нахъчӀвай).

## Хасиятал

- **Discord-алда лъазе кӀолеб кинабго.** ХӀаязул сияхӀ Discord-алъул жамгӀияб иццалдаса цӀалула, локалго
  кэш гьабула ва къо бахъанагӀан цӀигьабула. ЦӀиял хӀаял ва цӀиял exe файлал жидедаго рачӀуна.
- **Цадахъ кколеб балагьи.** ЦӀаралдалъун яги exe файлдалъун азарханал хӀаязда гьоркьоб хераб балагьи, хъалиязул яги битӀараб
  сияхӀалъул бихьизаби, хириял ва «Гьанжесел» мухъ.
- **Цо басиялда.** ХӀай тӀаса бище, exe бище (гӀемерал ратани), чан заманалъ кквелеб бихьизабе ва бачине тӀаде басе.
  Хан лорулеб чӀагаралъ ва лъазабиялъ заман лъугӀараблъи бицуна.
- **Нахъе щибго тун толаро.** Decoy хӀалтӀулеб мехалъ гурони букӀунаро: гьитӀинаб exe файл бачулаго гьабула ва
  чӀезабулаго тӀагӀинабула. Программаялдаса къватӀибе унго кинабго чӀезабула, цӀидалъун хӀалтӀи чӀедал хутӀарал нахъисеб нухалъ бачулаго бацӀцӀадула.
- **Гьаракь гьечӀеб.** Системаялъул треялда букӀуна, decoy-язе гордал яги кнопкаби рукӀунаро.
- **Рагьарал таржамаби.** Интерфейс къалибаб JSON файллаздалъун хӀалтӀула, гьединлъидал мацӀ жубаялъе цо файл гӀула.
  Инглис ва гӀурус мацӀал жанир руго.
- **Къайлахалъи.** Аккаунт къваригӀунаро, Discord токен гьечӀо, телеметрия гьечӀо. Ралагье [Къайлахалъи](#къайлахалъи).

## Гьеб муха хӀалтӀулеб

1. Discord-алъ нужехъ хӀай хӀалтӀулеб бугин рикӀкӀуна компутералда хӀалтӀулел процессазухъ балагьун ва гьезул exe
   цӀерал жиндирго жамгӀияб сияхӀгун (`/api/v9/applications/detectable`) данде ккун.
2. Decoy-алъ гьеб сияхӀ цӀалула ва нужеца бищараб хӀаялъе гьитӀинаб программа-заглушка (120 KB гӀанасеб, Rust мацӀалда
   хъвараб ва Decoy жаниб лъураб) заманаялъулаб папканибе копи гьабула, сияхӀалда бугеб exe цӀаралдалъун, масала
   `.../cod26-cod.exe`.
3. Заглушкаялъ щибго гьабуларо, экраналдаса рикӀкӀад бахчараб цо гордо кквей гурони. Discord-алъ гордо бугеб процесс
   гурони лъазабуларо, гьединлъидал гордо гьечӀеб процесс къабул гьабуларо.
4. ГӀага-шагар 15 секундалдаса Discord-алъ нуж хӀай хӀалел ругин рихьизарула.
5. Таймер лъугӀараб мехалъ яги нужеца чӀезабураб мехалъ, Decoy-алъ процесс лъугӀизабула ва файл тӀагӀинабула. Windows job
   object-алъ Decoy-гун цадахъ киналго decoy-ял чӀезарула, программа халат ккун чӀедалцин.

## Лъей

[Releases](../../../../releases) гьумералдаса цояб бище:

| ЦӀай | Щибизе |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ХӀотторг (Installer).** ХӀорасеб хӀалтӀизабулевчиясе, администраторасул ихтиярал къваригӀунаро, «Пуск» менюнибе журала, тӀагӀинарулеб программа буго. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив (Portable).** Муьлххараб бакӀалде рагье ва `decoy.exe` баче. Киналго баянал аскӀоб бугеб `data` папканир цӀунула, хӀалтӀизабулевчиясул профилалде щибго хъван толаро. ТӀагӀинабизе папка тӀагӀинаби гӀула. |

ЦӀараб файл `SHA256SUMS.txt` хӀисабалда хал гьабе (PowerShell чохь `Get-FileHash <file>`).

Windows SmartScreen-алъ билгьун гьечӀеб басмачиясул хӀасил лъазабизе бегьула, щай гурелъул дигиталаб гъулбас гьечӀо;
нужеца божилъи гьабулеб батани, *More info → Run anyway* бище.

КъваригӀарал шартӀал: Windows 10 яги 11 (64-бит) WebView2 runtimeгун (Windows 11 жаниб ва Windows 10 цӀиял цӀигьабиязда жаниб буго).

## ХӀалтӀизаби

1. **ТӀехьалда** рагье ва хӀай балагье, яги муьлххараб бакӀалда `Ctrl` + `K` тӀаде басе.
2. ХӀаялда тӀаде басе. КвегӀаб рахъалда бугеб панелалда процесс бище ва чан минуталъ кквелеб бихьизабе (Discord масъалабазе гӀемерисеб 15 къваригӀуна).
3. **Decoy бачине** тӀаде басе. Чанго секундалдаса Discord-алда хӀай бихьизе ккола.
4. **ХӀалтӀулел** гьумералда халккве, цояб яги киналго муьлххараб мехалъ чӀезаре, яги Decoy треялда те.

Discord сияхӀалда exe гьечӀел хӀаял Ӏадйитин куцалъ бахчун рукӀуна (гьел лъазе кӀоларо). Гьел рихьизе
*Exe гьечӀел хӀаял рихьизаризе* баче; сияхӀ къо бахъанагӀан цӀигьабула, гьединлъидал Discord-алъ процесс жубадалго гьел хӀалтӀизе бегьулеб лъугьуна.

### Буюрухъазул мухъ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Decoy хадубго бачула, масала `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Иццалдаса гьаби

КъваригӀарал: [Node.js](https://nodejs.org) 20+, хӀалтӀулеб [Rust](https://rustup.rs) алат (MSVC target) Visual Studio C++
build toolsгун, ва WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reloadгун хӀалбихьиялъул режим бачине
npm run tauri build    # src-tauri/target/release/bundle/nsis жаниб хӀотторг гьабизе
```

Пайдаял халгьабиял:

```bash
npm run check-locales  # ru.json хӀисабалда щибаб таржама файл халгьабизе
npx tsc --noEmit       # фронтендалъул тайпаби халгьабизе
cargo check --manifest-path src-tauri/Cargo.toml
```

Баянал: decoy exe файл `src-tauri/build.rs` чохь ялсаманияб `rustc`далъун `src-tauri/stub/stub.rs` файлалдаса данде гьабула ва
программаялде жаниб лъола. Фронтенд гӀадатаб браузералда хӀалтӀулаго (`npm run dev`) гьитӀинаб mock backend
(`src/mock.ts`) хӀалтӀизабула, гьеб UIгун хӀалтӀизе бигьаяб буго.

## Таржамаби

Интерфейсалъул мухъал руго [`src/locales`](../../src/locales) жанир, мацӀазе цо-цо JSON файл (`en.json`, `ru.json`, ...).
МацӀ жубазе цо файл жубай гӀула; код хисизе къваригӀунаро. Ралагье [docs/TRANSLATING.md](../TRANSLATING.md) файлан формат,
таржама гьабиялъе хӀадураб промпт ва халгьабиялъул скрипт бихьизе. Гьаб README-ялъул таржамаби рачуна
`docs/i18n/README.<code>.md` жанире.


## Къайлахалъи

- Decoy-алъ гӀицӀго Discord-алъул жамгӀияб сияхӀ цӀализе интернет хӀалтӀизабула (тӀоцебе бачулаго, хадуб къоялда цо нухалдаса цӀикӀкӀун гуро
  яги цӀигьабизе басараб мехалъ), ва хӀаязул иконкабигун суратал рихьизаризе Discord-алъул жамгӀияб CDN-алдаса.
- Гьелъ нужер Discord токен яги аккаунтазул баянал цӀалуларо, цӀунуларо ва ритӀуларо, ва Discord клиентгун кӀалъаларо.
- Рекъезаби (хириял, мацӀ, заманал) локалго WebView цӀунулеб бакӀалда цӀунула; хӀаязул сияхӀ ва decoy-ялъул заманаялъулал
  файлал `%LOCALAPPDATA%\app.decoy.desktop` жанир рукӀуна.
- Аналитика гьечӀо, гӀалаталъул хӀакъалъулъ баянал ритӀи гьечӀо, аккаунташ гьечӀо.

## Лъалел гӀурхъаби

- Discord-алъ муьлххараб заманалда хӀаял лъазари хисизе бегьула. Decoy лъазаби чӀаго хутӀани, issue рагье.
- Цо-цо хӀалтӀабазе хӀалтӀулеб процесс гурониги къваригӀуна (масала хӀаялъул платформаялда жаниб батӀияб бакӀ). Decoy-алъ процес хӀисаб гурони гьабуларо.
- Discord сияхӀалда exe гьечӀел хӀаял лъазаризе бегьуларо.
- ХӀинкъигьечӀолъиялъул программабаз цо-цо эсирда ракӀалде кколеб гъулбас гьечӀеб exe шек гьабула. Decoy рагьараб код бугеб
  буго ва `src-tauri/stub/stub.rs` файладаса гьабураб буго; нужедаго жидецаго гьеб данде гьабизе бегьула.

## Жавабчилъи нахъчӀвай

Decoy кьолеб буго «бугеб куцалъ» хасаб, цӀалул ва хӀалбихьиялъул мурадазе. ХӀалтӀулеб хӀай рихьизаби Discord-алъул яги хӀаялъул
издателасул ихтияразда данде ккезе бегьула, ва нужер аккаунтазе зарал гьабизе бегьула. Нужго жовабчилал руго гьеб хӀалтӀизабиялъе.
«Discord» ва киналго хӀаязул цӀералгун логотипал ккола жидерго бетӀергьабазул тӀарикъат ва гьанир хӀалтӀизарун руго хӀалтӀулеб программа
бихьизаби гурони батӀияб мурадалъе гуро.
