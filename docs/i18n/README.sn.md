# Decoy

**Tupurogiramu tudiki tunoita kuti Discord ifunge kuti pane mutambo urikutambwa.**

![Chikuva](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Yakavakwa ne](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Rezinesi](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Raibhurari yeDecoy ine mitambo ichangobva kushandiswa nemifananidzo" />

</div>

Decoy inoita kuti pave ne-process isina ngozi ine hwindo inomhanya pasi pezita re-executable yemutambo, kuitira kuti kuona kwemitambo kweDiscord kuratidze kuti urikutamba mutambo iwoyo. Haufanire kuisa kana kutanga mutambo chaiwo, saka hapana zvikuru zvinogara padhisiki rako.

Inoziva nezve **mutambo wese unogona kuonekwa neDiscord** (zvinosvika 25,000) nokuti inoverenga rondedzero yavose yeDiscord pachayo uye inozvigadziridza yega.

> [!WARNING]
> Kutevedzera mutambo uri kumhanya kunogona kutyora Mitemo yeKushandisa yeDiscord uye unoshandisa Decoy **panjodzi yako wega**.
> Purojekiti iyi haina kudyidzana, kutsigirwa kana kubatanidzwa neDiscord Inc. Ona [Kuzvidavirira](#kuzvidavirira).

## Zvakanakira

- **Zvese zvinogona kuonekwa neDiscord.** Rondedzero yemitambo inotorwa kubva pa-endpoint yavose yeDiscord, inochengetwa pakombiyuta uye inogadziridzwa zuva nezuva. Mitambo mitsva nema-executable achangobva kuwedzerwa anozviratidza ega.
- **Kutsvaga kunokurumidza.** Tsvaga mutambo ipapo ipapo nezita kana exe pakati pezviuru zvemitambo, kuratidzwa nenzira yezvidhina kana yerondedzero, zvinodiwa uye mutsara we“Zvichangobva kushandiswa”.
- **Kudzvanya kamwe chete.** Sarudza mutambo, sarudza exe (kana dziripo dzakawanda), sarudza nguva yekuichengeta wodzvanya tanga. Denderedzwa rekuverenga nguva yakanangana neshure nechiziviso zvinokuudza kana nguva yapera.
- **Hapana chainosiya shure.** Decoy inongovapo chete painenge ichimhanya: exe diki inogadzirwa pakutanga yodzimiwa pakumisa. Zvese zvinomiswa paunobuda, uye zvisaririra zvinobva pakudonha zvinotsvairwa pakubatidza kunotevera.
- **Yakanyarara.** Inogara mutray yesystem, hapana mahwindo kana mabhatani epabhawa rebasa (taskbar) ema-decoy acho pachawo.
- **Shanduro dzakavhurika.** Interface inoshandisa mafaira akajairika eJSON, saka kuwedzera mutauro kunongoda faira rimwe chete. Chirungu neChirussia zvirimo kare.
- **Chakavanzika.** Hapana akaunti, hapana tokeni yeDiscord, hapana telemetry. Ona [Zvirevo Zvekuvanzika](#zvirevo-zvekuvanzika).

## Mashandiro azvinoita

1. Discord inosarudza kuti urikutamba mutambo nekutarisa ma-process ari kumhanya pakombiyuta yako nekuenzanisa mazita awo e-executable nerondedzero yavose (`/api/v9/applications/detectable`).
2. Decoy inotora rondedzero iyoyo uye, pamutambo waunosarudza, inokopa purogiramu diki inomiririra (inenge 120 KB, yakanyorwa neRust uye yakadzamidzwa mukati meDecoy) kune folda yenguva diki ichishandisa zita re-executable kubva parondedzero, semuenzaniso `.../cod26-cod.exe`.
3. Purogiramu iyi inomiririra hapana chainoita kunze kwekuva nehwindo repamusoro-soro rimwe chete, rakamiswa kure ne-screen kuti usamboona. Discord inongoziva chete process ine hwindo, chikonzero nei process isina hwindo zvachose ichingofuratirwa.
4. Mukati memasekonzi anenge 15 Discord inoratidza mutambo sechiitiko chako chazvino.
5. Kana nguva yapera kana ukadzvanya kumisa, Decoy inopedza process yodzima faira. Job object yeWindows inoona kuti ma-decoy anofa pamwe chete neDecoy, kunyange ikadzika netsaona.

## Kuisa

Sarudza imwe kubva papeji ye-[Releases](../../../../releases):

| Kudhaunirodha | Ye |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Muisi (Installer).** Pemushandisi wega wega, hapana kodzero dzemukuru (admin) dzinodiwa, inowedzera entry muStart menu ne-uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Inotakurika (Portable).** Sunungura chero kupi womhanyisa `decoy.exe`. Data rese rinogara mufolda ye`data` iri pedyo nayo, hapana chinonyorwa kune profile yako yemushandisi. Dzima folda kuti uibvise. |

Simbisa zvadhaunirodhwa ne`SHA256SUMS.txt` (`Get-FileHash <file>` muPowerShell).

Windows SmartScreen inogona kuyambira pamusoro pemubudisi asingazivikanwe nokuti ma-build haana kusainwa; sarudza *More info → Run anyway* kana uchivimba ne-build racho.

Zvinodiwa: Windows 10 kana 11 (64-bit) ine WebView2 runtime (yakatoiswa kare muWindows 11 nezvigadziridzo zvitsva zveWindows 10).

## Mashandisirwo

1. Vhura **Raibhurari** wotsvaga mutambo, kana kudzvinya `Ctrl` + `K` kubva chero kupi.
2. Dzvanya mutambo. Muchikamu chiri kurudyi sarudza process nemaminitsi mangani ekuichengeta (zviitiko zveDiscord zvinowanzokumbira 15).
3. Dzvanya **Tanga decoy**. Discord inoratidza mutambo pashure pemasekonzi mashoma.
4. Tarisa pasi pe**Zvirikushanda**, misa imwe kana ese chero nguva, kana kungosiya Decoy iri mutray.

Mitambo isina ma-executable parondedzero yeDiscord parizvino yakavanzwa (haikwanise kuonekwa). Batidza *Ratidza mitambo isina exe* kuti uione; rondedzero inogadziridzwa zuva nezuva, saka inozowanikwa kana Discord yangowedzera process.

### Mutsetse weMirairo (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Inotanga decoy ipapo ipapo, semuenzaniso `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kuvaka kubva kune kodhi (source)

Zvinodiwa: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) toolchain yakatsiga (chinangwa cheMSVC) ine maturusi ekuvaka eVisual Studio C++, uye WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # mhanyisa mune modhi yekugadzira ine kurodha patsva kwepakarepo
npm run tauri build    # gadzira muisi mu src-tauri/target/release/bundle/nsis
```

Zvinobatsira kutarisa:

```bash
npm run check-locales  # tarisa faira rega rega reshanduro uchishandisa ru.json
npx tsc --noEmit       # tarisa mhando dzemakodhi e-frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Zvimwe zvinyorwa: decoy exe inounganidzwa ne`src-tauri/build.rs` ichishandisa `rustc` yakajairika kubva `src-tauri/stub/stub.rs` yozodzikwa mukati me-app. Kana frontend ichimhanya mubrowser yakajairika (`npm run dev`) backend diki yekutevedzera (`src/mock.ts`) inoshandiswa, iyo inobatsira pakushanda pa-UI.

## Shanduro

Mabhii e-UI anogara mu[`src/locales`](../../src/locales), faira rimwe reJSON pamutauro wega wega (`en.json`, `ru.json`, ...). Kuwedzera mutauro zvinoreva kuwedzera faira; hapana kushandura kodhi. Ona [docs/TRANSLATING.md](../TRANSLATING.md) kune chimiro chefaira, mibvunzo yakagadzirirwa kushandiswa pakushandura nemuchina uye script rekuongorora. Shanduro dzeREADME ino dzinoenda ku`docs/i18n/README.<code>.md`.

## Zvirevo Zvekuvanzika

- Decoy inoshandisa chete network kudhaunirodha rondedzero yavose yeDiscord (pakutanga kekutanga, uye kamwe chete pazuva kana ukadzvanya gadziridza) uye, pakuratidza, mifananidzo yemitambo kubva kuCDN yavose yeDiscord.
- Haimbofa yakaverenga, yakachengeta kana kutumira tokeni yako yeDiscord kana chero data reakaunti, uye haitaure ne-client yeDiscord.
- Zvirongwa (zvinodiwa, mutauro, nguva) zvinochengetwa pakombiyuta mu-WebView storage ye-app; cache yerondedzero yemitambo nemafaira enguva diki edecoy anogara mu`%LOCALAPPDATA%\app.decoy.desktop`.
- Hapana analytics, hapana mishumo yekudonha kwekombiyuta, hapana maakaunti.

## Zvinonetsa Zvinozivikanwa

- Discord inogona kuchinja mashandiro anoita kuona mutambo chero nguva. Kana decoy ikarega kuzivikanwa, ndapota vhura nyaya (issue).
- Zvimwe zviitiko zvinoda zvinopfuura kungomhanya kwe-process chete (semuenzaniso kuve mukati mechiitiko chakati chemutambo). Decoy inongotevedzera process chete.
- Ma-entry asina ma-executable parondedzero yeDiscord haakwanise kuonekwa.
- Masoftware ekudzivirira anombofungira ma-executable madiki asina kusainwa anongogara asina zvaari kuita mumemory. Decoy ndeye open source uye yakavakwa kubva `src-tauri/stub/stub.rs`; unogona kuivaka pachako.

## Kuzvidavirira

Decoy inopiwa "sezvairi" nokuda kwezvinangwa zvako wega, zvedzidzo nezvekuedza. Kutevedzera mutambo uri kumhanya kunogona kutyora Mitemo yeKushandisa yeDiscord kana yemubudisi wemutambo, uye zvinogona kuunza matanho kune akaunti yako. Iwe pachako ndiwe une basa nemashandisirwo aunoita purogiramu iyi. "Discord" nemazita ese emitambo nemifananidzo zviratidzo zvevaridzi vazvo uye zviri kushandiswa pano chete kuratidza software inorehwa.
