# Decoy

**Discord-на ловзар латаяь моттадейтта кегийра йола процессаш.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека кесталера ловзарашца а сурташца а" />

</div>

Decoy-с ловзара exe файлан цӏераца зен доаца, кор дола заглушка-процесс латаяь латтайо, цундела Discord-а
ловзараш белгалдахара ражо хьо из ловзар ловзаш гойтаргва. Хьона боккъонца дола ловзар оттаде е латаде эшаш дац,
цундела диска тӏа совнах хӏама а дагӏац.

Цунна **Discord-на белгалдаккха ховра дола деррига ловзараш** довз (25 000 гаргга йоазув), хӏана аьлча цо
Discord-а ший юкъара могӏам доьш, тӏаккха ший боараме кердаяккхарца лоаттаду.

> [!WARNING]
> Ловзар харц латаяр Discord-а Низамашца доагӏаш ца хила мег, Decoy **хьай дог тохаш а кхераме а** леладу ӏа.
> Ер проект Discord Inc. компаница бувзам болаш яц, цо къоабалйийна е гӏо лоаттадаь яц. Хьажа [Бехк цабилларах лаьца](#бехк-цабилларах-лаьца).

## Билгалдахараш

- **Discord-на белгалдаккха ховра дола деррига.** Ловзарий могӏам Discord-а юкъара хьастера хьаэц, локально
  кэш ду, хӏара дийнахьа кердадоккх. Керда ловзараш а керда тӏатеха exe файлаш а шаьш хьагургья.
- **Чехка лахар.** Эзараш ловзарашта юкъе цӏераца е exe файлца сихха лахар, урашца е юткъа могӏамца гайтар,
  хержараш а «Кесталера» могӏа а.
- **Цхьан таӏорца.** Ловзар хержа, exe файл хержа (дуккха елахь), маса минота латтае еза белгалде, тӏаккха латае.
  Хан ларара чӏуралго а хоамо а ха чакхъяьлча хоаморгда.
- **Тӏехьа лар ца юташ.** Decoy из болх беча хана мара яц: зӏамига exe латаяьча хана хьахул, сацайича дӏайовл.
  Программера араваьлча деррига а сацаду, ткъа аварийни сецачул тӏехьа йиса файлаш тӏехьа латаяьча цӏенъю.
- **Тийна раж.** Системан трей чу лоаттаду, заглушкашта шашта леррина кораш е панель тӏа кнопкаш яц.
- **Дийла таржамаш.** Интерфейс атта JSON файлаш тӏа болх беш я, цундела керда мотт тӏатохар — цхьа файл тӏатохар мара дац.
  Инглис а эрсий а метташ чулаьца да.
- **Къайлахалла.** Аккаунт эшаш яц, Discord токен яц, телеметри яц. Хьажа [Къайлахалла](#къайлахалла).

## Цо болх мишта бу

1. Discord-о хьай компьютере болх беш йола процессашта хьажарца а уж юкъарча могӏамца (`/api/v9/applications/detectable`)
   дистараца белгалду хьо ловзаш волга.
2. Decoy-с из могӏам хьаэц, ӏа хержача ловзарна зӏамига заглушка-программа (120 КБ гаргга, Rust меттала язъяь а
   Decoy чу яьккха а йола) хана йолча папка чу копи ю списокера exe цӏераца, масала `.../cod26-cod.exe`.
3. Заглушкас цхьаккха хӏама дец, цхьа кор мара доацаш, из экранал арахьа лечкъадаь латт, хьона из гургдац.
   Discord-на кор дола процесс мара йовзац, цундела кор доаца процесс цо теркалйийргияц.
4. 15 секундах Discord-о из ловзар хьай хӏанзара болх санна гойтаргда.
5. Таймер чакхъяьлча е ӏа «Сецае» тӏатехача, Decoy-с процесс саца а ю, файл дӏа а йоаккх. Windows job object-о
   Decoy-ца цхьана заглушкаш а сацайо, из сацарах кхерам хилча а.

## Чуоттае

[Releases](../../../../releases) оагӏон тӏара хержа:

| Хьаэцар | Хьанна |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталлятор.** Хӏара леладечунна, администратора бакъонаш эшац, Меню Пуск чу дакъа а дӏаяккхара программа а тӏатух. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативни.** Хьай безам болча хьаделла а `decoy.exe` латае. Деррига дараш цун юхе йолча `data` папка чу хургда, профиль чу цхьаккха хӏама яздергдац. Дӏаяккха папка дӏаяккха мара ца эшаш. |

Хьаэцара бакъдар `SHA256SUMS.txt` гӏоьнца тохка (`Get-FileHash <файл>` PowerShell чу).

Windows SmartScreen-о дика йовзаш йоаца арахецархо я аьлла хоам бан мег, цун бахьан цун код-подпись йоацаш хилар да;
*More info → Run anyway* хержа нагахь санна сборкана тешаш вале.

Эшаш йола хӏамаш: Windows 10 е 11 (64-бит) WebView2 runtime-ца (Windows 11 чу а кердача Windows 10 чу а хӏинцале йоллуш я).

## Мишта лелае еза

1. **Библиотека** хьаелла а ловзар лаха, е миччахьара а `Ctrl` + `K` тӏатоӏаде.
2. Ловзар тӏа таӏаде. Аьтта оагӏорахьа йолча панель тӏа процесс хержа а маса минота латтае еза хержа а (Discord-а
   активностшта дукхагӏа 15 оашу).
3. **Decoy латае** тӏатоӏаде. Массехк секундал тӏехьагӏа Discord-о ловзар хьакъоастадергда.
4. **Латаяьраш** оагӏон тӏа хьажа, цхьаъ е деррига муххача хана сацаде, е Decoy трей чу йита.

Discord-а могӏаме exe йоаца ловзараш хьалха дуйна кхайла хул (уж белгалдаккха йиш яц).
*Exe йоаца ловзараш хьакъоастаде* латаде уж гургдолаш; могӏам хӏара дийнахьа кердабоккх, цундела Discord-о процесс тӏатехача уж латае йиш хургья.

### Командни могӏа

```
decoy.exe --launch "<Discord списокера exe никъ>" [миноташ]
```

Decoy сиха латайо, масала `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Хьастера гулъяр

Эшараш: [Node.js](https://nodejs.org) 20+, стабильни [Rust](https://rustup.rs) гӏирсаш (MSVC target) Visual Studio C++
build tools-ца, WebView2 runtime-ца цхьана.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload-ца кхетора раже латаяр
npm run tauri build    # src-tauri/target/release/bundle/nsis чу инсталлятор гулъяр
```

Пайда болаш тохкамаш:

```bash
npm run check-locales  # массо таржама файл ru.json тӏа тохкар
npx tsc --noEmit       # фронтенда тайпаш тохкар
cargo check --manifest-path src-tauri/Cargo.toml
```

Билгалдахар: Decoy exe файл `src-tauri/build.rs` чохь ялсамане `rustc` гӏоьнца `src-tauri/stub/stub.rs` файлах гулйийргия,
тӏаккха программа чу хӏоттаю. Браузер чу фронтенд латаяьча хана (`npm run dev`) зӏамига mock backend
(`src/mock.ts`) леладу, UI-ца болх бе атта хилийта.

## Таржамаш

Интерфейса могӏамаш [`src/locales`](../../src/locales) чохь да, хӏара меттана цхьа JSON файл (`en.json`, `ru.json`, ...).
Керда мотт тӏатохар — цхьа файл тӏатохар мара дац, код хувца ца эшаш. Хьажа [docs/TRANSLATING.md](../TRANSLATING.md) файлан формат
хьокъехь, машина таржама кийчча промпт а тохкама скрипт а кораярга. Ер README таржамаш `docs/i18n/README.<code>.md` чу да.

## Проекта хӏоттам

```
src/                    React + TypeScript фронтенд
  components/           Библиотека, хабара панель, оттамаш, ...
  locales/              таржама файлаш (хӏара меттана цхьа JSON)
  i18n-core.ts          мотт хьаэцар а лахар а
  store.ts              программан хьал (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            ловзарий база, Decoy процессаш, трей
  stub/stub.rs          чуоттаю заглушка-программа
scripts/                гӏоьн скрипташ (таржамаш тохкар)
docs/                   таржама кулгал, скриншоташ
```

## Къайлахалла

- Decoy-с маза лелабу Discord-а юкъара могӏам хьаэца (духхьашха латаяьча хана, тӏаккха дийнахьа цкъа мара ца эцаш,
  е кердаяккхача хана) а Discord-а CDN тӏара ловзарий иконаш а сурташ а гайта.
- Цо хьай Discord токен е аккаунт дараш дешац, лоаттадец, дӏасахьийдадец, иштта Discord клиентца бувзам а лелабец.
- Оттамаш (хержараш, мотт, хан боарам) локально WebView чу лоаттаду; ловзарий могӏам а хана йола Decoy файлаш а
  `%LOCALAPPDATA%\app.decoy.desktop` чохь лоаттаду.
- Аналитика яц, гӏалаташ дӏахьехар дац, аккаунташ яц.

## Довзаш дола доазонаш

- Discord-о ший безам болча хана ловзар белгалдаккхар хувца мег. Нагахь санна Decoy белгал ца яккхахь, issue хьаелла.
- Цхьацца балхашта процесс мара ца хилча кхы а хӏама эша (масала ловзара платформа чу къаьстта меттиг). Decoy-с процесс мара харц латаец.
- Discord могӏаме exe йоаца ловзараш белгалдан йиш яц.
- Кхерамзлен программашта наггахь эс чу яьсса латта кулгакуо йоаца зӏамига exe файлаш шеконе хета тарлуш да. Decoy дийла код йолаш я
  а `src-tauri/stub/stub.rs` чура гулйийргия; хьай а гулъе йиш я.
