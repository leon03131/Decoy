# Decoy

**چھوٹے متبادل پروسیس جو Discord کو یہ باور کرواتے ہیں کہ کوئی گیم چل رہی ہے۔**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="حالیہ گیمز اور آرٹ ورک کے ساتھ Decoy لائبریری" />

</div>

Decoy گیم کے قابل عمل نام (executable name) کے تحت ایک بے ضرر، ونڈو والا متبادل پروسیس چلاتا رہتا ہے، تاکہ Discord کا گیم ڈیٹیکشن یہ ظاہر کرے کہ آپ وہ گیم کھیل رہے ہیں۔ آپ کو کبھی بھی اصل گیم انسٹال یا لانچ کرنے کی ضرورت نہیں پڑتی، لہذا آپ کی ڈسک پر کچھ بھی بھاری محفوظ نہیں ہوتا۔

یہ **ہر اس گیم سے واقف ہے جسے Discord شناخت کر سکتا ہے** (تقریباً 25,000 اندراجات) کیونکہ یہ Discord کی اپنی عوامی ڈیٹیکشن لسٹ پڑھتا ہے اور اسے خود بخود اپ ٹو ڈیٹ رکھتا ہے۔

> [!WARNING]
> کسی چلتی ہوئی گیم کا دکھاوا کرنا Discord کی سروس کی شرائط کے خلاف ہو سکتا ہے اور آپ Decoy کو **اپنے خطرے پر** استعمال کرتے ہیں۔
> یہ پروجیکٹ Discord Inc سے وابستہ، اس کی توثیق شدہ، یا اس سے منسلک نہیں ہے۔ دیکھیے [دستبرداری](#دستبرداری)۔

## خصوصیات

- **ہر وہ چیز جسے Discord شناخت کر سکتا ہے۔** گیم کی فہرست Discord کے عوامی ڈیٹیکشن اینڈ پوائنٹ سے ڈاؤن لوڈ کی جاتی ہے، مقامی طور پر کیش کی جاتی ہے اور روزانہ تازہ دم کی جاتی ہے۔ نئی گیمز اور نئی شامل کی گئی ایکزیکییوٹیبلز خود بخود ظاہر ہو جاتی ہیں۔
- **تیز رفتار تلاش۔** ہزاروں گیمز میں گیم کے نام یا ایکزیکییوٹیبل کے ذریعے فوری تلاش، گرڈ یا کمپیکٹ لسٹ ویو، پسندیدہ (favorites)، اور ایک "حالیہ" قطار۔
- **ایک کلک۔** گیم منتخب کریں، ایکزیکییوٹیبل چنیں (اگر متعدد ہوں)، منتخب کریں کہ اسے کتنی دیر چلانا ہے اور اسٹارٹ دبائیں۔ ایک الٹی گنتی کا دائرہ اور اطلاع آپ کو وقت مکمل ہونے پر آگاہ کرتے ہیں۔
- **پیچھے کوئی نشان نہیں چھوڑتا۔** ایک decoy صرف اسی وقت تک موجود رہتا ہے جب تک وہ چل رہا ہو: چھوٹا سا exe شروع ہونے پر بنایا جاتا ہے اور رکنے پر حذف کر دیا جاتا ہے۔ جب آپ ایپ بند کرتے ہیں تو سب کچھ بند ہو جاتا ہے، اور کسی کریش کا بچا ہوا مواد اگلی بار لانچ ہونے پر صاف کر دیا جاتا ہے۔
- **خاموش۔** سسٹم ٹرے میں رہتا ہے، خود decoys کے لیے کوئی ونڈو یا ٹاسک بار بٹن نہیں ہوتے۔
- **کھلے ترجمے۔** انٹرفیس عام JSON فائلوں سے چلتا ہے، لہذا نئی زبان شامل کرنا صرف ایک فائل کا کام ہے۔ انگریزی اور روسی پہلے سے شامل ہیں۔
- **پرائیویٹ۔** کوئی اکاؤنٹ نہیں، کوئی Discord ٹوکن نہیں، کوئی ٹیلی میٹری نہیں۔ دیکھیے [رازداری](#رازداری)۔

## یہ کیسے کام کرتا ہے

1. Discord آپ کے پی سی پر چلنے والے پروسیسز کو دیکھ کر اور ان کے ایکزیکییوٹیبل ناموں کا موازنہ عوامی فہرست (`/api/v9/applications/detectable`) سے کر کے یہ طے کرتا ہے کہ آپ کوئی گیم کھیل رہے ہیں۔
2. Decoy اس فہرست کو ڈاؤن لوڈ کرتا ہے اور آپ کی منتخب کردہ گیم کے لیے فہرست سے ایکزیکییوٹیبل کا نام استعمال کرتے ہوئے ایک عارضی فولڈر میں ایک چھوٹا سا متبادل پروگرام (تقریباً 120 KB، Rust میں لکھا ہوا اور Decoy میں ایمبیڈڈ) کاپی کرتا ہے، مثال کے طور پر `.../cod26-cod.exe`۔
3. یہ متبادل پروگرام اس کے علاوہ کچھ نہیں کرتا کہ اس کی ایک ٹاپ لیول ونڈو ہوتی ہے، جسے اسکرین سے بہت دور پارک کیا جاتا ہے تاکہ آپ اسے کبھی نہ دیکھ سکیں۔ Discord صرف اسی پروسیس کو تسلیم کرتا ہے جس کی کوئی ونڈو ہو، یہی وجہ ہے کہ مکمل طور پر بغیر ونڈو والے پروسیس کو نظر انداز کر دیا جاتا ہے۔
4. تقریباً 15 سیکنڈ کے اندر Discord اس گیم کو آپ کی موجودہ سرگرمی کے طور پر دکھاتا ہے۔
5. جب ٹائمر ختم ہوتا ہے یا آپ اسٹاپ دباتے ہیں، تو Decoy پروسیس کو ختم کرتا ہے اور فائل کو حذف کر دیتا ہے۔ ایک Windows job object اس بات کو یقینی بناتا ہے کہ decoys خود Decoy کے ساتھ ہی ختم ہو جائیں، چاہے وہ کریش ہی کیوں نہ ہو جائے۔

## انسٹال کریں

[Releases](../../../../releases) پیج سے کوئی ایک منتخب کریں:

| ڈاؤن لوڈ | برائے |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **انسٹالر۔** فی صارف، ایڈمنسٹریٹر کے حقوق کی ضرورت نہیں، اسٹارٹ مینو کا اندراج اور ایک ان انسٹالر شامل کرتا ہے۔ |
| `Decoy_x.y.z_x64-portable.zip` | **پورٹ ایبل۔** کہیں بھی ان زپ کریں اور `decoy.exe` چلائیں۔ تمام ڈیٹا اس کے ساتھ موجود `data` فولڈر میں رہتا ہے، آپ کے صارف پروفائل میں کچھ نہیں لکھا جاتا۔ اسے ہٹانے کے لیے فولڈر حذف کر دیں۔ |

ڈاؤن لوڈ کی تصدیق `SHA256SUMS.txt` کے ساتھ کریں (PowerShell میں `Get-FileHash <file>`)۔

Windows SmartScreen غیر شناخت شدہ پبلشر کے بارے میں انتباہ دے سکتا ہے کیونکہ بلڈز کوڈ سائن شدہ نہیں ہیں؛ اگر آپ کو بلڈ پر بھروسہ ہے تو *More info → Run anyway* منتخب کریں۔

ضروریات: Windows 10 یا 11 (64-bit) مع WebView2 رن ٹائم (جو پہلے سے ہی Windows 11 اور حالیہ Windows 10 اپ ڈیٹس میں شامل ہے)۔

## استعمال کا طریقہ

1. **Library** کھولیں اور کوئی گیم تلاش کریں، یا کہیں سے بھی `Ctrl` + `K` دبائیں۔
2. کسی گیم پر کلک کریں۔ دائیں جانب والے پینل میں پروسیس اور منٹوں کی تعداد منتخب کریں کہ اسے کتنی دیر تک جاری رکھنا ہے (Discord سرگرمیاں عام طور پر 15 منٹ مانگتی ہیں)۔
3. **Start decoy** دبائیں۔ Discord چند سیکنڈ کے بعد گیم دکھا دے گا۔
4. اسے **Running** کے تحت دیکھیں، کسی ایک یا سب کو کسی بھی وقت روکیں، یا صرف Decoy کو ٹرے میں چھوڑ دیں۔

جن گیمز کے Discord اندراج میں ابھی تک کوئی ایکزیکییوٹیبل نہیں ہے وہ پہلے سے پوشیدہ ہوتی ہیں (انہیں شناخت نہیں کیا جا سکتا)۔ انہیں دیکھنے کے لیے
*Show games without exe* کو آن کریں؛ فہرست روزانہ تازہ دم کی جاتی ہے، اس لیے وہ جیسے ہی Discord کوئی پروسیس شامل کرتا ہے دستیاب ہو جاتی ہیں۔

### کمانڈ لائن

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

فوری طور پر ایک decoy شروع کرتا ہے، مثال کے طور پر `decoy.exe --launch "robloxplayerbeta.exe" 15`۔

پیشگی ضروریات: [Node.js](https://nodejs.org) 20+، مستحکم [Rust](https://rustup.rs) ٹول چین (MSVC ٹارگٹ) مع Visual Studio C++ بلڈ ٹولز، اور WebView2 رن ٹائم۔

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

مفید جانچ پڑتال:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

نوٹس: decoy exe کو `src-tauri/build.rs` کے ذریعے سادہ `rustc` سے `src-tauri/stub/stub.rs` سے مرتب کیا جاتا ہے اور پھر ایپ میں ایمبیڈ کیا جاتا ہے۔ جب فرنٹ اینڈ عام براؤزر میں چلتا ہے (`npm run dev`) تو ایک چھوٹا موک بیک اینڈ (`src/mock.ts`) استعمال ہوتا ہے، جو UI پر کام کرنے کے لیے آسان ہے۔

## ترجمے

UI سٹرنگز [`src/locales`](../../src/locales) میں رہتی ہیں، فی زبان ایک JSON فائل (`en.json`, `ru.json`, ...).
نئی زبان شامل کرنے کا مطلب ایک نئی فائل کا اضافہ ہے؛ کوڈ میں کوئی تبدیلی نہیں۔ فائل فارمیٹ، مشین ٹرانسلیشن کے لیے تیار پرامپٹ اور توثیق کے اسکرپٹ کے لیے [docs/TRANSLATING.md](../TRANSLATING.md) دیکھیں۔ اس README کے ترجمے `docs/i18n/README.<code>.md` میں جاتے ہیں۔

## پروجیکٹ کا ڈھانچہ

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## رازداری

- Decoy نیٹ ورک کو صرف Discord کی عوامی ڈیٹیکشن لسٹ ڈاؤن لوڈ کرنے کے لیے استعمال کرتا ہے (پہلے آغاز پر، پھر زیادہ سے زیادہ دن میں ایک بار یا جب آپ ریفریش دبائیں) اور ڈسپلے کے لیے، گیم آئیکنز اور Discord کے عوامی CDN سے آرٹ ورک لانے کے لیے۔
- یہ آپ کا Discord ٹوکن یا اکاؤنٹ کا کوئی بھی ڈیٹا نہ تو پڑھتا ہے، نہ اسٹور کرتا ہے اور نہ ہی بھیجتا ہے، اور یہ Discord کلائنٹ سے بات نہیں کرتا۔
- ترتیبات (پسندیدہ، زبان، دورانیے) ایپ کے WebView اسٹوریج میں مقامی طور پر محفوظ ہوتی ہیں؛ گیم لسٹ کیش اور عارضی decoy فائلیں `%LOCALAPPDATA%\app.decoy.desktop` میں رہتی ہیں۔
- کوئی اینالیٹکس نہیں، کوئی کریش رپورٹنگ نہیں، کوئی اکاؤنٹس نہیں۔

## معلوم حدود

- Discord کسی بھی وقت ڈیٹیکشن کے کام کرنے کا طریقہ بدل سکتا ہے۔ اگر کسی decoy کی شناخت بند ہو جائے، تو برائے مہربانی ایشو (issue) کھولیں۔
- کچھ سرگرمیوں کو محض چلتے ہوئے پروسیس سے زیادہ کی ضرورت ہوتی ہے (مثال کے طور پر کسی گیم پلیٹ فارم کے مخصوص تجربے کے اندر ہونا)۔ Decoy صرف پروسیس کی نقل کرتا ہے۔
- Discord کی فہرست میں بغیر ایکزیکییوٹیبل والے اندراجات کی شناخت نہیں کی جا سکتی۔
- سیکیورٹی سافٹ ویئر کبھی کبھار چھوٹی غیر دستخط شدہ ایکزیکییوٹیبلز پر الرٹ دے سکتا ہے جو میموری میں غیر فعال پڑی رہتی ہیں۔ decoy اوپن سورس ہے اور `src-tauri/stub/stub.rs` سے تیار کیا گیا ہے؛ آپ اسے خود کمپائل کر سکتے ہیں۔
