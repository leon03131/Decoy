# Decoy

**Processos substitutos minúsculos que fazem o Discord pensar que um jogo está em execução.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca do Decoy com jogos recentes e ilustrações" />

</div>

O Decoy mantém em execução um processo fictício inofensivo com janela sob o nome do executável de um jogo, para que a detecção de jogos do Discord informe que você está jogando aquele jogo. Você nunca precisa instalar ou iniciar o jogo real, portanto nada pesado ocupa espaço no seu disco.

Ele conhece **todos os jogos que o Discord consegue detectar** (cerca de 25.000 entradas), pois lê a própria lista pública de detecção do Discord e a mantém atualizada por conta própria.

> [!WARNING]
> Simular um jogo em execução pode violar os Termos de Serviço do Discord e você usa o Decoy **por sua própria conta e risco**.
> Este projeto não é afiliado, endossado ou conectado à Discord Inc. Consulte o [Aviso Legal](#aviso-legal).

## Recursos

- **Tudo o que o Discord consegue detectar.** A lista de jogos é baixada do endpoint público de detecção do Discord, armazenada em cache localmente e atualizada diariamente. Novos jogos e executáveis adicionados recentemente aparecem automaticamente.
- **Busca que acompanha o ritmo.** Busca instantânea por nome do jogo ou executável em milhares de jogos, visualização em grade ou lista compacta, favoritos e uma linha de "Recentes".
- **Um clique.** Escolha um jogo, escolha o executável (se houver vários), defina por quanto tempo mantê-lo e clique em iniciar. Um anel de contagem regressiva e uma notificação avisam quando o tempo acabar.
- **Não deixa rastros.** Um decoy só existe enquanto está em execução: o pequeno exe é criado ao iniciar e excluído ao parar. Tudo é encerrado quando você sai, e resquícios de falhas anteriores são limpos na próxima inicialização.
- **Silencioso.** Fica na bandeja do sistema, sem janelas ou botões na barra de tarefas para os próprios decoys.
- **Traduções abertas.** A interface é baseada em arquivos JSON simples, então adicionar um idioma requer apenas um arquivo. Inglês e russo estão incluídos.
- **Privado.** Sem conta, sem token do Discord, sem telemetria. Consulte [Privacidade](#privacidade).

## Como funciona

1. O Discord determina que você está jogando ao analisar os processos em execução no seu PC e comparar seus nomes de executável com uma lista pública (`/api/v9/applications/detectable`).
2. O Decoy baixa essa lista e, para o jogo escolhido, copia um programa substituto minúsculo (cerca de 120 KB, escrito em Rust e embutido no Decoy) para uma pasta temporária usando o nome de executável da lista, por exemplo `.../cod26-cod.exe`.
3. O substituto não faz nada além de manter uma janela de nível superior posicionada bem fora da tela para que você nunca a veja. O Discord só reconhece processos que possuem uma janela, e é por isso que um processo completamente sem janela é ignorado.
4. Em cerca de 15 segundos, o Discord exibirá o jogo como sua atividade atual.
5. Quando o temporizador termina ou você clica em parar, o Decoy encerra o processo e exclui o arquivo. Um job object do Windows garante que os decoys sejam encerrados junto com o Decoy, mesmo em caso de travamento.

## Instalação

Escolha uma opção na página de [Releases](../../../../releases):

| Download | Para |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por usuário, sem necessidade de privilégios de administrador, adiciona uma entrada no menu Iniciar e um desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portátil.** Descompacte em qualquer lugar e execute o `decoy.exe`. Todos os dados permanecem na pasta `data` ao lado dele, nada é gravado no seu perfil de usuário. Basta excluir a pasta para removê-lo. |

Verifique o download com o `SHA256SUMS.txt` (`Get-FileHash <file>` no PowerShell).

O Windows SmartScreen pode alertar sobre um fornecedor não reconhecido porque os executáveis não possuem assinatura digital; escolha *Mais informações → Executar assim mesmo* caso confie no arquivo compilado.

Requisitos: Windows 10 ou 11 (64 bits) com o WebView2 runtime (já incluído no Windows 11 e em atualizações recentes do Windows 10).

## Como usar

1. Abra a **Biblioteca** e busque por um jogo, ou pressione `Ctrl` + `K` de qualquer lugar.
2. Clique em um jogo. No painel à direita, escolha o processo e por quantos minutos deseja mantê-lo (atividades do Discord geralmente pedem 15).
3. Clique em **Iniciar decoy**. O Discord exibirá o jogo após alguns segundos.
4. Acompanhe em **Em execução**, pare um ou todos a qualquer momento, ou simplesmente deixe o Decoy na bandeja do sistema.

Jogos cuja entrada no Discord ainda não possui executáveis ficam ocultos por padrão (eles não podem ser detectados). Ative *Mostrar jogos sem exe* para visualizá-los; a lista é atualizada diariamente, portanto eles ficarão disponíveis assim que o Discord adicionar um processo.

### Linha de comando

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Inicia um decoy imediatamente, por exemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar a partir do código-fonte

Pré-requisitos: [Node.js](https://nodejs.org) 20+, toolchain estável do [Rust](https://rustup.rs) (alvo MSVC) com as ferramentas de compilação C++ do Visual Studio e o WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Verificações úteis:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Observações: o executável do decoy é compilado pelo `src-tauri/build.rs` usando `rustc` padrão a partir de `src-tauri/stub/stub.rs` e então embutido no aplicativo. Quando o frontend é executado em um navegador comum (`npm run dev`), um pequeno backend simulado (`src/mock.ts`) é utilizado, o que é muito prático para desenvolver a interface.

## Traduções

Os textos da interface ficam em [`src/locales`](../../src/locales), um arquivo JSON por idioma (`en.json`, `ru.json`, ...).
Adicionar um idioma significa apenas adicionar um arquivo; sem alterações no código. Consulte [docs/TRANSLATING.md](../TRANSLATING.md) para obter informações sobre o formato do arquivo, um prompt pronto para tradução automática e o script de validação. As traduções deste README ficam em `docs/i18n/README.<code>.md`.

## Estrutura do projeto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacidade

- O Decoy só utiliza a rede para baixar a lista pública de detecção do Discord (na primeira inicialização e, depois, no máximo uma vez ao dia ou quando você clicar em atualizar) e, para exibição, ícones de jogos e ilustrações da CDN pública do Discord.
- Ele não lê, não armazena e não envia o seu token do Discord nem quaisquer dados da conta, além de não se comunicar com o cliente do Discord.
- As configurações (favoritos, idioma, durações) são armazenadas localmente no armazenamento WebView do aplicativo; o cache da lista de jogos e os arquivos temporários dos decoys ficam em `%LOCALAPPDATA%\app.decoy.desktop`.
- Sem telemetria/análise de dados, sem relatórios de falhas, sem contas.

## Limitações conhecidas

- O Discord pode alterar o funcionamento da detecção a qualquer momento. Se um decoy deixar de ser reconhecido, por favor abra uma issue.
- Algumas atividades exigem mais do que apenas um processo em execução (por exemplo, estar dentro de uma experiência específica em uma plataforma de jogos). O Decoy apenas imita o processo.
- Entradas sem executáveis na lista do Discord não podem ser detectadas.
- Softwares de segurança ocasionalmente sinalizam executáveis pequenos e não assinados que permanecem ociosos na memória. O decoy é de código aberto e compilado a partir de `src-tauri/stub/stub.rs`; você mesmo pode compilá-lo.
