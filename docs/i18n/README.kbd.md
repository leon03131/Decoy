# Decoy

**Discord-ым джэгу макӀуэ къыщӀэгъэхъуным папщӀэ цӀыкӀу-цӀыкӀуу заглушкэ процессхэр.**

![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотекэ мыгувэу зэӀуха джэгухэмрэ сурэтхэмрэ ягъусэу" />

Decoy-м джэгум и exe файлым и цӀэкӀэ зэрар зимыӀэ, бжьажэ зиӀэ заглушкэ процесс гъэлэжьауэ елъытэ, абы къыхэкӀыу Discord-ым джэгур къэхутэным и системэм фэ а джэгум евджэгуу къевбж. Шыпкъэ джэгур гъэувын е гъэлэжьэн хуейкъым, дискам зыри мыхьэнэншэу темылъу къонэ.

Абы **Discord-ым къихутэфу хъуа джэгу псори** ещӀэ (25 000 хуэдиз тхыгъэ), сыт щхьэкӀэ жыпӀэмэ Discord-ым и зэӀуха тхылъпкъ езыр-езыру къеджэ икӀи зэпытху игъэщӀэрэщӀэж.

> [!WARNING]
> Джэгу гъэлэжьам хуэдэу къэгъэлъэгъуэныр Discord-ым и Гъэбзэ Хабзэхэм екӀуу къыщӀэкӀынкъым, Decoy **фи щхьэ хуэсакъыжу, фи бэрныгъэкӀэ** къэвгъэсэбэп.
> Мы проект Discord Inc. компанием епхакъым, абы къищтакъым икӀи игъэунэфакъым. Еплъ: [Бэрычэт жэуаплыныгъэ](#бэрычэт-жэуаплыныгъэ).

## Амалхэр

- **Discord-ым къихутэфу хъуа псори.** Джэгухэм я тхылъпкъ Discord-ым и зэӀуха хъыбар къещтэ, щӀыпӀэм кэш хуэдэу къонэ икӀи махуэ къэс егъэщӀэрэщӀэж. ДжэгущӀэхэри цӀыкӀу-цӀыкӀуу хагъэхъуа exe файлхэри езыр-езыру къыхофэ.
- **ПсынщӀэу лъыхъуэн.** Мин бжыгъэ джэгухэм я зэхуаку джэгум и цӀэкӀэ е exe файлкӀэ псынщӀэу лъыхъуэн, плӀимэхэмкӀэ е къебжэкӀкӀэ къэгъэлъэгъуэн, хэхахэмрэ «Мыгувэу зэӀухахэр» сатырымрэ.
- **Зы тевкъузэкӀэ.** Джэгур къыхэх, exe файлыр къыхэх (куэд хъумэ), дакъикъэ дапщэкӀэ Ӏыгъынур гъэуви заглушкэр гъэлажьэ. Зэжэну хъуреймрэ хъыбар къэгъэщӀэнымрэ уахътыр зэрыухам я хъыбар къахьынущ.
- **Лъэужь къинэкъым.** Заглушкэр щыӀэр зэрылажьэ закъуэм дежщ: цӀыкӀу exe файлыр къызэрыжьэу къохъу, къэувыӀа иужь къабзэу тохуж. Приложенэм укъыхэкӀыжмэ псори къэувыӀэ, къутакъэхэм къахэкӀыу къэнахэр къыкӀэлъыкӀуэу зэӀухыжым деж егъэкъэбзэж.
- **Сабыр режим.** Системнэ трейм щопсэу, заглушкэхэм я щхьэхуэ бжьажэхэр е панелым кнопкэхэр яӀэкъым.
- **ЗэӀуха зэдзэкӀыгъэхэр.** Интерфейсыр гурыӀуэгъуэ JSON файлхэм ятетщ, арати бзэщӀэ хэлъхьэныр — зы файл закъуэщ. Инджылыбзэри урысыбзэри хэтщ.
- **Шэхуныгъэ.** Аккаунт хуейкъым, Discord токен щыӀэкъым, телеметри щыӀэкъым. Еплъ: [Шэхуныгъэ](#шэхуныгъэ).

## Мыр зэрылажьэр

1. Discord-ым фи компьютерым щылажьэ процессхэр къэпщытэурэ, абыхэм я exe файлхэм я цӀэхэр зэӀуха тхылъпкъым (`/api/v9/applications/detectable`) хэтхэм иригъэпщэурэ, джэгум евджэгуу къелъытэ.
2. Decoy-м а тхылъпкъыр къещтэри, фэ къыхэфха джэгум папщӀэ цӀыкӀу-цӀыкӀуу заглушкэ программэ (120 КБ хуэдиз, Rust-кӀэ тхауэ Decoy-м хэлъыр) уахътэ папкэм тхылъпкъым къыхэкӀа exe цӀэкӀэ егъэкӀуэ, псалъэм папщӀэ `.../cod26-cod.exe`.
3. Заглушкэм экраным куэдкӀэ пэжыжьэу гъэува зы бжьажэ зэӀуха закъуэм фӀэкӀа зыри ищӀэркъым, арати фэ а бжьажэр зэи плъагъунукъым. Discord-ым бжьажэ зиӀэ процессхэр фӀэкӀа къищтэркъым, бжьажэншэ процессхэр къилъытэркъым.
4. Секунд 15 хуэдиз дэкӀмэ Discord-ым а джэгур фи иджыпстурей Ӏуэхугъуэу къегъэлъагъуэ.
5. Таймерыр зэрыуху е гъэувыӀэн тевкъузэу, Decoy-м процессыр егъэувыӀэри файлыр тохуж. Windows-ым и job object Ӏэмалым Decoy зэуэ къутэжми заглушкэхэр зэдигъэувыӀэну къегъэгугъэ.

## Гъэувын

КъыдэкӀыгъэхэм я [релиз напэкӀэ](../../../../releases) зы къыхэфх:

| Къещэн | Сыт хуэдэ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ГъэувыпӀэ.** Зы гъэблэжьакӀуэм папщӀэ, администратор фитыныгъэ хуейкъым, «Пуск» менюм тхыгъэ хегъахьэ икӀи деинсталлятор иӀэщ. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативнэ.** Хэт щӀыпӀи къызэӀухи `decoy.exe` гъэлажьэ. Дахэ псори и бгъум щылъ `data` папкэм къонэ, гъэблэжьакӀуэм и профилым зыри тетхэркъым. ТекӀуэдэжын папщӀэ папкэр хэгъэкӀуэдэж хъунущ. |

Къещэгъэ файлыр `SHA256SUMS.txt` щӀыкӀэкӀэ къэпщытэж (PowerShell-м `Get-FileHash <файл>`).

Windows SmartScreen-ым цӀэрыӀуэ мыхъуа къыдэгъэкӀакӀуэ уиӀ жаӀэу гузэвэгъуэ къыфхуищӀынкӀэ хъунущ, сыт щхьэкӀэ жыпӀэмэ сборкэхэм цифрэ ӀэпапӀэ яӀэкъым; фэ шэч къытумыхьэу фыщыгугъымэ *Нэхъыбэ къэбар → Сытми гъэлэжьэн* хэфх.

Хуэныкъуэгъуэхэр: Windows 10 е 11 (64-bit) WebView2 runtime игъусэу (Windows 11-ми иужьрей Windows 10 гъэщӀэрэщӀэгъуэхэми хэтщ).

## ГъэблэжьэкӀэ

1. **Библиотекэ** къызэӀухи джэгум лъыхъуэ, е дэнэ дежи `Ctrl` + `K` тевкъузэ.
2. Джэгум тевкъузэ. Ижь лъэныкъуэмкӀэ щыт панелым процессыр къыхэфхи дакъикъэ дапщэкӀэ Ӏыгъынур къэгъэлъагъуэ (Discord Ӏуэхугъуэхэм нэхъыбэм 15 яхуэныкъуэщ).
3. **Decoy гъэлажьэ** тевкъузэ. Секунд зыбжанэ дэкӀмэ Discord-ым джэгур къигъэлъэгъуэнущ.
4. **Гъэлэжьахэр** вкладкэм щӀэлъу еплъ, зыр е псори хэт уахъти гъэувыӀэ, е Decoy трейм бгъэзэгъэну къэбгъанэ хъунущ.

Discord базэм exe файлхэр иджыри зимыӀэ джэгухэр къызэрыгуэкӀу гъэпщкӀуащ (ахэр къэгъуэтыфынукъым). Ахэр плъагъун папщӀэ *Exe зимыӀэ джэгухэр къэгъэлъэгъуэн* къэгъэлажьэ; тхылъпкъыр махуэ къэс егъэщӀэрэщӀэж, абы къыхэкӀыу Discord-ым процесс хигъэхьэжмэ, хьэзыр хъунущ.

### Команднэ сатыр

```
decoy.exe --launch "<Discord тхылъпкъым къыхэкӀа exe гъуэгур>" [дакъикъэхэр]
```

Заглушкэр сыт уахъти псынщӀэу егъэлажьэ, псалъэм папщӀэ: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Хъыбар хъугъэм къыхэхыу гъэпсын

Хуэныкъуэгъуэхэр: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) хъыбар Ӏэмэпсымэхэр (MSVC target) Visual Studio C++ build tools игъусэу, икӀи WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # горячэу кӀэрыгъэщӀэрэщӀэжкӀэ гъэлэжьэн
npm run tauri build    # src-tauri/target/release/bundle/nsis-м гъэувыпӀэ файл къыщыдэгъэкӀын
```

Къэгъэсэбэпыпхъэ къэпщытэныгъэхэр:

```bash
npm run check-locales  # дэтхэнэ зэдзэкӀыгъэ файлыр ru.json-м иригъэпщэун
npx tsc --noEmit       # фронтендым и типхэр уплъэкӀун
cargo check --manifest-path src-tauri/Cargo.toml
```

Гу лъитэныгъэхэр: decoy exe файлыр `src-tauri/build.rs` ӀэмалкӀэ `rustc` хуэдэу `src-tauri/stub/stub.rs` къыхэкӀыу егъэхьэзыр икӀи приложенэм хелъхьэ. Фронтендыр браузер къызэрыгуэкӀым щылажьэкӀэ (`npm run dev`) цӀыкӀу мок-бэкенд (`src/mock.ts`) къагъэсэбэп, интерфейсымкӀэ Ӏуэху пщӀэну нэхъ тыншщ.

## ЗэдзэкӀыгъэхэр

Интерфейсым и псалъэхэр [`src/locales`](../../src/locales) щӀэлъщ, бзэ къэс зы JSON файл (`en.json`, `ru.json`, ...). Бзэ хэлъхьэным папщӀэ файл хэлъхьэн закъуэщ — кодым зыри зэблихъуркъым. Файлхэм я формат, машинэкӀэ зэдзэкӀыным и промптыр икӀи валидацэ скриптыр къэгъуэтын папщӀэ еплъ: [docs/TRANSLATING.md](../TRANSLATING.md). Мы README-м и зэдзэкӀыгъэхэр `docs/i18n/README.<code>.md` папкэм итхэх.

## Проектым и щытыкӀэ

```
src/                    React + TypeScript фронтенд
  components/           Библиотекэ, куэд къэзыӀуатэ панель, гъэзэщӀэкӀэхэр, ...
  locales/              зэдзэкӀыгъэ файлхэр (бзэ къэс зы JSON)
  i18n-core.ts          бзэр зэӀухыныр икӀи лъыхъуэныр
  store.ts              приложенэм и щытыкӀэ (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            джэгухэм я базэ, заглушкэ процессхэр, трей
  stub/stub.rs          чӀэгъэлъ заглушкэ программэ
scripts/                ӀэпыӀэгъу скриптхэр (локальхэр уплъэкӀун)
docs/                   зэдзэкӀыным и гъуазэ, скриншотхэр
```

## Шэхуныгъэ

- Decoy-м сетьыр Discord-ым и зэӀуха тхылъпкъ къещтэным папщӀэ фӀэкӀа къигъэсэбэпкъым (япэ зэӀухыгъэм, итӀанэ махуэм зэ е гъэщӀэрэщӀэжыным тевкъузэмэ) икӀи къэгъэлъэгъуэным папщӀэ джэгу тамыгъэхэр Discord CDN-м къыхех.
- Фи Discord токен е аккаунт хъыбархэр къеджэркъым, ихъумэркъым, игъакӀуэркъым икӀи Discord клиентми епсалъэркъым.
- ГъэзэщӀэкӀэхэр (хэхахэр, бзэр, уахътыр) щӀыпӀэм деж приложенэм и WebView хъумапӀэм къонэ; джэгу тхылъпкъым и кэшрэ заглушкэм я уахътэ файлхэмрэ `%LOCALAPPDATA%\app.decoy.desktop` щӀэлъщ.
- Аналитикэ щыӀэкъым, къутэгъэ отчёт щыӀэкъым, аккаунтхэр щыӀэкъым.

## ЗэлъащӀэ гъэунэфыгъэхэр

- Discord-ым къэгъуэтыным и хабзэ сыт уахъти зэблихъуфынущ. Заглушкэр къэмылъытэж хъумэ, фӀыщӀэ фщӀи issue къызэӀух.
- Зыгуэр Ӏуэхугъуэхэм папщӀэ лажьэ процесс закъуэр икъуркъым (псалъэм папщӀэ джэгу платформым и хэха щӀыпӀэ ущыӀэн хуейщ). Decoy-м процессыр закъуэщ зэригъэпцӀыр.
- Discord тхылъпкъым exe зимыӀэ тхыгъэхэр къэгъуэтыфынукъым.
- ХъумакӀуэ программэхэм я ӀэпыӀэгъу системэхэм памяти щылъ цифрэ ӀэпапӀэ зимыӀэ exe файлхэм гузэвэгъуэ къахуащӀынкӀэ хъунущ. Заглушкэр зэӀуха код зиӀэу `src-tauri/stub/stub.rs` къыхэкӀыу гъэпсащ; езыр-езыру компилировать пщӀы хъунущ.

Decoy хэхауэ, егъэджэн икӀи къэпщытэн мурадхэм папщӀэ къыттащ. Лажьэ джэгум хуэдэу къэгъэлъэгъуэныр Discord-ым е джэгу къыдэгъэкӀакӀуэм я Гъэбзэ Хабзэхэм екӀуу къыщӀэкӀынкъым икӀи фи аккаунтым папщӀэ Ӏуэху къыдишэфынущ. КъэгъэсэбэпыкӀэм папщӀэ фэ езыр фэ фыжэуаплыжщ. «Discord» икӀи джэгу цӀэ псори я езы-езыхэм я товар тамыгъэхэу щытщ икӀи программэхэр къэгъэлъэгъуэным папщӀэ закъуэщ мыбдеж къызэрыщыгъэсэбэпар.
