# Decoy

**Minuscule processos substitutive que face Discord creder que un joco es in execution.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibliotheca de Decoy con jocos recente e illustrationes" />

</div>

Decoy mantene in execution un processo sustitutive innocue con fenestra sub le nomine del executabile de un joco, de sorta que le detection de jocos de Discord reporta que tu joca a ille joco. Tu nunquam require installar o lancear le joco real, de maniera que nihil de grande occupa spatio sur tu disco.

Illo cognosce **omne joco que Discord pote deteger** (circa 25.000 entratas) proque illo lege le proprie lista public de detection de Discord e lo mantene a die per se mesme.

> [!WARNING]
> Simular un joco in execution pote contravenir al Conditiones de Servicio de Discord e tu usa Decoy **a tu proprie risco**.
> Iste projecto non es affiliate con, approbate per o ligate a Discord Inc. Vide [Clausula de non-responsabilitate](#clausula-de-non-responsabilitate).

## Functiones

- **Toto lo que Discord pote deteger.** Le lista de jocos es discargate ab le puncto final public de detection de Discord, ponite in cache localmente e refrescate quotidianmente. Nove jocos e executabiles recentemente addite appare per se mesme.
- **Recerca rapide e efficace.** Recerca instantanee per nomine de joco o per executabile a transverso milles de jocos, vista in grillia o lista compacte, favoritos e un linea de “Recente”.
- **Un sol clic.** Selige un joco, selige le executabile (si il ha plures), selige quanto tempore mantener lo e pressa initiar. Un anello de conto a rebordo e un notification te avisa quando le tempore ha expirate.
- **Lassa nihil post se.** Un decoy existe solmente durante su execution: le parve exe es create al initio e delite al arresto. Toto es stoppate quando tu quita, e le restos post un collapso es mundate al proxime lanceamento.
- **Tranquille.** Vive in le tabula de notificationes del systema, sin fenestras o botones in le barra de cargas pro le decoys mesme.
- **Traductiones aperte.** Le interfacie es guidate per files JSON simple, de maniera que adder un lingua require solmente un singule file. Anglese e russo es includite.
- **Private.** Nulle conto, nulle token de Discord, nulle telemetria. Vide [Privacitate](#privacitate).

## Como illo functiona

1. Discord decide que tu joca a un joco per examinar le processos in execution sur tu computator e comparar lor nomines de executabile con un lista public (`/api/v9/applications/detectable`).
2. Decoy discarga ille lista e, pro le joco que tu selige, copia un minuscule programma sustitutive (circa 120 KB, scribite in Rust e incorporate in Decoy) a un dossier temporari usante le nomine de executabile ex le lista, per exemplo `.../cod26-cod.exe`.
3. Le sustituto face nihil excepte posseder un fenestra de nivello superior, placiate multo foras del schermo pro que tu nunquam lo vide. Discord recognosce solmente un processo que possede un fenestra, ration pro le qual un processo completemente sin fenestra es ignorate.
4. Intra approximativemente 15 secundas, Discord monstra le joco como tu activitate actual.
5. Quando le temporisator expira o tu pressa stoppar, Decoy termina le processo e dele le file. Un objecto de labor de Windows assecura que le decoys mori insimul con Decoy, mesmo si illo se collapso.

## Installar

Selige un ex le pagina de [Releases](../../../../releases):

| Discargamento | Pro |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installator.** Pro cata usator, nulle derectos de administrator es necessari, adde un entrata in le menu Initio e un desinstallator. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabile.** Discomprime ubicunque e executa `decoy.exe`. Tote le datos remane in le dossier `data` juxta illo, nihil es scribite a tu profilo de usator. Dele le dossier pro remover lo. |

Verifica un discargamento con `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen pote advertir super un publicator non recognoscite proque le versiones non es signate con codice; selige *Plus de informationes → Executar totevia* si tu te fide del version.

Requisitos: Windows 10 o 11 (64-bit) con le ambiente de execution WebView2 (jam includite in Windows 11 e in actualisationes recente de Windows 10).

## Uso

1. Aperi **Bibliotheca** e cerca un joco, o pressa `Ctrl` + `K` ab ubicunque.
2. Clicca sur un joco. In le pannello a dextera, selige le processo e quante minutas mantener lo (le activitates de Discord require usualmente 15).
3. Pressa **Initiar decoy**. Discord monstrara le joco post alcun secundas.
4. Observa lo sub **In execution**, stoppa un o totes a omne momento, o simplemente lassa Decoy in le tabula de notificationes.

Le jocos cuje entrata in Discord non ha ancora executabiles es celate per predefinition (illos non pote esser detegite). Activa *Monstrar jocos sin exe* pro vider los; le lista es refrescate quotidianmente, de maniera que illos deveni disponibile assi tosto que Discord adde un processo.

### Linea de commando

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Initia un decoy immediatemente, per exemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar ab le codice fonte

Pre-requisitos: [Node.js](https://nodejs.org) 20+, le collection de instrumentos stabile de [Rust](https://rustup.rs) (scopo MSVC) con le instrumentos de compilation C++ de Visual Studio, e le ambiente de execution WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Controllos utile:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notas: le exe de decoy es compilate per `src-tauri/build.rs` con `rustc` simple ab `src-tauri/stub/stub.rs` e postea incorporate in le application. Quando le frontend se executa in un navigator web simple (`npm run dev`), un parve backend simulate (`src/mock.ts`) es usate, lo que es commode pro travaliar sur le interfacie de usator.

## Traductiones

Le catenas de interfacie de usator reside in [`src/locales`](../../src/locales), un file JSON per lingua (`en.json`, `ru.json`, ...). Adder un lingua significa adder un file; nulle modificationes de codice. Vide [docs/TRANSLATING.md](../TRANSLATING.md) pro le formato de file, un prompt preste a usar pro traduction automatic e le script de validation. Le traductiones de iste README va a `docs/i18n/README.<code>.md`.

## Structura del projecto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacitate

- Decoy utilisa le rete solmente pro discargar le lista public de detection de Discord (al prime initio, postea al maximo un vice per die o quando tu pressa refrescar) e, pro le presentation visual, le icones de joco e illustrationes ab le CDN public de Discord.
- Illo non lege, non immagazina e non invia tu token de Discord o ulle datos de conto, e illo non communica con le cliente de Discord.
- Le configurationes (favoritos, lingua, durationes) es conservate localmente in le immagazinage WebView del application; le cache del lista de jocos e le files temporari de decoy reside in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nulle telemetria o statisticas, nulle reporto de collapso, nulle contos.

## Limitationes cognoscite

- Discord pote cambiar le modo de functionamento del detection a omne momento. Si un decoy cessa de esser recognoscite, per favor aperi un problema (issue).
- Alcun activitates require plus que un processo in execution (per exemplo esser intra un experientia particular de un platteforma de jocos). Decoy solmente imita le processo.
- Entratas sin executabiles in le lista de Discord non pote esser detegite.
- Le software de securitate occasionalmente marca parve executabiles non signate que remane inactive in memoria. Le decoy es a codice aperte e compilate ab `src-tauri/stub/stub.rs`; tu pote compilar lo tu mesme.
