# Decoy

**Փոքր փոխարինող գործընթացներ, որոնք ստիպում են Discord-ին կարծել, թե խաղ է աշխատում:**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy գրադարանը վերջին խաղերով և պատկերներով" />

</div>

Decoy-ը պահպանում է անվնաս, պատուհան ունեցող փոխարինող գործընթաց խաղի գործարկվող ֆայլի (executable) անվան տակ, որպեսզի Discord-ի խաղերի հայտնաբերման համակարգը ցույց տա, որ դուք խաղում եք այդ խաղը: Ձեզ երբեք հարկավոր չէ տեղադրել կամ գործարկել իրական խաղը, ուստի սկավառակի վրա ծավալուն ոչինչ չի պահվում:

Այն տեղյակ է **յուրաքանչյուր խաղի մասին, որը Discord-ը կարող է հայտնաբերել** (մոտ 25,000 գրառում), քանի որ այն կարդում է Discord-ի հանրային հայտնաբերման ցանկը և ինքնուրույն պահպանում այն արդի վիճակում:

> [!WARNING]
> Գործարկվող խաղի կեղծումը կարող է հակասել Discord-ի Ծառայության պայմաններին, և դուք օգտագործում եք Decoy-ը **ձեր իսկ պատասխանատվությամբ**:
> Այս նախագիծը փոխկապակցված չէ, չի հաստատվել կամ կապված չէ Discord Inc.-ի հետ: Տեսեք [Հրաժարում պատասխանատվությունից](#հրաժարում-պատասխանատվությունից):

## Հատկություններ

- **Ամեն ինչ, ինչ Discord-ը կարող է հայտնաբերել:** Խաղերի ցանկը ներբեռնվում է Discord-ի հանրային հայտնաբերման հասցեից, պահվում տեղային քեշում և թարմացվում ամեն օր: Նոր խաղերը և նոր ավելացված գործարկվող ֆայլերը հայտնվում են ինքնուրույն:
- **Որոնում, որը չի զիջում:** Ակնթարթային որոնում ըստ խաղի անվան կամ գործարկվող ֆայլի հազարավոր խաղերի միջև, ցանցային կամ սեղմ ցուցակի տեսք, ընտրյալներ և «Վերջիններ» տող:
- **Մեկ սեղմումով:** Ընտրեք խաղը, ընտրեք գործարկվող ֆայլը (եթե մի քանիսն են), նշեք, թե քանի րոպե պահել այն և սեղմեք մեկնարկ: Հետհաշվարկի շրջանակը և ծանուցումը ձեզ կտեղեկացնեն, երբ ժամանակը լրանա:
- **Հետքեր չի թողնում:** Փոխարինող գործընթացը գոյություն ունի միայն աշխատելու ընթացքում. փոքրիկ exe ֆայլը ստեղծվում է մեկնարկին և ջնջվում կանգնեցնելիս: Ծրագրից դուրս գալիս ամեն ինչ կանգնեցվում է, իսկ վթարային ավարտից մնացած մնացորդները մաքրվում են հաջորդ գործարկման ժամանակ:
- **Հանգիստ:** Աշխատում է համակարգային թրեյում (tray), առանց պատուհանների կամ առաջադրանքների տողի (taskbar) կոճակների հենց իրենց՝ փոխարինող գործընթացների համար:
- **Բաց թարգմանություններ:** Ինտերֆեյսն աշխատում է պարզ JSON ֆայլերով, այնպես որ լեզու ավելացնելը կատարվում է մեկ ֆայլով: Անգլերենը և ռուսերենը ներառված են:
- **Գաղտնիություն:** Ոչ մի հաշիվ, ոչ մի Discord token, ոչ մի տելեմետրիա: Տեսեք [Գաղտնիություն](#գաղտնիություն):

## Ինչպես է այն աշխատում

1. Discord-ը որոշում է, որ դուք խաղում եք որևէ խաղ՝ ստուգելով ձեր համակարգչում աշխատող գործընթացները և համեմատելով դրանց գործարկվող ֆայլերի անունները հանրային ցանկի հետ (`/api/v9/applications/detectable`):
2. Decoy-ը ներբեռնում է այդ ցանկը և ձեր ընտրած խաղի համար պատճենում է փոքրիկ փոխարինող ծրագիր (մոտ 120 ԿԲ, գրված Rust-ով և ներկառուցված Decoy-ի մեջ) ժամանակավոր թղթապանակում՝ օգտագործելով ցանկի գործարկվող ֆայլի անունը, օրինակ՝ `.../cod26-cod.exe`:
3. Փոխարինող ծրագիրը ոչինչ չի անում, բացի մեկ վերին մակարդակի պատուհան պահելուց, որը տեղադրված է էկրանից շատ հեռու, որպեսզի դուք այն երբեք չտեսնեք: Discord-ը ճանաչում է միայն այն գործընթացները, որոնք ունեն պատուհան, ինչի պատճառով ամբողջությամբ առանց պատուհանի գործընթացներն անտեսվում են:
4. Մոտ 15 վայրկյանի ընթացքում Discord-ը ցույց է տալիս խաղը որպես ձեր ընթացիկ գործունեություն:
5. Երբ ժամանակաչափն ավարտվում է կամ սեղմում եք դադարեցնել, Decoy-ը դադարեցնում է գործընթացը և ջնջում ֆայլը: Windows job object-ը երաշխավորում է, որ փոխարինող գործընթացները փակվեն Decoy-ի հետ միասին, նույնիսկ եթե այն վթարային ավարտվի:

## Տեղադրում

Ընտրեք տարբերակներից մեկը [Թողարկումների](../../../../releases) էջից:

| Ներբեռնում | Նկարագրություն |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Տեղադրիչ (Installer):** Մեկ օգտատիրոջ համար, ադմինիստրատորի իրավունքներ չեն պահանջվում, ավելացնում է գրառում Start մենյուում և ապատեղադրիչ: |
| `Decoy_x.y.z_x64-portable.zip` | **Դյուրակիր (Portable):** Քաղեք ցանկացած վայրում և գործարկեք `decoy.exe`-ն: Բոլոր տվյալները պահվում են դրա կողքի `data` թղթապանակում, օգտատիրոջ պրոֆիլում ոչինչ չի գրվում: Հեռացնելու համար պարզապես ջնջեք թղթապանակը: |

Ստուգեք ներբեռնված ֆայլը `SHA256SUMS.txt`-ով (PowerShell-ում՝ `Get-FileHash <file>`):

Windows SmartScreen-ը կարող է զգուշացնել չճանաչված հրատարակչի մասին, քանի որ կառուցվածքները (builds) թվային ստորագրված չեն. ընտրեք *More info → Run anyway*, եթե վստահում եք հավելվածին:

Պահանջներ՝ Windows 10 կամ 11 (64-բիթ) WebView2 runtime-ով (արդեն ներառված է Windows 11-ում և Windows 10-ի վերջին թարմացումներում):

## Օգտագործում

1. Բացեք **Գրադարանը (Library)** և որոնեք խաղը, կամ սեղմեք `Ctrl` + `K` ցանկացած տեղից:
2. Սեղմեք խաղի վրա: Աջ կողմի վահանակում ընտրեք գործընթացը և քանի րոպե այն պահել (Discord-ի առաջադրանքները սովորաբար պահանջում են 15):
3. Սեղմեք **Start decoy**: Discord-ը ցույց կտա խաղը մի քանի վայրկյան անց:
4. Հետևեք դրան **Աշխատող (Running)** բաժնում, կանգնեցրեք մեկը կամ բոլորը ցանկացած պահի կամ պարզապես թողեք Decoy-ը համակարգային թրեյում:

Այն խաղերը, որոնց Discord գրառումը դեռ չունի գործարկվող ֆայլեր, լռելյայն թաքցված են (դրանք չեն կարող հայտնաբերվել): Միացրեք *Show games without exe*, դրանք տեսնելու համար. ցանկը թարմացվում է ամեն օր, ուստի դրանք հասանելի կդառնան հենց որ Discord-ն ավելացնի գործընթացը:

### Հրամանային տող

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Անմիջապես գործարկում է decoy, օրինակ՝ `decoy.exe --launch "robloxplayerbeta.exe" 15`:

## Կառուցում աղբյուրից

Նախապայմաններ՝ [Node.js](https://nodejs.org) 20+, կայուն [Rust](https://rustup.rs) գործիքակազմ (MSVC target) Visual Studio C++ build tools-ով և WebView2 runtime:

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Օգտակար ստուգումներ՝

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Նշումներ. decoy exe-ն կոմպիլացվում է `src-tauri/build.rs`-ի կողմից սովորական `rustc`-ով `src-tauri/stub/stub.rs`-ից և այնուհետև ներկառուցվում հավելվածի մեջ: Երբ ֆրոնտենդն աշխատում է սովորական բրաուզերում (`npm run dev`), օգտագործվում է փոքր mock backend (`src/mock.ts`), ինչը հարմար է միջերեսի վրա աշխատելիս:

## Թարգմանություններ

Միջերեսի տողերը գտնվում են [`src/locales`](../../src/locales) պանակում՝ մեկական JSON ֆայլ յուրաքանչյուր լեզվի համար (`en.json`, `ru.json`, ...):
Լեզու ավելացնելը նշանակում է ֆայլ ավելացնել. կոդի փոփոխություններ պետք չեն: Ֆայլի ձևաչափի, մեքենայական թարգմանության պատրաստի հուշման և վավերացման սկրիպտի համար տեսեք [docs/TRANSLATING.md](../TRANSLATING.md): Այս README-ի թարգմանությունները պահվում են `docs/i18n/README.<code>.md`-ում:

## Նախագծի կառուցվածքը

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Գաղտնիություն

- Decoy-ն օգտագործում է ցանցը միայն Discord-ի հանրային հայտնաբերման ցանկը ներբեռնելու համար (առաջին մեկնարկի ժամանակ, այնուհետև օրական առավելագույնը մեկ անգամ կամ երբ սեղմում եք թարմացնել) և Discord-ի հանրային CDN-ից խաղերի պատկերակներն ու նկարները ցուցադրելու համար:
- Այն չի կարդում, չի պահում կամ ուղարկում ձեր Discord token-ը կամ հաշվի որևէ տվյալ և չի շփվում Discord հավելվածի (client) հետ:
- Կարգավորումները (ընտրյալներ, լեզու, տևողություններ) պահվում են տեղում՝ հավելվածի WebView պահեստում. խաղերի ցանկի քեշը և ժամանակավոր decoy ֆայլերը գտնվում են `%LOCALAPPDATA%\app.decoy.desktop`-ում:
- Ոչ մի վերլուծություն, ոչ մի վթարային հաշվետվություն, ոչ մի հաշիվ:

## Հայտնի սահմանափակումներ

- Discord-ը կարող է ցանկացած պահի փոխել հայտնաբերման աշխատանքի ձևը: Եթե decoy-ը դադարի ճանաչվել, խնդրում ենք բացել issue:
- Որոշ գործողությունների համար անհրաժեշտ է ավելին, քան պարզապես աշխատող գործընթացը (օրինակ՝ խաղային հարթակի կոնկրետ ռեժիմում գտնվելը): Decoy-ը միայն նմանակում է գործընթացը:
- Discord-ի ցանկում առանց գործարկվող ֆայլերի գրառումները չեն կարող հայտնաբերվել:
- Անվտանգության ծրագրերը երբեմն կասկածելի են համարում հիշողության մեջ պարապուրդի մատնված փոքր չստորագրված գործարկվող ֆայլերը: Decoy-ը բաց կոդով է և ստեղծված է `src-tauri/stub/stub.rs`-ից. դուք կարող եք այն կոմպիլացնել ինքներդ:

## Մասնակցություն նախագծին

Սխալների մասին հաշվետվությունները, գաղափարները և թարգմանությունները ողջունվում են: Խնդրում ենք նախ կարդալ [CONTRIBUTING.md](../../CONTRIBUTING.md):

Decoy-ը տրամադրվում է «ինչպես որ կա» անձնական, կրթական և թեստավորման նպատակներով: Գործարկվող խաղի նմանակումը կարող է խախտել Discord-ի կամ խաղի հրատարակչի Ծառայության պայմանները և կարող է հանգեցնել ձեր հաշվի նկատմամբ միջոցների կիրառման: Դուք միանձնյա եք պատասխանատու այն օգտագործելու եղանակի համար: «Discord»-ը և խաղերի բոլոր անվանումներն ու լոգոները համապատասխան սեփականատերերի ապրանքային նշաններն են և այստեղ օգտագործվում են միայն այն ծրագրակազմը նույնականացնելու համար, որին դրանք վերաբերում են:
