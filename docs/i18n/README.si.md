Decoy මඟින් ක්‍රීඩාවක ක්‍රියාත්මක කළ හැකි ගොනු නාමය (executable name) යටතේ හානිකර නොවන, කවුළුවක් සහිත ආදේශක ක්‍රියාවලියක් ධාවනය කර තබයි. එවිට Discord හි ක්‍රීඩා හඳුනාගැනීමේ පද්ධතිය ඔබ එම ක්‍රීඩාව ක්‍රීඩා කරන බව පෙන්වයි. ඔබට සැබෑ ක්‍රීඩාව ස්ථාපනය කිරීමට හෝ ආරම්භ කිරීමට අවශ්‍ය නොවන බැවින්, ඔබගේ ඩිස්ක් මත විශාල ඉඩක් වැය නොවේ.

Discord හි තමන්ගේම පොදු හඳුනාගැනීමේ ලැයිස්තුව කියවා එය ස්වයංක්‍රීයව යාවත්කාලීනව තබා ගන්නා බැවින්, **Discord හට හඳුනාගත හැකි සෑම ක්‍රීඩාවක්ම** (වාර්තා 25,000 ක් පමණ) මෙය හඳුනයි.

## විශේෂාංග

- **Discord හට හඳුනාගත හැකි සෑම දෙයක්ම.** ක්‍රීඩා ලැයිස්තුව Discord හි පොදු හඳුනාගැනීමේ endpoint එකෙන් බාගත කර, දේශීයව හැඹිලිගත (cached) කර දිනපතා යාවත්කාලීන කෙරේ. නව ක්‍රීඩා සහ අලුතින් එක් කරන ලද executables ස්වයංක්‍රීයවම දිස්වේ.
- **වේගවත් සෙවුම.** ක්‍රීඩා දහස් ගණනක් අතරින් ක්‍රීඩාවේ නම හෝ executable මඟින් ක්ෂණික සෙවීම, කොටු (grid) හෝ සංයුක්ත ලැයිස්තු දසුන, ප්‍රියතමයන් සහ "මෑතකාලීන" පේළිය.
- **එක් ක්ලික් කිරීමකින්.** ක්‍රීඩාවක් තෝරන්න, executable එක තෝරන්න (කිහිපයක් තිබේ නම්), එය කොපමණ වේලාවක් තබා ගත යුතුද යන්න තෝරා ආරම්භ කරන්න ඔබන්න. ගණන් කිරීමේ වළල්ලක් සහ දැනුම්දීමක් මඟින් කාලය අවසන් වූ විට ඔබට දන්වනු ඇත.
- **කිසිදු අපද්‍රව්‍යයක් ඉතිරි නොකරයි.** Decoy පවතින්නේ එය ධාවනය වන තුරු පමණි: ආරම්භයේදී කුඩා exe ගොනුව සාදනු ලබන අතර නැවැත්වූ විට මකා දමනු ලැබේ. ඔබ ඉවත් වූ විට සියල්ල නතර වන අතර, යෙදුම බිඳවැටීමකින් පසු ඉතිරි වන දේ ඊළඟ ආරම්භයේදී ඉවත් කරනු ලැබේ.
- **නිහඬයි.** System tray එකේ පවතී, decoys සඳහා කවුළු හෝ taskbar බොත්තම් නොමැත.

3. මෙම ආදේශක වැඩසටහන ඔබට කිසිදා නොපෙනෙන පරිදි තිරයෙන් බොහෝ ඈතින් ස්ථානගත කර ඇති එක් ප්‍රධාන කවුළුවක් (top-level window) තබා ගැනීම හැර අන් කිසිවක් නොකරයි. Discord හඳුනාගන්නේ කවුළුවක් හිමි ක්‍රියාවලියක් පමණක් වන අතර, සම්පූර්ණයෙන්ම කවුළුවක් රහිත ක්‍රියාවලියක් නොසලකා හරිනු ලබන්නේ එබැවිනි.

## භාවිතය

1. **පුස්තකාලය** විවෘත කර ක්‍රීඩාවක් සොයන්න, නැතහොත් ඕනෑම තැනක සිට `Ctrl` + `K` ඔබන්න.
2. ක්‍රීඩාවක් මත ක්ලික් කරන්න. දකුණු පස ඇති පැනලයෙන් ක්‍රියාවලිය සහ එය කොපමණ මිනිත්තු ගණනක් තබා ගත යුතුද යන්න තෝරන්න (Discord ක්‍රියාකාරකම් සාමාන්‍යයෙන් මිනිත්තු 15 ක් ඉල්ලයි).
3. **Decoy අරඹන්න** ඔබන්න. තත්පර කිහිපයකට පසු Discord විසින් ක්‍රීඩාව පෙන්වනු ඇත.
4. **ධාවනය වන** යටතේ එය නිරීක්ෂණය කරන්න, ඕනෑම වේලාවක එකක් හෝ සියල්ල නවත්වන්න, නැතහොත් Decoy ට්‍රේ (tray) එකේ තබන්න.

Discord ලැයිස්තුවේ තවමත් executables නොමැති ක්‍රීඩා පෙරනිමියෙන් සඟවා ඇත (ඒවා හඳුනාගත නොහැක). ඒවා බැලීමට *exe නොමැති ක්‍රීඩා පෙන්වන්න* සක්‍රීය කරන්න; ලැයිස්තුව දිනපතා නැවුම් වන බැවින්, Discord ක්‍රියාවලියක් එක් කළ වහාම ඒවා ලබා ගත හැකි වනු ඇත.

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

වහාම decoy එකක් අරඹයි, උදාහරණයක් ලෙස `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## මූලාශ්‍රයෙන් Build කිරීම

පූර්වාවශ්‍යතා: [Node.js](https://nodejs.org) 20+, Visual Studio C++ build tools සමඟ ස්ථාවර [Rust](https://rustup.rs) toolchain (MSVC target), සහ WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload සමඟ සංවර්ධන මාදිලියේ ධාවනය කරන්න
npm run tauri build    # src-tauri/target/release/bundle/nsis තුළ ස්ථාපකය නිෂ්පාදනය කරන්න
```

ප්‍රයෝජනවත් පරීක්ෂාවන්:

```bash
npm run check-locales  # ru.json වලට එරෙහිව සෑම පරිවර්තන ගොනුවක්ම වලංගු කරන්න
npx tsc --noEmit       # frontend හි වර්ග (types) පරීක්ෂා කරන්න
cargo check --manifest-path src-tauri/Cargo.toml
```

සටහන්: decoy exe ගොනුව `src-tauri/stub/stub.rs` වෙතින් සාමාන්‍ය `rustc` සමඟ `src-tauri/build.rs` මඟින් සම්පාදනය කර යෙදුම තුළ කාවැද්දේ. Frontend සාමාන්‍ය බ්‍රවුසරයක ධාවනය වන විට (`npm run dev`) කුඩා mock පසුබිමක් (`src/mock.ts`) භාවිතා වන අතර එය UI මත වැඩ කිරීමට පහසු වේ.

## පරිවර්තන

UI වැකි [`src/locales`](../../src/locales) හි එක් භාෂාවකට එක් JSON ගොනුවක් ලෙස පවතී (`en.json`, `ru.json`, ...). භාෂාවක් එකතු කිරීම යනු ගොනුවක් එක් කිරීමයි; කේත වෙනස් කිරීම් නැත. ගොනු ආකෘතිය, යන්ත්‍ර පරිවර්තනය සඳහා භාවිතයට සූදානම් prompt එකක් සහ වලංගු කිරීමේ ස්ක්‍රිප්ටය සඳහා [docs/TRANSLATING.md](../TRANSLATING.md) බලන්න. මෙම README හි පරිවර්තන `docs/i18n/README.<code>.md` වෙත යයි.
