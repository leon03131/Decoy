# Decoy

**Discord'го оюн иштеп жаткандай көрсөтүүчү чакан жалган процесстер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Акыркы оюндары жана мукабалары бар Decoy китепканасы" />

</div>

Decoy оюндун аткарылуучу файлынын аты менен зыянсыз, терезеси бар жалган процессти иштетип турат, ошондуктан Discord'дун оюн аныктоо тутуму сизди ошол оюнду ойноп жатат деп эсептейт. Чыныгы оюнду орнотуунун же иштетүүнүн кереги жок, дискте эч кандай чоң көлөмдөгү нерсе сакталбайт.

Ал **Discord аныктай алган бардык оюндарды** билет (болжол менен 25 000 жазуу), анткени ал Discord'дун өзүнүн ачык аныктоо тизмесин окуйт жана аны өз алдынча жаңыртып турат.

> [!WARNING]
> Оюнду жалган иштетип көрсөтүү Discord'дун Тейлөө шарттарына каршы келиши мүмкүн жана Decoy'ду **өз тобокелиңиз менен** колдоносуз.
> Бул долбоор Discord Inc. компаниясы менен байланышы жок, жактырылган эмес же ага тиешеси жок. [Жоопкерчиликтен баш тартуу](#жоопкерчиликтен-баш-тартуу) бөлүмүн караңыз.

## Мүмкүнчүлүктөр

- **Discord аныктай алган нерселердин баары.** Оюндар тизмеси Discord'дун ачык аныктоо түйүнүнөн жүктөлүп алынат, жергиликтүү кэштелет жана күн сайын жаңыртылат. Жаңы оюндар жана жаңы кошулган аткарылуучу файлдар өзүнөн-өзү пайда болот.
- **Ыкчам издөө.** Миңдеген оюндар боюнча оюндун аты же аткарылуучу файлы аркылуу көз ачып жумганча издөө, торчо же чакан тизме көрүнүшү, тандалмалар жана «Акыркылар» сабы.
- **Бир чыкылдатуу.** Оюнду тандаңыз, аткарылуучу файлды тандаңыз (бир нече болсо), канча убакытка кармап туруу керектигин белгилеп, баштоону басыңыз. Артка саноо шакекчеси жана билдирүү убакыт бүткөнүн кабарлайт.
- **Артынан из калтырбайт.** Decoy иштеп жаткан учурда гана болот: чакан exe баштаганда түзүлөт жана токтоткондо өчүрүлөт. Чыкканыңызда баары токтотулат, ал эми күтүүсүз авариялык жабылуудан калган калдыктар кийинки ишке киргизүүдө тазаланат.
- **Тынч.** Тутумдук лотокто (трейде) жайгашат, жалган процесстердин өздөрүнүн терезелери же тапшырмалар тилкесинде баскычтары болбойт.
- **Ачык котормолор.** Интерфейс жөнөкөй JSON файлдары аркылуу башкарылат, ошондуктан жаңы тилди кошуу болгону бир эле файлды түзүү менен бүтөт. Англис жана орус тилдери камтылган.
- **Купуялуулук.** Эсептик жазуу жок, Discord токени жок, телеметрия жок. [Купуялуулук](#купуялуулук) бөлүмүн караңыз.

## Кантип иштейт

1. Discord сиздин компьютериңизде иштеп жаткан процесстерди карап чыгып, алардын аткарылуучу файл аталыштарын ачык тизме менен (`/api/v9/applications/detectable`) салыштыруу аркылуу оюн ойноп жатканыңызды аныктайт.
2. Decoy ошол тизмени жүктөп алат жана сиз тандаган оюн үчүн тизмедеги аткарылуучу файл атын колдонуп (мисалы, `.../cod26-cod.exe`), убактылуу папкага чакан программа-орунбасарды (болжол менен 120 КБ, Rust тилинде жазылган жана Decoy ичине камтылган) көчүрөт.
3. Программа-орунбасар сиз эч качан көрбөгүдөй экрандан сырткары алыс жайгаштырылган бир гана жогорку деңгээлдеги терезеге ээ болуудан башка эч нерсе кылбайт. Discord терезеси бар процессти гана тааныйт, ошондуктан толугу менен терезесиз процесс четке кагылат.
4. Болжол менен 15 секунд ичинде Discord оюнду сиздин учурдагы аракетиңиз катары көрсөтөт.
5. Таймер бүткөндө же токтотууну басканыңызда, Decoy процессти аяктайт жана файлды өчүрөт. Windows'дун job объекти Decoy күтүүсүздөн бузулуп жабылса дагы, decoy'лордун Decoy менен чогуу токтотулушун камсыздайт.

## Орнотуу

[Releases](../../../../releases) бетинен бирин тандап алыңыз:

| Жүктөп алуу | Арналышы |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Орноткуч.** Ар бир колдонуучу үчүн, администратор укуктары талап кылынбайт, «Баштоо» (Start) менюсуна жазуу жана өчүргүч кошот. |
| `Decoy_x.y.z_x64-portable.zip` | **Портативдүү.** Каалаган жерге чыгарып алып, `decoy.exe` иштетиңиз. Бардык дайындар жанындагы `data` папкасында сакталат, колдонуучунун профилине эч нерсе жазылбайт. Жок кылуу үчүн папканы өчүрүп салуу жетиштүү. |

Жүктөлүп алынган файлды `SHA256SUMS.txt` аркылуу текшериңиз (PowerShell ичинде `Get-FileHash <файл>`).

Windows SmartScreen түзүлүштөрдүн санариптик кол тамгасы жок болгондуктан белгисиз басып чыгаруучу жөнүндө эскертиши мүмкүн; эгер түзүлүшкө ишенсеңиз, *Кененирээк (More info) → Баары бир иштетүү (Run anyway)* тандаңыз.

Талаптар: WebView2 runtime бар Windows 10 же 11 (64 биттик) (Windows 11 жана соңку Windows 10 жаңыртууларында мурунтан эле камтылган).

## Колдонуу

1. **Китепкананы** ачып, оюнду издеңиз же каалаган жерден `Ctrl` + `K` басыңыз.
2. Оюнду басыңыз. Оң жактагы тилкеде процессти жана аны канча мүнөт кармап туруу керектигин тандаңыз (Discord тапшырмалары көбүнчө 15 мүнөт талап кылат).
3. **Decoy иштетүү** баскычын басыңыз. Discord бир нече секунддан кийин оюнду көрсөтөт.
4. Аны **Иштеп жаткандар** бөлүмүнөн көзөмөлдөңүз, каалаган убакта бирин же баарын токтотуңуз же жөн гана Decoy'ду трейде калтырып коюңуз.

Discord жазуусунда аткарылуучу файлдары жок оюндар баштапкы абалында жашырылган (аларды аныктоо мүмкүн эмес). Аларды көрүү үчүн *exe жок оюндарды көрсөтүү* опциясын күйгүзүңүз; тизме күн сайын жаңырып турат, андыктан Discord процесс кошору менен алар жеткиликтүү болот.

### Буйрук сабы

```
decoy.exe --launch "<Discord тизмесиндеги аткарылуучу файл жолу>" [мүнөт]
```

Жалган процессти дароо иштетет, мисалы `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Баштапкы коддон куруу

Алдын ала талаптар: [Node.js](https://nodejs.org) 20+, Visual Studio C++ куруу куралдары бар туруктуу [Rust](https://rustup.rs) инструменттер топтому (MSVC target) жана WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # өзгөртүүлөрдү дароо чагылдыруу (hot reload) менен иштеп чыгуу режиминде иштетүү
npm run tauri build    # src-tauri/target/release/bundle/nsis ичинде орноткучту түзүү
```

Пайдалуу текшерүүлөр:

```bash
npm run check-locales  # ар бир котормо файлын ru.json файлына салыштырып текшерүү
npx tsc --noEmit       # фронтенд типтерин текшерүү
cargo check --manifest-path src-tauri/Cargo.toml
```

Эскертүүлөр: decoy exe файлы `src-tauri/build.rs` аркылуу `src-tauri/stub/stub.rs` кодунан жөнөкөй `rustc` жардамы менен компиляцияланат жана колдонмонун ичине камтылат. Фронтенд кадимки браузерде иштетилгенде (`npm run dev`), интерфейс менен иштөөгө ыңгайлуу болгон чакан мок-бэкенд (`src/mock.ts`) колдонулат.

## Котормолор

Интерфейс саптары [`src/locales`](../../src/locales) ичинде сакталат, ар бир тил үчүн бирден JSON файл (`en.json`, `ru.json`, ...).
Тилди кошуу жаңы файл кошуу дегенди билдирет; кодго өзгөртүү киргизүүнүн кажети жок. Файлдын форматы, машиналык котормо үчүн даяр промпт жана текшерүү скрипти боюнча [docs/TRANSLATING.md](../TRANSLATING.md) файлын караңыз. Бул README файлынын котормолору `docs/i18n/README.<code>.md` ичине жайгаштырылат.

## Купуялуулук

- Decoy тармакты Discord'дун ачык аныктоо тизмесин жүктөп алуу үчүн гана (биринчи иштеткенде, андан кийин күнүнө эң көп дегенде бир жолу же жаңыртууну басканда) жана оюн сүрөтчөлөрү менен мукабаларын көрсөтүү үчүн Discord'дун ачык CDN'инен жүктөп алуу үчүн гана колдонот.
- Ал сиздин Discord токениңизди же эсептик жазуу дайындарыңызды окубайт, сактабайт же жөнөтпөйт, ошондой эле Discord кардары менен байланышпайт.
- Ырастоолор (тандалмалар, тил, мөөнөттөр) колдонмонун WebView сактагычында жергиликтүү түрдө сакталат; оюн тизмесинин кэши жана убактылуу decoy файлдары `%LOCALAPPDATA%\app.decoy.desktop` ичинде болот.
- Аналитика, бузулуулар тууралуу отчеттор, эсептик жазуулар жок.

## Белгилүү чектөөлөр

- Discord оюнду аныктоо ишин каалаган убакта өзгөртө алат. Эгерде decoy таанылбай калса, сураныч, issue ачыңыз.
- Кээ бир аракеттер жөн гана иштеп жаткан процесстен көбүрөөк нерсени талап кылат (мисалы, оюн платформасынын белгилүү бир режиминде же тажрыйбасында болуу). Decoy процессти гана туурайт.
- Discord тизмесинде аткарылуучу файлдары жок жазуулар аныкталбайт.
- Коопсуздук программалары эстутумда бош турган санариптик кол тамгасы жок чакан аткарылуучу файлдарды кээде шектүү деп белгилеши мүмкүн. Decoy ачык баштапкы коддуу жана `src-tauri/stub/stub.rs` файлынан куралган; аны өзүңүз компиляциялап алсаңыз болот.

## Салым кошуу

Каталар тууралуу билдирүүлөр, идеялар жана котормолор кубануу менен кабыл алынат. Сураныч, адегенде [CONTRIBUTING.md](../../CONTRIBUTING.md) файлын окуп чыгыңыз.

## Жоопкерчиликтен баш тартуу

Decoy жеке, билим берүү жана сыноо максаттары үчүн "кандай болсо ошондой" берилет. Иштеп жаткан оюнду жалган тууроо Discord'дун же оюн чыгаруучунун Тейлөө шарттарын бузушу мүмкүн жана сиздин аккаунтуңузга каршы чаралардын көрүлүшүнө алып келиши мүмкүн. Аны кандайча колдоноруңузга өзүңүз гана жооптуусуз. "Discord" жана бардык оюндардын аталыштары менен логотиптери алардын тиешелүү ээлеринин соода белгилери болуп саналат жана бул жерде алар шилтеме кылган программалык камсыздоону аныктоо үчүн гана колдонулат.
