# Decoy

**Môłé zastãpczé procesë, bez chtërné Discord mësli, że gra dzejô.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteka Decoy ze slédnyma grama i grafikama" />

</div>

Decoy trzëmô bezpieczny, zastãpczy proces z òknã pòd mionã wëkònywalnégò lopka grë, bez co system wëkriwaniô grów w Discordze pòdôwô, że w tã grã grajesz. Nigdë nie mùszisz instalowac ani zrëszac prôwdzëwi grë, temù nic wiôldżégò nie leżi na Twòjim disczi.

Znaje **kòżdą grã, jaką Discord mòże wëkric** (kòl 25 000 wpisów), bò czëtô pùbliczną lëstã wëkriwaniô samégò Discorda i samòstójnie dbô ò ji aktualnosc.

> [!WARNING]
> Falszowanié zrëszony grë mòże naruszac Prawidła ùżiwaniô Discorda i brëkùjesz Decoy **na swòją òdpòwiédzalnosc**.
> Nen projekt nie je sparłãczony z Discord Inc., przez nich wspiéróny ani zrzeszony. Zdrzë [Zrzeczenié sã òdpòwiédzalnoscë](#zrzeczenié-sã-òdpòwiédzalnoscë).

## Fùnkcëje

- **Wszëtkò, co Discord mòże wëkric.** Lësta grów je zladëwónô z pùblicznégò pùnktu kùńca Discorda, bùforowónô môlowò i òdswieżanô codzéń. Nowé grë i nowò dodóné wëkònywalné lopczi pòkazywają sã same.
- **Szëkôczka, co dëcht nadążô.** Chùtczé szëkanié pò mionie grë abò lopkù exe westrzód tësąców grów, widok kaflów abò zwiãzły lëstë, lubòtné i réga „Slédné”.
- **Jedno klëkniãcé.** Wëbiérzë grã, wëbiérzë wëkònywalny lopk (jeżlë je jich cziles), òpiszë jak długò gò trzëmac i klëkni zrëszë. Kòło òdliczaniô i wiadło pòpòwiédzą Cë, cziej czas dobiegnie kùńca.
- **Nie òstawiô nic pò se.** Decoy bëtnikùje le tedë, cziej dzejô: môłi lopk exe je twòrzony przë zrëszeniu i wëwalóny przë zatrzëmaniu. Wszëtkò je zatrzimóné przë wëłączeniu, a pòòstałoscë pò awarii są sprzątóné przë nôslédnym zrëszeniu.
- **Cëchi.** Żëje w systemòwi tacce, niżódnëch òcen ani knapów na lëstwie dzejaniów dlô samëch decoyów.
- **Òtemkłé dolmaczeniô.** Interfejs je òpiarti na prostëch lopkach JSON, temù dodanié jãzëka to le jeden lopk. Jãzëk anielsczi i rusczi są w zestôwù.
- **Priwatnosc.** Bez kònta, bez tokena Discorda, bez telemetrii. Zdrzë [Priwatnosc](#priwatnosc).

## Jak to dzejô

1. Discord decyduje, że grajesz w grã, sprôwdzając procesë zrëszoné na Twòjim kòmpùtrze i przërównywając miona jich wëkònywalnëch lopków z pùbliczną lëstą (`/api/v9/applications/detectable`).
2. Decoy zladëwô tã lëstã i dlô wëbróny przez Cebe grë kòpiëje môłi zastãpczy program (kòl 120 KB, napisóny w Rust i wbùdowóny w Decoy) do timczasowégò kùfra, dając jemù miono wëkònywalnégò lopka z lëstë, na przëkład `.../cod26-cod.exe`.
3. Zastãpczy program nie robi nic òkróm trzëmaniô jednégò òkna nôwëższégò pòzdrzatkù, zaparkòwónégò dalek za ekranã, bë nigdë gò nie bëło widzec. Discord pòznôwô blós procesë mającé òkno, temù proces całkòwice bez òkna je òmijóny.
4. W czasu kòl 15 sekùnd Discord pòkazywô grã jakno Twòją biezëcną aktiwnosc.
5. Cziej czas minie abò klëkniesz zatrzëmôj, Decoy kùńczy proces i wëwôlô lopk. Òbiekt zleceniô Windows (job object) dba ò to, bë decoyë kùńczyłë dzejanié do grëpë z Decoy, nawetka jeżlë aplikacëjô padnie.

## Instalacëjô

Wëbiérzë jedną z wersëjów na starnie [Releases](../../../../releases):

| Zladënk | Dlô kògò |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalator.** Dlô pòjedinczégò brëkòwnika, nie brëkùje prôw administratora, dodôwô wpis w menu Start i program do wëinstalowaniô. |
| `Decoy_x.y.z_x64-portable.zip` | **Wersëjô przenośnô (portable).** Rozpakùjë gdzekòlwiek i zrëszë `decoy.exe`. Wszëtczé pòdôwczi òstôwają w kùfrze `data` kòl programu, nic nie je zapisëwóné w profilu brëkòwnika. Bë wëwalëc program, pò prostu skasëjë kùfer. |

Sprôwdzë zladóny lopk przez `SHA256SUMS.txt` (`Get-FileHash <file>` w PowerShellu).

Windows SmartScreen mòże wëskrzenioc òstrzega ò nieznónym wëdôwcë, bò kòmpilacëje nie mają cyfrowégò pòdpisënkù; wëbiérzë *Wicy wëdowiédzë → Zrëszë mimo to*, jeżlë ùfôsz ti kòmpilacëji.

Wëmôgania: Windows 10 abò 11 (64-bit) ze strzodowiskã WebView2 (ju zawarté w Windows 11 i nowszich aktualizacëjach Windows 10).

## Ùżëcé

1. Òtemkni **Bibliotekã** i szëkôj grë, abò wcësni `Ctrl` + `K` z kòżdégò môla.
2. Klëkni grã. W panelu pò prawi starnie wëbiérzë proces i wiela minutów gò trzëmac (misje Discorda zazwëczaj brëkùją 15).
3. Klëkni **Zrëszë decoy**. Discord pòkôże grã pò czile sekùndach.
4. Òbzérôj gò w kôrce **Zrëszoné**, zatrzëmôj jeden abò wszëtczé w kòżdi chwili, abò pò prostu òstawi Decoy w tacce.

Grë, chtërnëch wpis w Discordze nie mô jeszcze wëkònywalnëch lopków, są domëslno schòwóné (nie mògą bëc wëkrite). Włączë *Pòkôżë grë bez exe*, bë je widzec; lësta je òdswieżanô codzéń, temù stóną sã przëstãpné, cziej le Discord dodô proces.

### Linijô pòléceniów

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Zrëszywô decoy òd razu, na przëkład `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kòmpilacëjô ze zdrojów

Wëmôgania: [Node.js](https://nodejs.org) 20+, stabilny zestaw nôrzãdzów [Rust](https://rustup.rs) (cel MSVC) z nôrzãdzama kòmpilacëji C++ Visual Studio i strzodowiskò WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Pòżëteczné sprôwdzenia:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Wiadła: lopk exe decoya je kòmpilowóny przez `src-tauri/build.rs` ze zwëczajnégò `rustc` z lopka `src-tauri/stub/stub.rs` i pòtemkù wbùdowiwóny w aplikacëjã. Cziej frontend dzejô w zwëczajny przezérnikù (`npm run dev`), ùżiwóny je môłi zastãpczy backend (`src/mock.ts`), co pòmôgô w robòce nad interfejsã.

## Dolmaczeniô

Napisë interfejsu leżą w [`src/locales`](../../src/locales), pò jednym lopkù JSON na jãzëk (`en.json`, `ru.json`, ...). Dodanié jãzëka òznôczô dodanié lopka; niżódnëch zmianów w kòdze. Zdrzë [docs/TRANSLATING.md](../TRANSLATING.md), bë pòznac fòrmat lopka, parôt prompt do maszinowégò dolmaczeniô i skript walidacëji. Dolmaczeniô negò README idą do `docs/i18n/README.<code>.md`.

## Ùstôw projektu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Priwatnosc

- Decoy ùżëwô sécë le do zladënkù pùbliczny lëstë wëkriwaniô Discorda (przë pierszim zrëszeniu, a pòtemkù nôwëżi rôz na dzéń abò pò wësëpaniu òdswieżaniô) i do wëskrzenianiô ikònów i grafik grów z pùblicznégò CDN Discorda.
- Nie czëtô, nie trzëmô ani nie wësëłô Twòjégò tokena Discorda ani niżódnëch pòdôwków kònta, i nie kòmùnikùje sã z klientã Discorda.
- Nastôwë (lubòtné, jãzëk, cządë trzëmaniô) są zapisëwóné môlowò w magazynie WebView aplikacëji; bùfor lëstë grów i timczasowé lopczi decoyów leżą w `%LOCALAPPDATA%\app.decoy.desktop`.
- Niżódny analitëczi, niżódnégò rapòrtowaniô awariów, bez kòntów.

## Znóné ògrańczeniô

- Discord mòże w kòżdi chwili zmienic ôrt wëkriwaniô. Jeżlë decoy przestanié bëc rozpòznôwóny, prosymë ò zgłoszenié problemù (issue).
- Niechtërné aktiwnoscë brëkùją wicy jak zrëszonégò procesu (na przëkład bëcégò w kònkretnym swiece platformë grë). Decoy imitëje blós proces.
- Wpisë bez wëkònywalnëch lopków w lëscie Discorda nie mògą bëc wëkrite.
- Programë bezpiekù czasã òznaczają môłé, niepòdpisóné lopczi exe, chtërné sedzą bezczënno w pamiãcë. Decoy je òtemkłozdrójny i bùdowóny z `src-tauri/stub/stub.rs`; mòżesz gò skòmpilowac samòstójnie.

## Zrzeczenié sã òdpòwiédzalnoscë

Decoy je dôwóny „tak jak je” do priwatnëch, edukacëjnëch i testowëch célów. Falszowanié zrëszony grë mòże naruszac Prawidła ùżiwaniô Discorda abò wëdôwcë grë i mòże prowadzëc do sankcjów procëm Twòjemù kòntu. Blós Të pònosisz òdpòwiédzalnosc za to, jak gò brëkùjesz. „Discord” i wszëtczé miona grów oraz loga są znakama towarowyma swòjich prawowitëch pòsadników i są tu ùżëté blós do identyfikacëji softwaru, do chtërnégò sã tikają.
