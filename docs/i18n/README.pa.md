# Decoy

**ਛੋਟੇ ਸਟੈਂਡ-ਇਨ ਪ੍ਰੋਸੈਸ ਜੋ Discord ਨੂੰ ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ ਕੋਈ ਗੇਮ ਚੱਲ ਰਹੀ ਹੈ।**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="ਹਾਲੀਆ ਗੇਮਾਂ ਅਤੇ ਆਰਟਵਰਕ ਨਾਲ Decoy ਲਾਇਬ੍ਰੇਰੀ" />

</div>

Decoy ਕਿਸੇ ਗੇਮ ਦੇ executable ਨਾਮ ਹੇਠ ਇੱਕ ਨੁਕਸਾਨ-ਰਹਿਤ, ਵਿੰਡੋ ਵਾਲਾ ਪਲੇਸਹੋਲਡਰ ਪ੍ਰੋਸੈਸ ਚਾਲੂ ਰੱਖਦਾ ਹੈ, ਤਾਂ ਜੋ Discord ਦਾ ਗੇਮ ਡਿਟੈਕਸ਼ਨ ਤੁਹਾਨੂੰ ਉਹ ਗੇਮ ਖੇਡਦੇ ਹੋਏ ਦਿਖਾਏ। ਤੁਹਾਨੂੰ ਕਦੇ ਵੀ ਅਸਲ ਗੇਮ ਨੂੰ ਇੰਸਟਾਲ ਜਾਂ ਲਾਂਚ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੁੰਦੀ, ਇਸ ਲਈ ਤੁਹਾਡੀ ਡਿਸਕ 'ਤੇ ਕੁਝ ਵੀ ਵੱਡਾ ਨਹੀਂ ਰਹਿੰਦਾ।

ਇਹ **ਹਰ ਉਸ ਗੇਮ ਬਾਰੇ ਜਾਣਦਾ ਹੈ ਜਿਸਨੂੰ Discord ਡਿਟੈਕਟ ਕਰ ਸਕਦਾ ਹੈ** (ਲਗਭਗ 25,000 ਐਂਟਰੀਆਂ) ਕਿਉਂਕਿ ਇਹ Discord ਦੀ ਆਪਣੀ ਜਨਤਕ ਡਿਟੈਕਸ਼ਨ ਸੂਚੀ ਪੜ੍ਹਦਾ ਹੈ ਅਤੇ ਇਸਨੂੰ ਆਪਣੇ ਆਪ ਅੱਪ-ਟੂ-ਡੇਟ ਰੱਖਦਾ ਹੈ।

> [!WARNING]
> ਚੱਲ ਰਹੀ ਗੇਮ ਦਾ ਦਿਖਾਵਾ ਕਰਨਾ Discord ਦੀਆਂ ਸੇਵਾ ਸ਼ਰਤਾਂ (Terms of Service) ਦੇ ਵਿਰੁੱਧ ਹੋ ਸਕਦਾ ਹੈ ਅਤੇ ਤੁਸੀਂ Decoy ਦੀ ਵਰਤੋਂ **ਆਪਣੇ ਜੋਖਮ 'ਤੇ** ਕਰਦੇ ਹੋ।
> ਇਹ ਪ੍ਰੋਜੈਕਟ Discord Inc. ਨਾਲ ਸੰਬੰਧਿਤ, ਸਮਰਥਿਤ ਜਾਂ ਜੁੜਿਆ ਹੋਇਆ ਨਹੀਂ ਹੈ। [ਬੇਦਾਅਵਾ](#ਬੇਦਾਅਵਾ) ਵੇਖੋ।

## ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- **ਸਭ ਕੁਝ ਜੋ Discord ਡਿਟੈਕਟ ਕਰ ਸਕਦਾ ਹੈ।** ਗੇਮਾਂ ਦੀ ਸੂਚੀ Discord ਦੇ ਜਨਤਕ ਡਿਟੈਕਸ਼ਨ ਐਂਡਪੁਆਇੰਟ ਤੋਂ ਡਾਊਨਲੋਡ ਕੀਤੀ ਜਾਂਦੀ ਹੈ, ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਕੈਸ਼ ਕੀਤੀ ਜਾਂਦੀ ਹੈ ਅਤੇ ਰੋਜ਼ਾਨਾ ਰਿਫ੍ਰੈਸ਼ ਹੁੰਦੀ ਹੈ। ਨਵੀਆਂ ਗੇਮਾਂ ਅਤੇ ਨਵੀਆਂ ਸ਼ਾਮਲ ਕੀਤੀਆਂ executables ਆਪਣੇ ਆਪ ਦਿਖਾਈ ਦਿੰਦੀਆਂ ਹਨ।
- **ਤੇਜ਼ ਖੋਜ।** ਹਜ਼ਾਰਾਂ ਗੇਮਾਂ ਵਿੱਚ ਗੇਮ ਦੇ ਨਾਮ ਜਾਂ executable ਰਾਹੀਂ ਤੁਰੰਤ ਖੋਜ, ਗਰਿੱਡ ਜਾਂ ਸੰਖੇਪ ਸੂਚੀ ਦ੍ਰਿਸ਼, ਮਨਪਸੰਦ ਅਤੇ ਇੱਕ "Recent" ਕਤਾਰ।
- **ਇੱਕ ਕਲਿੱਕ।** ਕੋਈ ਗੇਮ ਚੁਣੋ, executable ਚੁਣੋ (ਜੇਕਰ ਕਈ ਹੋਣ), ਚੁਣੋ ਕਿ ਇਸਨੂੰ ਕਿੰਨੀ ਦੇਰ ਤੱਕ ਰੱਖਣਾ ਹੈ ਅਤੇ ਸਟਾਰਟ ਦਬਾਓ। ਇੱਕ ਕਾਊਂਟਡਾਊਨ ਰਿੰਗ ਅਤੇ ਨੋਟੀਫਿਕੇਸ਼ਨ ਤੁਹਾਨੂੰ ਦੱਸਦੇ ਹਨ ਜਦੋਂ ਸਮਾਂ ਪੂਰਾ ਹੋ ਜਾਂਦਾ ਹੈ।
- **ਪਿੱਛੇ ਕੁਝ ਨਹੀਂ ਛੱਡਦਾ।** ਇੱਕ decoy ਕੇਵਲ ਉਦੋਂ ਤੱਕ ਹੀ ਰਹਿੰਦਾ ਹੈ ਜਦੋਂ ਤੱਕ ਇਹ ਚੱਲਦਾ ਹੈ: ਛੋਟੀ exe ਸ਼ੁਰੂ ਹੋਣ 'ਤੇ ਬਣਾਈ ਜਾਂਦੀ ਹੈ ਅਤੇ ਰੁਕਣ 'ਤੇ ਮਿਟਾ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ ਬਾਹਰ ਨਿਕਲਦੇ ਹੋ ਤਾਂ ਸਭ ਕੁਝ ਬੰਦ ਹੋ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਕ੍ਰੈਸ਼ ਤੋਂ ਬਾਅਦ ਬਚੀਆਂ ਚੀਜ਼ਾਂ ਅਗਲੀ ਵਾਰ ਖੋਲ੍ਹਣ 'ਤੇ ਸਾਫ਼ ਕਰ ਦਿੱਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- **ਸ਼ਾਂਤ।** ਸਿਸਟਮ ਟਰੇ ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ, decoys ਲਈ ਖੁਦ ਕੋਈ ਵਿੰਡੋ ਜਾਂ ਟਾਸਕਬਾਰ ਬਟਨ ਨਹੀਂ ਹੁੰਦੇ।
- **ਖੁੱਲ੍ਹੇ ਅਨੁਵਾਦ।** ਇੰਟਰਫੇਸ ਸਧਾਰਨ JSON ਫਾਈਲਾਂ ਦੁਆਰਾ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ, ਇਸ ਲਈ ਭਾਸ਼ਾ ਜੋੜਨਾ ਸਿਰਫ਼ ਇੱਕ ਫਾਈਲ ਦਾ ਕੰਮ ਹੈ। ਅੰਗਰੇਜ਼ੀ ਅਤੇ ਰੂਸੀ ਸ਼ਾਮਲ ਹਨ।
- **ਨਿੱਜੀ।** ਕੋਈ ਖਾਤਾ ਨਹੀਂ, ਕੋਈ Discord ਟੋਕਨ ਨਹੀਂ, ਕੋਈ ਟੈਲੀਮੈਟਰੀ ਨਹੀਂ। [ਪਰਦੇਦਾਰੀ](#ਪਰਦੇਦਾਰੀ) ਵੇਖੋ।

## ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ

1. Discord ਤੁਹਾਡੇ PC 'ਤੇ ਚੱਲ ਰਹੇ ਪ੍ਰੋਸੈਸਾਂ ਨੂੰ ਦੇਖ ਕੇ ਅਤੇ ਉਹਨਾਂ ਦੇ executable ਨਾਮਾਂ ਦੀ ਤੁਲਨਾ ਇੱਕ ਜਨਤਕ ਸੂਚੀ (`/api/v9/applications/detectable`) ਨਾਲ ਕਰਕੇ ਇਹ ਫੈਸਲਾ ਕਰਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਕੋਈ ਗੇਮ ਖੇਡ ਰਹੇ ਹੋ।
2. Decoy ਉਸ ਸੂਚੀ ਨੂੰ ਡਾਊਨਲੋਡ ਕਰਦਾ ਹੈ ਅਤੇ, ਤੁਹਾਡੇ ਦੁਆਰਾ ਚੁਣੀ ਗਈ ਗੇਮ ਲਈ, ਸੂਚੀ ਵਿੱਚੋਂ executable ਨਾਮ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇੱਕ ਛੋਟੇ ਸਟੈਂਡ-ਇਨ ਪ੍ਰੋਗਰਾਮ (ਲਗਭਗ 120 KB, Rust ਵਿੱਚ ਲਿਖਿਆ ਗਿਆ ਅਤੇ Decoy ਵਿੱਚ ਸ਼ਾਮਲ) ਨੂੰ ਇੱਕ ਅਸਥਾਈ ਫੋਲਡਰ ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ, ਉਦਾਹਰਨ ਲਈ `.../cod26-cod.exe`।
3. ਸਟੈਂਡ-ਇਨ ਇੱਕ ਸਿਖਰਲੇ ਪੱਧਰ (top-level) ਦੀ ਵਿੰਡੋ ਰੱਖਣ ਤੋਂ ਇਲਾਵਾ ਕੁਝ ਨਹੀਂ ਕਰਦਾ, ਜਿਸਨੂੰ ਸਕ੍ਰੀਨ ਤੋਂ ਬਹੁਤ ਦੂਰ ਰੱਖਿਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਸਨੂੰ ਕਦੇ ਨਾ ਦੇਖ ਸਕੋ। Discord ਸਿਰਫ਼ ਉਸ ਪ੍ਰੋਸੈਸ ਨੂੰ ਪਛਾਣਦਾ ਹੈ ਜਿਸ ਕੋਲ ਵਿੰਡੋ ਹੁੰਦੀ ਹੈ, ਇਹੀ ਕਾਰਨ ਹੈ ਕਿ ਬਿਨਾਂ ਵਿੰਡੋ ਵਾਲੇ ਪ੍ਰੋਸੈਸ ਨੂੰ ਨਜ਼ਰਅੰਦਾਜ਼ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।
4. ਲਗਭਗ 15 ਸਕਿੰਟਾਂ ਦੇ ਅੰਦਰ Discord ਗੇਮ ਨੂੰ ਤੁਹਾਡੀ ਮੌਜੂਦਾ ਗਤੀਵਿਧੀ ਵਜੋਂ ਦਿਖਾਉਣ ਲੱਗਦਾ ਹੈ।
5. ਜਦੋਂ ਟਾਈਮਰ ਖਤਮ ਹੁੰਦਾ ਹੈ ਜਾਂ ਤੁਸੀਂ ਸਟਾਪ ਦਬਾਉਂਦੇ ਹੋ, ਤਾਂ Decoy ਪ੍ਰੋਸੈਸ ਨੂੰ ਸਮਾਪਤ ਕਰ ਦਿੰਦਾ ਹੈ ਅਤੇ ਫਾਈਲ ਨੂੰ ਮਿਟਾ ਦਿੰਦਾ ਹੈ। ਇੱਕ Windows ਜੌਬ ਆਬਜੈਕਟ ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ Decoy ਦੇ ਨਾਲ ਹੀ decoys ਵੀ ਬੰਦ ਹੋ ਜਾਣ, ਭਾਵੇਂ ਇਹ ਕ੍ਰੈਸ਼ ਹੀ ਕਿਉਂ ਨਾ ਹੋ ਜਾਵੇ।

`SHA256SUMS.txt` ਨਾਲ ਡਾਊਨਲੋਡ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ (PowerShell ਵਿੱਚ `Get-FileHash <file>`)।

Windows SmartScreen ਕਿਸੇ ਅਣਜਾਣ ਪ੍ਰਕਾਸ਼ਕ ਬਾਰੇ ਚੇਤਾਵਨੀ ਦੇ ਸਕਦਾ ਹੈ ਕਿਉਂਕਿ ਬਿਲਡ ਕੋਡ-ਸਾਈਨ ਨਹੀਂ ਕੀਤੇ ਗਏ ਹਨ; ਜੇਕਰ ਤੁਸੀਂ ਬਿਲਡ 'ਤੇ ਭਰੋਸਾ ਕਰਦੇ ਹੋ ਤਾਂ *More info → Run anyway* ਚੁਣੋ।

ਲੋੜਾਂ: WebView2 ਰਨਟਾਈਮ ਦੇ ਨਾਲ Windows 10 ਜਾਂ 11 (64-bit) (Windows 11 ਅਤੇ ਹਾਲੀਆ Windows 10 ਅੱਪਡੇਟਾਂ ਵਿੱਚ ਪਹਿਲਾਂ ਤੋਂ ਸ਼ਾਮਲ ਹੈ)।

## ਵਰਤੋਂ

1. **Library** ਖੋਲ੍ਹੋ ਅਤੇ ਕੋਈ ਗੇਮ ਖੋਜੋ, ਜਾਂ ਕਿਤੋਂ ਵੀ `Ctrl` + `K` ਦਬਾਓ।
2. ਕਿਸੇ ਗੇਮ 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਸੱਜੇ ਪਾਸੇ ਦੇ ਪੈਨਲ ਵਿੱਚ ਪ੍ਰੋਸੈਸ ਚੁਣੋ ਅਤੇ ਇਹ ਚੁਣੋ ਕਿ ਇਸਨੂੰ ਕਿੰਨੇ ਮਿੰਟ ਰੱਖਣਾ ਹੈ (Discord ਗਤੀਵਿਧੀਆਂ ਲਈ ਆਮ ਤੌਰ 'ਤੇ 15 ਮਿੰਟ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ)।
3. **Start decoy** ਦਬਾਓ। Discord ਕੁਝ ਸਕਿੰਟਾਂ ਬਾਅਦ ਗੇਮ ਦਿਖਾਉਣਾ ਸ਼ੁਰੂ ਕਰ ਦੇਵੇਗਾ।
4. ਇਸਨੂੰ **Running** ਅਧੀਨ ਦੇਖੋ, ਕਿਸੇ ਵੀ ਸਮੇਂ ਇੱਕ ਜਾਂ ਸਾਰਿਆਂ ਨੂੰ ਰੋਕੋ, ਜਾਂ Decoy ਨੂੰ ਟਰੇ ਵਿੱਚ ਛੱਡ ਦਿਓ।

ਉਹ ਗੇਮਾਂ ਜਿਨ੍ਹਾਂ ਦੀ Discord ਐਂਟਰੀ ਵਿੱਚ ਅਜੇ ਤੱਕ ਕੋਈ executables ਨਹੀਂ ਹਨ, ਮੂਲ ਰੂਪ ਵਿੱਚ ਲੁਕੀਆਂ ਹੁੰਦੀਆਂ ਹਨ (ਉਹਨਾਂ ਨੂੰ ਡਿਟੈਕਟ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ)। ਉਹਨਾਂ ਨੂੰ ਦੇਖਣ ਲਈ *Show games without exe* ਚਾਲੂ ਕਰੋ; ਸੂਚੀ ਰੋਜ਼ਾਨਾ ਰਿਫ੍ਰੈਸ਼ ਹੁੰਦੀ ਹੈ, ਇਸ ਲਈ ਜਿਵੇਂ ਹੀ Discord ਕੋਈ ਪ੍ਰੋਸੈਸ ਜੋੜਦਾ ਹੈ ਉਹ ਉਪਲਬਧ ਹੋ ਜਾਂਦੀਆਂ ਹਨ।

### ਕਮਾਂਡ ਲਾਈਨ

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ਤੁਰੰਤ ਇੱਕ decoy ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ, ਉਦਾਹਰਨ ਲਈ `decoy.exe --launch "robloxplayerbeta.exe" 15`।

## ਸਰੋਤ ਤੋਂ ਬਿਲਡ ਕਰੋ

ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ: [Node.js](https://nodejs.org) 20+, Visual Studio C++ ਬਿਲਡ ਟੂਲਸ ਦੇ ਨਾਲ ਸਥਿਰ [Rust](https://rustup.rs) ਟੂਲਚੇਨ (MSVC ਟੀਚਾ), ਅਤੇ WebView2 ਰਨਟਾਈਮ।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ਉਪਯੋਗੀ ਜਾਂਚਾਂ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ਨੋਟ: decoy exe ਨੂੰ `src-tauri/build.rs` ਦੁਆਰਾ ਸਧਾਰਨ `rustc` ਨਾਲ `src-tauri/stub/stub.rs` ਤੋਂ ਕੰਪਾਇਲ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ ਫਿਰ ਐਪ ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਜਦੋਂ ਫਰੰਟਐਂਡ ਇੱਕ ਸਾਧਾਰਨ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਚੱਲਦਾ ਹੈ (`npm run dev`), ਤਾਂ ਇੱਕ ਛੋਟਾ ਮੌਕ ਬੈਕਐਂਡ (`src/mock.ts`) ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ, ਜੋ UI 'ਤੇ ਕੰਮ ਕਰਨ ਲਈ ਸੁਵਿਧਾਜਨਕ ਹੈ।

## ਅਨੁਵਾਦ

UI ਸਟ੍ਰਿੰਗਾਂ [`src/locales`](../../src/locales) ਵਿੱਚ ਰਹਿੰਦੀਆਂ ਹਨ, ਪ੍ਰਤੀ ਭਾਸ਼ਾ ਇੱਕ JSON ਫਾਈਲ (`en.json`, `ru.json`, ...)।
ਇੱਕ ਭਾਸ਼ਾ ਜੋੜਨ ਦਾ ਮਤਲਬ ਹੈ ਇੱਕ ਫਾਈਲ ਜੋੜਨਾ; ਕੋਈ ਕੋਡ ਬਦਲਾਅ ਨਹੀਂ। ਫਾਈਲ ਫਾਰਮੈਟ, ਮਸ਼ੀਨ ਅਨੁਵਾਦ ਲਈ ਇੱਕ ਤਿਆਰ ਪ੍ਰੋਂਪਟ ਅਤੇ ਪ੍ਰਮਾਣਿਕਤਾ ਸਕ੍ਰਿਪਟ ਲਈ [docs/TRANSLATING.md](../TRANSLATING.md) ਵੇਖੋ। ਇਸ README ਦੇ ਅਨੁਵਾਦ `docs/i18n/README.<code>.md` ਵਿੱਚ ਜਾਂਦੇ ਹਨ।

## ਪ੍ਰੋਜੈਕਟ ਬਣਤਰ

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## ਪਰਦੇਦਾਰੀ

- Decoy ਸਿਰਫ਼ Discord ਦੀ ਜਨਤਕ ਡਿਟੈਕਸ਼ਨ ਸੂਚੀ ਡਾਊਨਲੋਡ ਕਰਨ ਲਈ (ਪਹਿਲੀ ਵਾਰ ਸ਼ੁਰੂ ਹੋਣ 'ਤੇ, ਫਿਰ ਦਿਨ ਵਿੱਚ ਵੱਧ ਤੋਂ ਵੱਧ ਇੱਕ ਵਾਰ ਜਾਂ ਜਦੋਂ ਤੁਸੀਂ ਰਿਫ੍ਰੈਸ਼ ਦਬਾਉਂਦੇ ਹੋ) ਅਤੇ ਡਿਸਪਲੇ ਲਈ Discord ਦੇ ਜਨਤਕ CDN ਤੋਂ ਗੇਮ ਆਈਕਨ ਅਤੇ ਆਰਟਵਰਕ ਡਾਊਨਲੋਡ ਕਰਨ ਲਈ ਨੈੱਟਵਰਕ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ।
- ਇਹ ਤੁਹਾਡੇ Discord ਟੋਕਨ ਜਾਂ ਕਿਸੇ ਖਾਤਾ ਡਾਟੇ ਨੂੰ ਨਹੀਂ ਪੜ੍ਹਦਾ, ਸਟੋਰ ਨਹੀਂ ਕਰਦਾ ਜਾਂ ਭੇਜਦਾ ਨਹੀਂ ਹੈ, ਅਤੇ ਇਹ Discord ਕਲਾਇੰਟ ਨਾਲ ਗੱਲ ਨਹੀਂ ਕਰਦਾ।
- ਸੈਟਿੰਗਾਂ (ਮਨਪਸੰਦ, ਭਾਸ਼ਾ, ਮਿਆਦ) ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਐਪ ਦੇ WebView ਸਟੋਰੇਜ ਵਿੱਚ ਸਟੋਰ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ; ਗੇਮ ਸੂਚੀ ਕੈਸ਼ ਅਤੇ ਅਸਥਾਈ decoy ਫਾਈਲਾਂ `%LOCALAPPDATA%\app.decoy.desktop` ਵਿੱਚ ਰਹਿੰਦੀਆਂ ਹਨ।
- ਕੋਈ ਵਿਸ਼ਲੇਸ਼ਣ (analytics) ਨਹੀਂ, ਕੋਈ ਕਰੈਸ਼ ਰਿਪੋਰਟਿੰਗ ਨਹੀਂ, ਕੋਈ ਖਾਤੇ ਨਹੀਂ।

## ਜਾਣੀਆਂ ਸੀਮਾਵਾਂ

- Discord ਕਿਸੇ ਵੀ ਸਮੇਂ ਡਿਟੈਕਸ਼ਨ ਦੇ ਕੰਮ ਕਰਨ ਦੇ ਤਰੀਕੇ ਨੂੰ ਬਦਲ ਸਕਦਾ ਹੈ। ਜੇਕਰ ਕੋਈ decoy ਪਛਾਣਿਆ ਜਾਣਾ ਬੰਦ ਹੋ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਕਿਰਪਾ ਕਰਕੇ ਇੱਕ issue ਖੋਲ੍ਹੋ।
- ਕੁਝ ਗਤੀਵਿਧੀਆਂ ਲਈ ਸਿਰਫ਼ ਇੱਕ ਚੱਲ ਰਹੇ ਪ੍ਰੋਸੈਸ ਨਾਲੋਂ ਵੱਧ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ (ਉਦਾਹਰਨ ਲਈ ਕਿਸੇ ਗੇਮ ਪਲੇਟਫਾਰਮ ਦੇ ਕਿਸੇ ਵਿਸ਼ੇਸ਼ ਅਨੁਭਵ ਦੇ ਅੰਦਰ ਹੋਣਾ)। Decoy ਸਿਰਫ਼ ਪ੍ਰੋਸੈਸ ਦੀ ਨਕਲ ਕਰਦਾ ਹੈ।
- Discord ਦੀ ਸੂਚੀ ਵਿੱਚ ਬਿਨਾਂ executables ਵਾਲੀਆਂ ਐਂਟਰੀਆਂ ਡਿਟੈਕਟ ਨਹੀਂ ਕੀਤੀਆਂ ਜਾ ਸਕਦੀਆਂ।
- ਸੁਰੱਖਿਆ ਸਾਫਟਵੇਅਰ ਕਈ ਵਾਰ ਛੋਟੀਆਂ ਅਣ-ਹਸਤਾਖਰਿਤ (unsigned) executables ਨੂੰ ਫਲੈਗ ਕਰ ਦਿੰਦੇ ਹਨ ਜੋ ਮੈਮੋਰੀ ਵਿੱਚ ਨਿਸ਼ਕਿਰਿਆ ਬੈਠੀਆਂ ਰਹਿੰਦੀਆਂ ਹਨ। Decoy ਓਪਨ ਸੋਰਸ ਹੈ ਅਤੇ `src-tauri/stub/stub.rs` ਤੋਂ ਬਣਾਇਆ ਗਿਆ ਹੈ; ਤੁਸੀਂ ਇਸਨੂੰ ਖੁਦ ਕੰਪਾਇਲ ਕਰ ਸਕਦੇ ਹੋ।

Decoy ਨਿੱਜੀ, ਵਿਦਿਅਕ ਅਤੇ ਜਾਂਚ ਦੇ ਉਦੇਸ਼ਾਂ ਲਈ "ਜਿਵੇਂ ਹੈ" ਪ੍ਰਦਾਨ ਕੀਤਾ ਗਿਆ ਹੈ। ਚੱਲ ਰਹੀ ਗੇਮ ਦੀ ਨਕਲ ਕਰਨਾ Discord ਜਾਂ ਗੇਮ ਪ੍ਰਕਾਸ਼ਕ ਦੀਆਂ ਸੇਵਾ ਸ਼ਰਤਾਂ (Terms of Service) ਦੀ ਉਲੰਘਣਾ ਕਰ ਸਕਦਾ ਹੈ, ਅਤੇ ਤੁਹਾਡੇ ਖਾਤੇ ਵਿਰੁੱਧ ਕਾਰਵਾਈ ਹੋ ਸਕਦੀ ਹੈ। ਤੁਸੀਂ ਇਸਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਦੇ ਹੋ ਇਸਦੇ ਲਈ ਸਿਰਫ਼ ਤੁਸੀਂ ਖੁਦ ਜ਼ਿੰਮੇਵਾਰ ਹੋ। "Discord" ਅਤੇ ਸਾਰੇ ਗੇਮਾਂ ਦੇ ਨਾਮ ਅਤੇ ਲੋਗੋ ਉਹਨਾਂ ਦੇ ਸੰਬੰਧਿਤ ਮਾਲਕਾਂ ਦੇ ਟ੍ਰੇਡਮਾਰਕ ਹਨ ਅਤੇ ਇੱਥੇ ਸਿਰਫ਼ ਉਸ ਸਾਫਟਵੇਅਰ ਦੀ ਪਛਾਣ ਕਰਨ ਲਈ ਵਰਤੇ ਗਏ ਹਨ ਜਿਸਦਾ ਉਹ ਹਵਾਲਾ ਦਿੰਦੇ ਹਨ।
