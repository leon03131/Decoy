# Decoy

**Pienet sijaisprosessat, kudamat luajitah Discord-sovelluksele mielen, gu kiža on käynnis.**

![Platformu](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Luajittu työkalul](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Lisensii](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-kirjasto uvvehkoin kižoin da kuvituksenke" />

</div>

Decoy pitäy käynnis varattoman ikkunallizen decoy-prosessan kižan ajettavan failan nimel, sendäh Discordin kižantunnistus ozuttau, gu sie kižuat sidä kižua. Oigiedy kižua ei tarviče niconzu azettua libo käynnistiä, eigo levytilua kulu turhah.

Se tundou **jogaizen kižan, kudaman Discord voi tunnistiä** (noin 25 000 kohtua), sendäh gu se lugou Discordin omua julgistu tunnistuslistua da pitäy sen ičestäh aijan mugazennu.

> [!WARNING]
> Käynnis olijan kižan imituacii voi rikkuo Discordin käyttoehtoloi, da käytät Decoy-sovellustu **omal vastvul**.
> Tämä projekti ei ole sidoksis Discord Inc. -yhtihöh, eigo se ole sen hyväksymä libo kannatettu. Kačo [Vastuuvapavus](#vastuuvapavus).

## Ominažuot

- **Kaikki, midä Discord voi tunnistiä.** Kižaluettelo ladatah Discordin julgizes tunnistusrajapinnaspäi, tallendetah välimuistih paikallizesti da uvvistetah jogapäivy. Uvvet kižat da äsken ližätyt ajettavat failat ilmestyttäh ičestäh.
- **Ečindö, kudai pysyy mukana.** Välitön ečindö kižan libo exe-failan nimel tuhanzien kižoin joukos, ruuvikko- libo tiivis luettelonäkymä, valitut da ”Uvvehkot”-rivi.
- **Yhtel painalluksel.** Vali kiža, vali ajettava failu (ku niidy on useambi), vali aiga da paina käynnistä. Aigalaskuri da ilmoitus sanotah, konzu aiga loppuu.
- **Ei jätä jälgie.** Decoy on olemassah vai ruadan aigua: pieni exe-failu luajitah käynnistykses da heitetäh poiš seizatukses. Kaikki seizatetah sovelluksespäi lähtijes, da mahdolliset rikki-menon jälgeh jiännyöt failat puhdistetah tuliel käynnistyksel.
- **Hil'l'aine.** Ruadau ilmoitusalovehel, eigo iče decoy-prosessoloil ozuteta ikkunoi libo tehtäväpalkin painikkehii.
- **Avvoimet kiännökset.** Käyttöliittymä toimiu tavallizien JSON-failoin pohjal, sendäh kielen ližiämine vaattiu vai yhten failan. Anglien da ven’an kielet ollah mukana valmehennu.
- **Privuattu.** Ei käyttäjätilidy, ei Discord-tokenua, ei telemetriedy. Kačo [Privuattus](#privuattus).

## Muga se ruadau

1. Discord piättäy sinun kižuavan kižua kaččojen tietokonehel käynnis olijoi prosessoi da vertailijen niiden ajettavien failoin nimilöi julgizien luettelonke (`/api/v9/applications/detectable`).
2. Decoy latau sen luettelon da kopioi valitulle kižale pienen sijaisohjelman (noin 120 kt, kirjutettu Rust-kielel da upotettu Decoy-sovellukseh) tilapäzeh papkah luettelos olijal ajettavan failan nimel, ezimerkikse `.../cod26-cod.exe`.
3. Sijaisohjelmu ei lua muudu nigonzu pidiä yhtty ylätazon ikkunua, kudai on sijoitettu loitton näytön ulgopuolele, ku et konzu näis sidä. Discord tunnistau vai prosessan, kudamal on ikkunu, sendäh tävvellizesti ikkunattomat prosessat jätetäh huomivottah.
4. Noin 15 sekunnin kuluus Discord ozuttau kižan sinun nygözenny toimindannu.
5. Konzu taimeri loppuu libo painat seizatuspainikkehen, Decoy lopettau prosessan da heittäy failan poiš. Windowsin job object -mekanizmu varmistau, gu decoy-prosessat kuoltah yhtes Decoynke, vaigu se menis rikki.

## Asennus

Vali yksi [Releases](../../../../releases) -sivulpäi:

| Ladavus | Tarkoitettu |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Azenusohjelmu.** Käyttäjäkohtaine, ei vaadi piäkäyttäjän oigevuksii, ližiäy Käynnistä-valikon kuvakkehen da poisto-ohjelman. |
| `Decoy_x.y.z_x64-portable.zip` | **Kannettava.** Pura mihin tahtot da käynnistä `decoy.exe`. Kaikki tiedot pysytäh sen rinnal olijas `data`-pawkas, nimidä ei kirjuteta käyttäjäprofilah. Poista papku sovelluksen heittämizekse. |

Tarkista ladattu failu `SHA256SUMS.txt`-failan avul (`Get-FileHash <failu>` PowerShellis).

Windows SmartScreen voi varoittua tundemattomas julgastajas, sendäh gu koondiversieloi ei ole allekirjutettu koodil; vali *Lisätietoja → Suorita silti*, ku uskot koonnan.

Vaatimukset: Windows 10 libo 11 (64-bittine) da WebView2-ajonaigaine ympäristö (jo mugažo mukana Windows 11:s da uvvehkohkois Windows 10 -uvvistuksis).

## Käyttö

1. Avua **Kirjasto** da eči kižua, libo paina `Ctrl` + `K` missä tahtot sovellukses.
2. Paina kižua. Oigienpuolizes paneelis vali prosessi da se, muga moni minuuttua sidä piettäh käynnis (Discord-tehtiävät ylezeh pyyttäh 15 min).
3. Paina **Käynnistä decoy**. Discord ozuttau kižan muutaman sekunnin kuluus.
4. Kačo sidä oziohs **Käynnis**, seizata yksi libo kaikki milloi tahtot, libo jätä Decoy ilmoitusalovehele.

Kižat, kudamien Discord-tiedoih ei vie ole merkitty ajettavii failoi, ollah oletuksennu peitetty (niidy ei voi tunnistiä). Ota käyttöh *Ozuttele kižat ilmai exeä* nähdäkseh net; luettelo uvvistetah jogapäivy, sendäh net tullah saatavile hedi, konzu Discord ližiäu prosessan.

### Komendorivi

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Käynnistäy decoy-prosessan hedi, ezimerkikse `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Kokoamine lähtekoodispäi

Vaatimukset: [Node.js](https://nodejs.org) 20+, vakaa [Rust](https://rustup.rs) -työkalurivi (MSVC-kohteh) sego Visual Studion C++ -käännöstyökalut da WebView2-ajonaigaine ympäristö.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Hyövyllizet tarkistukset:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Huomavutukset: decoy-exe kiännetäh failal `src-tauri/build.rs` käyttäjen tavallistu `rustc`-kändäjiä lähtekoodispäi `src-tauri/stub/stub.rs`, da se upotetah sovellukseh. Konzu käyttöliittymiä ajetah tavallizes brauzeras (`npm run dev`), käytetäh pientä mock-tagajärjestelmiä (`src/mock.ts`), mi on kätevy käyttöliittymän kehitystyös.

## Kiännökset

Käyttöliittymän merkkijonot sijaitah pawkas [`src/locales`](../../src/locales), yksi JSON-failu kieldy kohti (`en.json`, `ru.json`, ...). Kielen ližiämine merkiččöy uvven failan ližiämisty ilmai koodimuutoksii. Kačo failumuodo, valmis pyyntö konehkiändämizekse sego tarkistusskriptu ohjehes [docs/TRANSLATING.md](../TRANSLATING.md). Tämän README-failan kiännökset tallendetah polguh `docs/i18n/README.<code>.md`.

## Projektan rakendeh

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privuattus

- Decoy käyttäy verkkoyhtevytty vai Discordin julgizen tunnistusluettelon ladavukseh (ensimmäzel käynnistyskerral, sen jälgeh enindäh kerran päiväs libo konzu painat uvvistustu) da kižakuvakkehien sego kuvituksen ozuttamizekse Discordin julgizes CDN-verkos.
- Se ei luvve, tallenna eigo lähetä sinun Discord-tokenua libo nimittumii tilitiedoloi, eigo se pagize Discord-klientsovelluksenke.
- Asetukset (valitut, kieli, aijat) tallendetah paikallizesti sovelluksen WebView-tallendustilah; kižaluettelon välimuisti da tilapäzet decoy-failat sijaitah pawkas `%LOCALAPPDATA%\app.decoy.desktop`.
- Ei analitiikkua, ei kaatumizraportointii, ei käyttäjätililöi.

## Tunnetut rajoitukset

- Discord voi muuttua tunnistuksen ruadotabua milloi tahtot. Ku decoy ei enämbi tunnisteta, ole hyvä da avua ongelmaraportu (issue).
- Erähät toiminnot pyyttäh enämbän migu käynnis olijan prosessan (ezimerkikse olemižen tiätys kižualustan kižutilas libo kokemukses). Decoy imitiiruijou vai prosessua.
- Kohtii, kudamil ei ole ajettavii failoi Discordin luettelos, ei voi tunnistiä.
- Varutusohjelmat voijah toiči varoittua pienis allekirjuttamattomis ajettavis failois, kudamat ollah käyttämättöminny muistis. Decoy on avvoinda koodii da se nostetah failaspäi `src-tauri/stub/stub.rs`; voit kändiä sen iče.

## Ozanottamine

Vigaharavotukset, kehitysideat da kiännökset ollah tervetullehii. Luvve ensin [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Vastuuvapavus

Decoy toimitettah ”sellazennu ku se on” henkilökohtazeh, opastushollizeh da testavustarkoitukseh. Käynnis olijan kižan imituacii voi rikkuo Discordin libo kižanjulgastajan käyttolähtökohtii da voi vedä toimih sinun tilidy vaste. Sie yksin vastuat sen käytös. ”Discord” da kaikki kižoin nimet sego logot ollah niiden omistajien tavaramerkilöi, da niidy käytetäh täs vai viittuamah kysezeh ohjelmistoh.
