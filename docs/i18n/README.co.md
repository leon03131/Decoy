# Decoy

**Minusculi prucessi sustitutivi chì facenu crede à Discord chì un ghjocu hè in corsu.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibbiuteca di Decoy cù ghjochi ricenti è illustrazioni" />

</div>

Decoy mantene in corsu un innocuu prucessu rimpiazzadore dutatu d'una finestra sottu u nome esecutibile d'un ghjocu, di manera chì a rilevazione di i ghjochi di Discord vi annunzia cum'è s'è vo fussiate à ghjucà à stu ghjocu. Ùn avete mai bisognu d'installà nè di lancià u ghjocu propiu, cusì nulla d'ingumbrante ferma nant'à u vostru discu.

Cunnosce **ogni ghjocu chì Discord pò rilevà** (circa 25 000 voci) perchè leghje a lista publica di rilevazione di Discord è a mantene aghjurnata da per ellu.

> [!WARNING]
> Simulà un ghjocu in corsu pò andà contru à e Cundizioni d'Utilizazione di Discord è aduprate Decoy **à u vostru risicu**.
> Stu prugettu ùn hè micca affiliatu, appruvatu o ligatu à Discord Inc. Fighjate [Avisu legale](#avisu-legale).

## Funziunalità

- **Tuttu ciò chì Discord pò rilevà.** A lista di i ghjochi hè scaricata da u puntu d'accessu publicu di rilevazione di Discord, cunservata in a memoria lucale è rinfriscata ogni ghjornu. I ghjochi novi è l'esecutibili aghjunti di pocu appariscenu da per elli.
- **Ricerca sempre à ghjornu.** Ricerca istantanea per nome di ghjocu o esecutibile trà millaie di ghjochi, vista in piastelle o in lista cumpatta, preferiti è una fila di «Ricenti».
- **Un solu cliccu.** Sceglite un ghjocu, sceglite l'esecutibile (s'ellu ci ne hè parechji), definite quantu tempu mantene lu è appughjate nant'à lancià. Un anellu cù u contu à riversu è una nutificazione vi avvisanu quandu u tempu hè finitu.
- **Ùn lascia nunda daretu.** Un decoy esiste solu mentre gira: u picculu exe hè creatu à u lanciu è sguassatu à l'arrestu. Tuttu hè fermatu quandu chjudite, è e reste d'un eventuale piantone sò nettate à u prossimu lanciu.
- **Tranquillu.** Si stalla in a barra di statu di u sistema, senza finestre nè buttoni in a barra di i compiti per i decoy stessi.
- **Traduzzioni aperte.** L'interfaccia hè gestita da sèmplici schedarii JSON, cusì aghjunghje una lingua richiede solu un schedariu. L'inglese è u russu sò inclusi.
- **Riservatezza.** Nisun contu, nisun gettone Discord, nisuna telemetria. Fighjate [Riservatezza](#riservatezza).

## Cumu funziona

1. Discord decide chì state ghjucendu à un ghjocu analizendu i prucessi in corsu nant'à u vostru PC è paragunendu i so nomi esecutibili cù una lista publica (`/api/v9/applications/detectable`).
2. Decoy scarica sta lista è, per u ghjocu sceltu, copia un minusculu prugramma sustitutivu (circa 120 KB, scrittu in Rust è integratu in Decoy) ind'un cartulare timpuraneu aduprendu u nome esecutibile di a lista, per esempiu `.../cod26-cod.exe`.
3. U prugramma sustitutivu ùn face altru chè pussede una finestra di primu livellu, piazzata assai luntanu da u screnu per ùn vede la mai. Discord ricunnosce solu un prucessu chì pussede una finestra, eccu perchè un prucessu senza finestra hè ignuratu.
4. In una quindicina di seconde, Discord mostra u ghjocu cum'è a vostra attività attuale.
5. Quandu u timer finisce o s'è vo appughjate nant'à fermà, Decoy termina u prucessu è sguassa u schedariu. Un ughjettu job di Windows assicura chì i decoy si piantinu inseme cù Decoy, ancu s'ellu ci hè un crash.

## Installazione

Sceglite ne unu da a pagina di i [Releases](../../../../releases):

| Scaricamentu | Per |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Stallatore.** Per utilizatore, nisun dirittu d'amministratore necessariu, aghjusta una voce à u menu Start è un disinstallatore. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Scumpressate duv'ellu sia è lanciate `decoy.exe`. Tutti i dati fermanu in u cartulare `data` accantu, nunda hè scrittu in u vostru prufile d'utilizatore. Sguassate u cartulare per caccià lu. |

Verificate u scaricamentu cù `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen pò avvisà d'un editore micca ricunnisciutu perchè e versioni ùn sò micca firmate cù un certificatu; sceglite *Più infurmazione → Eseguisce listessu* s'è vo avete fiducia in a versione.

Requisiti: Windows 10 o 11 (64-bit) cù u runtime WebView2 (dighjà inclusu in Windows 11 è in l'aghjurnamenti ricenti di Windows 10).

## Utilizazione

1. Aprite a **Bibbiuteca** è cercate un ghjocu, o appughjate nant'à `Ctrl` + `K` da ogni locu.
2. Cliccate nant'à un ghjocu. In u pannellu à diritta, sceglite u prucessu è quantu minuti mantene lu (l'attività di Discord richiedenu di regula 15).
3. Appughjate nant'à **Lancià u decoy**. Discord mustrerà u ghjocu dopu à uni pochi di seconde.
4. Fighjate lu sottu à **In corsu**, fermate ne unu o tutti in ogni mumentu, o lasciate solu Decoy in a barra di statu.

I ghjochi chì a so voce Discord ùn hà ancu esecutibili sò piattati per difettu (ùn ponu micca esse rilevati). Attivate *Mustrà i ghjochi senza exe* per vede li; a lista hè rinfrescata ogni ghjornu, cusì diventanu dispunibili appena Discord aghjusta un prucessu.

### Linea di cumandu

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Lancia un decoy subitu, per esempiu `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Cumpilà da e surgenti

Prerequisiti: [Node.js](https://nodejs.org) 20+, a catena d'arnesi stabile [Rust](https://rustup.rs) (destinazione MSVC) cù l'arnesi di custruzzione Visual Studio C++, è u runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Cuntrolli utili:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Note: l'esecutibile decoy hè cumpilatu da `src-tauri/build.rs` cù `rustc` ordinariu à parte da `src-tauri/stub/stub.rs` è dopu integratu in l'appiecazione. Quandu u frontend viaghja in un navigatore ordinariu (`npm run dev`), un picculu backend fittiziu (`src/mock.ts`) hè adupratu, ciò chì hè praticu per travaglià nant'à l'interfaccia d'utilizatore.

## Traduzzioni

E parolle di l'interfaccia campanu in [`src/locales`](../../src/locales), un schedariu JSON per lingua (`en.json`, `ru.json`, ...). Aghjunghje una lingua significa aghjunghje un schedariu; nisuna mudifica di codice. Fighjate [docs/TRANSLATING.md](../TRANSLATING.md) per u furmatu di u schedariu, una dumanda pronta per a traduzzione automatica è u script di validazione. E traduzzioni di stu README vanu in `docs/i18n/README.<code>.md`.

## Struttura di u prugettu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Riservatezza

- Decoy usa a reta solu per scaricà a lista publica di rilevazione di Discord (à u primu lanciu, dopu à u massimu una volta à u ghjornu o quandu appughjate nant'à aghjurnà) è, per l'affissà, l'icone è l'illustrazioni di i ghjochi da u CDN publicu di Discord.
- Ùn leghje, ùn cunserva nè manda u vostru gettone Discord o dati di contu, è ùn cumunicheghja micca cù u cliente Discord.
- E preferenze (preferiti, lingua, durate) sò cunservate lucalmente in a memoria WebView di l'appiecazione; u cache di a lista di i ghjochi è i schedarii timpuranei di i decoy campanu in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nisuna analitica, nisun rapportu di crash, nisun contu.

## Limiti cunnisciuti

- Discord pò cambià u funziunamentu di a rilevazione in ogni mumentu. S'ellu un decoy ùn hè più ricunnisciutu, per piacè aprite un prublema (issue).
- Alcune attività necessitanu più d'un simplice prucessu in corsu (per esempiu esse ind'un'esperienza specifica d'una piattaforma di ghjocu). Decoy imita solu u prucessu.
- E voci senza esecutibili in a lista di Discord ùn ponu esse rilevate.
- I prugrammi di sicurezza signalanu di tantu in tantu picculi esecutibili micca firmati chì fermanu inattivi in memoria. U decoy hè open source è custruitu à parte da `src-tauri/stub/stub.rs`; pudete cumpilà lu da voi stessu.

## Avisu legale

Decoy hè furnitu «cusì com'ellu hè» per scopi persunali, educativi è di prova. Simulà un ghjocu in corsu pò violà e Cundizioni d'Utilizazione di Discord o di l'editore di u ghjocu, è pò cunduce à azzioni contru à u vostru contu. Voi solu site rispunsevule di a manera chì l'aduprate. «Discord» è tutti i nomi è loghi di ghjochi sò marchi di i so rispettivi pruprietarii è sò aduprati quì solu per identificà u prugramma à u quale si riferiscenu.
