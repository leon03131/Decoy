# Decoy

**Små erstatningsprosesser som får Discord til å tro at et spill kjører.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-bibliotek med nylige spill og grafikk" />

</div>

Decoy holder en harmløs erstatningsprosess med vindu kjørende under navnet på et spills kjørbare fil, slik at Discords spillregistrering rapporterer at du spiller spillet. Du trenger aldri å installere eller starte det faktiske spillet, så ingenting stort opptar plass på disken din.

Den kjenner til **alle spill Discord kan oppdage** (omtrent 25 000 oppføringer) fordi den leser Discords egen offentlige gjenkjennelsesliste og holder den oppdatert automatisk.

> [!WARNING]
> Å simulere et spill som kjører kan være i strid med Discords vilkår for bruk, og du bruker Decoy **på egen risiko**.
> Dette prosjektet er ikke tilknyttet, godkjent av eller koblet til Discord Inc. Se [Ansvarsfraskrivelse](#ansvarsfraskrivelse).

## Funksjoner

- **Alt Discord kan oppdage.** Spillisten lastes ned fra Discords offentlige gjenkjenningsendepunkt, hurtigbufres lokalt og oppdateres daglig. Nye spill og nylig tillagte kjørbare filer dukker opp automatisk.
- **Raskt søk som henger med.** Øyeblikkelig søk etter spillnavn eller kjørbar fil på tvers av tusenvis av spill, rutenett eller kompakt listevisning, favoritter og en rad med «Nylige».
- **Ett klikk.** Velg et spill, velg den kjørbare filen (hvis det er flere), velg hvor lenge den skal kjøre og trykk på start. En nedtellingsring og et varsel gir beskjed når tiden er ute.
- **Etterlater ingen spor.** En decoy eksisterer bare mens den kjører: den knøttlille exe-filen opprettes ved start og slettes ved stopp. Alt stoppes når du avslutter, og eventuelle rester etter en krasj ryddes opp ved neste oppstart.
- **Stillegående.** Ligger i systemstatusfeltet, uten egne vinduer eller oppgavelinjeknapper for selve decoy-prosessene.
- **Åpne oversettelser.** Grensesnittet styres av enkle JSON-filer, så å legge til et språk krever bare én enkelt fil. Engelsk og russisk er inkludert.
- **Privat.** Ingen konto, ingen Discord-token, ingen telemetri. Se [Personvern](#personvern).

## Hvordan det fungerer

1. Discord avgjør at du spiller et spill ved å se på prosessene som kjører på PC-en din og sammenligne navnene på de kjørbare filene med en offentlig liste (`/api/v9/applications/detectable`).
2. Decoy laster ned denne listen og kopierer, for spillet du velger, et knøttlite erstatningsprogram (omtrent 120 KB, skrevet i Rust og innebygd i Decoy) til en midlertidig mappe under det kjørbare filnavnet fra listen, for eksempel `.../cod26-cod.exe`.
3. Erstatningsprogrammet gjør ingenting annet enn å eie et toppnivåvindu, plassert langt utenfor skjermen slik at du aldri ser det. Discord gjenkjenner bare prosesser som eier et vindu, og derfor blir en helt vindusløs prosess ignorert.
4. Innen omtrent 15 sekunder viser Discord spillet som din nåværende aktivitet.
5. Når tidtakeren utløper eller du trykker på stopp, avslutter Decoy prosessen og sletter filen. Et Windows-jobbobjekt sørger for at decoy-prosessene avsluttes sammen med Decoy, selv om programmet skulle krasje.

## Installasjon

Velg en versjon fra [Releases](../../../../releases)-siden:

| Nedlasting | For |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installasjonsprogram.** Brukerbasert, krever ikke administratorrettigheter, legger til oppføring i Start-menyen og et avinstallasjonsprogram. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Pakk ut hvor som helst og kjør `decoy.exe`. Alle data forblir i `data`-mappen ved siden av, ingenting skrives til brukerprofilen din. Slett mappen for å fjerne det. |

Bekreft en nedlasting med `SHA256SUMS.txt` (`Get-FileHash <file>` i PowerShell).

Windows SmartScreen kan advare om en ukjent utgiver fordi byggene ikke er kodesignert; velg *Mer info → Kjør likevel* hvis du stoler på bygget.

Krav: Windows 10 eller 11 (64-bit) med WebView2-kjøremiljøet (allerede inkludert i Windows 11 og nyere Windows 10-oppdateringer).

## Bruk

1. Åpne **Bibliotek** og søk etter et spill, eller trykk på `Ctrl` + `K` hvor som helst.
2. Klikk på et spill. I panelet til høyre velger du prosessen og hvor mange minutter den skal holdes i gang (Discord-aktiviteter ber vanligvis om 15).
3. Trykk på **Start decoy**. Discord vil vise spillet etter noen sekunder.
4. Følg med under **Kjører**, stopp én eller alle når som helst, eller la bare Decoy ligge i systemstatusfeltet.

Spill der Discord-oppføringen foreløpig ikke har noen kjørbare filer, er skjult som standard (de kan ikke oppdages). Slå på *Vis spill uten exe* for å se dem; listen oppdateres daglig, så de blir tilgjengelige så snart Discord legger til en prosess.

### Kommandolinje

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Starter en decoy umiddelbart, for eksempel `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bygg fra kildekode

Forutsetninger: [Node.js](https://nodejs.org) 20+, den stabile [Rust](https://rustup.rs)-verktøykjeden (MSVC-mål) med Visual Studio C++-byggverktøy og WebView2-kjøremiljøet.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Nyttige sjekker:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Merknader: decoy-exe-filen kompileres av `src-tauri/build.rs` med vanlig `rustc` fra `src-tauri/stub/stub.rs` og bygges deretter inn i appen. Når grensesnittet kjører i en vanlig nettleser (`npm run dev`), brukes en liten simulert backend (`src/mock.ts`), noe som er praktisk ved arbeid med brukergrensesnittet.

## Oversettelser

Brukergrensesnittets strenger ligger i [`src/locales`](../../src/locales), én JSON-fil per språk (`en.json`, `ru.json`, ...). Å legge til et språk betyr å legge til en fil; ingen kodeendringer. Se [docs/TRANSLATING.md](../TRANSLATING.md) for filformatet, en klar instruks for maskinoversettelse og valideringsskriptet. Oversettelser av denne README-filen legges i `docs/i18n/README.<code>.md`.

## Prosjektstruktur

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Personvern

- Decoy bruker bare nettverket til å laste ned Discords offentlige gjenkjenningsliste (ved første oppstart, deretter høyst én gang om dagen eller når du trykker på oppdater) og, for visning, spillikoner og grafikk fra Discords offentlige CDN.
- Det leser, lagrer eller sender ikke Discord-tokenet ditt eller noen kontoopplysninger, og det kommuniserer ikke med Discord-klienten.
- Innstillinger (favoritter, språk, varighet) lagres lokalt i appens WebView-lagring; hurtigbufferen for spillisten og midlertidige decoy-filer ligger i `%LOCALAPPDATA%\app.decoy.desktop`.
- Ingen analyse, ingen krasjrapportering, ingen kontoer.

## Kjente begrensninger

- Discord kan når som helst endre hvordan gjenkjenning fungerer. Hvis en decoy slutter å bli gjenkjent, vennligst åpne et problem (issue).
- Noen aktiviteter krever mer enn bare en kjørende prosess (for eksempel å være inne i en bestemt opplevelse på en spillplattform). Decoy etterligner bare prosessen.
- Oppføringer uten kjørbare filer i Discords liste kan ikke oppdages.
- Sikkerhetsprogramvare kan av og til flagge små, usignerte kjørbare filer som ligger uvirksomme i minnet. Decoy er åpen kildekode og bygget fra `src-tauri/stub/stub.rs`; du kan kompilere den selv.

## Bidra

Feilrapporter, ideer og oversettelser er velkomne. Vennligst les [CONTRIBUTING.md](../../CONTRIBUTING.md) først.

## Ansvarsfraskrivelse

Decoy leveres «som det er» til personlige, pedagogiske og testformål. Å etterligne et kjørende spill kan være i strid med tjenestevilkårene til Discord eller spillets utgiver, og kan føre til tiltak mot kontoen din. Du er alene ansvarlig for hvordan du bruker programmet. «Discord» og alle spillnavn og logoer er varemerker for sine respektive eiere og brukes her kun for å identifisere programvaren de refererer til.
