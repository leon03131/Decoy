# Decoy

**Wee staund-in processes that makk Discord think a gemm is rinnin.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy leebrar wi laitest gemms an airtwark" />

</div>

Decoy keeps a skaithless, windaed placeholder process rinnin unner a gemm's executable name, sae Discord's
gemm detection reports ye as playin that gemm. Ye niver need tae instaw or stairt the rail gemm, sae
nocht muckle sits on yer disk.

It kens aboot **ilka gemm Discord can detect** (aboot 25,000 entries) acause it reads Discord's ain
public detection leet an keeps it up tae date bi itsel.

> [!WARNING]
> Fakin a rinnin gemm can gang agane Discord's Terms of Service an ye uise Decoy **at yer ain risk**.
> This project is no affiliatit wi, endorsit bi or connectit tae Discord Inc. See [Disclaimer](#disclaimer).

## Featurs

- **Awthing Discord can detect.** The gemm leet is dounlaadit frae Discord's public detection endpoint, cached
  locally an eikit daily. New gemms an newly eikit executables kythe on their ain.
- **Lukin that keeps up.** Instant serch bi gemm name or executable athort thoosands o gemms, grid or compact
  leet view, favourits an a "Laitest" raw.
- **Ae dunt.** Wale a gemm, wale the executable (gin there are sindry), choose hou lang tae haud it an dunt stairt.
  A coontdoun ring an a notification tell ye whan the time is up.
- **Leaves nocht ahint.** A decoy anely exists whiles it rins: the wee exe is creatit on stairt an deletit on
  haud. Awthing is haudit whan ye quit, an orrels frae a crash are soopit on the neist stairt.
- **Quait.** Bides in the seestem tray, nae windaes or taskbar buttons for the decoys themsels.
- **Apen translâtions.** The interface is driven bi plain JSON files, sae eikin a leid is a single file.
  English an Russian are includit.
- **Private.** Nae accoont, nae Discord token, nae telemetry. See [Privacy](#privacy).

## Hou it warks

1. Discord decides that ye are playin a gemm bi luikin at the processes rinnin on yer PC an comparin their
   executable names wi a public leet (`/api/v9/applications/detectable`).
2. Decoy dounlaads that leet an, for the gemm ye wale, copies a wee staund-in program (aboot 120 KB, written in
   Rust an embeddit intae Decoy) tae a temporary fauder uisin the executable name frae the leet, for ensaumple
   `.../cod26-cod.exe`.
3. The staund-in dis nocht cep awn ae tap-level windae, pairkit faur aff-screen sae ye niver see it. Discord
   anely recognizes a process that awns a windae, whilk is why a hail windaeless process is ignort.
4. Within rochly 15 seconds Discord shaws the gemm as yer praesent activity.
5. Whan the timer ends or ye dunt haud, Decoy ends the process an deletes the file. A Windows job object maks
   siccar decoys dee thegither wi Decoy, e'en gin it crashes.

## Instaw

Wale ane frae the [Releases](../../../../releases) page:

| Dounlaad | For |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instawer.** Per-uiser, nae administrator richts needit, eiks a Stairt menu entry an an uninstawer. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Unzip oniegate an rin `decoy.exe`. Aw data bides in the `data` fauder neist tae it, nocht is written tae yer uiser profile. Delete the fauder tae remove it. |

Verify a dounlaad wi `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen micht warn anent an unkent publisher acause the bigs are no code signed; wale
*Mair info → Rin oniegate* gin ye lippen the big.

Requirements: Windows 10 or 11 (64-bit) wi the WebView2 runtime (awready includit in Windows 11 an recent
Windows 10 updates).

## Uisage

1. Apen **Leebrar** an serch for a gemm, or dunt `Ctrl` + `K` frae oniegate.
2. Dunt a gemm. In the panel on the richt wale the process an hou monie minutes tae haud it (Discord activities
   maistly speir for 15).
3. Dunt **Stairt decoy**. Discord will shaw the gemm efter a puckle seconds.
4. Watch it unner **Rinnin**, haud ane or aw at onie time, or jist leave Decoy in the tray.

Gemms whas Discord entry has nae executables yet are hid bi defowt (they canna be detectit). Turn on
*Shaw gemms athoot exe* tae see them; the leet is eikit daily, sae they come available as suin as Discord eiks
a process.

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Stairts a decoy richt awa, for ensaumple `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Big frae soorce

Prerequisites: [Node.js](https://nodejs.org) 20+, the stable [Rust](https://rustup.rs) toolchain (MSVC target) wi
the Visual Studio C++ big tools, an the WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # rin in development mode wi hot reload
npm run tauri build    # produce the instawer in src-tauri/target/release/bundle/nsis
```

Uisefu checks:

```bash
npm run check-locales  # validate ilka translâtion file agane ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notes: the decoy exe is compiled bi `src-tauri/build.rs` wi plain `rustc` frae `src-tauri/stub/stub.rs` an then
embeddit intae the app. Whan the frontend rins in a plain browser (`npm run dev`) a wee mock backend
(`src/mock.ts`) is uised, whilk is handy for warkin on the UI.

## Translâtions

The UI strings bide in [`src/locales`](../../src/locales), ae JSON file per leid (`en.json`, `ru.json`, ...).
Eikin a leid means eikin a file; nae code chynges. See [docs/TRANSLATING.md](../TRANSLATING.md) for the file
format, a ready-tae-uise prompt for machine translâtion an the validation script. Translâtions o this README gang tae
`docs/i18n/README.<code>.md`.

## Privacy

- Decoy anely uises the netwark tae dounlaad Discord's public detection leet (on first stairt, then at maist aince a day
  or whan ye dunt eik) an, for display, gemm icons an airtwark frae Discord's public CDN.
- It disna read, store or send yer Discord token or onie accoont data, an it disna talk tae the Discord client.
- Settins (favourits, leid, durations) are stowed locally in the app's WebView storage; the gemm leet cache an
  temporary decoy files bide in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nae analytics, nae crash reportin, nae accoonts.

## Kent limitations

- Discord can chynge hou detection warks at onie time. Gin a decoy stops bein recognizit, please apen an issue.
- Some activities need mair nor a rinnin process (for ensaumple bein inside a pairticular experience o a gemm
  platform). Decoy anely imitates the process.
- Entries athoot executables in Discord's leet canna be detectit.
- Security saftware whiles flags wee unsigned executables that sit idil in memory. The decoy is apen soorce
  an biggit frae `src-tauri/stub/stub.rs`; ye can compile it yersel.
