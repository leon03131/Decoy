# Decoy

**微型替身處理程序，讓 Discord 誤以為遊戲正在執行。**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy 遊戲庫，包含最近遊玩的遊戲與封面圖" />

</div>

Decoy 會以遊戲可執行檔的名稱在背景執行一個無害且帶有視窗的佔位處理程序，使 Discord 的遊戲偵測機制判定您正在遊玩該遊戲。您完全不需要安裝或啟動真正的遊戲，因此不會佔用寶貴的磁碟空間。

它掌握 **Discord 能偵測到的所有遊戲**（約 25,000 款），因為它會讀取 Discord 本身的公開偵測清單並自動保持最新狀態。

> [!WARNING]
> 偽裝正在執行的遊戲可能違反 Discord 的服務條款，使用 Decoy 的**一切風險由您自行承擔**。
> 本專案與 Discord Inc. 無任何關聯、認可或隸屬關係。請參閱[免責聲明](#免責聲明)。

## 功能特色

- **支援 Discord 能偵測的所有遊戲。** 遊戲清單直接從 Discord 的公開偵測端點下載，快取於本地並每日自動重新整理。新遊戲與新加入的可執行檔會自動顯示。
- **快速靈敏的即時搜尋。** 支援在數千款遊戲中依遊戲名稱或可執行檔名稱即時搜尋，提供網格檢視或緊湊清單檢視、我的最愛以及「最近使用」列。
- **一鍵啟動。** 挑選一款遊戲，選擇可執行檔（若有多個），設定維持時間並按下啟動。倒數計時環與通知會在時間結束時提醒您。
- **不留痕跡。** 替身處理程序僅在執行時存在：微型 exe 會在啟動時建立，並在停止時自動刪除。當您結束應用程式時所有處理程序都會停止，崩潰遺留的暫存檔案也會在下次啟動時自動清除。
- **安靜無擾。** 常駐於系統匣，替身處理程序本身不會顯示視窗或工作列按鈕。
- **開放翻譯。** 介面由純 JSON 檔案驅動，新增一種語言只需要新增一個檔案。目前已內建英文與俄文。
- **注重隱私。** 無需註冊帳號、無需 Discord Token、無任何遙測數據收集。請參閱[隱私權](#隱私權)。

## 運作原理

1. Discord 透過檢查您電腦上正在執行的處理程序，並將其可執行檔名稱與公開清單（`/api/v9/applications/detectable`）進行比對，以此判斷您是否正在遊玩某款遊戲。
2. Decoy 會下載該清單，並針對您選擇的遊戲，將一個微型替身程式（約 120 KB，以 Rust 編寫並內嵌於 Decoy 中）複製到暫存資料夾中，並命名為清單中的可執行檔名稱，例如 `.../cod26-cod.exe`。
3. 該替身程式除了持有一個頂層視窗之外不做任何事，且該視窗停駐在螢幕視野之外，因此您永遠不會看到它。Discord 只會識別擁有視窗的處理程序，這也是完全無視窗處理程序會被忽略的原因。
4. 大約 15 秒內，Discord 就會將該遊戲顯示為您當前的活動。
5. 當計時結束或您按下停止時，Decoy 會結束該處理程序並刪除該檔案。透過 Windows 作業物件（Job Object），即使 Decoy 意外崩潰，替身處理程序也會一併退出。

## 安裝

前往 [Releases](../../../../releases) 頁面下載對應版本：

| 下載項目 | 說明 |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **安裝程式。** 適用於單一使用者，無需系統管理員權限，會自動新增開始功能表項目與解除安裝程式。 |
| `Decoy_x.y.z_x64-portable.zip` | **免安裝版。** 解壓縮至任意位置即可執行 `decoy.exe`。所有資料均儲存在其旁的 `data` 資料夾中，不會寫入使用者個人設定檔。刪除該資料夾即可完全移除。 |

可使用 `SHA256SUMS.txt` 驗證下載的檔案（在 PowerShell 中執行 `Get-FileHash <file>`）。

由於組建未進行程式碼簽署，Windows SmartScreen 可能會警告未知的發行者；如果您信任該組建，請選擇*其他資訊 → 仍要執行*。

系統需求：Windows 10 或 11（64 位元），並安裝有 WebView2 執行階段（Windows 11 與近期的 Windows 10 更新已預設內建）。

## 使用說明

1. 開啟**遊戲庫**並搜尋遊戲，或在任何位置按下 `Ctrl` + `K`。
2. 點擊一款遊戲。在右側面板中選擇處理程序以及要維持的分鐘數（Discord 活動通常需要 15 分鐘）。
3. 按下**啟動替身**。幾秒後 Discord 就會顯示該遊戲。
4. 在**執行中**分頁查看狀態，隨時停止個別或所有替身，或者直接將 Decoy 縮小到系統匣。

在 Discord 清單中尚未包含可執行檔的遊戲預設會被隱藏（因為無法被偵測）。開啟*顯示無 exe 的遊戲*即可檢視它們；清單每天重新整理一次，一旦 Discord 新增了處理程序即可立即使用。

### 命令列

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

立即啟動替身，例如 `decoy.exe --launch "robloxplayerbeta.exe" 15`。

## 從原始碼建置

先決條件：[Node.js](https://nodejs.org) 20+、帶有 Visual Studio C++ 建置工具的穩定版 [Rust](https://rustup.rs) 工具鏈（MSVC 目標），以及 WebView2 執行階段。

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # 以開發模式執行並支援熱重載
npm run tauri build    # 在 src-tauri/target/release/bundle/nsis 產生安裝程式
```

實用的檢查指令：

```bash
npm run check-locales  # 對照 ru.json 驗證所有翻譯檔案
npx tsc --noEmit       # 前端型別檢查
cargo check --manifest-path src-tauri/Cargo.toml
```

注意事項：替身 exe 是在 `src-tauri/build.rs` 中使用純 `rustc` 從 `src-tauri/stub/stub.rs` 編譯並內嵌至應用程式中。當前端在一般瀏覽器中執行時（`npm run dev`），會使用一個輕量級 mock 後端（`src/mock.ts`），這非常便於介面開發。

## 翻譯

介面字串位於 [`src/locales`](../../src/locales)，每種語言對應一個 JSON 檔案（`en.json`、`ru.json` 等）。
新增語言只需要新增一個檔案，無需修改程式碼。檔案格式、可直接使用的機器翻譯提示詞以及驗證指令碼請參閱 [docs/TRANSLATING.md](../TRANSLATING.md)。此 README 的翻譯請放置於 `docs/i18n/README.<code>.md`。

## 專案結構

```
src/                    React + TypeScript 前端
  components/           遊戲庫、詳細資訊面板、設定…
  locales/              翻譯檔案（每種語言一個 JSON）
  i18n-core.ts          語言載入與查詢
  store.ts              應用程式狀態 (zustand)
src-tauri/              Rust 後端 (Tauri 2)
  src/lib.rs            遊戲資料庫、替身處理程序、系統匣
  stub/stub.rs          內嵌的替身程式
scripts/                輔助指令碼（語言系系驗證）
docs/                   翻譯指南、螢幕截圖
```

## 隱私權

- Decoy 僅在下載 Discord 公開偵測清單（首次啟動時，之後最多每天一次或在您按下重新整理時）以及顯示遊戲圖示和封面（從 Discord 的公開 CDN 擷取）時使用網路。
- 它不會讀取、儲存或傳送您的 Discord Token 或任何帳號資料，也不會與 Discord 客戶端進行通訊。
- 設定（我的最愛、語言、時間）儲存在應用程式本地的 WebView 儲存空間中；遊戲清單快取與暫存替身檔案位於 `%LOCALAPPDATA%\app.decoy.desktop`。
- 無分析數據、無崩潰回報、無帳號機制。

## 已知限制

- Discord 隨時可能變更偵測運作方式。如果替身不再被識別，請回報 Issue。
- 部分活動需要的不僅僅是正在執行的處理程序（例如身處遊戲平台的特定體驗中）。Decoy 僅模擬處理程序本身。
- Discord 清單中沒有可執行檔的項目無法被偵測。
- 安全防護軟體偶爾可能會將在記憶體中閒置的小型未簽署可執行檔標記為可疑。替身程式完全開源，建置自 `src-tauri/stub/stub.rs`；您可以自行編譯。
