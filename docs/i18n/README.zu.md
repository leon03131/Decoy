# Decoy

**Izinqubo ezincane ezimele ezenza i-Discord icabange ukuthi umdlalo uyasebenza.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Umtapo we-Decoy onemidlalo yakamuva nobuciko" />

</div>

I-Decoy igcina inqubo yesibambi esingenangozi futhi enewindi isebenza ngaphansi kwegama lefayela elisebenzisekayo lomdlalo (executable), ukuze ukuthola umdlalo kwe-Discord kubike ukuthi udlala lowo mdlalo. Awudingi neze ukufaka noma ukuvula umdlalo wangempela, ngakho-ke akukho okukhulu okuhlala kudiski yakho.

Yazi nge-**midlalo yonke engatholwa yi-Discord** (okufakiwe okungaba ngu-25,000) ngoba ifunda uhlu lokuthola lomphakathi lwe-Discord uqobo futhi ilugcina lunolwazi lwakamuva ngokwayo.

> [!WARNING]
> Ukwenza sengathi umdlalo uyasebenza kungase kuphambane Nemigomo Yesevisi ye-Discord futhi usebenzisa i-Decoy **ngobungozi bakho**.
> Le phrojekthi ayixhumene, ayivunyelwe noma ayihlobene ne-Discord Inc. Bheka [Umshwana wokuzihlangula](#umshwana-wokuzihlangula).

## Izici

- **Konke i-Discord engakuthola.** Uhlu lwemidlalo lulandwa kusiphetho sokuthola somphakathi se-Discord, lugcinwe endaweni yangakini futhi lubuyekezwe nsuku zonke. Imidlalo emisha namafayela asebenzisekayo asanda kwengezwa avela ngokwawo.
- **Ukusesha okuhambisana nesivinini.** Ukusesha okusheshayo ngegama lomdlalo noma ifayela elisebenzisekayo emidlalweni eyizinkulungwane, ukubuka kwegridi noma uhlu oluhlangene, izintandokazi nomugqa othi "Kutshanje".
- **Ukuchofoza okukodwa.** Khetha umdlalo, khetha ifayela elisebenzisekayo (uma kukhona amaningana), khetha ukuthi uzoligcina isikhathi esingakanani bese ucindezela ukuqala. Indingilizi yokubala wehla nesaziso zikutshela lapho isikhathi sesiphelile.
- **Akushiyi lutho ngemuva.** I-decoy iba khona kuphela ngenkathi isebenza: i-exe encane idalwa lapho iqala futhi isuswe lapho imiswa. Konke kuyamiswa lapho uphuma, futhi izinsalela zokuphahlazeka zishanelwa lapho uphinda uvula ngokulandelayo.
- **Ethule.** Ihlala ku-system tray, awekho amawindi noma izinkinobho ze-taskbar zama-decoy ngokwawo.
- **Ukuhumusha okuvulekile.** Isixhumi esibonakalayo siqhutshwa amafayela e-JSON acacile, ngakho ukungeza ulimi ifayela elilodwa nje. IsiNgisi nesiRashiya kufakiwe.
- **Eyimfihlo.** Ayikho i-akhawunti, alikho ithokheni le-Discord, ayikho i-telemetry. Bheka [Ubumfihlo](#ubumfihlo).

## Indlela esebenza ngayo

1. I-Discord inquma ukuthi udlala umdlalo ngokubheka izinqubo ezisebenza ku-PC yakho nokuqhathanisa amagama azo asebenzisekayo nohlu lomphakathi (`/api/v9/applications/detectable`).
2. I-Decoy ilanda lolo hlu futhi, kumdlalo owukhethayo, ikopishela uhlelo oluncane olumele (elinganiselwa ku-120 KB, olubhalwe nge-Rust futhi olushunyekwe ku-Decoy) kufolda yesikhashana kusetshenziswa igama elisebenzisekayo elisuka ohlwini, isibonelo `.../cod26-cod.exe`.
3. Uhlelo olumele alwenzi lutho ngaphandle kokuba newindi elilodwa lezinga eliphezulu, elipakiwe kude kakhulu nesikrini ukuze ungaze walibona. I-Discord ibona kuphela inqubo enewindi, yingakho inqubo engenalo nhlobo iwindi izitshwa.
4. Cishe phakathi kwemizuzwana engu-15 i-Discord ibonisa umdlalo njengomsebenzi wakho wamanje.
5. Lapho isibali-sikhathi siphela noma ucindezela ukumisa, i-Decoy iqeda inqubo bese isusa ifayela. Into yomsebenzi ye-Windows (job object) iqinisekisa ukuthi ama-decoy afa kanye ne-Decoy, ngisho noma ingaphahlazeka.

## Ukufaka

Khetha eyodwa ekhasini le-[Releases](../../../../releases):

| Ukulanda | Okwe |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Isifaki.** Somsebenzisi ngamunye, awadingeki amalungelo omlawuli, sengeza okufakiwe kumenyu yokuqala kanye nesikhiphi. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Vula noma yikuphi bese usebenzisa `decoy.exe`. Yonke idatha ihlala kufolda ye-`data` eseduze kwayo, akukho okulotshwa kuphrofayela yakho yomsebenzisi. Susa ifolda ukuze uyisuse. |

Qinisekisa ukulanda nge-`SHA256SUMS.txt` (`Get-FileHash <file>` ku-PowerShell).

I-Windows SmartScreen ingase ixwayise ngomshicileli ongaziwa ngoba izakhiwo azisayinwanga ngekhodi; khetha *More info → Run anyway* uma wethemba isakhiwo.

Izidingo: Windows 10 noma 11 (64-bit) ene-WebView2 runtime (esevele ifakiwe ku-Windows 11 nasezibuyekezweni zakamuva ze-Windows 10).

## Ukusetshenziswa

1. Vula i-**Library** bese usesha umdlalo, noma cindezela u-`Ctrl` + `K` kusuka noma yikuphi.
2. Chofoza umdlalo. Ephanelini elingakwesokudla khetha inqubo nokuthi yimizuzu emingaki yokuyigcina (imisebenzi ye-Discord ngokuvamile idinga eyi-15).
3. Cindezela u-**Start decoy**. I-Discord izobonisa umdlalo ngemuva kwemizuzwana embalwa.
4. Yibuke ngaphansi kwe-**Running**, misa eyodwa noma zonke nganoma yisiphi isikhathi, noma vele ushiye i-Decoy ku-tray.

Imidlalo okufakiwe kwayo kwe-Discord okungenazo izinto ezisebenzisekayo okwamanje ifihliwe ngokuzenzakalelayo (azikwazi ukutholwa). Vula *Show games without exe* ukuze uzibone; uhlu lubuyekezwa nsuku zonke, ngakho ziba khona ngokushesha lapho i-Discord ingeza inqubo.

### Ulayini womyalo

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Iqala i-decoy ngokushesha, isibonelo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ukwakha kusuka kumthombo

Izimfuneko: [Node.js](https://nodejs.org) 20+, ithuluzi le-[Rust](https://rustup.rs) elizinzile (MSVC target) elinamathuluzi okwakha e-Visual Studio C++, kanye ne-WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # sebenzisa ngemodi yokuthuthukisa ngokulayisha kabusha okushisayo
npm run tauri build    # khiqiza isifaki ku-src-tauri/target/release/bundle/nsis
```

Ukuhlola okuwusizo:

```bash
npm run check-locales  # qinisekisa wonke amafayela okuhumusha ku-ru.json
npx tsc --noEmit       # hlola izinhlobo zangaphambili (frontend)
cargo check --manifest-path src-tauri/Cargo.toml
```

Amanothi: i-exe ye-decoy ihlanganiswa ngu-`src-tauri/build.rs` nge-`rustc` ecacile kusuka ku-`src-tauri/stub/stub.rs` bese ishunyekwa kuhlelo lokusebenza. Lapho ingxenye yangaphambili isebenza kusiphequluli esivamile (`npm run dev`) kusetshenziswa ingemuva mbumbulu elincane (`src/mock.ts`), eliwusizo ekusebenzeni ku-UI.

## Ukuhumusha

Izintambo ze-UI zihlala ku-[`src/locales`](../../src/locales), ifayela elilodwa le-JSON ngolimi ngalunye (`en.json`, `ru.json`, ...). Ukwengeza ulimi kusho ukwengeza ifayela; azikho izinguquko zekhodi. Bheka i-[docs/TRANSLATING.md](../TRANSLATING.md) ukuze uthole ifomethi yefayela, umyalo olungele ukusetshenziswa wokuhumusha komshini kanye nesikripthi sokuqinisekisa. Ukuhunyushwa kwale README kuya ku-`docs/i18n/README.<code>.md`.

## Isakhiwo sephrojekthi

```
src/                    React + TypeScript frontend
  components/           Umtapo, iphaneli lemininingwane, izilungiselelo, ...
  locales/              amafayela okuhumusha (i-JSON eyodwa ngolimi ngalunye)
  i18n-core.ts          ukulayishwa nokubhekwa kolimi
  store.ts              isimo sohlelo lokusebenza (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            isizindalwazi semidlalo, izinqubo ze-decoy, i-tray
  stub/stub.rs          uhlelo olumele olushunyekwayo
scripts/                izikripthi zomsizi (ukuqinisekiswa kwe-locale)
docs/                   umhlahlandlela wokuhumusha, izithombe-skrini
```

## Ubumfihlo

- I-Decoy isebenzisa inethiwekhi kuphela ukulanda uhlu lokuthola lomphakathi lwe-Discord (ekuqaleni kokuqala, bese okungenani kanye ngosuku noma uma ucindezela ukubuyekeza) futhi, ukubonisa, izithonjana zegeyimu nobuciko obuvela ku-CDN yomphakathi ye-Discord.
- Ayifundi, ayigcini noma ayithumeli ithokheni yakho ye-Discord noma iyiphi idatha ye-akhawunti, futhi ayikhulumi neklayenti le-Discord.
- Izilungiselelo (izintandokazi, ulimi, izikhathi) zigcinwa endaweni kwisitoreji se-WebView sohlelo lokusebenza; inqolobane yohlu lwemidlalo namafayela wesikhashana e-decoy ahlala ku-`%LOCALAPPDATA%\app.decoy.desktop`.
- Azikho izibalo, akukho ukubikwa kokuphahlazeka, awekho ama-akhawunti.

## Imikhawulo eyaziwayo

- I-Discord ingashintsha indlela ukuthola okusebenza ngayo nganoma yisiphi isikhathi. Uma i-decoy iyeka ukubonwa, sicela uvule inkinga (issue).
- Eminye imisebenzi idinga okungaphezulu kwenqubo esebenzayo (isibonelo ukuba ngaphakathi kokuhlangenwe nakho okuthile kwenkundla yomdlalo). I-Decoy ilingisa inqubo kuphela.
- Okufakiwe okungenazo izinto ezisebenzisekayo ohlwini lwe-Discord akukwazi ukutholwa.
- Isofthiwe yezokuphepha ngezinye izikhathi imaka amafayela amancane asebenzisekayo angasayinwanga ahlezi engenzi lutho kumemori. I-decoy iwumthombo ovulekile futhi yakhiwe kusuka ku-`src-tauri/stub/stub.rs`; ungazihlanganisela yona ngokwakho.

## Umshwana wokuzihlangula

I-Decoy inikezwa "njengoba injalo" ngezinjongo zomuntu siqu, ezemfundo nezokuhlola. Ukulingisa umdlalo osebenzayo kungase kwephule Imigomo Yesevisi ye-Discord noma yomshicileli womdlalo, futhi kungaholela esenzweni esimelene ne-akhawunti yakho. Wena wedwa unesibopho sendlela oyisebenzisa ngayo. "Discord" nawo wonke amagama emidlalo namalogo yizimpawu zokuthengisa zabanikazi bazo futhi asetshenziswa lapha kuphela ukuhlonza isofthiwe abhekisele kuyo.
