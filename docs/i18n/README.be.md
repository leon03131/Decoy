# Decoy

**Малюсенькія працэсы-заглушкі, дзякуючы якім Discord лічыць, што гульня запушчана.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Бібліятэка Decoy з нядаўнімі гульнямі і вокладкамі" />

</div>

Decoy падтрымлівае працу бясшкоднага аконнага працэсу-заглушкі пад назвай выканальнага файла гульні, таму функцыя выяўлення гульняў у Discord паказвае, што вы гуляеце ў гэтую гульню. Вам ніколі не трэба ўсталёўваць або запускаць сапраўдную гульню, таму нічога лішняга не займае месца на вашым дыску.

Праграма ведае пра **кожную гульню, якую можа выявіць Discord** (каля 25 000 запісаў), бо чытае ўласны агульнадаступны спіс выяўлення Discord і аўтаматычна падтрымлівае яго ў актуальным стане.

> [!WARNING]
> Імітацыя запушчанай гульні можа супярэчыць Умовам выкарыстання Discord, таму вы выкарыстоўваеце Decoy **на свой уласны рызыка**.
> Гэты праект не звязаны з кампаніяй Discord Inc., не ўхвалены ёю і не мае да яе дачынення. Гл. [Адмова ад адказнасці](#адмова-ад-адказнасці).

## Магчымасці

- **Усё, што можа выявіць Discord.** Спіс гульняў спампоўваецца з публічнага эндпойнта выяўлення Discord, кэшуецца лакальна і абнаўляецца штодня. Новыя гульні і новадададзеныя выканальныя файлы з'яўляюцца аўтаматычна.
- **Хуткі і зручны пошук.** Імгненны пошук па назве гульні або выканальным файле сярод тысяч гульняў, адлюстраванне пліткамі або кампактным спісам, выбранае і радок «Нядаўнія».
- **У адзін клік.** Выберыце гульню, выберыце выканальны файл (калі іх некалькі), пазначце працягласць і націсніце «Запусціць заглушку». Кольца зваротнага адліку і апавяшчэнне паведамяць, калі час вычарпаны.
- **Не пакідае слядоў.** Заглушка існуе толькі падчас працы: малюсенькі exe ствараецца пры запуску і выдаляецца пасля спынення. Усё спыняецца пры закрыцці праграмы, а любыя рэшткі пасля збою прыбіраюцца пры наступным запуску.
- **Ціхі рэжым.** Працуе ў сістэмным трэі; ніякіх вокнаў або кнопак на панэлі задач для саміх заглушак.
- **Адкрыты для перакладу.** Інтэрфейс працуе на звычайных файлах JSON, таму для дадання новай мовы дастаткова аднаго файла. Англійская і руская ўжо ўключаны.
- **Канфідэнцыяльнасць.** Без уліковага запісу, без токена Discord, без тэлеметрыі. Гл. [Канфідэнцыяльнасць](#канфідэнцыяльнасць).

## Як гэта працуе

1. Discord вызначае, што вы гуляеце ў гульню, правяраючы запушчаныя працэсы на вашым ПК і параўноўваючы назвы іх выканальных файлаў з публічным спісам (`/api/v9/applications/detectable`).
2. Decoy спампоўвае гэты спіс і для выбранай гульні капіруе малюсенькую праграму-заглушку (каля 120 КБ, напісаную на Rust і ўбудаваную ў Decoy) у часовую папку пад назвай выканальнага файла са спіса, напрыклад `.../cod26-cod.exe`.
3. Заглушка не робіць нічога, акрамя стварэння аднаго акна верхняга ўзроўню, размешчанага далёка за межамі экрана, каб вы яго ніколі не бачылі. Discord распазнае толькі тыя працэсы, якія маюць акно, таму цалкам безаконныя працэсы ігнаруюцца.
4. Прыкладна праз 15 секунд Discord паказвае гульню як вашу бягучую актыўнасць.
5. Калі таймер заканчваецца або вы націскаеце кнопку спынення, Decoy завяршае працэс і выдаляе файл. Аб'ект задання Windows (job object) гарантуе, што заглушкі спыняць працу разам з Decoy, нават калі адбудзецца збой.

## Усталяванне

Выберыце патрэбны варыянт на старонцы [рэлізаў](../../../../releases):

| Спампаваць | Прызначэнне |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Усталёўшчык.** Для аднаго карыстальніка, правы адміністратара не патрабуюцца, дадае пункт у меню «Пуск» і праграму выдалення. |
| `Decoy_x.y.z_x64-portable.zip` | **Партатыўная версія.** Распакуйце ў любое месца і запусціце `decoy.exe`. Усе даныя захоўваюцца ў папцы `data` побач з ім, у ваш профіль карыстальніка нічога не запісваецца. Для выдалення проста выдаліце папку. |

Праверце спампаваны файл з дапамогай `SHA256SUMS.txt` (`Get-FileHash <file>` у PowerShell).

Windows SmartScreen можа папярэдзіць аб невядомым выдаўцу, бо зборкі не маюць лічбавага подпісу; выберыце *Падрабязней → Выканаць у любым выпадку* (*More info → Run anyway*), калі давяраеце зборцы.

Патрабаванні: Windows 10 або 11 (64-бітная) з асяроддзем выканання WebView2 (ужо ўключана ў склад Windows 11 і апошніх абнаўленняў Windows 10).

## Выкарыстанне

1. Адкрыйце **Бібліятэку** і знайдзіце гульню або націсніце `Ctrl` + `K` у любым месцы.
2. Націсніце на гульню. На панэлі справа выберыце працэс і колькі хвілін яго трымаць (для заданняў у Discord звычайна патрабуецца 15).
3. Націсніце **Запусціць заглушку**. За некалькі секунд Discord пакажа гульню.
4. Сачыце за ёй ва ўкладцы **Запушчана**, спыняйце адну ці ўсе заглушкі ў любы момант або проста пакіньце Decoy у трэі.

Гульні, для якіх у базе Discord пакуль няма выканальных файлаў, схаваны па змаўчанні (іх немагчыма выявіць). Уключыце *Паказваць без exe*, каб убачыць іх; спіс абнаўляецца штодня, таму яны стануць даступнымі, як толькі Discord дадасць працэс.

### Камандны радок

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Запускае заглушку адразу, напрыклад: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Зборка з зыходнага кода

Папярэднія патрабаванні: [Node.js](https://nodejs.org) 20+, стабільны набор інструментаў [Rust](https://rustup.rs) (мэтавая платформа MSVC) з інструментамі зборкі C++ Visual Studio і асяроддзе выканання WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Карысныя праверкі:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Заўвагі: выканальны файл заглушкі кампілюецца скрыптам `src-tauri/build.rs` з дапамогай звычайнага `rustc` з `src-tauri/stub/stub.rs` і затым убудоўваецца ў праграму. Калі франтэнд запускаецца ў звычайным браўзеры (`npm run dev`), выкарыстоўваецца невялікі мок-бэкенд (`src/mock.ts`), што зручна для працы над інтэрфейсам.

## Пераклады

Радкі інтэрфейсу знаходзяцца ў [`src/locales`](../../src/locales), па адным файле JSON на мову (`en.json`, `ru.json`, ...). Даданне новай мовы — гэта проста даданне файла, без змен у кодзе. Гл. [docs/TRANSLATING.md](../TRANSLATING.md) для атрымання інфармацыі аб фармаце файлаў, гатовага промпта для машыннага перакладу і скрыпта валідацыі. Пераклады гэтага README захоўваюцца ў `docs/i18n/README.<code>.md`.

## Структура праекта

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Канфідэнцыяльнасць

- Decoy выкарыстоўвае сетку толькі для спампоўвання агульнадаступнага спіса выяўлення Discord (пры першым запуску, далей — не часцей за адзін раз на дзень або калі вы націскаеце «Абнавіць») і для адлюстравання абразкоў і вокладак гульняў з публічнага CDN Discord.
- Праграма не счытвае, не захоўвае і не адпраўляе ваш токен Discord або любыя даныя ўліковага запісу, а таксама не ўзаемадзейнічае з кліентам Discord.
- Налады (выбранае, мова, працягласць) захоўваюцца лакальна ў сховішчы WebView праграмы; кэш спіса гульняў і часовыя файлы заглушак знаходзяцца ў `%LOCALAPPDATA%\app.decoy.desktop`.
- Ніякай аналітыкі, ніякіх справаздач аб збоях, ніякіх уліковых запісаў.

## Вядомыя абмежаванні

- Discord можа змяніць логіку выяўлення ў любы час. Калі заглушка перастане распазнавацца, калі ласка, адкрыйце issue.
- Некаторыя актыўнасці патрабуюць большага, чым проста запушчаны працэс (напрыклад, знаходжанне ў пэўным плэйсе гульнявой платформы). Decoy імітуе толькі працэс.
- Запісы без выканальных файлаў у спісе Discord не могуць быць выяўлены.
- Ахоўнае ПЗ часам рэагуе на невялікія непадпісаныя выканальныя файлы, якія бяздзейна знаходзяцца ў памяці. Заглушка мае адкрыты зыходны код і збіраецца з `src-tauri/stub/stub.rs`; вы можаце скампіляваць яе самастойна.

## Удзел у распрацоўцы

Паведамленні пра памылкі, прапановы і пераклады вітаюцца. Калі ласка, спачатку азнаёмцеся з [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Адмова ад адказнасці

Decoy прадастаўляецца «як ёсць» для асабістых, адукацыйных і азнаямленчых мэт. Імітацыя запушчанай гульні можа парушаць Умовы выкарыстання Discord або выдаўца гульні і можа прывесці да прыняцця мер супраць вашага ўліковага запісу. Вы аднаасобна несяце адказнасць за тое, як выкарыстоўваеце гэтую праграму. «Discord» і ўсе назвы гульняў і лагатыпы з'яўляюцца таварнымі знакамі адпаведных уладальнікаў і выкарыстоўваюцца тут выключна для ідэнтыфікацыі праграмнага забеспячэння, да якога яны адносяцца.
