# Decoy

**Maliliit na stand-in na proseso na nagpapaisip sa Discord na may tumatakbong laro.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Library ng Decoy na may kamakailang mga laro at artwork" />

</div>

Pinapanatili ng Decoy ang isang hindi nakakapinsalang may-bintanang placeholder na proseso na tumatakbo sa ilalim ng pangalan ng executable ng isang laro, kaya inuulat ng game detection ng Discord na nilalaro mo ang larong iyon. Hindi mo kailanman kailangang i-install o ilunsad ang totoong laro, kaya walang malaking file na sasakop sa iyong disk.

Alam nito ang **bawat larong kayang matukoy ng Discord** (humigit-kumulang 25,000 entry) dahil binabasa nito ang pampublikong listahan ng detection ng Discord mismo at pinapanatili itong napapanahon nang mag-isa.

> [!WARNING]
> Ang pamemeke ng tumatakbong laro ay maaaring lumabag sa Mga Tuntunin ng Serbisyo ng Discord at ginagamit mo ang Decoy **sa iyong sariling peligro**.
> Ang proyektong ito ay hindi kaakibat, ineendorso ng, o konektado sa Discord Inc. Tingnan ang [Pagtanggi sa Pananagutan](#pagtanggi-sa-pananagutan).

## Mga Tampok

- **Lahat ng kayang matukoy ng Discord.** Ang listahan ng laro ay dina-download mula sa pampublikong detection endpoint ng Discord, naka-cache nang lokal at nire-refresh araw-araw. Kusang lumalabas ang mga bagong laro at mga bagong idinagdag na executable.
- **Paghahanap na mabilis at sumasabay.** Agarang paghahanap ayon sa pangalan ng laro o executable sa libu-libong mga laro, view na grid o compact na listahan, mga paborito at isang hilera ng "Kamakailan".
- **Isang pag-click.** Pumili ng laro, piliin ang executable (kung marami), piliin kung gaano katagal ito pananatilihin at pindutin ang simulan. Isang countdown ring at isang abiso ang magsasabi sa iyo kapag tapos na ang oras.
- **Walang iniiwang bakas.** Umiiral lamang ang isang decoy habang ito ay tumatakbo: ang maliit na exe ay nililikha sa pagsisimula at binubura kapag huminto. Hinihinto ang lahat kapag lumabas ka, at ang mga natira mula sa isang crash ay nililinis sa susunod na paglunsad.
- **Tahimik.** Namumuhay sa system tray, walang mga bintana o taskbar button para sa mga decoy mismo.
- **Bukas na mga pagsasalin.** Ang interface ay pinapagana ng mga plain JSON file, kaya ang pagdaragdag ng wika ay isang file lamang. Kasama ang Ingles at Ruso.
- **Pribado.** Walang account, walang Discord token, walang telemetry. Tingnan ang [Privacy](#privacy).

## Paano ito gumagana

1. Nagpapasya ang Discord na naglalaro ka ng isang laro sa pamamagitan ng pagtingin sa mga prosesong tumatakbo sa iyong PC at paghahambing ng kanilang mga pangalan ng executable sa isang pampublikong listahan (`/api/v9/applications/detectable`).
2. Dina-download ng Decoy ang listahang iyon at, para sa larong pinili mo, kinokopya ang isang maliit na stand-in na programa (humigit-kumulang 120 KB, nakasulat sa Rust at naka-embed sa Decoy) sa isang pansamantalang folder gamit ang pangalan ng executable mula sa listahan, halimbawa `.../cod26-cod.exe`.
3. Walang ginagawa ang stand-in maliban sa pagmamay-ari ng isang top-level window, na nakaparada nang malayo sa labas ng screen upang hindi mo ito makita kailanman. Kinikilala lamang ng Discord ang isang proseso na nagmamay-ari ng bintana, kaya naman binabalewala ang isang prosesong ganap na walang bintana.
4. Sa loob ng humigit-kumulang 15 segundo, ipinapakita ng Discord ang laro bilang iyong kasalukuyang aktibidad.
5. Kapag natapos ang timer o pinindot mo ang stop, tinatapos ng Decoy ang proseso at binubura ang file. Tinitiyak ng isang job object sa Windows na mamamatay ang mga decoy kasabay ng Decoy, kahit na mag-crash ito.

## Pag-install

Pumili mula sa pahina ng [Releases](../../../../releases):

| Download | Para sa |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installer.** Bawat user, hindi kailangan ng mga karapatan ng administrator, nagdaragdag ng entry sa Start menu at isang uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** I-unzip kahit saan at patakbuhin ang `decoy.exe`. Ang lahat ng data ay nananatili sa folder ng `data` sa tabi nito, walang isinusulat sa profile ng iyong user. Burahin ang folder upang alisin ito. |

I-verify ang na-download gamit ang `SHA256SUMS.txt` (`Get-FileHash <file>` sa PowerShell).

Maaaring magbabala ang Windows SmartScreen tungkol sa isang hindi kilalang publisher dahil ang mga build ay hindi code signed; piliin ang *More info → Run anyway* kung pinagkakatiwalaan mo ang build.

Mga Kinakailangan: Windows 10 o 11 (64-bit) na may WebView2 runtime (kasama na sa Windows 11 at kamakailang mga update ng Windows 10).

## Paggamit

1. Buksan ang **Library** at maghanap ng laro, o pindutin ang `Ctrl` + `K` mula sa kahit saan.
2. Mag-click sa isang laro. Sa panel sa kanan, piliin ang proseso at kung ilang minuto itong pananatilihin (karaniwang humihingi ng 15 ang mga aktibidad sa Discord).
3. Pindutin ang **Simulan ang decoy**. Ipapakita ng Discord ang laro pagkatapos ng ilang segundo.
4. Panoorin ito sa ilalim ng **Tumatakbo**, ihinto ang isa o lahat anumang oras, o iwanan lamang ang Decoy sa tray.

Ang mga larong ang Discord entry ay wala pang mga executable ay nakatago bilang default (hindi matutukoy ang mga ito). I-on ang *Ipakita ang mga larong walang exe* upang makita ang mga ito; nire-refresh ang listahan araw-araw, kaya magiging available ang mga ito sa sandaling magdagdag ang Discord ng isang proseso.

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Nagsisimula kaagad ng decoy, halimbawa `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## I-build mula sa source

Mga kinakailangan: [Node.js](https://nodejs.org) 20+, ang matatag na toolchain ng [Rust](https://rustup.rs) (MSVC target) kasama ang Visual Studio C++ build tools, at ang WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # patakbuhin sa development mode na may hot reload
npm run tauri build    # likhain ang installer sa src-tauri/target/release/bundle/nsis
```

Mga kapaki-pakinabang na pagsusuri:

```bash
npm run check-locales  # i-validate ang bawat translation file laban sa ru.json
npx tsc --noEmit       # i-type-check ang frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Mga tala: ang decoy exe ay kino-compile ng `src-tauri/build.rs` gamit ang plain `rustc` mula sa `src-tauri/stub/stub.rs` at pagkatapos ay ine-embed sa app. Kapag tumatakbo ang frontend sa isang ordinaryong browser (`npm run dev`), isang maliit na mock backend (`src/mock.ts`) ang ginagamit, na kapaki-pakinabang para sa paggawa sa UI.

## Mga Pagsasalin

Ang mga string ng UI ay nakatira sa [`src/locales`](../../src/locales), isang JSON file bawat wika (`en.json`, `ru.json`, ...). Ang pagdaragdag ng wika ay nangangahulugang pagdaragdag ng isang file; walang pagbabago sa code. Tingnan ang [docs/TRANSLATING.md](../TRANSLATING.md) para sa format ng file, isang handang-gamiting prompt para sa machine translation at ang validation script. Ang mga pagsasalin ng README na ito ay napupunta sa `docs/i18n/README.<code>.md`.

## Layout ng proyekto

```
src/                    React + TypeScript frontend
  components/           Library, panel ng detalye, mga setting, ...
  locales/              mga translation file (isang JSON bawat wika)
  i18n-core.ts          pagkarga at paghahanap ng wika
  store.ts              estado ng aplikasyon (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            database ng laro, mga proseso ng decoy, tray
  stub/stub.rs          ang stand-in na programa na ine-embed
scripts/                mga helper script (pagpapatunay ng locale)
docs/                   gabay sa pagsasalin, mga screenshot
```

## Privacy

- Ginagamit lamang ng Decoy ang network upang i-download ang pampublikong listahan ng detection ng Discord (sa unang pagsisimula, pagkatapos ay hindi hihigit sa isang beses bawat araw o kapag pinindot mo ang refresh) at, para sa pagpapakita, mga icon ng laro at artwork mula sa pampublikong CDN ng Discord.
- Hindi nito binabasa, iniimbak, o ipinapadala ang iyong Discord token o anumang data ng account, at hindi ito nakikipag-usap sa Discord client.
- Ang mga setting (mga paborito, wika, mga tagal) ay lokal na iniimbak sa WebView storage ng app; ang cache ng listahan ng laro at mga pansamantalang decoy file ay nakatira sa `%LOCALAPPDATA%\app.decoy.desktop`.
- Walang analytics, walang crash reporting, walang mga account.

## Mga kilalang limitasyon

- Maaaring baguhin ng Discord kung paano gumagana ang detection anumang oras. Kung ang isang decoy ay hindi na kinikilala, mangyaring magbukas ng issue.
- Ang ilang aktibidad ay nangangailangan ng higit pa sa isang tumatakbong proseso (halimbawa, ang pagiging nasa loob ng isang partikular na experience sa platform ng laro). Ginagaya lamang ng Decoy ang proseso.
- Ang mga entry na walang executable sa listahan ng Discord ay hindi matutukoy.
- Ang security software paminsan-minsan ay nagmamarka ng maliliit na hindi naka-sign na executable na nakatiwangwang sa memorya. Ang decoy ay open source at binuo mula sa `src-tauri/stub/stub.rs`; maaari mo itong i-compile sa iyong sarili.

## Pagtanggi sa Pananagutan

Ang Decoy ay ibinibigay nang "as is" para sa personal, pang-edukasyon, at pansubok na layunin. Ang panggagaya sa isang tumatakbong laro ay maaaring lumabag sa Mga Tuntunin ng Serbisyo ng Discord o ng publisher ng laro, at maaaring humantong sa aksyon laban sa iyong account. Ikaw lamang ang may pananagutan sa kung paano mo ito ginagamit. Ang "Discord" at lahat ng pangalan at logo ng laro ay mga trademark ng kani-kanilang mga may-ari at ginagamit lamang dito upang tukuyin ang software na kanilang tinutukoy.
