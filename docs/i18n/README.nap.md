# Decoy

**Prucesse sustitutive piccerille ca fanno credere a Discord ca nu juoco sta giranno.**

## Funziunalità

- **Tutto chello ca Discord po' truvà.** ‘A lista d''e juoche vene scarrecata da ll'endpoint prùbbreco ‘e Discord, sarvata dinto ‘a cache locale e aggiurnata ogne juorno. ‘E juoche nove e ll'eseguìbbili azzenzate ‘e fresco cumparisceno da sole.
- **Cerca ca nun perde nu colpo.** Ricerca a ll'istante p''o nomme d''o juoco o d''o file exe ammiezo a migliare ‘e juoche, vista a riggola o a lista cumpatta, preferite e ‘na riga cu ‘e «Recente».
- **Cu nu solo clic.** Sceglie nu juoco, sciglie ll'eseguìbbile (si ce ne stanno cchiù d'uno), ‘mpuosta quanto tiempo adda durà e arrucca avvia. N'aniello cu ‘o cunto a scennere e ‘na nutìfica te diceno quanno ‘o tiempo è sciveto.
- **Nun lassa niente appriesso.** Nu decoy esiste sulo mparamènte gira: ‘o piccerillo exe vene criato a ll'avvio e scancellato quanno se ferma. Tutte cose s'arrestano quanno chiure, e ‘e rresìddue d'arresto anòmalo veneno pulite a ll'avvio appriesso.
- **Discreto.** Se piazza dint'â cona ‘e sistema (tray), senza feneste o buttune dint'â sbarra d''e fatiche pe ‘e decoy stessi.
- **Traduzziune aperte.** Ll'interfaccia funziona cu sìmprece file JSON, accussì azzenzà ‘na lengua nova addimanna sulo nu file a parte. Ll'inglese e ‘o russo so' già dinto.
- **Reservato.** Nisciuno account, nisciuno token ‘e Discord, nisciuna telemetrìa. Vide [Privacy](#privacy).

## Comme funziona

1. Discord decide ca staje jucanno a nu juoco guardanno ‘e prucesse ca girano ngopp'ô PC tujo e cunfruntanno ‘e nomme d''e file eseguìbbili cu ‘na lista prùbbreca (`/api/v9/applications/detectable`).
2. Decoy scarreca chella lista e, p''o juoco ca sciglie, copia nu pruggrammiello piccerillo sustitutivo (cchiù o meno 120 KB, scritto ‘n Rust e ‘ncurpurato dinto a Decoy) dinto a ‘na cartella tempurània cu ‘o nomme d''o file exe d''a lista, pe tramente `.../cod26-cod.exe`.
3. ‘O pruggramma sustitutivo nun fa niente si nun tené ‘na fenesta ‘e primmo livello, piazzata assaje luntano a fora d''o schermo accussì nun ‘a vide maje. Discord arrecanosce nu prucesso sulo si téne ‘na fenesta, ed è pe chesto ca nu prucesso senza nisciuna fenesta vene ignurato.
4. Dinto a cchiù o meno 15 sicunne Discord mmustra ‘o juoco comm'attivitate currente toja.
5. Quanno ‘o timer fernesce o cliche ferma, Decoy stuta ‘o prucesso e scancella ‘o file. N'uggetto job ‘e Windows assicura ca ‘e decoy se chiudeno ‘nzieme a Decoy, pure si cadesse all'antrasatto.

## Uso

1. Arape **Libreria** e cerca nu juoco, oppuro arrucca `Ctrl` + `K` da addó staje staje.
2. Clica ngopp'a nu juoco. Dint'ô pannello a dritta sciglie ‘o prucesso e quanta minute adda durà (pe ll'attivitate ‘e Discord ‘e sòleto ne serveno 15).

‘E juoche addó Discord nun tene ancora ll'eseguìbbili so' annascunnute ‘e base (nun ponno essere rilevate). Arape *Mmustra juoche senza exe* pe ‘e vedé; ‘a lista s'aggiurna ogne juorno, accussì addiventano dispunìbbili mparamènte Discord azzecca ‘o prucesso.

## Cumpilazzione d''o còdesce surgente


## Privacy

- Decoy usa ‘a rete sulamente pe scarrecà ‘a lista prùbbreca ‘e rilevamento ‘e Discord (ô primmo avvio, aroppo a ‘o màssemo ‘na vota ‘o juorno o quanno cliche aggiurna) e, p''a visualizzazzione, ll'icone e ‘e fiùre d''e juoche d''a CDN prùbbreca ‘e Discord.

- Quacche attivitate vò cchiù ‘e nu sìmprece prucesso ‘nfunzione (pe tramente stà dinto a ‘n'esperienza particulare ‘e ‘na piattaforma ‘e juoco). Decoy fa fenta sulo d''o prucesso.
- ‘E vvoce senza eseguìbbili dint'â lista ‘e Discord nun ponno essere rilevate.
