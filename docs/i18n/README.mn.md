# Decoy

**Discord-д тоглоом ажиллаж байна гэж харагдуулах авсаархан хуурамч процессууд.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Сүүлийн үеийн тоглоомууд болон ковер зураг бүхий Decoy сан" />

</div>

Decoy нь тоглоомын ажиллах файлын нэрээр (exe) хор хөнөөлгүй, цонх бүхий хуурамч процессыг ард ажиллуулдаг тул
Discord-ийн тоглоом илрүүлэгч таныг тухайн тоглоомыг тоглож байгаа мэтээр харуулдаг. Та жинхэнэ тоглоомыг суулгах
эсвэл эхлүүлэх шаардлагагүй тул диск дээр тань ямар ч илүү хүнд файл хадгалагдахгүй.

Энэ нь Discord-ийн нийтийн илрүүлэлтийн жагсаалтыг уншиж, өөрөө автоматаар шинэчилж байдаг тул **Discord-ийн илрүүлж чадах
бүх тоглоомыг** (ойролцоогоор 25,000 бичлэг) мэддэг.

> [!WARNING]
> Тоглоом ажиллаж байгаа мэтээр хуурамчаар үйлдэх нь Discord-ийн Үйлчилгээний нөхцөлийг зөрчиж болзошгүй бөгөөд та Decoy-г **өөрийн эрсдэлээр** ашиглана.
> Энэхүү төсөл нь Discord Inc.-тэй ямар нэг байдлаар холбоогүй, дэмжигдээгүй, хамтраагүй болно. [Хариуцлагын хязгаарлалт](#хариуцлагын-хязгаарлалт)-ыг үзнэ үү.

## Онцлог боломжууд

- **Discord-ийн илрүүлж чадах бүх зүйл.** Тоглоомын жагсаалтыг Discord-ийн нийтийн илрүүлэлтийн холбоосоос татаж, төхөөрөмж дээр кэшлэн өдөр бүр шинэчилдэг. Шинэ тоглоомууд болон шинээр нэмэгдсэн ажиллах файлууд автоматаар гарч ирнэ.
- **Хурдан хайлт.** Мянга мянган тоглоом дундаас нэр эсвэл exe-ээр шуурхай хайх, хавтанцар эсвэл авсаархан жагсаалт харагдац, дуртай тоглоомууд болон "Сүүлийн үеийн" эгнээ.
- **Нэг товшилт.** Тоглоомоо сонгоод, exe файлыг сонгож (хэрэв хэд хэдэн хувилбартай бол), хэр удаан ажиллуулахаа тохируулаад эхлүүлэх дээр дарна. Тоолох цагираг болон мэдэгдэл нь цаг дуусах үед танд мэдэгдэнэ.
- **Мөр үлдээхгүй.** Decoy нь зөвхөн ажиллаж байх үедээ л оршдог: жижиг exe файл эхлэх үед үүсэж, зогсох үед устдаг. Аппыг хаахад бүх зүйл зогсох бөгөөд гэнэтийн уналтаас үлдсэн үлдэгдлүүдийг дараагийн эхлүүлэлтээр цэвэрлэдэг.
- **Чимээгүй.** Системийн трей дотор байрлана, decoy-д зориулсан тусдаа цонх эсвэл taskbar товчлуур байхгүй.
- **Нээлттэй орчуулга.** Интерфэйс нь энгийн JSON файлуудаар ажилладаг тул шинэ хэл нэмэхэд ердөө нэг файл шаардлагатай. Англи болон Орос хэл багтсан.
- **Хувийн нууцлал.** Бүртгэлгүй, Discord токен ашиглахгүй, хэрэглээний мэдээлэл цуглуулахгүй. [Нууцлал](#нууцлал)-ыг үзнэ үү.

## Хэрхэн ажилладаг вэ

1. Discord нь таны компьютерт ажиллаж байгаа процессуудыг шалгаж, тэдгээрийн exe нэрсийг нийтийн жагсаалттай (`/api/v9/applications/detectable`) харьцуулах замаар таныг тоглоом тоглож байна гэж үздэг.
2. Decoy нь уг жагсаалтыг татаж аваад, таны сонгосон тоглоомд зориулан жижиг хэмжээтэй орлуулагч програмыг (ойролцоогоор 120 КБ, Rust дээр бичигдсэн ба Decoy дотор суулгагдсан) жагсаалт дахь exe нэрээр түр хавтсанд хуулдаг, жишээ нь `.../cod26-cod.exe`.
3. Орлуулагч програм нь танд харагдахгүйгээр дэлгэцийн гадна байрлах дээд түвшний ганц цонхыг ажиллуулахаас өөр юу ч хийдэггүй. Discord зөвхөн цонхтой процессыг таньдаг бөгөөд огт цонхгүй процессыг үл тоомсорлодог учир ийм бүтэцтэй байдаг.
4. Ойролцоогоор 15 секундийн дотор Discord тухайн тоглоомыг таны одоогийн идэвхтэй үйл ажиллагаа гэж харуулна.
5. Цаг хэмжигч дуусах эсвэл та зогсоох товчийг дарахад Decoy процессыг дуусгаж, файлыг устгана. Windows-ийн ажил обьект (job object) нь Decoy унасан ч гэсэн decoy процессууд цуг хаагдахыг баталгаажуулдаг.

## Суулгах

[Хувилбарууд](../../../../releases) хуудаснаас сонгоно уу:

| Татах | Зорилго |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Суулгагч програм.** Нэг хэрэглэгчид зориулагдсан, админ эрх шаардлагагүй, Эхлүүлэх цэсэнд холбоос болон устгагчийг нэмнэ. |
| `Decoy_x.y.z_x64-portable.zip` | **Зөөврийн хувилбар.** Хаана ч хамаагүй задлаад `decoy.exe`-г ажиллуулна уу. Бүх өгөгдөл хажуугийн `data` хавтсанд хадгалагдах бөгөөд хэрэглэгчийн системд юу ч бичигдэхгүй. Устгахдаа хавтсыг нь устгахад хангалттай. |

Татаж авсан файлаа `SHA256SUMS.txt`-ээр баталгаажуулна уу (PowerShell дээр `Get-FileHash <file>`).

Бүтээн угсралтуудад тоон гарын үсэг зурагдаагүй тул Windows SmartScreen танигдаагүй хөгжүүлэгчийн талаар сэрэмжлүүлж магадгүй; хэрэв та уг бүтээцэд итгэж байгаа бол *Нэмэлт мэдээлэл → Ямар ч байсан ажиллуулах* (More info → Run anyway)-ыг сонгоно уу.

Тавигдах шаардлага: Windows 10 эсвэл 11 (64-бит), WebView2 runtime (Windows 11 болон сүүлийн үеийн Windows 10 шинэчлэлтүүдэд аль хэдийн багтсан байдаг).

## Ашиглалт

1. **Сан** хэсгийг нээгээд тоглоом хайх, эсвэл хаанаас ч `Ctrl` + `K` товчийг дарна уу.
2. Тоглоом дээр дарна уу. Баруун талын самбарт процессыг сонгож, хэдэн минут ажиллуулахаа сонгоно уу (Discord даалгавруудад ихэвчлэн 15 минут хэрэгтэй байдаг).
3. **Decoy эхлүүлэх** дээр дарна уу. Хэдэн секундийн дараа Discord тоглоомыг харуулах болно.
4. **Ажиллаж буй** цонхноос хянаж, аль нэгийг эсвэл бүгдийг хүссэн үедээ зогсоож болно, эсвэл Decoy-г зүгээр л систем трейд үлдээнэ үү.

Discord-ийн жагсаалтад одоогоор exe файл нь ороогүй тоглоомууд анхдагч байдлаар нуугдсан байдаг (тэдгээрийг илрүүлэх боломжгүй). Тэдгээрийг харахын тулд *exe-гүй тоглоомуудыг харуулах*-ыг идэвхжүүлнэ үү; жагсаалт өдөр бүр шинэчлэгддэг тул Discord процесс нэммэгц тэдгээр нь боломжтой болно.

### Тушаалын мөр

```
decoy.exe --launch "<Discord жагсаалтаас авсан ажиллах файлын зам>" [минут]
```

Decoy-г шууд эхлүүлнэ, жишээ нь `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Эх кодоос угсрах

Урьдчилсан шаардлага: [Node.js](https://nodejs.org) 20+, Visual Studio C++ угсрах хэрэгслүүд бүхий тогтвортой [Rust](https://rustup.rs) хэрэгслийн багц (MSVC зорилт), болон WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload бүхий хөгжүүлэлтийн горимд ажиллуулах
npm run tauri build    # src-tauri/target/release/bundle/nsis хавтсанд суулгагчийг үүсгэх
```

Хэрэгцээт шалгалтууд:

```bash
npm run check-locales  # орчуулгын файл бүрийг ru.json-той харьцуулан шалгах
npx tsc --noEmit       # фронтендийн төрлийг шалгах (type-check)
cargo check --manifest-path src-tauri/Cargo.toml
```

Тэмдэглэл: decoy exe-г `src-tauri/build.rs` нь `src-tauri/stub/stub.rs`-ээс энгийн `rustc`-ээр хөрвүүлж, дараа нь уг апп-д шингээдэг. Фронтенд энгийн хөтөч дээр ажиллах үед (`npm run dev`) жижиг mock бэкенд (`src/mock.ts`) ашиглагддаг бөгөөд энэ нь UI дээр ажиллахад тохиромжтой байдаг.

## Орчуулга

Интерфэйсийн текстүүд [`src/locales`](../../src/locales) хавтсанд хэл бүрт нэг JSON файл байдлаар байрладаг (`en.json`, `ru.json`, ...).
Шинэ хэл нэмнэ гэдэг нь ямар ч кодын өөрчлөлтгүйгээр зөвхөн файл нэмнэ гэсэн үг юм. Файлын формат, машин орчуулгад зориулсан бэлэн заавар болон баталгаажуулах скриптийг [docs/TRANSLATING.md](../TRANSLATING.md)-аас үзнэ үү. Энэхүү README-ийн орчуулгууд `docs/i18n/README.<code>.md` хавтсанд хадгалагдана.

## Төслийн бүтэц

```
src/                    React + TypeScript фронтенд
  components/           Сан, дэлгэрэнгүй самбар, тохиргоо, ...
  locales/              орчуулгын файлууд (хэл тус бүрт нэг JSON)
  i18n-core.ts          хэл ачаалах болон хайх логик
  store.ts              програмын төлөв (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            тоглоомын өгөгдлийн сан, decoy процессууд, систем трей
  stub/stub.rs          суулгагдах орлуулагч програм
scripts/                туслах скриптүүд (орчуулгыг шалгах)
docs/                   орчуулгын заавар, дэлгэцийн агшин
```

## Нууцлал

- Decoy нь сүлжээг зөвхөн Discord-ийн нийтийн илрүүлэлтийн жагсаалтыг татаж авах (анхны эхлүүлэлтээр, дараа нь өдөрт хамгийн ихдээ нэг удаа эсвэл та шинэчлэх товчийг дарах үед) болон Discord-ийн нийтийн CDN-ээс тоглоомын дүрс, ковер зургийг харуулахад л ашигладаг.
- Энэ нь таны Discord токен эсвэл дансны аливаа өгөгдлийг уншдаггүй, хадгалдаггүй, дамжуулдаггүй бөгөөд Discord клиенттэй шууд холбогддоггүй.
- Тохиргоо (дуртай тоглоомууд, хэл, хугацаа) нь апп-ийн WebView хадгалахад дотооддоо хадгалагддаг; тоглоомын жагсаалтын кэш болон түр хуурамч файлууд `%LOCALAPPDATA%\app.decoy.desktop` хавтсанд байрлана.
- Аналитик байхгүй, алдааны тайлан цуглуулахгүй, бүртгэл байхгүй.

## Мэдэгдэж буй хязгаарлалтууд

- Discord тоглоом илрүүлэх ажиллагаагаа хүссэн үедээ өөрчилж болно. Хэрэв decoy илрэхээ болибол issue нээнэ үү.
- Зарим үйл ажиллагаанд зөвхөн ажиллаж буй процессоос илүү зүйл шаардагддаг (жишээ нь тоглоомын платформын тодорхой сервэр, өрөөнд байх). Decoy зөвхөн процессыг л дуурайдаг.
- Discord-ийн жагсаалтад exe файлгүй бичлэгүүдийг илрүүлэх боломжгүй.
- Аюулгүй байдлын програмууд (антивирус) санах ойд сул зогсож буй жижиг, гарын үсэггүй exe файлуудыг заримдаа сэжиглэж болзошгүй. Decoy нь нээлттэй эх сурвалжтай бөгөөд `src-tauri/stub/stub.rs`-ээс угсрагддаг; та үүнийг өөрөө хөрвүүлж болно.

## Хувь нэмэр оруулах

Алдааны тайлан, шинэ санаа болон орчуулгыг талархан хүлээн авна. Эхлээд [CONTRIBUTING.md](../../CONTRIBUTING.md)-тэй танилцана уу.

## Хариуцлагын хязгаарлалт

Decoy нь хувийн, боловсролын болон туршилтын зорилгоор "байгаагаар нь" (as is) хангагдана. Ажиллаж буй тоглоомыг дуурайлгах нь Discord эсвэл тоглоом нийтлэгчийн Үйлчилгээний нөхцөлийг зөрчиж болзошгүй бөгөөд таны дансанд арга хэмжээ авах эрсдэлтэй. Та үүнийг хэрхэн ашиглахдаа зөвхөн өөрөө бүрэн хариуцлага хүлээнэ. "Discord" болон бүх тоглоомын нэр, лого нь тус тусын эзэмшигчдийн худалдааны тэмдэг бөгөөд энд зөвхөн тухайн програм хангамжийг таних зорилгоор ашиглагдсан болно.
