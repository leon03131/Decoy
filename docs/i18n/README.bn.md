# Decoy

**ক্ষুদ্র স্ট্যান্ড-ইন প্রসেস যা Discord-কে দেখায় যে একটি গেম চলছে।**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="সাম্প্রতিক গেম এবং আর্টওয়ার্ক সহ Decoy লাইব্রেরি" />

</div>

Decoy কোনো গেমের এক্সিকিউটেবল নামে একটি ক্ষতিকর-নয় এমন, উইন্ডোযুক্ত প্লেসহোল্ডার প্রসেস চালু রাখে, যাতে Discord-এর গেম শনাক্তকরণ ব্যবস্থা আপনাকে সেই গেমটি খেলছেন হিসেবে দেখায়। আপনাকে কখনোই আসল গেমটি ইনস্টল বা চালু করতে হয় না, ফলে আপনার ডিস্কে বড় কোনো ফাইল জায়গা নেয় না।

এটি **Discord শনাক্ত করতে পারে এমন প্রতিটি গেম** (প্রায় ২৫,০০০ এন্ট্রি) সম্পর্কে জানে, কারণ এটি Discord-এর নিজস্ব পাবলিক ডিটেকশন তালিকা পড়ে এবং নিজে থেকেই তা আপ-টু-ডেট রাখে।

> [!WARNING]
> চলমান গেমের ভুয়া উপস্থিতি দেখানো Discord-এর পরিষেবার শর্তাবলীর (Terms of Service) পরিপন্থী হতে পারে এবং আপনি **নিজ দায়িত্বে** Decoy ব্যবহার করবেন। এই প্রকল্পটি Discord Inc.-এর সাথে অনুমোদিত, সমর্থিত বা কোনোভাবেই সংযুক্ত নয়। [দাবিত্যাগ](#দাবিত্যাগ) দেখুন।

## বৈশিষ্ট্যসমূহ

- **Discord শনাক্ত করতে পারে এমন সবকিছু।** গেমের তালিকাটি Discord-এর পাবলিক ডিটেকশন এন্ডপয়েন্ট থেকে ডাউনলোড করা হয়, লোকালভাবে ক্যাশ করা হয় এবং প্রতিদিন রিফ্রেশ করা হয়। নতুন গেম এবং নতুন যোগ করা এক্সিকিউটেবলগুলো নিজে থেকেই তালিকায় চলে আসে।
- **গতিশীল অনুসন্ধান।** হাজার হাজার গেমের মধ্যে গেমের নাম বা এক্সিকিউটেবল দিয়ে তাত্ক্ষণিক অনুসন্ধান, গ্রিড বা কমপ্যাক্ট তালিকা ভিউ, ফেভারিট এবং "Recent" (সাম্প্রতিক) সারি।
- **এক ক্লিকেই সব।** একটি গেম বেছে নিন, এক্সিকিউটেবল নির্বাচন করুন (যদি একাধিক থাকে), কতক্ষণ চালাতে চান নির্ধারণ করুন এবং স্টার্ট চাপুন। একটি কাউন্টডাউন রিং এবং নোটিফিকেশন আপনাকে সময় শেষ হওয়ার কথা জানিয়ে দেবে।
- **কোনো অবশিষ্ট ফেলে রাখে না।** একটি decoy কেবল চলার সময়ই বিদ্যমান থাকে: ক্ষুদ্র exe ফাইলটি চালু করার সময় তৈরি হয় এবং বন্ধ করার সময় মুছে ফেলা হয়। আপনি প্রস্থান করলে সবকিছু বন্ধ হয়ে যায় এবং ক্র্যাশজনিত কোনো অবশিষ্ট থাকলে পরবর্তী চালুর সময় তা পরিষ্কার করা হয়।
- **শান্ত ও নিরব।** সিস্টেম ট্রে-তে অবস্থান করে, decoy-গুলোর নিজস্ব কোনো উইন্ডো বা টাস্কবার বাটন থাকে না।
- **উন্মুক্ত অনুবাদ ব্যবস্থা।** ইন্টারফেসটি সাধারণ JSON ফাইল দ্বারা পরিচালিত, তাই একটি ভাষা যোগ করতে কেবল একটি ফাইলের প্রয়োজন। English এবং Russian অন্তর্ভুক্ত রয়েছে।
- **ব্যক্তিগত ও সুরক্ষিত।** কোনো অ্যাকাউন্ট নেই, কোনো Discord টোকেন নেই, কোনো টেলিমেট্রি নেই। [গোপনীয়তা](#গোপনীয়তা) দেখুন।

## এটি যেভাবে কাজ করে

1. Discord আপনার পিসিতে চলমান প্রসেসগুলো পর্যবেক্ষণ করে এবং সেগুলোর এক্সিকিউটেবল নাম একটি পাবলিক তালিকার (`/api/v9/applications/detectable`) সাথে তুলনা করে নির্ধারণ করে যে আপনি কোনো গেম খেলছেন কি না।
2. Decoy সেই তালিকাটি ডাউনলোড করে এবং আপনার নির্বাচিত গেমটির জন্য তালিকা থেকে পাওয়া এক্সিকিউটেবল নাম ব্যবহার করে একটি ক্ষুদ্র স্ট্যান্ড-ইন প্রোগ্রাম (প্রায় ১২০ KB, Rust-এ লেখা এবং Decoy-এর মধ্যে এমবেড করা) একটি অস্থায়ী ফোল্ডারে কপি করে, উদাহরণস্বরূপ `.../cod26-cod.exe`।
3. এই স্ট্যান্ড-ইন প্রোগ্রামটি কেবল একটি টপ-লেভেল উইন্ডো ধারণ করা ছাড়া আর কিছুই করে না, যা স্ক্রিনের অনেক বাইরে রাখা থাকে যাতে আপনি কখনোই তা দেখতে না পান। Discord কেবল এমন প্রসেসকেই শনাক্ত করে যার একটি উইন্ডো রয়েছে, এ কারণেই উইন্ডোহীন প্রসেসকে সম্পূর্ণরূপে উপেক্ষা করা হয়।
4. প্রায় ১৫ সেকেন্ডের মধ্যে Discord গেমটিকে আপনার বর্তমান অ্যাক্টিভিটি হিসেবে দেখাতে শুরু করে।
5. টাইমার শেষ হলে বা আপনি স্টপ চাপলে, Decoy প্রসেসটি বন্ধ করে দেয় এবং ফাইলটি মুছে ফেলে। একটি Windows job object নিশ্চিত করে যে Decoy ক্র্যাশ করলেও decoy প্রসেসগুলো Decoy-এর সাথেই বন্ধ হয়ে যাবে।

| `Decoy_x.y.z_x64-setup.exe` | **ইনস্টলার।** ব্যবহারকারী-ভিত্তিক (per-user), কোনো অ্যাডমিনিস্ট্রেটর সুবিধার প্রয়োজন নেই, স্টার্ট মেনুতে এন্ট্রি এবং একটি আনইনস্টলার যোগ করে। |
| `Decoy_x.y.z_x64-portable.zip` | **পোর্টেবল।** যেকোনো স্থানে আনজিপ করে `decoy.exe` চালান। সমস্ত ডেটা এর পাশের `data` ফোল্ডারে থাকে, আপনার ব্যবহারকারী প্রোফাইলে কিছুই লেখা হয় না। এটি সরাতে কেবল ফোল্ডারটি মুছে ফেলুন। |

`SHA256SUMS.txt` দিয়ে ডাউনলোড যাচাই করুন (PowerShell-এ `Get-FileHash <file>`)।

বিল্ডগুলোতে কোড সাইন না থাকায় Windows SmartScreen অজ্ঞাত প্রকাশকের বিষয়ে সতর্ক করতে পারে; আপনি যদি বিল্ডটি বিশ্বাস করেন তবে *More info → Run anyway* নির্বাচন করুন।

প্রয়োজনীয়তা: WebView2 রানটাইম সহ Windows 10 বা 11 (64-bit) (Windows 11 এবং সাম্প্রতিক Windows 10 আপডেটগুলোতে এটি আগে থেকেই অন্তর্ভুক্ত রয়েছে)।

## ব্যবহারবিধি

1. **Library** খুলুন এবং একটি গেম খুঁজুন, অথবা যেকোনো স্থান থেকে `Ctrl` + `K` চাপুন।
2. একটি গেমে ক্লিক করুন। ডানদিকের প্যানেলে প্রসেসটি এবং এটি কত মিনিট ধরে রাখবেন তা বেছে নিন (Discord অ্যাক্টিভিটিগুলো সাধারণত ১৫ মিনিট চায়)।
3. **Start decoy** চাপুন। কয়েক সেকেন্ডের মধ্যে Discord গেমটি প্রদর্শন করবে।
4. **Running**-এর অধীনে এটি দেখুন, যেকোনো সময় একটি বা সবগুলো বন্ধ করুন, অথবা Decoy-কে ট্রে-তে রেখে দিন।

যেসব গেমের Discord এন্ট্রিতে এখনও কোনো এক্সিকিউটেবল নেই, সেগুলো ডিফল্টভাবে লুকানো থাকে (সেগুলো শনাক্ত করা সম্ভব নয়)। সেগুলো দেখতে *Show games without exe* চালু করুন; তালিকাটি প্রতিদিন রিফ্রেশ করা হয়, তাই Discord কোনো প্রসেস যুক্ত করার সাথে সাথেই সেগুলো ব্যবহারের উপযোগী হয়ে যায়।

### কমান্ড লাইন

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

সরাসরি একটি decoy চালু করে, উদাহরণস্বরূপ `decoy.exe --launch "robloxplayerbeta.exe" 15`।

## সোর্স থেকে বিল্ড করা

পূর্বশর্ত: [Node.js](https://nodejs.org) 20+, Visual Studio C++ বিল্ড টুলস সহ স্টেবল [Rust](https://rustup.rs) টুলচেইন (MSVC টার্গেট), এবং WebView2 রানটাইম।

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

দরকারী পরীক্ষা:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

নোট: decoy exe ফাইলটি `src-tauri/build.rs` দ্বারা `src-tauri/stub/stub.rs` থেকে সাধারণ `rustc` দিয়ে কম্পাইল করা হয় এবং তারপর অ্যাপে এমবেড করা হয়। যখন ফ্রন্টএন্ড সাধারণ ব্রাউজারে চলে (`npm run dev`), তখন একটি ছোট মক ব্যাকএন্ড (`src/mock.ts`) ব্যবহৃত হয়, যা UI নিয়ে কাজ করার জন্য সুবিধাজনক।

## অনুবাদ

UI স্ট্রিংগুলো [`src/locales`](../../src/locales)-এ থাকে, প্রতি ভাষার জন্য একটি করে JSON ফাইল (`en.json`, `ru.json`, ...)। একটি ভাষা যোগ করার অর্থ হলো কেবল একটি ফাইল যোগ করা; কোডে কোনো পরিবর্তন করতে হয় না। ফাইলের ফরম্যাট, মেশিন অনুবাদের জন্য প্রস্তুত প্রম্পট এবং যাচাইকরণ স্ক্রিপ্টের জন্য [docs/TRANSLATING.md](../TRANSLATING.md) দেখুন। এই README-এর অনুবাদগুলো `docs/i18n/README.<code>.md`-তে সংরক্ষিত হয়।

## প্রজেক্টের গঠন

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## গোপনীয়তা

- Decoy শুধুমাত্র Discord-এর পাবলিক ডিটেকশন তালিকা ডাউনলোড করার জন্য (প্রথমবার চালুর সময়, এরপর বড়জোর দিনে একবার অথবা আপনি যখন রিফ্রেশ চাপেন) এবং প্রদর্শনের জন্য Discord-এর পাবলিক CDN থেকে গেম আইকন ও আর্টওয়ার্ক আনার জন্য নেটওয়ার্ক ব্যবহার করে।
- এটি আপনার Discord টোকেন বা কোনো অ্যাকাউন্ট ডেটা পড়ে না, সংরক্ষণ করে না বা পাঠায় না এবং এটি Discord ক্লায়েন্টের সাথে কোনো যোগাযোগ করে না।
- সেটিংস (ফেভারিট, ভাষা, সময়কাল) লোকালভাবে অ্যাপের WebView স্টোরেজে সংরক্ষিত থাকে; গেম তালিকার ক্যাশ এবং অস্থায়ী decoy ফাইলগুলো `%LOCALAPPDATA%\app.decoy.desktop`-এ থাকে।
- কোনো অ্যানালিটিক্স নেই, কোনো ক্র্যাশ রিপোর্টিং নেই, কোনো অ্যাকাউন্ট নেই।

## জানা সীমাবদ্ধতাসমূহ

- Discord যেকোনো সময় তাদের শনাক্তকরণ পদ্ধতি পরিবর্তন করতে পারে। যদি কোনো decoy শনাক্ত হওয়া বন্ধ হয়ে যায়, দয়া করে একটি issue খুলুন।
- কিছু অ্যাক্টিভিটির জন্য কেবল একটি চলমান প্রসেসের চেয়ে বেশি কিছুর প্রয়োজন হয় (যেমন কোনো গেম প্ল্যাটফর্মের নির্দিষ্ট কোনো অভিজ্ঞতার ভেতরে থাকা)। Decoy কেবল প্রসেসটি অনুকরণ করে।
- Discord-এর তালিকায় যেসব এন্ট্রিতে কোনো এক্সিকিউটেবল নেই, সেগুলো শনাক্ত করা সম্ভব নয়।
- মেমরিতে নিষ্ক্রিয় বসে থাকা ছোট আনসাইন্ড এক্সিকিউটেবলগুলোকে নিরাপত্তা সফটওয়্যার (অ্যান্টিভাইরাস) মাঝে মাঝে সন্দেহজনক হিসেবে চিহ্নিত করতে পারে। Decoy ওপেন সোর্স এবং `src-tauri/stub/stub.rs` থেকে তৈরি; আপনি চাইলে এটি নিজেই কম্পাইল করে নিতে পারেন।

Decoy ব্যক্তিগত, শিক্ষামূলক এবং পরীক্ষামূলক উদ্দেশ্যে "যেমন আছে তেমন" (as is) ভিত্তিতে সরবরাহ করা হয়েছে। কোনো চলমান গেমের অনুকরণ করা Discord বা গেম প্রকাশকের পরিষেবার শর্তাবলী (Terms of Service) লঙ্ঘন করতে পারে এবং আপনার অ্যাকাউন্টের বিরুদ্ধে ব্যবস্থা গ্রহণের কারণ হতে পারে। আপনি এটি কীভাবে ব্যবহার করবেন তার সম্পূর্ণ দায়ভার একান্তই আপনার। "Discord" এবং সমস্ত গেমের নাম ও লোগো তাদের স্বত্বাধিকারীদের ট্রেডমার্ক এবং এখানে কেবল সফটওয়্যারগুলোকে চিহ্নিত করার উদ্দেশ্যে ব্যবহৃত হয়েছে।
