# Decoy

**ໂປຣເຊສຕົວແທນຂະໜາດນ້ອຍທີ່ເຮັດໃຫ້ Discord ຄິດວ່າມີເກມກຳລັງເຮັດວຽກຢູ່.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="ຄັງເກມ Decoy ພ້ອມເກມຫຼ້າສຸດ ແລະ ຮູບພາບໜ້າປົກ" />

</div>

Decoy ຈະຮັກສາໂປຣເຊສຕົວແທນແບບມີໜ້າຕ່າງທີ່ບໍ່ເປັນອັນຕະລາຍໃຫ້ເຮັດວຽກຢູ່ພາຍໃຕ້ຊື່ໄຟລ໌ executable ຂອງເກມ, ເຮັດໃຫ້ລະບົບກວດຈັບເກມຂອງ Discord ລາຍງານວ່າທ່ານກຳລັງຫຼິ້ນເກມນັ້ນຢູ່. ທ່ານບໍ່ຈຳເປັນຕ້ອງຕິດຕັ້ງ ຫຼື ເປີດເກມແທ້ເລີຍ, ສະນັ້ນຈຶ່ງບໍ່ມີໄຟລ໌ຂະໜາດໃຫຍ່ກິນພື້ນທີ່ໃນດິສກ໌ຂອງທ່ານ.

ໂປຣແກຣມນີ້ຮູ້ຈັກ **ທຸກເກມທີ່ Discord ສາມາດກວດຈັບໄດ້** (ປະມານ 25,000 ລາຍການ) ເພາະວ່າມັນອ່ານລາຍການກວດຈັບສາທາລະນະຂອງ Discord ເອງ ແລະ ອັບເດດໃຫ້ເປັນປັດຈຸບັນຢູ່ສະເໝີໂດຍອັດຕະໂນມັດ.

> [!WARNING]
> ການຈຳລອງເກມທີ່ກຳລັງເຮັດວຽກຢູ່ນັ້ນອາດຂັດກັບເງື່ອນໄຂການໃຫ້ບໍລິການຂອງ Discord ແລະ ທ່ານນຳໃຊ້ Decoy **ດ້ວຍຄວາມສ່ຽງຂອງທ່ານເອງ**.
> ໂຄງການນີ້ບໍ່ມີສ່ວນກ່ຽວຂ້ອງ, ບໍ່ໄດ້ຮັບການຮັບຮອງ ຫຼື ເຊື່ອມໂຍງກັບ Discord Inc. ແຕ່ຢ່າງໃດ. ເບິ່ງ [ຂໍ້ປະຕິເສດຄວາມຮັບຜິດຊອບ](#ຂໍ້ປະຕິເສດຄວາມຮັບຜິດຊອບ).

## ຄຸນສົມບັດ

- **ທຸກສິ່ງທີ່ Discord ສາມາດກວດຈັບໄດ້.** ລາຍຊື່ເກມຖືກດາວໂຫຼດມາຈາກ endpoint ກວດຈັບສາທາລະນະຂອງ Discord, ບັນທຶກແຄຊໄວ້ໃນເຄື່ອງ ແລະ ອັບເດດໃໝ່ທຸກມື້. ເກມໃໝ່ ແລະ ໄຟລ໌ executable ທີ່ຫາກໍ່ເພີ່ມເຂົ້າມາຈະສະແດງຂຶ້ນມາເອງ.
- **ການຄົ້ນຫາທີ່ວ່ອງໄວທັນໃຈ.** ຄົ້ນຫາໄດ້ທັນທີຕາມຊື່ເກມ ຫຼື ໄຟລ໌ executable ຈາກຫຼາຍພັນເກມ, ເລືອກເບິ່ງໄດ້ທັງແບບຕາຕະລາງ ຫຼື ແບບລາຍການກະທັດຮັດ, ມີລາຍການທີ່ມັກ ແລະ ແຖວ "ຫຼ້າສຸດ".
- **ຄລິກດຽວ.** ເລືອກເກມ, ເລືອກໄຟລ໌ executable (ຫາກມີຫຼາຍໄຟລ໌), ເລືອກໄລຍະເວລາທີ່ຕ້ອງການເປີດໄວ້ ແລ້ວກົດເລີ່ມຕົ້ນ. ວົງແຫວນນັບຖອຍຫຼັງ ແລະ ການແຈ້ງເຕືອນຈະບອກໃຫ້ທ່ານຮູ້ເມື່ອໝົດເວລາ.
- **ບໍ່ປະສິ່ງເສດເຫຼືອໄວ້.** Decoy ຈະມີຢູ່ສະເພາະຕອນທີ່ມັນເຮັດວຽກເທົ່ານັ້ນ: ໄຟລ໌ exe ຂະໜາດນ້ອຍຈະຖືກສ້າງຂຶ້ນເມື່ອເລີ່ມຕົ້ນ ແລະ ຖືກລຶບອອກເມື່ອຢຸດ. ທຸກຢ່າງຈະຢຸດເຮັດວຽກເມື່ອທ່ານອອກຈາກໂປຣແກຣມ, ແລະ ໄຟລ໌ຕົກຄ້າງຈາກການປິດແບບຜິດປົກກະຕິຈະຖືກເກັບກວາດໃນການເປີດໃຊ້ງານຄັ້ງຕໍ່ໄປ.
- **ງຽບສະຫງົບ.** ເຮັດວຽກຢູ່ໃນ system tray, ບໍ່ມີໜ້າຕ່າງ ຫຼື ປຸ່ມເທິງ taskbar ສຳລັບຕົວ decoy ເອງ.
- **ເປີດກວ້າງສຳລັບການແປພາສາ.** ສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ເຮັດວຽກຜ່ານໄຟລ໌ JSON ທຳມະດາ, ສະນັ້ນການເພີ່ມພາສາໃໝ່ຈຶ່ງໃຊ້ພຽງໄຟລ໌ດຽວ. ມີພາສາອັງກິດ ແລະ ພາສາຣັດເຊຍລວມຢູ່ນຳແລ້ວ.
- **ເປັນສ່ວນຕົວ.** ບໍ່ຕ້ອງໃຊ້ບັນຊີ, ບໍ່ຕ້ອງໃຊ້ໂທເຄັນ Discord, ບໍ່ມີການເກັບຂໍ້ມູນການນຳໃຊ້ (telemetry). ເບິ່ງ [ຄວາມເປັນສ່ວນຕົວ](#ຄວາມເປັນສ່ວນຕົວ).

## ຫຼັກການເຮັດວຽກ

1. Discord ຈະຕັດສິນວ່າທ່ານກຳລັງຫຼິ້ນເກມຢູ່ຫຼືບໍ່ ໂດຍການກວດເບິ່ງໂປຣເຊສທີ່ກຳລັງເຮັດວຽກຢູ່ເທິງ PC ຂອງທ່ານ ແລະ ປຽບທຽບຊື່ໄຟລ໌ executable ກັບລາຍການສາທາລະນະ (`/api/v9/applications/detectable`).
2. Decoy ຈະດາວໂຫຼດລາຍການດັ່ງກ່າວ ແລະ ສຳລັບເກມທີ່ທ່ານເລືອກ, ມັນຈະສຳເນົາໂປຣແກຣມຕົວແທນຂະໜາດນ້ອຍ (ປະມານ 120 KB, ຂຽນດ້ວຍ Rust ແລະ ຝັງໄວ້ໃນ Decoy) ໄປຍັງໂຟນເດີຊົ່ວຄາວ ໂດຍໃຊ້ຊື່ໄຟລ໌ executable ຈາກລາຍການ, ຕົວຢ່າງເຊັ່ນ `.../cod26-cod.exe`.
3. ໂປຣແກຣມຕົວແທນນີ້ຈະບໍ່ເຮັດຫຍັງເລີຍ ນອກຈາກຄອບຄອງໜ້າຕ່າງລະດັບເທິງສຸດໜຶ່ງໜ້າຕ່າງ, ເຊິ່ງຖືກວາງໄວ້ນອກຈໍເພື່ອບໍ່ໃຫ້ທ່ານເຫັນມັນ. Discord ຈະຮັບຮູ້ສະເພາະໂປຣເຊສທີ່ຄອບຄອງໜ້າຕ່າງເທົ່ານັ້ນ, ນີ້ຄືເຫດຜົນທີ່ໂປຣເຊສທີ່ບໍ່ມີໜ້າຕ່າງເລີຍຈະຖືກລະເລີຍ.
4. ພາຍໃນເວລາປະມານ 15 ວິນາທີ Discord ຈະສະແດງເກມນັ້ນເປັນກິດຈະກຳປັດຈຸບັນຂອງທ່ານ.
5. ເມື່ອຕົວນັບເວລາສິ້ນສຸດລົງ ຫຼື ທ່ານກົດຢຸດ, Decoy ຈະປິດໂປຣເຊສ ແລະ ລຶບໄຟລ໌ອອກ. Windows job object ຈະຊ່ວຍຮັບປະກັນວ່າຕົວ decoys ຈະຖືກປິດໄປພ້ອມກັບ Decoy, ເຖິງແມ່ນວ່າໂປຣແກຣມຈະເກີດການແຄຣຊກໍຕາມ.

## ການຕິດຕັ້ງ

ເລືອກດາວໂຫຼດອັນໃດອັນໜຶ່ງຈາກໜ້າ [Releases](../../../../releases):

| ດາວໂຫຼດ | ສຳລັບ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **ຕົວຕິດຕັ້ງ.** ສຳລັບຜູ້ໃຊ້ແຕ່ລະຄົນ, ບໍ່ຕ້ອງໃຊ້ສິດ administrator, ເພີ່ມລາຍການໃນເມນູ Start ແລະ ມີຕົວຖອນການຕິດຕັ້ງ. |
| `Decoy_x.y.z_x64-portable.zip` | **ແບບພົກພາ.** ແຕກໄຟລ໌ໄວ້ບ່ອນໃດກໍໄດ້ແລ້ວເປີດໃຊ້ `decoy.exe`. ຂໍ້ມູນທັງໝົດຈະຢູ່ໃນໂຟນເດີ `data` ທາງຂ້າງມັນ, ບໍ່ມີການຂຽນຂໍ້ມູນໃສ່ໂປຣໄຟລ໌ຜູ້ໃຊ້ຂອງທ່ານ. ລຶບໂຟນເດີອອກເພື່ອຖອນການຕິດຕັ້ງ. |

ກວດສອບໄຟລ໌ທີ່ດາວໂຫຼດດ້ວຍ `SHA256SUMS.txt` (`Get-FileHash <file>` ໃນ PowerShell).

Windows SmartScreen ອາດຈະແຈ້ງເຕືອນກ່ຽວກັບຜູ້ພັດທະນາທີ່ບໍ່ຮູ້ຈັກ ເນື່ອງຈາກໄຟລ໌ບິລດ໌ບໍ່ໄດ້ຮັບການລົງລາຍເຊັນດິຈິຕອນ (code signed); ເລືອກ *More info → Run anyway* ຫາກທ່ານເຊື່ອຖືໄຟລ໌ບິລດ໌ນີ້.

ຄວາມຕ້ອງການຂອງລະບົບ: Windows 10 ຫຼື 11 (64-bit) ພ້ອມດ້ວຍ WebView2 runtime (ມີລວມຢູ່ນຳແລ້ວໃນ Windows 11 ແລະ ໃນອັບເດດຫຼ້າສຸດຂອງ Windows 10).

## ການໃຊ້ງານ

1. ເປີດ **Library** ແລ້ວຄົ້ນຫາເກມ, ຫຼື ກົດ `Ctrl` + `K` ຈາກບ່ອນໃດກໍໄດ້.
2. ຄລິກທີ່ເກມ. ໃນແຜງດ້ານຂວາໃຫ້ເລືອກໂປຣເຊສ ແລະ ຈຳນວນນາທີທີ່ຕ້ອງການເປີດຄ້າງໄວ້ (ກິດຈະກຳ Discord ມັກຈະຮ້ອງຂໍ 15 ນາທີ).
3. ກົດ **Start decoy**. Discord ຈະສະແດງເກມຫຼັງຈາກນັ້ນສອງສາມວິນາທີ.
4. ຕິດຕາມເບິ່ງມັນໄດ້ພາຍໃຕ້ **Running**, ຢຸດອັນໃດອັນໜຶ່ງ ຫຼື ທັງໝົດໄດ້ທຸກເວລາ, ຫຼື ພຽງແຕ່ປະ Decoy ໄວ້ໃນ tray.

ເກມທີ່ໃນລາຍການຂອງ Discord ຍັງບໍ່ມີໄຟລ໌ executable ຈະຖືກເຊື່ອງໄວ້ໂດຍຄ່າເລີ່ມຕົ້ນ (ເນື່ອງຈາກບໍ່ສາມາດກວດຈັບໄດ້). ເປີດໃຊ້ງານ *Show games without exe* ເພື່ອເບິ່ງພວກມັນ; ລາຍຊື່ເກມຈະຖືກອັບເດດໃໝ່ທຸກໆມື້, ສະນັ້ນພວກມັນຈະພ້ອມໃຊ້ງານທັນທີທີ່ Discord ເພີ່ມໂປຣເຊສເຂົ້າມາ.

### ຄຳສັ່ງ Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ເລີ່ມຕົ້ນ decoy ທັນທີ, ຕົວຢ່າງເຊັ່ນ `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## ການບິລດ໌ຈາກຊອດໂຄ້ດ

ສິ່ງທີ່ຕ້ອງມີກ່ອນ: [Node.js](https://nodejs.org) 20+, ທູນເຊນ [Rust](https://rustup.rs) ລຸ້ນ stable (MSVC target) ພ້ອມດ້ວຍ Visual Studio C++ build tools, ແລະ WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ຄຳສັ່ງກວດສອບທີ່ເປັນປະໂຫຍດ:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ໝາຍເຫດ: ໄຟລ໌ decoy exe ຖືກຄອມໄພລ໌ໂດຍ `src-tauri/build.rs` ດ້ວຍ `rustc` ທຳມະດາຈາກ `src-tauri/stub/stub.rs` ແລ້ວຈຶ່ງຝັງລົງໃນແອັບ. ເມື່ອ frontend ເຮັດວຽກໃນບຣາວເຊີທຳມະດາ (`npm run dev`) ຈະມີການໃຊ້ mock backend ຂະໜາດນ້ອຍ (`src/mock.ts`), ເຊິ່ງສະດວກຫຼາຍສຳລັບການພັດທະນາ UI.

## ການແປພາສາ

ຂໍ້ຄວາມ UI ຢູ່ໃນ [`src/locales`](../../src/locales), ໜຶ່ງໄຟລ໌ JSON ຕໍ່ໜຶ່ງພາສາ (`en.json`, `ru.json`, ...). ການເພີ່ມພາສາໝາຍເຖິງການເພີ່ມໄຟລ໌; ບໍ່ມີການແກ້ໄຂໂຄ້ດ. ເບິ່ງ [docs/TRANSLATING.md](../TRANSLATING.md) ສຳລັບຮູບແບບໄຟລ໌, ພຣອມພ໌ພ້ອມໃຊ້ສຳລັບການແປດ້ວຍເຄື່ອງ ແລະ ສະຄຣິບກວດສອບຄວາມຖືກຕ້ອງ. ການແປຂອງ README ນີ້ຈະໄປທີ່ `docs/i18n/README.<code>.md`.

## ໂຄງສ້າງໂຄງການ

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## ຄວາມເປັນສ່ວນຕົວ

- Decoy ໃຊ້ເຄືອຂ່າຍພຽງແຕ່ເພື່ອດາວໂຫຼດລາຍການກວດຈັບສາທາລະນະຂອງ Discord ເທົ່ານັ້ນ (ເມື່ອເລີ່ມຕົ້ນຄັ້ງທຳອິດ, ຈາກນັ້ນບໍ່ເກີນມື້ລະຄັ້ງ ຫຼື ເມື່ອທ່ານກົດຣີເຟຣຊ) ແລະ ສຳລັບການສະແດງຜົນ, ໄອຄອນເກມ ແລະ ພາບໜ້າປົກຈາກ CDN ສາທາລະນະຂອງ Discord.
- ມັນບໍ່ອ່ານ, ບໍ່ບັນທຶກ ຫຼື ສົ່ງໂທເຄັນ Discord ຂອງທ່ານ ຫຼື ຂໍ້ມູນບັນຊີໃດໆ, ແລະ ມັນບໍ່ຕິດຕໍ່ສື່ສານກັບໄຄລເອັນຕ໌ Discord.
- ການຕັ້ງຄ່າຕ່າງໆ (ລາຍການທີ່ມັກ, ພາສາ, ໄລຍະເວລາ) ຈະຖືກເກັບໄວ້ພາຍໃນເຄື່ອງໃນບ່ອນເກັບຂໍ້ມູນ WebView ຂອງແອັບ; ແຄຊລາຍຊື່ເກມ ແລະ ໄຟລ໌ decoy ຊົ່ວຄາວຈະຢູ່ໃນ `%LOCALAPPDATA%\app.decoy.desktop`.
- ບໍ່ມີການວິເຄາະຂໍ້ມູນ, ບໍ່ມີການລາຍງານການແຄຣຊ, ບໍ່ມີບັນຊີຜູ້ໃຊ້.

## ຂໍ້ຈຳກັດທີ່ຮູ້ຈັກ

- Discord ສາມາດປ່ຽນແປງວິທີການກວດຈັບໄດ້ທຸກເວລາ. ຫາກ decoy ຢຸດການຖືກກວດຈັບ, ກະລຸນາເປີດ issue.
- ບາງກິດຈະກຳຕ້ອງການຫຼາຍກວ່າພຽງແຕ່ໂປຣເຊສທີ່ກຳລັງເຮັດວຽກຢູ່ (ຕົວຢ່າງເຊັ່ນ ການຢູ່ໃນປະສົບການສະເພາະໃດໜຶ່ງຂອງແພລດຟອຣ໌ມເກມ). Decoy ຈະຮຽນແບບສະເພາະຕົວໂປຣເຊສເທົ່ານັ້ນ.
- ລາຍການທີ່ບໍ່ມີໄຟລ໌ executable ໃນລາຍຊື່ຂອງ Discord ຈະບໍ່ສາມາດກວດຈັບໄດ້.
- ບາງຄັ້ງຊອບແວຄວາມປອດໄພອາດແຈ້ງເຕືອນກ່ຽວກັບໄຟລ໌ executable ຂະໜາດນ້ອຍທີ່ບໍ່ໄດ້ເຊັນດິຈິຕອນ ເຊິ່ງເປີດຄ້າງໄວ້ໃນໜ່ວຍຄວາມຈຳ. Decoy ເປັນໂອເພນຊອຣ໌ສ ແລະ ສ້າງຂຶ້ນມາຈາກ `src-tauri/stub/stub.rs`; ທ່ານສາມາດຄອມໄພລ໌ມັນດ້ວຍຕົວທ່ານເອງໄດ້.

## ຂໍ້ປະຕິເສດຄວາມຮັບຜິດຊອບ

Decoy ຖືກສະໜອງໃຫ້ "ຕາມສະພາບທີ່ເປັນຢູ່" ສຳລັບຈຸດປະສົງສ່ວນຕົວ, ການສຶກສາ ແລະ ການທົດສອບເທົ່ານັ້ນ. ການຮຽນແບບເກມທີ່ກຳລັງເຮັດວຽກຢູ່ນັ້ນອາດລະເມີດເງື່ອນໄຂການໃຫ້ບໍລິການຂອງ Discord ຫຼື ຂອງຜູ້ເຜີຍແຜ່ເກມ, ແລະ ອາດນຳໄປສູ່ການດຳເນີນການຕໍ່ບັນຊີຂອງທ່ານ. ທ່ານແຕ່ພຽງຜູ້ດຽວເປັນຜູ້ຮັບຜິດຊອບຕໍ່ວິທີການນຳໃຊ້ມັນ. "Discord" ແລະ ຊື່ເກມ ພ້ອມທັງໂລໂກ້ທັງໝົດເປັນເຄື່ອງໝາຍການຄ້າຂອງເຈົ້າຂອງທີ່ກ່ຽວຂ້ອງ ແລະ ຖືກນຳໃຊ້ໃນທີ່ນີ້ເພື່ອລະບຸເຖິງຊອບແວທີ່ພວກມັນອ້າງອີງເຖິງເທົ່ານັ້ນ.
