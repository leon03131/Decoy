# Decoy

**Discord-диз къугъун кутунва лагьана чӏалахъардай бицӏи процесс-заглушкаяр.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy библиотека мукьвара хьайи къугъунрихъ ва шикилрихъ галаз" />

Decoy-ди къугъундин exe файлдин тӏварцӏихъ галаз хата авачир, пэнжер гвай процесс-заглушка кутуна хуьзва, гьавиляй Discord-дин къугъунар жагъурдай системади куьне и къугъун къугъвазва лагьана къалурзава. Квез гьакъикъи къугъун кутун ва я кардик кутун герек туш, дискадал артух затӏ амач.

Адаз **Discord-диз жагъуриз жедай вири къугъунар** чида (25 000 гергга къугъун), вучиз лагьайтӏа ада Discord-дин вичин ахъа сиягь кӏелзава ва ам вичи цӏийи хъувуна хуьзва.

> [!WARNING]
> Къугъун кардик кутунин имитация авун Discord-дин Талабрин къайдайрихъ галаз акси хьун мумкин я, куьне Decoy **квечел хатавал алаз** кардик кутазва.
> И проект Discord Inc. компаниядихъ галаз алакъалу туш, ада тестикьарнавач ва адан патай куьмек аваз туш. Килиг: [Хатавал хиве тачун](#хатавал-хиве-тачун).

## Мумкинвилер

- **Discord-диз жагъуриз жедай вири затӏ.** Къугъунрин сиягь Discord-дин ахъа чешмедай эцигзава, чкадал кэшзава ва гьар юкъуз цӏийи хъувузва. Цӏийи къугъунар ва цӏийиз кутунвай exe файлар чпи-чпиз акъатзава.
- **Фагьумлу ва йигин жугъурун.** Агъзурралди къугъунрин арадай тӏварцӏелди ва я exe файлдалди йигин жугъурун, плиткайралди ва я компакт сиягьдалди къалурун, кӏанибур ва «Мукьвара хьайибур» цӏар.
- **Са басмахуналди.** Къугъун хкягъа, exe файл хкягъа (са шумуд аватӏа), шумуд декӏикьада хуьдатӏа тайинара ва «Заглушка кутун» басмаха. Къаткдай чӏагури ва хабардарвили вахт куьтягь хьайила хабар гуда.
- **Гележегдиз гел тамир.** Заглушка анжах ам кӏвалахдай вахтунда аваз жеда: бицӏи exe кутунин вахтунда тешкилзава ва акъвазарайла тергзава. Программадай экъечӏайла вири акъвазда, хаталу куьтягь хьуникай амукьай файлар кьатӏидай сеферда кардик кутайла михьизва.
- **Тиш раж.** Системадин трейда яшамиш жезва, заглушкаяр патал кьилдин пэнжерар ва я тапшуругърин панелдал кнопкаяр авач.
- **Ахъа таржумаяр.** Интерфейсди фагьумлу JSON файлардал кӏвалахзава, гьавиляй цӏийи чӏал кутун — са файл я. Инглис ва урус чӏалар ква.
- **Хсусивал.** Аккаунт авач, Discord токен авач, телеметрия авач. Килиг: [Хсусивал](#хсусивал).

## Ида гьикӏ кӏвалахзава

1. Discord-ди куь компьютердал кутунвай процессар ахтармишуналди ва церан exe файлрин тӏварар ахъа сиягьдихъ галаз (`/api/v9/applications/detectable`) гекъигуналди куьне къугъун къугъвазва лагьана тайинарзава.
2. Decoy-ди гьа сиягь эцигзава ва квез кӏани къугъуна патал бицӏи заглушка-программа (120 КБ гергга, Rust чӏалал кхьенва ва Decoy-дик кутунва) вахтунин папкадиз сиягьдай тир exe файлдин тӏварцӏихъ галаз копи ийизва, мисал яз `.../cod26-cod.exe`.
3. Заглушкади са верхний уровеньдин пэнжер тешкилуникай гъейри са затӏни ийизвач, гьамни экрандилай яргъа эцигнава, гьавиляй квез ам садрани аквадач. Discord-ди анжах пэнжер гвай процесс кьабулзава, гьавиляй пэнжер тамам квачир процесс фикирда кьазвач.
4. 15 секундрилай Discord-ди и къугъун куь гилан гьал (активность) хьиз къалурзава.
5. Таймер куьтягь хьайила ва я куьне акъвазарунин төгме басмахайла, Decoy-ди процесс куьтягьзава ва файл тергзава. Windows-дин job object-ди заглушкаяр Decoy-дихъ галаз санал куьтягь хьун таъминзава, программа хатавилелди акъвазнатӏани.

## Кутун

[Releases](../../../../releases) ччинай хкягъа:

| Эцигун | Вучиз я |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Хкун (Installer).** Са кардик кутадайдав, администраторвилин ихтиярар герек туш, «Пуск» менюдиз алава ийизва ва деинсталлятор ква. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив (Portable).** Кӏани чкадиз ахъая ва `decoy.exe` кукӏура. Вири макъаматар адан къвалав гвай `data` папкада хуьзва, кардик кутадайдан профилдиз са затӏни кхьизвач. Терг авун патал папка терг авурла бес я. |

Эцигнавай файл `SHA256SUMS.txt` куьмекдалди ахтармиша (PowerShell-да `Get-FileHash <file>`).

Windows SmartScreen-ди чин тийир чапханачидикай хабардар ийиз жеда, вучиз лагьайтӏа сборкадиз цифрадин имза авач; нагагь куьн сборкадихъ чӏалахъ ятӏа, *Подробнее → Выполнить в любом случае* хкягъа.

Ихтиярар: Windows 10 ва я 11 (64-бит) WebView2 runtime-дихъ галаз (Windows 11-дик ва Windows 10-дин эхиримжи цӏийи хъувунрик кутунва).

## Кардик кутун

1. **Библиотека** ахъая ва къугъун жагъура, ва я гьина хьайитӏани `Ctrl` + `K` басмаха.
2. Къугъундин винел илиса. Эрф патан панелда процесс ва ам шумуд декӏикьада хуьдатӏа хкягъа (Discord тапшуругъра адет яз 15 декӏикьа жезва).
3. **Заглушка кутун** басмаха. Са кьадар секундрилай Discord-ди къугъун къалурда.
4. **Кутунва** вкладкада адаз гуьзчивал ая, са затӏ ва я вири кӏани вахтунда акъвазара, ва я Decoy трейда тамир.

Discord-дин сиягьда exe квачир къугъунар сифте яз чуькьвенва (абур жагъуриз жедач). Абур акун патал *exe квачирбур къалурун* кукӏура; сиягь гьар юкъуз цӏийи хъувузва, гьавиляй Discord-ди процесс кутурла абур кардик акас жеда.

### Командайрин цӏар

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Заглушка гьасятда кутазва, мисал яз `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Чешмедай эцигун

Талабвилер: [Node.js](https://nodejs.org) 20+, багьаз [Rust](https://rustup.rs) гӀирсарин десте (MSVC target) Visual Studio C++ build tools-рихъ галаз, ва WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload-дихъ галаз талларан режимда кутун
npm run tauri build    # src-tauri/target/release/bundle/nsis-да хкун гьазурун
```

Багьа ахтармишунар:

```bash
npm run check-locales  # ru.json-дихъ галаз гьар са таржума ахтармишун
npx tsc --noEmit       # фронтенддин типар ахтармишун
cargo check --manifest-path src-tauri/Cargo.toml
```

Къейд: Decoy exe файл `src-tauri/build.rs` кӏвалахалди гьакӏан `rustc`-далди `src-tauri/stub/stub.rs` файлдай эцигзава ва программадик кутазва. Фронтенд гьакӏан браузерда кӏвалахдайла (`npm run dev`) бицӏи mock backend (`src/mock.ts`) кардик кутазва, им UI кӏвалахун патал къулай я.

## Таржумаяр

Интерфейсдин цӏарар [`src/locales`](../../src/locales) папкада ава, гьар са чӏалаз са JSON файл (`en.json`, `ru.json`, ...). Цӏийи чӏал кутун — са файл кутун я; код дегишариз герек туш. Файлдин формат, машинадин таржумадиз гьазур промпт ва ахтармишунин скрипт патал [docs/TRANSLATING.md](../TRANSLATING.md) килиг. И README-дин таржумаяр `docs/i18n/README.<code>.md` чкада ава.

## Хсусивал

- Decoy-ди анжах Discord-дин ахъа сиягь эцигун патал (сад лагьай сеферда кутайла, ахпа юкъуз садра ва я «Цӏийи хъувун» басмахайла) ва къалурун патал Discord-дин CDN-дай къугъунрин иконаяр ва суьретар эцигун патал маша кӏвалахарзава.
- Ада куь Discord токен ва я аккаунтдин макъаматар кӏелзавач, хуьзвач ва рекье твазвач, ва Discord клиентдихъ галаз рахунар ийизвач.
- Кӏвалахар (кӏанибур, чӏал, вахтар) чкадал WebView-дин ампарда хуьзва; къугъунрин сиягьдин кэш ва Decoy-дин вахтунин файлар `%LOCALAPPDATA%\app.decoy.desktop` папкада ава.
