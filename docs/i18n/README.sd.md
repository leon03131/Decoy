# Decoy

**ننڍڙا متبادل پروسيس جيڪي Discord کي يقين ڏيارين ٿا ته ڪا راند هلي رهي آهي.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="تازو راندين ۽ آرٽ ورڪ سان Decoy لائبريري" />

</div>

Decoy راند جي ايگزيڪيوٽيبل (executable) نالي هيٺ هڪ بي ضرر، ونڊو رکندڙ متبادل پروسيس هلائيندو رهي ٿو، جنهن ڪري Discord جي راند جي سڃاڻپ وارو نظام توهان کي اها راند کيڏندي ڏيکاري ٿو. توهان کي ڪڏهن به اصل راند انسٽال يا شروع ڪرڻ جي ضرورت نٿي پوي، ان ڪري توهان جي ڊسڪ تي ڪو به وڏو بار نٿو پوي.

هي **هر ان راند کان واقف آهي جنهن جي Discord سڃاڻپ ڪري سگهي ٿو** (تقريباً 25,000 داخلا)، ڇاڪاڻ ته هي Discord جي پنهنجي عوامي سڃاڻپ واري لسٽ پڙهي ٿو ۽ ان کي پاڻمرادو اپڊيٽ رکندو رهي ٿو.

> [!WARNING]
> هلندڙ راند جي نقالي ڪرڻ Discord جي سروس وارين شرطن جي خلاف ٿي سگهي ٿي ۽ توهان Decoy کي **پنهنجي ذميواري تي** استعمال ڪريو ٿا.
> هي پروجيڪٽ Discord Inc سان لاڳاپيل، ان جي توثيق ڪيل، يا ان سان ڳنڍيل ناهي. ڏسو [دستبرداري](#دستبرداري).

## خاصيتون

- **هر اها شيءِ جنهن جي Discord سڃاڻپ ڪري سگهي ٿو.** راندين جي لسٽ Discord جي عوامي اينڊ پوائنٽ تان ڊائون لوڊ ڪئي ويندي آهي، مقامي طور ڪيش ٿيندي آهي ۽ روزانو تازي ڪئي ويندي آهي. نيون رانديون ۽ نيون شامل ڪيل ايگزيڪيوٽيبلز پاڻمرادو ظاهر ٿينديون آهن.
- **تيز ڳولا.** راند جي نالي يا ايگزيڪيوٽيبل ذريعي هزارين راندين مان فوري ڳولا، گرڊ يا ڪمپيڪٽ لسٽ ويئو، پسنديده (favorites) ۽ هڪ "تازو" قطار.
- **هڪ ڪلڪ.** راند چونڊيو، ايگزيڪيوٽيبل چونڊيو (جيڪڏهن هڪ کان وڌيڪ هجن)، چونڊيو ته ان کي ڪيتري دير هلائڻو آهي ۽ اسٽارٽ دٻايو. هڪ الٽي ڳڻپ واري رنگ ۽ هڪ نوٽيفيڪيشن توهان کي وقت پورو ٿيڻ تي آگاهه ڪن ٿا.
- **پٺيان ڪجھ به نٿو ڇڏي.** هڪ decoy رڳو تڏهن تائين موجود رهي ٿو جڏهن اهو هلي رهيو هجي: ننڍڙو exe شروعات تي ٺاهيو وڃي ٿو ۽ بند ٿيڻ تي ختم ڪيو وڃي ٿو. جڏهن توهان نڪري وڃو ٿا ته سڀ ڪجھ روڪيو وڃي ٿو، ۽ ڪنهن ڪريش جا بچيل حصا ايندڙ شروعات تي صاف ڪيا وڃن ٿا.
- **خاموش.** سسٽم ٽري ۾ رهي ٿو، decoys لاءِ پنهنجي ڪا به ونڊو يا ٽاسڪ بار بٽڻ ناهي.
- **کليل ترجما.** انٽرفيس عام JSON فائلن ذريعي هلي ٿو، تنهنڪري نئين ٻولي شامل ڪرڻ رڳو هڪ فائل جو ڪم آهي. انگريزي ۽ روسي اڳ ئي شامل آهن.
- **رازداري.** ڪو اڪائونٽ ناهي، ڪو Discord ٽوڪن ناهي، ڪا به ٽيلي ميٽري ناهي. ڏسو [رازداري](#رازداري).

## هي ڪيئن ڪم ڪري ٿو

1. Discord توهان جي پي سي تي هلندڙ پروسيسز کي ڏسي ۽ انهن جي ايگزيڪيوٽيبل نالن جو مقابلو هڪ عوامي لسٽ (`/api/v9/applications/detectable`) سان ڪري اهو فيصلو ڪري ٿو ته توهان ڪا راند کيڏي رهيا آهيو.
2. Decoy ان لسٽ کي ڊائون لوڊ ڪري ٿو ۽، توهان جي چونڊيل راند لاءِ، لسٽ مان ايگزيڪيوٽيبل جو نالو استعمال ڪندي هڪ عارضي فولڊر ۾ هڪ ننڍڙو متبادل پروگرام (تقريباً 120 KB، Rust ۾ لکيل ۽ Decoy ۾ شامل ٿيل) ڪاپي ڪري ٿو، مثال طور `.../cod26-cod.exe`.
3. اهو متبادل پروگرام ان کان سواءِ ڪجھ به نٿو ڪري ته ان وٽ هڪ ٽاپ ليول ونڊو هوندي آهي، جيڪا اسڪرين کان پري رکيل هوندي آهي ته جيئن توهان ان کي ڪڏهن به نه ڏسي سگهو. Discord صرف اهڙي پروسيس جي سڃاڻپ ڪري ٿو جنهن وٽ ڪا ونڊو هجي، ان ڪري بلڪل بي ونڊو پروسيس کي نظرانداز ڪيو ويندو آهي.
4. تقريباً 15 سيڪنڊن اندر Discord اها راند توهان جي موجوده سرگرمي طور ڏيکاري ٿو.
5. جڏهن ٽائيمر پورو ٿئي ٿو يا توهان اسٽاپ دٻايو ٿا، Decoy پروسيس ختم ڪري ٿو ۽ فائل کي ڊليٽ ڪري ٿو. هڪ Windows job object پڪ ڪري ٿو ته decoys خود Decoy سان گڏ ئي ختم ٿين، توڙي جو اهو ڪريش ئي ڇو نه ٿئي.

## انسٽال ڪريو

[Releases](../../../../releases) صفحي تان ڪو هڪ چونڊيو:

| ڊائون لوڊ | لاءِ |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **انسٽالر.** في صارف، ايڊمنسٽريٽر اختيارن جي ضرورت ناهي، اسٽارٽ مينيو اندراج ۽ هڪ ان‌انسٽالر شامل ڪري ٿو. |
| `Decoy_x.y.z_x64-portable.zip` | **پورٽيبل.** ڪٿي به ان‌زپ ڪريو ۽ `decoy.exe` هلايو. سڀ ڊيٽا ان جي ڀرسان موجود `data` فولڊر ۾ رهي ٿو، توهان جي يوزر پروفائل ۾ ڪجھ به نٿو لکيو وڃي. هٽائڻ لاءِ فولڊر ڊليٽ ڪريو. |

ڊائون لوڊ جي تصديق `SHA256SUMS.txt` سان ڪريو (PowerShell ۾ `Get-FileHash <file>`).

Windows SmartScreen غير سڃاتل پبلشر بابت خبردار ڪري سگهي ٿو ڇاڪاڻ ته بلڊز ڪوڊ سائن ٿيل ناهن؛ جيڪڏهن توهان کي بلڊ تي ڀروسو آهي ته *More info → Run anyway* چونڊيو.

گهربل شيون: Windows 10 يا 11 (64-bit) مع WebView2 رن ٽائيم (جيڪو اڳ ئي Windows 11 ۽ تازين Windows 10 اپڊيٽس ۾ شامل آهي).

## استعمال جو طريقو

1. **Library** کوليو ۽ ڪا راند ڳوليو، يا ڪٿان به `Ctrl` + `K` دٻايو.
2. ڪنهن راند تي ڪلڪ ڪريو. ساڄي پاسي واري پينل ۾ پروسيس ۽ منٽن جو مدو چونڊيو ته ان کي ڪيتري دير هلائڻو آهي (Discord جون سرگرميون عام طور تي 15 منٽ گهرن ٿيون).
3. **Start decoy** دٻايو. Discord ڪجھ سيڪنڊن کانپوءِ راند ڏيکارڻ شروع ڪندو.
4. ان کي **Running** هيٺ ڏسو، ڪنهن هڪ يا سڀني کي ڪنهن به وقت روڪيو، يا صرف Decoy کي ٽري ۾ رهڻ ڏيو.

جن راندين جي Discord داخلا ۾ اڃا ڪا به ايگزيڪيوٽيبل ناهي اهي اڳواٽ لڪيل آهن (انهن جي سڃاڻپ نٿي ٿي سگهي). انهن کي ڏسڻ لاءِ
*Show games without exe* آن ڪريو؛ لسٽ روزانو اپڊيٽ ڪئي ويندي آهي، ان ڪري جيئن ئي Discord ڪو پروسيس شامل ڪندو، اهي دستياب ٿي وينديون.

### ڪمانڊ لائن

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

فوري طور تي هڪ decoy شروع ڪري ٿو، مثال طور `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## سورس مان بلڊ ڪريو

تياريون: [Node.js](https://nodejs.org) 20+، مستحڪم [Rust](https://rustup.rs) ٽول چين (MSVC ٽارگيٽ) مع Visual Studio C++ بلڊ ٽولز، ۽ WebView2 رن ٽائيم.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

مفيد جاچ پڙتال:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

نوٽس: decoy exe کي `src-tauri/build.rs` ذريعي سادي `rustc` سان `src-tauri/stub/stub.rs` مان ڪمپائيل ڪيو ويندو آهي ۽ پوءِ ايپ ۾ ايمبيڊ ڪيو ويندو آهي. جڏهن فرنٽ اينڊ عام برائوزر ۾ هلندو آهي (`npm run dev`) ته هڪ ننڍڙو موڪ بيڪ اينڊ (`src/mock.ts`) استعمال ڪيو ويندو آهي، جيڪو UI تي ڪم ڪرڻ لاءِ ڪارائتو آهي.

## ترجما

UI جون اسٽرنگز [`src/locales`](../../src/locales) ۾ رهن ٿيون، في ٻولي هڪ JSON فائل (`en.json`, `ru.json`, ...).
نئين ٻولي شامل ڪرڻ جو مطلب رڳو هڪ فائل جو اضافو آهي؛ ڪوڊ ۾ ڪا تبديلي ناهي. فائل فارميٽ، مشين ٽرانسليشن لاءِ تيار پرامپٽ ۽ تصديق واري اسڪرپٽ لاءِ [docs/TRANSLATING.md](../TRANSLATING.md) ڏسو. هن README جا ترجما `docs/i18n/README.<code>.md` ۾ وڃن ٿا.

## پروجيڪٽ جو ڍانچو

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## رازداري

- Decoy نيٽ ورڪ رڳو Discord جي عوامي سڃاڻپ واري لسٽ ڊائون لوڊ ڪرڻ لاءِ استعمال ڪري ٿو (پهريون ڀيرو هلائڻ تي، پوءِ وڌ ۾ وڌ ڏينهن ۾ هڪ ڀيرو يا جڏهن توهان ريفريش دٻايو) ۽ ڏيک لاءِ، راندين جا آئڪن ۽ آرٽ ورڪ Discord جي عوامي CDN تان آڻڻ لاءِ.
- هي توهان جو Discord ٽوڪن يا اڪائونٽ جو ڪو به ڊيٽا نه پڙهي ٿو، نه اسٽور ڪري ٿو ۽ نه ئي موڪلي ٿو، ۽ هي Discord ڪلائنٽ سان ڳالهه ٻولهه نٿو ڪري.
- ترتيبون (پسنديده، ٻولي، مدي) مقامي طور تي ايپ جي WebView اسٽوريج ۾ محفوظ ٿين ٿيون؛ راندين جي لسٽ جو ڪيش ۽ عارضي decoy فائلون `%LOCALAPPDATA%\app.decoy.desktop` ۾ رهن ٿيون.
- ڪا اينالائيٽڪس ناهي، ڪا ڪريش رپورٽنگ ناهي، ڪي به کاتا (accounts) ناهن.

## ڄاتل حدون

- Discord ڪنهن به وقت سڃاڻپ جو طريقو بدلائي سگهي ٿو. جيڪڏهن ڪنهن decoy جي سڃاڻپ بند ٿي وڃي، ته مهرباني ڪري هڪ مسئلو (issue) کوليو.
- ڪجھ سرگرمين کي رڳو هلندڙ پروسيس کان وڌيڪ جي ضرورت هوندي آهي (مثال طور ڪنهن راند واري پليٽ فارم جي مخصوص تجربي اندر هجڻ). Decoy رڳو پروسيس جي نقالي ڪري ٿو.
- Discord جي لسٽ ۾ بغير ايگزيڪيوٽيبل وارين داخلائن جي سڃاڻپ نٿي ٿي سگهي.
- سيڪيورٽي سافٽ ويئر ڪڏهن ڪڏهن انهن ننڍڙن غير دستخط ٿيل ايگزيڪيوٽيبلز تي الرٽ ڏئي سگهن ٿا جيڪي ميموري ۾ بيڪار پيل هجن. decoy اوپن سورس آهي ۽ `src-tauri/stub/stub.rs` مان تيار ڪيو ويو آهي؛ توهان ان کي پنهنجي پاڻ ڪمپائيل ڪري سگهو ٿا.

## دستبرداري

Decoy ذاتي، تعليمي ۽ آزمائشي مقصدن لاءِ "جيئن آهي" بنياد تي مهيا ڪيو ويو آهي. هلندڙ راند جي نقالي ڪرڻ Discord يا راند جي پبلشر جي سروس جي شرطن جي ڀڃڪڙي ٿي سگهي ٿي، ۽ توهان جي کاتي خلاف ڪارروائي جو سبب بڻجي سگهي ٿي. ان کي ڪيئن استعمال ڪرڻو آهي ان جا ذميوار رڳو توهان آهيو. "Discord" ۽ سمورين راندين جا نالا ۽ لوگوز انهن جي لاڳاپيل مالڪن جا ٽريڊمارڪ آهن ۽ هتي رڳو ان سافٽ ويئر جي سڃاڻپ لاءِ استعمال ڪيا ويا آهن جنهن جو اهي حوالو ڏين ٿا.
