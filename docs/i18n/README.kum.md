# Decoy

**Discord-гъа оюн юрюле деп гёрсетмек учун гиччи ялгъан процесслер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Артдагъы оюнлар ва суратлар булан Decoy китапханасы" />

</div>

Decoy оюнну юрюлювчю файлыны аты булан зарарсыз, терезели ялгъан процессни юрютюп тура, шо саялы Discord оюнланы таныв системасы сизин шо оюнну ойнай деп гёрсете. Сизге герти оюнну салмагъа яда юрютмеге тарыкъ тюгюл, шо саялы дискигизде уллу затлар ятмай.

Ол **Discord танып болагъан гьар оюнну** биле (25 000-ге ювукъ язма), неге тюгюл ол Discord-ну оьзюню ачыкъ сиягьын окъуй ва ону оьзю янгыртып тура.

> [!WARNING]
> Оюнну юрюлювюн ялгъан кюйде гёрсетмек Discord-ну Къуллукъ этилив шартларына къаршы болмагъа ярай ва сиз Decoy-ну **оьз жавапчылыгъыгъыз булан** къоллайсыз.
> Бу проект Discord Inc. булан байлавлу тюгюл, якъланмагъан ва ону булан бир алакъасы да ёкъ. [Жавапчылыкъдан баш тартыв](#жавапчылыкъдан-баш-тартыв) бёлюгюн къарагъыз.

## Хусусиятлары

- **Discord танып болагъан бары да зат.** Оюнланы сиягьы Discord-ну ачыкъ таныв нокъатындан юклене, ерли кэшлана ва гюн сайын янгыртыла. Янгы оюнлар ва янгы къошулгъан exe файллар оьзлюгюнден чыгъа.
- **Тез излев.** Минглер булан оюн арасында оюн ат яда exe аты булан лап тез излев, плиткалар яда къысгъа сиягь гёрюнюшю, сайлангъанлар ва «Артдагъылар» сыдырасы.
- **Бир басыв булан.** Оюнну сайлагъыз, exe файлын сайлагъыз (бир нечесе бар буса), нечакъы тутуп токътамагъа герекни белгилегиз ва башлавгъа басыгъыз. Санав чархы ва билдирив заман чыкъгъанны хабарлай.
- **Ызын къоймай.** Decoy тек юрюлген заманда яшай: гиччи exe башлагъанда яратыла ва токътатгъанда гетериле. Программадан чыкъгъанда барысы да токътатыла, алда авариялардан къалгъан къалдыклар буса гезикли башлавда тазалана.
- **Тынч.** Система трейинде яшай, decoy процесслерини оьзлери учун бир де терезе яда масъалалар тахтасында тюймелер болмай.
- **Ачыкъ таржималар.** Интерфейс апи-ачыкъ JSON файллар булан ишлей, шо саялы янгы тил къошув — тек бир файл къошув. Инглиз ва орус тиллер ичинде бар.
- **Шяхсылыкъ.** Гьисап язылыву (аккаунт), Discord токени ва телеметрия ёкъ. [Шяхсылыкъ](#шяхсылыкъ) бёлюгюн къарагъыз.

## Бу нечик ишлей

1. Discord санакда юрюлеген процесслерге къарап ва оланы exe атларын ачыкъ сиягь (`/api/v9/applications/detectable`) булан тенглешдирип, сизин оюн ойнай деп белгилей.
2. Decoy шо сиягьны юклей ва, сиз сайлагъан оюн учун, сиягьдагъы exe атын къоллап (мисал учун, `.../cod26-cod.exe`), заманлыкъ папкагъа гиччи орунбасар программаны (120 КБ чакъы, Rust тилде язылгъан ва Decoy ичине салынган) гёчюре.
3. Орунбасар программа бир иш де этмей, тек сиз ону гёрмес учун экрандан йыракъда ерлешген бир баш даража терезеге иелик эте. Discord тек терезеси бар процесслерни таный, шо саялы тамам терезесиз процесс тергелмей къала.
4. 15 секундну ичинде Discord оюнну сизин гьалиги ишигиз гьисабында гёрсете.
5. Таймер битгенде яда токътатмакъгъа басгъанда, Decoy процессни тамамлай ва файлны тайдыра. Windows job объекти гьатта Decoy авария булан токътаса да бары decoy-ланы бирге ябылывун якълай.

## Салыв

[Releases](../../../../releases) бетинден бирисин сайлагъыз:

| Юклемек | Негер |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Салывчу.** Гьар къолланывчу учун, администратор ихтиярлары тарыкъ тюгюл, «Башлав» (Start) менюсуна языв ва тайдырывчу (uninstaller) къоша. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Къайсы ерге де чыгъарып, `decoy.exe` юрютесиз. Бары маълумат янындагъы `data` папкасында сакълана, профилингызгъа бир зат да язылмай. Папканы гетерип бары затны тайдырып боласыз. |

Юклеген файлны `SHA256SUMS.txt` булан тергегиз (PowerShell ичинде `Get-FileHash <файл>`).

Яратылгъан къурулушланы санлы къолу (code sign) болмагъаны саялы, Windows SmartScreen танылмагъан басмачы деп эсгертип билер; эгер къурулушгъа инана бусагъыз, *More info → Run anyway* сайлагъыз.

Талаплар: WebView2 runtime булан Windows 10 яда 11 (64-бит) (Windows 11 ва артдагъы Windows 10 янгыртывларында бар).

## Къоллав

1. **Китапхана**ны ачыгъыз ва оюн излегиз, яда къайдан да болсун `Ctrl` + `K` басыгъыз.
2. Оюнну басыгъыз. Онгдагъы панелде процессни ва ону нечакъы минут сакъламагъа тарыкъны сайлагъыз (Discord тапшурувлары адетде 15 минут сорай).
3. **Decoy юрютмек** дегенге басыгъыз. Discord бир нече секунддан сонг оюнну гёрсетежек.
4. Ону **Юрюле** тюбюнде гёзден гечиригиз, бирде-бир вакътиде биревин яда барысын да токътатыгъыз, яда Decoy-ну трейде къоюгъуз.

Discord язмасында гьалиге exe файлы болмагъан оюнлар адетде яшырылгъан (оланы танып болмай). Оланы гёрмек учун *Exe ёкъ оюнланы да гёрсетмек* дегенни къошугъуз; сиягь гюн сайын янгыртыла, шо саялы Discord процессни къошгъан заманда олар ачыкъ болар.

### Командалар сыдырасы

```
decoy.exe --launch "<Discord сиягьындагъы exe файлыны ёлу>" [минутлар]
```

Decoy-ну шоссагьат башлай, мисал учун: `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Чешме коддан жыйыв

Герекли алатлар: [Node.js](https://nodejs.org) 20+, Visual Studio C++ къурув алатлары булан токъташгъан [Rust](https://rustup.rs) къураллар жыйымы (MSVC target) ва WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # чалт янгыртыв (hot reload) булан сынав режиминде юрютмек
npm run tauri build    # installer пакетин src-tauri/target/release/bundle/nsis ичинде къурмакъ
```

Пайдалы тергевлер:

```bash
npm run check-locales  # гьар таржима файлын ru.json булан тергемек
npx tsc --noEmit       # фронтенд типлерин тергемек
cargo check --manifest-path src-tauri/Cargo.toml
```

Эсгеривлер: decoy exe файлы `src-tauri/build.rs` булан `src-tauri/stub/stub.rs` чешмесинден апи-ачыкъ `rustc` булан жыйыла ва программагъа салына. Фронтенд янгыз браузерде юрюлгенде (`npm run dev`), гиччи ялгъан бэкенд (`src/mock.ts`) къоллана, бу UI булан ишлемеге бек къолай.

## Таржималар

Интерфейс тизгилери [`src/locales`](../../src/locales) ичинде, гьар тил учун бир JSON файл болуп сакълана (`en.json`, `ru.json`, ...).
Янгы тил къошмакъ бир файл къошмакъны англата; кодну алышдырмагъа герек тюгюл. Файл форматы, машина таржимасы учун гьазир тилев (prompt) ва тергев скрипти учун [docs/TRANSLATING.md](../TRANSLATING.md) файлын къарагъыз. Бу README-ни таржималары `docs/i18n/README.<code>.md` папкасына салына.

## Проект къурулушу

```
src/                    React + TypeScript фронтенд
  components/           Китапхана, детал панель, кюйлевлер, ...
  locales/              таржима файллары (гьар тил учун бир JSON)
  i18n-core.ts          тилни юклемек ва тапмакъ
  store.ts              программа гьали (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            оюнлар базасы, Decoy процесслери, трей
  stub/stub.rs          ичине салынагъан орунбасар программа
scripts/                кёмекчи скриптлер (локалланы тергев)
docs/                   таржима ёлгёрсетивю, скриншотлар
```

## Шяхсылыкъ

- Decoy сетьни тек Discord-ну ачыкъ таныв сиягьын юклемек учун (биринчи башлагъанда, сонг гюнюне кёбюси бир керен яда янгыртмакъгъа басгъанда) ва оюнланы тамгъаларын суратларын Discord ачыкъ CDN-ден гёрсетмек учун къоллай.
- Ол сизин Discord токенигизни яда бир де гьисап маълуматыгъызны окъумай, сакъламай ва йибермей, ва Discord клиенти булан лакъыр этмей.
- Кюйлевлер (сайлангъанлар, тил, заманлар) программаны WebView сакълавында ерли сакълана; оюнлар сиягьыны кэши ва вакътилик decoy файллары `%LOCALAPPDATA%\app.decoy.desktop` ичинде яшай.
- Аналитика ёкъ, авария хабарлары ёкъ, аккаунтлар ёкъ.

## Белгили чеклевлер

- Discord таныв къайдасын къайсы вакътиде де алышдырып бола. Эгер decoy танылмай къалса, тилейбиз, issue ачыгъыз.
- Бир-бир ишлер тек юрюлеген процессден артыкъны излей (мисал учун оюн платформасыны белгили бир сыновун ичинде болмакъ). Decoy тек процессни ошатып гёрсете.
- Discord сиягьында exe файлы болмагъан язмалар танылмай.
- Къоркъунчсузлукъ программалары эсде бош токътагъан имзаланмагъан гиччи exe файлларны ара-сыра шекли деп белгилеп биле. Decoy ачыкъ чешмели ва `src-tauri/stub/stub.rs` чешмесинден къурула; ону оьзюгюз жыйып боласыз.

## Жавапчылыкъдан баш тартыв

Decoy шяхсы, билим алыв ва сынав муратлар учун «болгъан кюйде» бериле. Юрюлеген оюнну ялгъан ошатыв Discord-ну яда оюн чыгъарывучуну Къуллукъ этилив шартларын бузмагъа ярай ва сизин аккаунтугъузгъа къаршы чаралар гёрюлювге гелтирмеге ярай. Ону нечик къоллайгъаныгъызгъа тек оьзюгюз жавап бересиз. «Discord» ва бары оюн атлары ва логотиплери оланы иелерини белгилери булып тора ва мунда тек тийишли программаны танытмакъ учун къоллана.
