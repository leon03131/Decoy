# Decoy

**Discord ጨዋታ እየተጫወቱ እንደሆነ እንዲያስብ የሚያደርጉ ጥቃቅን ተተኪ ሂደቶች (processes)።**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="የDecoy ቤተ-መጽሐፍት ከቅርብ ጊዜ ጨዋታዎች እና ምስሎች ጋር" />

</div>

Decoy ጉዳት የሌለው እና በመስኮት የሚታይ ተተኪ ሂደት በአንድ ጨዋታ የexecutable ስም እንዲሰራ ያደርጋል፤ በዚህም የDiscord የጨዋታ መለያ ያንን ጨዋታ እየተጫወቱ እንዳሉ ሪፖርት ያደርጋል። ትክክለኛውን ጨዋታ መጫን ወይም ማስጀመር በጭራሽ አያስፈልግዎትም፣ ስለዚህ በኮምፒውተርዎ ዲስክ ላይ ምንም ትልቅ ቦታ የሚይዝ ነገር አይኖርም።

Discord **ሊያውቃቸው የሚችላቸውን ሁሉንም ጨዋታዎች** (ወደ 25,000 የሚጠጉ) ያውቃል፣ ምክንያቱም የDiscordን ይፋዊ የመለያ ዝርዝር ስለሚያነብ እና ራሱ በራሱ ወቅታዊ ስለሚያደርግ ነው።

> [!WARNING]
> ጨዋታ እየሄደ እንደሆነ ማስመሰል የDiscordን የአገልግሎት ውል (Terms of Service) ሊጥስ ይችላል እና Decoyን የሚጠቀሙት **በራስዎ ኃላፊነት** ነው።
> ይህ ፕሮጀክት ከDiscord Inc. ጋር ምንም ዓይነት ግንኙነት የለውም፣ አልተደገፈም ወይም አልተያያዘም። [የኃላፊነት ማስተባበያ](#የኃላፊነት-ማስተባበያ) ይመልከቱ።

## ገጽታዎች

- **Discord ሊያውቃቸው የሚችላቸው ነገሮች በሙሉ።** የጨዋታው ዝርዝር ከDiscord ይፋዊ የመለያ endpoint ይወርዳል፣ በኮምፒውተርዎ ውስጥ በካሽ ይቀመጣል እንዲሁም በየቀኑ ይታደሳል። አዳዲስ ጨዋታዎች እና አዲስ የተጨመሩ executables በራሳቸው ጊዜ ይታያሉ።
- **ፈጣን ፍለጋ።** በሺዎች በሚቆጠሩ ጨዋታዎች ውስጥ በጨዋታ ስም ወይም በexecutable ፈጣን ፍለጋ፣ የፍርግርግ (grid) ወይም የታመቀ ዝርዝር እይታ፣ ተወዳጆች እና "የቅርብ ጊዜ" ረድፍ።
- **በአንድ ጠቅታ።** ጨዋታ ይምረጡ፣ executable ይምረጡ (በርካታ ካሉ)፣ ለምን ያህል ጊዜ እንዲቆይ እንደሚፈልጉ ይወስኑ እና Start የሚለውን ይጫኑ። የጊዜ ቆጣሪ ቀለበት እና ማሳወቂያ ጊዜው ሲያበቃ ያሳውቁዎታል።
- **ምንም ዱካ አይተውም።** አንድ decoy የሚኖረው በሚሰራበት ጊዜ ብቻ ነው፡ ትንሿ exe ሲጀመር ትፈጠራለች እና ሲቆም ትሰረዛለች። ሲወጡ ሁሉም ነገር ይቆማል፣ እንዲሁም መተግበሪያው በድንገት ቢዘጋ (crash ቢያደርግ) የተረፉ ነገሮች በሚቀጥለው መክፈቻ ላይ ይጠረጋሉ።
- **ጸጥተኛ።** በሲስተም ትሬይ (system tray) ውስጥ ይኖራል፣ ለdecoys ምንም ዓይነት መስኮቶች ወይም የተግባር አሞሌ (taskbar) አዝራሮች አይኖሩም።
- **ክፍት ትርጉሞች።** የበይነገጹ ጽሑፎች የሚመሩት በቀላል JSON ፋይሎች ነው፣ ስለዚህ ቋንቋ ማከል አንድ ነጠላ ፋይል ብቻ ነው። እንግሊዝኛ እና ሩሲያኛ ተካትተዋል።
- **ግላዊነት የተጠበቀ።** መለያ አያስፈልግም፣ የDiscord token የለም፣ የቴሌሜትሪ መረጃ መሰብሰብ የለም። [ግላዊነት](#ግላዊነት) ይመልከቱ።

3. ተተኪው ፕሮግራም አንድ ከላይ ያለ መስኮት (top-level window) ከማስተናገድ ውጭ ምንም አያደርግም፣ ይህም እርስዎ እንዳያዩት ከማያ ገጹ በጣም ርቆ እንዲቀመጥ ተደርጓል። Discord መስኮት ያለውን ሂደት ብቻ ነው የሚያውቀው፤ መስኮት የሌለው ሂደት ችላ የሚባለው ለዚህ ነው።
4. በግምት በ15 ሰከንዶች ውስጥ Discord ጨዋታውን እንደ ወቅታዊ እንቅስቃሴዎ ያሳያል።
5. የጊዜ ቆጣሪው ሲያበቃ ወይም Stop የሚለውን ሲጫኑ Decoy ሂደቱን ያቆማል እና ፋይሉን ይሰርዛል። የWindows job object መተግበሪያው ቢዘጋም (crash ቢያደርግም) decoys ከDecoy ጋር አብረው እንዲጠፉ ያረጋግጣል።

ግንባታዎቹ (builds) በዲጂታል ፊርማ (code signed) ስላልተደረጉ Windows SmartScreen ባልታወቀ አታሚ ምክንያት ማስጠንቀቂያ ሊያሳይ ይችላል፤ ግንባታውን የሚያምኑት ከሆነ *More info → Run anyway* የሚለውን ይምረጡ።

መስፈርቶች፡ Windows 10 ወይም 11 (64-bit) ከWebView2 runtime ጋር (በWindows 11 እና በቅርብ ጊዜ የWindows 10 ዝማኔዎች ውስጥ ቀድሞውኑ ተካቷል)።

## አጠቃቀም

1. **Library** ይክፈቱ እና ጨዋታ ይፈልጉ፣ ወይም ከማንኛውም ቦታ `Ctrl` + `K` ይጫኑ።
2. ጨዋታን ጠቅ ያድርጉ። በቀኝ በኩል ባለው ፓነል ውስጥ ሂደቱን እና ለምን ያህል ደቂቃዎች እንዲቆይ እንደሚፈልጉ ይምረጡ (የDiscord activities አብዛኛውን ጊዜ 15 ደቂቃ ይጠይቃሉ)።
3. **Start decoy** የሚለውን ይጫኑ። Discord ከጥቂት ሰከንዶች በኋላ ጨዋታውን ያሳያል።
4. በ**Running** ስር ይመልከቱት፣ አንዱን ወይም ሁሉንም በማንኛውም ጊዜ ያቁሙ፣ ወይም Decoyን በሲስተም ትሬይ ውስጥ ይተዉት።

የDiscord ምዝገባቸው ገና executables የሌላቸው ጨዋታዎች በነባሪነት ተደብቀዋል (ሊታወቁ አይችሉም)። እነሱን ለማየት *Show games without exe* የሚለውን ያብሩ፤ ዝርዝሩ በየቀኑ ስለሚታደስ Discord ሂደትን እንዳከለ ወዲያውኑ ዝግጁ ይሆናሉ።

### የትእዛዝ መስመር (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

decoyን ወዲያውኑ ያስጀምራል፣ ለምሳሌ `decoy.exe --launch "robloxplayerbeta.exe" 15`።

## ከምንጩ መገንባት (Build from source)

ቅድመ-ሁኔታዎች፡ [Node.js](https://nodejs.org) 20+፣ የተረጋጋ የ[Rust](https://rustup.rs) መሣሪያ ስብስብ (MSVC target) ከVisual Studio C++ build tools ጋር፣ እና የWebView2 runtime።

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # በዴቨሎፕመንት ሁነታ በhot reload ያሂዱ
npm run tauri build    # ጫኙን በsrc-tauri/target/release/bundle/nsis ውስጥ ያዘጋጁ
```

ጠቃሚ ፍተሻዎች፡

```bash
npm run check-locales  # እያንዳንዱን የትርጉም ፋይል ከru.json አንጻር ያረጋግጡ
npx tsc --noEmit       # የfrontend አይነቶችን ያረጋግጡ
cargo check --manifest-path src-tauri/Cargo.toml
```

ማስታወሻዎች፡ የdecoy exe በ`src-tauri/build.rs` አማካኝነት በቀጥታ `rustc` ከ`src-tauri/stub/stub.rs` ተሰብስቦ (compile ተደርጎ) በመተግበሪያው ውስጥ ይካተታል። የfrontend ክፍል በመደበኛ አሳሽ (`npm run dev`) በሚሰራበት ጊዜ አነስተኛ mock backend (`src/mock.ts`) ጥቅም ላይ ይውላል፣ ይህም በUI ላይ ለመስራት ምቹ ነው።

## ግላዊነት

- Decoy ኔትወርክን የሚጠቀመው የDiscordን ይፋዊ የመለያ ዝርዝር ለማውረድ (በመጀመሪያ ሲከፈት፣ ከዚያም በቀን ቢበዛ አንድ ጊዜ ወይም refresh ሲጫኑ) እንዲሁም ለማሳያነት የጨዋታ አዶዎችን እና ምስሎችን ከDiscord ይፋዊ CDN ለማውረድ ብቻ ነው።
- የDiscord tokenዎን ወይም ማንኛውንም የመለያ ውሂብ አያነብም፣ አያስቀምጥም ወይም አይልክም፣ እንዲሁም ከDiscord client ጋር አይነጋገርም።
- ቅንብሮች (ተወዳጆች፣ ቋንቋ፣ የቆይታ ጊዜያት) በመተግበሪያው WebView ማከማቻ ውስጥ በአካባቢው ይቀመጣሉ፤ የጨዋታ ዝርዝር ካሽ እና ጊዜያዊ የdecoy ፋይሎች በ`%LOCALAPPDATA%\app.decoy.desktop` ውስጥ ይገኛሉ።
- ምንም አናሌቲክስ የለም፣ ምንም የብልሽት ሪፖርት የለም፣ ምንም መለያዎች የሉም።

- Discord የመለያ አሰራሩን በማንኛውም ጊዜ ሊለውጥ ይችላል። አንድ decoy መታወቁ ካቆመ፣ እባክዎ issue ይክፈቱ።
- አንዳንድ እንቅስቃሴዎች ከሚሰራ ሂደት የበለጠ ነገር ያስፈልጋቸዋል (ለምሳሌ በአንድ የጨዋታ መድረክ ልዩ ተሞክሮ ውስጥ መሆን)። Decoy ሂደቱን ብቻ ነው የሚመስለው።
- በDiscord ዝርዝር ውስጥ executables የሌሏቸው ምዝገባዎች ሊታወቁ አይችሉም።

Decoy ለግል፣ ለትምህርታዊ እና ለሙከራ ዓላማዎች "እንደነበረው" (as is) የቀረበ ነው። የሚሰራ ጨዋታን መምሰል የDiscordን ወይም የጨዋታውን አሳታሚ የአገልግሎት ውል (Terms of Service) ሊጥስ ይችላል፣ እና በመለያዎ ላይ እርምጃ እንዲወሰድ ሊያደርግ ይችላል። እንዴት እንደሚጠቀሙበት ኃላፊነቱ የራስዎ ብቻ ነው። "Discord" እና ሁሉም የጨዋታ ስሞች እና አርማዎች የየባለቤቶቻቸው የንግድ ምልክቶች ናቸው እና እዚህ ጥቅም ላይ የዋሉት የሚያመለክቱትን ሶፍትዌር ለመለየት ብቻ ነው።
