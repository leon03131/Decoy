# Decoy

**Tiny stand-in ghost vessels that trick Discord into believin' yer playin' a game.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy Ship's Log with recent booty and artwork" />

</div>

Decoy keeps a harmless phantom placeholder process sailin' under a game's executable moniker, foolin' Discord's
scouts into reportin' ye as sailin' that game. Ye never need to board or install the real behemoth of a game, so
nary a heavy chest clutters yer hard drive.

It knows of **every game Discord can spot across the seven seas** (about 25,000 entries) because it peruses Discord's
own public detection charts and keeps 'em shipshape on its own.

> [!WARNING]
> Fakin' a sailin' vessel can breach Discord's Pirate Code (Terms of Service), and ye take the helm of Decoy **at yer own peril**.
> This vessel be not allied with, endorsed by, nor tied to Discord Inc. See [Disclaimer](#disclaimer).

## Ship's Capabilities

- **Every vessel Discord can spot.** The sea charts be fetched straight from Discord's public harbor endpoint, stowed
  away locally, and freshened daily. New games and fresh executables show up on the charts all on their own.
- **Search that keeps the pace.** Swift huntin' by game moniker or executable across thousands of titles, cargo grid or compact
  scroll view, a Treasure Chest for favorites, and a "Recent booty" row.
- **Single click to hoist colors.** Pick yer plunder, pick the executable (if there be a fleet of 'em), choose how long
  to keep sailin', and strike start. A countdown glass and a ship's bell alert ye when the sand runs dry.
- **Leaves nary a trace.** A decoy only walks the deck while it sails: the tiny exe be conjured upon start and thrown
  overboard upon drop anchor. All vessels be scuttled when ye quit, and any wreckage from a squall be scrubbed clean on the next launch.
- **Silent as the night.** Stows away quietly in the system tray, with no porthole windows or taskbar clutter for the decoys themselves.
- **Open sea tongues.** The deck interface runs on plain JSON scrolls, so chartin' a new tongue takes but a single scroll.
  English, Pirate English, and Russian come in the chest.
- **Guarded like buried treasure.** No account, no Discord token, no prying eyes or telemetry. See [Privacy](#privacy).

## How the magic works

1. Discord decides ye be playin' a game by scoutin' the processes sailin' on yer rig and checkin' their
   executable monikers against a public scroll (`/api/v9/applications/detectable`).
2. Decoy fetches that scroll and, for the game ye pick, copies a tiny stand-in craft (about 120 KB, forged in
   Rust and stowed inside Decoy) into a temporary hold using the executable moniker from the scroll, for instance
   `.../cod26-cod.exe`.
3. The ghost craft does naught but hold open one top-level porthole window, moored far beyond the edge of yer screen so ye never spy it. Discord
   only salutes a process that flies a window, which is why a completely windowless ghost is ignored by their scouts.
4. Within roughly 15 seconds, Discord hoists yer colors and reports the game as yer current voyage.
5. When the sandglass empties or ye drop anchor, Decoy scuttles the process and tosses the file to Davy Jones' locker. A Windows job object makes
   sure decoys sink together with Decoy, even if a kraken crashes the main ship.

## Boarding & Install

Plunder a copy from the [Releases](../../../../releases) dock:

| Plunder | For |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Ship's Rigger (Installer).** Per-crewman, requires no Admiral rights, drops an anchor in the Start menu with an uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Chest on the go (Portable).** Unpack anywhere and launch `decoy.exe`. All charts stay in the `data` hold next to it; nary a scratch touches yer user quarters. Cast the folder into the deep to remove it. |

Inspect yer cargo with `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen might holler about an unrecognized captain because our builds bear no paid seal; choose
*More info → Run anyway* if ye trust the crew.

Ship's requirements: Windows 10 or 11 (64-bit) with the WebView2 riggin' (already aboard Windows 11 and recent Windows 10 updates).

## How to Set Sail

1. Pry open the **Ship's Log** and hunt for a game, or strike `Ctrl` + `K` from any station.
2. Click upon a game. In the starboard panel, choose the process and how many glasses to keep sailin' (Discord quests usually ask for 15 min).
3. Strike **Set sail!**. Discord will spot yer colors in a few heartbeats.
4. Keep watch under **Sailin'**, drop anchor on one or all vessels whenever ye please, or stow Decoy away in the tray.

Games whose Discord charts carry no executable yet are hidden below deck by default (they cannot be spotted). Toggle
*Show games without exe* to spy 'em; charts be renewed daily, so they become fit to sail as soon as Discord logs a process.

### Ship's Helm (Command line)

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Sets sail on a decoy right away, for example `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Rigging from Source

Prerequisites: [Node.js](https://nodejs.org) 20+, the sturdy [Rust](https://rustup.rs) toolchain (MSVC target) with
Visual Studio C++ build tools, and the WebView2 engine.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # sail in development mode with live rigging
npm run tauri build    # forge the installer in src-tauri/target/release/bundle/nsis
```

Handy ship inspections:

```bash
npm run check-locales  # verify every tongue scroll against ru.json
npx tsc --noEmit       # inspect the frontend types
cargo check --manifest-path src-tauri/Cargo.toml
```

Ship's notes: the decoy exe is forged by `src-tauri/build.rs` using plain `rustc` from `src-tauri/stub/stub.rs` and
embedded straight into the vessel. When the frontend runs in a dry-dock browser (`npm run dev`), a mock backend
(`src/mock.ts`) takes the wheel, handy for designin' the deck.

## Tongues of the World

The ship's UI scrolls live in [`src/locales`](../../src/locales), one JSON scroll per tongue (`en.json`, `en-pirate.json`, `ru.json`, ...).
Chartin' a new tongue is as simple as addin' a file; no ship rebuilding required. Inspect [docs/TRANSLATING.md](../TRANSLATING.md) for the
file guidelines, a machine translator incantation, and the inspection script. Translations of this ship's log go to
`docs/i18n/README.<code>.md`.

## Ship's Hold & Layout

```
src/                    React + TypeScript deck
  components/           Ship's Log, detail helm, settings, ...
  locales/              tongue scrolls (one JSON per tongue)
  i18n-core.ts          tongue loader and lookup
  store.ts              quartermaster state (zustand)
src-tauri/              Rust boiler room (Tauri 2)
  src/lib.rs            game charts, decoy processes, tray
  stub/stub.rs          the phantom vessel that gets embedded
scripts/                deckhand scripts (locale inspection)
docs/                   translation guide, spyglass screenshots
```

## Privacy & Pirate Honor

- Decoy only hails the outside seas to fetch Discord's public detection charts (on maiden voyage, then at most once a day
  or when ye order a chart refresh) and to hoist game icons and artwork from Discord's public CDN.
- It never touches, hoards, nor broadcasts yer Discord token or account secrets, nor does it speak to the Discord client.
- Preferences (Treasure Chest, tongue, voyage lengths) are kept safe in the app's WebView hold; game charts cache and
  temporary decoy files rest in `%LOCALAPPDATA%\app.decoy.desktop`.
- Nary a spyglass tracker, no crash beacons, no accounts needed.

## Known Reefs & Hazards

- Discord may change how their lookouts spot games at any tide. If a decoy stops bein' spotted, please send word via an issue.
- Certain quests demand more than a floatin' vessel (such as bein' inside a specific world on a game platform). Decoy only mimics the vessel process.
- Entries lackin' executables in Discord's charts cannot be spotted.
- Overzealous guard dogs (antivirus) occasionally bark at small unsigned binaries driftin' in memory. The decoy is open source
  and forged from `src-tauri/stub/stub.rs`; ye can forge it with yer own hammer.
