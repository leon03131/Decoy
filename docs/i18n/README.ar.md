# Decoy

**عمليات بديلة خفيفة تجعل Discord يعتقد أن هناك لعبة قيد التشغيل.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="مكتبة Decoy مع الألعاب الأخيرة والرسومات الفنية" />

</div>

يقوم Decoy بتشغيل عملية بديلة غير ضارة ذات نافذة تحت اسم الملف التنفيذي للعبة، بحيث يُظهر نظام اكتشاف الألعاب في Discord أنك تلعب تلك اللعبة. لست بحاجة أبداً لتثبيت اللعبة الحقيقية أو تشغيلها، وبالتالي لا يشغل أي مساحة كبيرة على قرصك.

يتعرف البرنامج على **كل لعبة يمكن لـ Discord اكتشافها** (حوالي 25,000 إدخال) لأنه يقرأ قائمة الاكتشاف العامة الخاصة بـ Discord ويحدّثها تلقائياً بنفسه.

> [!WARNING]
> قد يتعارض تزييف تشغيل لعبة مع شروط خدمة Discord، واستخدامك لـ Decoy يقع **على مسؤوليتك الخاصة**.
> هذا المشروع غير تابع لشركة Discord Inc أو معتمد منها أو مرتبط بها بأي شكل. راجع [إخلاء المسؤولية](#إخلاء-المسؤولية).

## الميزات

- **كل ما يمكن لـ Discord اكتشافه.** يتم تنزيل قائمة الألعاب من نقطة نهاية الاكتشاف العامة لـ Discord، وتخزينها مؤقتاً محلياً وتحديثها يومياً. تظهر الألعاب الجديدة والملفات التنفيذية المضافة حديثاً تلقائياً.
- **بحث سريع ومواكب.** بحث فوري باسم اللعبة أو الملف التنفيذي عبر آلاف الألعاب، وعرض شبكي أو قائمة مدمجة، وقائمة المفضلة، وشريط للألعاب "الحديثة".
- **بنقرة واحدة.** اختر اللعبة، وحدد الملف التنفيذي (إذا كان هناك أكثر من ملف)، واختر مدة التشغيل، ثم اضغط على بدء. تخبرك حلقة العد التنازلي وإشعار النظام عند انتهاء الوقت.
- **لا يترك أي أثر خلفه.** لا وجود لعملية التمويه إلا أثناء تشغيلها: يتم إنشاء ملف exe الصغير عند البدء وحذفه عند الإيقاف. يتوقف كل شيء عند الخروج، وتتم إزالة أي مخلفات ناتجة عن تعطل البرنامج تلقائياً عند التشغيل التالي.
- **هادئ وخفي.** يستقر في علبة النظام (system tray)، دون نوافذ ظاهرة أو أزرار في شريط المهام لعمليات التمويه نفسها.
- **ترجمات مفتوحة.** واجهة المستخدم تعتمد على ملفات JSON بسيطة، لذا فإن إضافة لغة جديدة يتطلب ملفاً واحداً فقط. اللغتان الإنجليزية والروسية مدمجتان بالفعل.
- **يحافظ على الخصوصية.** لا حسابات، لا رمز مصادقة (token) لـ Discord، ولا جمع لبيانات الاستخدام (telemetry). راجع [الخصوصية](#الخصوصية).

## كيف يعمل

1. يحدد Discord أنك تلعب لعبة معينة عبر فحص العمليات قيد التشغيل على جهازك ومقارنة أسماء ملفاتها التنفيذية بقائمة عامة (`/api/v9/applications/detectable`).
2. يقوم Decoy بتنزيل تلك القائمة، وبالنسبة للعبة التي تختارها، ينسخ برنامجاً بديلاً صغيراً (حوالي 120 كيلوبايت، مكتوب بلغة Rust ومدمج داخل Decoy) إلى مجلد مؤقت مستخدماً اسم الملف التنفيذي من القائمة، على سبيل المثال `.../cod26-cod.exe`.
3. لا يقوم هذا البرنامج البديل بأي شيء سوى امتلاك نافذة رئيسية واحدة متمركزة بعيداً خارج حدود الشاشة حتى لا تراها إطلاقاً. يتعرف Discord فقط على العمليات التي تمتلك نافذة، ولهذا السبب يتم تجاهل أي عملية ليس لها نافذة تماماً.
4. خلال قرابة 15 ثانية، يُظهر Discord اللعبة كنشاطك الحالي.
5. عندما ينتهي المؤقت أو تضغط على إيقاف، يُنهي Decoy العملية ويحذف الملف. كما يضمن كائن المهام في Windows (job object) إغلاق جميع عمليات التمويه مع إغلاق Decoy، حتى لو تعطل البرنامج بشكل مفاجئ.

## التثبيت

اختر واحداً من صفحة [الإصدارات](../../../../releases):

| التنزيل | الاستخدام |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **برنامج التثبيت.** لكل مستخدم، لا يتطلب صلاحيات المسؤول (Administrator)، ويضيف مدخلاً في قائمة ابدأ وبرنامجاً لإلغاء التثبيت. |
| `Decoy_x.y.z_x64-portable.zip` | **النسخة المحمولة.** فك الضغط في أي مكان وشغّل `decoy.exe`. تبقى جميع البيانات داخل مجلد `data` بجانبه، ولا يُكتب أي شيء في ملف تعريف المستخدم الخاص بك. احذف المجلد لإزالته بالكامل. |

تحقق من صحة الملف المُنزّل باستخدام `SHA256SUMS.txt` (عبر الأمر `Get-FileHash <file>` في PowerShell).

قد يعرض Windows SmartScreen تحذيراً بشأن ناشر غير معروف لأن الإصدارات غير موقّعة رقمياً؛ اختر *معلومات إضافية (More info) ← تشغيل على أي حال (Run anyway)* إذا كنت تثق بالإصدار.

المتطلبات: نظام Windows 10 أو 11 (بمعمارية 64 بت) مع بيئة تشغيل WebView2 (مضمنة بالفعل في Windows 11 وتحديثات Windows 10 الحديثة).

## طريقة الاستخدام

1. افتح **المكتبة (Library)** وابحث عن لعبة، أو اضغط على `Ctrl` + `K` من أي مكان.
2. انقر على لعبة. في اللوحة الموجودة على اليمين، اختر العملية وعدد دقائق تشغيلها (تتطلب أنشطة Discord عادةً 15 دقيقة).
3. اضغط على **بدء التمويه (Start decoy)**. سيُظهر Discord اللعبة بعد بضع ثوانٍ.
4. تابعه في قسم **قيد التشغيل (Running)**، ويمكنك إيقاف عملية واحدة أو جميع العمليات في أي وقت، أو ترك Decoy في علبة النظام فحسب.

يتم إخفاء الألعاب التي ليس لها ملفات تنفيذية في قائمة Discord افتراضياً (لأنه لا يمكن اكتشافها). فعّل خيار
*إظهار الألعاب بدون exe (Show games without exe)* لرؤيتها؛ يتم تحديث القائمة يومياً، لذا ستصبح متاحة بمجرد أن يضيف Discord عملية لها.

### سطر الأوامر

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

يبدأ تشغيل التمويه مباشرة، على سبيل المثال `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## البناء من المصدر

المتطلبات الأساسية: [Node.js](https://nodejs.org) 20 أو أحدث، حزمة أدوات [Rust](https://rustup.rs) المستقرة (هدف MSVC) مع أدوات بناء Visual Studio C++‎، وبيئة تشغيل WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

فحوصات مفيدة:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ملاحظات: يتم تجميع ملف exe الخاص بالتمويه بواسطة `src-tauri/build.rs` باستخدام `rustc` البسيط من الملف `src-tauri/stub/stub.rs` ثم يتم تضمينه في التطبيق. وعند تشغيل الواجهة الأمامية في متصفح عادي (`npm run dev`)، يتم استخدام خلفية برمجية وهمية صغيرة (`src/mock.ts`)، وهو أمر مفيد لتطوير واجهة المستخدم.

## الترجمات

توجد نصوص واجهة المستخدم في المجلد [`src/locales`](../../src/locales)، بمعدل ملف JSON واحد لكل لغة (`en.json`، `ru.json`، ...). إضافة لغة جديدة تعني ببساطة إضافة ملف؛ دون الحاجة لأي تعديل في الشيفرة البرمجية. راجع [docs/TRANSLATING.md](../TRANSLATING.md) لمعرفة تنسيق الملف، والحصول على مطالبة جاهزة للاستخدام للترجمة الآلية، والسكربت الخاص بالتحقق من الصحة. تُحفظ ترجمات هذا الملف في `docs/i18n/README.<code>.md`.

## هيكل المشروع

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## الخصوصية

- يستخدم Decoy الشبكة فقط لتنزيل قائمة الاكتشاف العامة لـ Discord (عند أول تشغيل، ثم بحد أقصى مرة واحدة يومياً أو عند الضغط على تحديث)، ولعرض أيقونات الألعاب والرسومات الفنية من شبكة توصيل المحتوى (CDN) العامة الخاصة بـ Discord.
- لا يقرأ أو يخزن أو يرسل رمز مصادقة Discord (token) الخاص بك أو أي بيانات حساب، ولا يتواصل مع تطبيق Discord على الإطلاق.
- تُحفظ الإعدادات (المفضلة، اللغة، مدد التشغيل) محلياً في مساحة تخزين WebView الخاصة بالتطبيق؛ وتوجد ذاكرة التخزين المؤقت لقائمة الألعاب وملفات التمويه المؤقتة في المسار `%LOCALAPPDATA%\app.decoy.desktop`.
- لا تحليلات، لا تقارير للأعطال، ولا حسابات.

## القيود المعروفة

- يمكن لـ Discord تغيير طريقة عمل الاكتشاف في أي وقت. إذا توقف التعرف على عملية تمويه، يرجى فتح تذكرة خطأ (issue).
- تتطلب بعض الأنشطة أكثر من مجرد عملية قيد التشغيل (على سبيل المثال التواجد داخل تجربة معينة ضمن منصة ألعاب). يكتفي Decoy بمحاكاة العملية فقط.
- لا يمكن اكتشاف الإدخالات التي ليس لها ملفات تنفيذية في قائمة Discord.
- قد تضع برامج الحماية الأمنية أحياناً إشارة تحذير على الملفات التنفيذية الصغيرة غير الموقعة التي تبقى خاملة في الذاكرة. برنامج التمويه مفتوح المصدر ومبني من `src-tauri/stub/stub.rs`؛ ويمكنك تجميعه بنفسك.

## إخلاء المسؤولية

يتم توفير Decoy "كما هو" لأغراض شخصية وتعليمية واختبارية. قد تؤدي محاكاة لعبة قيد التشغيل إلى انتهاك شروط خدمة Discord أو ناشر اللعبة، وقد يؤدي ذلك إلى اتخاذ إجراءات ضد حسابك. أنت وحدك المسؤول عن كيفية استخدامه. يُعد اسم "Discord" وجميع أسماء الألعاب وشعاراتها علامات تجارية لأصحابها المعنيين وتُستخدم هنا فقط لتحديد البرمجيات المشار إليها.
