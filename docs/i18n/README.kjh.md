# Decoy

**Discord ойын тоғынча тіп санар ӱчӱн кічиҷек заглушка-процесстер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Хаҷандағы ойыннарлығ паза обложкаларлығ Decoy библиотеказы" />

</div>

Decoy ойынның толдырар файлының (executable) адынаң хорғыс чох, кӧзӧнектіг заглушка-процессті тудып тоғындырча, аны ӱчӱн Discord ойынны таныыр системазы сірерні ол ойында ойнапчатхан полтыра кӧзідер. Сын ойынны орнатарға алай сығарарға кирек чоғыл, дискте артых ниме де халбинча.

Ол **Discord таап аларға чарар пӱкӱ ойыннарны** пілче (25 000 чағын ойын), че Discord-тың позының азых сизігін хығырча паза аны позы ла нааҷылап одырча.

> [!WARNING]
> Тоғынчатхан ойынны ӧӧртері Discord тудынар ээжилеріне киліспес оңай, сірер Decoy-наң **позыңарның чобағыңаң** тудынчазар.
> Пу проект Discord Inc. компаниязынаң палғалыстығ нимес, оларнаң махтатылбаан паза пӱдірілбеен. [Чобағнаң тудынары](#чобағнаң-тудынары) кӧріңер.

## Оңдайлары

- **Discord таап аларға чарар нимелернің хазназы.** Ойыннар сизігі Discord-тың азых эндпоинтынаң сығарылча, локально кэштелче паза кӱн сайын нааҷылалча. Наа ойыннар паза наа толдырар файллар посттары ла сығып килчелер.
- **Тӱрген тілеп алары.** Муңнар ойын аразында ойын адынаң алай толдырар файлынаң тута тілеп алары, плиткаларнаң алай хысых сизікнең кӧрері, иреелеп алғаннар паза «Хаҷандағылар» хази.
- **Пір басканнаң.** Ойынны таллап алыңар, толдырар файлны таллап алыңар (кӧп полза), нинҷе минут тударға палғаңар паза сығарарға пазыңар. Айландыра тус санағы паза чардых тус тоозылғанын искірерлер.
- **Соонда ниме де арттырбинча.** Заглушка ол тоғынчатхан туста ла пар полча: кічиҷек exe сығарылғанда пӱдірілче паза тохтадылғанда чох идилче. Программадаң сыхсаң пӱкӱзі тохтир, сбой соонда халған файллар улуғ сығарыста арығлалчалар.
- **Тымырах.** Система трейинде одырча, заглушкалар позы ӱчӱн кӧзенектер алай тоғыс панелінде кнопкалар чоғыл.
- **Азых тілбестер.** Интерфейс оой JSON файлларнаң тоғынча, наа тіл хозары — пір ле файл. Англий паза орыс тіллері хозылғаннар.
- **Чазырығ.** Аккаунт чоғыл, Discord токені чоғыл, телеметрия чоғыл. [Чазырығ](#чазырығ) кӧріңер.

## Хайди тоғынча

1. Discord сірернің компьютеріңерде тоғынчатхан процесстерні кӧріп паза толдырар файлларның аттарын азых сизікнең (`/api/v9/applications/detectable`) тиңнестіріп, сірер ойын ойнапчатханығарны піліп алар.
2. Decoy пу сизікті сығарып алар паза таллап алған ойыныңарға сизіктең толдырар файлның адынаң (кӧзідімге, `.../cod26-cod.exe`) кічиҷек заглушка-программаны (120 КБ чағын, Rust тілінең язылған паза Decoy істіне салылған) уахыттығ папкаға кӧчирер.
3. Заглушка экраннаң ырах одырчатхан ӱстӱндегі пір кӧзенекти тударынаң пасха ниме де итпинче, аны ӱчӱн сірер аны хаҷан даа кӧрбессер. Discord кӧзӧнектіг ле процессті таныпча, ол ӱчӱн кӧзенек чох процесс чарабас.
4. Чағын 15 секунд аразында Discord пу ойынны сірернің амдығы идінізіңер полтыра кӧзідер.
5. Таймер тоозыл парза алай тохтадарға пассаңар, Decoy процессті тохтадар паза файлны чох идер. Windows job объект Decoy чабылза даа, ол санда тоғызы тудыл парза даа, заглушкалар оонаң хада чабыларын хандырча.

## Орнадары

[Releases](../../../../releases) страницазынаң пірсін таллап алыңар:

| Сығарып алары | Ниме ӱчӱн |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Орнатхыс (Installer).** Пір тудынҷыға, администратор эркі кирек чоғыл, «Пуск» менюзер пазылғанын паза соорар программаны хосча. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Хайда даа чазып алыңар паза `decoy.exe` сығарыңар. Пӱкӱ саннар чанындағы `data` папказында сахталчалар, тудынҷы профилине ниме де язылбинча. Чох идер ӱчӱн папканы чох идібізіңер. |

Сығарып алған файлны `SHA256SUMS.txt` полызиинаң тиктеп алыңар (PowerShell істінде `Get-FileHash <файл>`).

Windows SmartScreen цифрлығ хол басылбааны ӱчӱн пілдіс чох сығарҷы тузында сахтандырарға чарир; сборкаға изенчең ползаңар, *Искіріг (More info) → Пӱкӱзіне кӧрбин сығарарға (Run anyway)* таллаңар.

Киректелче: WebView2 runtime пар Windows 10 алай 11 (64-бит) (Windows 11 паза соолғы Windows 10 нааҷыланыстарында бар).

## Тудынары

1. **Библиотеканы** азыңар паза ойынны тілеп алыңар, алай хайдаң даа `Ctrl` + `K` пазыңар.
2. Ойынға пазыңар. Оң партада процессті паза хайдағ ӱр тударға таллап алыңар (Discord чаалағларында кӧбізін 15 минут киректелче).
3. **Заглушканы сығарарға** пазыңар. Discord нинҷе-де секунд аразында ойынны кӧзідер.
4. Аны **Тоғынчатханнар** вкладказында кӧріңер, хаҷан даа пірсін алай пӱкӱзізін тохтадып пириңер, алай Decoy-ны трейде артызыңар.

Discord сизігінде толдырар файллары амды чох ойыннар чазырығлығлар (оларны танып аларға чарабас). Оларны кӧрер ӱчӱн *exe чох ойыннарны кӧзідерге* кӧзӧниині қозыңар; сизік кӱн сайын нааҷылалча, ол ӱчӱн Discord процессті хосса ла, олар тута азыларлар.

### Командалар хази

```
decoy.exe --launch "<Discord сизігінең толдырар файлның чолы>" [минуттар]
```

Заглушканы тута сығарарға, кӧзідімге `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Тӧзӧк кодтаң чыыры

Пастағы киректер: [Node.js](https://nodejs.org) 20+, Visual Studio C++ чыыр ӱгренҷілері пар пӧгін [Rust](https://rustup.rs) үнүстүрүмүөннері (MSVC target), паза WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload-тығ ӧскен ээзинде сығарыс
npm run tauri build    # src-tauri/target/release/bundle/nsis істінде орнатхысты пӱдірері
```

Тузалығ тиктеглер:

```bash
npm run check-locales  # хайзы даа тілбес файлын ru.json-наң тиңнестіріп тиктерері
npx tsc --noEmit       # фронтенд типтерін тиктерері
cargo check --manifest-path src-tauri/Cargo.toml
```

Искіріглер: заглушка exe файлы `src-tauri/build.rs` полызиинаң `src-tauri/stub/stub.rs` файлынаң тигіс `rustc` тудынып чыылча паза приложение істіне хозылча. Фронтенд тигіс браузерде сығарылза (`npm run dev`), кічиҷек мок-бэкенд (`src/mock.ts`) тудынылча, пу интерфейснең тоғынғанда тузалығ.

## Тілбестер

Интерфейс хастары [`src/locales`](../../src/locales) істінде сахталчалар, хайзы даа тіл ӱчӱн пір JSON файл (`en.json`, `ru.json`, ...).
Тіл хозары — кодты солыбин, пір файл ла хозары полча. Файл форматы, машина тілбезіне бэлэн промпт паза тиктер скрипт тузында [docs/TRANSLATING.md](../TRANSLATING.md) кӧріңер. Пу README тілбестері `docs/i18n/README.<code>.md` істіне кирерлер.

## Проект пӱдізии

```
src/                    React + TypeScript фронтенд
  components/           Библиотека, сидік партазы, кӧзӧниилер, ...
  locales/              тілбес файллары (хайзы даа тіл ӱчӱн пір JSON)
  i18n-core.ts          тілні сығарып алары паза тілеп алары
  store.ts              приложение турузы (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            ойыннар базазы, заглушка-процесстер, трей
  stub/stub.rs          істіне салылған заглушка-программа
scripts/                полысхы скрипттер (локалларны тиктерері)
docs/                   тілбес тузында, скриншоттар
```

## Чазырығ

- Decoy сетьті Discord-тың азых сизігін сығарып аларға ла тудынча (пастағы сығарыста, аннаң андар кӱнде пір хати алай нааҷылаарын бассаңар) паза Discord-тың азых CDN-інең ойыннарның значоктарын паза обложкаларын кӧзідер ӱчӱн.
- Ол сірернің Discord токеніңерні алай аккаунт саннарын хығырбинча, сахтабинча паза ыспинча, Discord клиентнең дее палғалыс тутпинча.
- Кӧзӧниилер (иреелеп алғаннар, тіл, тус) приложение WebView сахтағлыында локально сахталчалар; ойыннар сизігінің кэші паза уахыттығ заглушка файллары `%LOCALAPPDATA%\app.decoy.desktop` істінде сахталчалар.
- Аналитика чоғыл, сбойлар чардығы чоғыл, аккаунт чоғыл.

## Пілдістіг сиктер

- Discord танып алар оңдайын хаҷан даа солып идерге чарир. Заглушка танылбин парза, уғаа улуғ сурынчабыс, issue азыңар.
- Пірее идіністерге тоғынчатхан процесстең пасха кӧп ниме киректелче (кӧзідімге, ойын платформазының пірее орнында одырары). Decoy процессті ле ӧӧртче.
- Discord сизігінде толдырар файллары чох ойыннар танылбастар.
- Хорғыс чох хандырар программалар (антивирустар) ара-аразында памятьте тиммир турған қол басылбаан кічиҷек толдырар файлларға сахтандырарға чарирлар. Заглушка азых кодтығ паза `src-tauri/stub/stub.rs` файлынаң чыылча; позыңар чыып аларға чарир.

## Чобағнаң тудынары

Decoy позының тудынарына, ӱгредіг паза танызар пӧгіннерге «хайдағ пар» полтыра пирілче. Тоғынчатхан ойынны ӧӧртері Discord-тың алай ойын сығарҷызының тудынар Ээжилеріне киліспеске чарир паза аккаунтыңарға хайдарға чарир. Аны хайди тудынғаныңар ӱчӱн сірер позыңар ла чобағ тудынчазар. «Discord» паза пӱкӱ ойын аттары, логотиптері позының ээлеринің садығ таңмалары полчалар паза мында оларға кирген программаларны танып алар ӱчӱн ле тудынылчалар.
