# Decoy

**Pequenos procesos substitutos que fan crer a Discord que un xogo está en execución.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca de Decoy con xogos recentes e ilustracións" />

</div>

Decoy mantén en execución un proceso substituto inofensivo con xanela baixo o nome do executable dun xogo, de xeito que a detección de xogos de Discord informa de que estás xogando a ese xogo. Nunca precisas instalar nin iniciar o xogo real, polo que nada pesado ocupa espazo no teu disco.

Coñece **todos os xogos que Discord pode detectar** (arredor de 25.000 entradas) porque le a propia lista pública de detección de Discord e mantena actualizada por si mesmo.

> [!WARNING]
> Falsificar un xogo en execución pode ir contra os Termos de Servizo de Discord e empregas Decoy **baixo a túa propia responsabilidade**.
> Este proxecto non está afiliado, avalado nin vinculado a Discord Inc. Consulta o [Descargo de responsabilidade](#descargo-de-responsabilidade).

## Características

- **Todo o que Discord pode detectar.** A lista de xogos descárgase dende o punto de acceso público de detección de Discord, gárdase na caché localmente e actualízase a diario. Os xogos novos e os executables engadidos recentemente aparecen automaticamente.
- **Busca que segue o ritmo.** Busca instantánea por nome de xogo ou executable entre milleiros de xogos, vista en cuadrícula ou lista compacta, favoritos e unha fila de «Recentes».
- **Un só clic.** Elixe un xogo, selecciona o executable (se hai varios), escolle canto tempo mantelo e preme iniciar. Un anel de conta atrás e unha notificación avisaranche cando remate o tempo.
- **Non deixa rastro.** Un decoy só existe mentres se executa: o pequeno exe créase ao iniciar e elimínase ao deter. Todo se detén ao saír, e os restos tras un peche inesperado límpanse no seguinte inicio.
- **Discreto.** Permanece na bandexa do sistema, sen xanelas nin botóns na barra de tarefas para os propios decoys.
- **Traducións abertas.** A interface baséase en ficheiros JSON simples, polo que engadir un idioma é cuestión dun só ficheiro. Inclúense inglés e ruso.
- **Privado.** Sen conta, sen token de Discord, sen telemetría. Consulta [Privacidade](#privacidade).

## Como funciona

1. Discord determina que estás xogando a un xogo observando os procesos en execución no teu PC e comparando os seus nomes de executable cunha lista pública (`/api/v9/applications/detectable`).
2. Decoy descarga esa lista e, para o xogo que elixas, copia un diminuto programa substituto (duns 120 KB, escrito en Rust e integrado en Decoy) nun cartafol temporal empregando o nome de executable da lista, por exemplo `.../cod26-cod.exe`.
3. O substituto non fai nada agás posuír unha xanela de nivel superior, situada moi lonxe fóra da pantalla para que nunca a vexas. Discord só recoñece un proceso se posúe unha xanela, motivo polo cal un proceso completamente sen xanela é ignorado.
4. Nun prazo de aproximadamente 15 segundos, Discord amosa o xogo como a túa actividade actual.
5. Cando remata o temporizador ou premes deter, Decoy finaliza o proceso e elimina o ficheiro. Un obxecto de traballo de Windows garante que os decoys rematen xunto con Decoy, mesmo se este pecha de xeito inesperado.

## Instalación

Elixe un dende a páxina de [Releases](../../../../releases):

| Descarga | Para |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por usuario, non precisa permisos de administrador, engade unha entrada no menú Inicio e un desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Descomprime en calquera lugar e executa `decoy.exe`. Todos os datos gárdanse no cartafol `data` ao seu carón, non se escribe nada no teu perfil de usuario. Elimina o cartafol para borralo. |

Verifica unha descarga con `SHA256SUMS.txt` (`Get-FileHash <file>` en PowerShell).

Windows SmartScreen pode advertir sobre un editor non recoñecido debido a que as compilacións non están asinadas dixitalmente; escolle *Máis información → Executar de todas formas* se confías na compilación.

Requisitos: Windows 10 ou 11 (64 bits) co runtime de WebView2 (xa incluído en Windows 11 e en actualizacións recentes de Windows 10).

## Uso

1. Abre a **Biblioteca** e busca un xogo, ou preme `Ctrl` + `K` dende calquera lugar.
2. Fai clic nun xogo. No panel da dereita, elixe o proceso e cantos minutos mantelo (as actividades de Discord normalmente piden 15).
3. Preme **Iniciar decoy**. Discord amosará o xogo pasados uns segundos.
4. Obsérvao en **En execución**, detén un ou todos en calquera momento, ou simplemente deixa Decoy na bandexa do sistema.

Os xogos cuxa entrada en Discord aínda non ten executables están agochados por defecto (non se poden detectar). Activa *Amosar xogos sen exe* para velos; a lista actualízase a diario, polo que estarán dispoñibles axiña que Discord engada un proceso.

### Liña de ordes

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Inicia un decoy de inmediato, por exemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar dende o código fonte

Requisitos previos: [Node.js](https://nodejs.org) 20+, a cadea de ferramentas estable de [Rust](https://rustup.rs) (destino MSVC) coas ferramentas de compilación de Visual Studio C++, e o runtime de WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Comprobacións útiles:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notas: o exe do decoy é compilado por `src-tauri/build.rs` con `rustc` directamente dende `src-tauri/stub/stub.rs` e logo intégrase na aplicación. Cando o frontend se executa nun navegador convencional (`npm run dev`), emprégase un pequeno backend simulado (`src/mock.ts`), o cal resulta práctico para traballar na interface de usuario.

## Traducións

As cadeas da interface residen en [`src/locales`](../../src/locales), un ficheiro JSON por idioma (`en.json`, `ru.json`, ...). Engadir un idioma significa engadir un ficheiro; sen cambios de código. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) para coñecer o formato do ficheiro, unha instrución lista para usar en tradución automática e o script de validación. As traducións deste README van en `docs/i18n/README.<code>.md`.

## Estrutura do proxecto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacidade

- Decoy só emprega a rede para descargar a lista pública de detección de Discord (no primeiro inicio, e logo como máximo unha vez ao día ou cando premes actualizar) e, para amosalos, as iconas e ilustracións dos xogos dende a CDN pública de Discord.
- Non le, non almacena nin envía o teu token de Discord nin ningún dato da túa conta, e non se comunica co cliente de Discord.
- Os axustes (favoritos, idioma, duracións) almacénanse localmente no almacenamento WebView da aplicación; a caché da lista de xogos e os ficheiros temporais dos decoys residen en `%LOCALAPPDATA%\app.decoy.desktop`.
- Sen analíticas, sen informes de erros e sen contas.

## Limitacións coñecidas

- Discord pode cambiar como funciona a detección en calquera momento. Se un decoy deixa de ser recoñecido, abre unha incidencia (issue).
- Algunhas actividades requiren algo máis ca un proceso en execución (por exemplo, estar dentro dunha experiencia concreta dunha plataforma de xogos). Decoy só imita o proceso.
- As entradas sen executables na lista de Discord non se poden detectar.
- En ocasións, o software de seguranza marca pequenos executables non asinados que permanecen inactivos na memoria. O decoy é de código aberto e compílase a partir de `src-tauri/stub/stub.rs`; podes compilalo ti mesmo.
