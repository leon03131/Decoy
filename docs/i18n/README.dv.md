# Decoy

**ގޭމެއް ހިނގަނީ ކަމަށް Discord އަށް ހީކުރުވާ ކުދި ބަދަލު ޕްރޮސެސްތައް.**

Decoy އިން ގޭމެއްގެ އެގްޒެކިއުޓަބަލް ނަމުގައި ގެއްލުމެއް ނެތް، ވިންޑޯއެއް އެކުލެވޭ ބަދަލު ޕްރޮސެސްއެއް ހިންގައެވެ، އެހެންކަމުން Discord ގެ ގޭމް ދެނެގަންނަ ނިޒާމުން ތިޔަބޭފުޅާ އެ ގޭމް ކުޅެނީ ކަމަށް ދައްކައެވެ. ހަގީގީ ގޭމް އިންސްޓޯލްކުރާކަށް ނުވަތަ ފަށާކަށް ނުޖެހެއެވެ، އެހެންކަމުން ޑިސްކުން ބޮޑު ޖާގައެއް ބޭނުމެއް ނުވެއެވެ.

މިއަށް **Discord އަށް ދެނެގަނެވޭ ކޮންމެ ގޭމެއް** އެނގެއެވެ (ގާތްގަނޑަކަށް 25،000 އެންޓްރީ) ސަބަބަކީ މިއީ Discord ގެ އަމިއްލަ އާންމު ޑިޓެކްޝަން ލިސްޓު ކިޔައި، އަމިއްލައަށް އަދާހަމަކޮށް ބަލަހައްޓާތީއެވެ.

> [!WARNING]
> ހިނގަމުންދާ ގޭމެއް ފޭކްކުރުމަކީ Discord ގެ ޚިދުމަތުގެ ޝަރުތުތަކާ ޚިލާފު ކަމަކަށް ވެދާނެއެވެ، އަދި Decoy ބޭނުންކުރަންވާނީ **އަމިއްލަ ޒިންމާގައެވެ**.
> މި ޕްރޮޖެކްޓަކީ Discord Inc އާ ގުޅުންހުރި، އެފަރާތުން ތާއީދުކޮށްފައިވާ ނުވަތަ އެފަރާތާ އެއްވެސް ގުޅުމެއް އޮތް އެއްޗެއް ނޫނެވެ. [ޒިންމާއިން ބަރީއަވުން](#ޒިންމާއިން-ބަރީއަވުން) ބައްލަވާ.

## ފީޗާތައް

- **Discord އަށް ދެނެގަނެވޭ ހުރިހާ އެއްޗެއް.** ގޭމް ލިސްޓު ޑައުންލޯޑް ކުރެވެނީ Discord ގެ އާންމު ޑިޓެކްޝަން އެންޑްޕޮއިންޓުންނެވެ، އަދި ލޯކަލްކޮށް ކޭޝްކޮށް ކޮންމެ ދުވަހަކު އާކުރެވެއެވެ. އާ ގޭމްތަކާއި އަލަށް އިތުރުކުރެވޭ އެގްޒެކިއުޓަބަލްތައް އަމިއްލައަށް ފެންނަން ފަށައެވެ.
- **ހަލުވިކަމާއެކު ހޯދުން.** އެތައް ހާސް ގޭމްތަކުގެ ތެރެއިން ގޭމްގެ ނަމުން ނުވަތަ އެގްޒެކިއުޓަބަލް އިން ވަގުތުން ހޯދުން، ގޮޅި ނުވަތަ ކޮމްޕެކްޓް ލިސްޓު ވިއު، ގަޔާވާ ލިސްޓު އަދި "އެންމެ ފަހުން" ބޭނުންކުރި ގޭމްތަކުގެ ބަރި.
- **އެއް ފިތާލުމަކުން.** ގޭމެއް ނަގާ، އެގްޒެކިއުޓަބަލް ޚިޔާރުކުރޭ (ގިނަ އެއްޗެހި ހުރިނަމަ)، ބަހައްޓަންވީ ވަގުތު ކަނޑައަޅައި ފަށަން ފިތާލާ. ކައުންޓްޑައުން ބުރަކާއި ނޮޓިފިކޭޝަނަކުން ވަގުތު ހަމަވުމުން އަންގައިދޭނެއެވެ.
- **ފަހަތަށް އެއްވެސް އެއްޗެއް ދޫނުކުރޭ.** decoy އެއް އޮންނާނީ ހަމައެކަނި އެ ހިނގަމުންދާއިރުއެވެ: ފަށާއިރު ކުޑަ exe އެއް އުފައްދައި، ހުއްޓާލުމުން ފޮހެލެވެއެވެ. އެޕް ނިމުމުން ހުރިހާ އެއްޗެއް ހުއްޓެއެވެ، އަދި ކްރޭޝްއެއްގެ ސަބަބުން ބާކީވާ ތަކެތި ދެން އެޕް ފަށާއިރު ސާފުކޮށްލެވެއެވެ.
- **ހަމަހިމޭން.** ސިސްޓަމް ޓްރޭގައި ހަރަކާތްތެރިވެއެވެ، decoy ތަކަށް ވަކި ވިންޑޯއެއް ނުވަތަ ޓާސްކްބާރ ބަޓަނެއް ނުހުރެއެވެ.
- **އޯޕަން ތަރުޖަމާތައް.** އިންޓަފޭސް މަސައްކަތްކުރަނީ އާދައިގެ JSON ފައިލްތަކުންނެވެ، އެހެންކަމުން ބަހެއް އިތުރުކުރުމަކީ އެންމެ ފައިލެއް އިތުރުކުރުމެވެ. އިނގިރޭސި އަދި ރަޝިއަން ހިމެނިފައިވެއެވެ.
- **ޒާތީ ސިއްރު ހިފެހެއްޓުން.** އެކައުންޓެއް ނޯންނާނެ، Discord ޓޯކަން ބޭނުމެއް ނުވާނެ، ޓެލެމެޓްރީއެއް ނުހުންނާނެއެވެ. [ޒާތީ ސިއްރު ހިފެހެއްޓުން](#ޒާތީ-ސިއްރު-ހިފެހެއްޓުން) ބައްލަވާ.

## މަސައްކަތްކުރާ ގޮތް

1. Discord އިން ތިޔަބޭފުޅާ ގޭމެއް ކުޅެނީ ކަމަށް ކަނޑައަޅަނީ ޕީސީގައި ހިނގަމުންދާ ޕްރޮސެސްތަކަށް ބަލައި، އެ ތަކެތީގެ އެގްޒެކިއުޓަބަލް ނަންތައް އާންމު ލިސްޓަކާ (`/api/v9/applications/detectable`) އަޅާކިޔައިގެންނެވެ.
2. Decoy އިން އެ ލިސްޓު ޑައުންލޯޑްކޮށް، ތިޔަބޭފުޅާ ޚިޔާރުކުރާ ގޭމަށްޓަކައި، ކުޑަ ބަދަލު ޕްރޮގްރާމެއް (ގާތްގަނޑަކަށް 120 KB، Rust އިން ލިޔެފައިވާ އަދި Decoy ގެ ތެރޭގައި އެމްބެޑްކުރެވިފައިވާ) ލިސްޓުގައިވާ އެގްޒެކިއުޓަބަލް ނަމުގައި ޓެމްޕަރަރީ ފޯލްޑަރަކަށް ކޮޕީކުރެއެވެ، މިސާލަކަށް `.../cod26-cod.exe`.
3. މި ބަދަލު ޕްރޮގްރާމް އެއްވެސް ކަމެއް ނުކުރެއެވެ، ހަމައެކަނި ސްކްރީނުން ބޭރުގައި ފޮރުވިފައިވާ އެއް ޓޮޕް-ލެވެލް ވިންޑޯއެއް ހިފަހައްޓައެވެ. Discord އިން ދެނެގަންނަނީ ވިންޑޯއެއް ހުންނަ ޕްރޮސެސްތައް އެކަންޏެވެ، އެހެންވެ އެއްވެސް ވިންޑޯއެއް ނެތް ޕްރޮސެސްތައް ދޫކޮށްލެވެއެވެ.
4. ގާތްގަނޑަކަށް 15 ސިކުންތު ތެރޭގައި Discord އިން އެ ގޭމަކީ މިހާރު ހިނގަމުންދާ ހަރަކާތް ކަމަށް ދައްކާނެއެވެ.
5. ޓައިމަރު ނިމުމުން ނުވަތަ ހުއްޓާލުމަށް ފިތާލުމުން، Decoy އިން އެ ޕްރޮސެސް ނިންމާލައި ފައިލް ފޮހެލައެވެ. Windows job object އެއްގެ ސަބަބުން Decoy ކްރޭޝްވި ކަމުގައި ވިޔަސް decoy ތައް Decoy އާއެކު ހުއްޓޭނެކަން ޔަގީންކޮށްދެއެވެ.

## އިންސްޓޯލްކުރުން

[Releases](../../../../releases) ޞަފްޙާއިން އެކަތި ޚިޔާރުކުރައްވާ:

| ޑައުންލޯޑް | ބޭނުންކުރަންވީ ފަރާތް |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **އިންސްޓޯލަރ.** ކޮންމެ ޔޫޒަރަކަށް ވަކިން، އެޑްމިނިސްޓްރޭޓަރ ހުއްދަ ބޭނުމެއް ނުވޭ، Start މެނޫ އަށް އިތުރުކުރޭ އަދި އަންއިންސްޓޯލަރެއް ހިމެނޭ. |
| `Decoy_x.y.z_x64-portable.zip` | **ޕޯޓަބަލް.** ކޮންމެ ތަނަކަށްވެސް އަންޒިޕްކޮށްފައި `decoy.exe` ހިންގާ. ހުރިހާ ޑޭޓާއެއް އޭގެ ކައިރީގައިވާ `data` ފޯލްޑަރުގައި ހުރެއެވެ، ޔޫޒަރ ޕްރޮފައިލަށް އެއްވެސް އެއްޗެއް ނުލިޔެއެވެ. ފޮހެލަން ބޭނުންނަމަ ފޯލްޑަރ ޑިލީޓްކޮށްލާ. |

ޑައުންލޯޑް `SHA256SUMS.txt` އިން ޔަގީންކުރައްވާ (PowerShell ގައި `Get-FileHash <file>`).

ބިލްޑްތަކަކީ ކޯޑް ސޮއިކުރެވިފައިވާ ތަކެތި ނޫން ކަމުން Windows SmartScreen އިން އިންޒާރެއް ދީފާނެއެވެ؛ ބިލްޑަށް އިތުބާރުކުރާނަމަ *More info → Run anyway* ނަންގަވާ.

ބޭނުންވާ މިންގަނޑު: Windows 10 ނުވަތަ 11 (64-bit) އެކު WebView2 runtime (Windows 11 އަދި ފަހުގެ Windows 10 އަދާހަމަތަކުގައި ކުރިންވެސް ހިމެނިފައިވެއެވެ).

## ބޭނުންކުރާނެ ގޮތް

1. **ލައިބްރަރީ** ހުޅުވައި ގޭމެއް ހޯދާ، ނުވަތަ ކޮންމެ ތަނަކުންވެސް `Ctrl` + `K` އަށް ފިތާލާ.
2. ގޭމަކަށް ފިތާލާ. ކަނާތްފަރާތުގައިވާ ޕެނަލުން ޕްރޮސެސް އަދި ބަހައްޓާނެ މިނެޓުގެ އަދަދު ޚިޔާރުކުރޭ (Discord ހަރަކާތްތަކަށް އާންމުކޮށް ބޭނުންވަނީ 15).
3. **Decoy ފަށާ** އަށް ފިތާލާ. މަދު ސިކުންތުކޮޅެއްގެ ތެރޭގައި Discord އިން ގޭމް ދައްކަން ފަށާނެއެވެ.
4. **ހިނގަނީ** ގެ ދަށުން ބަލާ، ކޮންމެ ވަގުތަކުވެސް އެކަތި ނުވަތަ ހުރިހާ އެއްޗެއް ހުއްޓާލާ، ނުވަތަ Decoy ޓްރޭގައި ބައިންދާ.

Discord އެންޓްރީގައި އެގްޒެކިއުޓަބަލް އަދި ނެތް ގޭމްތައް އާންމުކޮށް ހުންނާނީ ފޮރުވިފައެވެ (އެ ތަކެތި ދެނެއެއް ނުގަނެވޭނެއެވެ). އެ ތަކެތި ބެލުމަށް *exe ނެތް ގޭމްތައް ދައްކާ* އޮން ކުރޭ؛ މި ލިސްޓު ކޮންމެ ދުވަހަކު އާކުރެވެއެވެ، އެހެންކަމުން Discord އިން ޕްރޮސެސްއެއް އިތުރުކުރާ ވަގުތުން ފެށިގެން އެ ގޭމްތައް ލިބެން ފަށާނެއެވެ.

### ކޮމާންޑް ލައިން

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

ވަގުތުން decoy އެއް ފަށައެވެ، މިސާލަކަށް `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## ސޯސް އިން ބިލްޑްކުރުން

ބޭނުންވާ ތަކެތި: [Node.js](https://nodejs.org) 20+، Visual Studio C++ build tools އާއެކު ސްޓޭބަލް [Rust](https://rustup.rs) toolchain (MSVC target)، އަދި WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

ފައިދާހުރި ޗެކްތައް:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

ނޯޓްސް: decoy exe ކޮމްޕައިލް ކުރެވެނީ `src-tauri/build.rs` އިން އާދައިގެ `rustc` ބޭނުންކޮށްގެން `src-tauri/stub/stub.rs` އިންނެވެ އަދި އެއަށްފަހު އެޕްގެ ތެރެއަށް އެމްބެޑްކުރެވެއެވެ. ފްރަންޓްއެންޑް އާދައިގެ ބްރައުޒަރެއްގައި ހިންގާއިރު (`npm run dev`) ކުޑަ މޮކް ބެކްއެންޑެއް (`src/mock.ts`) ބޭނުންކުރެވެއެވެ، މިއީ UI ގައި މަސައްކަތްކުރުމަށް ވަރަށް ފަސޭހަ ގޮތެކެވެ.

## ތަރުޖަމާތައް

UI ގެ ލިޔުންތައް ހުންނަނީ [`src/locales`](../../src/locales) ގައެވެ، ކޮންމެ ބަހަކަށް އެއް JSON ފައިލެވެ (`en.json`, `ru.json`, ...).
ބަހެއް އިތުރުކުރުމަކީ ފައިލެއް އިތުރުކުރުމެވެ؛ އެއްވެސް ކޯޑެއް ބަދަލުކުރާކަށް ނުޖެހެއެވެ. ފައިލް ފޯމެޓާއި މެޝިން ޓްރާންސްލޭޝަނަށް ބޭނުންކުރާނެ ޕްރޮމްޕްޓާއި ވެލިޑޭޝަން ސްކްރިޕްޓް ބެއްލެވުމަށް [docs/TRANSLATING.md](../TRANSLATING.md) ބައްލަވާ. މި README ގެ ތަރުޖަމާތައް ދާނީ `docs/i18n/README.<code>.md` އަށެވެ.

## ޒާތީ ސިއްރު ހިފެހެއްޓުން

- Decoy އިން ނެޓްވޯކް ބޭނުންކުރަނީ ހަމައެކަނި Discord ގެ އާންމު ޑިޓެކްޝަން ލިސްޓު ޑައުންލޯޑްކުރުމަށާއި (ފުރަތަމަ ފަށާއިރު، ދެން ގިނަވެގެން ދުވާލަކު އެއްފަހަރު ނުވަތަ އަދާހަމަކުރަން ފިތާލުމުން) އަދި ދެއްކުމަށްޓަކައި Discord ގެ އާންމު CDN އިން ގޭމް އައިކަންތަކާއި އާޓްވޯކް ޑައުންލޯޑްކުރުމަށެވެ.
- މިއިން ތިޔަބޭފުޅާގެ Discord ޓޯކަން ނުވަތަ އެއްވެސް އެކައުންޓް ޑޭޓާއެއް ނުކިޔައެވެ، ރައްކަލެއް ނުކުރެއެވެ، އަދި ނުފޮނުވައެވެ، އަދި Discord ކްލައިންޓާ ވާހަކައެއް ނުދައްކައެވެ.
- ސެޓިންގްސް (ގަޔާވާ ލިސްޓު، ބަސް، ދިގުމިން) ލޯކަލްކޮށް ރައްކާކުރެވެނީ އެޕްގެ WebView ސްޓޯރޭޖްގައެވެ؛ ގޭމް ލިސްޓު ކޭޝް އަދި ވަގުތީ decoy ފައިލްތައް ހުންނަނީ `%LOCALAPPDATA%\app.decoy.desktop` ގައެވެ.
- އެނަލިޓިކްސްއެއް ނޯންނާނެ، ކްރޭޝް ރިޕޯޓެއް ނުފޮނުވާނެ، އެކައުންޓެއް ނޯންނާނެއެވެ.

## އެނގެންޖެހޭ ހިފެހެއްޓުންތައް

- Discord އިން ޑިޓެކްޝަން މަސައްކަތްކުރާ ގޮތް ކޮންމެ ވަގުތެއްގައިވެސް ބަދަލުކޮށްފާނެއެވެ. decoy ދެނެގަތުން ހުއްޓިއްޖެނަމަ، މައްސަލައެއް (issue) ހުށަހަޅުއްވާ.
- ބައެއް ހަރަކާތްތަކަށް ހަމައެކަނި ޕްރޮސެސްއެއް ހިންގުމަށްވުރެ އިތުރު ކަންތައްތައް ބޭނުންވެއެވެ (މިސާލަކަށް ގޭމް ޕްލެޓްފޯމެއްގެ ވަކި ތަޖުރިބާއެއްގެ އެތެރޭގައި ހުރުން). Decoy އިން ހަމައެކަނި ޕްރޮސެސް ނަކަލުކުރެއެވެ.
- Discord ގެ ލިސްޓުގައި އެގްޒެކިއުޓަބަލް ނެތް އެންޓްރީތައް ދެނެއެއް ނުގަނެވޭނެއެވެ.
- ސެކިއުރިޓީ ސޮފްޓްވެއާތަކުން ބައެއް ފަހަރު މެމޮރީގައި ހިމޭނުން އިންނަ ކުދި ސޮއިނުކުރާ އެގްޒެކިއުޓަބަލްތަކާމެދު ސުވާލު އުފައްދައި އިންޒާރު ދީފާނެއެވެ. decoy އަކީ އޯޕަން ސޯސް އަދި `src-tauri/stub/stub.rs` އިން ބިލްޑްކުރެވިފައިވާ އެއްޗެކެވެ؛ އަމިއްލައަށްވެސް ކޮމްޕައިލް ކުރެވިދާނެއެވެ.

## ބައިވެރިވުން

ބަގް ރިޕޯޓުތަކާއި، ޚިޔާލުތަކާއި ތަރުޖަމާތަކަށް މަރުޙަބާ ކިޔަމެވެ. އެންމެ ފުރަތަމަ [CONTRIBUTING.md](../../CONTRIBUTING.md) ވިދާޅުވުން އެދެމެވެ.

## ޒިންމާއިން ބަރީއަވުން

Decoy ފޯރުކޮށްދެވެނީ އަމިއްލަ ބޭނުމަށް، ތައުލީމީ އަދި ޓެސްޓުކުރުމުގެ ބޭނުމަށްޓަކައި "އޮތް ގޮތަށެވެ". ހިނގަމުންދާ ގޭމެއް ނަކަލުކުރުމަކީ Discord ނުވަތަ ގޭމް ޝާއިއުކުރި ފަރާތުގެ ޚިދުމަތުގެ ޝަރުތުތަކާ ޚިލާފު ކަމަކަށް ވެދާނެއެވެ، އަދި ތިޔަބޭފުޅާގެ އެކައުންޓަށް ފިޔަވަޅު އެޅުމަށް މަގުފަހިވެދާނެއެވެ. މިއިން ކުރާ ބޭނުމަކަށް ފުރިހަމަ ޒިންމާ އުފުލަންވާނީ ހަމައެކަނި ތިޔަބޭފުޅާއެވެ. "Discord" އަދި ހުރިހާ ގޭމްތަކުގެ ނަންތަކާއި ލޯގޯތަކަކީ އެ ފަރާތްތަކުގެ މިލްކިއްޔާތެކެވެ އަދި މިތަނުގައި ބޭނުންކޮށްފައިވަނީ ހަމައެކަނި އެ ސޮފްޓްވެއާތައް ފާހަގަކުރުމަށެވެ.
