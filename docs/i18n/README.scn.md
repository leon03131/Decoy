# Decoy

**Prucessi sustitutivi nicareddi chi fannu crìdiri a Discord chi nu jocu è 'n esecuzzioni.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibbiuteca di Decoy cu jòcura ricenti e mmàggini" />

</div>

Decoy manteni 'n esecuzzioni nu prucessu sustitutu nòcciu furnutu di na finestra sutta lu nomu esicutìbbili d'un jocu, di manera ca la rilivazzioni dî jòcura di Discord t'ammustra comu si stassi jucannu a ddu jocu. Nun c'è mai bisognu di nstallari né d'avviari lu jocu veru e propiu, pirciò nenti di pisanti resta supra lu tò discu.

Canusci **ogni jocu chi Discord pò rilivari** (circa 25.000 voci) pirchì leggi la lista pùbblica di rilivazzioni di Discord e la manteni agghiurnata d'iddu stissu.

> [!WARNING]
> Fàciri finta di girari nu jocu pò jiri contra li Cundizzioni di Serviziu di Discord e usi Decoy **a tò rìsicu**.
> Stu pruggettu nun è affiliatu, appruvatu o cullijatu cu Discord Inc. Talìa [Avisu ligali](#avisu-ligali).

## Funziunalità

- **Tuttu chiddu chi Discord pò rilivari.** La lista dî jòcura veni scaricata dû puntu d'accessu pùbblicu di rilivazzioni di Discord, sarvata nnâ cache lucali e aggiurnata ogni jornu. Li jòcura novi e l'esicutìbbili agghiunciuti di ricenti spùntanu d'iddi stessi.
- **Circata chi camina ô passu.** Circata istantània pi nomu dû jocu o di l'esicutìbbili tra migghiara di jòcura, visualizzazzioni a màsciddi o a lista cumpatta, prifiriti e na riga pi chiddi «Ricenti».
- **Cu nu sulu cliccu.** Scegli nu jocu, scegli l'esicutìbbili (si nni sunnu assai), mposta quantu tempu mantèniri e ammacca avvia. N'aneddu cû cuntu a riversu e na nutìfica ti dìcinu quannu lu tempu finìu.
- **Nun si lassa nenti darreri.** Nu decoy esisti sulu mentri gira: lu file exe nicareddu veni criatu quannu parti e cancillatu quannu si ferma. Tuttu veni firmatu quannu nesci, e li tracci di nu pussìbbili crash vennu puliziati ô pròssimu avviu.
- **Silenziusu.** Vivi nnâ trey di sistema, senza finestri né buttoni nnâ barra dî compiti pi li decoy stissi.
- **Traduzzioni graputi.** L'interfaccia veni gistita di file JSON sìmprici, pirciò agghiùnciri na lingua addumanna sulu nu file. Lu ngrisi e lu russu sunnu già nclùditi.
- **Risirvatezza.** Nissunu contu, nissunu token di Discord, nissuna telemetrìa. Talìa [Risirvatezza](#risirvatezza).

## Comu funziuna

1. Discord dicidi chi stai jucannu a nu jocu taliànnu li prucessi 'n esecuzzioni supra lu tò PC e cunfruntannu li noma di l'esicutìbbili cu na lista pùbblica (`/api/v9/applications/detectable`).
2. Decoy scarica sta lista e, pû jocu chi scegli, copia nu prugramma sustitutu nicareddu (circa 120 KB, scrittu 'n Rust e ncurpuratu 'n Decoy) nta na cartella timpurània usannu lu nomu di l'esicutìbbili dâ lista, pi asempiu `.../cod26-cod.exe`.
3. Lu sustitutu nun fa àutru chi aviri na finestra di primu liveddu, misa luntanu fora dû schermu accussì nun la vidi mai. Discord arricanusci sulu nu prucessu chi pussedi na finestra, ed è pi chissu chi nu prucessu sanu sanu senza finestri veni ignuratu.
4. Nta circa 15 secunni Discord ammustra lu jocu comu la tò attivitati currenti.
5. Quannu finisci lu timer o ammacchi firma, Decoy ferma lu prucessu e cancella lu file. N'oggettu job di Windows s'assicura chi li decoy mòrinu nzèmmula cu Decoy, macari si chistu va 'n crash.

## Nstallazzioni

Sceglini unu dâ pàggina dî [Releases](../../../../releases):

| Scaricamentu | Pi |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Nstallaturi.** Pi sìngulu utenti, nun servi nuddu priviliggiu d'amministraturi, agghiunci na vuci nnû menu Start e nu prugramma di disinstallazzioni. |
| `Decoy_x.y.z_x64-portable.zip` | **Purtàbbili.** Spacchetta unni voi e lancia `decoy.exe`. Tutti li dati rèstanu nnâ cartella `data` allatu, nenti veni scrittu nnû tò prufilu utenti. Cancella la cartella pi livàrilu. |

Cunferma lu scaricamentu cu `SHA256SUMS.txt` (`Get-FileHash <file>` 'n PowerShell).

Windows SmartScreen putissi ammustrari n'avvisu pi via d'un prudutturi nun arricanusciutu pirchì li build nun hannu la firma diggitali; scegli *Cchiù nfurmazzioni → Esegui comu è gghiè* si ti fidi dâ build.

Requisiti: Windows 10 o 11 (a 64 bit) cû runtime WebView2 (già nclùditu 'n Windows 11 e nnî ricenti aggiurnamenti di Windows 10).

## Usu

1. Grapi la **Bibbiuteca** e cerca nu jocu, o ammacca `Ctrl` + `K` d'unni è gghiè.
2. Fai clic supra nu jocu. Nnû pannellu a dritta scegli lu prucessu e quanti minuti mantèniri (li quest di Discord di sòlitu n'addumannanu 15).
3. Ammacca **Fai partiri lu decoy**. Discord ammustrirà lu jocu doppu quarchi secunnu.
4. Cuntrollalu sutta **In esecuzzioni**, fèrmani unu o tutti quannu voi, o lassa simpricimenti Decoy nnâ trey.

Li jòcura chi nnâ lista di Discord nun hannu ancora esicutìbbili sunnu ammucciati comu mpustazzioni pridifinita (nun ponnu èssiri rilivati). Attiva *Ammustra jòcura senza exe* pi vìdili; la lista si rinfrisca ogni jornu, pirciò addivèntanu dispunìbbili appena Discord agghiunci nu prucessu.

### Riga di cumannu

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Fa partiri subbutu nu decoy, pi asempiu `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Cumpilazzioni dâ surgenti

Pririchisiti: [Node.js](https://nodejs.org) 20+, la toolchain stàbbili di [Rust](https://rustup.rs) (target MSVC) cu li Visual Studio C++ build tools, e lu runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # esegui 'n modalità sviluppu cu ricaricamentu a càudu
npm run tauri build    # ginera lu nstallaturi 'n src-tauri/target/release/bundle/nsis
```

Cuntrolli ùtili:

```bash
npm run check-locales  # cunvalidi ogni file di traduzzioni rispettu a ru.json
npx tsc --noEmit       # cuntrollu dî tipi dû frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Noti: l'esicutìbbili dû decoy veni cumpilatu di `src-tauri/build.rs` cu `rustc` nurmali a pàrtiri di `src-tauri/stub/stub.rs` e appoi ncurpuratu nta l'app. Quannu lu frontend gira nta nu navigaturi nurmali (`npm run dev`), veni usatu nu nicu backend simulatu (`src/mock.ts`), comudu pi travagghiari supra l'interfaccia.

## Traduzzioni

Li stringhi di l'interfaccia s'attròvanu 'n [`src/locales`](../../src/locales), nu file JSON pi ogni lingua (`en.json`, `ru.json`, ...). Agghiùnciri na lingua signìfica agghiùnciri nu file, senza canciamenti ô còdici. Talìa [docs/TRANSLATING.md](../TRANSLATING.md) pû furmatu dû file, nu prompt prontu a l'usu pâ traduzzioni automàtica e lu script di cunvàlida. Li traduzzioni di stu README vannu sarvati 'n `docs/i18n/README.<code>.md`.

## Struttura dû pruggettu

```
src/                    Frontend React + TypeScript
  components/           Bibbiuteca, pannellu dî dittagghi, mpustazzioni, ...
  locales/              file di traduzzioni (nu JSON pi ogni lingua)
  i18n-core.ts          caricamentu e circata dî lingui
  store.ts              statu di l'applicazzioni (zustand)
src-tauri/              Backend Rust (Tauri 2)
  src/lib.rs            basa di dati dî jòcura, prucessi decoy, trey
  stub/stub.rs          lu prugramma sustitutu chi veni ncurpuratu
scripts/                script d'aiutu (cunvàlida dî locales)
docs/                   guida pâ traduzzioni, screenshot
```

## Risirvatezza

- Decoy usa la riti sulu pi scaricari la lista pùbblica di rilivazzioni di Discord (ô primu avviu, appoi ô màssimu na vota ô jornu o quannu ammacchi aggiurna) e, pi scopi visivi, li marchi e l'illustrazzioni dî jòcura dâ CDN pùbblica di Discord.
- Nun leggi, nun sarva e nun manna lu tò token di Discord o dati dû contu, e nun parra cû client di Discord.
- Li mpustazzioni (prifiriti, lingua, durati) vennu sarvati lucalmenti nnû spazziu di mimoria WebView di l'app; la cache dâ lista dî jòcura e li file timpurànii dî decoy stannu 'n `%LOCALAPPDATA%\app.decoy.desktop`.
- Nissuna anàlisi, nissuna signalazzioni d'arristati anòmali, nissunu contu.

## Limitazzioni canusciuti

- Discord pò canciari comu funziuna la rilivazzioni 'n ogni mumentu. Si nu decoy nun veni cchiù arricanusciutu, grapi na signalazzioni (issue).
- Certi attivitati addumannanu cchiù di nu sìmprici prucessu 'n esecuzzioni (pi asempiu èssiri dintra a na spirienza particulari d'una piattaforma di jocu). Decoy s'ammita sulu a cupiari lu prucessu.
- Li voci senza esicutìbbili nnâ lista di Discord nun ponnu èssiri rilivati.
- Li prugrammi di sicurizza ogni tantu sinnalanu picculi esicutìbbili senza firma chi arrèstanu inattivi nnâ mimoria. Lu decoy è open source e fabbricatu di `src-tauri/stub/stub.rs`; u poi cumpilari tu stissu.

Tu sulu sì rispunzàbbili di comu l'usi. «Discord» e tutti li noma e loghi dî jòcura sunnu marchi riggistrati dî rispittivi prupitari e sunnu usati ccà sulu pi idintificari lu software a cui si rifirìscinu.
