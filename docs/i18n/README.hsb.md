# Decoy

**Drobne zastupowace procesy, kotrež Discord wěrja, zo hra běži.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteka Decoy z najnowšimi hrami a wobrazkami" />

</div>

Decoy wobchowuje njestrašny zastupowacy proces z woknom pod mjenom wuwjedźomneje dataje hry w běhu, tak zo hrajne spóznaće Discorda zdźěli, zo tutu hru hraješ. Njetrjebaš ženje woprawdźitu hru instalować ani startować, tuž ničo wulke na twojim tačelu njeleži.

Wón wě wo **kóždej hrě, kotruž Discord móže spóznać** (něhdźe 25.000 zapiskow), dokelž čita swójsku zjawnu lisćinu spóznaća Discorda a wobchowuje ju sam aktualnu.

> [!WARNING]
> Falšowanje běžaceje hry móže přećiwo Wužiwanskim wuměnjenjam Discorda přeńć a wužiwaš Decoy **na swójske riziko**.
> Tutón projekt njeje zwjazany z Discord Inc., njebu wot njeje spěchowany ani schwaleny. Hlej [Wuzamknjenje zamołwitosće](#wuzamknjenje-zamołwitosće).

## Funkcije

- **Wšo, štož Discord móže spóznać.** Hrajna lisćina so ze zjawneho kónčneho dypka spóznaća Discorda sćahuje, lokalnje pufruje a kóždy dźeń aktualizuje. Nowe hry a nowo přidate wuwjedźomne dataje so same wot sebje jewja.
- **Pytanje, kotrež krok dźerži.** Hnydomne pytanje po mjenje hry abo wuwjedźomnej dataji přez tysacy hrow, napohlad kachlow abo kompaktneje lisćiny, favority a rjadka „Najnowše“.
- **Jedne kliknjenje.** Wubjer hru, wubjer wuwjedźomnu dataju (jeli je jich wjace), postaj, kak dołho ma wobstać, a tłóč na startować. Wobkruhlićel wotličowanja a zdźělenka ći powědźetej, hdyž čas spadnje.
- **Njezawostaji ničo.** Decoy eksistuje jenož tak dołho, kaž běži: drobna exe-dataja so při starće wutwori a při zastajenju zhaša. Wšo so zastaji, hdyž nałoženje skónčiš, a zbytki po spadźe so při přichodnym starće wumjetu.
- **Ćichi.** Běži w systemowym wotrězku, žane wokna ani tłóčatka na lajsće nadawkow za procesy decoya same.
- **Wotewrjene přełožki.** Powjerch so přez jednore dataje JSON rjaduje, tuž přidawanje rěče wobsahuje jenož jednu dataju. Jendźelšćina a rušćina stej zapřijatej.
- **Priwatnosć.** Žane konto, žadyn token Discorda, žana telemetrija. Hlej [Priwatnosć](#priwatnosć).

## Kak to funguje

1. Discord rozsudźi, zo hru hraješ, hdyž přepytuje procesy běžace na twojim ličaku a přirunuje mjena jich wuwjedźomnych datajow ze zjawnej lisćinu (`/api/v9/applications/detectable`).
2. Decoy tutu lisćinu sćehnje a za hru, kotruž sej wubjerješ, kopěruje drobny zastupowacy program (něhdźe 120 KB, napisany w Rusće a integrowany do Decoya) do nachwilneho rjadowaka pod mjenom wuwjedźomneje dataje z lisćiny, na přikład `.../cod26-cod.exe`.
3. Zastupowacy program njedźeła ničo druhe hač to, zo ma jedne wokno najwyšeje runiny, kotrež je daloko zwonka wobrazowki parkowane, tak zo jo ženje njewidźiš. Discord spóznawa jenož proces, kotryž ma wokno, čehoždla so proces cyle bjez wokna ignoruje.
4. Znutřka něhdźe 15 sekundow Discord hru jako twoju aktualnu aktiwitu pokazuje.
5. Hdyž časoměr spadnje abo tłóčiš na zastajić, Decoy proces skónči a dataju zhaša. Windowsowy nadawkowy objekt (job object) zawěsća, zo decoye hromadźe z Decoyom kónča, samo jeli Decoy spadnje.

## Instalacija

Wubjer sej jednu ze strony [Releases](../../../../releases):

| Sćehnjenje | Za |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalowak.** Za jednotliweho wužiwarja, bjez trjebnosće prawow administratora, přida zapisk do startoweho menija a wotinstalowak. |
| `Decoy_x.y.z_x64-portable.zip` | **Mobilna wersija.** Wupakuj hdźežkuli a startuj `decoy.exe`. Wšě daty wostanu w rjadowaku `data` pódla njeho, do twojeho wužiwarskeho profila so ničo njepisa. Zhaš rjadowak, zo by jón wotstronił. |

Wobkruć sćehnjenje z `SHA256SUMS.txt` (`Get-FileHash <dataja>` w PowerShellu).

Windows SmartScreen móže warnować před njespóznatym wudawaćelom, dokelž wudawki njejsu digitalnje signowane; wubjer *Dalše informacije → Přesto wuwjesć*, jeli wudawkej dowěrješ.

Žadanja: Windows 10 abo 11 (64-bitowy) z běhanskimi wobłukom WebView2 (hižo zapřijaty we Windows 11 a najnowšich aktualizacijach za Windows 10).

## Wužiwanje

1. Wočiń **Biblioteku** a pytaj hru, abo tłóč `Ctrl` + `K` ze wšěch stron.
2. Klikń na hru. W panelu naprawo wubjer proces a kelko mjeńšin ma wobstać (Discordowe aktiwity zwjetša 15 žadaja).
3. Tłóč **Decoy startować**. Discord budźe hru po mało sekundach pokazać.
4. Wotmachuj jón pod **Běžace**, zastaj jedyn abo wšě ke kóždemu časej, abo wostaj Decoy prosće w systemowym wotrězku.

Hry, kotrychž zapisk w Discordźe hišće nima wuwjedźomne dataje, su standardnje schowane (njedadźa so spóznać). Zmóžń *Hry bjez exe pokazać*, zo by je widźał; lisćina so kóždy dźeń aktualizuje, tak zo budu k dispoziciji, hnydom hdyž Discord proces přida.

### Příkazowa linka

```
decoy.exe --launch "<wuwjedźomna šćežka z lisćiny Discorda>" [mjeńšiny]
```

Startuje decoy hnydom, na přikład `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Ze žórłoweho koda natwarić

Wuměnjenja: [Node.js](https://nodejs.org) 20+, stabilna rjadownja gratow [Rust](https://rustup.rs) (MSVC-cil) z natwarjerskimi gratami Visual Studio C++ a běhanski wobłuk WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Wužitne pruwowanja:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Přispomnjenki: Exe-dataja za decoy so přez `src-tauri/build.rs` z prosćym `rustc` ze `src-tauri/stub/stub.rs` kompiluje a potom do nałoženja integruje. Hdyž frontend w normalnym wobhladowaku běži (`npm run dev`), wužiwa so mały podawkowy backend (`src/mock.ts`), štož je přihódne za dźěło na powjerchu.

## Přełožki

Teksty wužiwarskeho powjercha leža w [`src/locales`](../../src/locales), jedna dataja JSON na kóždu rěč (`en.json`, `ru.json`, ...). Přidawanje rěče woznamjenja přidawanje dataje; žane změny koda njejsu trěbne. Hlej [docs/TRANSLATING.md](../TRANSLATING.md) za format dataje, hotowe zadanje za mašinowe přełožowanje a skript přepruwowanja. Přełožki tutoho README słušeja do `docs/i18n/README.<code>.md`.

## Struktura projekta

```
src/                    React + TypeScriptowy frontend
  components/           Biblioteka, wobłuk podrobnosćow, nastajenja, ...
  locales/              přełožowanske dataje (jedna JSON-dataja na rěč)
  i18n-core.ts          začitowanje a pytanje rěčow
  store.ts              status nałoženja (zustand)
src-tauri/              Rustowy backend (Tauri 2)
  src/lib.rs            hrajna datowa banka, decoy-procesy, systemowy wotrězk
  stub/stub.rs          zastupowacy program, kotryž so integruje
scripts/                pomocne skripty (pruwowanje rěčnych datajow)
docs/                   přełožowanski nawod, fota wobrazowki
```

## Priwatnosć

- Decoy syć wužiwa jenož za sćehnjenje zjawneje lisćiny spóznaća Discorda (při prěnim starće, potom maksimalnje raz wob dźeń abo hdyž tłóčiš na aktualizować) a za zwobraznjenje hrajnych symbolow a wobrazkow ze zjawneho CDN Discorda.
- Nječita, njeskładuje ani njesćele twojeho tokena Discorda ani žane daty konta a njekomunikuje z klientom Discorda.
- Nastajenja (favority, rěč, doby traća) so lokalnje w składowaku WebView nałoženja składuja; pufrowak hrajneje lisćiny a nachwilne decoy-dataje leža w `%LOCALAPPDATA%\app.decoy.desktop`.
- Žana analytika, žane rozprawy wo spadach, žane konta.

## Znate wobmjezowanja

- Discord móže wašnje spóznaća ke kóždemu časej změnić. Jeli so decoy hižo njespóznawa, wočiń prošu zdźělenku wo problemje (issue).
- Někotre aktiwity trjebaja wjace hač běžacy proces (na přikład přitomnosć w specielnym dožiwjenju hrajneje platformy). Decoy jenož proces imituje.
- Zapiski bjez wuwjedźomnych datajow w lisćinje Discorda njedadźa so spóznać.
- Wěstotny softwar druhdy małe njesignowane wuwjedźomne dataje, kotrež njedźěławje w pomjatku leža, za podhladne ma. Decoy je wotewrjene žórło a je natwarjeny ze `src-tauri/stub/stub.rs`; móžeš jón sam kompilować.

Ty sam neseš zamołwitosć za to, kak jón wužiwaš. „Discord“ a wšě hrajne mjena a loga su wikowalske marki swojich wobsedźerjow a wužiwaja so tu jenož za identifikaciju softwara, na kotryž so poćahowaja.
