# Decoy

**Procesos sustitutos diminutos que faen creer a Discord qu'un xuegu ta n'execución.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca de Decoy con xuegos recientes ya ilustraciones" />

</div>

Decoy caltién n'execución un procesu sustitutu inofensivu con ventana col nome del executable d'un xuegu, de mou que la detección de xuegos de Discord informa de que tas xugando a esi xuegu. Enxamás precises instalar nin aniciar el xuegu real, polo que nada pesao ocupa espaciu nel to discu.

Conoz **tolos xuegos que Discord puede deteutar** (alredor de 25.000 entraes) porque llee la mesma llista pública de detección de Discord y caltienla anovada por sigo mesmu.

> [!WARNING]
> Asonsañar la execución d'un xuegu puede dir escontra les Condiciones de Serviciu de Discord y uses Decoy **baxo la to propia responsabilidá**.
> Esti proyeutu nun ta afiliáu, sofitáu nin vinculáu a Discord Inc. Consulta'l [Descargu de responsabilidá](#descargu-de-responsabilidá).

## Carauterístiques

- **Tolo que Discord puede deteutar.** La llista de xuegos descárgase dende'l puntu de conexón públicu de detección de Discord, gárdase na caché llocalmente y anuévase a diario. Los xuegos nuevos y los executables amestaos recién apaecen solos.
- **Gueta que sigue'l ritmu.** Gueta al intre por nome de xuegu o executable ente miles de xuegos, vista de cuadrícula o llista compacta, favoritos y una filera de «Recientes».
- **Un solu clic.** Escueyi un xuegu, escueyi l'executable (si hai dellos), define cuánto tiempu caltenelu y calca aniciar. Un aniellu de cuenta atrás y una notificación avísente cuando s'acabe'l tiempu.
- **Nun dexa rastru.** Un decoy namás esiste mientres s'executa: el diminutu exe créase al aniciar y desaníciase al parar. Tóo se para al colar, y los restos tres una cayida llímpiense nel siguiente aniciu.
- **Discretu.** Vive na bandexa del sistema, ensin ventanes nin botones na barra de xeres pa los propios decoys.
- **Traducciones abiertes.** La interfaz básase en ficheros JSON simples, polo qu'amestar una llingua ye cuestión d'un solu ficheru. Inclúyense inglés y rusu.
- **Priváu.** Ensin cuenta, ensin token de Discord, ensin telemetría. Consulta [Privacidá](#privacidá).

## Cómo funciona

1. Discord decide que tas xugando a un xuegu observando los procesos n'execución nel to PC y comparando los sos nomes d'executable con una llista pública (`/api/v9/applications/detectable`).
2. Decoy descarga esa llista y, pal xuegu qu'escueyas, copia un programa sustitutu perpequeñu (d'unos 120 KB, escritu en Rust ya integráu en Decoy) nuna carpeta temporal usando'l nome d'executable de la llista, por exemplu `.../cod26-cod.exe`.
3. El sustitutu nun fai nada sacante tener una ventana de nivel superior, allugada bien lloñe fuera de la pantalla pa que nunca la veas. Discord namás reconoz un procesu si tien una ventana, razón pola cual un procesu dafechu ensin ventana s'inora.
4. Nunos 15 segundos Discord amuesa'l xuegu como la to actividá actual.
5. Cuando'l temporizador fina o calques parar, Decoy fina'l procesu y desanicia'l ficheru. Un oxetu de trabayu (job object) de Windows garantiza que los decoys muerran xunto con Decoy, inclusive si cai de forma inesperada.

## Instalación

Escueyi unu na páxina de [Releases](../../../../releases):

| Descarga | Pa |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por usuariu, ensin necesidá de permisos d'alministrador, amiesta una entrada nel menú Aniciu y un desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Descomprime en cualquier llugar y executa `decoy.exe`. Tolos datos queden na carpeta `data` al so llau, nun s'escribe nada nel to perfil d'usuariu. Desanicia la carpeta pa borralu. |

Verifica una descarga con `SHA256SUMS.txt` (`Get-FileHash <file>` en PowerShell).

Windows SmartScreen puede alvertir sobre un editor non reconocíu porque les compilaciones nun tán firmaes dixitalmente; escueyi *Más información → Executar de toes maneres* si confíes na compilación.

Requisitos: Windows 10 o 11 (64 bits) col runtime de WebView2 (yá incluyíu en Windows 11 y n'anovamientos recientes de Windows 10).

## Usu

1. Abre la **Biblioteca** y busca un xuegu, o calca `Ctrl` + `K` dende cualesquier sitiu.
2. Fai clic nun xuegu. Nel panel de la drecha escueyi'l procesu y cuántos minutos caltenelu (les actividaes de Discord suelen pidir 15).
3. Calca **Iniciar decoy**. Discord va amosar el xuegu tres unos segundos.
4. Síguilu en **N'execución**, para unu o toos en cualquier momentu, o cenciellamente dexa Decoy na bandexa del sistema.

Los xuegos que la so entrada en Discord tovía nun tien executables tán anubríos de mou predetermináu (nun pueden deteutase). Activa *Amosar xuegos ensin exe* pa velos; la llista anuévase a diario, polo que van tar disponibles en cuanto Discord ameste un procesu.

### Llinia d'ordes

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Anicia un decoy darréu, por exemplu `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilar dende'l códigu fonte

Requisitos previos: [Node.js](https://nodejs.org) 20+, el conxuntu de ferramientes estable de [Rust](https://rustup.rs) (oxetivu MSVC) coles ferramientes de compilación de Visual Studio C++, y el runtime de WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Comprobaciones útiles:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notes: l'exe del decoy compílalu `src-tauri/build.rs` con `rustc` cenciellu dende `src-tauri/stub/stub.rs` y llueu intégrase na aplicación. Cuando'l frontend s'executa nun navegador convencional (`npm run dev`), úsase un pequeñu backend simuláu (`src/mock.ts`), lo que resulta práutico pa trabayar na interfaz d'usuariu.

## Traducciones

Les cadenes de la interfaz moren en [`src/locales`](../../src/locales), un ficheru JSON por llingua (`en.json`, `ru.json`, ...). Amestar una llingua significa amestar un ficheru; ensin cambeos de códigu. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) pa conocer el formatu del ficheru, una instrucción llista pa usar con traducción automática y l'escript de validación. Les traducciones d'esti README van a `docs/i18n/README.<code>.md`.

## Estructura del proyeutu

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacidá

- Decoy namás usa la rede pa descargar la llista pública de detección de Discord (nel primer aniciu, y llueu a lo más una vegada al día o cuando calques anovar) y, pa visualización, los iconos ya ilustraciones de los xuegos dende la CDN pública de Discord.
- Nun llee, nun guarda nin unvia'l to token de Discord nin dengún datu de la to cuenta, y nun fala col cliente de Discord.
- Los axustes (favoritos, llingua, duraciones) guárdense llocalmente nel almacenamientu WebView de l'aplicación; la caché de la llista de xuegos y los ficheros temporales de los decoys moren en `%LOCALAPPDATA%\app.decoy.desktop`.
- Ensin analítiques, ensin informes d'erros nin cuentes.

## Llimitaciones conocíes

- Discord puede camudar cómo funciona la detección en cualquier momentu. Si un decoy dexa de reconocese, por favor abre un issue.
- Delles actividaes precisen daqué más qu'un procesu n'execución (por exemplu, tar dientro d'una esperiencia particular d'una plataforma de xuegos). Decoy namás asonsaña'l procesu.
- Les entraes ensin executables na llista de Discord nun pueden deteutase.
- El software de seguridá dacuando marca executables pequeños non firmaos que queden inactivos na memoria. El decoy ye de códigu abiertu y compílase dende `src-tauri/stub/stub.rs`; pues compilalu tu mesmu.
