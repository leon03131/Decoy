# Decoy

**Proses pengganti kecil yang membuat Discord mengira sebuah game sedang berjalan.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Pustaka Decoy dengan game terbaru dan artwork" />

</div>

Decoy mempertahankan proses pengganti berjendela yang tidak berbahaya tetap berjalan di bawah nama file eksekusi game, sehingga deteksi game Discord melaporkan bahwa Anda sedang memainkan game tersebut. Anda tidak perlu menginstal atau meluncurkan game aslinya, sehingga tidak ada file besar yang memakan ruang penyimpanan Anda.

Aplikasi ini mengetahui **setiap game yang dapat dideteksi oleh Discord** (sekitar 25.000 entri) karena membaca daftar deteksi publik milik Discord sendiri dan memperbaruinya secara otomatis.

> [!WARNING]
> Memalsukan game yang sedang berjalan dapat melanggar Ketentuan Layanan Discord dan Anda menggunakan Decoy **atas risiko Anda sendiri**.
> Proyek ini tidak berafiliasi dengan, didukung oleh, atau terhubung dengan Discord Inc. Lihat [Penafian](#penafian).

## Fitur

- **Semua yang dapat dideteksi Discord.** Daftar game diunduh dari endpoint deteksi publik Discord, di-cache secara lokal, dan diperbarui setiap hari. Game baru dan file eksekusi yang baru ditambahkan akan muncul dengan sendirinya.
- **Pencarian yang responsif.** Pencarian instan berdasarkan nama game atau file eksekusi di antara ribuan game, tampilan kisi atau daftar ringkas, favorit, serta baris "Terbaru".
- **Satu klik.** Pilih game, pilih file eksekusi (jika ada beberapa), tentukan berapa lama ingin menjalankannya, lalu tekan mulai. Cincin hitung mundur dan notifikasi akan memberi tahu Anda saat waktunya habis.
- **Tidak meninggalkan jejak.** Decoy hanya ada selama dijalankan: file exe kecil dibuat saat mulai dan dihapus saat dihentikan. Semuanya dihentikan ketika Anda keluar, dan sisa-sisa akibat crash akan dibersihkan pada peluncuran berikutnya.
- **Senyap.** Berada di baki sistem (system tray), tanpa jendela atau tombol taskbar untuk decoy itu sendiri.
- **Terjemahan terbuka.** Antarmukanya digerakkan oleh file JSON biasa, sehingga menambahkan bahasa baru hanya memerlukan satu file. Bahasa Inggris dan Rusia sudah disertakan.
- **Privat.** Tanpa akun, tanpa token Discord, tanpa telemetri. Lihat [Privasi](#privasi).

## Cara kerja

1. Discord menentukan bahwa Anda sedang memainkan game dengan memeriksa proses yang berjalan di PC Anda dan membandingkan nama file eksekusinya dengan daftar publik (`/api/v9/applications/detectable`).
2. Decoy mengunduh daftar tersebut dan, untuk game yang Anda pilih, menyalin program pengganti berukuran kecil (sekitar 120 KB, ditulis dalam Rust dan disematkan ke dalam Decoy) ke folder sementara menggunakan nama file eksekusi dari daftar tersebut, misalnya `.../cod26-cod.exe`.
3. Program pengganti tidak melakukan apa pun selain memiliki satu jendela tingkat atas (top-level window), yang diletakkan jauh di luar layar sehingga Anda tidak pernah melihatnya. Discord hanya mengenali proses yang memiliki jendela, itulah sebabnya proses tanpa jendela sama sekali akan diabaikan.
4. Dalam waktu sekitar 15 detik, Discord akan menampilkan game tersebut sebagai aktivitas Anda saat ini.
5. Ketika penghitung waktu berakhir atau Anda menekan tombol stop, Decoy mengakhiri proses dan menghapus file tersebut. Windows job object memastikan decoy ditutup bersamaan dengan Decoy, bahkan jika aplikasi mengalami crash.

## Instalasi

Pilih salah satu dari halaman [Releases](../../../../releases):

| Unduhan | Untuk |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Penginstal.** Per pengguna, tidak memerlukan hak administrator, menambahkan entri menu Mulai (Start menu) dan uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Ekstrak di mana saja dan jalankan `decoy.exe`. Semua data tetap berada di folder `data` di sampingnya, tidak ada yang ditulis ke profil pengguna Anda. Hapus foldernya untuk menghapusnya. |

Verifikasi unduhan dengan `SHA256SUMS.txt` (`Get-FileHash <file>` di PowerShell).

Windows SmartScreen mungkin menampilkan peringatan tentang penerbit yang tidak dikenal karena build ini tidak ditandatangani secara digital (code signed); pilih *More info → Run anyway* jika Anda memercayai build tersebut.

Persyaratan: Windows 10 atau 11 (64-bit) dengan WebView2 runtime (sudah disertakan dalam Windows 11 dan pembaruan Windows 10 terkini).

## Penggunaan

1. Buka **Pustaka** dan cari game, atau tekan `Ctrl` + `K` dari mana saja.
2. Klik sebuah game. Pada panel di sebelah kanan, pilih proses dan berapa menit ingin menjalankannya (aktivitas Discord biasanya meminta 15 menit).
3. Tekan **Mulai decoy**. Discord akan menampilkan game tersebut setelah beberapa detik.
4. Pantau di bagian **Berjalan**, hentikan salah satu atau semuanya kapan saja, atau cukup biarkan Decoy di baki sistem (tray).

Game yang entri Discord-nya belum memiliki file eksekusi disembunyikan secara default (game tersebut belum dapat dideteksi). Aktifkan *Tampilkan game tanpa exe* untuk melihatnya; daftar ini diperbarui setiap hari, sehingga akan segera tersedia setelah Discord menambahkan prosesnya.

### Baris perintah

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Memulai decoy secara langsung, misalnya `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Membangun dari sumber

Prasyarat: [Node.js](https://nodejs.org) 20+, toolchain [Rust](https://rustup.rs) stabil (target MSVC) beserta Visual Studio C++ build tools, dan WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Pemeriksaan yang berguna:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Catatan: file exe decoy dikompilasi oleh `src-tauri/build.rs` menggunakan `rustc` standar dari `src-tauri/stub/stub.rs` dan kemudian disematkan ke dalam aplikasi. Ketika frontend dijalankan di browser biasa (`npm run dev`), backend tiruan (mock) kecil (`src/mock.ts`) akan digunakan, yang sangat berguna saat mengerjakan UI.

## Terjemahan

String UI berada di [`src/locales`](../../src/locales), satu file JSON per bahasa (`en.json`, `ru.json`, ...). Menambahkan bahasa baru berarti cukup menambahkan satu file; tanpa perlu mengubah kode. Lihat [docs/TRANSLATING.md](../TRANSLATING.md) untuk format file, prompt siap pakai untuk terjemahan mesin, dan skrip validasi. Terjemahan dari README ini disimpan di `docs/i18n/README.<code>.md`.

## Struktur proyek

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privasi

- Decoy hanya menggunakan jaringan untuk mengunduh daftar deteksi publik Discord (pada saat pertama kali dijalankan, lalu paling banyak sekali sehari atau saat Anda menekan tombol refresh) dan, untuk tampilan, ikon game serta artwork dari CDN publik Discord.
- Aplikasi ini tidak membaca, menyimpan, atau mengirimkan token Discord Anda maupun data akun apa pun, dan tidak berkomunikasi dengan klien Discord.
- Pengaturan (favorit, bahasa, durasi) disimpan secara lokal di penyimpanan WebView aplikasi; cache daftar game dan file sementara decoy berada di `%LOCALAPPDATA%\app.decoy.desktop`.
- Tanpa analitik, tanpa pelaporan crash, tanpa akun.

## Batasan yang diketahui

- Discord dapat mengubah cara kerja deteksi kapan saja. Jika decoy tidak lagi dikenali, silakan buka issue.
- Beberapa aktivitas memerlukan lebih dari sekadar proses yang berjalan (misalnya berada di dalam pengalaman tertentu pada platform game). Decoy hanya menirukan prosesnya saja.
- Entri tanpa file eksekusi di daftar Discord tidak dapat dideteksi.
- Perangkat lunak keamanan terkadang menandai file eksekusi kecil yang tidak ditandatangani dan diam di memori. Decoy bersifat sumber terbuka (open source) dan dibangun dari `src-tauri/stub/stub.rs`; Anda dapat mengompilasinya sendiri.

## Penafian

Decoy disediakan "apa adanya" untuk tujuan pribadi, pendidikan, dan pengujian. Meniru game yang sedang berjalan dapat melanggar Ketentuan Layanan Discord atau penerbit game yang bersangkutan, dan dapat menyebabkan tindakan terhadap akun Anda. Anda sendiri yang bertanggung jawab atas penggunaannya. "Discord" serta semua nama game dan logo adalah merek dagang dari pemiliknya masing-masing dan hanya digunakan di sini untuk mengidentifikasi perangkat lunak yang dirujuk.
