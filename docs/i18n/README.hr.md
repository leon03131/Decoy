# Decoy

**Mali zamjenski procesi zbog kojih Discord misli da je igra pokrenuta.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy knjižnica s nedavnim igrama i slikama" />

</div>

Decoy održava bezopasan zamjenski proces s prozorom pod nazivom izvršne datoteke igre, tako da
Discordovo otkrivanje igara prikazuje da igrate tu igru. Nikada ne morate instalirati niti pokrenuti
pravu igru, tako da vam ništa veliko ne zauzima prostor na disku.

Zna za **svaku igru koju Discord može otkriti** (oko 25.000 unosa) jer čita Discordov vlastiti
javni popis za otkrivanje i samostalno ga ažurira.

> [!WARNING]
> Lažiranje pokrenute igre može biti u suprotnosti s Discordovim Uvjetima pružanja usluge i Decoy koristite
> **na vlastitu odgovornost**. Ovaj projekt nije povezan s Discord Inc., niti ga oni podržavaju ili odobravaju.
> Pogledajte [Odricanje od odgovornosti](#odricanje-od-odgovornosti).

## Značajke

- **Sve što Discord može otkriti.** Popis igara preuzima se s Discordove javne krajnje točke za otkrivanje,
  sprema se lokalno i osvježava svakodnevno. Nove igre i novododane izvršne datoteke pojavljuju se same od sebe.
- **Pretraživanje koje drži korak.** Trenutačno pretraživanje po nazivu igre ili izvršnoj datoteci među tisućama
  igara, prikaz u obliku mreže ili kompaktnog popisa, favoriti i redak „Nedavno”.
- **Jedan klik.** Odaberite igru, odaberite izvršnu datoteku (ako ih ima više), odaberite koliko dugo želite
  zadržati proces i pritisnite pokreni. Prsten s odbrojavanjem i obavijest javit će vam kada vrijeme istekne.
- **Ne ostavlja ništa za sobom.** Decoy postoji samo dok radi: mali exe stvara se pri pokretanju i briše pri
  zaustavljanju. Sve se zaustavlja kada zatvorite program, a ostaci nakon rušenja čiste se pri sljedećem pokretanju.
- **Tih.** Nalazi se u programskoj traci (system tray), bez prozora ili gumba na traci zadataka za same zamjenske procese.
- **Otvoreni prijevodi.** Sučelje se pokreće putem običnih JSON datoteka, pa je dodavanje jezika samo jedna datoteka.
  Engleski i ruski su uključeni.
- **Privatno.** Bez računa, bez Discord tokena, bez telemetrije. Pogledajte [Privatnost](#privatnost).

## Kako radi

1. Discord utvrđuje igrate li igru pregledavanjem procesa pokrenutih na vašem računalu i uspoređivanjem njihovih
   naziva izvršnih datoteka s javnim popisom (`/api/v9/applications/detectable`).
2. Decoy preuzima taj popis i, za igru koju odaberete, kopira mali zamjenski program (oko 120 KB, napisan u
   Rustu i ugrađen u Decoy) u privremenu mapu koristeći naziv izvršne datoteke s popisa, na primjer
   `.../cod26-cod.exe`.
3. Zamjenski program ne radi ništa osim što posjeduje jedan prozor najviše razine, smješten daleko izvan zaslona
   tako da ga nikada ne vidite. Discord prepoznaje samo proces koji posjeduje prozor, zbog čega se proces potpuno
   bez prozora ignorira.
4. Unutar otprilike 15 sekundi Discord prikazuje igru kao vašu trenutnu aktivnost.
5. Kada tajmer istekne ili pritisnete zaustavi, Decoy prekida proces i briše datoteku. Windows objekt zadatka
   (job object) osigurava da se zamjenski procesi ugase zajedno s aplikacijom Decoy, čak i ako se ona sruši.

## Instalacija

Odaberite jednu s stranice [Releases](../../../../releases):

| Preuzimanje | Za |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalacijski program.** Po korisniku, nisu potrebna administratorska prava, dodaje unos u izbornik Start i program za deinstalaciju. |
| `Decoy_x.y.z_x64-portable.zip` | **Prijenosna verzija (Portable).** Raspakirajte bilo gdje i pokrenite `decoy.exe`. Svi podaci ostaju u mapi `data` pored njega, ništa se ne zapisuje u vaš korisnički profil. Izbrišite mapu da biste ga uklonili. |

Provjerite preuzimanje pomoću `SHA256SUMS.txt` (`Get-FileHash <datoteka>` u programu PowerShell).

Windows SmartScreen može upozoriti na neprepoznatog izdavača jer međuverzije nisu digitalno potpisane; odaberite
*Više informacija → Svejedno pokreni* ako vjerujete međuverziji.

Zahtjevi: Windows 10 ili 11 (64-bitni) s WebView2 runtimeom (već uključen u Windows 11 i novijim ažuriranjima za
Windows 10).

## Korištenje

1. Otvorite **Knjižnica** i potražite igru ili pritisnite `Ctrl` + `K` s bilo kojeg mjesta.
2. Kliknite igru. Na ploči s desne strane odaberite proces i koliko minuta ga želite zadržati (Discord aktivnosti
   obično traže 15).
3. Pritisnite **Pokreni decoy**. Discord će prikazati igru nakon nekoliko sekundi.
4. Pratite je pod **Pokrenuto**, zaustavite jedan ili sve u bilo kojem trenutku, ili jednostavno ostavite Decoy u programskoj traci.

Igre čiji unos na Discordu još nema izvršne datoteke skrivene su prema zadanim postavkama (ne mogu se otkriti). Uključite
*Prikaži igre bez exe* da biste ih vidjeli; popis se osvježava svakodnevno, pa postaju dostupne čim Discord doda
proces.

### Naredbeni redak

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Pokreće decoy odmah, na primjer `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Izgradnja iz izvornog koda

Preduvjeti: [Node.js](https://nodejs.org) 20+, stabilan [Rust](https://rustup.rs) alatni lanac (MSVC cilj) s
Visual Studio C++ alatima za izgradnju i WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # pokretanje u razvojnom načinu s vrućim ponovnim učitavanjem
npm run tauri build    # stvaranje instalacijskog programa u src-tauri/target/release/bundle/nsis
```

Korisne provjere:

```bash
npm run check-locales  # provjera svake datoteke prijevoda u odnosu na ru.json
npx tsc --noEmit       # provjera tipova sučelja
cargo check --manifest-path src-tauri/Cargo.toml
```

Napomene: izvršna datoteka zamjenskog programa (decoy exe) prevodi se pomoću `src-tauri/build.rs` običnim `rustc` alatom iz `src-tauri/stub/stub.rs` i zatim
se ugrađuje u aplikaciju. Kada sučelje radi u običnom pregledniku (`npm run dev`), koristi se mali imitirani poslužitelj
(`src/mock.ts`), što je prikladno za rad na korisničkom sučelju.

## Prijevodi

Tekstovi korisničkog sučelja nalaze se u [`src/locales`](../../src/locales), jedna JSON datoteka po jeziku (`en.json`, `ru.json`, ...).
Dodavanje jezika znači dodavanje jedne datoteke; bez promjena koda. Pogledajte [docs/TRANSLATING.md](../TRANSLATING.md) za format
datoteke, gotov upit za strojno prevođenje i skriptu za provjeru valjanosti. Prijevodi ove datoteke README spremaju se u
`docs/i18n/README.<code>.md`.

## Struktura projekta

```
src/                    React + TypeScript sučelje
  components/           Knjižnica, ploča s detaljima, postavke, ...
  locales/              datoteke prijevoda (jedan JSON po jeziku)
  i18n-core.ts          učitavanje i pretraživanje jezika
  store.ts              stanje aplikacije (zustand)
src-tauri/              Rust pozadinski sustav (Tauri 2)
  src/lib.rs            baza podataka igara, decoy procesi, programska traka
  stub/stub.rs          zamjenski program koji se ugrađuje
scripts/                pomoćne skripte (provjera valjanosti prijevoda)
docs/                   vodič za prevođenje, snimke zaslona
```

## Privatnost

- Decoy koristi mrežu samo za preuzimanje Discordovog javnog popisa za otkrivanje (pri prvom pokretanju, a zatim najviše
  jednom dnevno ili kada pritisnete osvježi) i, radi prikaza, ikona igara i slika s Discordovog javnog CDN-a.
- Ne čita, ne pohranjuje niti šalje vaš Discord token ili bilo kakve podatke o računu, i ne komunicira s Discord klijentom.
- Postavke (favoriti, jezik, trajanja) pohranjuju se lokalno u WebView pohrani aplikacije; predmemorija popisa igara i
  privremene datoteke zamjenskih procesa nalaze se u `%LOCALAPPDATA%\app.decoy.desktop`.
- Bez analitike, bez izvještavanja o rušenju, bez računa.

## Poznata ograničenja

- Discord može u bilo kojem trenutku promijeniti način otkrivanja. Ako se decoy prestane prepoznavati, otvorite prijavu problema (issue).
- Neke aktivnosti zahtijevaju više od samog pokrenutog procesa (na primjer, boravak unutar određenog iskustva na
  platformi za igre). Decoy oponaša samo proces.
- Unosi bez izvršnih datoteka na Discordovom popisu ne mogu se otkriti.
- Sigurnosni softver povremeno može označiti male nepotpisane izvršne datoteke koje neaktivno stoje u memoriji. Decoy je otvorenog
  koda i izgrađen je iz `src-tauri/stub/stub.rs`; možete ga sami prevesti.

## Odricanje od odgovornosti

Decoy se pruža „kakav jest” u osobne, obrazovne i svrhe testiranja. Oponašanje pokrenute igre može kršiti
Uvjete pružanja usluge za Discord ili izdavača igre te može dovesti do mjera protiv vašeg računa. Vi sami snosite
isključivu odgovornost za način na koji ga koristite. „Discord” i svi nazivi i logotipi igara zaštitni su znakovi
svojih odgovarajućih vlasnika i ovdje se koriste samo za identifikaciju softvera na koji se odnose.
