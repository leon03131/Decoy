## Nähili işleýär

1. Discord kompýuteriňizde işleýän prosesleri gözden geçirmek we olaryň ýerine ýetirilýän faýl atlaryny köpçülige açyk sanaw (`/api/v9/applications/detectable`) bilen deňeşdirmek arkaly siziň oýun oýnaýandygyňyzy kesgitleýär.
2. Decoy şol sanawy ýükläp alýar we saýlan oýnuňyz üçin sanawdaky ýerine ýetirilýän faýlyň adyny ulanyp, kiçijik çalşyryjy programmany (takmynan 120 KB, Rust dilinde ýazylan we Decoy içine gurlan) wagtlaýyn bukja göçürýär, mysal üçin `.../cod26-cod.exe`.
3. Çalşyryjy programma siziň hiç haçan görmejek, ekrandan daşda ýerleşýän ýokary derejeli ýekeje penjirä eýe bolmakdan başga hiç zat etmeýär. Discord diňe penjiresi bolan prosesi ykrar edýär, şol sebäpli bütinleý penjiresiz prosesler hasaba alynmaýar.
4. Takmynan 15 sekundyň içinde Discord oýny siziň häzirki işjeňligiňiz hökmünde görkezýär.
5. Taýmer tamamlananda ýa-da siz duruzmak düwmesine basanyňyzda, Decoy prosesi ýapýar we faýly pozýar. Windows job object guraly Decoy hatda näsazlyk bilen ýapylsa hem, decoy-laryň Decoy bilen bilelikde ýapylmagyny üpjün edýär.

## Ulanylyşy

1. **Kitaphana** açyň we oýun gözläň, ýa-da islendik ýerden `Ctrl` + `K` basyň.
2. Oýnuň üstüne basyň. Sag tarapdaky panelde prosesi we ony näçe minut saklamalydygyny saýlaň (Discord işjeňlikleri köplenç 15 minut talap edýär).
3. **Decoy başlat** basyň. Discord birnäçe sekuntdan soň oýny görkezer.
4. Ony **Işleýänler** bölüminde yzarlap bilersiňiz, islendik wagt birini ýa-da ählisini duruzyp bilersiňiz, ýa-da Decoy-y treýde goýup bilersiňiz.

## Çeşme kodundan gurmak

Talap edilýänler: [Node.js](https://nodejs.org) 20+, Visual Studio C++ gurnama gurallary bolan durnukly [Rust](https://rustup.rs) gural toplumy (MSVC nyşanly) we WebView2 runtime.


Peýdaly barlaglar:


Bellikler: decoy exe faýly `src-tauri/build.rs` tarapyndan adaty `rustc` arkaly `src-tauri/stub/stub.rs` faýlyndan jemlenýär we soňra programma gurnalýar. Frontend adaty brauzerde işlän wagty (`npm run dev`), kiçijik emeli backend (`src/mock.ts`) ulanylýar, bu bolsa UI üstünde işlemek üçin örän amatlydyr.
