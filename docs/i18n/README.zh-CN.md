# Decoy

**微型替身进程，让 Discord 误以为游戏正在运行。**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy 游戏库，包含最近运行的游戏与封面插画" />

</div>

Decoy 会以游戏可执行文件的名称在后台运行一个无害的、带窗口的占位进程，使 Discord 的游戏检测机制判定你正在游玩该游戏。你完全无需安装或启动真正的游戏，因此不会占用大量磁盘空间。

它了解 **Discord 所能检测到的所有游戏**（约 25,000 款），因为它会读取 Discord 官方公开的检测列表并自动保持更新。

> [!WARNING]
> 伪造正在运行的游戏可能违反 Discord 服务条款，使用 Decoy 的**一切风险由你自行承担**。
> 本项目与 Discord Inc. 没有任何关联、认可或隶属关系。参见[免责声明](#免责声明)。

## 功能特性

- **支持 Discord 能检测到的一切游戏。** 游戏列表直接从 Discord 的公开检测端点下载，在本地缓存并每日自动刷新。新游戏以及新添加的可执行文件会自动显示。
- **快速流畅的即时搜索。** 支持在数千款游戏中按游戏名称或可执行文件名即时搜索，支持网格视图与紧凑列表视图、收藏夹以及“最近使用”栏。
- **一键运行。** 选择一款游戏，挑选可执行文件（如果有多个），设定保持运行的时长并点击启动。倒计时环和系统通知会在时间结束时提醒你。
- **不留痕迹。** 替身进程仅在运行时存在：极小的 exe 在启动时创建，在停止时自动删除。退出程序时所有进程都会停止，崩溃遗留的残留文件也会在下次启动时自动清理。
- **安静无扰。** 常驻系统托盘，替身进程本身不会弹出窗口，也不会在任务栏显示按钮。
- **开放翻译。** 界面完全由纯 JSON 文件驱动，添加新语言只需新增一个文件。目前已内置英语和俄语。
- **注重隐私。** 无需注册账号，无需 Discord 令牌（Token），无任何遥测数据收集。参见[隐私](#隐私)。

## 工作原理

1. Discord 通过检查你电脑上正在运行的进程，并将其可执行文件名与公开列表（`/api/v9/applications/detectable`）进行比对，以此判断你是否正在游玩某款游戏。
2. Decoy 会下载该列表，并针对你选择的游戏，将一个微型替身程序（约 120 KB，使用 Rust 编写并内嵌于 Decoy 中）复制到临时文件夹中，重命名为列表中的可执行文件名（例如 `.../cod26-cod.exe`）。
3. 该替身程序除了持有一个顶层窗口外不做任何事，且该窗口停靠在屏幕视野之外，因此你完全看不到它。Discord 仅能识别拥有窗口的进程，这也是完全无窗口的进程会被忽略的原因。
4. 大约 15 秒内，Discord 就会将该游戏显示为你当前正在进行的活动。
5. 当计时器结束或你点击停止时，Decoy 会终止该进程并删除对应文件。借助 Windows 作业对象（Job Object），即使 Decoy 意外崩溃，替身进程也会随之退出。

## 安装

前往 [Releases](../../../../releases) 页面下载对应版本：

| 下载项 | 说明 |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **安装程序。** 单用户安装，无需管理员权限，会自动添加开始菜单快捷方式与卸载程序。 |
| `Decoy_x.y.z_x64-portable.zip` | **便携版。** 解压到任意位置即可运行 `decoy.exe`。所有数据均保存在程序旁的 `data` 文件夹中，不会向用户目录写入任何内容。删除该文件夹即可彻底卸载。 |

可通过 `SHA256SUMS.txt` 校验下载的文件（在 PowerShell 中运行 `Get-FileHash <file>`）。

由于构建产物未进行代码签名，Windows SmartScreen 可能会提示未知发布者；如果你信任该构建版本，请点击*更多信息 → 仍要运行*。

系统要求：Windows 10 或 11（64 位），并安装有 WebView2 运行时（Windows 11 及近期的 Windows 10 更新中已默认内置）。

## 使用说明

1. 打开**游戏库**并搜索游戏，或在任意位置按下 `Ctrl` + `K`。
2. 点击一款游戏。在右侧面板中选择进程以及需要保持的时长分钟数（Discord 活动任务通常需要 15 分钟）。
3. 点击**启动替身**。几秒后 Discord 就会显示该游戏。
4. 可在**运行中**列表查看状态，随时停止单个或所有替身进程，也可以直接让 Decoy 最小化到系统托盘。

Discord 词条中尚未包含可执行文件的游戏默认会被隐藏（因为它们无法被检测）。开启*显示无 exe 游戏*即可查看它们；列表每天刷新一次，一旦 Discord 添加了对应进程即可直接使用。

### 命令行

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

直接启动替身，例如 `decoy.exe --launch "robloxplayerbeta.exe" 15`。

## 从源码构建

环境要求：[Node.js](https://nodejs.org) 20+、带 Visual Studio C++ 构建工具的稳定版 [Rust](https://rustup.rs) 工具链（MSVC 目标平台），以及 WebView2 运行时。

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

常用检查命令：

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

注意：替身 exe 是在 `src-tauri/build.rs` 中通过原生的 `rustc` 将 `src-tauri/stub/stub.rs` 编译并嵌入到主程序中的。当在普通浏览器中运行前端时（`npm run dev`），程序会使用轻量级 mock 后端（`src/mock.ts`），方便开发调试界面。

## 翻译

界面文本位于 [`src/locales`](../../src/locales)，每种语言对应一个 JSON 文件（`en.json`、`ru.json` 等）。
添加一种语言只需添加一个文件，无需修改任何代码。有关文件格式、可直接使用的机器翻译提示词以及校验脚本，请参见 [docs/TRANSLATING.md](../TRANSLATING.md)。本自述文件的翻译请放置在 `docs/i18n/README.<code>.md`。

## 项目结构

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## 隐私

- Decoy 仅在下载 Discord 公开检测列表（首次启动时下载，之后最多每天一次或在你点击刷新时）以及展示游戏图标和封面（从 Discord 的公开 CDN 获取）时使用网络。
- 它不会读取、存储或发送你的 Discord 令牌（Token）或任何账户数据，也不会与 Discord 客户端通信。
- 设置项（收藏、语言、持续时长）存储在应用的本地 WebView 存储中；游戏列表缓存和临时替身文件保存在 `%LOCALAPPDATA%\app.decoy.desktop`。
- 无数据分析，无崩溃报告，无需账号。

## 已知限制

- Discord 可能会随时更改其检测机制。如果替身进程不再被识别，请提交 Issue。
- 某些活动不仅需要运行中的进程（例如处于游戏平台的特定体验或关卡中）。Decoy 仅模拟进程本身。
- Discord 列表中没有可执行文件的条目无法被检测。
- 安全软件有时可能会警告在内存中处于闲置状态的小型未签名可执行文件。替身程序完全开源并基于 `src-tauri/stub/stub.rs` 构建；你可以自行编译。
