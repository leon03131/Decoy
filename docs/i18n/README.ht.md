# Decoy

**Ti pwosesis ranplasman ki fè Discord kwè yon jwèt ap fonksyone.**

![Platfòm](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Konstwi ak](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![Lisans](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Bibliyotèk Decoy avèk jwèt ki fèk itilize ak ilistrasyon" />

</div>

Decoy kenbe yon ti pwosesis ranplasman inofansif avèk fenèt k ap fonksyone anba non fichye ègzekutab yon jwèt, pou deteksyon jwèt Discord ka rapòte w kòm moun k ap jwe jwèt sa a. Ou pa janm bezwen enstale oswa lanse vrè jwèt la, kidonk pa gen anyen ki lou k ap pran espas sou disk ou.

Li konnen **tout jwèt Discord ka detekte** (anviwon 25,000 antre) paske li li lis deteksyon piblik Discord la dirèkteman epi li mete l ajou poukont li.

> [!WARNING]
> Fo deteksyon yon jwèt ka vyole Kondisyon Sèvis Discord epi ou itilize Decoy **sou pwòp risk ou**.
> Pwojè sa a pa gen okenn afilyasyon, apwobasyon oswa koneksyon avèk Discord Inc. Gade [Avètisman](#avètisman).

## Karakteristik yo

- **Tout sa Discord ka detekte.** Yo telechaje lis jwèt yo nan endpoint deteksyon piblik Discord la, mete l nan kach lokal epi rafrechi l chak jou. Nouvo jwèt ak nouvo ègzekutab ki ajoute parèt poukont yo.
- **Rechèch rapid e efikas.** Rechèch enstantane pa non jwèt oswa pa ègzekutab atravè plizyè milye jwèt, afichaj an mozayik oswa an lis konpak, favori ak yon ranje «Dènye jwèt».
- **Nan yon sèl klik.** Chwazi yon jwèt, chwazi ègzekutab la (si gen plizyè), chwazi konbyen tan pou kenbe l epi peze kòmanse. Yon bag dekont ak yon notifikasyon fè w konnen lè tan an fin pase.
- **Li pa kite okenn tras.** Yon Decoy egziste sèlman pandan l ap fonksyone: ti exe a kreye lè w kòmanse l epi li efase lè w sispann li. Tout bagay kanpe lè w kite aplikasyon an, epi nenpòt rès apre yon pann netwaye nan pwochen lansman an.
- **Diskret.** Li rete nan plato sistèm nan (system tray), pa gen okenn fenèt oswa bouton nan ba tach la pou Decoy yo menm.
- **Tradiksyon ouvè.** Entèfas la baze sou senp fichye JSON, kidonk ajoute yon lang se jis ajoute yon sèl fichye. Anglè ak Ris enkli ladan l deja.
- **Prive.** Pa gen kont, pa gen jeton Discord, pa gen telemetri. Gade [Konfidansyalite](#konfidansyalite).

## Kijan li fonksyone

1. Discord detèmine si w ap jwe yon jwèt nan verifye pwosesis k ap fonksyone sou òdinatè w lan epi konpare non ègzekutab yo avèk yon lis piblik (`/api/v9/applications/detectable`).
2. Decoy telechaje lis sa a epi, pou jwèt ou chwazi a, kopye yon ti pwogram ranplasman (anviwon 120 Ko, ekri nan Rust epi entegre nan Decoy) nan yon dosye tanporè avèk non ègzekutab ki nan lis la, pa egzanp `.../cod26-cod.exe`.
3. Pwogram ranplasman an pa fè anyen apa posede yon fenèt nan premye plan, mete l byen lwen deyò ekran an pou w pa janm wè l. Discord sèlman rekonèt yon pwosesis ki posede yon fenèt, se poutèt sa yo inyore yon pwosesis ki pa gen fenèt ditou.
4. Nan anviwon 15 segonn, Discord montre jwèt la kòm aktivite w aktyèl.
5. Lè revèy la fini oswa lè w peze sispann, Decoy fèmen pwosesis la epi efase fichye a. Yon Windows job object asire Decoy yo fèmen ansanm avèk Decoy, menm si li ta plante sanzatann.

## Enstalasyon

Chwazi youn nan paj [Releases](../../../../releases) la:

| Telechaje | Pou |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Enstalatè.** Pa itilizatè, pa bezwen dwa administratè, ajoute yon antre nan meni Start ak yon pwogram pou dezinstale. |
| `Decoy_x.y.z_x64-portable.zip` | **Pòtab.** Dekonprese nenpòt kote epi kouri `decoy.exe`. Tout done rete nan dosye `data` bò kote l, pa gen anyen ki ekri nan pwofil itilizatè w la. Efase dosye a pou retire l. |

Verifye telechajman an avèk `SHA256SUMS.txt` (`Get-FileHash <fichye>` nan PowerShell).

Windows SmartScreen ka montre yon avètisman sou yon editè enkoni paske vèsyon yo pa gen siyati nimerik; chwazi *Plis enfòmasyon → Kouri kanmenm* si w fè fichye a konfyans.

Kondisyon nesesè: Windows 10 oswa 11 (64-ti moso) avèk runtime WebView2 a (deja enkli nan Windows 11 ak dènye mizajou Windows 10 yo).

## Itilizasyon

1. Louvri **Bibliyotèk** epi chèche yon jwèt, oswa peze `Ctrl` + `K` nenpòt kote.
2. Klike sou yon jwèt. Nan panèl sou bò dwat la, chwazi pwosesis la ak konbyen minit pou kenbe l (aktivite Discord yo anjeneral mande 15).
3. Peze **Kòmanse Decoy**. Discord ap montre jwèt la apre kèk segonn.
4. Gade l anba **Ap fonksyone**, sispann youn oswa tout nenpòt lè, oswa jis kite Decoy nan plato sistèm nan.

Jwèt ki nan lis Discord la ki poko gen ègzekutab kache pa defo (yo pa ka detekte). Aktive *Montre jwèt san exe* pou wè yo; lis la rafrechi chak jou, kidonk yo vin disponib le pli vit ke Discord ajoute yon pwosesis.

### Liy kòmand

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Lanse yon Decoy imedyatman, pa egzanp `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bati apati kòd sous

Kondisyon preliminè: [Node.js](https://nodejs.org) 20+, zouti estanda [Rust](https://rustup.rs) (sib MSVC) avèk zouti konpilasyon C++ Visual Studio, ak runtime WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # lanse nan mòd devlopman avèk rechajman rapid
npm run tauri build    # pwodui enstalatè a nan src-tauri/target/release/bundle/nsis
```

Verifikasyon itil:

```bash
npm run check-locales  # valide chak fichye tradiksyon parapò ak ru.json
npx tsc --noEmit       # tcheke tip frontend lan
cargo check --manifest-path src-tauri/Cargo.toml
```

Nòt: exe Decoy a konpile pa `src-tauri/build.rs` avèk senp `rustc` apati `src-tauri/stub/stub.rs` epi entegre nan aplikasyon an. Lè frontend lan ap kouri nan yon navigatè senp (`npm run dev`), yo itilize yon ti mock backend (`src/mock.ts`), ki pratik anpil pou travay sou UI a.

## Tradiksyon

Tèks UI yo sitiye nan [`src/locales`](../../src/locales), yon fichye JSON pou chak lang (`en.json`, `ru.json`, ...).
Ajoute yon lang vle di ajoute yon fichye; pa gen okenn chanjman nan kòd la. Gade [docs/TRANSLATING.md](../TRANSLATING.md) pou fòma fichye a, yon modèl envit pare pou itilize pou tradiksyon otomatik ak script validasyon an. Tradiksyon README sa a ale nan `docs/i18n/README.<code>.md`.

## Estrikti pwojè a

```
src/                    Frontend React + TypeScript
  components/           Bibliyotèk, panèl detay, paramèt, ...
  locales/              fichye tradiksyon yo (yon JSON pou chak lang)
  i18n-core.ts          chajman lang ak rechèch
  store.ts              eta aplikasyon an (zustand)
src-tauri/              Backend Rust (Tauri 2)
  src/lib.rs            baz done jwèt, pwosesis Decoy, plato sistèm
  stub/stub.rs          ti pwogram ranplasman ki entegre a
scripts/                script èd (validasyon lang)
docs/                   gid tradiksyon, kapti d ekran
```

## Konfidansyalite

- Decoy sèlman itilize rezo a pou telechaje lis deteksyon piblik Discord la (nan premye lansman an, apre sa omaksimòm yon fwa pa jou oswa lè w peze rafrechi) epi, pou afichaj, ikon jwèt yo ak ilistrasyon ki soti nan CDN piblik Discord la.
- Li pa li, anrejistre oswa voye jeton Discord ou a oswa nenpòt done kont, epi li pa pale avèk kliyan Discord la.
- Paramèt yo (favori, lang, dire) anrejistre lokalman nan espas depo WebView aplikasyon an; kach lis jwèt yo ak fichye tanporè Decoy yo rete nan `%LOCALAPPDATA%\app.decoy.desktop`.
- Pa gen analiz telemetri, pa gen rapò sou pann, pa gen kont.

## Limit li te ye

- Discord ka chanje jan deteksyon an fonksyone nenpòt lè. Si yon Decoy pa rekonèt ankò, tanpri louvri yon issue.
- Gen kèk aktivite ki bezwen plis pase yon senp pwosesis k ap fonksyone (pa egzanp rete andedan yon eksperyans espesifik sou yon platfòm jwèt). Decoy sèlman imite pwosesis la.
- Antre ki pa gen ègzekutab nan lis Discord la pa ka detekte.
- Lojisyèl sekirite ka pafwa sispèk ti ègzekutab ki pa siyen ki rete an repo nan memwa a. Decoy se kòd ouvè epi li bati apati `src-tauri/stub/stub.rs`; ou ka konpile li poukont ou.

## Avètisman

Decoy bay «jan li ye a» pou rezon pèsonèl, edikatif ak tès sèlman. Imite yon jwèt k ap fonksyone ka vyole Kondisyon Sèvis Discord oswa editè jwèt la, epi sa ka mennen nan sanksyon kont kont ou. Ou se sèl responsab fason ou itilize li. «Discord» ak tout non jwèt ak logo se mak komèsyal pwopriyetè respektif yo epi yo itilize yo isit la sèlman pou idantifye lojisyèl yo refere a.
