# Decoy

**Kleine stand-in processen die Discord laten denken dat er een game draait.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-bibliotheek met recente games en artwork" />

</div>

Decoy houdt een onschadelijk plaatsvervangend proces met een venster actief onder de naam van het uitvoerbare bestand van een game, zodat de gamedetectie van Discord aangeeft dat je die game speelt. Je hoeft de echte game nooit te installeren of te starten, waardoor er niets groots ruimte inneemt op je schijf.

Het kent **elke game die Discord kan detecteren** (ongeveer 25.000 vermeldingen) doordat het de openbare detectielijst van Discord zelf uitleest en automatisch up-to-date houdt.

> [!WARNING]
> Het nabootsen van een actieve game kan in strijd zijn met de Servicevoorwaarden van Discord en je gebruikt Decoy **op eigen risico**.
> Dit project is niet gelieerd aan, goedgekeurd door of verbonden met Discord Inc. Zie [Disclaimer](#disclaimer).

## Functies

- **Alles wat Discord kan detecteren.** De gamelijst wordt gedownload van het openbare detectie-eindpunt van Discord, lokaal gecachet en dagelijks vernieuwd. Nieuwe games en nieuw toegevoegde uitvoerbare bestanden verschijnen automatisch.
- **Razendsnel zoeken.** Direct zoeken op gamenaam of uitvoerbaar bestand tussen duizenden games, tegel- of compacte lijstweergave, favorieten en een rij met "Recent".
- **Eén klik.** Kies een game, kies het uitvoerbare bestand (als er meerdere zijn), kies hoe lang je deze actief wilt houden en druk op starten. Een aftelring en een melding laten je weten wanneer de tijd om is.
- **Laat niets achter.** Een decoy bestaat alleen zolang deze actief is: het kleine exe-bestand wordt aangemaakt bij het starten en verwijderd bij het stoppen. Alles wordt gestopt wanneer je afsluit, en restanten na een crash worden opgeruimd bij de volgende start.
- **Onopvallend.** Leeft in het systeemvak, zonder vensters of taakbalkknoppen voor de decoys zelf.
- **Open vertalingen.** De interface wordt aangestuurd door eenvoudige JSON-bestanden, dus het toevoegen van een taal is slechts één bestand. Engels en Russisch zijn inbegrepen.
- **Privacygericht.** Geen account, geen Discord-token, geen telemetrie. Zie [Privacy](#privacy).

## Hoe het werkt

1. Discord stelt vast dat je een game speelt door te kijken naar de actieve processen op je pc en hun uitvoerbare bestandsnamen te vergelijken met een openbare lijst (`/api/v9/applications/detectable`).
2. Decoy downloadt die lijst en kopieert voor de gekozen game een klein stand-in-programma (ongeveer 120 KB, geschreven in Rust en ingebed in Decoy) naar een tijdelijke map onder de uitvoerbare bestandsnaam uit de lijst, bijvoorbeeld `.../cod26-cod.exe`.
3. Het stand-in-programma doet niets anders dan een venster op het hoogste niveau bezitten, dat ver buiten het scherm is geplaatst zodat je het nooit ziet. Discord herkent alleen een proces dat een venster heeft; een proces zonder enig venster wordt daarom genegeerd.
4. Binnen ongeveer 15 seconden toont Discord de game als je huidige activiteit.
5. Wanneer de timer afloopt of je op stoppen klikt, beëindigt Decoy het proces en verwijdert het bestand. Een Windows-job-object zorgt ervoor dat decoys samen met Decoy worden afgesloten, zelfs als Decoy crasht.

## Installatie

Kies er een van de [Releases](../../../../releases)-pagina:

| Download | Voor |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installatieprogramma.** Per gebruiker, geen beheerdersrechten vereist, voegt een vermelding toe aan het Startmenu en een verwijderprogramma. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Pak het overal uit en voer `decoy.exe` uit. Alle gegevens blijven in de map `data` ernaast, er wordt niets naar je gebruikersprofiel geschreven. Verwijder de map om het te verwijderen. |

Verifieer een download met `SHA256SUMS.txt` (`Get-FileHash <bestand>` in PowerShell).

Windows SmartScreen kan waarschuwen voor een onbekende uitgever omdat de builds niet digitaal ondertekend zijn; kies *Meer informatie → Toch uitvoeren* als je de build vertrouwt.

Systeemvereisten: Windows 10 of 11 (64-bits) met de WebView2-runtime (reeds inbegrepen in Windows 11 en recente Windows 10-updates).

## Gebruik

1. Open de **Bibliotheek** en zoek naar een game, of druk overal op `Ctrl` + `K`.
2. Klik op een game. Kies in het paneel aan de rechterkant het proces en hoeveel minuten je dit actief wilt houden (Discord-activiteiten vereisen meestal 15 minuten).
3. Klik op **Decoy starten**. Discord toont de game na een paar seconden.
4. Volg het onder **Actief**, stop er op elk moment één of allemaal, of laat Decoy gewoon in het systeemvak staan.

Games waarvan de Discord-vermelding nog geen uitvoerbare bestanden heeft, zijn standaard verborgen (ze kunnen niet worden gedetecteerd). Schakel *Games zonder exe tonen* in om ze te zien; de lijst wordt dagelijks vernieuwd, dus ze worden beschikbaar zodra Discord een proces toevoegt.

### Opdrachtregel

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Start direct een decoy, bijvoorbeeld `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compileren vanuit broncode

Vereisten: [Node.js](https://nodejs.org) 20+, de stabiele [Rust](https://rustup.rs)-toolchain (MSVC-target) met de Visual Studio C++ build tools, en de WebView2-runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Handige controles:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Opmerkingen: het decoy-exe-bestand wordt gecompileerd door `src-tauri/build.rs` met een eenvoudige `rustc` vanuit `src-tauri/stub/stub.rs` en vervolgens ingebed in de app. Wanneer de frontend in een gewone browser draait (`npm run dev`), wordt er een kleine mock-backend (`src/mock.ts`) gebruikt, wat handig is om aan de gebruikersinterface te werken.

## Vertalingen

De interfacestrings staan in [`src/locales`](../../src/locales), één JSON-bestand per taal (`en.json`, `ru.json`, ...).
Het toevoegen van een taal betekent simpelweg het toevoegen van een bestand; er zijn geen codewijzigingen nodig. Zie [docs/TRANSLATING.md](../TRANSLATING.md) voor de bestandsindeling, een kant-en-klare prompt voor machinevertaling en het validatiescript. Vertalingen van deze README komen in `docs/i18n/README.<code>.md`.

## Projectstructuur

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacy

- Decoy gebruikt het netwerk alleen om de openbare detectielijst van Discord te downloaden (bij de eerste start, daarna maximaal eenmaal per dag of wanneer je op vernieuwen drukt) en om gamepictogrammen en artwork van het openbare CDN van Discord weer te geven.
- Het leest, bewaart of verzendt je Discord-token of accountgegevens niet, en communiceert niet met de Discord-client.
- Instellingen (favorieten, taal, tijdsduur) worden lokaal opgeslagen in de WebView-opslag van de app; de cache van de gamelijst en de tijdelijke decoy-bestanden bevinden zich in `%LOCALAPPDATA%\app.decoy.desktop`.
- Geen analyses, geen crashrapporten, geen accounts.

## Bekende beperkingen

- Discord kan op elk moment wijzigen hoe detectie werkt. Als een decoy niet meer wordt herkend, open dan een issue.
- Sommige activiteiten vereisen meer dan alleen een actief proces (bijvoorbeeld het spelen van een specifieke beleving op een gameplatform). Decoy bootst enkel het proces na.
- Vermeldingen zonder uitvoerbare bestanden in de lijst van Discord kunnen niet worden gedetecteerd.
- Beveiligingssoftware markeert soms kleine, niet-ondertekende uitvoerbare bestanden die inactief in het geheugen aanwezig zijn. De decoy is open source en gebouwd vanuit `src-tauri/stub/stub.rs`; je kunt deze zelf compileren.
