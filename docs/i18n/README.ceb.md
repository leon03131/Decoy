# Decoy

**Gagmay nga stand-in nga proseso nga magpahuna-huna sa Discord nga adunay nagdagan nga dula.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Library sa Decoy nga adunay bag-ong mga dula ug artwork" />

</div>

Ang Decoy nagpadagan og dili makadaot nga placeholder nga proseso nga adunay bintana ubos sa ngalan sa executable sa usa ka dula, aron ang game detection sa Discord magtaho nga nagdula ka niana nga dula. Dili nimo kinahanglan nga i-install o sugdan ang tinuod nga dula, busa walay dako nga file nga mokaon sa imong disk space.

Nasayod kini sa **matag dula nga kayang mamatikdan sa Discord** (mga 25,000 ka entry) tungod kay gibasa niini ang kaugalingong publikong listahan sa detection sa Discord ug gipabilin kining lab-as sa iyang kaugalingon.

> [!WARNING]
> Ang pagpalsipikar og nagdagan nga dula mahimong mosupak sa Mga Termino sa Serbisyo sa Discord ug gigamit nimo ang Decoy **sa imong kaugalingong risgo**.
> Kini nga proyekto dili kauban, gipaluyohan, o konektado sa Discord Inc. Tan-awa ang [Disclaimer](#disclaimer).

## Mga Feature

- **Tanan nga kayang mamatikdan sa Discord.** Ang listahan sa mga dula gi-download gikan sa publikong detection endpoint sa Discord, gi-cache sa lokal nga storage, ug gi-refresh adlaw-adlaw. Ang mga bag-ong dula ug bag-ong gidugang nga mga executable awtomatikong motungha.
- **Pangita nga abtik ug dali.** Diha-diha dayon nga pagpangita pinaagi sa ngalan sa dula o executable sa liboan ka mga dula, grid o compact nga listahan, mga paborito ug lumbay sa "Bag-o".
- **Usa ka pag-klik.** Pagpili og dula, pilia ang executable (kung daghan), pilia kung unsa kadugay kini padaganon ug pindota ang start. Usa ka countdown ring ug pahibalo ang mopahibalo kanimo kung nahurot na ang oras.
- **Walay gibilin nga basura.** Ang decoy magpabilin lamang samtang nagdagan kini: ang gamay nga exe himoon inigsugod ug papason inighunong. Ang tanan ihunong inigbiya nimo, ug ang mga salin gikan sa pagka-crash silhigon sa sunod nga pag-abli.
- **Hilom.** Nagpuyo sa system tray, walay mga bintana o taskbar button alang sa mga decoy mismo.
- **Bukas nga mga hubad.** Ang interface gipadagan sa yano nga mga JSON file, busa ang pagdugang og pinulongan usa lamang ka file. Giapil na ang English ug Russian.
- **Pribado.** Walay account, walay Discord token, walay telemetry. Tan-awa ang [Privacy](#privacy).

## Giunsa kini paglihok

1. Modesisyon ang Discord nga nagdula ka pinaagi sa pagsusi sa mga proseso nga nagdagan sa imong PC ug pagtandi sa ilang mga ngalan sa executable ngadto sa usa ka publikong listahan (`/api/v9/applications/detectable`).
2. I-download sa Decoy ang maong listahan ug, alang sa dula nga imong gipili, kopyahon ang gamayng stand-in nga programa (mga 120 KB, gisulat sa Rust ug gi-embed sa Decoy) ngadto sa usa ka temporaryong folder gamit ang ngalan sa executable gikan sa listahan, pananglitan `.../cod26-cod.exe`.
3. Walay laing gibuhat ang stand-in gawas sa paghupot og usa ka top-level window, nga gibutang layo sa gawas sa screen aron dili nimo kini makita. Ang Discord moila lamang sa proseso nga adunay bintana, hinungdan nga ang proseso nga walay bintana hingpit nga ibaliwala.
4. Sulod sa mga 15 segundos ipakita sa Discord ang dula isip imong kasamtangang kalihokan.
5. Inigkahurot sa timer o inigpindot nimo og stop, tapuson sa Decoy ang proseso ug papason ang file. Ang usa ka Windows job object mosiguro nga ang mga decoy mahanaw dungan sa Decoy, bisan pa kon kini mo-crash.

## Pag-install

Pagpili og usa gikan sa panid sa [Releases](../../../../releases):

| Download | Alang sa |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installer.** Alang sa matag user, dili kinahanglan og katungod sa administrador, nagdugang og entry sa Start menu ug uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** I-unzip bisan asa ug padagana ang `decoy.exe`. Ang tanang datos magpabilin sa `data` folder tapad niini, walay isulat sa profile sa imong user. Papasa ang folder aron tangtangon kini. |

I-verify ang gi-download gamit ang `SHA256SUMS.txt` (`Get-FileHash <file>` sa PowerShell).

Ang Windows SmartScreen mahimong mopasidaan bahin sa wala mailhing publisher tungod kay ang mga build dili code signed; pilia ang *More info → Run anyway* kung misalig ka sa build.

Mga Kinahanglanon: Windows 10 o 11 (64-bit) nga adunay WebView2 runtime (naapil na daan sa Windows 11 ug bag-ong mga update sa Windows 10).

## Paggamit

1. Ablihi ang **Library** ug pangitaa ang dula, o pindota ang `Ctrl` + `K` bisan asa.
2. I-klik ang dula. Sa panel sa tuo pilia ang proseso ug pila ka minuto kini padaganon (kasagaran mangayo og 15 ang mga kalihokan sa Discord).
3. Pindota ang **Sugdi ang decoy**. Ipakita sa Discord ang dula human sa pipila ka segundos.
4. Bantayi kini ubos sa **Nagalihok**, ihunong ang usa o tanan bisan unsang orasa, o pasagdi lang ang Decoy sa tray.

Ang mga dula nga ang entry sa Discord wala pay executable gitago pinaagi sa default (dili kini mamatikdan). I-on ang *Ipakita ang mga dula nga walay exe* aron makita kini; gi-refresh ang listahan adlaw-adlaw, busa magamit dayon kini sa higayon nga magdugang ang Discord og proseso.

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Magsugod dayon og decoy, pananglitan `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Pag-build gikan sa source

Mga kinahanglanon: [Node.js](https://nodejs.org) 20+, ang lig-on nga toolchain sa [Rust](https://rustup.rs) (MSVC target) uban sa Visual Studio C++ build tools, ug ang WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # padagana sa development mode nga adunay hot reload
npm run tauri build    # himoa ang installer sa src-tauri/target/release/bundle/nsis
```

Mapuslanong mga pagsusi:

```bash
npm run check-locales  # susiha ang matag translation file batok sa ru.json
npx tsc --noEmit       # susiha ang type sa frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Mga Pahibalo: ang decoy exe gi-compile sa `src-tauri/build.rs` gamit ang ordinaryong `rustc` gikan sa `src-tauri/stub/stub.rs` ug dayon gi-embed sa app. Kung ang frontend nagdagan sa ordinaryong browser (`npm run dev`), usa ka gamayng mock backend (`src/mock.ts`) ang gamiton, nga kombenyente alang sa pagtrabaho sa UI.

## Mga Hubad

Ang mga UI string anaa sa [`src/locales`](../../src/locales), usa ka JSON file matag pinulongan (`en.json`, `ru.json`, ...). Ang pagdugang og pinulongan nagpasabot og pagdugang og usa ka file; walay usbon sa code. Tan-awa ang [docs/TRANSLATING.md](../TRANSLATING.md) alang sa format sa file, usa ka andam-gamiton nga prompt alang sa machine translation ug ang validation script. Ang mga hubad niini nga README moadto sa `docs/i18n/README.<code>.md`.

## Layout sa proyekto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              mga translation file (usa ka JSON matag pinulongan)
  i18n-core.ts          pagkarga ug pagpangita sa pinulongan
  store.ts              kahimtang sa aplikasyon (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            database sa dula, mga proseso sa decoy, tray
  stub/stub.rs          ang stand-in nga programa nga gi-embed
scripts/                mga tabang nga script (pag-validate sa locale)
docs/                   giya sa paghubad, mga screenshot
```

## Privacy

- Ang Decoy naggamit lamang sa network sa pag-download sa publikong listahan sa detection sa Discord (sa unang pag-abli, unya labing daghan kausa sa usa ka adlaw o inigpindot nimo og refresh) ug, alang sa pagpakita, mga icon sa dula ug artwork gikan sa publikong CDN sa Discord.
- Wala kini nagbasa, nagtipig, o nagpadala sa imong Discord token o bisan unsang datos sa account, ug wala kini nakigsulti sa Discord client.
- Ang mga setting (mga paborito, pinulongan, mga gidugayon) lokal nga gitipigan sa WebView storage sa app; ang cache sa listahan sa dula ug temporaryong mga decoy file anaa sa `%LOCALAPPDATA%\app.decoy.desktop`.
- Walay analytics, walay crash reporting, walay mga account.

## Nailhang mga limitasyon

- Mahimong usbon sa Discord kung giunsa paglihok ang detection bisan unsang orasa. Kung ang usa ka decoy mohunong sa pagka-ila, palihug pag-abli og issue.
- Ang pipila ka kalihokan nagkinahanglan og labaw pa sa nagdagan nga proseso (pananglitan ang pagkaanaa sulod sa partikular nga kasinatian sa usa ka plataporma sa dula). Ang Decoy mo-kopya lamang sa proseso.
- Ang mga entry nga walay executable sa listahan sa Discord dili mamatikdan.
- Ang software sa seguridad usahay magtimaan sa gagmayng dili pinirmahan nga mga executable nga naglingkod sa memorya. Ang decoy kay open source ug gitukod gikan sa `src-tauri/stub/stub.rs`; mahimo nimo kining i-compile sa imong kaugalingon.
