# Decoy

**Cikne zástupno procesură so keren o Discord te gănol kaj jekh khelipen phravdol.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy biblioteka neve khelematěnca thaj grafika" />

</div>

Decoy garavel jekh bi-došalo, feliastrasa proceso telal o anav le khelipaske exe dokumentosko, kadǎ sar o Discordesko dikhipe mothovel kaj tu kheles kodo khelipen. Tu na trubus te instaliris vaj te phićares o čačo khelipen, thaj khańik bari na bešel pe ćiro disko.

Džanel pala **sako khelipen so o Discord šaj te arakhel** (pašal 25 000 arakhimata), sosqe ginel le Discordeski publikani lista thaj nevočharel la korkoro sako dives.

> [!WARNING]
> Te mukhes jekh zástupno khelipen šaj si kontra le Discordeske Regulură (Terms of Service) thaj tu utilizis Decoy **pe ćiro riziko**.
> Kado projekto na-i phandlo, ažutime vaj aprovirime katar Discord Inc. Dikh [Disclaimer](#disclaimer).

## Funkcije

- **Savoro so Discord šaj te dikhel.** E khelematengi lista si telal lidžandi katar Discordesko publikano detection endpoint, garavdi lokalo thaj nevočhardi sako dives. Neve khelematǎ thaj neve exe dokumentură arakhen-pe korkore.
- **Rodi bari thaj sigo.** Sigo rodi pala anav le khelipasko vaj exe maškar miile khelematǎ, grid vaj tikni lista, preferirime thaj jekh riga “Akanutne”.
- **Jekh klisardipe.** Alosar jekh khelipen, alosar o exe (te si buter), alosar sode vrama te del thaj de start. Jekh angrušti ginipnaski thaj jekh notifikacija phenen tuqe kana e vrama nakhli.
- **Na mukhel khańik palal.** Jekh decoy avel numaj kana butǎrel: o cikno exe dokumento si kerdo kana startis thaj khoslo kana aćhaves. Savoro si aćhavdo kana iklǒves, thaj o čik so aćhilo te perelas si khoslo pe kaver phravdipe.
- **Ćhutičho.** Bešel ando tray le sistemosko, nane feliastre vaj butoane pe taskbar vaš le decoy-ură korkore.
- **Puterde translatuată.** E interfața butǎrel pe semno JSON dokumentură, agor te thoves jekh čhib si numaj jekh dokumento. Anglezi thaj Rusi čhibă si ande kado.
- **Privato.** Bi-kontosko, bi-Discord tokenosko, bi-telemetriako. Dikh [Privatnost](#privatnost).

## Sar butǎrel

1. Discord decidisarel kaj tu kheles jekh khelipen dikhindoj le procesură so butǎren pe ćiro PC thaj komparisarindoj lenge exe anava e publikane listasa (`/api/v9/applications/detectable`).
2. Decoy lidžal kadaja lista thaj, vaš o alosardo khelipen, kopirisarel jekh cikno programo (pašal 120 KB, ramosardo ando Rust thaj ande thovdo ando Decoy) ande jekh temporaro mapa le exe anavasa andar e lista, sar egzemplo `.../cod26-cod.exe`.
3. O cikno programo kerel numaj jekh feliastra pe opreutno nivo, dur pe ekrano te na dikhes la nikana. Discord prinžarel numaj le procesură so si len feliastra, pala kado jekh proceso bi-feliastrako aćhel bi-dikhlo.
4. Ande pašal 15 sekunde o Discord sikavel o khelipen sar ćiri akanutni aktivita.
5. Kana o timero nakhel vaj tu des aćhav, Decoy phandavel o proceso thaj khosel o dokumento. Jekh Windows job object siguril kaj le decoy-ură meren khetane le Decoy-osa, vi te perel o programo.

## Instaliripe

Alosar jekh katar e rig [Releases](../../../../releases):

| Telal lidžipe | Vaš |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalatoro.** Vaš jekh jeno, bi-administratoroske dromosko, thovel jekh than ando Start menu thaj jekh uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Phrav kothe-godĭ thaj phaćar `decoy.exe`. Sā le date aćhen andi mapa `data` pašal leste, khańik na ramosardola ande ćiro profili. Khos e mapa te bistres les. |

Kontrolisar o telal lidžipe le dokumentosa `SHA256SUMS.txt` (`Get-FileHash <file>` ando PowerShell).

Windows SmartScreen šaj te del avertisaripe pala jekh bi-prinžardo ramosarno sosqe le build-ură nane semnosarde; alosar *More info → Run anyway* te patyas ando build.

Trubul: Windows 10 vaj 11 (64-bit) le WebView2 runtime (avel vi ando Windows 11 thaj akanutne Windows 10 aktualizacije).

## Utilizaripe

1. Phrav **Biblioteka** thaj rode jekh khelipen, vaj de `Ctrl` + `K` katar godĭ.
2. Klisar pe jekh khelipen. Andi tabla pe čaći rig alosar o proceso thaj kecika minutură te aćhel (Discord misionură trubun 15).
3. De **Phaćar decoy**. Discord mothovela o khelipen palal vash cikne sekunde.
4. Dikh les telal **Phaćardo**, aćhav jekh vaj savorren sako vrama, vaj mukh Decoy ando tray.

Khelematǎ kaste le Discordesko arakhipe na-i len exe dokumentură si garavde (našti oven prinžarde). Phrav *Sikav khelematǎ bi-exe* te dikhes len; e lista si nevočhardi sako dives, aver drom arakhen-pe kana Discord thovela procesură.

### Komandaki linija

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Phaćarel jekh decoy strašta, sar egzemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Vazde andar o surso

So trubul: [Node.js](https://nodejs.org) 20+, stabilno [Rust](https://rustup.rs) toolchain (MSVC target) Visual Studio C++ bućǎrnge instrumenturenca, thaj WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Laćhe kontrole:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Noti: o decoy exe si kompilirime katar `src-tauri/build.rs` le plain `rustc` andar `src-tauri/stub/stub.rs` thaj thovdo andi aplikacija. Kana o frontend butǎrel ando bi-bari browser (`npm run dev`) jekh cikno mock backend (`src/mock.ts`) butǎrel, so si laćho kana keres buti pe UI.

## Translatuată

Le UI lafa aćhen ande [`src/locales`](../../src/locales), jekh JSON dokumento sako čhibăqe (`en.json`, `ru.json`, ...).
Te thoves jekh čhib zveris numaj te thoves jekh dokumento; bi-kodurěnqo paruvipen. Dikh [docs/TRANSLATING.md](../TRANSLATING.md) te dikhes le dokumentosko formati, jekh prompt vaš e mašina thaj o kontrolako skripto. Translatuată kadale README dokumentosqe džan ande `docs/i18n/README.<code>.md`.

## Privatnost

- Decoy utilizil e rećeaua numaj te lidžal le Discordeski publikani detection lista (pe jekhto phravdipe, aver drom jekh data pe dives vaj kana des refresh) thaj, vaš dikhipe, ikone thaj grafika andar o publikano CDN le Discordesko.
- Na ginel, na garavel thaj na bićhalel ćiro Discord token vaj kontoske date, thaj na vakerel le Discord aplikacijasa.
- Ajusturură (preferirime, čhib, duracije) si garavde lokalo ando WebView le aplikacijako; le khelematengi lista thaj le temporare decoy dokumentură bešen ande `%LOCALAPPDATA%\app.decoy.desktop`.
- Khańik analitika, khańik crash reporting, bi-kontonge.

## Prinžarde limiturǎ

- Discord šaj paruvel sar rodel sako vrama. Te jekh decoy na-i maj dikhlo, molisares phrav jekh issue.
- Vare-save aktivitietură trubun maj but sar jekh phravdo proceso (sar egzemplo te aves ande jekh khelipen pe platforma). Decoy kerel numaj sar o proceso.
- Arakhimata bi-exe dokumenturenge ande Discordeski lista našti oven prinžarde.
- Sekuritatoske programură vov-vov keren problemi pe cikne bi-semnosarde exe dokumentură so bešen andi memorija. O decoy si open source thaj kerdo andar `src-tauri/stub/stub.rs`; šaj kompiliris les korkoro.
