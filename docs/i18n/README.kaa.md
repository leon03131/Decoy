# Decoy

**Discord oyın islep tur dep oylawı ushın kishi orınbasar procesler.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Aqırǵı oyınlar hám posterleri bar Decoy kitapxanası" />

</div>

Decoy oyınnıń orınlanatuǵın (exe) faylı atı astında zıyansız, aynalı orınbasar processtiń islep turıwın támiyinleydi, sol sebepli Discord oyındı anıqlaw sisteması sizdi sol oyındı oynap atırǵan etip kórsetedi. Haqıyqıy oyındı ornatıw yamasa iske túsiriw ulıwma shárt emes, sol sebepli diskińizde úlken fayllar orın almaydı.

Ol **Discord anıqlay alatuǵın barlıq oyınlardı** (shama menen 25 000 jazıw) biledi, sebebi ol Discordtıń óziniń ashıq anıqlaw dizimin oqıydı hám onı óz-ózinen jańalap baradı.

> [!WARNING]
> Oyınnıń islep turǵanın jasama kórsetiw Discordtıń Xızmet kórsetiw shártlerine qarsı keliwi múmkin hám siz Decoydı **óz táwekeleńizge qaray** paydalanasız.
> Bul joybar Discord Inc. penen baylanıslı emes, olar tárepinen tastıyıqlanbaǵan yamasa qollap-quwatlanbaydı. [Juwapkershilikten bas tartıw](#juwapkershilikten-bas-tartıw) bólimin qarań.

## Ózgeshelikleri

- **Discord anıqlay alatuǵın hámme nárse.** Oyınlar dizimi Discordtıń ashıq anıqlaw manzilinen júklep alınadı, jergilikli keshlenedi hám kún sayın jańalanadı. Jańa oyınlar hám jańadan qosılǵan orınlanatuǵın fayllar óz-ózinen payda boladı.
- **Keshikpeytuǵın tez izlew.** Mıńlaǵan oyınlar arasında oyın atı yamasa orınlanatuǵın faylı boyınsha tez izlew, kataklı yamasa ıqsham dizim kórinisi, saylandılar hám «Aqırǵılar» qatarı.
- **Bir basıw.** Oyındı tańlań, (eger birneshew bolsa) orınlanatuǵın fayldı tańlań, qansha waqıt uslap turıwdı belgileń hám iske túsiriwdi basıń. Keri sanaw sheńberi hám bildiriwnama waqıt tawısılǵanın xabarlaydı.
- **Hesh qanday iz qaldırmaydı.** Decoy tek islep turǵan waqtında ǵana boladı: kishi exe iske túsirilgende jaratıladı hám toqtatılǵanda óshiriledi. Qosımshadan shıqqanıńızda hámme nárse toqtatıladı, al qáteliklerden qalǵan qaldıqlar keyingi iske túsiriwde tazalanadı.
- **Tınısh.** Tizim treyinde isleydi, decoylar ushın hesh qanday ayna yamasa tapsırmalar panelinde túyme bolmaydı.
- **Ashıq awdarmalar.** Interfeys ápiwayı JSON faylları tiykarında isleydi, sol sebepli til qosıw tek bir fayldan ibarat. Inglis hám orıs tilleri kiritilgen.
- **Qupıyalıq.** Esap jazıwı, Discord tokeni hám telemetriya joq. [Qupıyalıq](#qupıyalıq) bólimin qarań.

## Qalay isleydi

1. Discord sizdiń kompyuterińizde islep turǵan proceslerdi qarap hám olardıń orınlanatuǵın fayl atamaların ashıq dizim menen (`/api/v9/applications/detectable`) salıstırıw arqalı oyın oynap atırǵanıńızdı anıqlaydı.
2. Decoy bul dizimdi júklep aladı hám siz tańlaǵan oyın ushın dizimdegi orınlanatuǵın fayl atın paydalanıp (mısalı, `.../cod26-cod.exe`), waqıtsha papkaǵa kishi orınbasar baǵdarlamanı (shama menen 120 KB, Rust tilinde jazılǵan hám Decoy ishine kirgizilgen) kóshiredi.
3. Orınbasar baǵdarlama siz hesh qashan kórmeytuǵınday etip ekrannan sırtta alıs jaylasqan jalǵız joqarı dárejeli aynaǵa iye bolıwdan basqa hesh nárse islemeydi. Discord tek aynası bar processti ǵana tán aladı, sol sebepli pútkilley aynasız procesler esapqa alınbaydı.
4. Shama menen 15 sekund ishinde Discord oyındı sizdiń házirgi belsendiligińiz retinde kórsetedi.
5. Taymer tamamlanǵanda yamasa toqtatıwdı basqanıńızda, Decoy processti toqtatadı hám fayldı óshiredi. Windows job obyekti Decoy hátte qáteshe jabılıp qalsa da, decoylardıń Decoy menen birge toqtatılıwın támiyinleydi.

## Ornatıw

[Releases](../../../../releases) betinen birewin tańlań:

| Júklep alıw | Maqseti |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Ornatqısh.** Hár bir paydalanıwshı ushın, administrator huqıqları talap etilmeydi, «Baslaw» (Start) menyusına jazıw hám óshirgishti qosadı. |
| `Decoy_x.y.z_x64-portable.zip` | **Portativ.** Qálegen jerge arxivten shıǵarıp alıń hám `decoy.exe` faylın iske túsiriń. Barlıq maǵlıwmatlar qasındagı `data` papkasında qaladı, paydalanıwshı profiline hesh nárse jazılmaydı. Qosımshanı óshiriw ushın papkanı óshiriń. |

Júklep alınǵan fayldı `SHA256SUMS.txt` arqalı tekseriń (PowerShell ishinde `Get-FileHash <fayl>`).

Windows SmartScreen qurılmalar sanlı qol qoyılmaǵanlıǵı sebepli belgisiz baspadurıwshı haqqında eskertiwi múmkin; eger qurılmaǵa isenseńiz, *Tolıǵıraq (More info) → Bári-bir iske túsiriw (Run anyway)* variantın tańlań.

Talaplar: WebView2 runtime bar Windows 10 yamasa 11 (64-bit) (Windows 11 hám jaqındaǵı Windows 10 jańalanıwlarına aldın-ala kiritilgen).

## Paydalanıw

1. **Kitapxana**nı ashıń hám oyındı izleń yamasa qálegen jerden `Ctrl` + `K` túymelerin basıń.
2. Oyındı basıń. Oń táreptegi panelde processti hám onı qansha minut uslap turıwdı tańlań (Discord belsendilikleri ádette 15 minut talap etedi).
3. **Decoydı iske túsiriw** túymesin basıń. Discord birneshe sekundtan keyin oyındı kórsetedi.
4. Onı **Islep atırǵanlar** bóliminde baqlap barıń, qálegen waqıtta birewin yamasa barlıǵın toqtatıń, yamasa Decoydı treyde qaldırıń.

Discord jazıwında ele orınlanatuǵın faylları joq oyınlar baslanǵı jaǵdayda jasırılǵan (olar anıqlanbaydı). Olardı kóriw ushın *exe faylı joq oyınlardı kórsetiw* opsiyasın qosıń; dizim kún sayın jańalanıp baradı, sol sebepli Discord processti qosıwı menen olar qoljetimli boladı.

### Buyrıqlar qatarı

```
decoy.exe --launch "<Discord dizimindegi orınlanatuǵın fayl jolı>" [minut]
```

Decoydı dárriw iske túsiredi, mısalı `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Dáslepki kodtan jıynaw

Talaplar: [Node.js](https://nodejs.org) 20+, Visual Studio C++ jıynaw ásbapları bar turaqlı [Rust](https://rustup.rs) ásbaplar jıynaǵı (MSVC target) hám WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # rawajlandırıw rejiminde hot reload penen iske túsiriw
npm run tauri build    # src-tauri/target/release/bundle/nsis ishinde ornatqıshtı tayarlaw
```

Paydalı tekseriwler:

```bash
npm run check-locales  # hár bir awdarma faylın ru.json boyınsha tekseriw
npx tsc --noEmit       # frontend tiplerin tekseriw
cargo check --manifest-path src-tauri/Cargo.toml
```

Esletpeler: decoy exe faylı `src-tauri/build.rs` arqalı `src-tauri/stub/stub.rs` kodınan ápiwayı `rustc` kómeginde kompilyaciya qılınadı hám qosımsha ishine kirgiziledi. Frontend ápiwayı brauzerde iske túsirilgende (`npm run dev`), kishi jasama backend (`src/mock.ts`) qollanıladı, bul paydalanıwshı interfeysi ústinde islew ushın qolaylı.

## Awdarmalar

Paydalanıwshı interfeysi tekstleri [`src/locales`](../../src/locales) ishinde, hár bir til ushın bir JSON faylda saqlanadı (`en.json`, `ru.json`, ...). Til qosıw — jańa fayl qosıwdı ańlatadı; kodtı ózgertiw talap etilmeydi. Fayl formatı, mashinalıq awdarma ushın tayar soraw (prompt) hám tekseriw skripti ushın [docs/TRANSLATING.md](../TRANSLATING.md) faylına qarań. Usı README faylınıń awdarmaları `docs/i18n/README.<code>.md` ishine jaylastırıladı.

## Joybar dúzilisi

```
src/                    React + TypeScript frontend
  components/           Kitapxana, tolıq maǵlıwmat paneli, sazlawlar, ...
  locales/              awdarma faylları (hár bir tilge bir JSON)
  i18n-core.ts          tildi júklew hám tabıw
  store.ts              qosımsha jaǵdayı (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            oyınlar bazası, decoy procesleri, trey
  stub/stub.rs          kirgiziletuǵın orınbasar baǵdarlama
scripts/                járdemshi skriptler (lokallardı tekseriw)
docs/                   awdarma qollanbası, skrinshotlar
```

## Qupıyalıq

- Decoy tarmaqtan tek Discordtıń ashıq anıqlaw dizimin júklep alıw (birinshi iske túsirgende, soń kúnine kóbinese bir márte yamasa jańalaw túymesin basqanıńızda) hám interfeyste kórsetiw ushın Discordtıń ashıq CDN-inen oyın belsgileri menen súwretlerin alıw ushın paydalanadı.
- Ol sizdiń Discord tokenińizdi yamasa qanday da bir esap jazıwı maǵlıwmatlarıńızdı oqımaydı, saqlamaydı hám jibermeydi, sonday-aq Discord klientı menen baylanıspaydı.
- Sazlawlar (saylandılar, til, múddetler) qosımshanıń WebView yadında jergilikli saqlanadı; oyınlar dizimi keshi hám waqıtsha decoy faylları `%LOCALAPPDATA%\app.decoy.desktop` ishinde jaylasadı.
- Analitika, apatlıq esabatlar hám esap jazıwları joq.

## Belgili sheklewler

- Discord oyınlardı anıqlaw tártibin qálegen waqıtta ózgertiwi múmkin. Eger decoy anıqlanbay qalsa, iltimas, másáleni (issue) ashıń.
- Ayırım belsendilikler ápiwayı islep turǵan processten de kóbirek nárselerdi talap etedi (mısalı, oyın platformasınıń arnawlı oyın maydanında bolıw). Decoy tek processti ǵana tuwraydı.
- Discord diziminde orınlanatuǵın faylları bolmaǵan jazıwlar anıqlanbaydı.
- Qáwipsizlik baǵdarlamaları yadta bos turǵan qol qoyılmaǵan kishi orınlanatuǵın fayllardı geyde gúmanlı dep belgilewi múmkin. Decoy ashıq dáslepki kodqa iye hám `src-tauri/stub/stub.rs` arqalı jıynalǵan; onı ózińiz de kompilyaciya qıla alasız.

## Úles qosıw

Qáteler haqqındaǵı esabatlar, jańa pikirler hám awdarmalar quwanısh penen qabıl etiledi. Iltimas, aldın [CONTRIBUTING.md](../../CONTRIBUTING.md) qollanbasın oqıp shıǵıń.

## Juwapkershilikten bas tartıw

Decoy jeke, bilimlendiriw hám testlew maqsetlerinde «bar bolǵanınday» usınıladı. Islep turǵan oyındı jasama tuwraw Discordtıń yamasa oyın baspadurıwshısınıń Xızmet kórsetiw shártlerin buzıwı múmkin hám esap jazıwıńızǵa qarsı sharalar qollanıwına alıp keliwi múmkin. Onı qalay paydalanıwıńız ushın tek ózińiz juwapkersiz. «Discord» hám barlıq oyın atamaları menen logotipleri tiyisli iyeleriniń sawda belgileri bolıp tabıladı hám bul jerde tek kórsetilgen baǵdarlamalıq támiyinattı anıqlaw maqsetinde qollanılǵan.
