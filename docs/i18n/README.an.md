# Decoy

**Pequens procesos substitutos que fan creyer a Discord que un chuego ye en execución.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Biblioteca de Decoy con chuegos recients y ilustracions" />

</div>

Decoy mantiene en execución un proceso substituto inofensivo con finestra baixo lo nombre de l'executable d'un chuego, de traza que la detección de chuegos de Discord indica que yes chugando a ixe chuego. Nunca no cal instalar ni enchegar o chuego real, por lo que garra cosa pesada no ocupa espacio en o tuyo disco.

Conoixe **totz os chuegos que Discord puede detectar** (arredol de 25.000 entradas) perque leye la propia lista publica de detección de Discord y la mantiene actualizada por él mesmo.

> [!WARNING]
> Simular a execución d'un chuego puede ir contra os Termins de Servicio de Discord y fas servir Decoy **baixo lo tuyo propio risgo**.
> Iste prochecto no ye pas afiliau, emparau ni vinculau a Discord Inc. Consulta o [Descargo de responsabilidat](#descargo-de-responsabilidat).

## Caracteristicas

- **Tot o que Discord puede detectar.** La lista de chuegos se descarga dende o punto final publico de detección de Discord, s'almagazena en a memoria caché localment y s'actualiza cada día. Os nuevos chuegos y executables adhibius fa poco amaneixen solos.
- **Búsqueda que sigue o ritmo.** Búsqueda instantania por nombre de chuego u executable entre mils de chuegos, vista en mosaico u lista compacta, favoritos y una ringlera de «Recients».
- **Un solo clic.** Triga un chuego, triga l'executable (si en i hai quantos), triga quantos menutos mantener-lo y preta prencipiar. Un aniello de cuenta enrere y una notificación t'avisan quan o tiempo s'ha rematau.
- **No dixa garra rastro.** Un decoy nomás existe entre que s'executa: o chicot exe se creya en prencipiar y s'elimina en aturar. Tot s'atura quan sales, y as restas dimpués d'una cayida inesperada se neteyan en o siguient inicio.
- **Discreto.** Vive en a servilla d'o sistema, sin finestras ni botons en a barra de fayenas ta os propios decoys.
- **Traduccions ubiertas.** La interficie funciona con fichers JSON sencillos, por lo que adhibir un idioma ye qüestión d'un solo fichero. S'incluyen anglés y ruso.
- **Privau.** Sin cuenta, sin token de Discord, sin telemetría. Consulta [Privacidat](#privacidat).

## Cómo funciona

1. Discord decide que yes chugando a un chuego mirando os procesos que s'executan en o tuyo PC y comparando os suyos nombres d'executable con una lista publica (`/api/v9/applications/detectable`).
2. Decoy descarga ixa lista y, ta o chuego que trigues, copia un chicot programa substituto (d'uns 120 KB, escrito en Rust y incrustau en Decoy) enta una carpeta temporal fendo servir o nombre d'executable d'a lista, por eixemplo `.../cod26-cod.exe`.
3. O substituto no fa garra cosa fueras d'aguantar una finestra de libel superior, situada luent fuera d'a pantalla ta que nunca no la veigas. Discord nomás reconoixe un proceso que tienga finestra, razón por la quala un proceso totalment sin finestra ye ignorau.
4. En arredol de 15 segundos, Discord amuestra o chuego como la tuya actividat actual.
5. Quan o temporizador remata u pretas aturar, Decoy remata o proceso y elimina o fichero. Un obchecto de treballo de Windows (job object) s'asegura que os decoys mueran chunto con Decoy, mesmo si se zarra inesperadament.

## Instalación

Triga un dende a pachina de [Releases](../../../../releases):

| Descarga | Ta |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Instalador.** Por usuario, sin necesidat de permisos d'administrador, adhibe una dentrada a o menú Inicio y un desinstalador. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Descomprime en qualsequier puesto y executa `decoy.exe`. Totz os datos se quedan en a carpeta `data` d'o costau, no s'escribe nada en o tuyo perfil d'usuario. Elimina la carpeta ta borrar-lo. |

Verifica una descarga con `SHA256SUMS.txt` (`Get-FileHash <file>` en PowerShell).

Windows SmartScreen puede alvertir sobre un editor no reconoixiu perque as compilacions no son sinyadas con codigo; triga *Mas información → Executar de todas trazas* si confías en a compilación.

Requisitos: Windows 10 u 11 (64 bits) con o tiempo d'execución WebView2 (ya incluiu en Windows 11 y en actualizacions recients de Windows 10).

## Emplego

1. Ubre a **Biblioteca** y busca un chuego, u preta `Ctrl` + `K` dende qualsequier puesto.
2. Fai clic en un chuego. En o panel d'a dreita, triga o proceso y quantos menutos mantener-lo (as actividatz de Discord gosan pedir-ne 15).
3. Preta **Prencipiar decoy**. Discord amostrará o chuego dimpués d'uns pocos segundos.
4. Mira-lo en **En execución**, atura-ne un u totz en qualsequier momento, u simplament dixa Decoy en a servilla.

Os chuegos que en a lista de Discord encara no tiengan executables son amagaus por defecto (no se pueden detectar). Activa *Amostrar chuegos sin exe* ta veyer-los; la lista s'actualiza cada día, por o que serán disponibles malas que Discord adhiba un proceso.

### Linia d'ordres

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Prencipia un decoy a l'inte, por eixemplo `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Compilación dende a fuent

Requisitos previos: [Node.js](https://nodejs.org) 20+, o conchunto d'ferramientas estable de [Rust](https://rustup.rs) (obchectivo MSVC) con as ferramientas de compilación de Visual Studio C++, y o tiempo d'execución WebView2.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Comprobacions útils:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notas: l'exe d'o decoy ye compilau por `src-tauri/build.rs` con `rustc` directo a partir de `src-tauri/stub/stub.rs` y dimpués s'incrusta en l'aplicación. Quan o frontend s'executa en un navegador normal (`npm run dev`), se fa servir un chicot backend simulau (`src/mock.ts`), o que resulta comodo ta treballar en a interficie d'usuario.

## Traduccions

As cadenas d'a interficie d'usuario se troban en [`src/locales`](../../src/locales), un fichero JSON por idioma (`en.json`, `ru.json`, ...). Adhibir un idioma significa adhibir un fichero; sin cambeos en o codigo. Consulta [docs/TRANSLATING.md](../TRANSLATING.md) ta conoixer o formato d'o fichero, una plantilla d'indicacions presta ta traducción automatica y o script de validación. As traduccions d'iste README van a `docs/i18n/README.<code>.md`.

## Estructura d'o prochecto

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Privacidat

- Decoy nomás fa servir a rete ta descargar a lista publica de detección de Discord (en o primer inicio, y dimpués como maximo un golpe a lo día u quan pretas actualizar) y, ta la visualización, os iconos y ilustracions d'os chuegos dende a CDN publica de Discord.
- No leye, no almagazena ni ninvía o tuyo token de Discord ni garra dato d'a cuenta, y no se comunica con o client de Discord.
- Os achustes (favoritos, idioma, duradas) s'almagazenan localment en l'almagazenamiento WebView de l'aplicación; la memoria caché d'a lista de chuegos y os fichers temporals de decoy residen en `%LOCALAPPDATA%\app.decoy.desktop`.
- Sin analiticas, sin informes de fallos y sin cuentas.

## Limitacions conoixidas

- Discord puede cambiar o funcionamiento d'a detección en qualsequier momento. Si un decoy deixa d'estar reconoixiu, por favor ubre una incidencia.
- Bels tipos d'actividatz precisan mas que un proceso en execución (por eixemplo estar adintro d'una experiencia concreta d'una plataforma de chuegos). Decoy nomás imita o proceso.
- As dentradas sin executables en a lista de Discord no se pueden detectar.
- O software de seguranza a vegadas sinyala chicotz executables no sinyaus que remanen inactivos en a memoria. O decoy ye de codigo ubierto y ye construiu a partir de `src-tauri/stub/stub.rs`; puez compilar-lo tu mesmo.
