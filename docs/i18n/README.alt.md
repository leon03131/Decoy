# Decoy

**Discord-ко ойын иштеп турганын кӧргӱзер кичинек stand-in процесстер.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Јууктагы ойындар ла обложкаларлу Decoy библиотеказы" />

</div>

Decoy ойынныҥ бӱдӱрер файлыныҥ адыла терезелӱ, каршу јок stand-in процессти иштедип турат, оныҥ учун Discord-тыҥ ойын тапкыш системазы слерди ол ойынды ойноп јат деп кӧргӱзет. Тӧс ойынды бойын тургузар эмезе иштедер кереги јок, дискигерде канай да улу бичиктер артып калбайт.

Ол **Discord таап болор бастыра ойындарды** билет (25 000-ге шыку бичимел), не дезе ол Discord-тыҥ бойыныҥ ачык бедиреш списогын кычырып, бойы ла јаҥыртып турат.

> [!WARNING]
> Ойын иштеп турганын тӱҥейлеп јазаары Discord-тыҥ Тузаланыш ээжилерине келишпес болор аргалу,Decoy-ны **бойыгар каруулу болуп** тузаланараар.
> Бу проект Discord Inc. компанияла тудуш эмес, олорло јӧптӧлбӧгӧн лӧ олорго кандый да колбузы јок. [Каруукерликтенеҥ мойножоры](#каруукерликтенеҥ-мойножоры) деген бӧлӱкти кӧрӱгер.

## Јайалталары

- **Discord таап болор бастыра неме.** Ойындардыҥ списогы Discord-тыҥ ачык сервериндеҥ јӱктелет, јерлик кэште чектелет ле кӱн сайын јаҥыртылат. Јаҥы ойындар ла јаҥынаҥ кожылган бӱдӱрер файлдар бойлоры ла табылат.
- **Тӱрген бедиреш.** Муҥдар тоолу ойындардыҥ аразынаҥ ойынныҥ адыла эмезе бӱдӱрер файлыла кӧс ачып-жумгынча бедиреш, плиткала эмезе тудум списокло кӧргӱзери, талдалгандар ла «Јууктагылар» деген строка.
- **Бир ле базыш.** Ойынды талдагар, бӱдӱрер файлды талдагар (бир канча болзо), канча минут кармаарын кӧргӱзигер ле баштаар кнопканы базигер. Айландыра тоолош ло јетирӱ ӧй тӱгенгенин билдирер.
- **Ызырын калдырбайт.** Decoy иштеп турганча ла бар: кичинек exe баштаарда јазалат ла токтодордо јоголтылат. Колдонмонаҥ чыгарда бастыразы токтодолот, а сбой кийнинде арткан калдыктары келер башташта аруталат.
- **Тынч.** Систем трейде турат, decoy процесстердиҥ бойлорыныҥ терезелери эмезе задачалардыҥ панелинде кнопкалары јок.
- **Ачык кӧчӱрмелер.** Интерфейс жӧнӧкӧй JSON файлдарла иштейт, оныҥ учун јаҥы тил кожоры — ол бир ле файл. Англий ле орус тилдер кийдирилген.
- **Конфиденциальность.** Аккаунт јок, Discord токен јок, телеметрия јок. [Конфиденциальность](#конфиденциальность) деген бӧлӱкти кӧрӱгер.

## Канайып иштейт

1. Discord компьютеригерде иштеп турган процесстерди кӧрӱп, олордыҥ бӱдӱрер файлдарыныҥ адын ачык списокла (`/api/v9/applications/detectable`) тӱҥейлеп, ойын ойноп турганыгарды ајарат.
2. Decoy бу списокты јӱктеп алып, талдаган ойынныҥ бӱдӱрер файлыныҥ адын тузаланып (темдектезе, `.../cod26-cod.exe`), убактылу папкага кичинек stand-in программаны (120 КБ кире, Rust тилле бичилген ле Decoy ичине кийдирилген) кӧчӱрет.
3. Stand-in программа экраннаҥ ыраак јажыртылган бир ле ӱстӱги терезези бар болуп калганынаҥ башка нени де этпейт. Discord терезелӱ ле процессти таныыр, толо терезези јок процесске ајару этпейт.
4. 15 секунд киренеҥ Discord бу ойынды слердиҥ эмдиги ӧйдӧги ижигер деп кӧргӱзип ийет.
5. Таймер тӱгензе эмезе токтодорго бассагар, Decoy процессти токтодып, файлды јоголтып ийер. Windows-тыҥ job объекти Decoy сбойло јабылза да, decoy-лордыҥ Decoy-ло кожо токтодорын јеткилдейт.

## Орноторы

[Releases](../../../../releases) бӱгинеҥ талдап алыгар:

| Јӱктеер файл | Неге келижер |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Инсталлер.** Кажы ла тузалаачыга, администратордыҥ јарадузы керексис, «Баштаар» (Start) менюге бичимел ле јоголтотон программа кошот. |
| `Decoy_x.y.z_x64-portable.zip` | **Портатив.** Кайда да чыгарып алала, `decoy.exe` иштедигер. Бастыра бичиктер јанындагы `data` папкада чектелет, тузалаачыныҥ профилине не де бичилбейт. Јоголторго папканы согуп ийзе једер. |

Јӱктеген файлды `SHA256SUMS.txt` бичимелле чектеп кӧрӱгер (PowerShell ичинде `Get-FileHash <файл>`).

Windows SmartScreen программалардыҥ цифралык колы јок болгоныла јарлу эмес бичиктер деп сактандырар аргалу; эгер бу сборкага бӱдӱп турзагар, *Толо маалымат (More info) → Не де болзо иштедер (Run anyway)* деп талдагар.

Некелтелер: WebView2 runtime бар Windows 10 эмезе 11 (64-бит) (Windows 11 ле соҥгы Windows 10 јаҥыртылгандарында бар).

## Тузаланары

1. **Библиотеканы** ачып, ойынды бедирегер эмезе кайкаҥ да болзо `Ctrl` + `K` базигер.
2. Ойынга базыгар. Оҥ јандагы панельде процессти ле оны канча минут кармаарын талдагар (Discord молжолдорына кӧп сабада 15 минут керек).
3. **Decoy иштедер** деп базигер. Discord бир канча секундтаҥ ойынды кӧргӱзип баштаар.
4. Оны **Иштеп тургандар** деген јердеҥ кӧрӱгер, кайда да бирӱзин эмезе бастыразын токтодорго јараар, эмезе Decoy-ны трейде артыргызыгар.

Discord списогында бӱдӱрер файлдары јок ойындар баштапкыда јажырылган (олор табылбайт). Олорды кӧрӧргӧ *exe јок ойындарды кӧргӱзер* деп опцияны кӱйгӱзигер; список кӱн сайын јаҥыртылат, оныҥ учун Discord процесс кошсо ло, олор ачылар.

### Командалык строка

```
decoy.exe --launch "<Discord списогындагы бӱдӱрер файлдыҥ јолы>" [минуттар]
```

Decoy-ны туура ла иштедет, темдектезе `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Баштапкы кодтоҥ јууры

Керектӱ немелер: [Node.js](https://nodejs.org) 20+, Visual Studio C++ build tools бар [Rust](https://rustup.rs) турумкай ӱзеери (MSVC target) ле WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # hot reload-ту белендеериниҥ режиминде иштедери
npm run tauri build    # src-tauri/target/release/bundle/nsis ичинде инсталлерди јууры
```

Тузалу текшерӱлер:

```bash
npm run check-locales  # кажы ла кӧчӱрмени ru.json-го тӱҥейлеп текшерери
npx tsc --noEmit       # фронтендтиҥ типтерин текшерери
cargo check --manifest-path src-tauri/Cargo.toml
```

Јартамалдар: decoy exe файлы `src-tauri/build.rs` бичимелле `src-tauri/stub/stub.rs` бичимелинеҥ жӧнӧкӧй `rustc` тузаланып компиляцияланат ла колдонмоныҥ ичине кийдирилет. Фронтенд жӧнӧкӧй браузерде иштезе (`npm run dev`), интерфейсле иштеерге келиштирӱ кичинек мок-бэкенд (`src/mock.ts`) тузаланылат.

## Кӧчӱрмелер

Интерфейстиҥ строкалары [`src/locales`](../../src/locales) ичинде, кажы ла тилге бирдеҥ JSON файл (`en.json`, `ru.json`, ...).
Јаҥы тил кожоры — ол бир файл кожоры; кодты солыыр кереги јок. Файлдардыҥ форматы, машиналык кӧчӱрмеге белен промпт ло валидацияныҥ скрипти [docs/TRANSLATING.md](../TRANSLATING.md) бичимелде берилген. Бу README-ниҥ кӧчӱрмелери `docs/i18n/README.<code>.md` ичине чектелет.

## Проекттиҥ бӱдӱми

```
src/                    React + TypeScript фронтенд
  components/           Библиотека, толо маалыматту панель, келиштирӱлер, ...
  locales/              кӧчӱрмелердиҥ файлдары (кажы ла тилге бир JSON)
  i18n-core.ts          тилди јӱктӧӧри ле бедиреш
  store.ts              колдонмоныҥ айалы (zustand)
src-tauri/              Rust бэкенд (Tauri 2)
  src/lib.rs            ойындардыҥ базазы, decoy процесстер, трей
  stub/stub.rs          кийдирилген stand-in программа
scripts/                болушчы скрипттер (локалдарды текшерери)
docs/                   кӧчӱрериниҥ колдонмозы, скриншоттор
```

## Конфиденциальность

- Decoy сетьти јӱк ле Discord-тыҥ ачык бедиреш списогын јӱктеп аларга (баштапкы катап ачарда, оноҥ ары кӱнине бир катаҥ ажыра эмес эмезе јаҥыртар кнопканы бассагар) ла ойындардыҥ сӱрлерин Discord-тыҥ ачык CDN-индеҥ кӧргӱзерге тузаланат.
- Ол слердиҥ Discord токенигерди эмезе аккаунттыҥ бичиктерин кычырбайт, чектебейт ле ыйлабайт, анайда ок Discord клиентле колбу тутпайт.
- Келиштирӱлер (талдалгандар, тил, ӧйлӧр) колдонмоныҥ бойыныҥ WebView сакламында јерлик чектелет; ойындардыҥ списогыныҥ кэши ле убактылу decoy файлдары `%LOCALAPPDATA%\app.decoy.desktop` ичинде чектелет.
- Аналитика јок, сбойлор тужында јетирӱлер јок, аккаунттар јок.

## Јарлу кыйбулар

- Discord ойын таныырын канайда болзо солып ийер аргалу. Эгер decoy танылбай барза, биске issue ачыгар.
- Кери аракеттерге јӱк ле иштеп турган процесс эмес, кӧп неме керек болор аргалу (темдектезе, ойын платформаныҥ тузалу јеринде болоры). Decoy јӱк ле процессти тӱҥейлейт.
- Discord списогында бӱдӱрер файлы јок ойындар табылбайт.
- Корголоош программалар эске чектӱ бош турган цифралык колы јок кичинек файлдарды кээде шектӱ деп кӧрӱп ийет. Decoy ачык баштапкы кодту ла `src-tauri/stub/stub.rs` бичимелинеҥ јуулат; оны бойыгар компиляциялап алар аргалу.

## Каруукерликтенеҥ мойножоры

Decoy бойыныҥ ӱренчик, сынайтан ла шинжӱ амадуларыла тузаланарга «бар болгоныла» берилет. Иштеп турган ойынды тӱҥейлеп јазаары Discord-тыҥ эмезе ойынныҥ ээзиниҥ Тузаланыш ээжилерине келишпес болор аргалу, оныҥ учун слердиҥ аккаунтыгарга каршу јетирер аргалу. Оны канай тузаланганыгарга слер бойыгар каруулу болороор. «Discord» ло бастыра ойындардыҥ аттары ла логотиптери олордыҥ ээлериниҥ товар темдектери болуп јат ла мында јӱк ле программалык јеткилдешти темдектеерге тузаланылат.
