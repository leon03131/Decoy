# Decoy

**Små platshållarprocesser som får Discord att tro att ett spel körs.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="../screenshots/library.jpg" width="860" alt="Decoy-bibliotek med senaste spel och grafik" />

</div>

Decoy håller en ofarlig platshållarprocess med fönster igång under ett spels körbara filnamn, så att Discords
spelidentifiering visar att du spelar det spelet. Du behöver aldrig installera eller starta det riktiga spelet, så
ingenting stort tar upp plats på din disk.

Det känner till **alla spel som Discord kan upptäcka** (cirka 25 000 poster) eftersom det läser Discords egna
offentliga identifieringslista och håller den uppdaterad helt på egen hand.

> [!WARNING]
> Att simulera ett spel som körs kan strida mot Discords användarvillkor och du använder Decoy **på egen risk**.
> Detta projekt är inte anslutet till, sponsrat av eller kopplat till Discord Inc. Se [Ansvarsfriskrivning](#ansvarsfriskrivning).

## Funktioner

- **Allt Discord kan upptäcka.** Spellistan laddas ner från Discords offentliga identifieringsslutpunkt, sparas lokalt
  i cache och uppdateras dagligen. Nya spel och nytillkomna körbara filer dyker upp automatiskt.
- **Sökning som hänger med.** Blixtsnabb sökning efter spelnamn eller körbar fil bland tusentals spel, rutnäts- eller kompakt
  listvy, favoriter och en rad för ”Senaste”.
- **Ett klick.** Välj ett spel, välj körbar fil (om det finns flera), välj hur länge den ska hållas igång och tryck på start.
  En nedräkningsring och en avisering meddelar dig när tiden är slut.
- **Lämnar inga spår.** En decoy finns bara så länge den körs: den lilla exe-filen skapas vid start och raderas vid
  stopp. Allt avslutas när du stänger programmet, och eventuella rester från en krasch rensas bort vid nästa start.
- **Diskret.** Ligger i meddelandefältet, inga fönster eller knappar i aktivitetsfältet för själva decoy-processerna.
- **Öppna översättningar.** Gränssnittet styrs av vanliga JSON-filer, så att lägga till ett språk kräver bara en enda fil.
  Engelska och ryska ingår.
- **Integritetsvänligt.** Inget konto, ingen Discord-token, ingen telemetri. Se [Integritet](#integritet).

## Hur det fungerar

1. Discord avgör att du spelar ett spel genom att titta på processerna som körs på din dator och jämföra deras
   filnamn med en offentlig lista (`/api/v9/applications/detectable`).
2. Decoy laddar ner den listan och kopierar, för det spel du väljer, ett litet ersättningsprogram (cirka 120 KB, skrivet i
   Rust och inbäddat i Decoy) till en tillfällig mapp med filnamnet från listan, till exempel
   `.../cod26-cod.exe`.
3. Ersättningsprogrammet gör ingenting förutom att äga ett fönster på toppnivå, placerat långt utanför skärmen så att du aldrig ser det. Discord
   känner bara igen processer som äger ett fönster, vilket är anledningen till att en helt fönsterlös process ignoreras.
4. Inom ungefär 15 sekunder visar Discord spelet som din aktuella aktivitet.
5. När timern går ut eller du trycker på stopp avslutar Decoy processen och raderar filen. Ett Windows-jobbobjekt säkerställer
   att alla decoys avslutas tillsammans med Decoy, även vid en eventuell krasch.

## Installation

Välj en från sidan för [Releases](../../../../releases):

| Nedladdning | För |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installationsprogram.** Per användare, inga administratörsrättigheter krävs, lägger till ett alternativ i Start-menyn samt ett avinstallationsprogram. |
| `Decoy_x.y.z_x64-portable.zip` | **Portabel.** Packa upp var som helst och kör `decoy.exe`. All data sparas i mappen `data` bredvid filen, ingenting skrivs till din användarprofil. Ta bort mappen för att radera programmet. |

Verifiera en nedladdning med `SHA256SUMS.txt` (`Get-FileHash <fil>` i PowerShell).

Windows SmartScreen kan varna för en okänd utgivare eftersom versionerna inte är kodsignerade; välj
*Mer information → Kör ändå* om du litar på versionen.

Krav: Windows 10 eller 11 (64-bitars) med WebView2-körtiden (ingår redan i Windows 11 och de senaste uppdateringarna av Windows 10).

## Användning

1. Öppna **Bibliotek** och sök efter ett spel, eller tryck på `Ctrl` + `K` var du än befinner dig.
2. Klicka på ett spel. I panelen till höger väljer du process och hur många minuter den ska hållas igång (Discord-aktiviteter
   brukar kräva 15).
3. Tryck på **Starta decoy**. Discord visar spelet efter några sekunder.
4. Håll koll på den under **Körs**, stoppa en eller alla när som helst, eller låt helt enkelt Decoy ligga kvar i meddelandefältet.

Spel vars Discord-post ännu inte har några körbara filer är dolda som standard (de kan inte identifieras). Aktivera
*Visa spel utan exe* för att se dem; listan uppdateras dagligen, så de blir tillgängliga så snart Discord lägger till
en process.

### Kommandorad

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Startar en decoy direkt, till exempel `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Bygg från källkod

Förutsättningar: [Node.js](https://nodejs.org) 20+, den stabila [Rust](https://rustup.rs)-verktygskedjan (MSVC-mål) med
Visual Studio C++ build tools, samt WebView2-körtiden.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Användbara kontroller:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Observera: decoy-exe-filen kompileras av `src-tauri/build.rs` med vanlig `rustc` från `src-tauri/stub/stub.rs` och bäddas
sedan in i appen. När frontend körs i en vanlig webbläsare (`npm run dev`) används en liten mock-backend
(`src/mock.ts`), vilket är praktiskt när du arbetar med gränssnittet.

## Översättningar

Gränssnittets texter finns i [`src/locales`](../../src/locales), en JSON-fil per språk (`en.json`, `ru.json`, ...).
Att lägga till ett språk innebär bara att lägga till en fil; inga kodändringar krävs. Se [docs/TRANSLATING.md](../TRANSLATING.md) för
filformatet, en färdig prompt för maskinöversättning samt valideringsskriptet. Översättningar av denna README placeras i
`docs/i18n/README.<code>.md`.

## Projektstruktur

```
src/                    React + TypeScript frontend
  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup
  store.ts              application state (zustand)
src-tauri/              Rust backend (Tauri 2)
  src/lib.rs            game database, decoy processes, tray
  stub/stub.rs          the stand-in program that gets embedded
scripts/                helper scripts (locale validation)
docs/                   translating guide, screenshots
```

## Integritet

- Decoy använder nätverket endast för att ladda ner Discords offentliga identifieringslista (vid första start, därefter högst en gång om dagen
  eller när du trycker på uppdatera) samt, för visning, spelikoner och grafik från Discords offentliga CDN.
- Det varken läser, sparar eller skickar din Discord-token eller några kontouppgifter, och det kommunicerar inte med Discord-klienten.
- Inställningar (favoriter, språk, tidslängder) lagras lokalt i appens WebView-lagring; cachen för spellistan och
  tillfälliga decoy-filer ligger i `%LOCALAPPDATA%\app.decoy.desktop`.
- Ingen analys, ingen kraschrapportering, inga konton.

## Kända begränsningar

- Discord kan när som helst ändra hur identifieringen fungerar. Om en decoy slutar att kännas igen, öppna gärna ett ärende (issue).
- Vissa aktiviteter kräver mer än bara en process som körs (till exempel att befinna sig i en viss upplevelse på en spelplattform).
  Decoy efterliknar endast processen.
- Poster utan körbara filer i Discords lista kan inte identifieras.
- Säkerhetsprogram kan ibland flagga små osignerade körbara filer som ligger inaktiva i minnet. Decoyen är öppen källkod
  och byggs från `src-tauri/stub/stub.rs`; du kan kompilera den själv.

## Ansvarsfriskrivning

Decoy tillhandahålls i ”befintligt skick” för personliga, utbildnings- och testsyften. Att efterlikna ett spel som körs kan strida mot
användarvillkoren för Discord eller spelets utgivare, och kan leda till åtgärder mot ditt konto. Du är själv
ansvarig för hur du använder programmet. ”Discord” och alla spelnamn samt logotyper är varumärken som tillhör sina respektive ägare och
används här endast för att identifiera programvaran de hänvisar till.
