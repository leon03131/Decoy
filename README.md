# Decoy

**Tiny stand-in processes that make Discord think a game is running.**

![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-7c6cf6)
![Built with](https://img.shields.io/badge/built%20with-Tauri%202%20%2B%20Rust-7c6cf6)
![License](https://img.shields.io/badge/license-MIT-7c6cf6)

<img src="docs/screenshots/library.jpg" width="860" alt="Decoy library with recent games and artwork" />

</div>

Decoy keeps a harmless, windowed placeholder process running under a game's executable name, so Discord's
game detection reports you as playing that game. You never need to install or launch the real game, so
nothing big sits on your disk.

It knows about **every game Discord can detect** (about 25,000 entries) because it reads Discord's own
public detection list and keeps it up to date by itself.

> [!WARNING]
> Faking a running game can go against Discord's Terms of Service and you use Decoy **at your own risk**.
> This project is not affiliated with, endorsed by or connected to Discord Inc. See [Disclaimer](#disclaimer).

## Features

- **Everything Discord can detect.** The game list is downloaded from Discord's public detection endpoint, cached
  locally and refreshed daily. New games and newly added executables show up on their own.
- **Search that keeps up.** Instant search by game name or executable across thousands of games, grid or compact
  list view, favorites and a "Recent" row.
- **One click.** Pick a game, pick the executable (if there are several), choose how long to keep it and press start.
  A countdown ring and a notification tell you when the time is up.
- **Leaves nothing behind.** A decoy only exists while it runs: the tiny exe is created on start and deleted on
  stop. Everything is stopped when you quit, and leftovers from a crash are swept on the next launch.
- **Quiet.** Lives in the system tray, no windows or taskbar buttons for the decoys themselves.
- **Speaks 178 languages.** The interface and this README are translated into 170+ languages, including right-to-left
  ones. Almost all of it is machine-translated, so corrections are very welcome. Adding a language is a single JSON
  file, and the app only loads the language you pick.
- **Private.** No account, no Discord token, no telemetry. See [Privacy](#privacy).

## How it works

1. Discord decides that you are playing a game by looking at the processes running on your PC and comparing their
   executable names with a public list (`/api/v9/applications/detectable`).
2. Decoy downloads that list and, for the game you pick, copies a tiny stand-in program (about 120 KB, written in
   Rust and embedded into Decoy) to a temporary folder using the executable name from the list, for example
   `.../cod26-cod.exe`.
3. The stand-in does nothing except own one top-level window, parked far off-screen so you never see it. Discord
   only recognizes a process that owns a window, which is why a completely windowless process is ignored.
4. Within roughly 15 seconds Discord shows the game as your current activity.
5. When the timer ends or you press stop, Decoy ends the process and deletes the file. A Windows job object makes
   sure decoys die together with Decoy, even if it crashes.

## Install

Pick one from the [Releases](../../releases) page:

| Download | For |
|---|---|
| `Decoy_x.y.z_x64-setup.exe` | **Installer.** Per-user, no administrator rights needed, adds a Start menu entry and an uninstaller. |
| `Decoy_x.y.z_x64-portable.zip` | **Portable.** Unzip anywhere and run `decoy.exe`. All data stays in the `data` folder next to it, nothing is written to your user profile. Delete the folder to remove it. |

Verify a download with `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).

Windows SmartScreen may warn about an unrecognized publisher because the builds are not code signed; choose
*More info → Run anyway* if you trust the build.

Requirements: Windows 10 or 11 (64-bit) with the WebView2 runtime (already included in Windows 11 and recent
Windows 10 updates).

## Usage

1. Open **Library** and search for a game, or press `Ctrl` + `K` from anywhere.
2. Click a game. In the panel on the right choose the process and how many minutes to hold it (Discord activities
   usually ask for 15).
3. Press **Start decoy**. Discord will show the game after a few seconds.
4. Watch it under **Running**, stop one or all at any time, or just leave Decoy in the tray.

Games whose Discord entry has no executables yet are hidden by default (they cannot be detected). Turn on
*Show games without exe* to see them; the list is refreshed daily, so they become available as soon as Discord adds
a process.

### Command line

```
decoy.exe --launch "<executable path from the Discord list>" [minutes]
```

Starts a decoy straight away, for example `decoy.exe --launch "robloxplayerbeta.exe" 15`.

## Build from source

Prerequisites: [Node.js](https://nodejs.org) 20+, the stable [Rust](https://rustup.rs) toolchain (MSVC target) with
the Visual Studio C++ build tools, and the WebView2 runtime.

```bash
git clone https://github.com/leon03131/Decoy.git
cd Decoy
npm install

npm run tauri dev      # run in development mode with hot reload
npm run tauri build    # produce the installer in src-tauri/target/release/bundle/nsis
```

Useful checks:

```bash
npm run check-locales  # validate every translation file against ru.json
npx tsc --noEmit       # type-check the frontend
cargo check --manifest-path src-tauri/Cargo.toml
```

Notes: the decoy exe is compiled by `src-tauri/build.rs` with plain `rustc` from `src-tauri/stub/stub.rs` and then
embedded into the app. When the frontend runs in a plain browser (`npm run dev`) a small mock backend
(`src/mock.ts`) is used, which is handy for working on the UI.

## Translations

The UI strings live in [`src/locales`](src/locales), one JSON file per language (`en.json`, `ru.json`, ...).
Adding a language means adding a file; no code changes. Translations of this README live in `docs/i18n`, and the
language bar at the very top of every README is generated by `npm run readme-langs`.

Spotted a mistake in your language? A pull request that fixes a few lines is the most useful contribution there is.
See [docs/TRANSLATING.md](docs/TRANSLATING.md) for the file format, ready-to-use prompts for machine translation and the
validation scripts.

The installer itself is available in English and Russian; the app is in all languages. Scripts that Windows has no
system font for (very rare) fall back to Windows' own font substitution.

## Project layout

```

  components/           Library, detail panel, settings, ...
  locales/              translation files (one JSON per language)
  i18n-core.ts          language loading and lookup

```

## Privacy

- Decoy only uses the network to download Discord's public detection list (on first start, then at most once a day
  or when you press refresh) and, for display, game icons and artwork from Discord's public CDN.
- It does not read, store or send your Discord token or any account data, and it does not talk to the Discord client.
- Settings (favorites, language, durations) are stored locally in the app's WebView storage; the game list cache and
  temporary decoy files live in `%LOCALAPPDATA%\app.decoy.desktop`.
- No analytics, no crash reporting, no accounts.

## Known limitations

- Discord can change how detection works at any time. If a decoy stops being recognized, please open an issue.
- Some activities need more than a running process (for example being inside a particular experience of a game
  platform). Decoy only imitates the process.
- Entries without executables in Discord's list cannot be detected.
- Security software occasionally flags small unsigned executables that sit idle in memory. The decoy is open source
  and built from `src-tauri/stub/stub.rs`; you can compile it yourself.
